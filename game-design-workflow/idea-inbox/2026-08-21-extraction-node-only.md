# 仅在入口/撤离节点完成主动撤离

> 当前状态：`Raw Idea / Unqualified`
>
> 资格结果：已完成本轮 `grill-with-docs`，并晋级为正式素材；本文件继续保留原始来源和确认过程。

## 原始想法

玩家只有到达入口/撤离节点才能主动结束本次探索。位于资源、事件或战斗等其他节点时，玩家不能随时一键撤退，只能沿相邻节点向可用的入口/撤离节点移动。

## 触发来源

2026-08-21，在确认探索血量跨节点保留后，agent 为避免撤离成为随时可用且不受路线约束的按钮，向用户提出撤离可用性边界；用户确认只允许在入口/撤离节点完成主动撤离。

## 可能带来的玩家体验

- 撤离点的位置会成为路线规划的一部分。
- 低血量时，玩家需要承担返回撤离点途中仍可能遇到风险的压力。
- 玩家进入远离撤离点的路线时，会感到更明确的路线承诺。

## 暂定标签

- 类型：`System / Constraint`
- 情绪：压力、承诺、止损
- 玩法关键词：撤离节点、相邻移动、路线规划、主动结束探索
- 风险关键词：无路可退、软锁、撤离点布局、信息可读性
