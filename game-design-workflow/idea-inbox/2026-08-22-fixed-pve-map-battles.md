# 首个地图原型使用固定 AI/PvE 战斗节点

> 当前状态：`Raw Idea / Unqualified`
>
> 资格结果：已完成 `brainstorming + grill-with-docs`，并晋级为正式素材；本文件继续保留原始来源和确认过程。

## 原始想法

用户原话：“固定 AI/PvE”。

## 触发来源

2026-08-22，共享地图—战斗—撤离 GDD-0 已明确地图会进入战斗，但战斗节点的对手来源仍为 `Unknown`。agent 提出两种重要边界：首个地图原型使用固定 AI/PvE 对手，或直接接入玩家 PvP；推荐固定 AI/PvE，以避免匹配、联网和真人对手差异干扰地图闭环验证。用户确认固定 AI/PvE。

## 可能带来的玩家体验

- 玩家进入战斗节点后立即面对由系统控制的敌方对手，不需要等待真人匹配。
- 战斗损伤仍会返回地图并改变后续路线、返程和撤离判断。
- 不同测试局可以复用相同对手配置，使路线与血量结果更容易比较。

## 暂定标签

- 类型：`Prototype Constraint / System Interface`
- 情绪：压力、可预期、连续性
- 玩法关键词：战斗节点、AI 对手、PvE、地图—战斗接口、探索血量
- 风险关键词：AI 代表性、难度偏差、重复战斗、战前信息
