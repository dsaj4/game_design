# 节点结算完成后返回地图

> 当前状态：`Raw Idea / Unqualified`
>
> 边界：本文件先保留用户确认的节点时序；通过资格闸门前不能作为 GDD 或 Proposal 的正式依据。

## 原始想法

用户确认：玩家进入普通节点后完成该节点的一次结果处理；战斗节点先进入战斗，战斗结束后返回地图。节点结果处理完成并回到地图前，不能选择下一个相邻节点，也不能中途切换路线。

## 触发来源

2026-08-21，在确认地图信息层级、单撤离点原型和撤离点揭示时机后，agent 提出节点进入、结果处理和返回地图的时序方案；用户确认推荐方案。

## 可能带来的玩家体验

- 玩家能理解一次节点选择何时开始、何时结束，不会在结算中途做出路线跳转。
- 战斗成为节点结果的一种完整处理过程，战斗结束后再把结果带回地图决策。
- 地图路线选择保持离散、可追踪，便于测试每次进入节点的影响。

## 暂定标签

- 类型：`System / State Timing`
- 情绪：清晰、承诺、节奏、结果反馈
- 玩法关键词：节点进入、结果处理、战斗返回、地图选择状态
- 风险关键词：时序中断、重复触发、结果未结算、路线跳转
