# 有限人工节点图原型

> 当前状态：`Raw Idea / Unqualified`
>
> 资格结果：已完成本轮 `grill-with-docs`，并晋级为正式素材；本文件继续保留原始来源和确认过程。

## 原始想法

首个地图原型采用有限、人工配置的节点图，至少包含分支路线和可返回的撤离路径，暂不制作程序生成或无尽前进。

## 触发来源

2026-08-21，在确认持续探索血量和仅在撤离节点结束探索后，agent 提出先用有限人工图验证路线、血量和撤离闭环；用户确认，并补充正式版未来将采用程序生成或无尽前进。

## 可能带来的玩家体验

- 玩家能在稳定地图结构中比较至少两条路线。
- 玩家发现撤离点后能预估返程路径和撤离可达性。
- 设计测试能把核心循环问题与地图生成质量问题分开。

## 暂定标签

- 类型：`Prototype Constraint / Map Structure`
- 情绪：规划、风险承诺、可控探索
- 玩法关键词：有限节点图、人工配置、分支路线、撤离可达
- 风险关键词：地图过于线性、路线无差异、节点量级、过拟合单图
