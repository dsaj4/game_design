# 隐藏撤离点连接呈现

> 当前状态：`Raw Idea / Unqualified`
>
> 边界：本文件先保留用户确认的连接呈现规则；通过资格闸门前不能作为 GDD 或 Proposal 的正式依据。

## 原始想法

用户确认：普通节点与隐藏撤离点之间的连接，在撤离点揭示前完全不显示；玩家抵达与撤离点相邻的普通节点时，在下一步选择前连同撤离点节点和连接一起揭示，并永久保留。

## 触发来源

2026-08-21，在确认普通节点拓扑开局公开、撤离点位置保持未知后，agent 提出隐藏撤离点关联连接的显示方案；用户确认推荐方案。

## 可能带来的玩家体验

- 玩家不会从隐藏的出口边或占位符提前推断撤离点位置。
- 发现撤离点时同时获得节点和直接连接，能把发现转化为明确路线目标。
- 普通节点拓扑仍然可规划，隐藏信息只集中在撤离点及其关联连接。

## 暂定标签

- 类型：`Information Rule / Map Discovery`
- 情绪：神秘、发现、方向感、安全希望
- 玩法关键词：隐藏连接、撤离点揭示、拓扑边、永久标记
- 风险关键词：信息断裂、发现后迷路、地图错误感、出口软锁
