# 相邻节点三档风险与收益标签

> 当前状态：`Raw Idea / Unqualified`
>
> 边界：本文件先保留用户确认的标签规则；通过资格闸门前不能作为 GDD 或 Proposal 的正式依据。

## 原始想法

用户确认：相邻普通节点沿用资源、事件、战斗等固定类型；节点成为当前位置的相邻节点时，显示三档粗略风险（低/中/高）和三档收益类别（低/中/高），不显示具体敌人、事件内容或收益数量。

## 触发来源

2026-08-21，在确认普通节点拓扑开局公开、节点内容仅在相邻时显示后，agent 提出相邻节点风险/收益标签方案；用户确认推荐方案。

## 可能带来的玩家体验

- 玩家能在进入节点前形成可解释的风险—收益比较。
- 标签提供方向而不是确定答案，保留节点内容和探索结果的发现空间。
- 玩家可以把标签与当前探索血量、已知撤离点和路线距离结合，决定继续或返程。

## 暂定标签

- 类型：`Information Rule / Risk-Reward Signaling`
- 情绪：判断、权衡、期待、克制
- 玩法关键词：相邻节点、三档风险、三档收益、局部信息
- 风险关键词：标签误读、信息过度简化、伪精确、收益诱导
