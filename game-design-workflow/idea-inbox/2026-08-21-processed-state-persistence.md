# 已处理状态在本次探索中永久保留

> 当前状态：`Raw Idea / Unqualified`
>
> 边界：本文件先保留用户确认的状态持续规则；通过资格闸门前不能作为 GDD 或 Proposal 的正式依据。

## 原始想法

用户确认：已处理节点的状态在本次探索中永久保留，并可显示简洁的“已处理”标记；玩家返程经过时不重新触发原始处理。

## 触发来源

2026-08-21，在确认玩家可以沿已知连接返程且不自动重触发已处理节点后，agent 提出本次探索内永久保留已处理状态；用户确认推荐方案。随后用户确认探索结束或失败后清除，下一次新探索重新建立空白状态。

## 可能带来的玩家体验

- 玩家能清楚区分已处理路径和未处理路径，减少返程记忆负担。
- 永久状态让一次探索的路线历史可追踪，不会因返回而产生规则不确定性。
- 简洁标记保留地图可读性，不强行展示未确认的详细回访信息。

## 暂定标签

- 类型：`System / State Persistence / Map Feedback`
- 情绪：清晰、记忆、方向感、路线承诺
- 玩法关键词：已处理标记、探索内持久状态、返程识别、节点历史
- 风险关键词：状态遗忘、标记过载、跨探索残留、回访歧义
