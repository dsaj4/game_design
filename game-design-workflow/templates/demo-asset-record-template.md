# Demo / 素材登记模板

用途：DA-1资源元数据，不是GDD/合格设计素材模板。按[规范](../../docs/demo-asset-standard.md)填写，可直接嵌入所属方向README、开发索引或视觉包说明；已有权威字段用链接，不再维护副本。删除不适用提示，未知写Unknown，示例占位不作为真实资产登记。

## 〈DM或AS-ID〉〈名称〉

| 字段 | 内容 |
| --- | --- |
| 归属 / 维护位置 | 〈Project ID；main / DIR-NNN / shared-reference；权威文档链接〉 |
| 用途 / 类型 / 标签 | 〈解决什么、用于参考还是交付〉 |
| 主入口 | 〈源文件/包；Demo预览或构建；技术说明；本机/仓库/远端标记〉 |
| 固定版本 | 〈完整提交+路径，或版本+SHA-256/manifest；缺失则Unknown〉 |
| 设计或参考来源 | 〈规则/方向/来源记录及原版本；原设计状态〉 |
| 生命周期 / 访问检查 | 〈Planned/Catalogued/ReadyForScope/Archived；PresentLocal/Reachable/Missing/Unknown；检查日期、实际检查项〉 |
| 来源 / 复用条件 | 〈自制/用户提供/生成/第三方；作者、来源、许可/授权、署名、适用范围及Unknown〉 |
| 关联 / 派生 | 〈uses: ID@版本；derived-from: ID@版本；无则None，未核对则Unknown〉 |

Demo补充：〈已实现范围；未实现和偏差；运行/操作/依赖说明入口；原验证报告及适用版本；本轮是否执行〉。

素材补充：〈文件范围；源文件与导出/预览关系；按类型必要规格；生成提示词/来源；依赖与兼容限制〉。
