## 使用说明

- 本模板承接 [GDD 系统规格](../gdd-writing-requirements-and-template.md)，把同一规格按内容性质分文件；不另建资格或采纳流程。
- 未确认内容放设计页，未知项写 Unknown；没有已确认规则时，规则页保持空白并说明状态。
- 规则性内容仍标明 Qualified／Accepted 等实际状态。设计方向即使放在设计页，已确认的部分也不能静默修改。
- 实际证据填写版本与适用范围；尚未运行就写 NotRun。规则核对不能代替体验观察。
- 示例统一放 examples.md；规则、体验和设计页只链接，不重复维护情境。每例注明依据／状态、前提、步骤、确定结果、未决部分及用途；候选先满足项目资格要求。示例不新增规则、不确立默认数值，也不作为实际验证证据。
- 可选小节不适用时删除，不为填表虚构机制或数值。
