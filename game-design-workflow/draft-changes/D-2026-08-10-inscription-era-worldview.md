```md
### 世界观基底（铭文纪元）

本项目采用“铭文场”作为系统隐喻，而非独立剧情主线：

- 物质与效应可被理解为可调用的字素；玩家是诺莫斯文明派出的拓宇者。
- 唯一核心卡是拓宇者的**本源字**：机制固定、不可资源化，标识其身份与可接纳异界语法的认知上限。
- 通用辅助卡是已知字素词组；组合规则表是语法层，负责语义叠加与动态平衡。
- 共享世界探索对应寻找异源字素 / 异界语法；战斗是关键冲突上的语义解码与收容。
- 母星危机（字素有限常数 Ω）解释长期远征动机；具体剧情、典籍与历史不在本阶段展开。

#### 最小术语映射

| 术语 | 系统对象 |
| --- | --- |
| 拓宇者 | 玩家身份 |
| 本源字 | 唯一核心卡 |
| 已知字素词组 | 通用辅助卡 |
| 语法 / 语义叠加 | 组合规则表 |
| 异源字素 / 异界语法 | 世界探索掉落与遭遇规则 |
| 语义污染 | 环境修正、组合禁用、风险区域 |
| 回响 | 长期目标 / 文明进度反馈（轻量） |
```
