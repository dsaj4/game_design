# 提案名称

铭文纪元世界观：用“字素—词组—语法”解释唯一核心卡与整体系统

## 来源想法

`game-design-workflow/idea-inbox/2026-08-10-inscription-era-worldview.md`

## 核心玩法假设

如果玩家以“拓宇者”身份反复进行“用已知字素词组解析、对抗并收容未知字/规则”，并持续获得“新词组、异源字素线索、回响进度与世界位置变化”，那么当前主线中的唯一核心卡、组合规则表、共享世界资源循环与回合制对战可以被同一套叙事基底统一解释，核心乐趣也会从“纯战斗构筑”升级为“语义探索驱动的长期远征”。

## 玩家会做什么

- 主要动作：
  - 在共享世界中探索、遭遇、争夺资源点与未知铭文场域。
  - 用核心卡（身份本源字/活体字素种子）与通用辅助卡（已知字素词组）进行回合制对战。
  - 通过组合（语法联结）触发更强的语义叠加效果。
- 次要动作：
  - 交易受限字素/辅助卡；向母星“回响”汇报发现进度。
  - 在安全与污染风险之间选择是否启用高风险组合。
- 决策点：
  - 何时单卡稳定推进，何时押注高阶组合。
  - 是否进入未知语法区域（高收益、高认知/战斗风险）。
  - 发现异源字素后，优先自用强化，还是优先回传打破欧米伽危机。
- 反馈方式：
  - 战斗胜负、词组解锁、组合表变化、世界铭文污染/净化状态、回响里程碑。

## 为什么可能好玩

- 把“唯一核心卡”解释为拓宇者不可资源化的本源字身份，直接服务稀缺感与长期资产感。
- 把“组合规则表”解释为可运营调控的语法/修辞层，天然对接动态平衡，而不改核心卡本体。
- 把战斗重定义为语义解码，使战斗成为整体系统中的“关键解决层”：打赢不是终点，收容与理解才是。
- 天算危机与界外拓宇给出共享世界存在的理由：玩家不是在空地图刷怪，而是在文明存续压力下拓宇。
- “语义污染/洁字战争”可把禁用组合、环境修正包装成世界事件，而不是后台数值补丁。

## 已锁定定义

- 唯一核心卡 = **A. 拓宇者本源字**（用户确认于 2026-08-10）
- 含义：机制固定、不可资源化；代表拓宇者身份与可接纳异界语法的认知上限；不是可消耗携带物。

## 最小术语映射（已收束）

| 世界观术语 | 系统对象 | 备注 |
| --- | --- | --- |
| 拓宇者 | 玩家身份 | 强调认知韧性，而非纯战力 |
| 本源字 | 唯一核心卡 | 已锁定定义 A |
| 已知字素词组 | 通用辅助卡 | 母星携带 + 新世界拼凑 |
| 语法 / 语义叠加 | 组合规则表 | 动态平衡主调节点 |
| 异源字素 / 异界语法 | 世界探索掉落与遭遇规则 | 支撑共享世界主循环 |
| 语义污染 | 环境修正、组合禁用、风险区域 | 解释动态平衡 |
| 回响 | 长期目标 / 文明进度反馈 | 先做轻量，不做完整母星模拟 |

## 最小可验证原型

不涉及完整系统，只说明如何用最小成本验证：

- 原型形式：
  1. 一张“术语→系统”对照单页 + 一局纸面卡牌：核心卡 1、辅助卡 8、组合 3。
  2. 一次 20 分钟叙事测试：玩家只读 150 字简介，看是否理解“为何战斗=解码”。
- 需要验证的核心问题：
  - 玩家是否在不读长文的情况下，仍能感到核心卡是“身份本源字”。
  - “组合=语法叠加”是否比“组合=更强技能”更有记忆点。
  - 世界观是否增强探索动机，还是只增加理解成本。
- 成功信号：
  - 玩家能用自己的话复述：我在用已知字去理解未知字。
  - 玩家主动追问“还有没有新字/新语法”，而不是只问伤害数字。
- 失败信号：
  - 玩家觉得设定很酷，但打牌时完全忽略设定。
  - 玩家因术语过多而放弃理解系统。

## 可能的同类参考

- 产品/玩法：以“语言/符文/法则”包装构筑与组合的卡牌或 Roguelike；带远征使命的系统型游戏。
- 相似点：用统一隐喻解释卡牌组合与成长。
- 差异点：本提案用“有限字素 Ω + 异源拓宇”同时解释内容边界、动态平衡与共享世界，不只是魔法皮。
