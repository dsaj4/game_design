# 展示优先的卡面：七款游戏横向研究

2026-10-29 · **Research / LimitedEvidence** · CARD-FACE-RESEARCH-01。研究问题：完整效果说明离开卡面后，怎样用简洁、有特色的图像维持身份与吸引力？本报告记录外部观察与推断；《言咒》的具体转化见[项目意图记录](../../../yanzhou/sources/inbox/2026-10-29-display-first-card-face.md)，不在公共研究中采纳项目规则。

依据官方Steam截图、官方媒体包和开发者文章。实际目视22张图片；部分图片仅用于排除无关镜头。没有启动这七款游戏、测试输入或验证其最新运行版。截图版本Unknown，2023年的开发稿单独标明。

## 结论

**最贴近本次问题的是 Balatro 的 Joker／塔罗牌，以及 BOOK OF HOURS 的主体图设计。** 前者让插画占据正面、解释在独立框中；后者以鲜明的图形隐喻形成卡牌身份，卡牌详情在另外的区域展开。Cultist Simulator适合作为“大量卡片并置时仍能分辨”的参考。它们都不能被概括成“所有卡牌完全无字、无状态”。

简洁可以来自明确的图像主次，并不要求画面退化成一个通用功能图标。图像能提供身份、主题与记忆线索，精确数值、条件和操作权限则需要另外的可靠阅读位置。此处的阅读负担与记忆优势是设计推断，尚无本轮用户测试支持。

### BOOK OF HOURS：图形隐喻比通用功能图标更有身份

![BOOK OF HOURS 2023年官方图标探索稿](E:/Project/game-research/card-face-display-2026-10-29/raw/book-of-hours-icon-sketches.png)

来源：[开发者文章，2023-01-27](https://weatherfactory.biz/boh-the-early-draft-edition/)。这是**概念探索稿**，不是所有备选都已发行的卡牌表。作者说明每组只挑一个成为最终图标。图中既有结、眼、门等抽象形，也有手、动物、器物与局部场景；同一主题的变化来自轮廓、姿态、负形和背景方向，而不只换颜色。文章还讨论图形化卡牌与有纹理的世界物件如何并存。【E2】

判断：简洁可以保留叙事意味。用独特的物象、结构或姿态代替“盾=防御、剑=攻击”的统一按钮式表达，更有机会形成作品自己的图像语言；可读性是否仍足够，需要后续样张比较验证。【E2，分析推断】

## 七款游戏分别解决了什么

| 游戏／相关情境 | 正面实际保留 | 说明与信息放哪里 | 值得提取的结构／边界 |
| --- | --- | --- | --- |
| **Balatro**：并列识别Joker、查看塔罗牌 | 主体插画、扑克牌骨架、装饰字或题名 | 所选Justice截图显示独立说明框；其他牌种不可由此一概而论 | 最接近展示优先；具体能力仍需要可读说明【E1】 |
| **BOOK OF HOURS**：从卡列选用对象、查看详情 | 大主体图、短题签；部分卡有数量／计时等状态 | 所选图右上详情区、任务窗与属性区 | 主题隐喻鲜明；不能把密集属性区照搬成新卡框【E2】 |
| **Cultist Simulator**：在桌面辨认卡、投入动作窗 | 色底、物象／人物／符号、名称带；部分带计时和数量 | 所选图右上详情和中部动作窗口 | 同一骨架容纳不同图像；名称有实际身份作用【E3】 |
| **Reigns**：读事件、辨认当前说话者 | 大块几何人物肖像 | 所选图的事件句在肖像上方、姓名在下方、全局状态在另一区 | 学习形体概括和留白；这是单事件焦点界面，不能直接证明适合多牌并列【E4】 |
| **Stacklands**：在牌堆中识别物品、查看用途 | 顶部名称、手绘物象、色底、少量数字 | 图0左下说明；图1图鉴的说明在卡片下方 | 展示与解释分离很直接；卡面仍有短信息，不等于纯插画【E5】 |
| **Inscryption**：辨认桌上与手中战斗牌 | 名称、动物画、费用符号、攻防数字等 | 本次图不能证明全部能力解释的位置 | 只借鉴粗线、印刷与统一纸感；它仍是明显的信息卡，非本轮布局主参考【E6】 |
| **Signs of the Sojourner**：在对话牌列中辨认连接符号 | 左右几何符号、中央连接纹、少量能力图标 | 叙事文字在独立对话区域；全部能力说明方式未核实 | 无段落文字仍可能是规则驱动卡面；不应误当纯展示卡【E7】 |

表中“情境”仅帮助理解信息为何这样分配，不是完整玩法拆解。相似外观在多牌桌面、单张焦点和符号接龙中承担不同工作。

## 可以直接观察的图像元素

| 元素 | 这些参考中的有效做法 | 展示优先时的取舍 |
| --- | --- | --- |
| 主体轮廓 | 极简脸、单个器物、剪影或自成构图的物象 | 每张牌有一个首要视觉焦点；避免所有牌都变成“图标＋同款底框” |
| 颜色 | 少量大色域、主体与背景有明确明度差 | 颜色辅助识别，同时保留轮廓差异；不从截图自行推定全套配色规则 |
| 留白／负形 | 主体周围空白，或让背景成为主体的一部分 | 留白参与构图，删掉效果区后重新安排图像，不能只留下空白说明框 |
| 框与边缘 | Balatro保留统一扑克牌形态；Reigns弱化肖像内部边框 | 框主要提供实体感和家族感，少做多层金边、角饰与重复分类章 |
| 纹理 | 像素印刷、手绘线条、纸感分别建立不同气质 | 一套主媒介即可；“有特色”不需要同时堆纸斑、排线、发光和复杂法阵 |
| 题名 | CS／BOH／Stacklands保留名称，Balatro塔罗有题名 | 效果外置与取消名称是两个决定，不能互相代替 |
| 动态状态 | 一些参考仍保留计时／数量／数值 | 规则说明移出后，瞬时状态也需要有明确去处；本报告不替目标项目选择宿主 |

上表前半来自图像观察，右列为跨案例提炼。没有测量“图像应该占多少百分比”，也没有据宣传截图推断新手学习效率。

## 由研究得出的设计假设

1. **先拆分图像与解释的职责。** 保持卡面完整，选中对象时在卡外读取条件、费用和结果；这可能减少牌面视觉噪声，但也可能增加逐张查看。成功信号是识别更快且解释仍容易找到，失败信号是频繁来回查看、把插画隐喻当成精确规则。
2. **通过物象与形体建立特色。** 在同一媒介内比较印记、器物寓言、极简版画三条路线。特色来自对主题的独特处理；直接复用他作的眼、结、动物或牌框，会带来雷同与识别体系混杂。
3. **主视图的克制需要查看层配合。** 题名与必要状态可以有独立宿主；不能假定艺术图本身能完整解释一张复杂牌，也不能把取消说明区变成一排只有老玩家看得懂的小符号。
4. **先做图像选型，暂不锁定所有交互。** 同一批内容制作纯图面、带极短题名等静态比较稿；在多张缩小并列和单张查看中比较。此处只是建议的验证方式，本轮未生成新稿、制作原型或执行玩法实验。
