## 局部可支持的事实

| 观察 | 支持范围 | 限制 |
| --- | --- | --- |
| 伤害内部流程先加性修饰、再逐项乘性修饰、随后检查伤害上限 | 两种修饰分阶段，倍率在所读流程中逐项连乘 | 不代表所有卡效无特殊步骤；不提供加工时间公式 |
| 力量按所属攻击者与攻击资格提供固定量，可为负 | 固定修饰与倍率不同；来源和作用资格需明确 | 不能把所有Buff都当成力量式线性数值 |
| 虚弱／易伤的通常倍率分别为0.75／1.5，存在遗物等改写接口 | 条件匹配时返回一个有效倍率，而不是按层数循环乘倍率 | 特殊改写对象未全部展开，不声称覆盖所有交互 |
| 虚弱／易伤的层数通过回合末递减维持时长；双倍伤害返回2倍并有自己的递减条件 | 效果强度与层数／持续时间不能仅按名称混同 | 各种Buff生命周期不同，没有推导统一叠层政策 |
| 格挡局部还先处理附魔，再进入普通加性与乘性阶段 | 外部系统可能有额外专用处理阶段 | 不能把局部伤害次序泛化为所有数值共用同一流程 |

DamageCmd的特定动态伤害入口注释提到适当位置的中间向下取整；本轮未追完整调用路径，**不据此宣称游戏全部统一最终取整，也不把时间向上取整归因于参考游戏**。

## 可迁移的方法与不可迁移的结论

可以借鉴：先明确对象与资格，再区分固定量和倍率；多个有效倍率连乘；每种Buff单独声明层数改变强度还是时长；显示和结果使用同一规则。仍需检查例外，不能只看Buff名字猜计算方式。

不能直接迁移：攻击／格挡的具体倍率、遗物例外、伤害上限、取整位置、回合末递减条件，或“连乘必然更有策略”的体验结论。本报告不包含任何目标项目的采纳、参数或资格；项目转化由各项目sources另行记录。
