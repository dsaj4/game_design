# Anode Heart: Layer Null Outline

## Thesis

The supplied materials support a concise but real Phase 1 dossier: Anode Heart: Layer Null is best described as a collection/deckbuilding card battler whose repeated pleasure comes from rebuilding a deck around color/tag synergies, then resolving dense board-state decisions through summon effects, response windows, typed energy, evolution/growth, and combat spillover. Visual evidence strongly supports the combat and system-surface claims, while market, narrative, and exact long-term progression claims remain under-evidenced.

## Target Questions

- Can this BiliSum material support a comprehensive and accurate gameplay analysis dossier?
- What are the core loop, combat resolution, deckbuilding constraints, in-run economy, and growth routes of Anode Heart: Layer Null?
- Which structures can transfer into the current unique-core-card card-battle project?
