# 战前构句、循环法术与法杖设置适配

## 修改目标

将战前“构句—构成法术—设置法杖”明确为当前自动战斗的配置流程，并把此前战中构句、状态、法术类型与全局道具设计中仍兼容的部分迁移到新框架。该变更承接 `Core Concept v0.4`，形成 `Core Concept v0.5 / Stable Design Baseline`。

## 来源

- 用户在 2026-09-09 明确要求：战前构句沿用战中构句逻辑，一组组合对应一道法术，完整词卡库存可用于装配；设置法杖决定法术绑定关系，法杖镶嵌承接原全局道具方向。
- [纵向时间背包的战前编排与循环调度](../../../../exploration/game-002-optimization/idea-materials/M-2026-09-09-timeline-backpack-scheduling.md)：TS1–TS8，已作为时间背包来源合并。
- [省略句与显式主语](../idea-materials/M-2026-09-06-flexible-sentences-and-subject-roles.md)、[整句效果与词义复用](../idea-materials/M-2026-09-06-compositional-spells-and-word-meaning.md)、[法术类型与全局道具触发](../idea-materials/M-2026-09-06-spell-types-and-item-triggers.md)、[全局道具的基础持有与生效](../idea-materials/M-2026-09-07-global-item-ownership-and-passive-effects.md)：作为兼容规则来源，按本变更重新解释其战前适用范围。

时间背包素材中关于 4+1 示例和“敌方命中同刻优先打断释放”的早期表述不随本次适配进入当前规则；当前稳定基线明确为冷却从第 0 刻开始、4 刻冷却后第 4 刻释放，并按同刻“法术效果—敌人攻击—环境变化—状态效果”结算。

## 已采纳的设计文本

```md
每场战斗开始前，玩家依次完成三个不推进战斗时间的配置阶段：构句、构成法术、设置法杖。

构句与构成法术沿用此前战中构句的合法性与语义逻辑：名词、动词的词性限制，动宾句与名动名句，省略主语与显式主语，执行者、操作内容和受术目标的区分，语义兼容，状态引用，以及已确认的法术类型判定均继续适用。一个合法组合共同定义一条完整法术；组合中的多个词不分别施法，多个相关变化仍属于同一法术。构句阶段可以使用当前战外词卡库存中的任意实体词卡，不经过抽牌、手牌或补牌。每张实体词卡在本次战前配置中最多归属于一条循环法术；同名法术需要对应数量的实体副本，未使用的词卡可以留在库存中。

构成法术后，每条法术成为战斗中自动循环尝试释放的一条循环法术。战前配置保存的是法术组合及其使用的实体词卡分配，不是一次性消耗；战斗中不再进行构句、抽弃词卡或补牌。状态引用仍需投入对应的宾语词卡，引用本身不自动消耗状态；状态的生成、保留、重施、叠加与结算继续遵循已确认的状态规则。法术完成时读取效果所需的状态和执行者修正，具体读取时点沿既有法术结算规则。

设置法杖阶段为每条循环法术绑定一根法杖；基础规则中每根法杖承载一条循环法术。玩家在此阶段同时确定法杖及其法术的前后顺序，顺序靠后的法术在同刻释放冲突时覆盖靠前法术。法杖的镶嵌系统承接此前全局道具的效果设计方向：未来由镶嵌配置为对应法杖提供施法范围、特殊效果或其他明确修正。法杖镶嵌是法杖配置的一部分，不把旧版“全局道具无需装备槽、全部直接生效”的承载方式自动带入当前框架。

法杖绑定与镶嵌完成后，玩家在第 0–10 刻安排每条循环法术第一次冷却的开始时刻。冷却从第 0 刻开始时，4 刻冷却加 1 刻释放的法术在第 4 刻首次释放；循环周期为冷却与释放之和。启动后各法术按自身周期独立循环，覆盖和生命伤害打断只影响当次释放机会，不改变后续周期。
```

## 兼容关系

| 旧设计内容 | 当前适配方式 |
| --- | --- |
| 主谓宾职责、词性与语义兼容 | 保留，作为战前组合的合法性检查 |
| 省略主语与显式主语 | 保留，改变法术的执行者或施法形式 |
| 一句一法术、词义复用 | 保留，一个组合只产出一条循环法术 |
| 状态引用、状态保留、重施、叠加和周期读值 | 保留，转为循环法术每次完成时的效果规则 |
| 执行者、操作内容、受术目标 | 保留，战前确定语义关系，目标沿当前战场对象规则处理 |
| 法术类型与触发条件 | 保留，按战前构成的法术特征判定，具体触发时点沿现行规则 |
| 全局道具的被动修正与特殊效果 | 迁移为法杖镶嵌候选效果；旧全局持有和直接生效边界不再自动适用 |
| 战中抽牌、手牌、补牌、逐句施法与投入后弃置 | 当前首版移除，仅保留为历史来源 |
