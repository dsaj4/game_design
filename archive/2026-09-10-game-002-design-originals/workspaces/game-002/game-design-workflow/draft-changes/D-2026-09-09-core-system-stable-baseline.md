# game-002 全系统稳定基线审查

## 审查目的

用户要求对 game-002 当前系统做一次全系统检查，统一各部分表述，确认冲突，并将已确认规则冻结为可继续进行数值与原型工作的稳定版本。

## 规则优先级

当前规则以 `Core Concept v0.4 / Stable Design Baseline` 为最高设计口径，其次是 `decision-log.md` 中最新的 Accepted 决定，再次是本工作区的 Draft Change。早期 Qualified GDD Material、idea-inbox 和旧原型记录保留为来源与证据，不覆盖当前核心；其中与 v0.4 冲突的内容必须按历史记录理解。

## 已检查并统一的系统边界

| 检查项 | 当前稳定口径 |
| --- | --- |
| 战斗模式 | 自走棋式自动战斗；战中无牌组、手牌、补牌和战中构句 |
| 战前构筑 | 战斗外保留词卡库存；战前从库存构筑循环法术、设置法杖和顺序 |
| 法杖关系 | 每根法杖只承载一条循环法术；法杖确定该法术范围 |
| 时间轴 | 所有首次冷却在第 0–10 刻开始；周期为冷却加释放；第 0 刻开始的 4+1 法术第 4 刻首次释放 |
| 同刻释放 | 每刻一个共享释放槽；靠后的法术覆盖靠前法术，被覆盖本次无效果且无释放特效，后续周期不变 |
| 目标 | 长方形地图中对象占据实际位置；第一阶段不移动；首版战前固定范围内合法对象 |
| 失效 | 失效目标不结算并跳过，法术继续处理其他合法对象；失效目标无实际效果但播放释放特效 |
| 打断 | 只有玩家实际受到生命伤害才打断，且只打断正在冷却的法术；护甲全额抵伤不打断；不追溯已结算法术 |
| 同刻顺序 | 法术效果 -> 敌人攻击 -> 环境变化 -> 状态效果 |
| 终止 | 胜利成立后立即停止所有后续处理，包括法术 |
| 环境对象 | 有位置、可被法术作用、无生命值和攻击行为 |
| 收益 | 金币来自基础收益、时间额外奖励和特殊法术效果；卡牌由法术效果产生；战后整体领取或放弃 |

## 冲突处理

早期素材中关于战中牌组、手牌、补牌、逐句施法、施法耗时和“本局卡组”的表述不删除，继续保留其历史来源和原有证据状态；它们不再作为 v0.4 首版运行规则。后续设计使用“战外词卡库存”描述可用于战前构筑的词卡集合，避免与已取消的战中牌组概念混淆。

## 稳定版本边界

本次稳定冻结的是规则口径，不是具体词义、卡片效果、状态强度、法杖范围参数、词卡容量、敌人参数、奖励数量、目标动态扩展、移动扩展、数值平衡、原型表现或玩家体验结论。任何改变上述稳定规则的内容都需要新的 Draft Change 和决策记录。

状态：`Accepted / Stable Design Baseline`；证据状态：`Hypothesis`。
