# 核心卡战斗机制与第一阶段数值草案

## 核心玩法假设

如果战斗把唯一核心卡固定为“战术解释器”（独立区域 + 有限组合槽），并用简单递增费用约束节奏，那么玩家会围绕核心卡做可读的构筑与时机决策，同时运营方可只调组合规则表而不改核心卡本体。

## 玩家会做什么

- 主要动作：打出辅助卡、激活核心卡、发动组合、有限响应（防/扰）
- 次要动作：预填组合槽、管理手牌与费用曲线
- 决策点：本回合稳定推进 vs 攒费开组合；防自己生命 vs 打断对方组合
- 反馈方式：伤害/护盾、语义稳定、组合触发特效、槽位占用变化

## 为什么可能好玩

- Commander 式身份 + Balatro 式槽位修正 + 宝可梦式焦点，匹配“唯一核心卡”
- 费用曲线保证对战节奏可控（对标炉石/Snap），避免游戏王式长连锁
- 组合规则表可运营，保护核心卡稳定预期
- 适配“豪杰/王权”这类低适性高韧性幻想：基础动作可靠，爆发靠槽位与时机，不靠华丽天赋数值

## 推荐战斗框架（第一阶段）

### 1. 核心卡定位

- 独立固定区域，始终在场（不进牌库）。
- 角色：构筑身份入口 + 战斗焦点 + 组合解释器。
- 不建议：把核心卡做成普通大怪，或纯被动倍率器。

### 2. 回合与费用

| 项 | 建议值 | 理由 |
| --- | --- | --- |
| 起始费用 | 1 | Snap/炉石式可读成长 |
| 每回合费用上限增加 | +1 | 到中期自然解锁组合 |
| 费用上限 | 6 | 比炉石 10 更短对局 |
| 回合开始抽牌 | 1 | 标准 |
| 起始手牌 | 5 | 快速进入决策 |
| 手牌上限 | 7 | 抑制囤牌爆炸 |
| 对局目标时长 | 8–12 回合 | 适配关键解决层，不宜过长 |

### 3. 生命与胜负

| 项 | 建议值 | 备注 |
| --- | --- | --- |
| 玩家生命（语义稳定度） | 30 | 略高于炉石 30 的“英雄血”体感，便于护盾玩法 |
| 核心卡耐久（可选） | 无 / 或不作为胜负条件 | 第一阶段建议核心卡不可被击杀，避免身份资产被局内抹除 |
| 胜负 | 对方生命归零，或完成遭遇目标 | PvE 可改为倒计时/收容进度 |

### 4. 牌组规模

| 项 | 建议值 |
| --- | --- |
| 辅助卡组规模 | 20–24 张 |
| 同名辅助卡上限 | 2（关键稀有 1） |
| 核心卡 | 1（身份位，外置） |
| 组合槽 | 2（后期成长可到 3） |

### 5. 响应规则（极简）

- 仅两类：受到攻击时可防御响应；对方发动组合时可干扰响应。
- 每次行动最多 1 次响应窗口，不做多层连锁。

## 数值曲线草案

### 费用—期望伤害（单卡，无组合）

| 费用 | 期望净效果（攻击向） | 设计意图 |
| --- | --- | --- |
| 1 | 3–4 伤 或 抽1 | 过牌/点伤 |
| 2 | 5–6 伤 或 4伤+小附加 | 曲线中坚 |
| 3 | 7–8 伤 或 5伤+强附加 | 中费节拍 |
| 4 | 9–10 伤 或 控场效果 | 偏重 |
| 5 | 11–13 伤 或 强干扰 | 高费但非必胜 |
| 6 | 14–16 伤 或 终结技雏形 | 应少于组合爆发 |

经验法则：**单卡伤害约等于 `2.5 × 费用 + 1`（可 ±1）**，强关键词（穿透/打断）需降 1–2 点伤害。

### 组合倍率（相对同费单卡）

| 组合档 | 费用区间 | 相对同费单卡强度 | 每局次数建议 |
| --- | --- | --- | --- |
| 轻组合（核心+1辅） | 2–3 | 130%–150% | 不限 / 或 3 |
| 标准组合 | 3–4 | 160%–190% | 2 |
| 重组合（核心+2辅或高槽） | 5–6 | 200%–240% | 1 |

原则：组合必须明显强于单卡，但重组合应吃掉整回合大部分费用，并受槽位/次数限制。

### 防御/护盾

| 费用 | 护盾期望 | 备注 |
| --- | --- | --- |
| 1 | 4–5 | 略高于同费攻击，鼓励防守节奏 |
| 2 | 7–8 | |
| 3 | 10–11 | 可附带反制条件 |

### 辅助卡四类配比（20 张示例构筑）

| 类型 | 张数 | 占比 |
| --- | --- | --- |
| 攻击 | 7–8 | 35%–40% |
| 防御 | 4–5 | 20%–25% |
| 调度 | 4–5 | 20%–25% |
| 干扰 | 3–4 | 15%–20% |

## 核心卡模板字段（生成/手写共用）

每张核心卡建议只暴露这些可玩字段：

1. **本源机制（不可改）**：1 条被动解释规则 + 1 个主动（费用 1–2）
2. **标签**：主标签 1 + 副标签 1–2（如：稳、攻、调度、干扰、收容）
3. **组合槽**：默认 2
4. **适性评级（叙事）**：S/A/B/C 不影响基础数值上限，只影响可选机制池的“华丽度/复杂度”
5. **等级**：影响匹配与交易，不直接加伤（避免成长碾压）

### 示例：豪杰向核心卡（B，稳）

- 被动：你的基础攻击类单卡不会因负面效果“失效”，最低仍造成 1 点效果；语义塌缩/沉默类环境中，体能行动可替代 1 次调度。
- 主动（费用 1）：检查——本回合第一次受伤减少 2。
- 标签：`稳` `救援`
- 组合偏好：防御+调度；轻组合多、重组合少。

### 示例：王权向核心卡（C，承诺）

- 被动：你可“宣告”一个本回合目标；若本回合内兑现，下回合费用 +1（每回合最多一次）。
- 主动（费用 2）：号令——抽 1，且一张友方下张攻击 +2。
- 标签：`号令` `声望`
- 组合偏好：调度+攻击；偏中费组合。

> 适性 C/B 不降低生命或费用成长；差异放在机制复杂度与组合覆盖面，避免“低评级=废物卡”。

## 动态平衡旋钮（只调组合层）

优先顺序：

1. 组合费用  
2. 组合每局次数  
3. 组合倍率  
4. 槽位占用  
5. 环境禁用某标签组合  

禁止直接改：核心机制文本、核心卡持有属性。

## 最小可验证原型

- 原型形式：纸面或纯战斗 Demo；3 张模板核心卡 × 共享 24 张辅助池；无大地图。
- 需要验证：
  - 玩家是否理解“核心卡解释辅助卡”
  - 2 槽是否够用且不爆炸
  - 8–12 回合内是否常出现有意义的组合决策
- 成功信号：复盘时玩家先谈核心卡差异，再谈具体伤高
- 失败信号：只会点杀；或组合必胜导致无单卡回合
