```md
## 一句话概念

一款围绕唯一核心卡展开构筑、探索、资源竞争、交易与回合制卡牌对战的 2D 系统型游戏。玩家以不可资源化的核心卡作为身份与长期资产，在共享世界中通过外围玩法获得资源、辅助卡与战斗机会，再用卡牌对战解决关键冲突。

## 整体系统核心结构

### 核心卡层

核心卡仍是玩家身份、构筑中心和长期资产。它既决定战斗中的组合方向，也决定玩家在世界系统中的路线偏好、争夺目标和长期判断。

### 战斗层

战斗继续采用“唯一核心卡 + 通用辅助卡 + 激活费用 + 组合规则表 + 回合制对战”的主框架，但它现在是整体系统中的关键解决层，而不是唯一优先推进对象。

### 世界与资源层

共享世界、资源点、探索、占领、开发、野外遭遇与事件，将成为战斗外的长期循环来源。它们负责制造目标、风险、争夺和差异化发展路径。

### 交易与成长层

资源、辅助卡、节点收益与部分资产可进入交换和积累循环；核心卡仍保持不可资源化与受限交易，确保身份价值不会被一般经济系统完全吞没。

### 动态平衡层

动态平衡不只作用于组合规则，也可作用于资源产出、掉落分布、进入门槛、事件密度和交易摩擦，但仍尽量保护核心卡本体的稳定预期。

## 当前阶段推进范围

当前阶段不再只细化单局战斗，而是优先明确整体系统闭环：

- 战斗如何被地图、资源与世界目标触发。
- 资源如何流向构筑、扩张、掉落与交易。
- 核心卡如何在长期循环中保持身份感、稀缺性和成长动机。
- 世界观如何解释唯一核心卡、资源争夺和玩家冲突。

当前阶段可以正式推进：

- 共享地图或世界结构提案。
- 资源系统与产出/消耗关系。
- 野怪/Boss、掉落、遭遇与外部目标。
- 交易与长期成长结构。
- 服务上述系统的世界观框架。

暂不在核心文档中展开：

- 详细数值平衡表。
- 完整自动化动态平衡后台。
- 真实 AI 生成核心卡的最终技术管线。
- 完整剧情脚本或海量设定文本。
```

## 采纳理由

此前把主线收束为卡牌战斗原型，有利于控范围，但也切断了项目最初最强的长期动机来源：世界目标、资源争夺、长期资产与外围反馈。用户现在明确要求转回整体系统构思，这一修改使正式主线重新对齐“唯一核心卡驱动完整系统”的项目初衷。

## 仍需保留的疑问

- 整体系统里，战斗究竟是唯一冲突解决器，还是最主要但非唯一的解决器？
- 世界资源循环是否会过强，导致构筑与战斗变成从属层？
- 核心卡掉落、交易和成长之间如何保持稀缺与公平？
- 世界观框架应先服务规则解释，还是先服务情绪与题材识别？
