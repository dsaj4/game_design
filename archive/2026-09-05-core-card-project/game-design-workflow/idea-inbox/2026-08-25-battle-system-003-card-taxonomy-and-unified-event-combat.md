# 战斗系统 003：卡牌分类、统一事件战斗与情境互动

## 原始想法

基本沿用字素合成战斗系统，做澄清和修改：

1. 卡片定位修改：分为字素卡和行动卡。
   - 行动卡代表个人动作，一回合可多次打出，不消耗费用，但没有直接收益。
   - 字素卡代表可用资源，一回合使用即消耗，消耗费用，但单独打出也有收益。
2. 事件战斗系统统一：不存在额外选择选项的事件，所有事件/战斗玩家共享一个页面、一套卡组、同样的约束；区别在于具体卡牌的效果不同。
3. 事件系统触发：玩家对事件也可以打出卡牌，事件会因打出卡牌不同获得不同收益，且往往和行动卡联系紧密。例如“煤矿突显！”事件中，使用“采集”行动卡获得高额收益；使用“土元素”字素卡或“压缩”行动卡获得一般收益。
4. 合成系统理清：不再构建临时合成和战斗外事件合成，玩家随时随地均可以合成。合成成为类似打牌一样的基础动作，可以发生在自己回合战斗/事件系统触发的任何时间，成为游戏的核心机制之一。合成表中行动卡不再消耗，玩家声明合成，通过若干行动卡加若干字素卡，或者若干字素卡的组合，字素卡消耗而行动卡不消耗，生成新卡，视为一次合成。
5. 合成系统补偿：为了防止玩家因合成导致资源消耗或不可逆操作，存在特殊的分解事件可以打出合成卡获取基础卡。
6. 环境系统加入：玩家对于周围环境也可以使用行动卡进行互动。例如在山地使用采集，概率获得“土元素”；对于敌人也可以使用行动卡，例如对低血量、眩晕的史莱姆使用压缩可以获取额外史莱姆黏液。

## 可能带来的玩家体验

- 通过情境识别和动作匹配获得“我找到了正确处理方式”的掌控感。
- 在统一的战斗、事件、环境页面中持续使用同一套卡牌语言，降低系统割裂感。
- 通过消耗字素资源、复用行动卡和随时合成获得构筑与临场应变的张力。
- 通过分解事件降低合成造成的不可逆焦虑，同时保留长期资源取舍。

- 类型：战斗系统 / 事件系统 / 合成系统 / 环境互动
