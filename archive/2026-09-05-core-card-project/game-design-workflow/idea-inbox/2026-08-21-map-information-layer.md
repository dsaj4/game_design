# 普通节点拓扑公开与相邻信息显示

> 当前状态：`Raw Idea / Unqualified`
>
> 边界：本文件先保留用户确认的原始表达；通过资格闸门前不能作为 GDD 或 Proposal 的正式依据。

## 原始想法

用户确认：首个地图原型开局公开完整地图拓扑，也就是所有普通节点的位置和连接关系；普通节点的类型、粗略风险和收益类别，只有在它成为当前位置的相邻节点时才显示。撤离点继续保持未知，并沿用相邻揭示规则。

## 触发来源

2026-08-21，在确认撤离点保持未知并于相邻节点揭示后，agent 提出地图信息层级方案；用户确认推荐方案。

## 可能带来的玩家体验

- 玩家可以依据普通节点的位置和连接规划分支，而不必完全盲走。
- 玩家只能在接近普通节点时判断其风险和收益，保留局部发现与路线取舍。
- 撤离点仍通过寻找和相邻揭示提供神秘感，不会被完整普通节点拓扑抵消。

## 暂定标签

- 类型：`Information Rule / Map Presentation`
- 情绪：规划、发现、克制、神秘
- 玩法关键词：普通节点拓扑、相邻信息、风险可见性、撤离点隐藏
- 风险关键词：信息过载、局部盲猜、隐藏出口连接、风险等级误读
