# 原始想法隔离区

本目录允许保存模糊、不完整或尚未确认的原始想法，状态统一视为 `Raw Idea / Unqualified`，不具备 GDD、Proposal、Evaluation、Draft Change 或核心构思的正式引用资格。

## 晋级规则

- 用户提出零散构思时，agent 先保留原始表达，再使用 [`grill-with-docs`](C:/Users/Administrator/.codex/skills/grill-with-docs/SKILL.md) 逐项澄清。
- 只有通过资格闸门，才能复制 [合格 GDD 素材模板](../../../../game-design-workflow/templates/qualified-gdd-material-template.md) 写入 `../idea-materials/`。
- 未达标内容继续留在本目录，并记录下一个最关键的澄清问题。
- GDD 或 Proposal 不得直接引用本目录中的内容；若用户希望采用，必须先晋级正式想法素材库。

## 历史文件

已有文件保留原始内容和历史勾选，不自动迁移或自动判定为合格。历史文件中的“已整理成提案”等文字，必须在实际使用前重新通过当前资格闸门。

旧版 Proposal、Draft Change 或决策记录可能直接链接这些 inbox 文件；这些链接属于历史溯源，不是当前 `Qualified GDD Material` 资格证明。新建或更新的正式文档必须改为引用 `idea-materials/`。
