# 字素组合构筑：基础铭文 × 字词合成（发散补充稿）

## 原始想法（用户草案摘要）

- 卡牌体系：基本「字」+ 复数基本字合成的复杂「字词」。
- 例：手牌「水」「火」可合成「气」；「气」也可由事件/击杀/商店获得（类 STS）。
- 核心卡：每名玩家一张独有基础铭文；是否仅本局存在待定。
- 铭文组合上限 = 铭文耐性（例：豪杰耐性 6 → 一个复杂字最多堆叠 6 个基本字）。
- 费用直觉：元素 1 + 处理方式 1（压缩/发散/加热…）+ 使用手段 1（释放/保护/增幅…）+ 其他 1。
- 已有样例：水/火/气/毒/砂、蒸汽/冷气/毒气/酸、压缩/堆砌、水刃/气枪/土墙/混凝土/混凝土墙/高压蒸汽等。

## 触发来源

用户 2026-08-14 卡牌核心机制草案；承接 `P-2026-08-13-core-card-combat-numbers.md` 与铭文纪元设定。

## 设计澄清（建议先锁这 4 条，灵感才不会散）

1. **两层牌，不是两套规则**  
   - 基础字：可打出，也可作为合成材料。  
   - 字词：合成结果或奖励直接获得；占用「耐性层数」= 构成它的基本字数量（直接掉落的字词也要标注层数）。

2. **核心铭文（建议默认）**  
   - 对齐全案「拓宇者本源字」：账号长期身份，**本源机制跨局保留**。  
   - 「本局独有」留给：本局随机的**辅铭/环境字**或**本局变异旁注**，不要和身份核抢位置。  
   - 若你更想做纯 Roguelike 单局 build：可改成「本局抽取本源字」，但会削弱交易/养成主线。

3. **费用统一成可读公式**  
   - `费用 = 元素层 + 处理层 + 手段层 + 修饰层`（每层默认 1，特殊字可 0 或 2）。  
   - 手牌里「已经合成好的字词」打出时付**合成后标价**，不必再现场拆层心算。  
   - 「冷气（0 费）」作为稀有的负/零费调度，应限次或附带脆弱，避免破曲线。

4. **耐性 = 单卡复杂度上限，不是手牌数量**  
   - 豪杰 6：单张字词最多含 6 个基本字。  
   - 王权（C）可给更低耐性（如 4）但用核心机制补「承诺兑现」资源，形成差异。

## 可能带来的玩家体验

- **炼金感**：水+火=气 的「识字创造」。  
- **STS 成长感**：商店/精英掉落成品字词，缩短合成路径。  
- **耐性张力**：想做混凝土墙（3 层+）就要排队耐性与手牌空间。  
- **身份差异**：同牌池，豪杰能堆更厚的字，王权更能「宣告后兑现」低耐性爆发。

## 处理层扩充（默认各 1 费；可作独立牌或合成标签）

| 处理 | 单独/作为标签时 | 典型合成 |
| --- | --- | --- |
| 压缩 | 弃 1 牌，获得 2 费 | 水刃、气枪、混凝土、高压蒸汽 |
| 堆砌 | 下回合 +2 费 | 土墙、混凝土墙 |
| 加热 | 本回合同系伤 +2 | 火+加热→爆炎 |
| 冷却 | 获得 1 费（冷气路线） | 水+气→冷气 |
| 发散 | 单体效果改范围，伤害 -2 或层数 -1 | 蒸汽、毒气 |
| 提纯 | 去掉字词上 1 个负面；或伤 -1 换「不可被打断」 | 光系 |
| 催化 | 本回合下一合成不占手牌操作（或减 1 耐性占用预览） | 木系 |
| 铭刻 | 本场战斗该字词费用永久 -1（最少 1） | 后期成长 |

## 核心铭文如何「解释」同一字词（承接战术解释器）

同一张「高压蒸汽」，不同本源字只改**解释规则**，不改配方：

| 本源倾向 | 对高压蒸汽的解释例 |
| --- | --- |
| 豪杰（稳） | 范围伤改为「可分配到多个目标」；溢出伤变 2 甲 |
| 王权（承诺） | 若本回合已宣告「清场」，高压蒸汽费用 -1 |
| 爆发核 | 范围变为单体 +50% 伤 |
| 收容核 | 击杀时多 1 个字词奖励选项 |

这样动态平衡仍可只砍「高压蒸汽」公共数值，不动本源文本。

## 获取与合成节奏（STS 感）

| 来源 | 给什么 | 设计目的 |
| --- | --- | --- |
| 常规战斗 | 1 基础字三选一 | 扩元素覆盖 |
| 精英 | 2 层字词 或 稀有处理牌 | 跳过合成步骤 |
| Boss | 3–4 层成品 / 耐性+1 遗物 | 长线成长 |
| 商店 | 基础字、处理、手段、成品 | 主动补短板 |
| 事件 | 「强制合成」「分解字词还 2 基础」 | 牌组雕塑 |
| 分解 | 字词→随机退回半数基本字 | 防牌组锁死 |

**手牌合成规则建议（防操作地狱）：**

- 每回合免费合成 1 次；额外合成耗 1 费或耗「耐性冲动」资源。  
- 合成预览显示层数/费用/是否超出耐性。  
- 超出耐性：禁止合成，或允许但打出时爆 3 自伤（慎用）。

## 数值对齐备忘（与费用草案兼容）

- 基础字单独：3–5 效 / 1 费（你已有区间合理）。  
- 2 层字词：约 5–8 效或强关键词 / 2 费。  
- 3 层：10–14 或强范围 / 3–4 费。  
- 水刃 12 伤、土墙 12 甲作为 2 层「压缩/堆砌」尖刺是好的；请让同类尖刺都带**手牌或费用代价**（压缩弃牌、堆砌延迟）。  
- 「永久 +50% 护甲」建议改为**本场战斗**，Roquelike 永久放遗物层。

## 灵感枯竭时用的「造字三问」

1. 这两个字在物理/语义上会发生什么？（水+雷=？）  
2. 它服务哪条战术：伤、甲、费、抽、毒、打断、成长？  
3. 它的层数配得上耐性门槛吗？配不上就降层或降效。

批量刷配方时，可固定模板：

`效果 ≈ (基础均伤 × 层数 × 1.1) ± 关键词税`
