# 撤离点位置保持未知

> 当前状态：`Raw Idea / Unqualified`
>
> 资格结果：已完成本轮 `brainstorming` 与 `grill-with-docs`，并晋级为正式素材；本文件继续保留原始来源和确认过程。

## 原始想法

用户原话：“撤离点保持未知，增加神秘感。”

## 触发来源

2026-08-21，agent 提议首个地图原型开局公开完整地图拓扑和所有入口/撤离点；用户否定撤离点公开部分，要求保持未知以增加神秘感。

## 可能带来的玩家体验

- 探索路线包含寻找出口的未知感和发现感。
- 玩家不能从开局直接计算最短撤离路线。
- 撤离点被发现时可以形成明确的安全希望和位置记忆。

## 暂定标签

- 类型：`Information Rule / Map Discovery`
- 情绪：神秘、寻找、发现
- 玩法关键词：隐藏撤离点、地图信息、出口发现、探索
- 风险关键词：盲目搜索、低血量无解、撤离不可规划、软锁感
