## 读取顺序和成本共同约束

先看能力契约，再看名词可表达什么，最后按动词核对执行者、输入、去向、数量、费用、结果和失败。O/A/N/V/S编号只用于文档追踪，不是代码类型或玩家必须背诵的名称。

已采纳规则继续生效：实际每个词卡出现位置都需要独立实体，一卡同场只归一法术；普通同名最多3张。冷却c等于本句实际词卡时间贡献之和，释放时长r单独设计，周期c+r。省略执行者“我”不占卡。所有下表具体词卡时间、释放时长、效果量和范围均Unknown；符号表示要重新设计的参数，不是默认值。

固定成本不足时不部分扣款；按实际量仅在词条明确允许时使用。一次性费用的首合法目标检查、同源合计支付、无合法结果不付费、已合法结果不回滚都按R10执行。本批没有额外一次性货币费；V17使用逐产物固定材料，V06/V10/V20及V05使用明示实际量，V12–V16/V18/V19提出逐合法结果额度。额度由相应词条引入，尚不是核心资源。

动词合法性与释放失败分开：战前就可判定的词性、角色、卡数及固定能力不兼容，不能配置；战前合法而运行时失效、材料不足或窗口关闭，按无效释放反馈与周期处理。被覆盖/生命伤害打断的尝试不播放正常释放特效；不能套用“无效目标仍播放”的规则。

## SC01：复合表达与实体词卡建议

状态：新候选。外层继续V+N或N+V+N，一条法术只有一个外层动词。括号、箭头、“的”与〈绑定说明〉是可读结构标记；它们只能展示已分配词卡声明的角色、路径和字段，没有独立新词性或免费效果。

| 需要表达的含义 | 本批实体成本建议 | 可作为配置值的内容 |
| --- | --- | --- |
| 明确对象身份 | 对象名词每出现一次占一张 | 甲/乙编号、实例选择，属于该词许可的身份字段 |
| 宿主的状态/部件/过程 | 每个有新增含义的名词各一张，如敌人+护甲、法术+冷却 | “的”只连接这两词已经许可的宿主路径 |
| 材料来源和去向 | 各端点对应名词不能省略，如水+容器、木块+材料+位置 | 箭头仅展示V10/V17等动词已声明的角色，不附送移动或取材 |
| 属性比较 | 属性含义需要对应名词，如敌人+生命 | 在对应词许可下选比较符和阈值；不准任意输入另一条法术 |
| 空间筛选 | 区域含义需要N21 | 该区域允许的形状、尺寸、锚点与存续值 |
| 与/或/非的对象组合 | N33交集、N34并集、N35排除各为名词卡，输入名词也须逐位置分配 | 输入组内的实例或许可条件；不免费提供无限逻辑层级 |

普通对象名词独立作目标时首批取单个；条件模式按公开顺序取第一个，未命中无对象。N33–N35集合名词明确输出全部成员，并为其输入开启明示集合选择；V03允许处理该集合全部单位，V10允许一来源对收材集合。其他动词本批仍一对一，集合不得默默广播。所谓甲组/乙组是战前固定实例列表，不额外生成阵营或标记状态。

有限关系路径只允许名词明示的“登记部件、所属表面、附着状态、当前过程”等边；每层含义须有词卡。最大路径深度、逻辑层数、处理数量上限均Unknown。短语排列方案与逻辑卡方案需一起验证可读性；当前55词不是起始词表，也不是承诺所有组合合法。

## 能力契约：A01–A18

### A01 接受伤害

- 配型对象：O01 O02；O03仅单位模型。
- 前提：目标仍是活单位；伤害词义与来源明确。
- 允许结果：按护甲与生命规则结算；真实生命伤害才触发对应打断。
- 不兼容/失败边界：环境没有单位生命；生命视图不是伤害入口。

### A02 承载可变状态

- 配型对象：O01 O02 O04 O05 O06 O08 O12 O13；O16 O17接口。
- 前提：状态允许该宿主、来源与叠加方式明确。
- 允许结果：增加、消耗或清除已声明状态；宿主身份不变。
- 不兼容/失败边界：没有该状态权限不能任意贴状态；表面和整体不得重复结算同一份状态。

### A03 接受位移

- 配型对象：O01 O02 O04 O05 O06 O07 O09 O27 O28。
- 前提：对象未受未解除的锚定/连接约束，完整路径和终点合法。
- 允许结果：更新位置；携带明确归属的部件与内容物；更新锚定范围。
- 不兼容/失败边界：受阻全次位移失败；不自动冲撞、推开、穿透或造成伤害。

### A04 可拆分连接

- 配型对象：O04 O05 O08 O18。
- 前提：连接已登记且声明可解除；端点仍有效。
- 允许结果：只解除点名连接，保留已登记部件身份，更新归属。
- 不兼容/失败边界：不能把未登记外观碎片当部件；不能暗中解除所有连接或触发坍塌。

### A05 可建立连接

- 配型对象：O04 O05 O06 O08 O09 O18。
- 前提：两端有兼容且空闲端口，在连接距离内。
- 允许结果：产生新的连接关系，端点身份保留。
- 不兼容/失败边界：已连接、端口不兼容或空间不合法时不扣固定材料，不自动合并对象。

### A06 提供材料或消耗量

- 配型对象：O04 O05 O06 O07 O08 O09 O10 O11 O13 O27。
- 前提：来源、归属、可用量与允许消耗方式明确。
- 允许结果：减少真正来源可用量；护甲仅支持状态消耗，不等于物质。
- 不兼容/失败边界：整体与部件共享份额不得双取；无资源不能以外观替代。

### A07 接收材料

- 配型对象：O09 O10 O11。
- 前提：去向接受该材质且有剩余容量；结果持有者明确。
- 允许结果：来源减量和去向增量成对发生；份额身份按对象目录的转移细则。
- 不兼容/失败边界：不自动混材、溢流或生成无限容器；水体接受能力仅作候选。

### A08 按配方转化

- 配型对象：O06 O07 O11。
- 前提：输入符合明示配方；输入量与输出落点合法；O11的转化能力目前仅扩展接口，无份额再转化配方。
- 允许结果：消耗输入并产生配方指定的新身份、材质和数量。
- 不兼容/失败边界：词义没有列入的跨材质转化失败；不暗中产生金币/词卡。

### A09 读取公开事实

- 配型对象：O01–O30，后置条目仅接口。
- 前提：事实属于该对象并且当前存在。
- 允许结果：供战前引用、条件与解释使用；不主动施法。
- 不兼容/失败边界：未知未来只能显示条件；可读不等于可写，装饰无资源事实。

### A10 修改许可属性

- 配型对象：O01 O02 O14。
- 前提：属性明确开放修改、上下界与来源修正规则已列明。
- 允许结果：按限定量更新该属性；后续效果按其声明读取。
- 不兼容/失败边界：生命上限、法杖顺序、词卡时间等不凭属性名称获得写权限。

### A11 提供空间参照

- 配型对象：O20 O21。
- 前提：参照系、边界、锚点和存续明确。
- 允许结果：给移动终点、范围或空间条件提供引用。
- 不兼容/失败边界：位置没有生命和材料；空间参照不把区域内对象自动变为处理目标。

### A12 延迟未完成过程

- 配型对象：O23 O24 O25。
- 前提：尚未交付效果、介入窗口开放、允许改期。
- 允许结果：当前预计完成/释放刻向后移动；公开更新。
- 不兼容/失败边界：不改变来源的基础周期；已完成过程不回滚。

### A13 加速未完成过程

- 配型对象：O23 O24 O25。
- 前提：满足对应过程窗口与改期边界。
- 允许结果：缩短当前剩余时间；冷却最早下一刻调度。
- 不兼容/失败边界：不追加本次释放或追溯到已过去阶段；不改基础词卡时间。

### A14 取消未完成作用

- 配型对象：O23 O24；O22生命周期接口。
- 前提：过程允许取消，仍有未结算作用。
- 允许结果：结束该过程未来作用；来源和其后续独立计划保留。
- 不兼容/失败边界：O25冷却与O26释放进度本批不开放取消；不返还过去成本。

### A15 偏转飞行方向

- 配型对象：O24。
- 前提：真实飞行物、方向可改、尚未命中。
- 允许结果：按V15的方向终点方案更新剩余行程。
- 不兼容/失败边界：纯弹道演出不可偏转；没有自动追踪、反弹或阵营变更。

### A16 改换受术端点

- 配型对象：O23 O24。
- 前提：过程允许改目标；新端点满足原攻击类型和作用距离。
- 允许结果：替换本次未来作用的端点，来源与伤害归属不变。
- 不兼容/失败边界：不能改已完成结果；不隐含魅惑、召唤指挥或后续目标锁定。

### A17 有成本复制惰性物体

- 配型对象：O06 O07；O27须具体产物开放。
- 前提：模板允许复制，明示同材质来源、足额材料与合法位置。
- 允许结果：消耗来源，产生新身份；只复制词义列明的外形和物质。
- 不兼容/失败边界：不复制单位行为、附着效果、库存、金币、词卡、法术配置或介入额度。

### A18 响应已登记环境规则

- 配型对象：O16 O17 O19，仅接口。
- 前提：具体反应表、阶段、终止条件完成资格确认后才可用。
- 允许结果：届时按R26–R29处理阶段、传播与阵营。
- 不兼容/失败边界：本批无可执行燃烧、导电或坍塌条目，不能从现实物理补规则。

## SC03：过程窗口与介入成本建议

状态：新候选；R21–R25本身已采纳。本批为具体词卡填写如下窗口与代价。

| 过程 | 准备/进行 | 窗口结束 | 本批操作 |
| --- | --- | --- | --- |
| 攻击 | 从公开预告开始，到原攻击交付伤害或把唯一作用交给真实飞行物前 | 已交付、取消或来源失效 | 延迟、加速、取消、改向；每个具体攻击仍须声明许可端点 |
| 飞行物 | 创建并接管唯一未交付作用，按公开路径运行 | 终点作用交付、碰到阻挡而取消、明确取消或场景结束 | 延迟、加速、取消、偏转、改向；来源不再重复交付 |
| 冷却 | 一次具体冷却开始，到释放开始/该次机会失效 | 当前冷却结束，不自动成为下一轮冷却 | 延迟、加速；实际释放完成后按基础冷却继续 |
| 释放进度 | 直接效果开始时已完整结算，显示直到释放结束 | 释放时长结束 | 首批只读；未来持续段须另建明示过程 |
| 效果场 | 具体场定义后按其阶段运行 | 自然结束或明确取消 | 取消接口；本批没有具体载荷、周期或伤害内容 |

为避免“延迟攻击—再次延迟”仅靠等待就无限持续，本批推荐每条介入法术持有有限的本场有效介入额度K_intervene。只有产生合法改期/取消/偏转/改向才减1；无匹配、窗口关闭、材料/额度不足、没有实际变化不扣。每条法术单独记，不从全场合并，不被物体复制、时间变更或战中改配置恢复。K的取值和各词卡时间需联合重新设计。这是一项新内容建议，不是已采纳规则的隐含要求。

本批推荐攻击和飞行物的加速也不早于下一刻，避免同次求值插入额外交付；R23对冷却的下一刻边界本来已经生效。飞行物改期保持当前剩余路径的几何终点，调整剩余时间与进度；不会追溯改变已走过的位置。偏转/改向按SC02重审路径。

## SC04：材料、复制与产出建议

状态：新候选。每份可消耗量都有唯一来源与归属；部分/完全转移和同材质归入的份额身份按[对象目录](2026-09-10-semantic-object-catalog.md)细则。水源首批使用有限现量，不自动补水；木材/石料/水各自计量，无隐式混合、溢流、蒸发、化学反应或无限背景采集。

| 项目 | 输入 → 输出 | 身份、状态和总量 | 缺口 |
| --- | --- | --- | --- |
| 转移水/材料 | 明示来源 → 一个/明示集合接收者 | 实际q成对减加，接收者身份保持；部分份额拆分按归属记录 | 每次上限、距离、材质容量Unknown |
| 木块分解 | 独立无状态/子部件木块 → 木材份额 | 同材质记账量相等；输入身份结束，输出新身份；原处生成 | 计量单位、份额粒度Unknown |
| 石块分解 | 独立无状态/子部件石块 → 石料份额 | 同上，不可跨材质 | 同上 |
| 复制惰性物体 | 无状态/子部件木块或石块模板+足额同材质 → 新物体 | 模板保留，新身份；材料守恒；不复制附着效果、关系或权益 | 每模板材料量、可用体积、距离Unknown |
| 造卡 | 合格模板+本场造卡额度 → 一张待领取卡 | 已持有+待领取不超3；合法才扣额度 | 模板集合、K_card、时间Unknown |
| 产金 | 本场产金额度 → 一笔待领取金币 | 金额为正且合法才扣额度；无额度后不再产出 | K_gold、G_gold、时间Unknown |

K_card/K_gold/K_intervene分别是相应词条提出的独立本场限制，不互换、不共池。本场重置只是相应内容候选的额度生命周期；奖励资格、整体领取以及跨战保留仍按现行核心。产出额度具体如何与多法杖、同名三张和遭遇数量配合，需要在参数比较中检查。

## 需要重新设计的参数输入

| 参数组 | 含义/单位 | 验证重点 |
| --- | --- | --- |
| t(N/V)、r | 每实际词卡贡献与整句释放时长，战斗刻 | 复合表达成本、覆盖频率、短句是否全面支配 |
| G、D_fire、D_hit、P_gain、P_loss | 护甲/伤害/力量数量，非负数，按既有修正和取整 | 进攻、防御、增益的时间回报；无限堆叠是否有有效代价 |
| Q_devour、K_fire、Q_clear | 状态消耗上限、转伤率、清除上限 | 吞噬与直接打击/清甲是否各有用途 |
| Q_transfer、M_copy、各容量 | 各材质计量单位 | 材料守恒、共享来源不足、分离后归属 |
| L_move、L_join、区域尺寸 | 场景长度单位 | 位移与范围取舍；对象体积和合法落点 |
| T_delay、T_advance、K_intervene | 改期刻数、每法术每场介入次数 | 不产生同刻追加，攻击能否被永久压制，额度可读性 |
| K_card、K_gold、G_gold | 本场合法次数、产出金币 | 多法杖复制产出策略与跨战经济比较 |
| 路径深度、集合规模、逻辑层数 | 有限整数容量 | 可读性及复杂构句是否值得其资源成本 |

各项当前取值均Unknown。只保留已确认的0–10刻首次冷却起点区间、每刻一个释放槽和普通同名≤3等结构规则，不从示例数字建立平衡基线。
