# 启动探索与阅读范围

Project ID：new-roguelike。2026-10-01 / READ-NR-1。默认NONE，当前没有正式核心设计或GDD。

| 模式 | 本项目允许材料 |
| --- | --- |
| NONE／空白 | 本轮输入；续作另含所选方向自身已登记记录。项目CONTEXT仅说明已知范围与Unknown |
| CORE／核心设计 | 正式建立后仅design/core-design.md；当前不可用，说明缺口，不替换成言咒核心 |
| GDD／完整GDD | 正式建立后按design/README登记的固定包；当前不可用，不用草案冒充 |
| FULL／全量主系统文本 | 本项目README、CONTEXT及design、sources、governance、development下已登记文本；不含其他方向、历史、外部游戏和代码 |
| CUSTOM／自选 | 用户明确文件、章节、方向或外部参考清单；显式增补与排除优先 |

所有模式都需读适用操作规则，但不因此加载玩法背景。用户选择不可用模式时，报告缺口，先继续不依赖正文的工作；不自行扩读。未来建立核心/GDD后同步本表和design入口的准确文件清单。

开读前说明模式，锁定完整Git提交及文件/章节；用户明确使用工作树时记HEAD与实际SHA-256。方向README记录允许清单、实际覆盖、未读和范围变更，不另建背景包。只有完整读取所选清单才称已读完整；新增文件不自动加入。

范围外材料先集中列用途和推荐，按[批量澄清](../../docs/design-workflow.md#批量澄清)取得明确逐项或整批授权；已有授权不重复询问。链接不递归授权，FULL不包含言咒、旧游戏、其他方向、联网或实验执行。当前任务已读过的范围外材料如实记录，不承诺可清除背景。

示例：`启动独立肉鸽方向：〈主题〉。阅读模式NONE，仅使用本轮输入。` 方向README继续记录原话、模式、版本、允许/已读清单、构思、Unknown与下一步。
