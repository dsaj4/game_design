# FX-069 释放作用下异种元素消散后的补生

修订：r1（2026-09-12）。来源：[本轮原话](../../../game-design-workflow/idea-inbox/2026-09-12-element-spell-archetype.md)；规则唯一正文：[元素素材EL04／06](../../../game-design-workflow/idea-materials/M-2026-09-12-element-spell-archetype.md)。

| 字段 | 当前登记 |
| --- | --- |
| 分类／承载 | 元素消散后的条件生成；释放法术与元素系统 |
| 设计状态／证据 | 用户明确方向／Qualified；具体执行未闭合，Hypothesis／NotRun |
| 触发与结果 | 在相关释放法术作用下，其他元素本体被抵消至消失时，新增该释放法术对应元素；没有释放法术则不新增 |
| 来源与目标 | 来源是影响该元素的释放法术，不是场上无关的任意施法；旧元素消失后产生新元素，不能将状态继续附着旧宿主 |
| 必需关系 | FX-064共享层数归零消散、FX-067/r2状态抵消、FX-063生成／同种叠层；不同于FX-065/r2环境转化继承 |
| 剩余缺项 | 生成位置、初始层数、恰好抵消时层数来源、已有同种元素时生成或叠层的协调；不默认使用余量或固定层数 |
| 时点／费用／叠加 | 具体步骤与完整事件、费用和多来源顺序待定；不增加额外完整释放，不默许循环派生 |
| 失败／终止 | 无相关释放时不生成；胜利后停止；其余生成资格与失败处理尚未定义 |
| 下一步／测试 | TH-002/r11积累有释放／无释放两分支及补生边界，未运行；草状态与法术第一阶段后置 |
