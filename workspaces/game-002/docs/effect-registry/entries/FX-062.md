| 触发／对象／范围 | 每刻环境阶段末统一检查；对象须属于合格环境，并满足对应状态、当前量与释放覆盖；释放最后一刻仍有效，残留元素不提供释放许可 |

| 存续／终止 | 同一环境身份中保留已达形态；最终转化结束旧身份，转化结果依FX-065；战终停止，下一场按实际初态建立 |
| 叠加与无效 | 状态不存在或当前量不足不推进；层数下降不倒退；地面不成为占位元素，不发生树草二次传播 |
| 类型与承载 | 环境系统效果，不是额外词卡／镶嵌，不凭形态增加法术类型 |
| 现行证据 | 已采纳规则Hypothesis／NotRun；旧BF试案不是本修订输入 |
| 剩余候选 | [EG v0.1](../../../game-design-workflow/idea-inbox/2026-09-14-environment-forms-and-thresholds.md)给火冰实际形态／阈值；EG-C01双类痕迹共存、EG-C02一次跨多阈值均为Raw待审，不自动变成当前规则 |
| 案例／下一步 | 当前5层的烧焦树仍烧焦，但不凭曾有20层转化；仅残留火焰无释放覆盖不推进。待审实际EG／RG并补功能呈现，当前不运行玩法测试 |
