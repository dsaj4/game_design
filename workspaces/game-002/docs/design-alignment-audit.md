## 语义审查矩阵

| 规则维度 | 当前统一结果 | 边界 |
| --- | --- | --- |
| 配置 | 完整库存战前构句，一实体一位置且同场一法术，一法术一法杖 | 固定配置与目标，省略主语无隐藏词卡成本 |
| 时间 | 词卡时间相加用于冷却，释放单独设计；起点0–10刻，周期冷却加释放 | 具体时长重新设计，示例不作为默认参数 |
| 覆盖与打断 | 共享单刻释放槽、后法杖覆盖；生命伤害打断当前冷却，只取消当次 | 后续周期保持，打断独立反馈；生命支付不自动算伤害 |
| 对象与材料 | 战前公开的固定顺序，逐对象检查；固定消耗不足只跳过该对象且不部分扣除 | 其他合法结果保持，无效目标实际释放有特效 |
| 成功与结束 | 至少一对象合法结算才计一次成功，合法零值可满足；完整法术后检查胜负 | 不逐词或逐对象判胜；胜利后停止其余全部处理，同检查点失败优先 |
| 状态 | 存续、重施、周期及到期按对应素材处理，强化不重复计入周期 | 法术源方强度在法术开始读取，对象材料在轮到对象时检查 |
| 收益 | 金币与法术造卡整体领取或放弃；造卡资格前置，同名计数包含已持有及待领取 | 产金须有限触发或实质成本，次数/金额/成本重新设计 |
| 召唤与引用 | 保留类型与单位模型，完整指挥后置；后续设计战前单位占位和出生位置 | 当前不新增专属引用词卡；条件方向不等于完整占位机制 |
| 镶嵌与环境 | 法杖起始资源、镶嵌细则及BF1–BF3后置；对象变化描述可继续 | 固定货架、去重和触发计数仅为镶嵌的后续评议方案 |
| 数值与证据 | 已确认结构性规则保留，平衡参数重新建立 | 所有具体锚点不作为基线，尚无完整对局与平衡验证 |

## 文档情境复核

以下为规则文本的独立边界审查，不是已运行的游戏测试。

| 情境 | 唯一预期与正文依据 | 文档结果 |
| --- | --- | --- |
| 固定顺序中前对象固定材料不足，后对象足额 | 前者不部分扣除，后者继续结算；目标/材料素材一致 | 通过 |
| 前对象已合法结算，后对象失效 | 保留前者结果，整条法术只产生一次成功；目标/类型/整句素材一致 | 通过 |
| 全部对象失效或不足 | 不产生成功事件；实际发生的无效释放仍有释放特效 | 通过 |
| 合法读取结果为零 | 不仅因零值判失败，至少一合法对象可构成成功 | 通过 |
| 前对象处理后看似达成胜利，法术尚有后续对象 | 处理完整条法术后再检查胜负；胜负与目标素材一致 | 通过 |
| 伤害被护甲全挡，或明确支付生命 | 前者未造成生命伤害，后者不自动属于伤害；都不据此触发生命伤害打断 | 通过 |
| 被覆盖、被打断、无效目标尝试 | 前两者取消本次释放，后者实际释放但无效果；反馈文案可区分 | 通过 |
| 已持有同名两张，连续两次尝试各生成一个副本 | 首次合法进入待领取，第二次计入待领取后已满三张，不再产出；整体领取规则保持 | 通过 |
| 对象出现、召唤单位离场或专属引用需求 | 不增加战中选卡/换目标权限，完整占位机制后置 | 通过 |
| 设计者需要填入生命、伤害、库存或默认释放长度 | 转入数值重设计任务，不从时序示例填入参数 | 通过 |
