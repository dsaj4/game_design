## 已确认的约束

- 离散战斗时间；全部首次冷却起点在第0–10刻，周期等于冷却加释放，覆盖和打断保持后续周期。
- 每刻最多一个释放槽，一法术一法杖，一实体词卡一出现位置且同场只属一法术；省略主语无隐藏词卡时间。
- 普通同名词卡最多三张；新局零金币；普通休整三候选选一等流程规则继续生效。
- [SW02两种引用](../game-design-workflow/idea-materials/M-2026-09-10-instance-and-conditional-binding.md)：实例身份固定、条件战前固定而每次匹配结果可变。实例既定顺序保留，SW02-A名单与R05–R11筛选、排序、成本已明确，可作为规则输入；逐对象材料检查、完整法术后检查胜负、生命伤害打断、同刻四阶段及胜利立即终止继续适用。
- [R01–R32](../game-design-workflow/idea-materials/M-2026-09-10-semantic-world-executable-rules.md)已采纳：复合短语、数量与关系路径容量、三类成本、位移和区域、过程介入与改期、按刻传播均作为参数设计输入；实例词条和具体量待填写。
- 收益整体领取或放弃；造卡先满足资格，产金须有有限触发或实质成本。数值设计不得暗中改变这些规则。

## 工作与验证顺序

1. 建立基础遭遇节奏、容错和跨战压力的候选目标，写清每个目标如何衡量。
2. 基于目标提出最小词表、起始实体分配、基础法杖配置、敌人安排与第一组参数。每项记录含义、单位、取值、理由与Unknown依赖；不从示例抄入默认值。
3. 在同一公开遭遇下，逐刻比较攻击、防御、强化和材料转换方案，记录释放、覆盖、打断、无效尝试、损耗与结束时间。
4. 验证多对象不足材料、合法零值、生命支付和收益额度等边界，再比较连续战斗、休整取舍与首次购物。
5. 比较偏快、偏稳与产出方案，识别短句全面支配、强化无代价累积或无成本拖延收益；按目标修订并保留证据。
6. 参数表通过局部资格确认后进入正式素材/GDD；改变核心规则时单独建立Draft Change。玩家体验与平衡验证分别记录，不能以表格完成代替验证。
