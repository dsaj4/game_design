## 已确认的约束

- 离散战斗时间；全部首次冷却起点在第0–10刻，周期等于冷却加释放，覆盖和打断保持后续周期。
- 每刻最多一个释放槽，一法术一法杖，一实体词卡一出现位置且同场只属一法术；省略主语无隐藏词卡时间。
- 普通同名词卡最多三张；新局零金币；普通休整三候选选一等流程规则继续生效。
- [SW02两种引用](../game-design-workflow/idea-materials/M-2026-09-10-instance-and-conditional-binding.md)：实例身份固定、条件战前固定而每次匹配结果可变。实例既定顺序保留，SW02-A名单与R05–R11筛选、排序、成本已明确，可作为规则输入；逐对象状态数量与成本检查、完整法术后检查胜负、生命伤害打断、同刻四阶段及胜利立即终止继续适用。
- [R01–R32](../game-design-workflow/idea-materials/M-2026-09-10-semantic-world-executable-rules.md)已采纳：按当前G002-CORE-011范围，数量/状态、真实生成物、必要条件、过程改期及对象掉卡作为参数输入；位移/材料加工/复杂传播参数暂缓；实例词条和具体量待填写。
- 超时后双方进入疲劳持续扣血，法术不能恢复生命；胜负依生命结果，战外休整仍按既有规则。具体执行和数值见疲劳候选。
- 收益整体领取或放弃；造卡先满足资格，产金须有有限触发或实质成本。数值设计不得暗中改变这些规则。

## 当前简单作用参数输入

[简化范围](semantic-world-content-index.md)已经采纳；具体词义未填完的参数先保留Unknown。点燃/冰冻与三种元素进入当前内容设计，材料加工、空间操作及其参数不列为当前任务。

| 输入 | 需要设计的量 | 验收 |
| --- | --- | --- |
| 实体词卡与释放 | 每词时间、整句释放时长、容量 | 组合成本可解释，共享槽与周期成立 |
| 攻防及许可属性 | 伤害、护甲、强化/削弱量 | 保留既有伤害/状态规则，方案有取舍 |
| 点燃与冰冻 | 已明确词义的状态量、持续、周期或行动影响 | 不凭名称默认传播、伤害或硬控 |
| 火焰/雷电/冰霜 | 生成量、强度、作用与结束时点 | 有真实可介入窗口，不只延长特效 |
| 抵挡/反弹/转移 | 处理量、接收资格、限制与成本 | 不定向或手选目标，但结果有明确规则 |
| 当前过程时间 | 加速/延迟量与具体成本 | 最早下一刻，不改变基础周期 |
| 对象掉卡 | 合格对象、卡种、次数/概率、代价 | 资格/同名额度成立，无无限重复默认规则 |

## 框架确定后逐层落实的顺序

1. 先审查四层框架的指标、收益去重、预算可达性、分母与体验门槛；用现有结果复评，不扩展其他词效。
2. 基于目标提出最小词表、起始实体分配、基础法杖配置、敌人安排与第一组参数。每项记录含义、单位、取值、理由与Unknown依赖；不从示例抄入默认值。
3. 在同一公开遭遇下，逐刻比较攻击、防御、强化、简单状态与对象掉卡方案，记录释放、覆盖、打断、无效尝试、损耗与结束时间。
4. 验证多对象状态量/成本不足、合法零值、生命支付和收益额度等边界，再比较连续战斗、休整取舍与首次购物。
5. 比较偏快、偏稳与产出方案，识别短句全面支配、强化无代价累积或无成本拖延收益；按目标修订并保留证据。
6. 参数表通过局部资格确认后进入正式素材/GDD；改变核心规则时单独建立Draft Change。玩家体验与平衡验证分别记录，不能以表格完成代替验证。

## 本轮交付：参数定义与首轮测试数值

用户启动与交付深度见[原始记录](../game-design-workflow/idea-inbox/2026-09-11-parameter-design-start.md)。[参数候选v0.1](../game-design-workflow/idea-materials/M-2026-09-11-simple-spell-parameter-candidates.md)通过局部素材资格确认，包含参数归属、单位、公式、局部目标、两个完整法术、共同测试资源、4个代表配置及事件记录；全部具体值仍为Candidate。

- 关注类型：伤害敌人＝简易；获得护甲＝简易＋状态，一份护甲参数共同引用。
- 本轮给值范围：词卡时间、两句释放时长、直接伤害、护甲生成、玩家与单敌测试量；其他类型先列词效依赖。
- 算术复核：12刻首攻／间隔下，错峰双攻击23刻结束、损失10生命；攻击加护甲35刻结束、零损伤。8、10刻节奏会暴露护甲被击穿后的连续打断问题。
- 候选先做固定条件的纸面比较，随后完成限定独立计算与demo事件一致性验证；尚无玩家测试或完整平衡结论，不改变正式起始资源、既有词表或核心参数基线。

当前优先级按用户最新指令为全局规则审查后回归卡牌／流派设计，参见[审查](global-rules-audit-2026-09-11.md)与[流程](card-design-review-workflow.md)。框架、疲劳及新卡待测项持续积累，下次一起测试；阶段资源、路线与恢复／经济输入按评测需要补齐。
