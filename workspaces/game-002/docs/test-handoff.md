## 新增候选边界输入

所有FAT-C细节按固定素材运行，测试结果只证明该候选的性质。测试装置中的恢复事件与生命尺度变化不新增可用词卡或正式成长数值。

- F07至少覆盖：F−1／F／F＋1的法术恢复；疲劳前创建、F后到期的恢复；复合效果仅恢复被阻止；全部仅恢复无合法成功与仍有其他合法效果时只计一次成功；F刻不扣血、F＋2首扣；大量护甲不抵消候选疲劳且疲劳不打断；同次双方死亡失败优先；法术阶段先胜利时不追扣；F＋2的敌攻先致死时不再执行疲劳；多个敌人同次扣血；冷却改期不改变疲劳日历；战后合法休整不受本场禁疗影响。
- F07隔离事件可使用Hf玩家60／敌人72、当前生命1或满生命、护甲0或100及恢复尝试10作为明示测试输入。逐例注明其设置，其余按FAT-C完整包；不能将这些量登记为正式能力或参数。
- F08固定普通遭遇：原攻防Candidate v0.1的词卡时间、伤害12、护甲6、两杖和6卡、敌攻12／12且伤害10；比较T01起点0／1、T02起点0／1及仅一条护甲起点0（其余资源闲置仍计可用预算）。
- F08生命上限对为玩家／敌人＝60／60、60／72、120／30；每对分别测试双方满生命、仅玩家半生命、仅敌人半生命，共9场景×3配置＝27个候选情境。每个场景内资源和敌人条件相同；各对象Hf取其已登记上限，不以残余生命替换。按疲劳时点观察到真实结束；若过80刻仍未结束，报Fail并保留轨迹，不伪造80刻判负。
- F08的总可用资源保持一致；仅护甲允许闲置卡／法杖。样本为边界装置而非真实玩家分布或成长曲线，不据27组证明全局无最优。报告纯等待获胜案例及是否被T01／T02支配，再决定是否需要调候选。
