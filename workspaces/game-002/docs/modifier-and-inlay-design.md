## 修饰词的当前结论

[Modifier v0.1](../game-design-workflow/idea-materials/M-2026-09-11-modifier-card-system.md)已按G002-CORE-016采纳，证据Hypothesis。规则与案例只在该素材维护；本页用于工作衔接。

| 项目 | 当前结论 |
| --- | --- |
| 词卡类别 | 名词、动词、修饰词；形容词修饰名词，副词修饰动词 |
| 挂接与成本 | 可多张直接挂原词，不递归；每张占实体副本与时间贡献 |
| 兼容判定 | 不兼容→适配→通用，特殊替代通用；判定始终依据原词 |
| 数值范围 | 只修正本句计算；实际产生状态按自身规则存续 |
| 多修饰顺序 | 同数值依GR01合并，不同附加效果按句中从左到右结算 |
| 分类与获取 | 不是新增法术类型；获取资格逐卡声明，沿现有普通词卡结构 |
| 内容缺项 | 寒冷增幅、冰冻词义、寒冰／冰霜身份、吞噬语义与各卡参数另行设计 |

系统模型已明确；附加效果相对基础操作的时点、宿主、能力事件及互相排斥范围是各条词义的必填内容。涉及新的系统级选择时再单独决策，不能由测试agent推断。

## 镶嵌可复用的基础

[法杖与镶嵌素材](../game-design-workflow/idea-materials/M-2026-09-07-wand-inlay-configuration.md)已明确：每杖承载一条法术；法杖及镶嵌配置决定范围或明确特殊效果；战前配置，战中不重新分配词卡或调整法杖顺序。

修饰词作用于句内原词，镶嵌作用于法杖配置。镶嵌须明示影响哪根法杖、哪类法术、哪个执行者及哪个事件；持有不自动使全部法术获得全局加成。

[镶嵌获取候选](../game-design-workflow/idea-inbox/2026-09-07-inlay-acquisition-boundary.md)重新列为待讨论来源，仍是Raw Idea / Unqualified。此前的固定货架、同种去重、一层响应与每战重置只是候选，尚未采纳。

## 下一步需补齐的镶嵌内容

| 设计面 | 已知依据 | 待明确内容及玩家影响 |
| --- | --- | --- |
| 物品与装配 | 法杖配置层，战前固定 | 是否占独立槽位、槽位数量与资格，能否换下／复用／跨杖；决定配置机会成本 |
| 效果范围 | 范围与明确特殊效果 | 初版可改哪些量与规则、是否允许附加事件，哪些权限明确禁止 |
| 同种与多枚 | GR01统一数值、GR07事件声明 | 同种持有／装配上限，不同效果冲突与优先级，是否互斥 |
| 时间与事件 | 一条完整法术一次成功，四阶段 | 按尝试／成功／对象计次、触发阶段和顺序、响应上限、取消或失败的计数 |
| 获取与收益 | 普通词卡资格和整体战后收益已明确 | 镶嵌进入商店还是独立渠道，价格／产出池，是否进入整体收益及如何放弃 |
| 跨战与新局 | 词卡与法杖配置的现行边界 | 镶嵌持有与配置保留多久，临时次数何时重置，初始资源是否提供 |
| 与修饰词合用 | 两层来源须分别记录 | 同参数归属、数值合并、附加事件顺序及同预算评价，避免重复计收益 |

本表是待设计字段，不是推荐参数或已采用规则。先明确物品与装配的基本模型，再顺着效果、叠加／事件、获取和跨战边界补齐。无须提前为所有流派创作镶嵌成品。

## 后续流派物品如何一起设计

系统边界齐备后，每个流派按同一清单组织：基础名词、基础动词、可用形容词／副词、法杖及镶嵌组件。分别标核心、替代、混搭与缺组件方案；附资源渠道、实体／槽位／时间／货币成本、类型索引和同预算对照。

复用[设计—评测—采纳流程](card-design-review-workflow.md)。素材合格、规则采纳、参数候选与测试通过分别记录，不因组件归属同一流派而共享一次成功结论。
