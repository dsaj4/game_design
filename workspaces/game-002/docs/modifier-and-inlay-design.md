| 项目 | 当前结论 |

## 镶嵌的当前结论与候选

[Inlay v0.1](../game-design-workflow/idea-materials/M-2026-09-12-wand-inlay-system.md)已区分IN-A用户模型、两项确认示例及IN-C01–IN-C14补充候选；全部具体规则只在素材维护。

已明确：每根法杖自带一个固定镶嵌，定义身份、基础范围与可选特效；镶嵌强化完整法术并关联类型／特征。简易加速是第2、4、6……次冷却各减1刻，覆盖／打断也计周期；燃烧强化是范围内各来源的施加增层，周期跳伤不重加。

| 候选范围 | 推荐方案概要 |
| --- | --- |
| 结构与装配 | 1固定＋2可换槽；固定不占活动槽、不可拆，可换战前免费拆装，不损坏 |
| 实体与同种 | 一件只装一杖，可换镶嵌同ID每局最多1件；同款法杖可多实体 |
| 获取 | 商店各提供1个可换镶嵌位、1个法杖位，不占普通词卡货架；资格／金币检查，固定公开、无刷新 |
| 替换与跨战 | 旧杖及镶嵌回库存，新杖不增出战上限；本局持有保留，计数每战重置，新局重置 |
| 激活与范围 | 出战且绑合法法术才激活；明确范围被动可协作，类型特效不匹配只休眠 |
| 叠加与事件 | 同效果组单事件取最强一次，异组依参数合并；计次事件逐条声明，默认一层派生 |
| 数值与成本 | 无词卡时间贡献；支付金币、槽位与机会成本。减冷却下限和参数在素材内明确为候选 |
| 初版边界 | 活动槽初始为空；暂不做镶嵌掉落、合成、升级、出售或额外战后领取 |

剩余的系统级工作是审阅上述整包候选并决定采纳范围。内容级缺项是法杖／镶嵌ID、基础范围、价格、起始法杖数与完整燃烧词义；这些应在流派和数值设计中补齐，不重复询问已明确的模型与两例。

## 后续流派物品如何一起设计

系统边界齐备后，每个流派按同一清单组织：基础名词、基础动词、可用形容词／副词、法杖及镶嵌组件。分别标核心、替代、混搭与缺组件方案；附资源渠道、实体／槽位／时间／货币成本、类型索引和同预算对照。

复用[设计—评测—采纳流程](card-design-review-workflow.md)。素材合格、规则采纳、参数候选与测试通过分别记录，不因组件归属同一流派而共享一次成功结论。
