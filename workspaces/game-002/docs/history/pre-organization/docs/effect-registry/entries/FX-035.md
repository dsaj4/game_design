## 当前修订 r3（2026-09-14，RC1）

状态：首版适用部分Accepted；量值为首版基准，效果与平衡证据Hypothesis／NotRun。[CG](../../../../../../game-design-workflow/idea-materials/M-2026-09-14-card-interface-completion.md)、[PG](../../../../../../game-design-workflow/idea-materials/M-2026-09-14-first-release-parameters-and-channels.md)、[EG](../../../../../../game-design-workflow/idea-materials/M-2026-09-14-environment-forms-and-thresholds.md)为本修订的完整角色、事件、分组、参数及环境来源。G002-CORE-032–034已经采纳；原页未选历史变体继续保持原状态，不因本次修订纳入首版。

### 印记（S2-N03）

- 合法角色与输入：敌人上的数量状态；输入或状态条件；限带正印记的合法宿主
- 正例：引爆／印记；伤害／印记／敌人（显示为“伤害带印记的敌人”）
- 边界／失败：没有印记不允许顽固免费引爆；标记敌人本身不另需印记实体
- 事件与顺序：标记施加；引爆全部支付或顽固免耗
- 参数、时间与渠道（依PG列序）：2；数量状态，正整数层、不自然衰减；引爆倍率见引爆行，不因引用而自动生成；期1；4。

### 标记（S2-V03）

- 合法角色与输入：仅玩家执行；一个存活敌人获得印记；输出许可由动词提供
- 正例：标记／敌人
- 边界／失败：标记／印记非法，输入应为敌人而不是已有标记；不额外消耗印记词卡
- 事件与顺序：原施加印记；输出状态不反推法术类型
- 参数、时间与渠道（依PG列序）：2；1；给一个敌人新增基础2层印记；要求存活敌人；新增0不建立印记，合法施加仍可计成功；期1；4。

共同执行：普通数量max(0，floor((基础＋固定增减)×已声明乘数))；具体新层入口及自然衰减例外按PG。完整动作先判合法、替换结果种类，再支付与求值，已提交自耗动作允许完成；主事件后先检查胜负，再按公开顺序执行有限一层响应。直接名单固定不补位，逐对象读当前量；同组去重与互斥依CG-G01。所有本页入选卡片的实际参数已给，设计缺口Closed；未测不是未决定。
