## 当前修订 r3（2026-09-14，RC1）

### 倾注（E3-V03）

- 合法角色与输入：一个火焰或冰霜执行；一个存活敌人接收对应状态；宾语为敌人，状态由动词提供
- 正例：火焰／倾注／敌人；冰霜／倾注／敌人
- 边界／失败：倾注／火焰缺显式执行者；火焰／倾注／护甲非法
- 事件与顺序：原限量自耗→对应状态单次入量修正／抵消；当前自耗动作可完成
- 参数、时间与渠道（依PG列序）：2；1；最多消耗自身4层，向一个敌人施加对应状态基础量＝实付层数×2；须有合法敌人再支付；允许支付至元素归零并完成本次已提交施加；克制只在目标入量修正一次；期1；6。

共同执行：普通数量max(0，floor((基础＋固定增减)×已声明乘数))；具体新层入口及自然衰减例外按PG。完整动作先判合法、替换结果种类，再支付与求值，已提交自耗动作允许完成；主事件后先检查胜负，再按公开顺序执行有限一层响应。直接名单固定不补位，逐对象读当前量；同组去重与互斥依CG-G01。所有本页入选卡片的实际参数已给，设计缺口Closed；未测不是未决定。
