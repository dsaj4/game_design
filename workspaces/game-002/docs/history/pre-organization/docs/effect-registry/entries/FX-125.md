### 双律环（S2-I04）

- 合法角色与输入：本杖伤敌直接结果改玩家护甲；护己改首个范围内敌人伤害；与攻守转盘互斥
- 正例：装在“获得／护甲”杖；由组件明确提供选敌许可
- 边界／失败：没有转换敌人时无收益，不恢复原甲；不能与攻守同装
- 事件与顺序：原结果替换；组DIRECT-REPLACE互斥
- 参数、时间与渠道（依PG列序）：期3；14；直接伤敌↔护己，结果种类替换换算系数1；选敌失败不还原；与攻守互斥。

共同执行：普通数量max(0，floor((基础＋固定增减)×已声明乘数))；具体新层入口及自然衰减例外按PG。完整动作先判合法、替换结果种类，再支付与求值，已提交自耗动作允许完成；主事件后先检查胜负，再按公开顺序执行有限一层响应。直接名单固定不补位，逐对象读当前量；同组去重与互斥依CG-G01。所有本页入选卡片的实际参数已给，设计缺口Closed；未测不是未决定。
