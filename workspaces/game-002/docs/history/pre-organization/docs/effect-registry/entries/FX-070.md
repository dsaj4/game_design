### 爆裂（E3-V08）

- 合法角色与输入：仅一个火焰执行；消耗其全部层数，宾语敌人；该动作明示覆盖目标范围内全部敌人
- 正例：火焰／爆裂／敌人
- 边界／失败：冰霜／爆裂／敌人非法；不能只付一次固定小量保留火焰
- 事件与顺序：原整次耗尽→固定范围名单伤害；然后可有一层消散爆炸
- 参数、时间与渠道（依PG列序）：4；1；一次耗尽火焰全部正层数，对本次名单内每个合法敌人造成实付层数×2基础伤害；须至少有一个合法敌人再整次支付；不是把一份资源重复按目标收费；失效目标不补位；期3；8。

共同执行：普通数量max(0，floor((基础＋固定增减)×已声明乘数))；具体新层入口及自然衰减例外按PG。完整动作先判合法、替换结果种类，再支付与求值，已提交自耗动作允许完成；主事件后先检查胜负，再按公开顺序执行有限一层响应。直接名单固定不补位，逐对象读当前量；同组去重与互斥依CG-G01。所有本页入选卡片的实际参数已给，设计缺口Closed；未测不是未决定。
