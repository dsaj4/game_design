### 自噬的（E3-A06）

- 合法角色与输入：挂释放的火焰／冰霜；自然衰减改为有合法目标的邻近事件限量自耗，以实付量求施加
- 正例：释放／自噬的／火焰
- 边界／失败：没有合法邻近对象不扣层；一次多目标邻近不按目标数重复付费
- 事件与顺序：生成持久衰减／支付替换；先付款，当前动作完成
- 参数、时间与渠道（依PG列序）：2；替换时间衰减：一次有合法目标的邻近事件最多支付自身2层；每个合法目标施加基础量＝实际支付层数×1；期3；8。

共同执行：普通数量max(0，floor((基础＋固定增减)×已声明乘数))；具体新层入口及自然衰减例外按PG。完整动作先判合法、替换结果种类，再支付与求值，已提交自耗动作允许完成；主事件后先检查胜负，再按公开顺序执行有限一层响应。直接名单固定不补位，逐对象读当前量；同组去重与互斥依CG-G01。所有本页入选卡片的实际参数已给，设计缺口Closed；未测不是未决定。
