# 首版逐卡目录

RC1 / 2026-09-14，Accepted；数值是待验证的首版基准。S2有25个设计ID，E3有30个；护甲与引爆跨流派共用实体，合计53种：9名词、14动词、11形容词、19可换镶嵌。

## 读卡与共同字段

短卡面用于快速阅读，详情用于说明角色、触发和例外。同一名称的词卡共享副本额度、时间与商品资格。所有词卡只占配置实体，不在施法后消失；同名最多3张，所有19件可换镶嵌每局每ID最多1件。词卡来自休整／商店，可换件只来自商店；第一期起始赠卡按起点表。期别是最早获得资格，价格单位均为金币，τ与L单位均为刻。

名词被引用不自动产生其“结果位”的基础量。形容词只能挂原词，不修饰其他形容词，不凭名称产生额外效果；首版没有可获得副词卡。效果改变类型与成功计数均沿完整法术规则。固定芯不属于本页19件可换件。

完整时序、来源与去重见[规则章](../../../../../../game-design-workflow/gdd/yanzhou-rc1/03-combat-and-status.md)、[CG角色与效果组](../../../../../../game-design-workflow/gdd/yanzhou-rc1/02-grammar-and-configuration.md)；所有新量与费用见[PG](../../../../../../game-design-workflow/gdd/yanzhou-rc1/06-parameters-and-economy.md)。所有卡共同采用UI的选取／挂接／失败文字及声画反馈，效果表现类别见[功能资产表](../../../../../../game-design-workflow/gdd/yanzhou-rc1/08-journey-ui-and-assets.md)。具体数值可在后续验证中调整，但不以调数改变规则。

## 组合关系与最小反例

| 组合 | 正常结果 | 反例／取舍 |
| --- | --- | --- |
| 回响的＋复诵晶石＋回响资格 | 合格原完整法术只请求1次复诵 | 多来源不叠次数；追加不再请求追加 |
| 蓄势＋复诵 | 完整复诵成功可计本杖蓄势 | 兑现整句不再计数；合法0收益不消耗待兑现 |
| 耗印＋顽固印记 | 顽固引爆仍造成允许结果 | 无实际印记消耗，不获跳冷却 |
| 双律＋融冰 | 先改直接结果类型，再判断融冰 | 改成护甲后不再消费冰冻加伤 |
| 空心＋自噬 | 无自动邻近且无自然衰减，可等操控 | 无合法邻近目标不支付；可以长期储层，仍受疲劳终局 |
| 指令＋应激 | 同一根事件同一元素邻近请求合一次 | 溢流没有实际补层，不触发应激 |
| 主动爆裂＋爆裂的＋返甲 | 原主动爆裂按全层伤害，可返实际敌甲比例 | 归零元素不能再指令邻近；消散爆炸是另一层有限触发，不再次返甲 |
| 逆霜＋同享 | 逆霜把首次来源冰冻的周期结果改伤害 | 没有实际周期得甲便不触发同享 |
| 止界＋其他火释放覆盖 | 异种抵消仍发生，剩余丢弃 | 已弃余量不能给后置覆盖杖重新用于补生 |

本表为规则关系，不承诺组合强度或必胜。重复成员仍须真实副本；改法杖顺序会改变覆盖，条件中途失效仍不补名单，新身份不继承实例。跨版本仍须保持已锁定一局的规则结果，不静默改写输入。具体版本兼容的制作安排属于外部依赖，发行前须证明中断恢复仍满足UX05。
