# 游戏构思002：《言咒》

Project ID：game-002。状态：Active / Stable Design Baseline。当前核心为Core Concept v0.5；证据为Hypothesis，数值平衡和玩家体验尚待验证。

玩家在战前使用完整词卡库存构句，每个组合对应一条循环法术；设置一法术一法杖的绑定、范围与顺序，在第0–10刻安排首次冷却。战斗自动运行，同刻按法术、敌人攻击、环境变化、状态效果处理。战后金币与法术产生的词卡整体领取或放弃。

当前有39份合格素材，涵盖构句、循环、状态、目标、局内成长与战场表现。具体召唤绑定、镶嵌、收益资格和时间数值的未决接口集中交由用户处理；尚无正式GDD或当前核心的完整验证结论。
