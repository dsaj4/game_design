## 开始

当前阶段（2026-09-07）：基础数值框架 v0.1 已获用户确认并独立晋级，正式素材共40份，证据 Hypothesis。已执行[首场牌库模拟报告](research/06-prototype-insights/2026-09-07-simple-spell-opening-battle.md)：主种子38T获胜、剩92血，另有256种子两策略对照；测试牌组和力量+2仍为候选，未完成整局或玩家平衡验证。

此前累计记录：固定三类不混用，且同时要求谓语能处理宾语、主语能承接谓语结果；两层兼容原则已确认并扩充既有合格素材，有限跨位建议未采纳。已有状态引用须投入对应宾语卡、制造状态本身不自动获得词卡，也已确认并扩充构句素材。词卡各自带耗时、整句基础耗时相加也已确认并扩充时间素材。基础版暂不启用独立字数上限也已确认，原稿保留待扩展阶段再评估。战斗之间收下的普通新词直接加入本局卡组、不设每战免费换牌备用库已确认并独立晋级。普通战斗后的词卡奖励允许全部跳过也已确认并扩充入组素材。同名独立副本与本局卡组同名最多三张已确认并扩充素材。临时复制、删除仅影响当前战斗已确认，副本战后消失、被本场移除的原有卡下一场恢复，持续范围已扩充入组素材；临时副本不占本局三张名额、允许使本场同名数量超过三张也已确认并扩充素材；临时副本正常弃置、参与洗回也已确认并扩充供给素材；用户要求基础复制相关设计待复制效果卡牌出现后再讨论，具体能力及默认置顶建议均已后置、未采纳；已有通用规则保留。敌方行动结束即开始下一次准备、战斗时间轴与补牌计时连续已确认并扩充时间素材；敌方准备开始时确定并公开行动及执行时间、准备中仅因明确效果变更并告知玩家，也已确认并扩充时间素材；战场状态本场跨施法、跨敌方行动保留，仅按自身规则或明确效果变化、消失，也已确认并独立晋级；引用本身不附加消耗、消耗与变化由具体操作决定也已确认，已扩充构句与状态素材；满足其他条件时允许在引用材料未出现前提前施法也已确认，已扩充构句素材并同步状态与时间素材；必需材料完全缺失时整句落空、弃牌且不退时间也已确认，已扩充时间、供给素材并同步构句与状态素材；基础版不提供通用主动取消也已确认，已扩充时间素材并同步供给、构句素材；普通战斗击败全部敌人获胜、玩家生命耗尽则失败也已确认并独立晋级；普通战败结束本局、继续游玩需重开也已确认并扩充胜负素材；普通胜利不自动回满生命、剩余生命继续保留也已确认并独立晋级；临时战场状态默认在整场结束时清除也已确认并扩充状态素材；终点首领战胜利即通关并结束本局已确认；途中休整的恢复与构筑互斥已确认并独立晋级；休整改善方式已确定为随机卡包三张词卡选一张，升级暂缓；先选拿牌或恢复再开包、开包后可全部放弃、候选排除本局同名满三张的词已确认；开包后放弃不返还恢复机会，同包三张候选互不重名已确认；休整卡包主谓宾各一张、各类内部随机已确认；选择收益前检查完整卡包、某类无合格词时不提供拿牌并保留恢复已确认；休整一次有限回血、最多补至生命上限已确认，轻伤可补满；2026-09-06 下一次休整的位置提前可知已确认，具体路线与间隔后定；局内分叉路线已确认并独立晋级；选路前公开下一步活动类型、战斗的敌人类型与主要机制已确认并扩充路线素材；路线只向前推进、进入后不可撤回、完成节点不可回访或重复触发已确认，后续分叉仍可选择；每局开局按约束随机确定路线与遭遇安排、本局内保持稳定已确认，正常可选路线可继续通往终点；每次新局从同一套预设起始卡组开始、上局构筑不带入已确认并独立晋级；普通战斗词卡奖励复用休整卡包规则并作为独立战后收益已确认、独立晋级；每次普通胜利提供一次奖励机会已确认并扩充奖励素材；多敌人各自准备并公开行动及时间、共用一条时间轴已确认并扩充时间素材；普通敌人被判定击败后取消待执行普通行动、停止后续准备已确认并扩充时间与胜负素材；每句法术或每次敌方行动完整结算后立即检查击败与胜负已确认并扩充时间、胜负素材，同步供给关系；普通战斗同一检查点同时满足胜负条件时失败优先已确认并扩充胜负素材；普通敌人检查时生命耗尽即被击败、无需额外清空护甲或状态已确认并扩充胜负素材；伤害、护甲与打断 D1-D4 已整组确认并独立晋级；单份状态计时与到期 S1-S5 已整组确认并独立晋级；同种状态重施板块已按用户修改后的 R3 时长相加整组确认，并独立晋级；状态读值与同刻内部顺序 T1-T5 已整组确认并独立晋级；普通敌人被击败后的对象与状态 H1-H4 已整组确认并独立晋级；基础句对象选择与锁定 G1-G3 已整组确认并独立晋级；多敌人同刻行动顺序 E1-E3 已整组确认并扩充时间素材；施法预算与未知后续行动 B1-B3 已整组确认并扩充时间素材；战斗开局与初始节拍 O1-O4 已整组确认并扩充时间与供给素材；L1-L3 后续因新方向需要重议。界面、逐事件等待操作与停点、具体数值及联想回忆等扩展继续后置。
