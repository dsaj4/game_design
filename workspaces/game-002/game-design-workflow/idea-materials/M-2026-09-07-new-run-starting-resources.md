## 规范化表述

NR1：基础版每次新局使用同一预设基础生命上限，并以满生命开始；不继承上一局剩余生命或上限变化。具体基础生命数值后定。只在重新开局时设置，不改变同一局普通胜利保留剩余生命、休整提供有限恢复的规则；本条不决定未来哪些效果可改变生命上限。

NR2：基础版初始金币为零，通过本局战斗结算开始积累。首次商店前的基础购买力按 MN4 的预设收入、节点间隔、商品池和价格目标设计；其合理性仍未验证，不因本条确认而视为已有可用参数。

NR3：基础版不自带全局道具，通过本局商店和指定战斗奖励取得，随构筑发展流派。此范围不取消道具系统，也不建立角色选择、初始道具抽选或局外解锁；未来角色专属起点须独立提出。

已确认的预设起始卡组、上局构筑不带入与 OH 合法起手保障继续有效，基础卡表须独立满足可表达性，不能依靠未定义的起始道具补齐。每场仍按 O 从本场起点准备，不继承上局临时战场产物。具体道具内部计数、充能及连锁留待相应效果设计。

## 玩家处境、行为与反馈

- 玩家处境：结束上一局后，从新的基础起点开始本局挑战。
- 玩家看见/知道什么：满生命、零金币、无初始道具，词卡仍来自同一预设起始卡组。
- 玩家会做什么或改变什么决定：先以基础词句和时间安排完成战斗，再通过本局资源形成构筑。
- 系统如何反馈：新局按预设生命起点建立资源；同局战后不执行新局重置，获得的金币与道具依已确认规则保存到本局结束。
- 希望产生的体验或设计价值：起点明确，成长来自本局选择；开局重复与首次道具时机仍需验证。

- 支持的核心体验/设计支柱：候选方向中的词句构筑与本局成长；正式核心仍为 Unknown 占位。
- 依赖的已有系统：[起始卡组](M-2026-09-06-preset-starting-deck.md)、[OH 起手保障](M-2026-09-06-opening-hand-guarantees.md)、[生命保留](M-2026-09-05-post-victory-health-persistence.md)。
