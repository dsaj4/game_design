## 规范化表述

法术的当前可操作范围以单位、环境物体、法术生成对象、属性状态及未完成过程为主。玩家用词卡使对象的数量、强度、剩余时间或状态发生可见变化，例如点燃、冰冻；这些数值含义逐对象声明，不把所有对象统一为单位生命。环境仍没有单位生命与自主攻击。

火焰、雷电、冰霜等由法术产生、真实存在且可继续受到作用的内容，明确纳入法术生成对象。它们具有独立身份、来源与可操作窗口；同名新生对象不继承已失效实例引用，符合战前条件的生成物可在后续释放中被匹配。生成物与附着状态、已经结算的伤害及纯演出分开；范围确认不自动补齐持续时间、周期、伤害、互相反应或再次命中。

位置用于场景展示和法杖范围判定，不作为移动指令的目标。暂不开放位移、连接、支撑、独立空间参照、指定飞行方向或玩家指定新受术端点。抵挡、不指定方向的反弹和无需玩家指定接收者的作用转移可继续设计；接收规则与失败结果由具体词义明确，不能通过运行中点选补齐，也不视为环境材料搬运。

暂不建立限定材料份额、容器收材、材料供给、环境材料转移、配方合成或物体复制等资源加工链。资源收集法术的流程止于“法术作用于合格对象 → 对象掉落卡牌”；掉落卡按现行资格、同名额度和待领取收益规则处理，不增加材料提取、加工、运输或手动拾取步骤。没有明示掉卡词义的普通效果不会自动产卡。

点燃和冰冻等简单对象状态变化进入当前内容设计；燃料、导电网络、自动传播、结构坍塌等复杂环境机制继续后置。既有护甲等状态数量与明确消耗规则仍可复用，但不再据此赋予对象通用供材能力。基础句式、词卡实体成本、实例/条件绑定、单次名单、共享释放槽、当前冷却改期、四阶段、胜负与整体收益规则继续适用。

### R01–R32当前适用规则

编号用于追踪同一设计问题；本表直接陈述当前范围。位移、结构、环境材料加工和指定端点相关项已改为暂缓边界，不能再将早先的框架采纳解释为这些能力当前可用。具体参数和未明示词义仍Unknown。

| 编号 | 设计问题 | 当前规则 |
| --- | --- | --- |
| R01 | 哪些可见内容可被操作？ | 可辨认战场对象与真实法术生成物有身份和作用入口；界面/纯演出指回真实对象，装饰明确区分；可见不代表所有动词都合法。 |
| R02 | 当前操作粒度是什么？ | 以单位、环境物体、法术生成物、属性状态和未完成过程为主；变化主要落在数量、强度、剩余时间或状态。暂不把位置、连接、支撑、材料份额、容器收材等作为操作对象。 |
| R03 | 能力由什么决定？ | 由具体对象类别、当前数量/状态与明示词义决定；直接影响对象发生变化，不要求建立材料、结构或空间加工链。 |
| R04 | 怎样区分对象、属性和状态？ | 真实生成物有自己的身份和来源；属性描述对象，状态附着宿主。既有护甲等状态数量/消耗继续适用；没有环境材料份额、存储或配方供给能力。 |
| R05 | 条件如何表达？ | 保留词义许可的数量/状态比较、与/或/非及有限宿主/来源/过程关系；不借关系路径启用暂缓的空间、结构或材料操作。条件战前固定，逐对象复查，不满足跳过不补位；容量另定。 |
| R06 | 一次选全部还是选部分？ | 词义声明全部、单个或限量选择；允许的优先选择方式写入配置，不默认所有名词代表全体。 |
| R07 | 两种绑定能否混用、重叠如何处理？ | 同一法术可在不同语义角色使用两种绑定；同一角色、同一效果步骤命中同一身份只处理一次，明确的不同效果步骤仍各自生效。 |
| R08 | 对象按什么顺序处理？ | 默认沿公开初始顺序，新生对象按确定的生成先后追加；同刻按既定阶段、来源顺序和效果内顺序定先后，选择优先级须显式声明。 |
| R09 | 空名单如何反馈和收费？ | 仍完成一次无效果释放并进入后续周期，不计成功事件、不扣对应状态消耗/成本；区分无匹配、对象失效和状态数量或成本不足的原因。 |
| R10 | 如何检查操作成本？ | 每个具体效果明示按次、按对象或按实际状态消耗量计费；一次性成本在首个可结算对象前支付，无合法对象不付，不足则本次无合法结果；固定消耗不足只跳过该对象且不部分扣除。此规则不自动开放环境供材。 |
| R11 | 是否跨对象提取或转移材料？ | 当前不做环境供材、接收材料、限定份额、容器收材或跨对象状态消耗/成本转移；既有宿主状态的明确消耗不成为通用供材能力。 |
| R12 | 是否改变位置、连接或支撑？ | 当前不做位移、连接、支撑与结构操作。场景位置和基础行动继续用于表现及既有范围判断，不提供移动指令。 |
| R13 | 法杖范围是否仍存在？ | 保留法杖允许范围及作用距离检查；位置是判定信息，不是可配置的移动/空间操作端点。实例身份不免除范围检查；具体范围参数仍待设计。 |
| R14 | 位置、区域和空间参照能否作为独立操作对象？ | 当前暂缓独立位置、区域编辑及提供空间参照能力。实际作用范围可作为词义或法杖的固定规则，不把范围判断扩展成移动、空间塑形或落点编辑。 |
| R15 | 对象变化后身份如何处理？ | 数量或附着状态改变保持宿主身份；法术新生成的火焰、雷电、冰霜等获得独立新身份。对象结束则原实例失效，不自动续绑同名新对象。分离、合并和配方转化身份规则当前不展开。 |
| R16 | 状态数量和归属如何处理？ | 同一宿主的一份状态只计一次；操作后读取当前量，不凭表现复制。法术生成物与宿主状态分别记录，不重复当作两份同一效果。环境材料拆分/归属转移暂缓。 |
| R17 | 遗体和残留物如何处理？ | 死亡单位身份结束，不继承其攻击或状态。内容可明示独立遗体/残留物；当前不展开遗体材料利用，是否成为合格掉卡对象须另有收集词义。 |
| R18 | 基础句式如何承载复杂对象？ | 保留两种外层句式，名词位置可扩展为可读的复合对象短语；增加的词义仍需实体词卡，绑定配置不代替词义成本。 |
| R19 | 是否指定复杂端点？ | 执行者、操作内容和受术者仍须明确；当前不要求玩家配置材料源/去向、移动终点或新的受术端。允许继续设计无需玩家指定接收者的作用转移，其自动接收规则必须在词义中明确，不临时补任意目标。 |
| R20 | 条件是否能免费变成事件触发？ | 条件默认只在循环释放时求值；若需要“每当发生某事”，必须是独立声明、具有触发条件和成本的效果，不能由筛选条件自动变成额外施法。 |
| R21 | 攻击、冷却、飞行物何时能被操作？ | 每种过程明确准备、进行、完成阶段及可介入窗口；仅能改变尚未完成的作用，演出和已经完成的记录不能被拦截或回滚。 |
| R22 | 过程可以接受哪些操作？ | 按能力保留取消、延迟、加速，并可设计抵挡、不指定方向的反弹与非指定接收者的作用转移；指定方向偏转和玩家指定端点改向暂缓。只处理尚未完成作用，不删除整个循环或发起者。 |
| R23 | 改冷却后如何排后续周期？ | 默认修改当前未完成的剩余冷却；本次实际释放完成后按基础冷却继续循环，不直接改基础周期参数；不能在当前结算内产生额外释放，最早进入下一刻调度。 |
| R24 | 多刻释放怎样使用共享槽？ | 共享槽仲裁释放开始；直接效果在开始时结算一次，释放时长仍计入周期；需要分段或持续效果时由明确的过程或状态承载。 |
| R25 | 反馈需要显示什么？ | 公开真实对象/生成物的身份、来源、当前状态或数量、过程窗口及失败原因；时间轴说明当前已知计划变化，未来条件未定显示条件。特效、状态和真实生成物不得混为一体。 |
| R26 | 间接反应在哪个阶段结算？ | 法术明示的直接变化归本次法术；环境性质诱发的反应归环境阶段，状态周期归状态阶段；已错过所属阶段的新事件转到下一刻对应阶段。 |
| R27 | 是否推进复杂传播链？ | 自动传播和复杂连锁当前后置。简单作用按已声明阶段与终止条件结算；不能重选本次直接名单制造同刻无限循环。未来启用连锁时仍须限制同根因、同对象、同规则同刻重复。 |
| R28 | 环境和元素怎样产生变化？ | 点燃、冰冻等简单状态变化纳入当前设计；火焰、雷电、冰霜等真实法术生成物可受后续合法作用。燃料、导电网络、自动传播和坍塌等复杂反应暂缓，不凭现实物理推定额外结果。 |
| R29 | 环境作用是否伤及友军和自己？ | 受明示名单或传播范围覆盖且能力匹配的对象均可受作用；阵营保护必须由选择条件或效果明确提供，不默认免疫友军。 |
| R30 | 法杖与配置是否可改？ | 法杖/配置用于承载法术和范围，当前不做法杖位移或连接。法术的明示运行数量/过程可按能力改变；战中仍不重分词卡、换法杖顺序或改镶嵌。 |
| R31 | 资源法术如何产出？ | 资源收集仅做法术作用于合格对象后对象掉落卡牌；生成前检查资格、已持有加待领取的同名额度及效果限制，合法才记入待领取。无材料提取/加工/运输/手动拾取链，也不通过复制/改名绕过权益规则。 |
| R32 | 变化能否跨战保留？ | 对象状态、法术生成物和过程默认本场有效；玩家生命、已领取库存与收益按现行跨战规则。场上掉卡表现不等于战中可重配库存，不新增永久世界加工。 |

### 共同解释边界

- R08的新对象进入世界公开顺序；SW02-A不向产生它的本次直接名单追加。下一次释放的条件引用可选符合条件的生成物。
- 燃烧状态不等于火焰生成物，冰冻状态不等于冰霜生成物，演出不等于真实作用。即使共用同一词名，不同语义角色也须写清，并按实际词卡出现项分配。
- 状态量消耗、合法零值、一次性费用、按对象费用及成功事件规则继续有效；不据此重建环境供材链。各类收集掉卡须明确产出资格与限制。
- 抵挡/反弹/转移只处理未来作用；接收规则未写清前不能声称可完整结算。没有指定方向不代表可以临时任意选目标。
- 当前冷却改期保留R23的最早下一刻与基础周期区别。火焰等生成物需要可介入窗口；延长画面动画不能延长已经结束的真实作用。
- 点燃/冰冻是当前简单状态设计方向，具体伤害、持续、控制与相互反应不自动成立。完整召唤、镶嵌、燃料/传播/导电/坍塌仍不在本轮展开。

## 设计对象与GDD映射

- 对象：简单数量/状态变化、真实法术生成物、作用过程与对象掉卡。
- 目标GDD：尚未创建；统一GDD的法术、对象、时序和反馈章节。
- 完成度：GDD-0 / 部分GDD-1素材输入，不等于完整内容规格。

## 玩家处境、行为与反馈

战前用真实词卡确定对象/条件与法杖安排，战中观察数量或状态变化及生成物。界面公开身份、来源、当前可操作量/状态、窗口、已知时点和失败原因；资源法术成功时显示合格对象掉卡并对应待领取记录。没有战中方向/接收端/位置操作。

## 与当前构思的关系

## 机制—行为—体验假设

| 规则 | 可能行为 | 目标体验 |
| --- | --- | --- |
| 简单对象变化与有身份的元素生成物 | 复用词义处理不同目标和法术结果 | 直接、可推导 |
| 窗口、当前数量与明确掉卡资格 | 安排作用先后、保护与收集 | 自动战斗的因果可理解 |

## 未知项与验证

具体元素作用/窗口、点燃与冰冻结果、反弹/转移自动规则、掉卡条件和所有参数继续设计。用生成后再次引用、状态结束、已完成作用不可回滚、重复收集超额及完整事件胜利停止检查；这些是纸面验收要求，不是通过运行验证的结论。
