## 规范化表述

玩家通过释放元素，在战场空格中建立真实元素单位。元素向附近单位施加对应状态，也能作为后续法术的执行者或作用对象，例如攻击敌人、消耗护甲。元素释放过程中，范围内已有同种元素则给已有元素叠层；无同种元素且有合法空格则生成；既无同种元素也无合法空格时，释放法术向施法范围中的单位施加对应状态，并继续尝试直到有空格或施法结束。

元素本体层数与其携带的对应元素状态共用一份量。该量随时间衰减，归零时元素消失并释放占位；环境单位转化为元素时继承对应状态层数。单位固有属性独立于当前元素状态，火克草、草克冰、冰克火；克制关系影响元素状态增减。每个单位最多同时有一种元素状态，异种施加先抵消旧状态，清空后的剩余施加量才建立新状态。

环境转化及异种元素消失后的补生须处于相关释放法术影响下。环境单位的转化阈值随各单位事先设置，先经历自身形态阶段，再消失并转为元素；无释放法术则停留末阶段。其他元素本体被抵消至消失时，有释放法术则新增其对应元素，无释放法术则不新增。第一阶段不设计草元素状态或法术，只保留草属性单位在克制中的关系。

## 已明确规则

### EL01 词卡入口与术语分离

- 简易卡池删除直接施加元素状态的“点燃”“冰冻”动词，状态与名词保留；元素释放和元素作用承担施加。
- 本轮按元素语境解释删除范围，非元素状态的获得、标记等暂保留；不得以获得燃烧／冰冻恢复同义入口。
- “元素单位”是占位的真实元素对象；“元素状态”是宿主携带的状态；“固有属性”是宿主自身属性。
- 大树为草属性，带燃烧不使它自动变成火属性或火焰元素。环境转化是另一个明确变化，不能把“带状态”与“已转化”混同。

### EL02 元素释放的判定顺序

| 当前释放检查中的情况 | 行为 |
| --- | --- |
| 法术范围内已有对应元素单位 | 不生成新同种元素，继续增加已有元素层数 |
| 没有对应元素，存在合法空格 | 尝试在空格生成元素，元素携带对应状态层数 |
| 没有对应元素，也没有合法空格 | 向本次释放法术范围内单位施加对应状态，并继续尝试 |
| 上述回退期间出现合法空格 | 转回生成机会；不以“开始时满格”永久判失败 |
| 施法结束 | 不再继续该释放过程的尝试；已经存在的元素按自身层数生命周期继续 |

“同种已有不新生”作为用户对生成分支的限制，因此即使仍有其他空格，也先处理已有同种元素。RC07已确定范围内公开顺序首个同种，每个释放窗口内逐刻检查；生成后后续检查转为补层。出生格按G002-CORE-021，见[首版空间素材](M-2026-09-13-first-release-content-scope.md)。

释放法术的范围与元素自身的邻近范围分别声明，不能把二者视为相同。空格具体合法性继承所选战场方案，不自行引入位移或挤占。

### EL03 邻近状态与主动操控

- 元素单位向附近单位施加其对应元素状态，例如火焰施加燃烧。
- 无空格时的施加来自仍在进行的释放法术，不要求场上凭空存在一个火焰。
- 后续可用法术操控元素；“火焰 伤害 敌人”按元素类型讨论，“火焰 消耗 护甲”按元素＋状态类型讨论。
- “攻击敌人”采用现有直接伤害方向作语义参照；“消耗护甲”的当前推荐是实际消耗敌方护甲并转为执行元素层数，来源状态和命名边界见EL07，完整数量规格未定。
- 旧树草不二次传播的确认保留；只有环境实际完成转化、成为元素单位后，才涉及新元素的邻近作用。环境的燃烧形态本身不自动获得传播。

### EL04 元素共享层数与消散

- 元素本体层数＝携带的对应元素状态层数；没有两份并行层数。
- 元素层数随时间衰减；归零则元素消失，空出其占用格子。
- 环境单位转化为元素，继承其对应状态的层数，不重置为默认初始量。
- 环境单位的转化阈值随各单位事先设置，不采用所有单位通用的默认阈值。在相关释放法术作用下，阈值内先经历形态阶段，例如树木→燃烧的树木→被烧焦的树木，再消失转为元素；新元素继承对应状态层数。
- 没有释放法术时，环境停留在最后形态阶段，不继续消失变为元素；不将“末阶段停留”解释成状态层数停止变化，形态保留与后续阈值按G002-CORE-022。
- G002-CORE-022：环境物体的各阶段形态阈值与最终转化阈值，均按该物体当前携带的对应元素状态层数判断，不另累计历史施加量。层数被抵消、消耗、清除或自然衰减后，后续判定读取降低后的当前量；未达到相应阈值时不能凭过去累计施加量继续推进或完成转化。阈值仍由各物体事先设置，最终转为元素仍须满足相关释放法术作用条件。已达到的形态只前进、不自动回退：状态层数降低或清空不会恢复原形态；燃烧结束后的焦树仍保留烧焦形态。状态消退会停止该状态的实际效果，继续推进或最终转化仍须当前层数达到相应阈值。
- G002-CORE-023：环境物体位于对应元素法术当前持续释放的范围内，即满足相关释放作用条件，不要求释放法术本身直接给该物体施加状态。每刻环境阶段末，先完成本刻元素的邻近施加，再统一检查环境形态推进与最终转化，读取此时当前对应状态层数及对应释放范围。法术释放段的最后一刻仍算有效覆盖；本次环境转化出的元素从下一刻开始自动邻近施加。没有对应法术正在释放并覆盖时，环境停留在已达到形态，不完成最终转化；残留元素本身不提供释放许可。
- G002-CORE-024：环境物体完成转化时，旧环境身份结束，生成具有新身份的对应元素，并继承对应元素状态的当前层数。原来固定指向旧环境实例的效果不自动转向新元素；本次已经确定的目标名单也不以新元素替换旧环境。后续按条件重新选取对象时，符合词义与范围的新元素可以正常入选。形态阶段变化本身仍不更换身份；创建归属、生成特性与小数衰减进度按后续G002-CORE-025执行。
- G002-CORE-025：环境转化的新元素归属于转化检查时提供对应持续释放覆盖的法杖，采用该条完整法术的生成特性；多个合格法杖同时覆盖时，取战前排列最靠后的法杖，与共享释放槽优先级一致，不沿用旧环境状态的首次来源。新元素的固有属性取自身种类：火焰为火，冰霜为冰。对应状态的当前层数与尚未扣足整层的小数衰减进度一并带入；继承不是重新施加，不重复计算克制入量修正或新增量加成，后续增减按新元素的固有属性和特性处理。旧环境的无关状态、旧护甲和掉卡额度不复制给新元素；转化不额外计为一次完整法术成功。
- G002-CORE-026：环境占位物转化、异种元素被抵消后按正余量补生，均在旧占位对象腾出的原格生成具有新身份的对应元素，不将层数并入别处已有同种元素，也不改找敌人旁的其他格子。即使当前范围内已有同种元素，原地替换仍可产生新元素；普通释放分支继续遵守同种优先、公开顺序首个同种补层的规则。第一版只有具备转化资格的环境占位物能转化成元素；地面保留原身份，不转化成占位元素，仅发生已经定义且自身具备资格的状态或形态变化。异种补生仍只使用先修正入量、再抵消旧状态后的正余量；余量为零或没有相关释放作用时不补生。
- G002-CORE-027：异种元素被合法状态施加抵消至消失后，只要对应新元素法术正在持续释放并覆盖原格，就允许按正抵消余量原地补生，不要求释放法术本身直接完成抵消。新元素归属于战前排列最靠后的合格覆盖法杖，采用其生成特性与新元素自身固有属性；入量仍只在抵消前修正一次，正余量不因创建来源改变而重新修正或加成。补生作为该抵消原事件的直接结果完成，不等待环境形态转化检查，不额外计一次完整法术成功。旧异种状态已经清空，新元素状态的小数衰减进度从零开始；环境转化带入进度的例外不用于异种补生。无对应释放覆盖或没有正余量时不生成新元素。
- 各形态的具体阈值与逐类物性资格仍待明确；不默认转化为角色死亡或额外掉卡。
- 其他元素本体被抵消至消失时：若处于相关释放法术作用下，则新增该释放法术对应元素；无释放法术则只消失、不新增。新增元素不同于把状态附到已不存在的旧宿主。
- 异种元素替换生成的初始层数等于抵消后的剩余施加量：先按新元素与目标固有属性的克制关系修正入量，再等量抵消旧元素层数；有相关释放法术且余量大于零时，以该余量生成对应元素。恰好抵消时余量为零，依据零层消散规则，不留下新元素；不足以抵消时旧元素减层并保留。没有相关释放法术时不新增元素。
- 环境转化继承原单位对应状态层数；异种元素替换使用抵消余量，两者分别处理。两者均原地生成新元素，范围内已有同种不合并；普通释放分支仍同种优先。异种补生许可与来源按G002-CORE-027，正余量随抵消原事件生成，新进度从零开始。

### EL05 固有属性与克制

克制环：火→草→冰→火。读取承受状态的单位固有属性，不读取它目前携带的元素状态来替代该属性。

| 施加元素与目标固有属性的关系 | 该元素状态层数增加速度 | 该元素状态层数减少速度 |
| --- | --- | --- |
| 施加元素克制目标属性 | 翻倍 | 减半 |
| 目标属性克制施加元素 | 减半 | 翻倍 |
| 没有已定义克制关系 | 不由本克制规则额外改动 | 不由本克制规则额外改动 |

这些倍数来自用户明示，属于机制，不是本轮新增平衡值。无属性单位不进入已定义三角；同属性未获得额外克制规则。第一阶段仅保留草元素／草属性单位的克制关系，不涉及草对应状态和法术；因此不得把草状态设计列为本阶段前置。雷电关系另未定义，不据此自动删除已有雷电候选。

例：火对草属性大树，燃烧更易积累、减少更慢；冰对草属性大树，草克冰，因此冰系状态更难积累、减少更快。大树当前带哪种状态，不改变它的草属性判定。

RC08明确：克制作用于元素状态入量及ST自然衰减，主动支付和清除不套自然衰减倍率；汲取移量补本体不额外乘克制，倾注对目标施加时修正一次。

### EL06 单元素状态与异种抵消

1. 每个单位同时最多一种元素状态；这不限制非元素状态护甲／力量等的共存。
2. 新施加元素先与目标固有属性比较，修正本次施加量。
3. 若目标没有元素状态，施加量建立对应状态；若是同种状态，累加。
4. 若已有异种元素状态，修正后的施加量先逐层消耗旧状态，按等量抵消。
5. 新施加量不足以清空旧状态，保留旧种类及其剩余量，不同时附加新状态。
6. 刚好全部抵消，目标没有元素状态。
7. 旧状态耗尽后仍有施加量剩余，才把余量转为新元素状态。
8. 同次抵消只按步骤2修正一次，不再因为旧状态的克制关系重复放大／缩小抵消量。

若宿主本身是元素单位，旧状态归零使旧元素消失，则进入EL04的元素补生规则：在相关释放法术作用下生成该法术对应元素，否则不新增。普通宿主的“余量建立新状态”不代表可继续给已经消失的元素宿主附着状态。补生初始层数取抵消余量；恰好抵消不留下新元素，有正余量且处于相关释放作用下才留下对应新元素。此零余量结果由共享层数归零消散规则推得，不另行规定瞬时生成事件。

这是用户选择的抵消顺序。不同来源同刻先后仍依最终事件顺序处理，不新增同时相抵的独立全局阶段。

### EL07 冰冻护甲方向与动作命名（2026-09-13）

来源：[第六项用户修订](../idea-inbox/2026-09-12-element-spell-archetype.md)。冰冻的状态效果为增加护甲，与燃烧造成伤害相对应；此前EL-R02普通攻击减速推荐退出当前设计，不同时保留。此方向Qualified／Hypothesis，冰冻每刻末增甲已由ST01明确，E3净化不撤回已得护甲；与层数的具体对应量仍待定，不默认存在额外减速。

“吞噬护甲”改名为“消耗护甲”，仅修改名称。已有推荐中的实际消耗敌方护甲并转换为执行元素对应层数、无实际消耗则无收益等效果保持原样；命名确认不等于整版推荐或全部执行细节已采纳。例句同步为“火焰消耗敌人的护甲”“冰霜消耗敌人的护甲”，仍为元素＋状态类型。

| 单次名单与持续重试 | 持续过程后续重新检查占位／目标，需要定义事件边界；建议各独立过程事件固定自己的名单，尚未作为通用规则采纳 |
| BF-C满位不挤占 | 保留不挤占；本次新增满位施加状态及重试，不能继续用“满位无任何效果”概括新元素法术 |
| BF火焰P与独立寿命 | 本轮共享层数与归零消散成为新方向依据；旧P／独立到期版本保留历史，不能同时作为元素流派默认 |
| BF烧焦后环境身份与占位保留 | 无释放法术时停留末形态；有相关释放法术且满足转化条件时环境消失变元素，不再把旧“始终占位烧焦”作为默认；阈值按单位预设；完成转化时新元素具有新身份，具体值及其他继承项另定 |
| 双生的 | 创意继续保留，但须明确如何与同种已有不新生的规则配合；未授权例外，当前不直接套入 |
| 寒冷／灼热／燃烧强化／融冰针 | 保留各自来源状态；后续按互斥与抵消规则逐项适配，不自动删除也不默认已兼容 |
