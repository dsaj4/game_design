## 规范化表述

词卡随战斗时间流逝按固定速度补充。玩家能够看见多张即将补入的词卡及其先后顺序，据此比较用现有词立即施法，或推进战斗时间等待更多组件。已确认的构句暂停继续适用，现实中的思考用时不推进补牌。开战建立牌库及弃牌洗回时随机洗牌，之后按序抽取；除正常抽取推进外，只有明确的效果才改变顺序，查看、思考或构句不重新随机下一张。具体补牌速度与可见张数尚未决定。

基础牌序来源：用户于 2026-09-05 对上述洗牌与顺序抽取规则回复“确认”，原问题和确认边界见[基础牌序确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#基础牌序确认)。该确认不决定起手保障、改序魔法细节、满手处理或洗回与其他事件同一时点的先后。

满手处理由后续用户表达明确：满手仍正常补入新牌，超过上限后立即由玩家选择弃牌至上限，使不需要的旧词能够被新词替换。弃牌从补入后的手牌选择，可保留旧词或新词，不自动丢弃新牌。普通弃牌进入弃牌循环，与本场移除不同；容量不阻止时间补牌和牌序前移。来源见[满手补牌确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#满手补牌确认)。

用户随后确认：超限弃牌时暂停战斗时间，只允许选择弃牌，完成后继续原行动。若当时正在施法，不得借此改句、取消或开启第二次施法。暂停期间施法、敌方计时和补牌计时都不推进，已过去的时间不回退，原计时不重置；这不是敌方命中造成的施法打断。同一时点先处理敌方行动，再处理固定补牌及其超限窗口，完整普通顺序见下文。

普通投入词的去向已由用户后续确认：本次施法结束后，无论成功还是被打断，投入的普通词卡都进入弃牌堆，等待后续洗回；施法结束不额外补牌，仍按既定战斗时间供牌。成功按既有规则产生整句效果，命中打断则整句无效、已过去的时间不退。来源见[施法投入词去向确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#施法投入词去向确认)。此规则不决定投入词何时离开手牌、是否占手牌上限及特殊词卡去向。

投入词的离手时点及容量占用由后续确认明确：确认施法时，投入词立即离开手牌，进入临时施法区，不占手牌上限，也不能用于超限弃牌；成功或被打断后依上述规则进入弃牌堆。施法期间的新牌进入手牌，是否超限仅看手牌中的词卡。腾出的空位不会立即补满，仍等待既定时间补牌。来源见[临时施法区确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#临时施法区确认)。

起手保障由用户后续确认：开局手牌至少能用本局自有词卡组成一条合法基础句，不保证最优组合，也不保证后续每次补牌都能成句。这是随机起手的明确保障，具体保障方式与起手牌数后置；不据此赋予玩家任意选牌、无限重抽或从卡组外获得词卡的权利。来源见[起手保障确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#起手保障确认)。

空抽牌堆的洗回触发由用户后续确认：到达补牌时点，抽牌堆为空且弃牌堆有牌时，将当时的弃牌堆随机洗回，在本次补牌时点继续抽取，不额外耗时，也不改变既定补牌节拍。手牌、临时施法区及本场移除牌不参与洗回。来源见[空抽牌堆洗回确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#空抽牌堆洗回确认)。

普通同刻结算顺序由用户后续确认：先结算已完成法术并弃置普通投入词，再处理敌方行动及可能的命中打断弃置，最后处理固定节拍补牌、所需洗回及超限弃牌。中间不开放新施法，战斗结束则停止后续流程；仍在施法则继续原施法，否则结清该时点事件后恢复构句。同刻刚弃置的词能参与随后的洗回，新补入的词不能抢在该时点敌方行动前使用。来源见[同一时点顺序确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#同一时点顺序确认)。多敌人内部顺序、持续效果、连锁触发及特殊抽牌尚未定义。

跨洗回预览由用户后续确认：抽牌堆剩余牌不足预览范围时，仅展示当前确定牌序，其后标为“待洗回”；不为补足预览提前洗牌。实际洗回并完成当次抽取后，才显示新抽牌堆顶部的未来牌序。临近洗回时可见信息可以少于通常预览范围，具体可见张数后置。来源见[跨洗回预览确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#跨洗回预览确认)。

用户随后要求设置卡组下限，防止抽牌堆与弃牌堆同时为空，并确认本场移除也受安全下限约束：移除不能使仍参与本场循环的词卡数量低于下限。参与循环的数量包括手牌、施法区、抽牌堆和弃牌堆，不包含已本场移除的词卡。安全下限需结合各牌区最大占用设计，具体数字后置。来源与资格复审见[卡组下限方向与资格追问](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#卡组下限方向与资格追问)。本规则不代表防双空堆已经验证。

触限处理由用户后续确认：移除效果最多执行到安全下限，超出可移除余量的部分不执行，并在施法前提前展示实际可移除量。余量为零时不再移除词卡；具体目标选择、关联收益及施法期间状态变化如何影响预览仍后置。数量截断不自动定义整句失败、返还时间或其他效果的结算。确认来源同上。

临时副本的默认循环由用户后续确认：副本投入施法后，无论成功还是被打断，均进入弃牌堆；从手牌被普通弃置时也进入弃牌堆，之后随既有洗回与时间补牌流程再次参与抽取，不因使用一次自动消失。明确的本场移除效果仍可使其提前退出循环，战后按已确认范围清除。来源见[临时副本正常循环确认](../idea-inbox/2026-09-05-deck-vocabulary-cycle.md#临时副本正常循环确认记录)。同名数量权限及跨战斗归属见[新词入组素材](M-2026-09-05-new-word-deck-inclusion.md)；本次不确定复制目标、初始进入位置、生成数量、复制链或费用，也不把确认循环等同于额外补牌或保证再次到手的时点。

## 玩家处境、行为与反馈

- 玩家处境：在敌方行动形成的时间压力下，使用当前词汇组织法术。
- 玩家看见/知道什么：多个未来词卡及其相对先后；显示具体到达时点为推荐细节，未自动采纳。
- 玩家会做什么或改变什么决定：比较现在施法与等待后可能形成的句子，为后续组件调整计划；满手收到新词后选择留下哪些组件、弃掉哪些词。
- 系统如何反馈：战斗时间推进带来补牌，未来可见序列相应前移；看见未来词不等于已经取得该词。已进入手牌并投入使用的临时副本可在弃置、洗回后再次参与抽取，本场移除和战后清除则使其退出。
- 希望产生的体验或设计价值：用更多信息支持时间规划与连句准备，减少等待完全依赖盲猜的情况；实际体验待验证。

## 机制—行为—体验假设

| Mechanics：提供什么规则/约束 | Dynamics：可能诱发什么行为 | Aesthetics：希望产生什么体验 |
| --- | --- | --- |
| 战斗时间以固定速度带来词卡 | 比较立即施法与等待更多组件 | 为机会承担时间代价 |
| 多张未来牌序可见 | 为后续句子保留组件，调整当前计划 | 预判与连句准备 |
| 跨洗回部分标为待洗回，实际洗回后才显示新序列 | 在已知近期组件与未知下一轮牌序之间安排施法和等待 | 信息可信，同时保留洗回前的不确定性 |
| 构句阶段时间暂停 | 比较当前词与未来词，不依靠现实操作速度等牌 | 推演与掌控 |
| 开战/洗回随机洗牌，随后按序抽取，明确效果才改序 | 在随机形成的供给上规划，依明确干预调整计划 | 预览可信且构筑分布有意义 |
| 满手仍补入新词，超限立即选择弃至上限 | 比较新旧组件，保留计划需要的词 | 手牌可更新，减少无用词占位造成的停滞 |
| 超限弃牌暂停时间，仅弃牌后继续原行动 | 从容整理手牌，保持已确认施法的承诺 | 选择清晰，不要求限时弃牌操作 |
| 普通投入词在成功或打断后统一弃置，结束不额外补牌 | 为新句子重新调度组件，承担失败投入 | 循环清楚，施法承诺有代价 |
| 临时副本默认正常弃置并参与洗回，本场移除可提前退出、战后清除 | 评估复制对本场后续组合与组件分布的持续影响 | 本场卡组调整具有延续性 |
| 确认施法时投入词离手进入不占容量的施法区 | 为施法期间的新牌留出空间，区分已承诺组件与可调度手牌 | 状态清晰，无法通过弃牌撤回投入 |
| 起手至少能用自有词卡组成一条合法基础句 | 开局能够比较施法与等待，无需因完全不能构句而必然空等 | 基础可表达性与构筑归属感 |
| 补牌遇空抽牌堆时洗回当时弃牌，继续抽取且不额外耗时 | 按固定供给节拍等待用过的词重新出现 | 词卡循环可理解，洗回不额外打断时间规划 |
| 卡组设置下限，本场移除也不得使仍参与循环的牌数低于安全下限 | 在有限的移除空间内选择压缩哪些组件 | 保持供给，保留精简卡组的取舍 |
| 移除量最多执行到下限，并提前显示实际可移除量 | 根据剩余移除空间判断该法术是否值得施放 | 约束可见、结果可预期 |
