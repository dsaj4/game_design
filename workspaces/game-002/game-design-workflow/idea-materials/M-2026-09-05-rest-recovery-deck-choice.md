## 规范化表述

基础版在一局途中提供战斗间休整机会。玩家选择收益之前，先检查当前词池在排除本局同名满三张的词后，能否组成主语、谓语、宾语各一张且互不重名的完整卡包。能够组成时提供恢复生命与拿牌两项选择，选择一项即放弃另一项；若某类没有合格候选，无法组成完整卡包，则本次不提供拿牌，只保留恢复分支。告知卡包不可用即可，检查不提前公开具体候选，也不自动为玩家恢复生命。

拿牌分支的可用条件仅取决于能否组成合格卡包，不因玩家不喜欢候选、候选彼此不兼容或不适配现有卡组而关闭。

选择恢复则按之后确定的恢复规则补充生命。选择拿牌后才开启随机卡包，固定提供主语、谓语、宾语各一张候选，在各自符合获取资格的词卡中随机产生。玩家可以收下其中一张，也可以一张都不拿；不会同时获得三类词。收下的词卡按既有规则直接加入本局卡组，参与后续战斗的抽取与循环；全部放弃则不加入候选，也不移除已有卡。

选择拿牌已放弃本次恢复机会，因此开包后全部放弃也不能改选恢复或取回恢复机会。这延续已有休整互斥关系；“可不拿牌”只决定是否收下候选，不撤销先前的分支选择。

本次休整卡包排除本局卡组中同名已达三张上限的词卡，供玩家选择的候选中不会出现这些满额词。已有两张的词仍可出现并收下一张达到三张；已有三张则不出现。上限按本局卡组拥有关系统计，临时复制或本场移除不改变本局持有名额；不以展示后禁选代替候选过滤。

同一次休整卡包的三张候选必须互不重名，提供三个不同词卡选项。该限制只作用于同包候选；不同卡包仍可出现本局尚未满三张的已有词，允许收集第二、第三张副本，不要求候选全是从未获得的词。

三类各一张提供三个句法类别的选择机会，不保证候选彼此兼容、与现有卡组兼容，或收下一张便能补齐合法句。满额过滤与同包不重名也不保证语义适配。新增卡可能拓宽表达、补齐组合，也可能改变组件分布并增加等待；允许全部放弃使玩家不必为使用休整机会而被迫加入不适配卡。

当前基础版暂不引入词卡升级，相关候选为 Parked / Deferred，保留待未来重新讨论；本次获取不强化或替换已有卡，也不开放永久删牌。

卡包候选池、各类内部随机权重、稀有度、主动重抽与补偿均待定；某类无合格词或全部满额时，执行上述拿牌分支不可用规则，不以跨类、重名、满额词或不完整卡包补位，也不因此给予免费重抽、补偿或自动恢复。休整的位置、次数、固定或随机分布、恢复量及能否在未选分支时直接跳过整次休整仍待设计。并非每场胜利都自动提供休整，也不能推定每次回满生命。

普通战斗词卡奖励可全部跳过的既有权限保持原有范围；休整开包后拒收是本轮独立明确的权限。休整三选一、三类各一张和满额卡过滤不自动规定普通战斗奖励的候选数量、领取数量、词类分布或满额处理，普通词卡奖励也不因休整互斥而与恢复捆绑。

休整发生于当前一局尚在进行的战斗间流程；普通战败或终点首领战胜利已使本局结束时，本机制不提供继续推进该局的权限。它也不允许在已经结束的原战斗中继续推进时间、施法或补牌来恢复生命。

## 玩家处境、行为与反馈

- 玩家处境：带着受损生命和仍有短板的卡组进入休整，需要准备后续战斗。
- 玩家看见/知道什么：在选择收益前知道拿牌分支是否可用，无法组成完整卡包时本次只保留恢复；拿牌可用时仍在不知道三张具体候选的情况下先选恢复或拿牌；选拿牌后才看见主语、谓语、宾语各一张、互不重名的候选，知道可全部放弃且满额词不出现，放弃不恢复本次恢复机会；界面后置。
- 玩家会做什么或改变什么决定：拿牌可用时先按剩余生命与卡组需求权衡恢复机会和未知的词卡机会；不可用时仍由玩家选择恢复，不自动回血；开包后比较三个词类各自的候选对卡组短板、语义兼容及循环的影响，选择收下一张或全部放弃。
- 系统如何反馈：选择恢复时补充生命；收下候选时，它成为本局卡组成员，参加后续战斗，不因此立即入手或保证起手抽到；开包后全部放弃则没有词卡入组，也不获得本次恢复。
- 希望产生的体验或设计价值：通过获取与搭配发展构筑，保留先选分支带来的随机风险，同时让玩家拒绝不适配的卡；需验证两类收益的价值以及开包后无收益的落差。

## 机制—行为—体验假设

| Mechanics：提供什么规则/约束 | Dynamics：可能诱发什么行为 | Aesthetics：希望产生什么体验 |
| --- | --- | --- |
| 途中提供战斗间休整机会 | 在生命损耗后考虑补救，并为后续遭遇准备 | 失误后仍有调整空间 |
| 同一次休整的恢复与改善卡组互斥 | 比较当前生存余量与后续构筑能力 | 成长与生存都有机会成本 |
| 先选拿牌再开启三张候选词卡的随机卡包 | 在未知具体候选时评估是否值得放弃恢复 | 构筑机会带有风险与期待 |
| 开包后可收下一张或全部放弃，放弃不返还恢复 | 根据搭配与循环代价拒绝不适配的词 | 保有卡组控制权，同时承担机会成本 |
| 卡包候选排除本局同名已满三张的词 | 在尚有入组名额的词中作选择 | 减少明确无法收下的候选 |
| 同包三张候选互不重名，跨卡包仍可出现未满额的已有词 | 比较三个不同词，同时保留收集熟悉词副本的机会 | 减少重复候选占位，维持构筑选择空间 |
| 候选固定为主语、谓语、宾语各一张，各类内部随机 | 比较当前更需要补强哪一类，以及候选能否兼容既有组件 | 三类都有选择机会，构筑短板影响取舍 |
| 选择收益前检查完整卡包可用性，某类无合格词时只保留恢复分支 | 在知道拿牌不可用的情况下决定后续行为，避免先放弃恢复才发现无法开包 | 收益承诺前获得必要信息；一类满额可能限制其他类获取的代价仍待验证 |
| 新增词卡参与固定时间补牌与循环 | 评估新组合价值能否补偿原有组件到手节奏的变化 | 拿牌有构筑后果，不只是数量增长 |
| 少受伤可降低对休整恢复的依赖 | 在战斗中更重视减少损耗，从而保留选择改善卡组的空间 | 本场选择影响整局发展 |

以上行为与体验均为假设，不由用户确认自动证明。

| 先选拿牌但开包后无合适词 | 玩家可能没有拿牌且失去恢复机会 | 比较不同生命与卡组需求下的开包选择、放弃理由和落空体验 | 玩家理解机会成本，仍有合理情境愿意选拿牌 | 普遍误以为放弃可改恢复，或落空感使拿牌长期无人选择 |

| 一类无合格词会使整次拿牌不可用 | 即使另外两类还有可用词，本次休整也无法获取它们，可能过早限制构筑 | 结合实际词池规模推演某类部分满额、整类满额与全部满额；检查分支可用性在选择收益前已明确，记录不可用频率及后续成长路径 | 玩家承诺收益前已知分支是否可用，仍有合理成长路径 | 先放弃恢复才发现无完整卡包，或一类满额过早封死其余类别的获取 |
| 不同词卡未必提供不同构筑价值 | 不重名可能只是名称不同，实际选择仍单一 | 词义明确后比较不同候选的用途及选择理由，检查玩家是否仍只按单卡强度固定拿牌 | 三张候选在部分局面具有不同用途，已有词副本仍有合理获取机会 | 不重名被误解为禁收副本，或候选总由同一种用途支配 |
| 新词可能稀释可用组合 | 新增表达收益未必补偿等待和缺类风险 | 词义明确后比较拿牌前后的可构句机会、等牌及弃牌行为，并推演即时适配与需后续配套的新词 | 部分新词因搭配价值值得收下，恢复与拿牌各有场景 | 候选长期不适配，拿牌只延长等待或总是固定选择 |
| 低生命玩家被迫持续恢复 | 失去成长后更容易受伤，形成进一步落后的循环 | 收益与遭遇节奏明确后，比较早期少量失误和较大损耗后的数次选择 | 受伤后仍有恢复并重新发展构筑的路径 | 连续只能恢复，卡组长期无法改善 |
| 某个分支长期占优 | 休整退化为固定选择 | 比较不同生命、卡组短板和已知挑战下的选择理由 | 两项分别有合理使用情境 | 总恢复或总改善，不看局面 |
| 休整位置、次数与恢复强度未定 | 无法判断补救是否及时，或是否抹平战斗损耗 | 后续确定机会分布，再结合连续战斗推演与试玩 | 损耗有意义，休整有可解释的规划价值 | 恢复总来不及，或轻易消除全部损耗 |
| 直接跳过休整与其他特殊流程未定 | 开包后拒收不等于未选分支前直接跳过，重抽、补偿及结束后的机会处理仍待定 | 后续按具体依赖澄清；只保留已明确的开包后拒收，不自动推广其他权限 | 能区分选分支、开包后拒收、普通奖励和本局结束 | 把拒收等同于恢复机会返还、免费重抽或其他奖励自动豁免 |
