# 时间背包自走棋规则确认记录

## 本轮目的

记录用户对 `Core Concept v0.2` 冲突和不明确部分的集中确认，并将首版玩法收束为自走棋式自动战斗。C01–C12 与 U01–U08 已确认内容进入 `Core Concept v0.4`；具体效果、参数和后续扩展继续保留为 Unknown。

## 已确认规则

| 编号 | 确认结果 | 状态 |
| --- | --- | --- |
| C01 | 战斗中不使用牌组、手牌或补牌；词卡不参与当前战斗构句。 | Confirmed |
| C02 | 战斗场景为简易长方形地图，敌人和环境对象占据实际位置。 | Confirmed |
| C03 | 每根法杖只承载一条循环法术并确定其释放范围；首版战前固定范围内的合法敌人、环境对象和自身，整场不按位置刷新。 | Confirmed |
| C04 | 所有法术第一次冷却的开始时刻必须安排在第 0–10 刻内。 | Confirmed |
| C05 | 循环周期等于冷却与释放相加；4 刻冷却加 1 刻释放的周期为 5。 | Confirmed |
| C06 | 法杖配置时确定法术顺序；同刻冲突时靠后的法术覆盖靠前法术，靠前法术本次无实际效果，也没有释放特效，后续周期不变。 | Confirmed |
| C07 | 普通循环法术只有在玩家实际受到生命值伤害时才会被打断，而且只打断当时正在冷却的法术；单纯被攻击或被护甲完全抵消不打断。 | Confirmed |
| C08 | 同刻处理顺序为：法术效果、敌人攻击、环境变化、状态效果。 | Confirmed |
| C09 | 环境对象指长方形场景地图中、在法术范围内、可被操作但没有生命值和攻击行为的对象，例如大树、溪流；第一阶段敌人和环境对象不移动。 | Confirmed |
| C10 | 战后金币与由法术效果产生的卡牌一起结算，玩家可以整体领取或放弃；金币来源包括基础收益、时间额外奖励和特殊法术效果。 | Confirmed |
| C11 | 首版不允许脱离循环编排的主动施法或一次性法术。 | Confirmed |
| C12 | 胜利成立后立即中断所有其余处理，包括尚未处理的法术。 | Confirmed |

## U01–U08 集中确认结果

| 编号 | 确认结果 | 状态 |
| --- | --- | --- |
| U01 | 冷却在第 0 刻开始；4 刻冷却加 1 刻释放的法术在第 4 刻首次释放。 | Confirmed |
| U02 | 首版在战前固定法杖范围内的合法对象，释放时不按位置动态刷新；动态目标作为后续候选。 | Confirmed / Versioned |
| U03 | 目标失效时不结算，直接跳过该目标；法术继续处理其他合法对象。失效目标没有实际效果，但释放特效仍播放。该规则区别于同刻被后置法术覆盖的释放，后者没有释放特效。 | Confirmed |
| U04 | 每根法杖只承载一条循环法术；法术的法杖范围和全局法术顺序在战前设置。 | Confirmed |
| U05 | 同刻先结算的法术不被随后生命伤害追溯打断；生命伤害只打断当时正在冷却的法术。 | Confirmed |
| U06 | 第一阶段不设置敌人或环境对象移动。 | Confirmed / Versioned |
| U07 | 金币由基础收益、时间额外奖励和特殊情况下的法术效果产生；卡牌由法术效果产生。金币与卡牌战后一起整体领取或放弃。 | Confirmed / Partial |
| U08 | 战斗外保留词卡库存，玩家根据库存在战前构筑法术并设置法杖；跨局继承沿用新局资源规则，具体跨局例外不在本轮新增。 | Confirmed / Versioned |
