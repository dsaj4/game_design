## 拟新增内容

以下文本新增至核心“法术类型”之后：

```md
## 修饰词

修饰词直接挂接本句的一张实体名词或动词；同一原词可挂多张，每张都直接修饰原词，不修饰其他修饰词。每张修饰词占用实体副本并贡献词卡时间，遵守普通库存与分配规则，不在每轮循环消耗。

每张修饰词明示可用角色、通用范围、适配及不兼容条件，按“不兼容→适配→通用”判定。不兼容挂接不能形成合法法术；适配时特殊效果替代通用效果，只执行一个版本。所有适配判定均依据原词，不靠前一修饰词改变后一张的适配结果。

数值修饰默认只用于当前法术的效果计算，不永久改写原词基础值或场上对象原值；实际产生的护甲、冰冻等结果仍按各自规则存续。同一数值按现有规则合并修正并统一取整、截断，不自动新增乘区；不同附加效果按句中修饰词从左到右结算。附加状态与附加施加状态的能力分别明示宿主／载体、作用时点、目标、存续与有限响应，并遵守完整法术及存活资格规则。

“获得寒冷的护甲”使用通用效果：增加自己获得的护甲并给自己冰冻；“寒冷的寒冰吞噬护甲”使用寒冰适配的特殊效果，提高其相应数值和冰冻附加能力；“寒冷的”挂到“火焰”不兼容。三例用于说明系统关系，具体数值、冰冻词义、寒冰与冰霜的身份关系及吞噬完整效果仍须另行设计。

修饰词不自动新增法术类型；分类继续读取既定主语与名词特征。修饰词的渠道资格逐卡声明；休整的名词、动词及剩余合格词三选一结构继续适用，第三候选可包含具备资格的修饰词。镶嵌属于法杖配置层，按当前顺序在修饰词之后补足，再开展流派成套物品设计。

规则详见[修饰词素材](idea-materials/M-2026-09-11-modifier-card-system.md)与[G002-CORE-016](draft-changes/D-2026-09-11-modifier-card-system.md)。当前证据Hypothesis，测试继续积累。
```

## 拟替换内容

构句说明原文：

```md
构句使用完整战外词卡库存，遵守名词、动词词性，以及“动词＋名词”和“名词＋动词＋名词”两种外层句式；名词位置可使用复合对象短语，新增词义仍须分配实体词卡。
```

新文：

```md
构句使用完整战外词卡库存，词卡分为名词卡、动词卡与修饰词卡；初版修饰词为修饰名词的形容词卡、修饰动词的副词卡。保留“动词＋名词”和“名词＋动词＋名词”两种外层句式，名词位置可使用复合对象短语，名词与动词均可带明确挂接的修饰词；每个出现位置仍须分配实体词卡。
```

核心边界中的“法杖起始资源与镶嵌细则后置；”改为“镶嵌细则进入当前系统设计顺序，法杖起始资源仍待明确；”。这项修改只调整设计顺序，不预设镶嵌规则与法杖起始数值。

## 采纳理由

用户已经定义第三类词卡，并逐项确定特殊替代通用、多张直接修饰原词、数值仅用于本句、同值合并与附加左右顺序。实体、时间、状态、获取及类型规则能够按这些明确决定同步，无需重复确认。

## 仍需保留的疑问

- 修饰词的精确词效、参数、渠道资格；寒冰与冰霜身份、冰冻含义、吞噬语义。
- 镶嵌的槽位、持有、替换、触发、成本、获取与跨战边界。
- 多修饰的可理解性与是否形成真实取舍，留待合批。
