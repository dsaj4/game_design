# 第一人称两行五格与环境作用拟修改

日期：2026-09-12。状态：Draft Change／待整包审阅。用户明确方向及“树草不传播”已经记录；本轮未修改core-concept.md。

## 修改目标

将核心中的简易长方形场景细化为第一人称2×5格，并有限开放地面对象、生成物占位和火焰邻近施加。其他框架仍适用，不恢复全面自动传播或空间操作。

## 拟新增内容

以下为整包候选被采纳后可加入核心的摘要，不是已生效规则：

```md
场景具有地面与占位体两层：每格固定一份地面及至多一个占位对象。单位、环境物体和法术生成物分别保持独立身份、属性与状态。树草按自身燃烧量及明示阈值进入燃烧／烧焦形态；烧焦不更换身份、不自动释放树的占位、不重置资源次数，也不产生未声明的收益。

火焰在出生后按明示的有限日历进行邻近施加，作用于本格地面及正交相邻格中的合法对象。每次脉冲独立确定名单并逐对象复查，不计为额外完整施法或法术成功。只有火焰产生这类邻近施加，燃烧的树草不继续传播；具体规则及参数引用第一人称格子战场GDD。
```

## 拟替换内容

### 场景与占位

原文：

```md
战斗位于简易长方形场景，敌人和环境对象有实际位置，基础行动预设；位置用于表现与法杖范围判定，不开放移动、连接或支撑操作。环境对象可被点燃、冰冻等明示法术改变状态，没有单位生命值或自主攻击行为。损毁表现须对应明示状态结果，不另建结构加工规则。死亡单位身份失效，内容可明示生成独立遗体或残留物，原攻击、专属引用及附着状态不自动复制到产物。
```

新文：

```md
战斗采用第一人称正面战场，由前后两行、每行五格组成，敌人默认居中。玩家在棋盘近端之外观察，前后排不是阵营分区。敌人、环境占位体、法术生成物和获准召唤单位占据这两行中的实际格子；格子地面与占位体分别具有明示物理属性和可操作状态。环境占位体不因占格而获得单位生命或自主攻击。生成需要合法空位，满位不自动替换、挤出或牺牲既有对象。完整召唤的具体属性与行为继续独立设计。
```

### 空间范围

原文：

```md
位置用于场景展示和法杖范围判定，不作为移动指令的目标。暂不开放位移、连接、支撑、独立空间参照、指定飞行方向或玩家指定新受术端点。抵挡、不指定方向的反弹和无需玩家指定接收者的作用转移可继续设计；接收规则与失败结果由具体词义明确，不能通过运行中点选补齐，也不视为环境材料搬运。
```

新文：

```md
格子用于法杖范围、出生位置与明示邻近关系；法杖范围限制直接作用和出生格，已获准的火焰对象按自身范围执行后续环境作用。生成位置由战前已有词义声明的确定规则求得，不新增战中自由选点或移动。仍暂不开放位移、连接、支撑、指定飞行方向、玩家指定转移端点或通用空间参照词卡；抵挡、非指定反弹与自动转移继续按各自状态设计。
```

### 传播边界

原文：

```md
点燃和冰冻等简单对象状态变化进入当前内容设计；燃料、导电网络、自动传播、结构坍塌等复杂环境机制继续后置。既有护甲等状态数量与明确消耗规则仍可复用，但不再据此赋予对象通用供材能力。基础句式、词卡实体成本、实例/条件绑定、单次名单、共享释放槽、当前冷却改期、四阶段、胜负与整体收益规则继续适用。
```

新文：

```md
点燃、冰冻等简单状态变化继续可设计；本轮有限开放火焰元素对附近单位、地面及环境占位体施加燃烧，以及树草的燃烧／烧焦形态变化。只有火焰元素执行邻近施加，树草不继续传播。燃料网络、导电、多级自动传播和结构坍塌仍后置。数量状态、单次名单、实体成本、共享槽、当前冷却改期、四阶段、完整事件胜负和整体收益规则继续适用。
```

## 采纳理由

让用户指定的2×5和火焰场景具有明确占位、范围、时间、阈值及失败语义；保留现有自动战斗，不用旧“全面后置”阻挡用户本次明确推进，也不因局部开放恢复所有空间和环境能力。

BF-C01–15整包为推荐，阈值／寿命等尚无测试值。需要审阅单格单占位、正交范围、出生优先级、有限脉冲、燃烧B驱动形态与烧焦持久等选择。参数、完整召唤／元素互作和Raw新卡继续独立。
