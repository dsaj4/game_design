### 4.5 成本、限制与取舍

更窄范围换节律／余火；买杖不扩大4杖上限。战前未提交的配置可反复编辑；进入路线、交易、领取和开战后的结果依保存边界保留，不以退出撤销。自动战斗中不能通过查看界面改变计划。

### 4.6 失败、取消与玩法异常

双律与攻守互斥；0合法杖不可开战；合法0输出可战。失败原因须区分配置非法、无匹配、对象失效、材料不足、结果0、被覆盖、被打断与规则禁止。对应阶段允许修复的仅修复该输入；已完成合法结果不回滚，不自动退款或补替代目标。

### WG01 法杖锚点、范围形状与借位（已采纳）

棋盘仍是前排F1–F5、后排B1–B5。每根出战法杖在战前选择一个棋盘格作为范围锚点，可选全部10格；锚点只定位固定形状，不占格，不要求空格，战中固定，不是移动指令。范围包含所列格子的独立地面和占位对象，随后由词义筛选实际目标。越出棋盘的部分裁掉，不平移补足、不环绕、不旋转。

| ID／法杖 | 初始固定镶嵌 | 固定范围 | 特殊效果 | 首版获取方向 |
| --- | --- | --- | --- | --- |
| W01 原木杖 | 木纹芯 | 以锚点为中心，纵横各一格的方形覆盖；在两排棋盘内通常为两排三列，边缘裁切 | 无附加效果 | 起始4根；原木杖不出售 |
| W02 节律杖 | 节律芯 | 锚点及上下左右一格的十字；边缘裁切 | 沿IN-X01：本杖简易法术第2、4、6……次冷却各减1刻；普通冷却最低1刻 | 商店可购 |
| W03 余火杖 | 余火芯 | 锚点所在行的本格及左右一格；边缘裁切 | 沿IN-X02：范围内各来源合法燃烧新增量＋1，同组不重复 | 商店可购 |

这三种固定芯只作为对应法杖身份，不是新增三件可换镶嵌；19件可换镶嵌不增减。固定芯不可拆出、转移或出售；每杖另外2个可换槽沿BR06。

范围例：锚点F3时，W01＝F2/F3/F4/B2/B3/B4；W02＝F2/F3/F4/B3；W03＝F2/F3/F4。W01锚点B1时仅F1/F2/B1/B2，不补到六格。W02锚点B3时为F3/B2/B3/B4。

借位镜只把本次操控法术的目标范围锚点换到已选执行元素所在格，形状与裁边规则不变；原杖的执行者选择仍用原锚点范围。例：原木杖锚点F3选到F2火焰，借位后的目标范围为F1/F2/F3/B1/B2/B3，下一条未借位法术不继承这个临时锚点。元素的固有邻近仍按正交范围，不能把W01斜角格误当自动邻近。

己方玩家及其明示可引用状态、己方已出战法杖的冷却在施法侧选择，不使用棋盘格距离；实际动作仍受词义许可，不能借此获得“任意战场状态不限距离”。这是已采纳的角色范围；BR01的自身收益规则继续适用。


### SG01 同一起点的实际资源（已采纳）

每局从4根W01原木杖、0金币和满生命开始；生命上限为100。4根均带木纹芯，可换槽全部为空，没有初始可换镶嵌。本局最多同时出战4根法杖，买新法杖用于替换，不增加出战上限。不同实体可为同款法杖；原杖退回库存，活动镶嵌卸回库存，再按战前规则配置。

| 词卡 | 起始副本 | 依据／用途 |
| --- | --- | --- |
| 敌人 | 2 | 两条直接攻击或一条玩家攻击＋一条元素操控 |
| 伤害 | 2 | 基础攻击与元素显式执行者复用同一动词 |
| 获得 | 2 | 可编两条护甲，也可在取得回响后作切换 |
| 护甲 | 2 | 基础防御；S2／E3共用同一实体词条 |
| 释放 | 1 | 火／冰生成二选一，共用实体机会成本 |
| 火焰 | 2 | 一张用于释放，一张用于操控引用 |
| 冰霜 | 1 | 可改用冰霜生成；先用简单法术，不预赠拆甲或凝结 |
| 合计 | 12 | 7种词卡，均不超过同名3张 |

首版词卡不另设库存总容量，仍受34种普通词卡每种最多3张的上限；理论普通词卡最多102张，不把未纳入首版的词名计入。构句不另设任意字数或条件数量上限，实际受库存实体分配、合法词义和4条出战法术约束；同一实体不跨句复用。修饰词全都只挂原词，未提供的筛选和关系仍不允许。

法杖库存不另设总容量，同款可多根；每个商店提供的有限货架限制实际购入数。可换镶嵌仍每种每局1件、19种最多19件，本局最多同时安装8件；多余物品可持有但不提供被动。此处采用的是具体容量规则，不把旧IN-C中所有其他内容一并采纳。

## 法杖镶嵌与法术特征

镶嵌作用于法杖，用于强化整体法术，是流派的重要组件。效果可依据法术类型或明确作用特征触发；类型标签本身不产生加成。固定镶嵌属于法杖身份，基础范围和可选特殊效果须逐杖明示，不能再把是否存在初始固定镶嵌列为Unknown。

“简易法术加速”在本杖承载简易法术时，让第2、4、6……次冷却各减少1刻；按周期计数，覆盖和打断也推进，不按成功次数计，不永久累计。普通冷却最低1刻；装配与同组去重按BR06／07及CG-G01。

“燃烧效果强化”为范围被动：范围内合法目标每次被施加燃烧时，本次新增层数＋1，可作用于其他法杖和其他来源。燃烧周期伤害不算再次施加；已有状态量不追溯重算，新增量沿现有状态规则保留。同效叠加和空杖激活按BR06／07；具体燃烧数值、实际范围和宿主资格按PG／WG／HG表执行。

依据[G002-CORE-017](../../../draft-changes/D-2026-09-12-wand-inlay-system.md)，[Inlay v0.1](../../../idea-materials/M-2026-09-12-wand-inlay-system.md)区分用户明确模型与IN-C01–IN-C14补充候选。BR06／07已采纳明确的装配、单件、跨战、激活与同组去重；首版实际19件镶嵌的角色、事件、叠加、参数与渠道已按CORE-032／033完成；未入选扩展继续Parked。新规则NotRun。



## CG-G01：效果组与不可比改写

组名仅供设计追踪，玩家卡面仍使用短规则，不向玩家展示这些登记名。

| 组 | 成员／适用结果 | 合并或冲突规则 |
| --- | --- | --- |
| REPEAT | 回响许可、回响的、复诵晶石、破甲回环 | 同一原完整法术最多一个追加；RC02优先，不叠次数 |
| CHARGE | 蓄势晶石 | 本杖一份计数与待兑现；数值不同取强者一次，首版无升级变体 |
| DIRECT-REPLACE | 双律环、攻守转盘 | 两者同杖互斥；原结果只替换一次 |
| MARK-ON-HIT | 留痕针 | 同目标同原事件一次，按实际命中资格 |
| INTERRUPT-GUARD | 稳息扣 | 取消豁免为布尔资格，同杖重复无额外收益 |
| SKIP-COOLDOWN | 耗印芯 | 一份待用标志；排定下一正常机会时消费 |
| MELT | 融冰针 | 每个合格直接伤害结果一次支付；先结果替换后决定是否付费 |
| AUTO-OFF | 空心的、指令芯的停止自动部分 | 停止资格合并，不把其中一项消失解释为自动恢复；本场创建特性固定 |
| NEIGHBOR | 指令、应激的邻近请求 | 同原事件同元素合并一次；自然环境事件独立；溢流是原分支操作，不变成递归触发 |
| CONTROL-RANGE | 借位镜 | 一次临时换锚点；不叠加多次平移 |
| FALLBACK-REPLACE | 满溢阀 | 只改无同种且无合法出生格分支 |
| SAME-REPLACE | 溢流芯 | 只改已有同种分支；可与满溢共装，两个分支同次不同时发生 |
| SHARE-ARMOR | 同享镜 | 同一他人冰冻增甲事件一次，先有真实增甲 |
| FROST-REPLACE | 逆霜镜 | 仅首次来源确定的冰冻结果替换；与DIRECT-REPLACE不是同一种直接结果 |
| COUNTER-STOP | 止界针 | 异种余量截断；后续生成规则不得重新使用已弃余量 |
| EMBER | 余烬钉 | 一次合格燃烧清空事件一次；自然／战终不触发 |
| CORROSION | 蚀甲炉 | 本次燃烧实际敌甲损耗对应一次补层；不得找替代源火焰 |
| ARMOR-RETURN | 返甲镜 | 本次元素主动直接敌甲损耗一次增甲 |
| BYPASS / MARK-FILTER / STUBBORN | 裸露的／专注的／顽固的，各自独立组 | 同一次同对象布尔性质去重，不互相替代 |
| THORN / DEATH-BLAST | 反刺的／爆裂的，各自独立组 | 同原事件同目标一次；重复挂接不生成重复特性 |
| ALLY-FILTER / ENEMY-FILTER | 护生的／避亲的 | 依各自生成名词适配，不能把两种不兼容挂接强行合成 |
| DECAY-MODE | 自噬的 | 自然衰减替换为邻近支付；没有两份并行衰减／支付 |
| PERIODIC-CD | 节律杖固定芯（WG01已采纳，CG分组已定） | 按周期序号一次修正；与跳冷却先后在时间表明确 |
| BURN-ADD | 余火杖固定芯（WG01已采纳）及同机制范围被动；CG分组已定 | 同受益事件最强一次，等强沿BR07固定顺序 |

同一件物品可涉及两个不同规则组，不能只按卡名分一个总组。不同组并不表示无限相乘；同参数按GR01合并，支付、替换、生成、触发仍按表中不同阶段。表内未出现的新变体不能自动借组名取得已采纳资格。



### BR06 可换镶嵌装配与激活

每根法杖保留自身固定镶嵌，另设2个可换镶嵌槽，固定镶嵌不占可换槽。可换镶嵌在战前免费装卸，一件实体同时只装一根法杖；同种可换镶嵌按同一物品ID每局最多持有1件，已装与库存合计。可换镶嵌采用商店获取，货架名额和价格按G002-CORE-033。只有已出战且绑定合法完整法术的法杖激活镶嵌；空杖不提供被动，固定镶嵌定义的基础范围仍是法杖身份。被动是否响应按自身事件与适配条件判断，不统一要求本次法术成功。物品在本局跨战保留，每战相关计数重置；战中配置保持固定。双律环与攻守转盘继续互斥，触发顺序和有限响应按RC执行。


### BR07 同效果组去重

同一效果组对同一受益事件只生效最强的一次，适用于不同法杖以及固定和可换镶嵌的同组重叠。等强时按战前法杖公开顺序，再按固定镶嵌、可换槽1、可换槽2取先者；这不改变共享槽的后置优先。效果组按机制和受益参数登记，不能靠更换卡名规避。不可比较强弱的规则改写须逐项声明互斥或执行顺序；RC已经定义的复诵合并、邻近合并及双律／攻守互斥优先适用。去重只针对同一事件，不把两个不同事件合并，也不改写既定首次来源。

## 基础合同与完整闭环

以下按既有核心闭环分配到本系统，细则以本页具名规则及明确例外展开；不另设第二套执行顺序。

每条循环法术绑定一根法杖，每根法杖承载一条法术。设置法杖时确定前后顺序及镶嵌配置。每根法杖自带一个初始固定镶嵌，代表法杖身份，规定基础施法范围及可选特殊效果；特殊效果多数与法术类型相关，但不要求每杖均有特殊效果。镶嵌强化完整法术或明示的范围内作用，与修饰词直接修饰原词分工。每杖另有2个可换槽，可换镶嵌战前免费装卸、一件一杖、同种每局最多1件，通过商店获取；空杖不激活被动，每战计数重置。实际法杖、范围、起始库存及容量按本页WG01／SG01；货架、价格与参数按G002-CORE-033／035的RC1基准。已采用装配边界见BR06／07和[镶嵌素材](../../../idea-materials/M-2026-09-12-wand-inlay-system.md)。

完成法杖配置后，玩家在第0–10刻内安排所有循环法术第一次冷却的开始时刻。每个词条声明参数归属、单位及适用角色，操作声明整句效果与释放时长的计算方法；词卡时间贡献按实际分配相加，合计用于法术冷却，周期为冷却与释放时长之和。非负普通数量在完整修正后向下取整并截断至0；自然衰减保留不足整层的进度，累计足整层再扣除（G002-CORE-018）；首版释放时长L为正整数；冷却等其余时间参数的整数域与零值许可逐项声明，不以整句名称、词数或类型标签暗设加成。第0刻开始、冷却4刻、释放1刻的示例在第4刻首次释放，之后每5刻循环尝试；示例不规定默认参数。战斗自动推进，本场词卡分配、绑定条件和法杖顺序固定；按基础参数及明示周期修正规则运行，运行时间可被已配置法术或镶嵌依规则改变并公开原因。
