## 1. 产品与体验合同

### 1.1 一句话概念

玩家面对一个可读的两排战场，战前编排法术，使生成物与环境按明确规则逐步变化，用空间占用、作用节拍和地面差异换取可预测的战斗收益。

### 1.2 目标玩家与情境

沿用读牌、构筑和自动战斗规划的单人玩家。第一人称是观察方式，不新增自由行走或镜头瞄准施法。发行平台、输入设备与单局时长Unknown，本轮不从参考画面推断。

### 1.3 体验承诺

玩家能解释“火焰为什么生在这里、哪些对象会受影响、何时变成燃烧或烧焦、火焰消失后留下什么”。

### 1.4 设计支柱

| 支柱 | 可观察表现 | 对应规则 | 反面信号 |
| --- | --- | --- | --- |
| 世界变化可读 | 地面、树、火焰和敌人各有明确状态 | BF-C01／07／15 | 一团火光看不清作用对象 |
| 空间产生取舍 | 火焰需要真实空位，其邻近对象决定价值 | BF-C02–05 | 不论位置都命中全场 |
| 单次输入有持续结果 | 一次生成带来有限多次邻近作用 | BF-C06／10 | 每次脉冲被算成免费完整施法 |
| 有限、可推导 | 不二次传播，烧焦不刷奖励，不自动复位 | BF-C07／11–14 | 无穷连锁或状态变化反复产卡 |

### 1.5 反支柱

本阶段不追求物理模拟、可移动战棋、材料加工或树草无限蔓延；不因第一人称参考引入手牌回合、能量或“结束回合”操作。

### 1.6 核心假设

公开占位、属性和阶段变化能使玩家通过战前法术配置预测持续世界反应。Hypothesis；本轮只有设计推理，无体验证据。

### 1.7 下一验证问题

优先验证玩家能否从格子图预测火焰出生与首个作用范围，以及能否区分地面、占位体和元素。最小方法是固定场景的预测任务；成功为按规则指出落点／对象／阶段，失败为以为树能继续传火或同格对象共用一份状态。测试暂缓。

## 2. 核心循环与玩家旅程

### 2.1 核心循环

读取敌人和格子属性 → 战前构句与法杖配置 → 预览出生及作用范围 → 自动战斗和环境变化 → 终局停止 → 整体收益与下一场。

### 2.2 多时间尺度

| 尺度 | 行为与结果 | 边界 |
| --- | --- | --- |
| 单次释放 | 生成火焰或直接作用 | 仍参与共享释放槽 |
| 火焰存续 | 按自己的有限作用日历影响附近 | 不新增玩家操作 |
| 单场 | 空位被占用／释放，树草变形 | 本场形态保留；胜负沿核心 |
| 跨战 | 重新载入下一遭遇的地面与占位 | 不继承上一战火焰、燃烧或烧焦地图 |

### 2.3 玩家旅程

| 阶段 | 可见信息 | 动作与取舍 | 反馈／失败 |
| --- | --- | --- | --- |
| 战前 | 两排格子、物性、空位、敌人和法杖范围 | 按已有词义配置，不免费移动敌人或树 | 显示预计落点、相邻格和无空位原因 |
| 战中生成 | 生成事件与占位变化 | 观察 | 有真实火焰身份；失败无替换／挤出 |
| 战中发展 | 下一次作用、燃烧量、阈值和寿命 | 观察计划是否兑现 | 后续法术可按许可影响真实火焰 |
| 战后 | 终局、损耗与明确收益 | 整体领取或放弃 | 环境变形本身不额外产卡／金币 |

### 2.4 胜负与退出

全部敌人被击败且玩家存活则胜利；玩家死亡则失败，同检查点失败优先。树、草地和玩家火焰不计作必须击败的敌人。无生成空位只是该效果失败，不自动结束战斗。疲劳、认输和整体收益沿现有规则；不引入新的撤退或存档制度。

## 3. 规则总览

### 3.1 术语

| 术语 | 定义 | 不等同于 |
| --- | --- | --- |
| 前排F／后排B | 从玩家视角近／远两排；各列从左到右1–5 | 敌我阵营两排 |
| 格子地面 | 永久存在的格子及其地表属性，可有独立状态 | 空位中的“无对象” |
| 占位对象 | 敌人、环境占位体、法术生成物或获准召唤单位 | 该格地面 |
| 环境占位体 | 树、石块等可被影响但无单位生命／攻击的对象 | 有自主行动的战斗单位 |
| 燃烧层数B | 宿主自身的数量状态，本方案用其驱动热变化 | 第二份“点燃状态”或单位生命 |
| 燃烧形态／烧焦形态 | 对象由明示阈值决定的当前物理／视觉状态 | 新对象身份或自动奖励事件 |
| 火焰邻近脉冲 | 火焰在环境阶段的一个完整有限作用事件 | 完整法术再次释放 |

### 3.2 不变量

| ID | 规则 |
| --- | --- |
| BF-I01 | 总是2×5个地面格；地面不会因无占位而消失 |
| BF-I02 | BF-C01下每格最多一个占位对象；地面与占位体可各有燃烧 |
| BF-I03 | 只有火焰进行邻近施加，树草不成为下一代传播源 |
| BF-I04 | 原法术名单与后续火焰脉冲名单分别固定；各自事件中不补位、不扩表 |
| BF-I05 | 地面与树的形态变化不换身份、不重置已消耗产出额度 |
| BF-I06 | 完整事件后检查终局；终局成立不再处理后续脉冲／状态／收集 |

### 3.3 时间

沿用离散刻与“法术→敌攻→环境→状态”四阶段。火焰首次作用与每次间隔为明确正整数，生成刻不立即脉冲。普通状态首次周期和到期继续按原状态规则。

### 3.4 系统依赖

本系统输入是场景布局、地面／占位体属性、合法生成法术与源方参数；输出是占位、燃烧和形态。上游依赖法杖范围、语法、名单与费用；下游供状态、后续引用、表现及终局读取。完整召唤、其他元素、Raw卡池不作为本系统首版的统一前置条件。

## 4. SYS-BF：战场与环境系统规格

### 4.1 目的与承诺

让玩家看得见并能预测空间和物性如何改变法术结果；每次失败能指明空位、范围、物性或事件阶段原因。

### 4.2 MDA推理

| 规则 | 可能行为 | 目标体验 | 风险 |
| --- | --- | --- | --- |
| 真实占位＋局部影响 | 比较火焰与直接伤害、不同作用起点 | 编排有环境意义 | 满场后大量空转 |
| 独立地面与树 | 看懂同格两个不同宿主的变化 | 世界有结构而非贴图 | 状态信息过密 |
| 燃烧／烧焦阈值 | 规划持续量与时间 | 逐步改造可观察 | 只有演出没有决策价值 |

### 4.3 输入、状态与输出

| 项目 | 内容 |
| --- | --- |
| 触发 | 合法法术生成；到期的火焰脉冲；合法状态施加／清除 |
| 玩家输入 | 已确认的战前配置；战中只观察与查看信息 |
| 场景输入 | 10格地面、已占位对象、能力白名单与公开顺序 |
| 状态 | 格子占用、对象身份／阵营、火焰量与寿命、宿主燃烧量／时长、环境形态 |
| 输出 | 合法占位、逐宿主燃烧、阈值变形、明确失败 |
| 存续 | 原身份保持；火焰和状态按自身期限结束；本场烧焦保持 |
| 派生 | 环境脉冲只施加状态并完成对应有限阈值子步骤；树草不派生传播 |

### 4.4 核心规则：推荐候选

| ID | 候选规则 | 结果与反馈 |
| --- | --- | --- |
| BF-C01 两层占位 | 每格固定一份地面＋至多一个占位对象；敌人、树、火焰、合法召唤物都占后者。首版不做跨多格单位 | 同格可有草地和树，两者属性与状态分开；空格也有地面 |
| BF-C02 邻近 | 火焰作用于本格地面，以及上／下／左／右一格中的地面和占位对象；不含斜角、不环绕 | 火焰自身不接受自己的燃烧；最多受影响的具体对象由实际布局决定 |
| BF-C03 居中与布场 | 主敌默认F3；多敌按F3、F2、F4、B3、B2、B4、F1、F5、B1、B5取合法空位。关卡可明示固定布局，环境与敌人不得重叠 | 该布场次序不改变既有对象处理顺序；战前展示实际布局 |
| BF-C04 火焰出生 | 在释放开始，以“范围内公开对象顺序首个存活敌人”为词义自带锚点；在其正交相邻、法杖允许且可生成的空格中，按F1至F5再B1至B5选首格，并固定本次落点 | 不出现临时玩家选点；无锚点或无格则无生成，不能跨场补位。处理时落点失效则失败 |
| BF-C05 范围分工 | 法杖格子范围限定直接目标及出生格；合法火焰之后按自己的BF-C02范围作用，可越过原法杖格子边界。自行作用权限只属于这份已明示火焰 | 这是本轮待采纳的局部扩展，不是所有法术自动越界；原有自身效果不把玩家强放入格子 |
| BF-C06 火焰存续 | 每次基础释放在初始P＞0时生成一个独立火焰，占一格；P≤0无生成资格，不计生成成功或由此产生的法术成功；持续时间D，脉冲间隔Δ，均为正整数且D＞Δ；生成刻g，脉冲为g＋kΔ，k≥1且时点＜g＋D；到g＋D先消散；P归0也立即消散 | 首次至少下一刻；结束刻不再脉冲；到期刻起即无操作资格，环境阶段清理才释放占位，法术阶段不能预支稍后腾出的格子；不是旧“一次使用”或固定6刻方案 |
| BF-C07 环境阶段 | 可燃地面／环境占位体各自声明0＜点燃阈值I＜烧焦阈值C，使用自身燃烧层数B判断：0＜B＜I为受火积累，I≤B＜C为燃烧，B≥C变烧焦 | 阈值不同体现不同物性；变焦后清除燃烧并失去本轮可燃资格，原身份／占位保持 |
| BF-C08 单位燃烧 | 敌人及获准召唤单位若支持燃烧，沿同一B状态；不套树草形态阈值。候选每隔δ刻以当前B×每层周期伤害d按GR01形成周期伤害，伤害走护甲／生命规则 | 施加时不额外造成一次伤害；首周期至少δ刻后，重施保持原周期。δ、d及持续时间T尚未赋值 |
| BF-C09 物性资格 | 首批建议草地／树可燃，石地／石块不可燃；敌人和召唤物逐内容声明；脉冲不默认排除友方或中立，玩家本人在棋盘外，不在此邻域内。只有获准承受燃烧的对象进入施加结算 | 火焰不因站在石地就失去存在资格；石地不燃不等于阻挡火焰邻近作用 |
| BF-C10 脉冲与层数 | 每次环境阶段脉冲开始固定一次邻近名单，先按公开格子顺序，本格地面在占位体之前；逐个复查存续和资格。火焰当前强度P作为本次基础施加层数，合并当次适用量修正后取整截断 | 原施法源修正只在生成P时计入，不在脉冲重复；范围燃烧＋1按当次目标与资格判断。脉冲不是第二次法术成功 |
| BF-C11 重施／清除 | 正层数施加按现有状态规则增加数量及有限时长T，保留原周期；最终新增量为0则不新建状态、不增加时长。主动清除使未烧焦对象回到未燃烧形态，可保留无规则效果的火痕 | 烧焦是本场持久形态，清状态不会还原成可燃树草；没有隐含修复卡 |
| BF-C12 多源与有限性 | 火焰按确定生成顺序分别脉冲，合法层数可合并；每份火焰有有限寿命，十格占位有限；树草不自主加层或产生新火焰 | 若较早火焰令树烧焦，较晚火焰复查时跳过它；烧焦过程不循环重入 |
| BF-C13 离场与失败 | 火焰正常消散释放占位；烧焦树保留占位。单位死亡沿既有清理点离场；不自动生成遗体占位，若未来内容明确遗体再登记 | 生成失败不挤走旧对象、不退实体配置或时间；本轮基础生成例不另收生命／状态费用；其他效果若明示额外费，按GR05仅在可实际生成时支付 |
| BF-C14 场景与资源 | 初版遭遇需预留至少一个与主要敌人正交相邻、允许火焰生成的空格；树草燃烧／烧焦不掉卡、不产金、不提供材料；换战重载场景 | 避免示教时天生无法生成；后续拥塞是实际代价，不提供临时隐藏空位 |
| BF-C15 呈现与行列 | 玩家位于棋盘外的近端，不占十格；前后排不等于阵营、前排不默认挡后排、树不默认遮断施法；需要这种规则时另行设计 | 前后排仅通过占位、邻近与明示法杖范围产生效果；后排轮廓和格子信息始终可读 |

上述C规则形成一个具体可审阅版本。特殊大体积单位、任意物性组合、跨格移动、按风向传播均不从本表推导开放。

### 4.5 成本与取舍

| 选择 | 收益 | 成本／风险 | 边界 |
| --- | --- | --- | --- |
| 释放火焰 | 有限多次局部燃烧 | 实体词卡、冷却／释放、法杖和一个场地占位；可能来不及兑现 | 不给默认伤害倍率 |
| 对象直接点燃 | 可直接选合法宿主 | 实际词卡与范围；不能免费生成火焰 | 具体施加词参数按自身设计 |
| 反复生成 | 增加不同来源或覆盖位置 | 可能堵住后续出生格，同刻普通法术仍会覆盖 | 不自动合并或刷新旧火焰 |
| 引用或强化火焰 | 有机会改变后续脉冲量 | 多次编排、词卡和法杖；火焰可能先结束 | 当前强度P的具体修改需FX-013等另行闭合 |

这里没有给环境变形新增奖励。若未来希望烧焦增加策略收益，需明确单独能力并登记，不能把演出当数值收益。

### 4.6 失败与异常

无合法敌人锚点、范围内没有邻近空格、格子已被占、生成资格禁止分别反馈。名单锁定后失效不重新寻找；取消的法术不生成。火焰生成后，来源法术未来被打断不撤销该火焰。空间满不跳过时间成本，后续周期仍可再次尝试。直接名单与脉冲名单各自完整事件后查终局，不逐对象判胜。

### 4.7 信息与反馈

战前描边十格、标F／B与列号，可查看地面和占位体的两份说明；悬停／选中只查看信息。显示生成候选和最终落点、脉冲邻域、可燃资格及满位原因。战中显示火焰剩余时长／下一脉冲，宿主燃烧量／阈值阶段；同格地面以边缘纹理、占位体以轮廓和图标区别。后排被前排图像遮挡时仍显示可读轮廓与说明入口，不用自由移动镜头解决规则歧义。

### 4.8 正例与反例

布局示例只说明空间，不提供生命、伤害或阈值数值：

| 远／后排 | B1 石地·空 | B2 草地·树 | B3 草地·空 | B4 石地·空 | B5 石地·空 |
| --- | --- | --- | --- | --- | --- |
| 近／前排 | F1 石地·空 | F2 草地·空 | F3 石地·敌人 | F4 草地·空 | F5 石地·空 |

玩家在前排外。法杖允许示例全部格子，敌人为唯一锚点。

- 释放火焰时，候选邻近空格为F2、F4、B3，按BF-C04选F2。
- 首脉冲在生成后的Δ刻。作用F2地面、F1地面、F3地面／敌人、B2地面／树；石地因不可燃跳过，火焰自身不施加。
- B2草地和B2树独立增加B，各自跨I后燃烧、跨C后烧焦；因阈值不同，可以一方先烧焦。敌人只用单位燃烧规则。
- B3不是F2的正交邻格，不被这份火焰作用；B2树燃烧也不向B3传播。
- 若F2已经被占，下一次新的释放在开始时可选F4；若本次已锁F2后才失效，则本次失败，不补F4。
- 若环境B从I以下一次跃过C，直接得到烧焦结果，不停留一个额外燃烧回合或补发中间伤害。

### 4.9 验收

规则验收：唯一出生、占位不重叠、两份宿主状态分开、无斜角／二次传播、脉冲有限且不计施法成功、阈值变化不重建身份／奖励、终局停止。体验验收：玩家能据图预测范围与失效，并分清石地、草地、树和真实火焰。具体样本与量值后续在交接冻结，本轮NotRun。

### 4.10 未知与依赖

BF-C01–15整包仍待审阅；火焰P／D／Δ、状态T／δ／d与不同对象I／C及词卡时间未赋值。范围镶嵌激活与叠加沿IN-C候选，实际测试前必须指定选用版本。完整召唤属性与行动不在本首版；测试可使用明确标为装置的占位单位，不把装置当成可用卡。

## 5. 状态与事件时序

### 5.1 环境形态

未燃烧（B＝0） → 受火积累（0＜B＜I） → 燃烧（I≤B＜C） → 烧焦（曾达到C，B清除，本场不可再次燃烧）。

阈值变化是一次合法施加后的有限子步骤；允许直接越级。状态被清除／到期，未烧焦者回到未燃烧；烧焦形态不受该回退。树草不会仅因“燃烧形态”而自动增加B；继续达到C需要明确的后续施加。

### 5.2 同刻顺序

| 顺序 | 阶段 | 本系统处理 |
| --- | --- | --- |
| 1 | 法术 | 共享槽仲裁；存活的生成尝试锁锚点／落点、支付、生成；本刻不发首脉冲。直接点燃及其阈值子步骤按完整法术处理 |
| 2 | 敌攻 | 沿既定攻击安排；格子前后不自动挡伤害 |
| 3 | 环境 | 火焰先检查自身结束与资格，到期则离场；未到期且日历命中才发脉冲，逐宿主施加及形态变化，完成该脉冲后查终局 |
| 4 | 状态 | 单位燃烧到期周期等按既有顺序；新施加未满δ不提前跳伤；环境状态到期按BF-C11处理 |

若纳入FAT-C05，环境阶段疲劳事件按该候选在其他环境事件前；不得把火焰插到疲劳前绕过死亡。GR07-C01仍是待测候选；本方案没有同阶段递归生成新火焰，阈值变化为当前事件有限子步骤。

### 5.3 冲突

多火焰使用确定生成顺序，逐次复查；同一个脉冲内地面／占位体是不同身份，各处理一次。生成法术的两个同刻普通释放先经过共享槽，不能在环境层偷偷让被覆盖者也生成。状态B达到C后清除，不补发已取消周期；已发生伤害不回滚。

每条生成物有独立身份；火焰多次生成不合并、刷新或治疗已有火焰。后续若选择双生，另行声明多对象生成的空位与部分成功，不在此预设它能挤占同格。法术类型不因为树草被燃烧而增添状态类型；镶嵌范围被动本身也不是一条法术。

## 8. 资源与成长

空间是本场机会成本，不是新增可收集材料。烧焦不给金币或卡；收集仍须独立词效、资格与额度。生成物不因是玩家创建就取得可收集资格。环境收益在四层框架中按实际生命／护甲结果和终局统计，不能把火焰面板、单位燃烧伤害和同一实际扣血重复相加。纯环境变形若没有额外玩法收益则如实标为表现结果。

## 9. 遭遇与地图

本系统只定义一场战斗，不改变分叉路线。初版教学布局使用一个居中敌人、一棵邻近树和草／石两类地面，保证首条基础生成句有合法空位。后续场景可改变地面和环境分布，但须展示布局，避免仅以遮挡制造规则信息缺失。多敌、满位、邻近空位被占等留作边界场景；无空位不被解释成法术语法非法。

## 10. 引导

本轮GDD-1只要求依次教会“格子和占位体分开→火焰需要空位→正交邻近→受火与烧焦阈值→无二次传播”。不制定分钟数或额外教程系统。

## 11. UI与可读性

第一人称固定正面构图，十格通过地面边界、近远关系与列号可辨；后排和地面信息可查看。燃烧与烧焦同时使用形态、文字／图标和颜色，不能只靠红／黑颜色区分。时间预览、玩家生命和法杖信息沿项目已有要求，不照搬截图中的回合按钮或手牌流程。

## 12. 音画与参考

[用户附件](../../docs/reference-images/2026-09-12-first-person-battlefield-reference.jpg)仅参考正面敌人、近景地面和远景背景。两排格子、地面状态及UI自行按本方案组织；不从附件推断其游戏规则。资产首版需区分树／草地的未燃烧、受火、燃烧、烧焦，以及真实火焰出现／存续／结束；表现不得继续承载已结束对象的交互资格。

## 13. 设计边界与制作依赖

不设技术方案。需要保证十格、两个可查看层、后排可读与阶段反馈；若后续表现无法清楚区分，先调整展示而非暗改邻近规则。完整召唤行动、生命范围、雷电／冰霜互作及大单位为后续独立内容。

## 14. 原型与测试计划

先做图示预测，再在用户明确启动后验证固定参数场景。本轮不执行。最小问题是出生／范围／形态结果是否唯一且可理解；只需单敌、树、两类地面和一条生成句，其他组件不作为前提。正常／边界场景见BF-T01–12并进入[测试交接](../../docs/test-handoff.md)。
