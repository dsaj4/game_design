## 一条可解释的求值顺序

战前检查实际词卡与词义兼容 → 到释放时参加共享槽仲裁 → 获得释放机会后确定一次直接名单 → 逐对象检查当前能力/状态/窗口及成本 → 发生明示变化或合格掉卡 → 完整法术后检查胜负 → 未结束才继续其余既定阶段和后续循环。

空名单/对象失效不计成功；实际无效释放有反馈；被覆盖或生命伤害打断的尝试无正常释放特效。成功事件以完整法术计一次。新生生成物只在后续释放匹配，不能通过继续追加本次名单制造连锁。

## 生成物窗口的最小纸面走查

法术甲在时点a生成真实火焰f，法术乙在较晚时点b尝试削弱火焰，f实际结束时点为e。这里a/b/e描述事件先后；具体窗口候选已Parked，见上方保留记录；当前不使用其数字作为默认值。

| 条件 | 乙在b的结果 |
| --- | --- |
| a<b<e，乙获释放槽，f仍合法 | 条件绑定可以匹配f，按词义改变其当前量 |
| b在f已完成/结束之后 | 跳过；即使火光仍显示也没有可回滚作用 |
| a生成f时甲本次直接名单已确定 | f不追加给甲本次处理 |
| f结束后生成同名g | f的实例引用不指向g；后续条件引用可匹配g |
| b之前已胜利或败北终止 | 不再执行乙，不因生成物存在而延长战斗 |
| b乙被覆盖或受到适用打断 | 按既有时序处理，无本次改变；后续计划保持 |

能列出f的名字仍不足以通过：必须为至少一种实际生成词条设计出可介入的真实窗口。瞬时效果可以保留，但不能冒充本例验证的可操作生成物。
