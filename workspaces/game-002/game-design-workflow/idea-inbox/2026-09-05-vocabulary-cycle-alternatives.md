## 评议前提

- 词卡是句子的组成部分，完整法术由组合产生；采用抽牌与弃牌并不意味着每张词卡都必须有独立法术效果。
- 已确认的暂停构句、施法耗时、攻击命中打断、完成后整句结算等规则作为两条路线的相同约束。
- 比较的是可用词如何流转和被选择；不比较具体牌面强度，不规定牌数、手牌数、抽取数量、成本数值或制作周期。
- 以下“A 候选”“B 候选”和共同建议均待用户确认。保留失败路径与备选，不自动混合两条路线。

## A：抽牌与弃牌循环

### 机制完善草案

建议把玩家的局内词典理解为拥有的词卡集合，进入战斗的卡组决定本场可用词及出现分布。战斗中的主要位置为抽牌堆、手牌、本次施法占用区、弃牌堆。

候选循环：卡组形成抽牌堆，抽出的词进入手牌；玩家从手牌构句并确认施法，参与的词暂时被占用；本次施法结束后投入词进入弃牌堆，手牌获得补充；抽牌堆耗尽后，弃牌堆重新洗入抽牌堆。

| 机制环节 | 候选规则 | 设计用途 |
| --- | --- | --- |
| 构句时 | 手牌构句，确认前可改选；未投入的词可保留 | 允许为后续组合保留稀缺成分 |
| 使用后 | 投入词在施法结束后弃置；被打断也弃置是待评议建议 | 让词语持续轮换，防止默认无限调用固定套组 |
| 补牌 | 建议先以一次施法结束作为常规补充节点；不引入隐含的传统整回合弃手牌 | 适应现有时间轴，减少重复创建一套回合流程 |
| 主动换词 | 玩家可付出可见的行动机会成本换掉不合适的词；该成本占用时间，具体规则待确认 | 避免暂停构句期间免费无限筛牌 |
| 牌库耗尽 | 弃牌堆洗回；其他仍在手牌或施法中的词不随之复制 | 保持有限牌库的循环与可追踪性 |
| 卡组成长 | 新增、移除或调整词卡改变某类句子出现的机会与循环效率 | 将局间选牌直接连接到局内可用表达 |

补牌节点及打断后弃牌尚未采纳，也没有从既存时间素材中自动推出。若评议发现打断同时失去时间与关键词过重，可以另选返还词卡的候选处理，但本轮不替用户作此决定。

### 最大机制风险：有牌却无法造句

主谓宾需要协作出现；传统卡组中一张牌常能独立行动，本作可能整手都无法形成合法句子。仅保证主谓宾各出现一个，也不保证语义类型兼容。不能假设成熟的抽牌结构会自动解决这个问题。

完善建议：保留统一牌库作为默认比较版本，先提供带代价的换词路径，并在后续设计中评议“按缺失语法类别纠正补充”的保障。需要同时检查类别与语义兼容。保障应处理完全无法表达的问题，不应直接把最优组合送给玩家；具体采用哪种保障仍待确认。

### 收益与代价

- 规则较容易解释；牌库组成、删牌、留牌和过牌都有直接可感知的构筑价值。
- 组合施法和世界状态再利用仍然可以保留，抽弃只是决定何时拿到组件。
- 语言表达受抽取结果限制，可能经常知道理想解法却没有必要词语。
- 卡组比例可能受主谓宾刚需约束，形成构筑税；大量保障又可能使构筑比例失去意义。
- 反复无合法句、打断后关键词离手以及抽牌随机性可能叠加，需要作为整体惩罚检查。

### 初步判断

推荐作为优先审查的基准候选，原因是它更直接体现用户强调的卡组构筑定位，且能较清楚地定位“抽弃循环”和“组合语义”各自带来的问题。此判断不证明它更好玩，也不代表已选择 A 或可开始实现。

## B：回忆、联想与语义继承

### 核心完善方向

建议保留“玩家拥有有限词卡、词卡会在可用与已用位置间流转”的构筑基础，把创新集中在如何找到下一批词。这样可以具体检验语义调度的价值，而不用同时重做所有词义与语法规则。

此处是 B 的一个明确候选版本，不是对用户“回忆、联想、语义继承”含义的擅自确认，也不表示最终必须沿用 A 的所有结构。

| 机制 | 本草案建议的职责 | 玩家可见的决定 |
| --- | --- | --- |
| 联想 | 从玩家自己的未用词池中，依据明确的语义标签形成有限候选，玩家选择补入可用区的词 | 沿当前主题继续，或选择能转向另一主题的词 |
| 回忆 | 付出时间机会成本，将已用区中选定的词移回可用区 | 为熟悉的关键组件花时间，还是接受当前词继续施法 |
| 语义继承 | 上一句成功完成的法术留下一个清楚可见的主题线索，影响下一次联想的候选范围 | 为下一批词规划上一句，而不只看眼前效果 |

这里的“语义继承”只指调度线索，不自动提供免费词卡、不复制上一句效果、不省略主谓宾。用户若期望继承目标或语法成分，那是另一种语境机制，需要单独评议；原稿 P2 连句设想不会在这里自动晋级。

### 候选循环

战斗开始时尚无上一句线索，先从本场词库获得基础可用词。玩家构句并施法，投入词在本次施法结束后进入已用区；成功完成的法术更新公开的语义线索，下一次补充由该线索组织候选，玩家选择词语。需要刚用过的特定词时，可另用有时间成本的回忆调回。

被打断不生成成功法术的继承线索；投入词是否同样进入已用区，在比较版本中建议与 A 保持相同处理，避免同时改变太多变量。这个去向仍待用户确认。

### 为可理解性补上的边界建议

- 联想标签应由词语规则明确给出，玩家可以提前理解；不要仅凭模糊的“意思相近”临时决定候选。
- 联想只从已拥有且可被抽取的词中挑选，不凭空产生新词，否则卡组选择的意义会变弱。
- 回忆把一张现有词卡移回，不生成副本；它必须付出会影响施法安排的机会成本。
- 基础候选只保留上一句的一个语义线索，不无限叠加历史；线索的选择规则仍待定义。
- 无匹配词时需有公开的普通补充途径；不能把用户锁在没有后续词的主题里。
- 候选主题要允许转向。若某一条线索总导向同一套牌，即使每步可以选择，也可能退化为固定检索连招。
- “语义继承”增强的是后续词的选择倾向，不能保证每次都拿到最强组件。

以上均为完善建议。具体匹配规则、回忆时机、普通补充的方式，以及可否主动放弃继承线索仍为 Unknown。

### 收益与代价

- 当前语言行为会改变未来的可用语言，主题与操作能更紧密地结合。
- 卡组构筑可能从比例与重复，进一步发展为选择语义标签之间的连接和转向能力。
- 玩家需要同时理解本句效果、词语兼容、时间窗和下一批候选；新增调度负担可能盖过施法本身。
- 过强的定向检索会降低抽取的不确定性，让少数关键词反复出现，削弱新增词的价值。
- 联想标签会成为另一套重要规则，解释、校对与内容设计负担明显增加；暂无具体工期估算。
- 若回忆只是弃牌堆检索，联想只是抽牌换名，玩家可能承担新术语成本却没有获得新决策。

### 初步判断

值得保留为独立探索候选，但必须证明“上一句改变下一批选择”带来玩家能察觉的决策收益。建议未来先单独审查联想调度，再检验回忆和继承是否各自有必要；这属于验证顺序建议，不是当前启动测试或实现的授权。

## 横向比较

| 维度 | A 抽牌与弃牌 | B 语义调度 |
| --- | --- | --- |
| 玩家核心问题 | 当前手牌如何组成有效句子，哪些词值得保留 | 当前怎么说，会让之后更容易想到什么 |
| 构筑价值 | 配比、重复、保留、删牌与过牌效率 | 词义连接、主题转向与关键词可访问性，同时仍需有限词库 |
| 随机来源 | 牌库顺序与抽取 | 语义约束下的候选抽取和选择；不必全部确定 |
| 无合法句风险 | 类别和类型搭配不足 | 缺少兼容组件，另加无匹配主题的风险 |
| 固定最优策略风险 | 小牌库快速循环 | 定向联想或回忆锁住关键套组 |
| 与时间轴的关系 | 过牌或换词是否值得占用时间 | 联想与回忆的准备收益是否值得占用时间 |
| 学习负担 | 主要新增负担来自组合语言 | 组合语言之外，还需理解候选来源与继承线索 |
| 主要证据缺口 | 在不频繁卡手的情况下，抽弃能否支撑表达与构筑 | 语义调度是否提供额外决策，而非仅增加操作步骤 |

两者都可能服务卡组构筑，差别不在于有没有卡组，而在于卡组成员如何变成当前可用的词。也不能由名称“保守/创新”推断前者缺乏特色或后者必然更有趣。

## 整体验证建议

本轮仅拟定比较方法，未运行试玩或原型，不提供虚构的测试结论。

1. 用户已审阅比较并选择 A 优先深化；这一步不等于批准实现。
2. 完成各自仍缺的基础流转规则确认，再决定是否晋级为独立合格素材。
3. 如后续获准比较，使用相同词库、相同语法、相同敌方意图和已确认时间规则，只改变词汇调度；“打断后牌去哪”等共用变量保持相同。
4. 记录无法造句的次数与原因、检索或换词的选择、构句与管理词库各占多少精力、连续使用同一套组的倾向，以及玩家能否解释下一批词为什么出现。
5. 使用多个不同词库组合和抽取序列，区分偶然好手牌与稳定体验；调整顺序，避免第二种方案只是因为玩家已经学会词义而占优。
6. 具体牌数、耗时、胜率目标与样本数量另定。理解失败和规则理解后仍乏味分开记录。

| 路线 | 推进信号 | 修改或停止信号 |
| --- | --- | --- |
| A | 玩家通过卡组与留牌改善表达能力，卡手可通过有代价的决定恢复；施法选择会随战况变化 | 大量操作只是在等待合法句；所有卡组都被迫使用相同语法比例，或保护规则抹平了构筑差异 |
| B | 玩家能主动解释并利用语义线索改变未来选择，新增操作确实改变计划，仍会重视词库构成 | 玩家看不懂候选来源；管理词库压过施法；稳定找回固定套组；与普通抽牌相比只有换名或多点击 |
