## “所见即可操作”的可检查含义（推荐候选）

推荐将战场上被表现为独立事物、可辨认部件或实际作用的内容，都对应到可检查的语义对象；玩家可以看到它是什么、属于谁、具有哪些性质、支持哪些变化。句子能否作用于它，再由词义、引用、能力和当前条件共同决定。检查信息本身不推进时间，也不改变战前配置和战中观察的玩家职责；具体交互方式待定。

| 判断 | 玩家需要得到的答案 | 与下一层的区别 |
| --- | --- | --- |
| 看见或获知 | 这段画面、状态图标或时间轴标记表示什么？ | 画面可以表示同一个对象的多个侧面；标记本身不产生额外物质 |
| 识别 | 这是哪一个对象、部件、状态或过程？ | 名称相同不意味着身份相同 |
| 读懂结构 | 它由什么组成、附着于谁、正在做什么？ | 展示属性不自动赋予直接修改任何数值的能力 |
| 拥有表达手段 | 当前库存中的哪些词义能描述或操作它？ | 所见扩大可理解的世界，不免费增加实体词卡或施法权限 |
| 能够引用 | 此句通过何种明确关系指向它，是否在授权范围内？ | 支持某种动词的对象也可能不在这条法术的对象范围中 |
| 当前能执行 | 能力、状态、时机与所需材料是否满足？ | 合法句子允许有本轮无效结果，并应说明具体原因 |
| 结果可追踪 | 哪些对象、属性或关系改变，后续留下什么？ | 演出规模不额外决定伤害、传播或对象数量 |

对纳入可操作范围的对象，只有“可查看”仍未完成设计：必须至少有一种通过合法句子改变它或让它参与作用的途径，并明确所需能力与词义。反之，“所见即可操作”不要求每个对象接受每一个动词。

画面承诺建议采用以下判据：可辨认的树枝可以指回它所属的树及其结构；残留焦痕若只有历史表现，就明确显示当前没有可消耗的燃烧；飞行火球若只是已经结算法术的演出，就不能同时承诺可以拦截。若设计要允许拦截，火球必须先具有真实、尚未完成的作用过程及可介入时段。纯装饰应有清楚的归属或装饰标识，不能用一批未定义装饰掩盖本应可交互的战场内容。

## 对象—能力—操作—结果矩阵（agent候选）

以下是能力类别，尚不是正式动词卡目录。“可复用”仅表示已有规则支持其中明确部分，其余操作均待确认。能力与材料、状态之间的推导也需要明文规则，例如“木制”是否获得“可燃”，不能交由现实常识临时判定。

| 对象类别 | 需要显式声明的能力或条件 | 候选操作与可见结果 | 当前依据 / 必须补齐 |
| --- | --- | --- | --- |
| 玩家与敌方单位 | 生命、防护、可附着状态及身份 | 承受伤害、恢复、获得或失去状态，显示对应变化 | 生命、防护、状态可复用；移动、部位受损和支配权限未定义 |
| 召唤单位 | 独立身份、生命、在场资格、可执行行为 | 入场、承受作用、执行已许可指令、离场 | 单位模型可复用；完整指挥、占位和容量仍后置 |
| 植被与自然实体 | 材料、组成、可变化形态 | 点燃、浸湿、切分、改变覆盖形态 | 对象与表现方向已有；燃料、湿润、切分均为新增机制 |
| 建筑与器物 | 部件、连接、支撑及可开闭关系 | 开闭、连接、拆分、改变支撑，显示结构变化 | 环境无生命和攻击行为；不能用未说明的生命条代替结构规则 |
| 身体、装备或建筑的部件 | 所属整体、共享材料、独立受术资格 | 作用于局部、分离或修复，影响明确的整体能力 | 不自动建立部位伤害或装备耐久；局部与整体的数值关系待定 |
| 物质、液体、气体与残留物 | 明确来源、存在位置、可用数量、形态 | 生成、提取、消耗、转移、转化，显示来源减少和产物形成 | 逐对象材料检查可复用；水源是否有限、气体如何分区等未定 |
| 可读取属性 | 所属对象、量的含义、允许的变化方式 | 读取或按特定作用增减某种量，显示变化原因 | 生命等已有；温度、重量、导电等候选属性不能默认为全世界通用 |
| 附着状态 | 宿主、数量、周期、剩余时长、消耗方式 | 赋予、叠加、移除、消耗、转换 | 现有状态规则可复用；转移状态还须定义源与目的宿主及重施关系 |
| 表面、地块与空位置 | 可指向范围、承载物、占用关系 | 在合法位置生成内容、改变表面或占用 | 有位置场景可复用；空位置作为目标及位置变化触及固定目标边界 |
| 区域与持续作用场 | 边界、作用条件、存续和影响对象规则 | 创建、扩缩、消除覆盖，显示边缘与持续效果 | 区域与法杖范围分别定义；区域覆盖不得成为未声明的范围扩张 |
| 连接、附着、包含与支撑关系 | 两端身份、方向、允许建立/解除的条件 | 建立、解除、转移关系，显示关系前后变化 | 每个端点都必须能明确表达；单个名词不能默默补出第二目标 |
| 物理接触与传递关系 | 来源、接收方、媒介、传播条件 | 传热、传导或蔓延，引起接收方的已定义变化 | 全部为候选；距离、屏障、友伤和收束规则须随实际机制说明 |
| 飞行物与进行中的作用 | 来源、载荷、当前位置或阶段、完成条件 | 偏转、拦截、消散，改变尚未完成的作用 | 真实过程与演出要区分；已结算作用不因后续演出被操作而回滚 |
| 一次敌方攻击或释放尝试 | 发起者、目标、计划时刻、当前阶段 | 取消、延迟或改变尚未完成的本次作用 | SW01范围已确认；具体修改权限与公开预览须由SW05设计 |
| 持续法术及其冷却过程 | 法术归属、本轮进度、后续周期、可改字段 | 加速、延缓、强化或抑制，显示受影响的释放机会 | 强度修正已有；冷却修改和循环改写是不同权限，均未开放 |
| 法杖、词卡配置与战斗资源 | 物体身份、配置身份、持有者、使用资格 | 按明示效果产生资源；如需操作法杖实体，先说明影响哪些功能 | 产出与强度规则可复用；看见法杖不自动许可战中重新分配词卡或换序 |
| 基础规则及显示内容 | 对应世界信息与固定约束 | 基础规则保持固定；显示内容的检查方式仍为候选 | SW01已确认范围上限；这类只读内容不计入已完成的可操作对象数量 |

高度自定义的主要来源建议为：用同一个动词处理不同但能力相容的对象，用一个对象的不同结构、状态或关系作为操作内容，以及把一次变化留下的结果交给后续法术继续利用。是否兼容由共同词义解释；不能为每条完整句子另藏一套互不相通的结果表。

### 同一种“火”的语义区分示例

| 玩家看到的内容 | 对应候选含义 | 必须区分的结果 |
| --- | --- | --- |
| 树上正在燃烧 | 树是实体，燃烧是附着于树的作用 | 操作燃烧不自动删除树，也不自动把树当成燃料消耗 |
| 正在飞行的火球 | 尚未完成的一次投射作用 | 已纳入过程对象范围；拦截等具体操作及生效时机仍待设计 |
| 已经烧黑的树皮 | 树当前形态或已发生变化的痕迹 | 没有现存燃烧时不能继续消耗燃烧状态 |
| 法术释放时出现的火光 | 对一次释放的表现 | 除非有明确对应对象，否则不额外生成可提取火焰 |

该示例用于排除同名内容的身份歧义，不确认具体火系卡牌或物理反应。

## 每个对象都要回答的设计问题（候选填写框架）

| 要素 | 需要明确的内容 | 为什么影响玩家 |
| --- | --- | --- |
| 身份与粒度 | 是一棵树、一片树林、树枝，还是树上的某份燃烧状态？ | 决定句子究竟指向什么，变化后还算不算同一对象 |
| 结构与关系 | 包含哪些部件、由什么组成、连接或附着于谁？ | 使拆除、转移与连锁有可解释的条件 |
| 属性与状态 | 哪些值可观察、读取、修改；怎样显示？ | 避免把看见的数值误认为任意修改权限 |
| 交互能力 | 能接收何种操作，能主动执行什么，何时禁止？ | 同一动词跨对象使用有共同依据；不要求每个对象支持所有动词 |
| 输入与代价 | 读取什么、消耗谁的何种材料、成本不足怎样处理？ | 复用逐对象检查，避免材料被重复使用或无来源生成 |
| 作用结果 | 改变属性、转移关系、产生对象、使对象失效中的哪些？ | 玩家能分清“发生了什么”和单纯视觉变化 |
| 时间与持续 | 何时生效、持续多久、周期如何运行、何时结束？ | 与共享释放槽、攻击、环境和状态阶段建立统一结果 |
| 引用生命周期 | 生成、分离、转化、合并、销毁后引用如何处理？ | 自动循环不会暗中换目标或引用不存在的对象 |
| 可解释反馈 | 成功、跳过、能力不符、材料不足时显示什么原因？ | 让玩家用失败结果改进下一次表达 |

“可燃”“可承重”“可导通”等只是能力例子；是否采用、是否可被修改均需决定。外观相似不能代替对象实际声明的能力，材料名称也不自动授权现实中所有反应。

## 句子在世界上自动求值的讨论框架

1. **构句时读出含义**：确认执行者、动词操作、操作内容、结果承受者；沿用一组合一完整法术和实体卡分配规则。对象图谱不会自动增加词性或自由语序。
2. **明确引用**：说明该词表示种类、具体实例、属性、某份状态还是关系；按SW02区分实例与条件绑定。实例保持身份，条件每次匹配当前对象；SW02-A已确定单次直接名单，条件表达与过程窗口待设计。
3. **到点尝试释放**：沿用冷却、共享释放槽、覆盖和打断规则；句义合法不代表每轮必然有效。
4. **轮到对象时检查能力和材料**：已确认的逐对象检查可以复用。新增能力检查的结果与失败反馈仍为候选。
5. **执行明确变化**：按词义产生属性、状态或其他已定义结果；若是生成/分离/转化对象，先有身份与引用规则，不能临时决定。
6. **处理后续作用并检查结果**：完整法术后检查胜负。新增过程或环境连锁须明确属于同次法术还是未来事件、进入哪个阶段，以及如何终止，不能只因画面连续就自行延长结算。
7. **让玩家读懂因果**：候选反馈为“句子—对象—满足条件—付出材料—发生变化—留下结果”；重用同一词义时结果仍可解释。

上述步骤混合了明确标注的现行规则与待定扩展，只作为资格讨论框架，不是已采纳的执行规范。

### 一个对象被改变后，需要继续追踪什么

推荐为每类变化补齐以下结果，避免第一道法术成功后，第二道法术因身份不明而无法求值。

| 变化 | 必须留下的说明 | 可复用边界 |
| --- | --- | --- |
| 修改属性或附着状态 | 仍是谁、当前量是什么、下一次释放读取什么 | 固定身份不冻结状态；引用本身不自动消耗材料 |
| 生成 | 由谁产生、出现在哪里、何时可参与作用、如何被合法引用 | 新生对象可符合条件绑定，但不继承其他实例的引用；本次新生对象不追加进本次直接名单；召唤占位尚待设计 |
| 分离 | 整体失去哪些部分，分离物获得什么身份，资源与状态分别归谁 | 材料不能同时完整保留在整体与分离物；具体继承待设计 |
| 合并 | 哪些身份结束、保留或产生，材料如何合计，原引用如何处理 | 不能把附着状态的同种合并规则无条件套给实体 |
| 转化 | 保留对象身份还是产生新对象，输入和产出如何对应 | 固定消耗与按实际量转换必须事先声明；材料不足按当前规则处理 |
| 消失或销毁 | 哪些能力和引用失效，有无独立残留物，尚未完成的作用如何结束 | 失效只跳过对应对象；不能凭画面残留保留已经失效的材料 |

过程操作还需要有真实介入机会：如果敌人攻击在本刻攻击阶段直接完成，放在其后的视觉演出无法供本刻法术阶段再次拦截。若要操作攻击，必须明确玩家法术在攻击完成前能引用的是未来攻击、准备过程还是已存在投射物，并说明它如何进入四阶段与胜负检查。自动求值的可操作范围必须在时间上也成立。

连锁的推荐约束是：每条传播或触发规则说明原因、作用对象、所属结算阶段，以及本次或后续事件的终止条件；不能出现同刻两个过程相互触发而永不结束。不能为收束循环临时改变基础结算顺序，也不能把循环上限的示例值写成默认参数。

## SW02引用方案（模型已采纳，细则仍为候选）

设计问题：战前尚未存在的飞行物、分离部件或召唤单位，需要事先可表达、战中自动执行的引用方式。SW02已确认实例与条件绑定并存，以下将模型与尚未确认的细则分开说明。

### 已确认：实例绑定与条件绑定并存

| 引用意图 | 战前固定什么 | 本次释放指向谁 | 身份变化后 |
| --- | --- | --- | --- |
| 具体实例绑定 | 一个已明确的对象身份 | 始终尝试这个对象 | 原对象失效则跳过，不按同名转向另一个 |
| 条件绑定 | 战前明确的选择条件，遵守词义与法杖允许范围 | 每次完整法术开始处理时匹配当前对象并确定本次直接名单 | 新生对象可以参与；它仍是新身份，不继承原实例的专属指向 |

例如，战前表达“这棵树”与“范围内符合条件的树”是不同引用意图；表达“指定来源产生的、当前可操作的飞行物”则可以覆盖战中才出现的过程。这里描述的是绑定意图，不是新增词卡名、句式或已具备的配置界面。

以下为配套细则讨论：第1、2、6项对应模型及既有约束，第3、4项名单与排序尚未确认，第5项材料处理沿用C02而不确认重选时点。

1. 选择条件在战前完成并整场保持固定；战中由规则自动匹配，玩家仍观察已配置的方案。
2. 条件只能使用已定义词义、可表达关系与法杖允许范围，不凭空补充词卡、能力或来源权限。条件如何在两种基础句式与配置中表达，交由SW04明确。
3. 本次处理名单在完整法术开始处理时确定；本次法术新生成的对象不追加进本次名单，后续释放可以重新匹配。这样可以逐条读出一次法术处理哪些对象。
4. 名单顺序由战前公开的固定排序规则决定，而非玩家在战中换序。具体排序建议沿用初始对象公开顺序，新生对象使用可解释的来源与生成顺序；并发与同源并存细则待设计。
5. 按名单逐对象检查当前合法性与材料，沿用失效跳过、不部分扣除固定消耗和已合法结果不回滚。重新匹配不冻结状态数值，也不预留材料。
6. 特定实例的引用失效不触发条件搜索。新对象可以因满足另一个条件绑定而成为目标，但不能冒充已经消失的实例。

选择条件与法杖范围不是同一权限：满足词义也要满足相应范围判定。移动后的范围判定、关系端点和过程可介入时段分别依赖SW03–SW05；这些条件不明确时，对应代表句仍不能被标记为完整可执行。

### 两种方案的取舍

| 方案 | 优点 | 代价 | 建议 |
| --- | --- | --- | --- |
| 实例绑定＋条件绑定 | 保留精确指向，同时能表达后续出现的一类对象 | 本次名单会随世界变化，预览需解释变化原因 | SW02模型已采纳，具体细则另议 |
| 实例绑定＋逐个战前占位 | 目标身份和未来位置容易逐个展示 | 每个未来对象都需先有占位；连续产生的飞行物、碎片等容易受未设计占位规模限制 | 保留为特定单位身份的局部方案，不推荐承担全部对象引用 |

C03、C04的单位占位方向可以继续解决“某个未来单位是谁”，但不自动承担“当前符合某条件的全部单位”这一不同意图。SW02模型确认不等于完整召唤流程已经完成。

### 推荐方案的纸面边界推演

以下为候选规则的逻辑推演，不是玩家测试、正式效果规则或实现验证。

| 情境 | 按推荐候选会怎样 | 仍需补齐什么 |
| --- | --- | --- |
| 战前没有火球，某次释放前出现了符合声明来源与范围的真实火球 | 条件绑定可以找到它，具体实例绑定不会凭空改指向 | 火球何时成为可引用对象，以及拦截类操作的能力与时机 |
| 点名的树被毁，同时出现另一棵同名树 | 原实例引用失效；新的树只有通过符合条件的另一绑定才可参与 | 销毁与生成的具体身份规则 |
| 本次处理中的一个对象产生了新飞行物 | 新对象不加入本次名单；到后续释放再匹配 | 即时连锁与未来事件的边界，见SW05、SW06 |
| 名单中的后一个对象在轮到它前已失效或材料不足 | 按当前逐对象规则跳过，前面合法结果保持 | 操作本身的明确材料声明 |
| 两个新对象同时符合条件 | 按事先公开的排序规则处理 | 同源并发的具体顺序及可读反馈 |
| 画面还在播放火光，但对应作用已完成且没有真实在场过程 | 没有合法的过程对象可以匹配，不能拦截已完成的作用 | 表现到真实对象的对应方式 |

## SW02-A单次名单方案（Promoted / Accepted）

已确认在完整法术开始处理时，按当前世界确定一次直接处理名单。此后不在本次处理中重新选取或追加对象；轮到每个对象时仍检查它的当前合法性和材料。名单固定只固定本次处理对象，不冻结对象状态，也不保留已失效对象的操作资格。

| 情境 | 名单规则对应结果 | 尚未包含的其他决定 |
| --- | --- | --- |
| 释放开始前已有符合条件的火球 | 可以进入本次名单 | 火球是否有可用能力与介入时段仍须定义 |
| 本次法术处理某对象时产生了新火球 | 不追加到本次直接名单，后续释放再匹配 | 新火球本身何时生效及间接连锁另行设计 |
| 名单后面的对象在轮到它前失效或材料不足 | 按C02跳过，其他合法结果保留 | 不以名单成员身份保留生命、能力或材料 |
| 另一个对象在本次过程中才满足条件 | 不在本次重新选入，后续释放匹配 | 条件表达和状态改变的具体操作待定 |
| 本次某对象失效，另一个同名对象出现 | 不补位，也不让新身份继承实例引用 | 对象转化、合并与分离的身份规则仍待设计 |

取舍：一次确定名单更容易说明单次法术的处理边界，也避免本次生成对象被反复追加；持续重选则允许更即时的反应，但必须额外解决何时停止、补位和重复处理。用户已确认前者。

本题只决定直接对象名单时点及不追加/重选；不决定名单排序、跨引用去重、空名单反馈、间接传播、范围变化或多刻释放的各效果时点。这些作为下一层问题分别保留。

验收分开检查文档覆盖和玩家体验；完成本文不等于任何一项已经通过。

- **覆盖完整**：选取的验证场景中，每个可辨认的战斗对象、部件、状态和真实作用过程都能归类；显示层能指回对应对象或明确说明是表现。新增内容也按同一检查方式登记。
- **可以表达**：纳入操作范围的每类对象至少有一条具备合法词义、引用和执行时机的代表句；尚未设计的词卡与绑定须列为缺口，不能记为通过。
- **能力一致**：同一动词在同能力、同条件对象上遵循相同操作规则；对象差异由明确条件解释。每类至少检查适用与不适用情形。
- **结果闭合**：属性、材料、身份、关系及过程变化后，后续法术能读取唯一可解释的结果；每份材料去向清楚，引用不会无提示换人。
- **时间成立**：每种过程操作都有尚未完成且能被合法法术介入的时段；结算可结束，胜利后不继续处理，已完成效果不回滚。
- **玩家读得懂**：对照同场景的成功、能力不符、无引用、材料不足和对象失效结果，让玩家说明句子为什么如此结算；具体测试方案与通过阈值待定。

仅纳入对象图谱但没有可表达操作的类别，标记为“已盘点 / 未完成交互设计”；不能用分类覆盖冒充“所见即可操作”已经实现。全部数值重新设计，本文的语义例子不提供默认生命、伤害、时间或成本。

## 具体场景走查（尚未执行）

| 场景 | 用来检验的设计问题 | 期望的成功信号 | 失败信号 |
| --- | --- | --- | --- |
| 树和石块位于同一法杖范围 | 同一操作按对象能力区分结果，例：“点燃 树木”只作语义示例，非确认词卡 | 能从显式条件解释适用与不适用 | 为每条整句暗写独立例外，或只因看起来像树就假设可燃 |
| 一棵树的枝干被分离 | 整体与部件是否独立对象、资源是否重复、引用是否延续 | 分离前后对象和材料去向清楚 | 同一材料同时算在树和落枝上，循环法术暗中换目标 |
| 明火消失，只剩焦黑地表 | 可操作燃烧、残留物和表现痕迹是否区别 | 当前有何可读取或消耗的东西可以辨认 | 只因画面有焦痕便继续提取不存在的燃烧 |
| 水被转移或转化 | 是否有限来源，来源和去向如何同时表达 | 来源消耗、结果数量和引用身份明确 | 同一份材料无限复制，或一句话缺少目的对象仍凭空选取 |
| 战斗中出现新的火球或单位 | 未在战前存在的对象怎样进入自动求值 | 绑定规则事先可读，与直接对象范围一致 | 执行时任意改目标，或承诺可操作却永远无法引用 |
| 一道法术改变另一道法术的冷却 | 可操作过程是否包括运行节奏，何时读取新值 | 后续时间唯一可推导，能解释对敌方公开安排的影响 | 同刻相互修改形成无终点循环，或预览与实际安排含义不一致 |

这些场景用于暴露必须回答的问题，不自动确认点燃、分离、转移、冷却修改等具体动词或机制。
