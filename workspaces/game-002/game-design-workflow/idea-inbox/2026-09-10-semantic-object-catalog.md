## 当前条目

对象保留身份、类别、来源等识别信息；“用数值衡量”约束的是作用方式，不意味着把所有事物改成只有一个生命值。每项具体操作尽量对应一个明确的变化量或状态，不展开几何和材料流程。

## 法术生成物与状态的区别

| 画面或词语 | 规则中是什么 | 可继续操作的前提 |
| --- | --- | --- |
| 一份仍真实存在的火焰 | F01，独立生成对象 | 有当前身份、许可能力和未结束窗口 |
| 树木正在燃烧 | E01宿主上的S03状态 | 状态仍生效，词义允许作用 |
| 一道仍未交付作用的雷电 | F02，也可呈现P01过程视图 | 是同一个真实作用，不因显示两个视图结算两次 |
| 命中后留在画面上的电光 | 对应已经发生事件的演出 | 不提供回滚或新材料 |
| 一份真实冰霜与敌人冰冻 | F03生成物与U02上的S04状态 | 两者身份分开；具体施加关系须词义明示 |
| 环境上的焦痕、霜纹 | 当前状态或历史表现，必须说明 | 不能仅凭图像认定还有生效状态 |

生成名词在“释放 火焰”中可指产出类型，在“削弱 火焰”中可指当前真实火焰对象；词义须逐角色声明。它不能同时免费表示伤害、燃烧状态、燃料和三份独立资源。

## 通用生命周期

1. 生成效果合法结算时登记新身份、来源及词义所声明的数量/状态与窗口；具体生成条目未填完前只作为范围。
2. 条件绑定在后续释放时可匹配符合条件的生成物；本次生成不追加本次直接名单。
3. 数量或状态变化保持对象身份；是否归零消失、自然到期或作用完成结束，逐条声明。
4. 结束后的实例引用失效；同名新对象不能冒充它。特效延长不延长真实窗口。
5. 状态附着在其宿主，来源与宿主分别记录；与生成物相连的解释不自动复制数量或作用。
6. 本场结束清理对应场景对象；合格掉卡进入已有整体收益，不能把生成物直接带入库存。

## 当前不制作的条目

位置/空间参照、结构连接、支撑、材料份额、容器收材、配方和物体复制均暂缓。场景里仍可出现树枝、建筑或器物，但不要求拆成可操作连接和材料账户。法杖范围、图标和资源记录是必要判定/显示信息，不借此增加移动或加工操作。
