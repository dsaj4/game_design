## 1. 共同求值约定（候选）

每条本批作用词默认选择一个合法对象；载体句选择一个载体和一个受术对象。按名词含义、战前绑定、词义能力和法杖范围筛选，再按公开顺序选首个；状态名词若无宿主限定，也只取首个匹配状态，不默认全体。实例绑定失败时不搜索替代者。条件绑定的名单在完整法术开始时一次确定，轮到时复查，不追加、不补位。

“释放 火焰/雷电/冰霜”中的名词是一个产出类型。该类型是直接生成内容，本次新生对象是结果；生成成功不要求场上已经有同名对象，也不会再对新生对象执行第二次操作。其余引用元素的表达指当前仍存在的真实对象。元素名词不隐含敌方筛选、额外伤害或免费状态。

本批词条没有额外生命、金币、护甲或环境材料支付；费用来自真实词卡、法杖与时间。收集另受对象掉卡次数限制，元素载体合法完成作用后结束。无效尝试仍按基础循环占用本次释放机会；不能把“未扣数量成本”理解为没有时间代价。

对象面板显示身份、来源、强度或状态层数、消散/到期时点；使用前显示本次载体与受术者，结果显示前后值及失败原因。仅确定的时点写为确定事件，未来条件未定时显示条件，不能预报必定命中。

本批支持玩家省略主语的两词句，以及下表明示的三个载体句。载体是执行者，不是材料份额或收集资源；强度不按份额拆分、搬运、供给。载体完成一次合法作用后结束自身身份。

| 完整句子 | 含义 | 实体卡数 |
| --- | --- | --- |
| 点燃 敌人 / 点燃 树木 | 玩家直接施加燃烧 | 2 |
| 冰冻 敌人 / 冰冻 石块 | 玩家直接施加冰冻 | 2 |
| 伤害 敌人 | 玩家造成一次直接伤害 | 2 |
| 释放 火焰 / 雷电 / 冰霜 | 生成一种元素的一份真实对象 | 每句2 |
| 火焰 点燃 敌人（也可用树木名词） | 现存火焰作为载体，对一个合法宿主施加燃烧 | 3 |
| 雷电 伤害 敌人 | 现存雷电作为载体，造成一次直接伤害 | 3 |
| 冰霜 冰冻 敌人（也可用树木/石块名词） | 现存冰霜作为载体，对一个合法宿主施加冰冻 | 3 |

“火焰 冰冻 敌人”等未许可搭配为语义不兼容，不临时改名词意义。战斗中新生成的元素用战前固定的条件引用获得；没有战前真实实例时不能预绑虚构身份。生成法术与使用法术中的同名元素各占一张实体卡。

## 2. 三种生成物的完整词义（候选）

| 对象 | 生成强度 | 唯一载体作用 | 作用中的基础量 | 可直接受到的操作 |
| --- | --- | --- | --- | --- |
| F01 火焰 | 4 | 点燃合法宿主 | 施加燃烧层数＝作用时当前火焰强度 | 强化、削弱、抵挡 |
| F02 雷电 | 7 | 伤害合法单位 | 本次直接伤害基础量＝作用时当前雷电强度 | 强化、削弱、抵挡 |
| F03 冰霜 | 3 | 冰冻合法宿主 | 施加冰冻层数＝作用时当前冰霜强度 | 强化、削弱、抵挡 |

三者均采用以下明确规则：

1. 在生成法术释放开始时出现，登记新身份、来源、强度与消散时点；出生位置固定为本次执行玩家的当前位置。位置仅供展示与范围检查，没有选点或移动操作。
2. 自生成刻起存续6刻，到“生成刻＋6”的环境阶段自然消散。消散刻的法术阶段仍可合法使用；环境阶段结束后只可能留下演出。生成当次不追加名单，后续释放可引用。
3. 未被后续载体句使用时，不自动寻敌、造成伤害、附加状态、传播或掉卡。画面明确显示“待作用”，说明需要对应句子。用户能直接用点燃/冰冻短句，不必每次先生成元素。
4. 载体句在释放开始检查载体与受术者均有效、能力匹配且均在本次法杖允许范围，合法时完成一次作用，然后载体结束。它不另建飞行轨迹或在动画末尾再命中一次。
5. 没有合法受术者、载体已结束、条件或范围失效时，本次没有作用，尚有效的载体保留到原消散时点。合法零伤害仍算一次合法作用，载体照常结束。
6. 强化/削弱只改强度，不改身份、不续时；强度减至0立即消散。多个同名生成物分别存在、不自动合并；默认取公开顺序最早的合法对象。不存在“新生对象接替已经绑定的旧身份”。
7. 已被消散或使用的生成物不再有待交付作用，不能通过电光/火光重新引用。来源法术后续被覆盖或打断，不撤销已经生成的对象；战斗结束立即清理，不继续作用。
8. 本批只让单位和指定环境物体接受燃烧/冰冻；元素之间没有自动相克、互相合成或导电，三者可用数量操作改变。

生成时的强度是对象自身参数，生成操作不应用直接伤害或状态施加量加成。载体执行时，先以其当前强度为基础，按本次法术开始读取的玩家适用修正计算伤害或新增层数；非单位载体没有自己的单位属性。源方后来的变化不重算已经施加的状态，周期不重复强化。强度操作自身也只接受明确适用于“生成物强度变化量”的修正，不能把伤害加成自动套上。

## 3. 点燃与冰冻（候选）

| 项目 | S03 燃烧 | S04 冰冻 |
| --- | --- | --- |
| 合法宿主 | 本批普通单位和树木；石块不支持 | 本批普通单位、树木和石块 |
| 直接短句的新增量 | 2层 | 2层 |
| 元素载体句的新增量 | 按火焰当前强度计算 | 按冰霜当前强度计算 |
| 本次新增持续时间 | 3刻 | 3刻 |
| 主要效果 | 单位每1刻受到当前层数等量的燃烧伤害；环境显示状态并可被后续合法引用 | 有效期间，宿主作为源方的直接伤害固定减少当前层数，最终伤害最低0 |
| 第一次效果 | 满1刻后的状态阶段；施加当刻不立即周期伤害 | 施加完成后影响尚未计算的直接伤害；无自动周期 |
| 对环境的意义 | 可见层数、持续时间和燃烧条件；没有单位生命扣除 | 可见层数、持续时间和冰冻条件；没有单位攻击可削减 |
| 自然结束 | 末次周期先结算，再到期清除 | 到期刻状态阶段清除，因此同刻之前的攻击仍受影响 |
| 完全解除 | 熄灭对应燃烧状态 | 解除对应冰冻状态 |

两种状态允许层数相加，有限剩余时间相加。重施保留原周期及排序；部分层数变化保留时间；完全清除后重建重新计时。遵守[状态计时](../idea-materials/M-2026-09-06-status-timing-and-expiration.md)、[重施](../idea-materials/M-2026-09-06-status-reapplication-and-stacking.md)和[状态读值](../idea-materials/M-2026-09-06-status-values-and-resolution-order.md)。本批不添加数量或时长上限；能否长期压制需验证，不以没有上限暗示平衡已成立。

燃烧伤害先抵当前护甲，再扣生命；实际生命伤害按现行规则打断玩家当时正在冷却的普通法术。环境燃烧没有伤害周期事件，只保留数量、到期与可引用状态，不烧掉物体、不产出材料。

冰冻作为直接伤害的固定负修正，与其他适用固定项合计，再按[源方修正顺序](../idea-materials/M-2026-09-06-spell-effect-sources-and-modifiers.md)处理百分比与取整。玩家法术在本次释放开始读取；本批敌方普通攻击在攻击开始结算时读取。非单位载体按玩家的适用修正计算，因此玩家冰冻可削减雷电载体的直接伤害。

冰冻不改攻击时点、不取消攻击、不改变冷却，不降低燃烧周期伤害、燃烧/冰冻新增层数或护甲生成量；已经结算的结果不追溯改变。冻结后的单位仍可被点燃，两状态并存；施加一方不会自动清除另一方。

仅在合法效果明确产生0时才应用“合法零值”规则：例如雷电伤害被修正为0或被护甲全吸收，仍合法完成一次；新增状态层数为0且宿主原本无该状态时不新建空状态。若该状态已经存在，合法的0新增量仍按该施加词条增加3刻时长。对象不支持该状态属于非法目标，不是合法零值。

## 4. 数量操作与解除（候选）

| 词条 | 作用对象 | 改变 | 时点与结束 | 成本 | 失败与显示 |
| --- | --- | --- | --- | --- | --- |
| 强化 | 一份真实火焰/雷电/冰霜 | 强度＋2 | 释放开始一次生效；原消散时点保持 | 实体词卡与时间；无额外数量支付 | 无合法生成物则无效果；显示强度前后值 |
| 削弱 | 同上 | 强度－2，最低0 | 归零立即结束生成物 | 同上 | 已结束对象不处理；显示“削弱至消散” |
| 抵挡 | 同上，仍未作用 | 强度－3，最低0 | 减少未来载体作用量；归零结束 | 同上；词卡时间高于削弱 | 不回滚既成伤害；显示剩余强度与窗口 |
| 熄灭 | 一份仍有效燃烧状态 | 完全清除 | 取消未来周期和到期 | 同上 | 无状态则无效果；显示解除，不退款 |
| 解除 | 一份仍有效冰冻状态 | 完全清除 | 后续伤害计算不再受该状态影响 | 同上 | 无状态则无效果；已结算伤害保持 |

本批抵挡只完成三种生成物的数量处理；普通攻击过程的抵挡、反弹与自动转移尚未形成完整词义，不借本表自动开放。强化与削弱在本批只完成生成物用法；许可属性、护甲等其他词义另按对应素材设计。

“熄灭 燃烧”“解除 冰冻状态”各用2张卡；“熄灭 敌人的燃烧”用熄灭、敌人、燃烧3张卡，“的”仅连接已有词义，不新增效果或实体卡。宾语宿主限定也受本次法杖范围检查。

## 5. 对象直接掉卡（候选）

推荐采用确定掉落：场景开始时公开标记有掉卡资格的初始环境对象，各自本场最多成功掉1张预先公开的普通词卡，概率100%。卡名来自本批词表中的内容配置；不是所有树木、石块或每个场景都必须有掉卡资格。

“收集 树木/石块”在本次开始筛选该类具有资格、剩余次数大于0、预告卡仍有同名额度的对象，按公开顺序选一个。实例绑定始终只检查原实例；不合格则无结果。轮到该对象时再次检查资格、次数及“已持有＋待领取”小于3。

| 项目 | 明确规则 |
| --- | --- |
| 作用 | 合法时对象直接掉1张预告卡，立即记入本场待领取 |
| 对象变化 | 同一身份保留；剩余掉卡次数1→0；原有燃烧/冰冻及其时间保持 |
| 卡的来源 | 遭遇预设的对象掉卡许可；不提取、加工、收材或按配方转换物体 |
| 额外成本 | 不支付生命、金币或护甲；占用实体卡、法杖、词卡时间和实际释放槽；对象额度是有限产出限制 |
| 不合格范围 | 本批单位、法术生成物、状态、过程、场景装饰及未标记物件不掉卡 |
| 额度不足 | 不生成、不替换卡、不换成金币，不消耗对象剩余次数；无合法结果 |
| 重复作用 | 已耗尽对象不再次掉卡；点燃、冰冻、解除或强化不刷新次数 |
| 场景更新 | 同场对象不能靠改名、状态重建或新生身份继承掉卡资格；下一场仅由新遭遇的初始配置授予 |
| 战后 | 有效胜利后与金币整体领取或放弃；放弃不退次数、不重新进入这场收集；失败不发放本场收益 |

“收集”不会删除对象、清除状态、改变攻击安排或附送金币。正常点燃、冰冻、元素作用仍不产卡。战中掉卡动画直接对应待领取记录，不是另一份可拾取物品；已掉的卡不参与本场编排。若战斗在某次收集前已结束，该次不再执行。

具体测试对象可公开“树木A：掉点燃1张”“石块B：掉冰冻1张”；这是[纸面场景](2026-09-10-element-state-drop-paper-checks.md)的配置，不是物种永久绑定。
