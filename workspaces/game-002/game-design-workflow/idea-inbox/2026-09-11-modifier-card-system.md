# 修饰词系统与镶嵌设计顺序

状态：Promoted（本轮已明确的修饰词模型）；细项候选与镶嵌未定义内容不随来源晋级。日期：2026-09-11。Project ID：game-002。

## 原始想法

> 先不进入卡牌流派设计，而是补足剩下的两个修饰词系统和镶嵌系统，这样后续设计时可以一次性设计对应流派的全部有关物品
> 先说明修饰词系统：
> 除了名词卡和动词卡以外的第三种卡，用途是作为成分修饰对应法术语句，初版设计修饰名词的形容词卡和修饰动词的副词卡
> 其效果是按既定规则修改它修饰的卡，例如：”寒冷的“修饰卡，如果在简易法术“获得护甲”中加入修饰词卡形成”获得寒冷的护甲“后，则增加对象（自己）获得的护甲数量，同时对象被加上冰冻状态，这是修饰一般对象时的通用效果；如果在”寒冰吞噬护甲“中加入修饰词卡形成”“寒冷的寒冰吞噬护甲”，则会大幅增加寒冰数值和附加冰冻状态能力，这是修饰适配对象时的特殊效果；而“火焰吞噬护甲”则无法通过寒冷构成合法法术，这是修饰不适配对象时的不可组合限制

## 触发来源

用户在GR01–GR12处理采纳后调整顺序：先完成修饰词与镶嵌系统，再设计流派的成套物品。修饰词由用户给出两种子类及三种适配案例；镶嵌本轮只指定进入设计顺序，尚未给出完整规则。

## 可能带来的玩家体验

在保留名词与动词基本组合的基础上，用额外实体词卡改变数值、状态与能力；玩家依据明示兼容关系选择通用用途或适配用途。后续按同一流派一起比较基础词、修饰词与镶嵌资源的作用和机会成本。

### 用户补充确认

| 问题 | 用户选择 | 确认范围 |
| --- | --- | --- |
| 适配时特殊效果与通用效果的关系 | 特殊效果替代通用效果（推荐） | 不兼容→适配→通用，只执行一个版本 |
| 同一原词能否挂多张修饰词 | 允许多张，直接修饰原词（推荐） | 每张直接指向原词，不修饰其他修饰词；支付各实体与时间成本 |
| 是否永久改写场上原值 | 仅修正本句计算（推荐） | 原值不因修饰本身被改写；实际新增状态按自身规则存续 |
| 多修饰共同结算 | 采用这套固定顺序（推荐） | 同数值按现有规则合并，不同附加效果按句中从左到右结算，适配均依据原词 |
