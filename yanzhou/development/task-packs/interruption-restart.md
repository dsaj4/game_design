# 任务设计包：打断与重开

2026-10-27 · Derived Design / CORE-067 · 已同步，执行NotRun。包及规则共用执行任务固定提交，沿[任务规范](../task-pack.md)。

## 最小行为与边界

| 环节 | 行为与权威 |
| --- | --- |
| 锁定 | 延时原牌生成后续时锁剩余a+D−t最长加工法器，并列战前序；无加工记无对象。锁法器不锁原批。[TL-09](../../design/systems/action-card-system/rules.md#tl-09-敌牌揭示与锁定) |
| 下轮 | 后续公开、依生成序覆盖左位；原对应基础项跳过，不追加。[TL-16](../../design/systems/enemy-system/rules.md#tl-16-敌方程序约束) |
| 命中 | 后续列作用原法器当时批次；无对象／无批次只落空，不改选、不转伤害。[TL-12](../../design/GDD.md#tl-12-伤害与法器中断) |
| 损失与保留 | 在制批次失进度、不产卡；已有手牌／行牌保留，不追溯完工。普通伤害不打断。[TL-07](../../design/systems/artifact-system/rules.md#tl-07-打断与返工) |
| 退还 | 实际普通输入退回原实例，仍有效冻结释放；最早下一生产拍边界后恢复资格；退料在当轮后续列不能上牌，也不能供料。退料不同于战斗使用后的立即回手，不能借回收属性提前。[TL-15](../../design/systems/resource-system/rules.md#tl-15-配方托管产物与维护) |
| 重开 | 列间不生产或开工；下一生产拍拍末按完整条件检查，新批当拍不推进、不补失去批次。无容量预留／H3门槛。[TL-05／11](../../design/systems/artifact-system/rules.md) |
| 恢复 | 保留原锁定、批次与真实手／行／托管归属、退料可用拍及每次回收／支付事实，不复制、不重退或重产。[TL-19](../../design/common/interaction-save/rules.md#tl-19-中断与恢复) |

## 正常、反例与恢复

[EX-004 §5](../../design/examples/round-first-battle.md#5-从真实初态到手牌与打断)：第2轮R在10生产拍后锁施法；第3轮15拍已产新卡并续开15→18，后续打断的是新批。已有卡不消失，第16拍拍末才重开、19拍才产攻击。列间即使能再上回收牌，也不能推进加工。

若锁定时无对象，下一轮有法器也不补选；锁定法器当时无在制批次只落空。若当前列已终局，不开新出牌窗口或下一拍。EX-004为零材料、无开工冻结，不编造退款数量；有真实输入才按TL-15展开。

## 对话讲解

敌人盯的是一台法器。它出手时，那台法器已经做完的牌还在你手里或桌上；正在做的那批才会报废。原料若尚未消费会退回，但要到下一生产拍才可用。另一张刚打完的可回收牌却可以直接再上后续列——这是使用后的回手，两者时点不同。
