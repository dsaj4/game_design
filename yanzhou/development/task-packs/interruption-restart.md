## 目标与范围

玩家能理解“打断锁定哪台、损失哪一批、为何有时当拍重开、哪些回收量要等下拍”。包含揭示锁定、T拍事件、回收、再次开工、旧牌与恢复。不是新主动取消／躲打断能力。

## 直接用于开发的最小设计

| 环节 | 必须得到的行为 | 权威条款 |
| --- | --- | --- |
| r拍锁定 | 从正在加工者选剩余R=a+D−r最长的法器，R含0，并列按战前序；无加工者则无锁定对象。锁定法器而非批次，T=r+Δ且Δ>0 | [TL-09](../../design/systems/action-card-system/rules.md#tl-09-敌牌揭示与锁定) |
| T拍资格 | 检查被锁法器当时的批次。原批次已完成而后续又开工，后续批次仍可能中断；无对象、法器消失或无批次则落空一次，不改选／等候／转伤害 | [核心TL-12](../../design/GDD.md#tl-12-伤害与法器中断) |
| 同拍顺序 | 已有资格的防护先处理，再按TL-11结算打断；打断在幸存完工前，因此T拍本应完工也可能被中断。护甲不抵挡单列打断，普通掉血不打断 | [TL-11](../../design/systems/action-card-system/rules.md#tl-11-共同拍序与效果边界)、[核心TL-12](../../design/GDD.md#tl-12-伤害与法器中断) |
| 损失与回收 | 该批不产行动、丢进度，普通材料退回；解除预留，但材料及回收容量最早t+1可用。冻结标记只释放仍有效部分且t+1可用，不复活失效层、不退其他阶段已付费用 | [TL-07](../../design/systems/artifact-system/rules.md#tl-07-打断与返工)、[标记规则](../../design/systems/action-card-system/mark-system/rules.md) |
| 当拍重开 | 阶段5若另有本来可用的完整材料、标记与独立空位，可按有效供料序重新检查；不能使用刚回收量。否则等待，下拍再查，不追赶、不补发 | [TL-05／07](../../design/systems/artifact-system/rules.md#tl-05-开工预留与完成入行)、[核心TL-04](../../design/GDD.md#tl-04-实际节拍顺延) |
| 旧牌与终局 | 已入行牌不会随法器中断消失。每个完整事件后若终局成立，停止后续事件、完工和重开，已成结果不回滚 | [TL-07](../../design/systems/artifact-system/rules.md#tl-07-打断与返工)、[核心TL-13](../../design/GDD.md#tl-13-生命程序循环与终局) |
| 恢复与信息 | 保留敌牌锁定、当前批次、待用数量及拍号、真实队列和相位。恢复不重新锁定、不重退料、不提前复用；区分丢进度、缺料、缺位和落空原因 | [TL-17／19](../../design/common/interaction-save/rules.md#tl-19-中断与恢复) |

## 正常、反例与恢复

| 情境／操作 | 预期 |
| --- | --- |
| EX-001 r8：守护R0、施法R1 | 锁施法，T13；不是锁住当时的6→9批次 |
| EX-001 t13 | 中断施法12→15批次；12已入行的强化打击保留，14仍可生效 |
| EX-001 t13末 | 实牌1＋守护预留1＋重开施法预留1＋待复用1=4≤Q5；13→16重开用独立空位，回收的1到14才可用 |
| 同样打断，但没有独立空位／其他完整料 | t拍不重开；t+1回收量可用后重新检查其他条件，不保证一定开工 |
| r拍没有加工法器／T拍锁定法器无批次 | 按无锁定／落空一次，不追选后来出现的法器或转成伤害 |
| 冻结量部分先自然失效 | 本批D不变；打断只释放仍有效部分，不补回失效层 |
| 打断后退出恢复 | 保留待复用拍、旧牌及新批次是否已开；不把刚回收容量改为立即可用 |
| 同事件后已终局 | 不为完成一拍而继续生产或补偿中断 |

## 什么时候展开更多

- 改锁定算法／跨循环敌表：读敌人rules全部首版限制及TL-09／11；当前首版不安排同拍多敌牌到期。
- 改容量、维护或共享标记：读完整TL-05、资源维护次序与标记生命周期，联合检查不能简化为“材料够就开”。
- 实现保存：读TL-19完整字段及EX-002 §5；失焦／单步／音画再读CORE-061—063。
- 想让玩家主动避免这次打断：先使用真实已有操作；EX-001零材料无法通过停供停机，新增启停归FB-Q01，不从本包补权限。

## 对话讲解

敌人第8拍盯上的是施法护符这台法器。它手上那批先做完了也不算脱险：第13拍到期时，敌人会打断这台法器当时正在做的新批次。第12拍已经排进队列的强化打击不会一起消失。

打断后，回收的空位要到第14拍才能使用。不过本例还有另一个本来就空着的位置，所以第13拍末可以重新开工；若没有这个独立空位，就得等。这里的代价是丢掉一批进度，并非无条件停机一整拍，也不是免费撤销。

审阅覆盖：锁定对象、当前／旧批次、同拍先后、损失、独立重开条件、旧牌保留、恢复与终局。未覆盖：新主动启停、未发行的特殊保护、任意未来标记的生命周期。
