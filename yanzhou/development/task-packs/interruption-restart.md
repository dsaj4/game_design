# 任务设计包：打断与重开

2026-10-23 · Derived Design / CORE-065 · 文档已同步，执行NotRun。包与来源共用任务固定提交，沿[任务包规范](../task-pack.md)。替代旧r→T、预留回收和同拍重开的现行说明；旧EX固定结果不改。

## 目标与范围

玩家看到完整公开的后续打断牌，知道它盯住哪台法器、何时命中、为何已产牌保留而在制批次会丢失。普通伤害不打断；本包不增加主动停机、免费取消或即时打断牌。

## 直接用于开发的最小设计

| 环节 | 行为 | 权威条款 |
| --- | --- | --- |
| 生成时锁定 | 延时原牌结算生成后续打断时，从正在加工者选剩余a+D−t最长法器，并列战前序；没有则记无对象。锁法器，不锁该批次 | [TL-09](../../design/systems/action-card-system/rules.md#tl-09-敌牌揭示与锁定) |
| 下轮上桌 | 后续牌完整公开，在敌手牌等待；下轮按生成顺序占左侧位置，覆盖对应基础牌，不追加到行尾 | [TL-16](../../design/systems/enemy-system/rules.md#tl-16-敌方程序约束) |
| 命中 | 目标列到来时检查锁定法器的当前批次；无对象／无批次则落空，不改选、不候补。普通伤害与护甲不代替单列打断 | [TL-12](../../design/GDD.md#tl-12-伤害与法器中断) |
| 先后 | 本轮生产已全部结束；结算列不走生产时间，打断不能回溯已完成的牌，也没有列间完工／重开 | [TL-11](../../design/systems/action-card-system/rules.md#tl-11-共同拍序与效果边界) |
| 损失 | 只丢当前批次进度且不产牌；实际有普通耗材才退料，有有效冻结才释放，最早下一生产拍可用 | [TL-07](../../design/systems/artifact-system/rules.md#tl-07-打断与返工) |
| 重开 | 下一生产拍末检查合法开工；不等成品容量，不补发丢失批次。EX局部零材料、无开工标记费，无退款数可编造 | [TL-05／07](../../design/systems/artifact-system/rules.md) |
| 已产与终局 | 桌牌／手牌保留；每完整事件查终局，终局停止剩余列和后续生产 | [TL-13](../../design/GDD.md#tl-13-生命程序循环与终局) |
| 恢复 | 保存后续牌、固定目标、当前批次、释放资格及相位，不重新锁定或重复返料 | [TL-19](../../design/common/interaction-save/rules.md#tl-19-中断与恢复) |

## 正常、反例与恢复

| 情境 | 预期 |
| --- | --- |
| 上轮生成时锁A，原批已在下一轮生产期间完成并开了新批 | 后续列命中A的新批；原批已做好的桌／手牌安全 |
| 本轮末生产拍刚完工并重新开工，随后结算打断 | 已完工牌保留，新批可被打断；不取消本轮已经完成的生产 |
| 生成时无加工对象／生效时A无批次 | 记无对象或落空一次，不能追选另一台 |
| 第2列打断后第3列 | 无生产检查；法器仍空闲，不能当列重开；最早下一生产拍末开工 |
| 结算暂停后试图停机或改供料躲这次打断 | 玩法修改关闭；此前已接受的未来设置也不撤回当前批次 |
| 打断后恢复 | 旧牌仍在、批次已清；材料释放不提前、不重退，下个生产拍按保存游标继续 |

## 什么时候展开更多

改敌表要同时查后续覆盖和信息合同；新增合法取消牌才展开TL-10，只能在后续牌所在列开始前取消已公开的更右侧部署牌。引入材料／冻结费按实际内容读退回与释放；有限期／维护未进入当前首场。新的2D宿主另裁。

## 对话讲解

敌人这一轮翻开的准备牌，生成一张下轮才打你的牌，并公开盯住法器A。你还有下一轮五个生产拍，A可能先做完旧批又开始新批。等打断那一列结算时，损失的是A当时正在做的批次；已经到桌上或手里的牌不会消失。

打断后也不会立刻补开一批：接下来的列都只结算卡效，生产时间没有往前走。要到下一生产拍末才再检查开工。因此旧例“同拍另有空位即可重开”已经不适用于当前回合。
