## 目标与范围

玩家能切换护符未来用途，并知道当前批次不变、哪批开始采用新用途、兑现时才检查费用。包含提交、预告、承诺、生效及恢复；不制作新2D宿主、不解决FB-Q01主动启停或FB-Q02保留收益。

## 首场支付只看三个数

**可消费＝实有−玩家锁定**，仅适用于本例无批次冻结／定时释放的施法次数。锁定是保留数量，不是付款；兑现生效时才检查可消费是否≥5。满足则付5，不足则不扣并回退6伤；攻击成功且未终局后才记1层，不能倒补刚才的费用。

这是资源和标记共用的基础分配操作在本例中的应用。解锁受理后，释放的数量自动参加后续合法消费，无需再按一次支付；不会立即强制出牌或重做已失败的付款。来源：[共用锁定](../../design/common/interaction-save/rules.md#玩家消费锁定与预警core-055)。

本例开工不花标记，被打断也没有标记退款。资源／标记冻结不混入本例账目；新增此类内容时展开对应规则，不把上述减法当通用余额算法。来源：[EX-001施法次数](../../design/examples/simple-spell.md#5-施法次数)、[标记支付](../../design/systems/action-card-system/mark-system/rules.md#读取与支付)。

  A --> C["可消费4层"]
  C --> D["兑现需5层：不足"]

## 正常、反例与恢复

| 情境／操作 | 预期 |
| --- | --- |
| EX-001第7拍观察改兑现 | 6→9普通批次保持；9开兑现、12入行、14生效；10拍仍是普通攻击 |
| 当前结算中提交 | 留下一观察窗口受理，不插入本拍余步；无新可用输入窗口 |
| 合法目标，4层未锁／5层未锁 | 前者回退6并记1至5；后者付5打18并记1至1，均假定未终局 |
| 实有9层、锁5 | 可消费4，回退6后总层10、锁5；不能按总层支付 |
| 同样实有9层、锁5，兑现前的观察窗口解锁1层 | 锁定变4、可消费变5；轮到兑现且目标合法时自动付5打18，未终局再记1，最后实有5、锁4；解锁本身不提前扣费或出牌 |
| 致死或无目标 | 不执行依赖攻击成功且非终局的记次；无目标还不支付 |
| 提交后、下一窗口前退出恢复 | 待受理输入仍在；当前批次仍旧用途；按保存相位继续，不提前兑现 |
| 改变初态或选择时点 | 重新按规则计算，不把14拍18伤固定成所有输入的结果 |

来源：[EX-001 §4—7](../../design/examples/simple-spell.md#4-行动与用途)、[TL-V58／75／108／109](../../design/validation.md)及[EX-002 §5](../../design/examples/complete-battle.md#5-恢复与验收预期)。这些是设计预期，不是本包已执行结果。

## 什么时候展开更多

- 改通用开工／排程：读完整TL-03／05与TL-11，不只实现本包时序。
- 引入新消费、冻结、期限或周期：读标记rules和TL-11逐步支付／定时／终局接口；本例没有开工侧标记费或周期登记。
- 改真实交互：读CORE-060—063中对应合同；新2D先处理PRE2D-Q01，现有规则不授权新宿主。
- 增加材料或多用途内容：补资源TL-43及完整配方、目标、失败、数量与顺序。不能从“切用途”推定单器停机或战中重铭。

## 对话讲解

第7拍改兑现，并不会把手上那批普通攻击变强。它第9拍照常完工，第10拍仍打普通伤害；第9拍才新开的兑现批次要到12拍入队，排到14拍才使用。因此这次选择是在安排后面，不能立刻救急。

到使用那刻才看能不能付5层。只有4层，或9层里锁了5层，都会回退普通伤害；这次攻击后来新增的一层也不能倒补自己的费用。若已击杀敌人，就不再补记次。

审阅覆盖：选择影响的批次、延迟、支付／锁定、无目标／终局、受理与恢复。待判断只记录用户希望改变的具体后果，已有采纳不重复审批。未覆盖：新启停、新被动收益、新2D表现。
