## 目标与最小行为

| 环节 | 行为与权威 |
| --- | --- |
| 战前 | 在有限生产网格配置占格法器、相邻接口与专属供料区，选择已有合法用途并固定本战布局、形状、用途及法器序。[TL-31](../../design/common/interaction-save/rules.md#tl-31-战前配置与可表达性) |
| 放料 | 手牌先进入本器供料区；真实形状可旋转但须放得下，配方资格独立检查。一器一批在制＋至多一批待料；手动允许缺件准备。[TL-06](../../design/systems/artifact-system/rules.md#tl-06-路由与临时设置) |
| 自动补料 | 默认开，可逐器关；只补空缺，不换已放料。排除锁定及不可用牌，最低合格阶级、同阶手牌先后；不能组成可放入的完整配方就不部分搬入。第0拍首次检查后及每生产拍全部开工检查后按战前序补入，关闭保留待料。 |
| 受理 | 仅生产观察窗调整待料与自动开关，材料锁解亦限此窗；最终整理仅布牌及标记锁解；列间仅布牌。战中一律不改用途／设备／供料形状。[TL-17](../../design/common/interaction-save/rules.md#tl-17-暂停与信息) |
| 吸收 | t拍后放料最早t+1拍吸收；完整配方、空闲及费用全部满足，才托管并腾空待料位、冻结D。完工消费普通输入、直接产卡入手。第0拍仅零材料可开工；关闭自动不能让零材料停机。[TL-05](../../design/systems/artifact-system/rules.md#tl-05-开工与成品去向) |
| 失败／恢复 | 缺件不部分吸收，非法改送整项拒绝。打断退料回手待用，不覆盖已排下一批；恢复保留唯一归属、形状／朝向、最早拍、开关及补料阶段。[TL-15](../../design/systems/resource-system/rules.md#tl-15-配方托管产物与维护)、[TL-19](../../design/common/interaction-save/rules.md#tl-19-中断与恢复) |

## 首场支付只看三个数

EX-004无开工冻结／期限，可消费＝实有−锁定。实有9锁5只可花4，强化回退6；在最终整理解锁1，后续可付5打18，成功未终局再记1。列间不能临时解锁。材料锁定保护手牌免于自动补料，不能据此获得最终整理编辑材料或战中改用途的能力。

## 正常、反例与恢复

法器正在加工甲，生产观察窗可把下一批乙放进本器供料区；甲不变。乙齐备且到最早拍后，等法器空闲才吸收；此前可撤回／替换／改送。关闭自动保留乙，若不想乙开工须在合法窗口撤回。1×4区不能接2×2料，不能只比面积；两台争同一张手牌按战前序补料，不复制。

待料中的可战斗牌须先撤回手牌才可布上行；在制不能撤回。加工退回原料还须重新排队，不能跳过待用与最早吸收拍。参见[打断包](interruption-restart.md)。EX-004只有零材料三卡，没有真实供料形状，不能冒充这些边界的执行证据；完整输入缺口见BP-Q01／02。

## 对话讲解

开战前决定每台法器做什么，以及给它留多大的供料位置。战中它会自动补好下一批，你也可以在生产停稳时换料、撤料或关掉自动补料。已经吸收的这一批继续加工；旁边摆好的才是还能调整的下一批。做好的牌回到手中，再由你决定如何用于战斗。
