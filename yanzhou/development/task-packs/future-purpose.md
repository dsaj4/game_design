# 任务设计包：切换未来用途

2026-10-23 · Derived Design / CORE-065 · 文档已同步，执行NotRun。包及引用共用任务固定提交，沿[任务包规范](../task-pack.md)。数值引用[EX-003](../../design/examples/round-hand.md)明确借用的旧卡效，不把旧EX连续拍时序作为新预期。

## 目标与范围

玩家能区分“改以后制造什么”和“花点重排已经制造的牌”。未来用途免费、只影响下一次成功开工；整理消耗行动点，只改变成品位置，不改卡效。未提供单法器启停、战中重铭或新的保留层数增伤。

## 首场支付只看三个数

在本例无开工冻结／期限的施法次数中，**可消费＝实有−玩家锁定**。实有9层锁5，可消费4，兑现回退6；在最终整理合法解锁1后，可消费5，届时能付5打18。解锁免费且不立即付款，卡效到来才付；结算中不能解锁。新生的一层不能倒补刚才的费用。来源：[消费锁定](../../design/common/interaction-save/rules.md#玩家消费锁定与预警core-055)及EX-003。

## 正常、反例与恢复

| 情境 | 预期 |
| --- | --- |
| 第5生产拍已按旧用途开工，最终整理改兑现 | 这一批仍旧用途；再下一次成功开工才用兑现 |
| 初始4层、前普通后兑现，目标存活 | 普通6并记至5，兑现付5打18再记1，总24伤，最终1层 |
| 同样初态，前兑现后普通 | 兑现不足回退6并记至5，普通6再记至6，总12伤；调换花1点 |
| 最终整理解锁后开始结算 | 锁定按提交值保存，轮到卡效才支付；不得列间再次修改 |
| 无合法目标／致死 | 前者不付该步、不记次；后者不执行后续记次或其他事件 |
| 提交后退出恢复 | 只恢复已接受输入和对应相位，当前批次不改，不重扣点数 |

上述均是假定目标合法、无其他效果的局部设计预期，非实测结果。完整新敌表尚缺。

改排程读TL-11及[回合包](round-hand.md)；引入开工标记费、期限或周期须补对应规则并明确能否进入当前首场，不能套本例减法。真实交互依CORE-065，新的2D宿主先解决PRE2D-Q01。

## 对话讲解

你把法器的未来用途改成兑现，手里已经做好的普通攻击不会变强，正在做的那批也照旧。可你能花一点，把现成的普通攻击排到兑现前面：先打一击攒到五层，再由兑现花五层打出强化伤害。若顺序相反，兑现当时只有四层，就只打普通伤害；后来攒够也不补发。
