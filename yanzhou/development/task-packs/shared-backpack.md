## 玩家行为与边界

先让本局携带的卡、法器、备用配置和核心同包放下，再选择本场投入、展开生产结构；胜利后合格剩余物与配置重新竞争空间。散装核心1格，兼容嵌入额外0格，保留真实副本与战前可逆装配。

| 环节 | 最小行为与权威 |
| --- | --- |
| 携带与展开 | 同一实际网格；装得走和展开得下分别检查；备用设备不能放免费包外仓。[TL-46](../../design/systems/backpack-system/rules.md) |
| 投入与战斗 | 所选卡真实离包入手、无虚拟占格；留包物本战不可用，设备／供料结构固定；手牌继续无硬上限。[TL-31](../../design/common/interaction-save/rules.md#tl-31-战前配置与可表达性) |
| 核心与辅助 | 散装1格，兼容嵌入额外0格；拆回放不下整项拒绝；未部署辅助占包内空间但无本战效果。[TL-26](../../design/systems/inscription-system/rules.md#tl-26-实体铭文与词义) |
| 战后 | 卡的可回收与可携带分开；真实剩余与配置重装，已消耗输入不退；选留不复制、不重领。[TL-25／33](../../design/common/run-economy/rules.md) |
| 出售 | 旧配置可售已采纳；操作窗口、对象细分、价格与满包衔接未闭合，不能先做任意出售或免费遗弃。[TL-35](../../design/common/run-economy/rules.md#tl-35-固定商店与原子交易) |
| 恢复 | 保留阶段、实际归属、几何／装配和各次提交事实；旧分账存档不静默迁移。[TL-19](../../design/common/interaction-save/rules.md#tl-19-中断与恢复) |

## 正常、反例与制作缺口

携带两台法器、一件备用辅助和一枚散装核心时，四件都必须在包内有真实空间；把核心嵌入兼容法器后不再额外占1格，但它仍是被该法器占用的同一枚核心。若拆回没有合法落点，原装配保持。

投入卡进入手牌后不占虚拟格；战中不能从留包卡补料。胜利获得合格新卡，也不能额外生成一份包外库存。运输面积足够但真实待料无合法落点、卡可回收却不可携带、满包时售卖合同缺失，均不能伪造完成状态。条件情境见[CORE-070验收预期](../../design/validation.md#共用背包与分阶段装载core-070)。

CORE-074已定八器占形与可交叠范围，运输只计实体；CORE-073／074首战8×5及实际装载已闭合。其他取得、辅助／备用配置、种类限制和交易／满包仍沿BP-Q01／03／04等未决；EX-004已退役。只实现已定局部行为时需在任务中写清固定输入和排除范围；测试执行须另有对应任务授权。
