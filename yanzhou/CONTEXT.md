# 言咒术语

2026-10-31 · Glossary / CORE-069。具体行为以[系统规则](design/README.md)为准。

| 术语 | 定义 |
| --- | --- |
| 生产拍t | 只在生产阶段递增的整数逻辑时间；结算列不加拍 |
| 回合n／X | n从1计，每回合X个生产拍，当前X=5并对应双方桌面位数 |
| 结算列 | 回合末从左到右的一组敌我卡位；不是额外生产拍 |
| 最终整理 | 本回合最后生产拍收尾后的无时限受理窗口，明确确认后进入结算 |
| 玩家手牌／H | 可战斗与不可战斗两组持牌，切换仅查看；新产卡先入手，无硬上限；旧H3退出现行 |
| 整理行动点 | CORE-065旧费用；CORE-067取消，上牌、撤回未用牌及调序免费，卡效费用另付 |
| 原生暗牌／后续牌 | 基础表暗置卡／延时行动生成的公开下一回合卡，后者优先覆盖下轮左位 |
| 法器 | 在生产背包中占格，战前固定用途、位置和供料接口，执行一批加工的器具 |
| 生产背包 | 战前组织法器、辅助道具与专属供料位的有限格布局，不是跨战携带容量或成品库存 |
| 专属供料区／供料位 | 相邻接口连接一台法器，按实际形状容纳至多一批待料；允许材料旋转 |
| 待料／预放 | 已从手中移入供料区、尚未吸收的下一批候选；不等于托管或消费 |
| 自动补料 | 默认开启、可逐器关闭的待料补足；不替换已放料，不能补成整批则不部分自动搬入 |
| 吸收 | 完整开工条件满足时待料移入加工托管并腾位，普通耗材仍在完工时消费 |
| 铭文 | 战前可逆装入法器的实体词义，一实体一位置，嵌入不另占生产格，循环不消耗 |
| 暗句／核心槽 | 法器预设名词／动词结构及必填空缺，决定合法铭刻 |
| 辅助道具 | 独立占格的本局配置实体，用一个可旋转相邻接口指向一台兼容法器；多件同效可叠加 |
| 辅槽／辅槽打造 | CORE-069已淘汰的旧辅助位置及容量解锁，不是当前装配入口 |
| 契合增幅 | 指定法器与核心铭文搭配的特别效果 |
| 用途 | 内容预先声明的配方、D、张数及产物卡组合；同一合法铭刻可声明有限列表 |
| 基础加工 | 无需铭文的明示固有用途；与零材料含义不同 |
| 零材料配方 | 明确制造材料费用为0，仍需时间及其他必要条件；成品容量不挡开工 |
| 材料绑定 | 配方定义制造所需材料，不是核心槽选材 |
| 卡牌／资源卡 | 统一卡牌有三种战斗权限；原“资源卡”不再独立分类，材料是卡牌在配方中的用途 |
| 资源性质／阶级 | 配方匹配标签／材料身份等级；高阶可满足低阶要求 |
| 行动／行动卡 | 卡在战斗行的一次使用；原“行动卡”不再与材料互斥分类，是否回手由自身权限决定 |
| 战斗回收 | 本次卡效全部处理完成后原实例立即回手，无冷却；只在合法窗再上未开始列，不代表跨战携带 |
| 列间出牌窗口 | 非末列及动画结清后停住，只布置尚未开始己方列；确认后才揭示下一敌列 |
| 处理D | 本批加工拍数，a开工、a+D完工，开工冻结 |
| 批次承诺／托管 | 已开工用途、投入、产出、冻结D、静态辅助贡献和必要标记；新首场无成品容量预留 |
| 容量预留 | 旧连续拍术语，CORE-065不使用；不与材料托管混同 |
| 玩家战斗行 | X个固定列，玩家将可战斗手牌手动放入任意未开始空位；已处理列只读不可再填 |
| Q | 旧连续拍的成品总占用限制；CORE-065退出当前参数，不等于X＋H |
| 待复用容量 | 旧连续拍中断容量账户，CORE-065不使用；退料待用仍存在 |
| 缺料／缺位等待 | 缺料等使批次未开工；桌面位置不限制生产，产物入无硬上限手牌，不再满手烧牌 |
| 战前法器序 | 固定开工检查、自动补料竞争和同拍完工入手序 |
| 有效供料优先级 | 旧动态供料序；CORE-068当前检查与自动补料均沿固定战前法器序 |
| 临时供料方案 | CORE-068淘汰的旧限时路由／到期恢复接口，不等同当前自动补料开关 |
| 供料调时 | 通过未来材料可得性影响开工；不直接暂停当前批次 |
| 观察／提交窗口 | 生产观察编辑未吸收待料、自动开关及锁解；最终整理仅布牌与标记锁解；列间只布牌，列内不编辑 |
| 初始库存／新增资源 | 初始投入0拍可布牌／预放，有耗材最早1拍吸收；新增卡可下个合法窗上行，配方最早下一生产拍取得供料资格，排料后再等下一拍吸收，回收原卡不另等待 |
| 敌牌揭示r／延迟Δ／到期T | 旧连续拍时间术语；新首场原生牌到列翻开，后续牌下一回合使用 |
| 剩余R | 延时打断生成时，法器当前批次a+D−t的剩余生产拍 |
| 来源敌人 | 本场唯一发敌牌的敌人，其死亡进入胜负判断 |
| 固定循环L | 旧敌程序循环拍数；新基础表循环以回合计，不从旧L自动换算 |
| 取消敌牌 | 有明示权限的行动在目标列前，取消更右列已公开后续牌，留空不补 |
| 中断加工 | 打断指定法器当前批次，损失进度并按规则退料／释放承诺 |
| 落空 | 敌打断到期无有效锁定／批次，结算一次无效果 |
| 危险开工带 | 旧连续拍[T−D,T−1]公式，不用于新回合列；新威胁按真实批次与已知列解释 |
| 截击 | 旧连续拍Δ≤R的内容描述，新首场不启用即时打断 |
| 实例／条件绑定 | 指定唯一身份／保存选取规则；本次名单不补位 |
| 空放 | 目标或费用等不成立，按步骤及依赖完成本次；不退制造费、不补牌，仍按回收权限回手／移除 |
| 护甲 | 宿主累计防护，普通伤害先扣护甲，战终清理 |
| 标记 | 玩家／敌人的分种类层数状态，正负相对宿主 |
| 批次标记冻结 | 开工占用必要层数，完工扣除；其他效果不能读取或支付 |
| 玩家消费锁定 | 材料锁定保护手中未排队原卡免被自动补料选取；标记锁定保护未承诺层数不被支付，非消费读取仍沿内容 |
| 待释放标记 | 中断释放的仍有效冻结量，最早下一生产拍可用 |
| 独立定时登记／虚幻砝码 | 未迁移到当前首场的扩展；未来预告不等于实有层数 |
| 完整事件 | 一基础步骤的检查／支付、主结果、一层获准反应及必要清理 |
| 拍末暂停 | 生产期完成本生产拍及动画后停；新结算期按列或回合末事件收尾，见交互合同 |
| 维护／休眠 | 持续产物的自动周期支付／不足后保留身份与增幅的状态 |
| 携带选择 | 按标签、种类和容量统一选择跨战卡牌；保留身份阶级、重置运行状态 |
| 胜利收益包 | 每场一次整包领取／放弃，与卡牌携带分别提交 |
| 休整三选一 | 拿铭文时三个不同名候选选一个；与生命恢复互斥 |
| 固定货架 | 抵达生成后不刷新，一项一件，扣款与交付同时成立 |
| 递增疲劳 | 当前首场第10回合末起每回合一次，双方第n次损失5×n生命；共同事件判终局 |
| 结清时点恢复 | 异常后静态恢复最近完成事件及已提交操作，保留队列、支付、敌情和进度；不自动补跑 |
| 地域牌组 | 敌牌地域外观，保留通用类别符号与含义 |
| 可表达性 | 真实器具、铭文、材料／供给至少构成可执行基础路线 |

资格与证据术语：Accepted=已采纳；Qualified=可用于正式设计；Proposed=候选；Hypothesis／NotRun=未验证。GDD-0／1／2为文档成熟度；EX编号为案例身份，与TL规则、FX效果和发行实体身份分开。
