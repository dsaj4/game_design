# FX-002 获得护甲

## 当前修订 r3（2026-09-14，RC1）

状态：首版适用部分Accepted；量值为首版基准，效果与平衡证据Hypothesis／NotRun。[CG](../../../../../sources/materials/M-2026-09-14-card-interface-completion.md)、[PG](../../../../../sources/materials/M-2026-09-14-first-release-parameters-and-channels.md)、[EG](../../../../../sources/materials/M-2026-09-14-environment-forms-and-thresholds.md)为本修订的完整角色、事件、分组、参数及环境来源。G002-CORE-032–034已经采纳；原页未选历史变体继续保持原状态，不因本次修订纳入首版。

### 护甲（S2-N02、E3-N05）

- 合法角色与输入：数量状态；获得的结果，或清除／消耗／拆甲的输入；随宿主范围
- 正例：获得／护甲；冰霜／拆甲／护甲
- 边界／失败：树木没有护甲；消耗／护甲不能省略所需元素执行者
- 事件与顺序：创建／增量或支付由动词决定
- 参数、时间与渠道（依PG列序）：2；作为获得结果时基础6点；作为输入时读取宿主当前护甲，抵挡规则不变；期1；4。

### 获得（S2-V02）

- 合法角色与输入：仅省略主语的玩家执行；结果白名单护甲或回响；结果给自己
- 正例：获得／护甲；获得／回响
- 边界／失败：火焰／获得／护甲非法；获得／燃烧不在白名单
- 事件与顺序：原生成／增量；反刺创建或回响许可
- 参数、时间与渠道（依PG列序）：2；1；获得护甲按护甲结果的基础6点；获得回响设为有，不把6用于回响；护甲结果0或已有回响仍可合法结算；不建0甲身份；期1；4。

共同执行：普通数量max(0，floor((基础＋固定增减)×已声明乘数))；具体新层入口及自然衰减例外按PG。完整动作先判合法、替换结果种类，再支付与求值，已提交自耗动作允许完成；主事件后先检查胜负，再按公开顺序执行有限一层响应。直接名单固定不补位，逐对象读当前量；同组去重与互斥依CG-G01。所有本页入选卡片的实际参数已给，设计缺口Closed；未测不是未决定。
