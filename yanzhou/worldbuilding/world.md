# 世界、居民与既有设定

2026-11-01 · game-002。第1节继承原稿的限定用户确认；第2节承接原解释候选；第3节是本轮新增Raw工作稿。共同来源与阅读范围见[输入摘要](../sources/inbox/2026-11-01-worldbuilding-design.md)。本页没有创世定论。

## 1. 已明确的世界观

以下由2026-10-24—25《世界观与属性体系R01》第1节迁入。原来源为该轮用户意图与决定摘要；迁移前正文以本轮共同输入提交下`yanzhou/system-design/content/world-systems.md`取证。只继承下面列明的范围，不把原整稿的Raw候选升级为确认。

- 主角是失落文明的遗孤，从充斥铭文的文字界醒来，进入物质界探索；残存记忆只有赌桌、骰子、卡牌的剪影。
- 主角天生能够把铭文刻印在法器上，重现古代魔法；通过学习与收集，认识不同法术体系，追索文明消失的真正原因。
- 大陆存在许多与主角类似的存在，其中有人争夺他收集的铭文，因而发生战斗。尚未说明这些存在是否同源、全部具有相同天赋或都与主角敌对。
- **“世界毁灭”在此指古代文明消失，世界本身仍存在。** 不采用“大陆只是被毁世界的碎片”或“物质界已经被重新创造”作为既定事实。
- **物质界发生遭遇，冲突触及文字界，文字与法术的交锋产生真实后果。赌桌是主角凭残存记忆理解交锋的方式。** 不要求所有参与者都看见同一张实体赌桌。
- 风格重点为赌桌／筹码／卡牌、炼金／奥秘／奇幻，以及文字／语言／铭文。
- 用户认可“先理解用途，再认识原理”和“物件知识成为文明线索”两个优化方向；具体样本的故事仍为候选。

原稿同节的分类、炼金三性质、稀有度及生产认知决定继续在[体系工作稿第1节](../system-design/content/world-systems.md#1-已明确的分类与内容方向)维护；它们不是文明年表或已定宗教。历史思想研究仍沿该稿第3节，本轮未重新核实其网页。

## 2. 世界与玩法怎样连接：继承的解释候选

以下从原稿第2节迁入，均为**待审解释**。它们说明故事可以怎样理解已知对象，具体权限仍由[GDD](../design/GDD.md)裁决。

| 对象／关系 | 原解释候选 | 理解帮助与边界 |
| --- | --- | --- |
| 文字界 | 承载能够作用于现实的意义与法术原理；具体起源未知 | 研究文字可以认识力量；不先断定物质世界由文字创造 |
| 铭文 | 固定了一段能够生效的意义；识读字形、理解原理、持有承载效力的实体分别处理 | 天赋保证主角会刻印，探索增长理解与可用实体；抄写一个字不自动复制力量，保留一实体一位置 |
| 法器 | 将特定铭文稳定用于某些有限目的的器具 | 解释预设空缺、兼容、反复加工与有限用途；自然语言通顺仍不等于任意造法 |
| 行动卡的呈现 | 已经完成准备、尚待兑现的法术，在主角眼中呈现为牌 | 原稿将炼成与执行分开；不引入纸张耗材或抽牌规则。现行统一卡牌还可能用作材料，本解释不穷尽所有卡牌身份 |
| 「咒」 | 可继续用于施法的储备，筹码是数量表现候选 | 保留获得／消耗与实际支付规则；不把所有筹码定为「咒」，不合并金币、材料等余额。原稿提到的整理点不是现行资源 |
| 交锋后果 | 文字界的攻防能影响现实中的生命与行动能力 | 无须兵刃相击，也可有真实伤害与护甲；不增加精神生命值 |
| 争夺铭文 | 对手争夺可使用实体及其蕴含的知识 | 解释战斗动机；实际战利品、失败损失与跨战携带另由规则和内容裁决 |

成长可以同时表现为学会使用方法和理解其原理；这种关系适合连接构筑与追索文明，不自动生成永久解锁、熟练度或知识点。具体铭文实体怎样保存／转刻、天赋与学习的界线仍Unknown。

赌桌帮助主角理解准备、保留、投入与兑现。骰子仍只是已确认的记忆与风格要素；与文明消失是否有关尚未设计，不能因为出现骰子就将敌表、目标、伤害改成随机判定。

## 3. 世界的当下：首轮候选

**本节全部Raw / Unqualified。** 下面先让世界出现能与主角相遇的生活，不确认居民种族、国家名单、灾变年数或所有类似存在的起源。它可配合不同故事方向，但随方向选择仍需复核。

### 从工具推到生活

假定今日有小聚落依靠零散旧器具与普通劳动共同生活。居民需要水、热、药物和能修补的工具；他们关心某件器具下一次坏掉怎么办，也会争论把有限材料留给眼下还是修复旧设施。古文明对他们的意义先是能否继续生活，再是学者口中的过去。

| 因果链 | 居民得到什么、又付出什么 | 主角能看见什么 |
| --- | --- | --- |
| 有效铭文依赖实体和适配器具 → 看懂说明不等于能独立运转 → 掌握实物与维护知识者有议价能力 | 受益者能提供稳定服务；缺少组件或传承的人依赖交换，书本不能补齐一切 | 住户留着熟记的操作口诀，却不知道停摆后怎样重来；修补者反复检查同一处接口 |
| 古代公共设施失去整体维护 → 聚落保留少量局部用法 → 原用途与今日用途逐渐分离 | 今日的人延续了生活，也可能误解遗物；重新恢复整体未必符合他们现在的利益 | 一个古旧容器被小心修了几代，新补片比原器更醒目；屋主能说出每次修补者的名字，却不知道最初制造者 |
| 知识可讲述、有效实体难替代 → 公开方法与保存实物形成不同利益 → 争夺者不必都想毁坏世界 | 分享的人怕知识失传，收藏者怕失控或失去供给；普通居民可能同时需要两者 | 一位愿意教主角读旧标记，另一位要求保管铭文；争执围绕具体用途，而非一见面自报善恶 |

这里从实体与用途边界推演社会后果，仍依赖“有持续居住的聚落、存在民用遗产”等新增前提，不宣称GDD已经证明这些制度必然形成。也不据此宣布主角的天赋人人都有。

### 一个可触及的日常

清晨，聚落把几只补过口沿的瓶子放到桌边，等修补者分辨哪一只能再用一季。有人愿意把完好的旧瓶卖给收集者，另一个人担心下次搬水又要多走一趟。主角留意到瓶底的旧记号；主人先问的却是：“你能看出来它哪里快裂了吗？”

这个片段让古物同时有历史与当下价值。可引用[内容库](../content-library/catalog.json)的`alchemy.water`作为水的身份和既有说明参照；其文案、取得与数值仍沿原状态。瓶子的年代、刻记、修补史是待提议的叙事信息，并非该条目已有字段；未修改清泉水定义、画面或取得方式。

### 尚未设计的世界问题

文字界是否有稳定居民、谁能往返、古文明以外今天还有哪些社会，以及为何一些存在争夺铭文，都保持Unknown。三条故事方向对灾变提出不同答案，见[故事候选](story.md)；本页不先把某条答案铺成共同真相。
