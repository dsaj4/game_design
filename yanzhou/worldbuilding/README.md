## 维护边界

- 核心版本一经被方向引用，保持固定。以后用户明确修改共同核心时，生成下一版本，说明变化；旧方向不自动换版。某个方向内采纳的情节不等于共同核心采纳。
- 每个方向分别写清：继承版本、用户新增要求、模型候选、人物信念、作者暂拟真相和 Unknown。文献中的断言不能自动当成世界事实。
- 旧目录内 README 与 world 是原件，其历史指令、链接和“当前”只属于旧稿语境。进入旧方向仍需用户选择；保留不等于恢复为当前方案。
- 世界正文只在本目录维护。流派关联可以提出叙事需求，但配方、道具规格与正式物件文案仍由内容库单处维护；这里不增加任何玩法能力。
- 首战、局外系统、实现、美术和共享治理文件不属于本任务写入范围。需要对接时只在自己的方向中列候选接口。
