规则、理由、体验和示例按内容量展开，不再为未设计系统预建五个空页。细则保留确定行为与必要边界；任务包是带引用的派生视图，不能独立改规则。日常开发不加载全部来源、验收或设计理由。

复杂细则已按当前内容与条件扩展区分；周期、维护、开工标记冻结和附属反应不作为首场默认需求。审阅指出锁定／冻结／支付需优先简化后，首场说明收束为“实有、锁定、可消费与生效付款”；扩展仍在对应权威页按需读取。

完整GDD范围由[READ-1](../exploration/start.md#gdd包固定文件清单)固定，读取核心不能冒充全量。[EX-004](examples/round-first-battle.md)已按CORE-068同步战前用途选择、按CORE-069迁移迅速辅助，保留CORE-067手动出牌的限定首场；其零材料输入及未定辅助占形不覆盖完整空间布局，EX-003仅覆盖独立局部情境；EX-001和EX-002限定旧连续拍固定范围，案例值不成为全局默认，运行结果见开发入口。
