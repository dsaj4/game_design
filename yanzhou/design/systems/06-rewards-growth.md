# SYS-006 资源、收益与成长边界

Project ID：game-002。文档角色：CurrentSpec。2026-10-01 / GDD 2.0 / TL-1。结构已采纳；完整内容Unknown，体验Hypothesis / NotRun。

## 目的、行为与代价

玩家在战斗中分配材料与时间，在战外通过既有路线、休整和商店组织构筑。材料供给与法术产出支持当前战斗，词卡与法杖用于编排程序；两套资源不能因都画成卡而混账。

| 资源层 | 当前规则 | 尚未采用的推论 |
| --- | --- | --- |
| 战中基础材料 | 环境周期供给，法杖自动取用 | 不因此产金币或复制永久词卡 |
| 中间／高阶材料 | 按明示配方加工，付材料和时间 | 不自动继承旧火冰层数公式 |
| 行动卡 | 普通队列逐张兑现 | 不形成额外战后奖励容器 |
| 玩家干涉费用 | 每场固定，暂不设计成长 | 不默认随基础材料补给回充 |
| 战外物品与金币 | 保留库存、获取、购买与整体结算的分工 | 旧34词／19件货架和价格不自动迁入 |

## 跨战与跨局

保留单人单局、战外取得的正式物品由本局持有、普通战斗剩余生命延续的框架；终局按相应规则结束本局。新局不继承局外数值成长。

**TL-25 部分跨战保留**：用户明确允许部分资源和高阶产物跨战，不采用全量战后清理。仅卡表明确标注“可携带”的资源具备资格，基础环境料默认清空。可携带资源共用容量，战后选择带走哪些，界面自动沿用上次选择偏好；容量数值与每种资源占用量尚待定义。只保留资源种类与数量，增幅、休眠、维护进度及其他运行状态全部重置；下场按该资源的初始状态建立。不会把前场满增幅直接带入下场。

行动队列和加工进度不属于可携带资源数量。战终未完成加工的托管料是否先退回再参选、已完工但未交付资源的归属仍Unknown；不能擅自复制、丢弃或视为已获携带资格。结算后的携带清单必须一次提交，恢复不重领。战中退出恢复与战后重置是两个不同边界。

不能把“每场固定费用”解释成累加上限或成长。

## 获取与经济重审

新词卡及法杖需要实际获取方式、初始库存、同名额度、可达组合、价格和节点供给。旧开局12词、四根原木、8＋0–4金币、24恢复、三期货架、0–10起点和战斗时长奖金均保留为历史基准，不是本次重新设计卡表的默认参数。

不新增法术产金、永久卡片复制、额外奖励或费用成长。新卡表若改变库存规模，必须同时修改商店池、开局可表达性、资源补给和验收样本，不能只给理想组合免费组件。

## 异常、反馈与验收

材料不足、金币不足、词卡已占用、干涉费用不足使用不同提示。已完成的合法结果与支付不因临时设置恢复而回滚；未定义费用的能力不能被界面当成免费使用。

未来核对真实资源来源、重复领取、跨战清理和成型机会；体验上比较即时攻防与存料爆发的机会成本。全部NotRun。负责人为设计负责人，新卡表及经济采纳前补齐数值和持久化表。
