# SYS-006 资源、收益与成长边界

Project ID：game-002。文档角色：CurrentSpec。2026-10-04 / GDD 2.1 / TL-1 + INS-1。结构已采纳；完整内容Unknown，体验Hypothesis / NotRun。

## 目的、行为与代价

玩家在战斗中分配材料与时间，在战外通过既有路线、休整和商店组织构筑。材料供给与法术产出支持当前战斗，铭文与法器用于装配暗句配置；两套资源不能因都画成卡而混账。

| 资源层 | 当前规则 | 尚未采用的推论 |
| --- | --- | --- |
| 战中基础材料 | 环境周期供给，法器自动取用 | 不因此产金币或复制永久铭文 |
| 中间／高阶材料 | 新获取／加工途径待定；明确提供后按其来源与配方支付 | 不沿用法器直接输出资源，也不继承旧火冰层数公式 |
| 行动卡 | 普通队列逐张兑现 | 不形成额外战后奖励容器 |
| 玩家干涉费用 | 每场固定，暂不设计成长 | 不默认随基础材料补给回充 |
| 战外物品与金币 | 保留库存、获取、购买与整体结算的分工 | 旧34词／19件货架和价格不自动迁入 |

## 跨战与跨局

保留单人单局、战外取得的正式物品由本局持有、普通战斗剩余生命延续的框架；终局按相应规则结束本局。新局不继承局外数值成长。

**TL-25 部分跨战保留**：用户明确允许部分资源和高阶产物跨战，不采用全量战后清理。仅卡表明确标注“可携带”的资源具备资格，基础环境料默认清空。可携带资源共用容量，战后选择带走哪些，界面自动沿用上次选择偏好；容量数值与每种资源占用量尚待定义。只保留资源种类与数量，增幅、休眠、维护进度及其他运行状态全部重置；下场按该资源的初始状态建立。不会把前场满增幅直接带入下场。

行动队列和加工进度不属于可携带资源数量。战终未完成加工的托管料是否先退回再参选仍Unknown。旧直接资源成品情形由INS-1退出；新卡效产生资源及战终归属须依实际内容补齐，不能擅自复制、丢弃或视为已获携带资格。结算后的携带清单必须一次提交，恢复不重领。战中退出恢复与战后重置是两个不同边界。

不能把“每场固定费用”解释成累加上限或成长。

## TL-33 本局库存、生命与收益容器

正式铭文、法器和金币按本局库存持有；已装配铭文仍属于库存但不可重复占用，未装配铭文可留待后续战前重配。普通胜利不免费恢复生命，剩余生命进入下一场；明确的休整恢复不超过生命上限。新局以该局预设生命上限的满生命、0金币开始，旧局库存与战中状态重置；开局铭文／法器组合仍由新卡表决定，不恢复旧12词和四杖配置。

每场普通战斗至多提交一次明确配置的胜利收益包，不按击倒每名敌人再领一次。若包内同时有金币与铭文，领取／放弃针对整包；放弃不删除已有库存，不重抽、不返场再领，也不因为存在这个容器而默认每场赠铭文。具体奖励内容和金币数量仍待定。

TL-25的**资源携带选择是独立结算步骤**：玩家按资格和容量选本场剩余可携带资源，放弃普通收益包不等于放弃已有库存或携带资源；不能把制造的行动当作奖励再发一次。战终托管以及具体卡效资源是否进入可选集合仍Unknown。界面分别说明来源、去向与提交状态，已提交内容恢复不重领。

## TL-34 休整的互斥选择

每个休整节点只使用一次，可选生命恢复、取得一张铭文或跳过；恢复和拿词互斥。恢复量另定，满生命没有额外补偿；休整不额外发金币或商品。

先按新正式卡池和持有资格检查是否足以提供3个不重名铭文候选，且至少有1个名词、1个动词。检查只决定拿词选项是否可用，不提前显示候选。若不足，只提供恢复或跳过。选择拿词后，依次从合格名词、合格动词和剩余合格词名中各等概率抽1个，三个词名互不重复；不按当前构筑强塞适配组件。

玩家从3张中选1张，或全部放弃。看到候选后不改回恢复、不重抽。这里继承的是“3选1”的选项结构，**不是同名持有上限3张**；新铭文额度仍待卡表。修饰词等只有实际进入正式池且满足资格，才可能成为第三类候选。

## TL-35 固定商店与原子交易

商店是独立非战斗节点，不附送恢复、铭文或战斗收益。抵达生成本店一次性固定货架与价格，显示名称、完整效果、价格和购买资格；返回详情或恢复存档不刷新。铭文在每个抽取步骤按剩余合格词名等概率取样，同店不重复词名，每个货架条目只有一件，不补货；不同店可以再次出售同名铭文，仍受当时持有资格限制。

可连续购买不同商品，每次同时检查购买资格与金币足额，成功才扣款并交付；不部分扣款、不因界面显示过旧而超额买入。候选不足则少摆，空货架可直接离开，无额外补偿；商店不保证名词／动词配齐，也不按玩家余额或构筑暗改货架与价格。法器等商品使用各自资格，不套铭文副本额度；资源身份不自动成为可购买商品。

离开保留余款并沿路线前进，不返回旧店；不提供卖出、退款、付费刷新、随机包或永久删卡等未采纳功能。货架槽数、商品池、价格与铭文持有上限仍Unknown。经济设计应让前段正常基础收入有购买基础合格商品的机会，但须用实际路线核对，不能把这个目标当作已验证结论。

## 获取与经济重审

新铭文及法器需要实际获取方式、初始库存、同名额度、可达组合、价格和节点供给。旧开局12词、四根原木、8＋0–4金币、24恢复、三期货架、0–10起点和战斗时长奖金均保留为历史基准，不是本次重新设计卡表的默认参数。

不新增法术产金、永久卡片复制、额外奖励或干涉费用成长。新卡表若改变库存规模，必须同时修改商店池、开局可表达性、资源补给和验收样本，不能只给理想组合免费组件。辅槽打造是另行允许的构筑成长，不改变每战固定干涉费用的边界。

## 异常、反馈与验收

材料不足、金币不足、铭文已占用、干涉费用不足使用不同提示。已完成的合法结果与支付不因临时设置恢复而回滚；未定义费用的能力不能被界面当成免费使用。

未来核对真实资源来源、重复领取、跨战清理和成型机会；体验上比较即时攻防与存料爆发的机会成本。全部NotRun。负责人为设计负责人，新卡表及经济采纳前补齐数值和持久化表。

## TL-42 辅槽打造

每个法器采用核心槽＋辅槽。核心槽不可打造；辅槽可通过打造新增／解锁，用于装配修饰词，数量原则遵SYS-001 TL-41。这里采纳的是新增／解锁，未采纳升级槽位、随机词缀或额外核心空缺。

玩家可在实际开放的打造流程中选择增加哪个法器的修饰容量；打造来源、费用／资源、地点、时机、耗时、取消和返还，以及打造结果跨战／跨局如何保存，均Unknown。新增槽位本身不赠送修饰铭文，也不自动令修饰生效。未定义成本的打造不能按免费功能使用。

预期取舍是修饰容量与其他资源用途之间的竞争；当前仅为Hypothesis / NotRun，没有证明“可打造”必然形成成长深度。[采纳](../../sources/draft-changes/D-2026-10-04-artifact-inscription-core.md)。
