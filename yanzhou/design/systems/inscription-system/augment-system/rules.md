## 1. 装配与作用归属

辅槽在合法核心配置上修饰本法器。它不能补齐缺失核心，也不能凭修饰文本获得未声明的核心用途、目标类别或材料选择权限。

已有装配约束引用 [SYS-001 TL-26／28／40／41](../rules.md)：辅槽可空、挂接位置由法器预设、实际槽数逐法器声明、每个铭文实体只占一个位置，兼容与专属适配须明确。推荐选项数量不代表槽数、实体副本数或全部合法候选数。

打造引用 [TL-42（原 SYS-006）](../rules.md#tl-42-辅槽打造)：新增／解锁辅槽容量不等于获得修饰铭文。实际打造费用、时机和持久范围由该系统与后续内容定义，本页不另设统一槽数或打造等级。

## 2. 修改权限

| 修改位置 | 已确认权限 | 边界 |
| --- | --- | --- |
| 本法器的生成时间 | 可以修改生成行动所需时间 | 生产效率相关权限仅此一项；不修改制造材料消耗和每批成品产出张数 |
| 本法器生成的行动卡量值 | 可以修改效果中明确声明的数值 | 必须指出改哪个量值；“效果增强”不自动改变目标资格、行动卡种类、事件次数或取消权限 |
| 简单标记条件 | 可以按效果声明读取标记条件 | 读取不等于支付，不自动占有或锁定该标记 |
| 标记支付 | 可以按效果声明消费标记，换取本法器的时间或行动量值变化 | 必须满足第 4 节完整检查与支付原则；各效果的具体检查时点仍须声明 |

全局容量 Q 修改、新事件链不属于本轮通用能力；未来若需要，须单独设计、审查和采纳。已明确排除的减料、增加每批成品张数和法器直接加成协同，不因标为“扩展”而恢复。

生产时间沿 [SYS-002 TL-03](../../artifact-system/rules.md) 的唯一处理耗时 D 与合法域；本页不新设冷却、交付耗时或零时间生产。**CORE-055已确定开工时读取本批时间修饰所需条件并冻结D，处理中不随标记变化重算；多项时间修饰如何合成和舍入仍未确定**，见 [待补接口](design.md#待补接口与当前建议)。

普通行动量值引用 [SYS-004 TL-37](../../resource-system/rules.md) 的参数、取整与来源合同。该数量公式不自动套用生成时间；不同量纲不相加，契合、标记和辅槽不暗设独立乘区。

## 3. 跨法器只通过标记协同

跨法器组合通过共享标记发生：某行动形成标记，另一法器按自身效果声明读取或支付该标记，获得属于自身的修饰。标记的对象、层数、生命周期与可用时点仍由标记规则决定。

辅槽不能直接给另一法器添加伤害倍率、时间加成或其他修饰，也不能把本法器的辅槽加成自动继承给其他来源。共享标记不等于共享辅槽倍率。

关系示意见 [独立示例](examples.md#标记协同关系)。

行动生成的标记按已声明的行动／事件时点产生，不因行动卡完成生产就默认为标记已经生效。

## 4. 检查成功才支付

涉及标记支付时，先完整检查该步骤的必要条件，失败不部分支付。CORE-055将开工侧消费改为成功后足额冻结本批所需量、完工时扣除；其他支付步骤仍成功后足额扣除，不能把行动生效侧费用提前冻结。

- 要求支付指定层数而当前不足：不先扣掉现有层数，不以部分支付换取部分增强。
- 增强发生在制造开工侧：合法配置、完整制造材料、可用容量及相应标记条件必须共同满足，才能提交开工及足额标记冻结；缺料或缺位时既不冻结也不扣标记。
- 仅把标记作为条件：没有消费声明便不扣除。
- 若效果声明在行动生效侧支付：按该步骤的条件与费用检查，不能把尚未发生的支付当作已付制造成本。

[CORE-055](../../../../sources/draft-changes/D-2026-10-08-batch-freeze-consumption-lock.md)已进一步采纳：必需材料／必付标记不足则该批等待，只有明确声明可选增强且允许基础回退的内容才能不增强继续。开工冻结量不供其他支付或条件读取；本批被打断时释放，最早下一拍可用。详细生命周期唯一见[标记冻结](../../action-card-system/mark-system/rules.md#批次标记冻结core-055)。这不裁定其他阶段已付标记的退款、冻结量自然失效、同拍总序或战终归属。

## 5. 与生产、队列的关系

辅槽沿用 [SYS-002](../../artifact-system/rules.md) 的材料托管、容量预留与批次承诺，以及 [SYS-003](../../action-card-system/rules.md) 的普通队列、实际生效和目标失效规则。

缩短生成时间不会免除开工前的材料与容量检查，不让行动立即生效，也不绕过每拍结算上限。生产完成、实际入行和行动生效须分别解释。后续供料调整不改写既有批次承诺或已入行牌。

辅槽没有增加成品张数的权限，但更短时间可能改变一段时间内的实际生产次数；这是既有生产循环的结果，仍受材料、容量、队列与战斗时长约束。

## 6. 强弱与效果表达

强弱以稀有度表达。其他差异直接说明效果、条件和代价，不另设“基础—中等—高级”、用途等级或获取阶段等级等明显上下分级。

稀有度不替代效果说明，也不单凭标签证明某配置在所有情境中更优。本轮未确定稀有度名称、档数、具体强度预算、获取价格或掉率。

效果说明须能识别修饰对象、改变的量值／时间、必要条件、支付及结果。具体效果在投入正式内容前，还须补齐检查与兑现时点、失败分支和相关生命周期。未补齐的字段保持 Unknown，不能由界面、示例或实现补成默认。
