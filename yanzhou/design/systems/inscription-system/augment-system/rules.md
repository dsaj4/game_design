# 辅槽系统：规则

2026-10-23 · QualifiedFramework；CORE-055—057已采纳局部沿[基准](../../../baseline.md)。[设计](design.md) · [体验](experience.md) · [示例](examples.md)

## 1. 装配与作用归属

本法器辅槽可空；挂接、槽数、兼容、一实体一位置及不能补缺失核心，统一沿[铭文TL-26／28／41／42](../rules.md)。打造容量与取得铭文分开。

## 2. 修改权限

| 可修改 | 内容须声明 |
| --- | --- |
| 本法器D：固定时间／耗时倍率 | 条件、有效贡献、必要费用 |
| 本法器已有行动量值 | 修改哪个量、何时读取 |
| 简单标记读取／支付 | 宿主、种类、条件或费用、结果、失败 |

不能改制造耗材、每批张数、桌面X、卡的战斗／回收权限或手牌规则、目标资格、类别或新增事件。D按[时间公式](../../artifact-system/rules.md#时间修饰公式core-056)，普通量值按[TL-37](../../resource-system/rules.md#tl-37-参数来源与有限事件的共同合同)。

## 3. 辅槽跨法器修饰通过标记协同

A行动产标记，B按自身声明读取／支付，结果归B；不直接转送A的倍率。材料流转是另一条资源链，标记仅附玩家／敌人。

## 4. 检查成功才支付

开工侧沿[TL-05联合检查](../../artifact-system/rules.md#tl-05-开工预留与完成入行)和[标记冻结](../../action-card-system/mark-system/rules.md#批次标记冻结core-055)；行动侧沿[TL-30逐步支付](../../action-card-system/rules.md#tl-30-制造材料与效果支付分阶段)。只读不占用；取整未缩短D仍收费，见时间公式。

## 5. 与生产、队列的关系

缩短D可能增加批次数，不改每批张数、当前承诺或旧牌；开工检查材料与必要标记，不预留成品容量。完工依TL-05先入对应手牌组，不自动上桌、不烧新牌；末拍产物可由玩家放上本轮尚未开始列。加速的价值要看实际保留／使用的牌，不按产量面板直接判收益。

## 6. 强弱与效果表达

稀有度表达强弱，其余直接写用途、条件、代价，不另设用途／获取阶段等级。实际名称、档数、预算、投放与价格见[TL-Q06／INS-Q06](../../../../governance/questions.md)。
