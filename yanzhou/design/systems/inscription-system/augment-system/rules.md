# 辅槽系统：规则

2026-10-11 · QualifiedFramework；已采纳冻结、公式与支付接口沿CORE-055—057。[状态与来源](../../../baseline.md)。

[设计](design.md) · [体验](experience.md) · [示例](examples.md)

## 1. 装配与作用归属

辅槽修饰本法器的合法核心，可留空。挂接位置、实际槽数及兼容逐法器声明；一枚实体只装一处。修饰不能补缺失核心。打造容量与取得铭文分别处理。

## 2. 修改权限

| 位置 | 允许修改 | 内容须声明 |
| --- | --- | --- |
| 本法器D | 固定时间或耗时倍率 | 条件、有效贡献、必要费用 |
| 本法器已有行动量值 | 明确效果中的数值 | 修改哪个量、何时读取 |
| 简单标记条件／支付 | 读取或足额消费，换取上述变化 | 宿主、种类、条件／费用、结果、失败分支 |

辅槽不修改制造耗材、每批张数、全局Q、目标资格、行动类别或新增事件。D用[唯一公式](../../artifact-system/rules.md#时间修饰公式core-056)，普通量值用资源TL-37。

## 3. 辅槽跨法器修饰通过标记协同

A的行动产生标记，B按自身声明读取／支付，结果归B。不直接把A的倍率给B。材料在法器间流转是独立的资源链；标记仍只附着于玩家／敌人。

## 4. 检查成功才支付

开工侧同时检查配置、完整材料、容量及全部必要标记。成功足额冻结，完工扣除；缺料、缺位或必需费用不足则等待，本次不部分承诺。明确打断只释放仍有效部分，下拍可用。只读条件不占用。

行动侧费用在相应步骤足额支付，不提前冻结。失败不部分支付，只有内容明示可选且允许基础回退才不增强继续。玩家锁定量不供自动消费。启用的付费时间效果即使取整未缩短D仍收费，预告显示实际结果与费用。

## 5. 与生产、队列的关系

加速不免除材料或容量检查，完工仍入普通队列、最早下拍生效。更短D可能增加批次数，但不增加每批张数，不改已有承诺或队列牌。

## 6. 强弱与效果表达

稀有度表达强弱，其余直接写用途、条件与代价；不另设用途等级或获取阶段等级。名称、档数、预算、投放与价格统一见[TL-Q06／INS-Q06](../../../../governance/questions.md)。
