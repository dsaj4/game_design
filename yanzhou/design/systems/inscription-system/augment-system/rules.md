# 辅助道具：规则

2026-10-31 · CurrentSpec / CORE-069 spatial-auxiliaries.1。[采纳依据](../../../../sources/draft-changes/D-2026-10-31-spatial-auxiliaries.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)。沿用augment-system路径，现行实体已替换辅槽；旧标记付费等扩展仍按其原资格及具体内容启用。

## 1. 装配与作用归属

辅助是独立配置实体，与法器、专属供料区共享有限生产格；实体不得越界或重叠，不作供料材料，也不进入战斗手牌。战前部署、旋转、撤回库存；开战后位置、朝向及连接本战固定，不随生产消耗。未部署者不生效，一实体一位置，不复制。

首批每件只有一个指向正交相邻格的可见接口，随实体按90°旋转，不默认镜像；效果指示不额外占格。指向法器本体任一格且兼容本器当前用途即可生效，不要求法器具有固定接收槽；不能以材料、供料区、嵌入核心或另一辅助为目标。空格、包外或不兼容目标显示无效，可保留合法占格摆放，不使合法核心失效。一件只指向一器，多格法器仍按一个实例计。

辅助可不部署，不能补缺失核心。核心装配与兼容沿[铭文TL-26／28／41](../rules.md)；固定辅槽数量、词性挂接和打造容量已退出。

## 2. 修改权限

| 可修改 | 内容须声明 |
| --- | --- |
| 本法器D：固定时间／耗时倍率 | 兼容用途、参数、有效贡献及运算 |
| 本法器已有行动量值 | 具体步骤与参数、修饰值和读取时点 |

首批每件静态修改一个已有参数，无独立运行耗材、计时器或维护费。核心铭文继续决定合法组合；辅助不再按形容词／副词挂接原词。

不能改制造耗材、每批张数、桌面X、卡的战斗／回收权限或手牌规则、目标资格、类别或新增事件。D按[时间公式](../../artifact-system/rules.md#时间修饰公式core-056)，普通量值按[TL-37](../../resource-system/rules.md#tl-37-参数来源与有限事件的共同合同)。

## 3. 多件叠加与来源

多件合法连接同一法器的辅助共同生效，同名／同效果可叠加，固定减时与耗时倍率可同时参与；不同效果也可并存。不设每组限一件、自动择强或手动择一规则。每件独立占格、每个实例只计一次贡献，不因法器占多格重复计数，也不与辅助互相强化。

D沿固定量合计、倍率连乘、最终一次取整且至少1拍的公式；普通量值沿TL-37，固定增量合计，多倍率须有具体内容合成声明。保留其他合法核心／契合贡献，不互读中间结果。空间、数值、价格与内容预算承担强度约束；未定义通用叠加上限或递减，不自行补入。

## 4. 标记协同与付费扩展

首批静态辅助不额外发行标记付费能力。后续实际采用简单标记读取／支付时，须声明宿主、种类、条件或费用、结果及失败；既有权限不因更换承载而扩大。

A行动产标记，B按自身声明读取／支付，结果归B；不直接转送A的倍率。材料流转是另一条资源链，标记仅附玩家／敌人。

开工侧沿[TL-05联合检查](../../artifact-system/rules.md#tl-05-开工预留与完成入行)和[标记冻结](../../action-card-system/mark-system/rules.md#批次标记冻结core-055)；行动侧沿[TL-30逐步支付](../../action-card-system/rules.md#tl-30-制造材料与效果支付分阶段)。只读不占用；取整未缩短D仍收费，见时间公式。

联合检查成功才冻结完整开工费用，幸存完工扣除；必要条件不足等待，仅明示可选并有基础回退时可不增强运行。行动逐步检查目标与足额费用，不部分支付，不因未获预期收益退还已成支付。

## 5. 与生产、队列的关系

开工冻结D及本批静态辅助贡献，由本批生成的卡继承；只增强本法器新产物，不追溯已有手牌、初始牌或其他法器产物。冻结的是辅助贡献，不是未来目标、最终伤害、行动条件或费用。回收再用保留同一份合计贡献，不重新加算；成品作为普通材料再加工不自动向新产物传递修饰。打断批次不补产物、不消耗或退还辅助实体。

缩短D可能增加批次数，不改每批张数、当前承诺或旧牌；开工检查材料与必要标记，不预留成品容量。完工依TL-05先入对应手牌组，不自动上桌、不烧新牌；末拍产物可由玩家放上本轮尚未开始列。加速的价值要看实际保留／使用的牌，不按产量面板直接判收益。

## 6. 强弱与效果表达

稀有度表达强弱，其余直接写用途、条件、代价，不另设用途／获取阶段等级。实际名称、档数、预算、投放与价格见[TL-Q06／INS-Q06](../../../../governance/questions.md)。

战前同时展示实体占格、效果指向、目标、各件贡献和合计结果；法器可反查来源。区分无目标、不兼容、取整或下限造成的无收益，不只依赖颜色。展示最终D和结合待料的最早产出拍，不把百分比当成实际提前出牌。

## 7. 本局持有与恢复

辅助按配置库存本局跨战保留；胜利后可在下战重新部署，不套用材料携带标签／容量，未部署库存无本战效果。普通失败结束本局，具体取得与价格由内容声明；不新增磨损、随机损毁或自动升级。可携带成品战后按TL-25重置本战临时辅助增幅，实体持有与效果留存分开。

保存唯一实体身份、占形、位置、朝向、受益目标及贡献来源，以及批次／成品牌已记录的合计贡献；恢复不重复施加，战前换核心或重排立即重核兼容和预览。旧辅槽存档不隐式转为新空间布局，版本不兼容保留原档并说明。
