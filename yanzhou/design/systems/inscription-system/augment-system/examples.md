## 标记协同关系

依据：[跨法器只通过标记协同](rules.md#3-跨法器只通过标记协同)，AUG-Q2／3。

```text
法器 A 的行动 → 依已声明效果形成标记
                         ↓
法器 B 的辅槽读取／支付标记 → 修饰 B 的生成时间或行动量值
```

这只是接口关系，不新增标记种类、叠层上限或具体辅槽。

## 边界例

| 情境 | 可确定的结果 | 本例没有确定什么 |
| --- | --- | --- |
| 核心完整合法，辅槽留空 | 不因空辅槽禁止生产，继续按既有生产条件检查 | 不保证当前有材料或容量 |
| 开工侧增强需要标记，但当前队列无可用容量 | 不开工，不扣标记 | 不决定标记充足时具体怎样缩短 D |
| 效果要求 n 层标记，现有层数少于 n | 不部分扣除，不产生足额支付才有的增强 | 不决定该法器等待还是走基础分支 |
| 生成时间缩短，但行动仍排在已有牌后 | 普通队列与每拍上限继续约束实际生效 | 不保证提前生效或整场收益提高 |
| A 形成标记，B 按自身效果合法支付 | 修饰结果归 B 的时间或行动量值 | 不把 A 的辅槽倍率带给 B |

以上为规则边界示例，不是发行卡效、数值方案或玩法测试结果。


依据：[装配、权限、支付与普通队列边界](rules.md)。示例从原规则页迁出，原确认范围不变。
