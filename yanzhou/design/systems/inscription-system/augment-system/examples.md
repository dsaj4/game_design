## 标记协同关系

依据：[辅槽跨法器修饰通过标记协同](rules.md#3-跨法器只通过标记协同)，AUG-Q2／3。

```text
法器 A 的行动 → 依已声明效果形成标记
                         ↓
法器 B 的辅槽读取／支付标记 → 修饰 B 的生成时间或行动量值
```

这只是接口关系，不新增标记种类、叠层上限或具体辅槽。

## 边界例

| 情境 | 可确定的结果 | 本例没有确定什么 |
| --- | --- | --- |
| 核心完整合法，辅槽留空 | 不因空辅槽禁止生产，继续按既有生产条件检查 | 不保证当前有材料或容量 |
| 开工侧增强需要标记，但当前队列无可用容量 | 不开工，不冻结也不扣标记 | 不决定标记充足时具体怎样缩短 D |
| 效果要求 n 层标记，现有层数少于 n | 不部分扣除，不产生足额支付才有的增强 | CORE-055：开工必需不足等待；仅明示可选并允许基础回退才不增强继续 |
| 生成时间缩短，但行动仍排在已有牌后 | 普通队列与每拍上限继续约束实际生效 | 不保证提前生效或整场收益提高 |
| A 形成标记，B 按自身效果合法支付 | 修饰结果归 B 的时间或行动量值 | 不把 A 的辅槽倍率带给 B |

以上为规则边界示例，不是发行卡效、数值方案或玩法测试结果。

## 时间修饰与付费门槛（CORE-056）

以下依据[时间公式](../../artifact-system/rules.md#时间修饰公式core-056)，均为Illustrative／Derived／NotRun，不发行具体卡效。

| 合法输入 | 结果 | 边界 |
| --- | --- | --- |
| D0=8、固定−2拍、两个不同生效效果倍率0.8与0.75 | 6×0.8×0.75=3.6，最终D=4 | 先固定后倍率；不是把−20%与−25%合为−45% |
| D0=8，无固定修正，倍率0.8与0.8 | 8×0.64=5.12，D=6 | 两个独立有效倍率连乘，不是0.6；不据此把同一Buff的两层当两项 |
| D0=8，倍率0.8与0.75 | 4.8，D=5 | 不先把6.4取整成7，否则会错误得到6拍 |
| 某效果明确“层数仅代表持续时间、有效时耗时×0.8”，当前3层，D0=8 | 本批只取一次0.8，D=7 | 此为已声明内容的条件例；不替所有标记选持续层数规则 |
| D0=3、已启用付费修饰×0.9，条件与费用齐备 | 2.7向上取整仍D=3，按声明冻结／完工扣费 | 预告提示未缩短，不自动免单或改成基础分支 |
| D0=1、已启用付费修饰×0.5 | 最低D=1，费用按声明处理 | 不产生0拍或半拍；必要标记被锁住仍不能开工 |
