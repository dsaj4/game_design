# 辅槽子系统：玩家体验

Project ID：game-002。文档角色：ExperienceHypothesis。修订：2026-10-08 / augment-framework.1。证据：**Hypothesis / NotRun**。来源：[通用框架素材](../../../../sources/materials/M-2026-10-08-augment-framework.md)。

[入口](README.md) · [已确认规则](rules.md) · [设计](design.md)

本页回答辅槽是否能让玩家作出有理由的选择，并看见成长。规则检查通过只能说明结果符合规格，不能证明选择有趣、成长清楚或理解成本更低。以下关系需要后续内容和观察支持。

## 1. 时间与量值能否形成情境取舍

**机制**：生成时间与行动量值是主要修饰位置；材料消耗和每批张数不由辅槽修改，行动仍受普通队列约束。

**可能行为**：玩家比较截止窗口、缺料／缺位情况与单次行动价值，在更早生成和更强单次效果之间调整配置。

**预期体验**：能说明当前为什么选择某个辅槽，换一个情境时有理由选择另一个。

**观察**：比较相近获取条件、同稀有度的不同用途，记录玩家选择及理由，并对照实际开工、完工和生效时刻。

**不支持该假设的信号**：所有代表情境都由同一效果占优；玩家只是追逐面板数字；D 变小却长期没有可辨认结果。需要区分内容失衡、队列瓶颈与说明误导，不能直接判成玩家没有理解。

## 2. 标记协同能否形成可理解的组合

**机制**：行动形成标记，本法器按明确条件读取或支付；直接跨法器加成被排除。

**可能行为**：玩家安排哪些行动提供标记、哪台法器使用，比较现在增强与保留标记的后续价值。

**预期体验**：能够把组合效果归因到具体来源和消费，同时感到配置之间有联系。

**观察**：让玩家解释一次收益来自哪张行动、哪个标记、谁支付、谁得到修饰；对照标记来源与支付记录。

**不支持该假设的信号**：玩家以为倍率自动传递；标记被消费后难以解释；组合收益只有在频繁盯盘或反复调整供料时才能成立。自动消费的等待／回退规则未定前，不能预先承诺“无额外操作负担”。

## 3. 稀有度能否同时表达成长并保留适配判断

**机制**：稀有度表达强弱，具体效果说明用途、条件和代价。

**可能行为**：玩家能辨认成长，同时仍会根据当前法器、队列和标记条件判断适配。

**预期体验**：得到更强修饰时看见实际改变，也能解释为什么某个用途更适合当前构筑。

**观察**：先比较同稀有度的用途选择，再比较同方向跨稀有度的实际结果；记录离散取整、D 下限与材料瓶颈是否抹掉差别。

**不支持该假设的信号**：稀有度升级只改标签而实际结果相同；强弱标识长期与效果相反；高稀有度内容使所有配置只剩同一答案。具体预算与投放未确定，本页不给强度百分比或胜率目标。

## 4. 支付与反馈能否支持预测

**机制**：必要条件检查成功才扣标记；生成完成与行动生效分开。

**可能行为**：玩家在配置或观察时预测是否会支付、何时可能兑现，并根据失败原因调整。

**预期体验**：代价和结果有清楚因果，失败可以理解。

**观察**：分别询问缺标记、缺容量、已付后中断、已完成但排队等情境中的预期，和已闭合的规则结果对照。

**不支持该假设的信号**：把完工当生效、把缺位当标记不足、认为材料退款必然包含标记退款；即使界面说明正确仍无法解释。未决退款与失败分支须先在设计页完成，不能把尚无答案的题目算作玩家理解失败。

## 验证前提与记录边界

以上均未运行。后续验证需先固定合法法器、辅槽效果、稀有度预算、获取条件、标记生命周期和必要结算接口，再获得实验任务授权。

规则核对保留支付前后状态、来源、开工／完工／生效时刻与失败原因；体验观察另外记录选择理由、预测是否准确及操作频率。结论只覆盖实际输入和观察情境，不由理论引用或文档完成推定成功。
