# 辅槽：体验目标

2026-10-11 · Hypothesis / NotRun。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 选择有情境 | 同一装配机会在不同局面有不同理由 | 所有场景只追同一效果 |
| 增强看得见 | 更强替换改变实际行动结果 | 取整、下限或排队吃掉所有成长 |
| 协同能解释 | 说出标记来源、消费者和剩余用途 | 以为共享所有法器倍率 |
| 自动支付可预测 | 解释冻结、完工扣费和中断释放 | 必须反复锁解才能维持普通循环 |

观察时先记录玩家预测与选择理由，再对照实际结果。分开记录规则误读、信息找不到、数值失衡；使用具体内容和界面版本。验证任务尚未执行。
