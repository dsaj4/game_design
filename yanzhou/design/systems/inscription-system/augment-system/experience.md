# 辅助道具：体验目标

2026-10-31 · Hypothesis / NotRun。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 选择有情境 | 随需求改变集中强化、分给多器或扩大供料的选择 | 同一辅助组合永远必放，空间成为固定税 |
| 增强看得见 | 更强替换改变实际行动结果 | 取整／下限抹平数值收益，或更多产物只在手中积累、没有改善实际用牌 |
| 来源能解释 | 指出每件辅助的受益者、合计贡献与成品继承 | 以为作用格占空间、邻接材料也获益，或回手再次叠加 |
| 未来付费扩展可预测 | 实际发行后能解释冻结、完工扣费和中断释放 | 必须反复锁解才能维持普通循环；首批静态辅助不以此为功能需求 |

观察时先记录玩家预测与选择理由，再对照实际结果。分开记录规则误读、信息找不到、数值失衡；使用具体内容和界面版本。验证任务尚未执行。
