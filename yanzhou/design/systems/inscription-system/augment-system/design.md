# 辅槽：设计

2026-10-27 · DesignNote。AUG-Q1—5、INS-I4／5 为已确认方向。 [版本与来源](../../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

保留主逻辑，为同一方案选择强化侧重。

| 设计重点 | 内容 |
| --- | --- |
| 价值顺序 | 取舍为主、成长并存。比较一个装配机会用于更早生成、单次量值或标记条件的收益；无需每项附负面词条。 |
| 主副差异 | 副铭文修改本法器D或已有行动量值；核心调整配方逻辑。升级按替换更适配或更高稀有度副铭文理解。 |
| 组合归因 | 沿“谁产生标记—谁使用—谁获益”解释协同。资源流转另按资源规则。 |
| 成长表达 | 稀有度表达强弱，其余直接写效果、条件、代价。比较同稀有度用途，再比较同方向成长。 |
| 反馈 | 配置展示基础值、修正、最终值及支付；实战区分缺开工条件、完工入手、因未开始列已占用或主动留手而尚未使用、以及实际卡效生效；行满不挡加工。 |

待决与风险统一见[问题登记](../../../../governance/questions.md)：INS-Q04—06、TL-Q02／06。
