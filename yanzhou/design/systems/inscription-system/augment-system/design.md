# 辅助道具：设计

2026-10-31 · DesignNote / CORE-069；玩法价值仍Hypothesis。 [版本与来源](../../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

保留主逻辑，为同一方案选择强化侧重。

| 设计重点 | 内容 |
| --- | --- |
| 价值顺序 | 取舍为主、成长并存。比较同一片面积用于增加法器、扩大供料、集中或分散辅助的收益；无需每项附负面词条。 |
| 核心与辅助 | 核心决定合法组合，可拆装且嵌入不另占格；辅助独立占格，首批静态修改一个已有参数，同效可叠加，强度由实际内容预算控制。 |
| 组合归因 | 首批沿“哪件辅助—指向哪器—哪些批次与成品继承”解释贡献；未来采用标记协同时再分清产生与支付。资源流转另按资源规则。 |
| 成长表达 | 稀有度表达强弱，其余直接写效果、条件、代价。比较同稀有度用途，再比较同方向成长。 |
| 反馈 | 配置展示占格／指向、各件贡献、叠加后最终值和无效原因；实战区分缺开工条件、完工入手、因未开始列已占用或主动留手而尚未使用、以及实际卡效生效；行满不挡加工。 |

待决与风险统一见[问题登记](../../../../governance/questions.md)：INS-Q04／06、BP-Q01、TL-Q02／06。
