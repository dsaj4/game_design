# 铭文：设计

2026-10-11 · DesignNote。INS-I1—5 为已确认设计意图；发现与知识保存的落地见 INS-Q07。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

用可学习的配方语言组织法器与行动。

| 设计重点 | 内容 |
| --- | --- |
| 三项职责 | 核心词解释配方在做什么；组合尝试帮助发现合法配方；共享词义帮助迁移知识和调整搭配。 |
| 核心与辅助分工 | CORE-069保留核心合法组合；战前在背包中可逆装配，嵌入不另占格。独立辅助道具承担空间强化，首批只改已有参数；同效可叠加。 |
| 实体分配 | 用实际持有铭文装配，一枚实体只占一处。材料负责每批运行成本，标记负责宿主状态与协同。 |
| 发现方向 | 基本语义可读，未知合法组合不预先列全；用持有实体免费试配，反馈成立与否，成立后可读行动和制造要求。 |
| 知识方向 | 已发现知识可长期查阅，服务后续推理和部署；知识不赠组件。 |
| 风格 | 简单清晰、有神秘感、尽量符号化。反馈帮助解释结果，避免只能背密码或穷举。 |
| 编辑反馈 | 分开缺核心、不兼容、重复占用和缺料；显示基础词义、器具预设、各件辅助与契合各自贡献。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：INS-Q01—04／06—07；INS-Q05旧辅槽打造已淘汰。
