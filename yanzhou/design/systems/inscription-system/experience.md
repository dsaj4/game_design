# 铭文：体验目标

2026-10-11 · Hypothesis / NotRun。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 配方可推理 | 先预测，再用反馈改善下一次尝试 | 遍历组合，结果没有可解释共性 |
| 知识可迁移 | 将同一词义用于新器具 | 每个组合都需孤立记忆 |
| 装配可理解 | 区分核心缺项、实体占用和材料不足 | 换铭文试图修复供料不足 |
| 发现后仍有选择 | 旧知识用于当前库存的不同部署 | 记录只剩唯一最优配方清单 |

观察时先记录玩家预测与选择理由，再对照实际结果。分开记录规则误读、信息找不到、数值失衡；使用具体内容和界面版本。验证任务尚未执行。
