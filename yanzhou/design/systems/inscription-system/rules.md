# 铭文系统：规则

2026-10-31 · CurrentSpec / CORE-069。[状态与来源](../../baseline.md)。

[设计](design.md) · [体验](experience.md) · [示例](examples.md)

## TL-39 暗句与核心空缺

法器预设名词／动词组合，只开放声明的核心空缺。填入词性由预设决定，不要求玩家恰填一名一动。核心不含对象类别或材料类别；效果目标由行动声明，材料由配方声明。

合法性同时满足语义和器具兼容表。同词性或自然语言通顺不构成兼容；暗句没有额外隐藏整句奖励。

## TL-40 核心必填与有限兼容

铭刻的全部核心空缺必填，核心槽不可打造。缺核心、不兼容时该铭刻用途不执行；完整合法但暂缺材料时等待。法器另有明示基础加工用途时，按其自身资格运行；开战仍至少需要一台合法铭刻法器。

<a id="tl-41-辅槽修饰与预设挂接"></a>
## TL-41 辅助道具与空间连接

辅助可选部署，独立占格，通过一个可旋转相邻接口指向兼容法器；多件同效可叠加，不设固定辅助槽数或预设词性挂接。无辅助或辅助无有效目标不阻止合法核心运行，辅助不能补核心、改材料或目标资格。权威细则见[辅助道具](augment-system/rules.md)。

## TL-02 配置与批次承诺

法器反复执行当前合法核心及战前辅助配置；制造配方、供料接口和卡效各自声明。CORE-059允许同一合法铭刻声明有限固定用途，CORE-068改为战前择一、本战固定；批次开工后保留用途、投入、产出和预设。当前战中不提供重铭操作。CORE-067的免费布牌只改卡牌位置／所在区，不改当前批次、卡效、目标选择规则或来源。

己方行动在生效时按本批预设自动选目标；敌后续打断在生成时锁定；普通伤害按其执行列的内容确定目标。加工开始不额外选敌。名单确定后不补位，逐项复查，已完成结果不回滚。

## TL-26 实体铭文与词义

同一铭文保持已声明词义；法器预设、修饰和契合分别说明变化来源。实体持续占用本局库存，一实体一位置；循环不消耗铭文。同名多位置需要真实副本，副本不自动合并升级。未装配实体留库存，在战前允许的编辑中重配。

CORE-069：通过背包拖放到兼容法器，预览完整动作、配方、D及条件后明确提交；提供等价点击／键盘路径。装配可在战前拆回真实库存，铭文不永久消耗，嵌入后不另占生产格；战中不拆换。保留所有预设核心空缺，不简化为每器一枚。非法配对拒绝、不吞实体；换核心前若有待料，预告并随确认退回手牌，再复核配方、供料及辅助兼容，不静默沿旧配方开工。

持有铭文、持有材料、制造成功和效果命中是不同条件。读取不产生消费；词性、语义角色、行动类别分别判断。

## TL-27 卡效的实例、条件绑定与本次名单

| 绑定 | 规则 |
| --- | --- |
| 实例 | 保存唯一身份；同名新对象不替换消失实例，战前悬空引用须修正 |
| 条件 | 保存选择规则，生效时选当前合法对象；后续新对象只能在后续行动入选 |
| 名单 | 先核身份、能力、状态，再按已声明的全部／单个／限量选择；单个／限量优先级必须写明 |
| 去重与配对 | 同角色同一步按实例去重；跨角色配对明确声明，不默认全排列 |
| 执行 | 逐项复查、不补位、不回滚已完成结果；无目标按TL-21空放 |

## TL-28 修饰兼容

核心语义／器具兼容沿TL-39／40；辅助按声明的法器、当前用途和具体参数判定，不再使用副铭文形容词／副词挂接。每件只作用一个法器，不扩散到同名法器或递归增强辅助。

兼容判断依次为明确不兼容、专属适配、通用效果；同一来源的专属适配替代对应通用贡献，不把同一件计两次，也不排除其他合法实体。多件同效果可叠加，具体运算沿辅助规则及TL-37。修饰不永久覆盖词义，首批只改一个已有参数，不新增步骤／事件。

<a id="tl-42-辅槽打造"></a>
## TL-42 退役：辅槽打造

CORE-069取消辅槽及其新增／解锁容量流程，本ID退役不复用。核心槽仍不可打造；辅助取得由实际内容声明，不等于建槽或免费发件。INS-Q05原打造待办随功能淘汰，不转为辅助的隐含费用。
