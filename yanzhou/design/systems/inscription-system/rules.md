# 铭文系统：规则

2026-10-31 · CurrentSpec。[状态与来源](../../baseline.md)。

[设计](design.md) · [体验](experience.md) · [示例](examples.md)

## TL-39 暗句与核心空缺

法器预设名词／动词组合，只开放声明的核心空缺。填入词性由预设决定，不要求玩家恰填一名一动。核心不含对象类别或材料类别；效果目标由行动声明，材料由配方声明。

合法性同时满足语义和器具兼容表。同词性或自然语言通顺不构成兼容；暗句没有额外隐藏整句奖励。

## TL-40 核心必填与有限兼容

铭刻的全部核心空缺必填，核心槽不可打造。缺核心、不兼容时该铭刻用途不执行；完整合法但暂缺材料时等待。法器另有明示基础加工用途时，按其自身资格运行；开战仍至少需要一台合法铭刻法器。

## TL-41 辅槽、修饰与预设挂接

辅槽可空，不阻止合法核心运行。每个辅槽预设挂接位置／词义及兼容修饰；不能借此增加核心词义、选材或改目标。实际槽数逐器具声明，原则上不多于核心槽，例外须明确采纳。

## TL-02 配置与批次承诺

法器反复执行当前合法核心及辅槽配置；制造配方、供料接口和卡效各自声明。CORE-059允许同一合法铭刻声明有限固定用途，CORE-068改为战前择一、本战固定；批次开工后保留用途、投入、产出和预设。当前战中不提供重铭操作。CORE-067的免费布牌只改卡牌位置／所在区，不改当前批次、卡效、目标选择规则或来源。

己方行动在生效时按本批预设自动选目标；敌后续打断在生成时锁定；普通伤害按其执行列的内容确定目标。加工开始不额外选敌。名单确定后不补位，逐项复查，已完成结果不回滚。

## TL-26 实体铭文与词义

同一铭文保持已声明词义；法器预设、修饰和契合分别说明变化来源。实体持续占用本局库存，一实体一位置；循环不消耗铭文。同名多位置需要真实副本，副本不自动合并升级。未装配实体留库存，在战前允许的编辑中重配。

持有铭文、持有材料、制造成功和效果命中是不同条件。读取不产生消费；词性、语义角色、行动类别分别判断。

## TL-27 卡效的实例、条件绑定与本次名单

| 绑定 | 规则 |
| --- | --- |
| 实例 | 保存唯一身份；同名新对象不替换消失实例，战前悬空引用须修正 |
| 条件 | 保存选择规则，生效时选当前合法对象；后续新对象只能在后续行动入选 |
| 名单 | 先核身份、能力、状态，再按已声明的全部／单个／限量选择；单个／限量优先级必须写明 |
| 去重与配对 | 同角色同一步按实例去重；跨角色配对明确声明，不默认全排列 |
| 执行 | 逐项复查、不补位、不回滚已完成结果；无目标按TL-21空放 |

## TL-28 修饰兼容

形容修饰挂名词，副词修饰挂动词；每个实体直接作用一个预设原词位置，不递归修饰其他修饰词，也不扩散到同名词。

兼容判断依次为明确不兼容、专属适配、通用效果；专属替代对应通用。多辅槽冲突与叠加逐内容声明。修饰改变本次参数或步骤，不永久覆盖词义；数量与额外事件必须明示。

## TL-42 辅槽打造

打造可新增／解锁辅槽，核心不可打造；新增槽位不赠修饰铭文。具体费用、时机、取消和持久范围集中见[INS-Q05](../../../governance/questions.md)，当前不提供未定义的打造操作。
