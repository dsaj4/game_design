# 敌人系统：规则

2026-10-11 · CurrentSpec，SYS-005。[状态与来源](../../baseline.md)。

[设计](design.md) · [体验](experience.md) · [示例](examples.md)

## TL-16 敌方程序约束

每场只有1名来源敌人，负责全部敌牌。开战前程序固定：每牌有位置、循环内翻开偏移、正延迟Δ，循环长度L。取消或玩家操作不移动程序，跨段保留旧倒计时。

开战公开位置、翻开拍及卡背种类，r拍揭示完整效果、目标、T=r+Δ和可取消条件并锁定。敌人不临时读取玩家选择改牌；指定打断读取公开加工状态只用于锁定法器，按行动TL-09执行。

取消留空档，不提前后续牌或补发。目标失效按落空处理。敌牌不占玩家队列，不使用玩家生产系统。

## 必需字段

| 对象 | 字段 |
| --- | --- |
| 来源敌人 | 唯一身份、地域牌组、生命与护甲 |
| 每张敌牌 | 种类、程序位置、翻开偏移、正延迟、效果／量、锁定规则、可取消条件 |
| 遭遇程序 | 循环L、全部到期拍、段尾遗留及跨轮碰撞检查 |
| 环境初态 | 玩家真实套组、起始材料、基础供给；零材料／无供给须明确 |
| 双威胁 | 各自截止、普通循环处理哪项、另一项的实际应对路线 |

## 首版内容约束

- 任意两敌牌T不同，含跨循环；允许段尾遗留。
- 来源敌人只有生命，不使用护甲、防御■／其他✱敌牌或附属物。
- 基准打断Δ≥预期玩家套组最长D，锁定时当前批次可先完成，压力落在后来续开。
- 特色“截击”满足Δ≤目标剩余R，使当前批次无法先完成；截击双威胁须满足T伤≥r断+D防+1，并另查材料、容量和队列。

## 应对窗口核对

若r拍法器空闲、料与容量齐备、无前方排队，r拍末开工，r+D完工，最早e=r+D+1生效。

| 行动 | 条件 |
| --- | --- |
| 新起手防护 | e≤T；理想条件Δ≥D防+1，效果须能挡对应威胁 |
| 新起手取消 | e<T；理想条件Δ≥D取消+2 |
| 有等待 | 依等料／等位／排队顺延e，再检查原截止 |

正延迟不是任意局面都有补救的保证。无取消法术时只能使用实际已有的承受、防护或生产调整路线。零材料用途不能凭停供材料调时。

## 敌情信息合同

出发前显示下一可选敌人类型与主机制；开战显示翻开表／种类；揭示后显示完整效果、锁定或无锁定、T、取消条件。锁定打断显示危险开工带[T−D,T−1]与真实预测；适用停供方案结束拍须≥T。

所有种类用攻击▲、防御■、打断⊘、其他✱配文字。地域只改花色、材质、配色及装饰，保留通用符号轮廓／位置／含义；形态不泄露未揭示Δ、量值或目标。

## 跨系统接口

锁定法器到期无批次则落空一次，不改选、不转伤害；护甲不自动挡打断。打断与返工沿法器TL-07；同拍组序、复合事件、终局沿行动TL-11／13。玩家存活且来源死亡才胜，同检查点双亡玩家败，未到期牌随终局作废。

暂停冻结双方，恢复保留程序、锁定及倒计时。标记宿主可为敌人，实际敌人标记内容仍需完整声明；不改首版内容限制。[缺口](../../../governance/questions.md)统一登记，实际敌表见[内容目录](../../content/enemies-encounters.md)。
