# 敌人系统：规则

2026-10-27 · CurrentSpec / CORE-065 round-hand.1，SYS-005。[基准](../../baseline.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

## TL-16 敌方程序约束

一场只有1名来源敌人。开战前固定按回合的基础X位表及循环长度（单位为回合），X初始5；敌人不根据玩家最后布局临时改牌。每个位置是一项原生即时／延时牌，当前完整实例见[EX-004](../../examples/round-first-battle.md#4-敌牌基础表与覆盖)，不能搬用旧L16及r／Δ／T。

回合开始，把上一回合生成的k张后续牌按生成顺序放位置1—k；位置k+1—X取**该回合基础表同位置的牌**。基础表1—k项本轮跳过、不排到以后、不形成欠牌；本轮基础表照常消耗一次循环位置。首回合k=0。后续牌跨基础表循环边界照常优先，不复制、不重置。

原生牌暗置，只公开位置、类别和即时／延时标识。即时牌在其列翻开并执行普通伤害；延时牌在其列生成对应后续行动，进入敌手牌，资格为下一回合。生成不同时执行后续效果；该后续从生成起公开完整效果、目标／无对象及可用回合，下轮保持公开。

首版每张延时牌至多生成1张后续牌，后续牌不递归生成，因此一轮至多X张、全部下轮放完；不按玩家手牌操作或回收；玩家H3已由CORE-067取消。敌手牌只容纳已声明的下一回合后续，不新增任意囤积、叠同列或途中插牌权限。

## 必需字段

| 对象 | 字段 |
| --- | --- |
| 来源敌人 | 唯一身份、地域牌组、生命；首版不启用护甲 |
| 基础表 | 按回合的全部X位，循环回合数；即时／延时、类别、完整效果与量、目标、可取消范围 |
| 延时／后续对 | 生成步骤及对应行动身份、完整效果、下一回合资格、生成序、目标锁定时点与空对象失败；不得递归生成 |
| 环境初态 | 真实玩家套组、D、初始两组手牌／桌面、材料与可运行路线；零材料／无补给须明示 |
| 风险与应对 | 牌背能支持哪些准备、后续牌在哪列、生产能否赶上、卡效费用及放弃项；不能以“有预告”代替实际可达性 |

## 首版内容约束

- 原生即时牌仅普通伤害；指定法器打断用延时生成，后续可为已声明的伤害或打断。
- 不启用敌护甲、防御／其他类牌、附属物；即时／延时是时间行为标识，不替代攻击▲／打断⊘类别。
- 不叠同列，不在生产拍途中补敌牌，不临时针对玩家布局改变程序。
- 取消只作用更右列的已公开后续牌，目标列开始前完成，留空不补。详见[TL-10](../../GDD.md#tl-10-取消敌牌)；首场尚无取消卡。

## 应对窗口核对

即时牌到执行才公开完整内容，玩家只能按其牌背类型提前准备。后续牌至少在上轮生成后已知，能在下一回合生产与最终整理中据此安排；并不保证真实套组、材料与实际卡效足以应对。

同列已有防护先于敌方其余步骤，后列防护不提前；取消必须处于目标更左列且有合法权限。新起手能否完工进桌面、能否在合法窗口手动上行、回手后是否还有未开始列，逐项按真实状态检查，不再用Δ≥D+1／2推断。

## 敌情信息合同

出发前显示下一可选敌人类型与主机制；战斗只公开当前行的合法信息和已生成的下一轮后续。原生暗牌不通过详情、历史、尺寸、纹饰或预览泄露量值、效果和目标。后续牌显示已知内容、所在／将进入回合、生成顺序及锁定对象，不能重新伪装成未知。

种类符号和文字一致，地域只改外观。打断生成时按[TL-09](../action-card-system/rules.md#tl-09-敌牌揭示与锁定)锁最长剩余加工法器，后续执行时只作用原法器的当前批次；无对象或批次落空一次，不改选、不转伤害。旧[T−D,T−1]危险带不适用于新结算列。

## 跨系统接口

加工在列间冻结，打断不追溯本回合已经完工的牌；下一生产拍才重新检查开工。逐完整事件检查终局，玩家存活且唯一来源死亡才胜，同点双亡玩家败。终局不执行余下效果，敌手牌作废；玩家实际卡按回收／使用事实及独立携带资格清理，不把只读结果计成副本。

恢复保持同一回合基础表位置、替换关系、生成序、原锁定、公开范围与已处理列；不重新布牌、不补被跳过基础牌。真实新敌表见[内容登记](../../content/enemies-encounters.md)，旧EX只能按旧固定规则回归。
