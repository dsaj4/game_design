## 对象、输入与输出

| 对象 | 输入与状态 | 输出与边界 | 权威位置 |
| --- | --- | --- | --- |
| 来源敌人 | 遭遇指定的唯一发牌者、生命与所属地域牌组 | 提供固定程序；胜负还须检查玩家存活及完整事件边界 | 本页 TL-16；行动卡 TL-13／29 |
| 敌方程序 | 暗牌位置、翻开偏移、各牌正延迟 Δ、循环长 L | 按时间表揭示；循环不清除旧倒计时 | 本页 TL-16 |
| 已揭示敌牌 | 翻开拍 r、到期 T＝r＋Δ、完整效果与锁定对象 | 到期结算一次，或在合法取消／终局下结束；不占玩家队列 | 行动卡 TL-09—13 |
| 遭遇环境 | 起始材料与基础供给、玩家实际合法配置 | 决定应对是否有料、有位并能赶上；不是免费应对保证 | 本页字段合同；法器 TL-05／06、资源 TL-14／23 |

时间以拍计；Δ＞0。具体生命、伤害、L、翻开偏移和 Δ 由内容声明，不从说明性示例补默认值。敌人不因拥有行动牌而取得玩家法器的制造、配方或付费干涉机制。

## TL-16 敌方程序约束

- 每场战斗只有一个发出敌牌的来源敌人，其死亡即胜（SYS-003 TL-13）；可有不发牌的附属物，规则另定。
- 开战前预置敌方暗牌程序，采用固定循环时间表：每张暗牌有循环内翻开偏移与Δ，循环长L，不因取消或玩家行为移动。开战即公开程序位置、翻开拍与卡背行动种类，内容在翻开时公开（[CORE-054](../../../sources/draft-changes/D-2026-10-05-stage-two-enemy-pressure.md)）。
- 所有敌方行动牌揭示后按SYS-003启动正延迟倒计时，完整公开并锁定目标；不存在揭示即生效的敌方行动牌。

- 成功取消保留空档，后续程序不提前；段尾循环不清掉旧倒计时。
- 设计应对窗口时，要计算开工前的供料／容量等待、处理耗时与入行后排队；入行后最早下一拍翻开，队列可能更晚，不再加J、R、独立周期或S。取消必须严格早于T；已可生效防护按TL-11可在T拍先结算，不能给两者套同一截止。正延迟为资源改配和未来开工调整提供预警，不保证每个失误后的状态都可挽回。
- 敌方的隐藏信息不代表临时读取玩家选择后改牌；是否及怎样生成程序，具体内容须明示。指定打断按SYS-003 TL-09在翻开时读取公开施法状态锁定法器，属于目标选择，不改变牌的内容。


## 遭遇字段与失败路径

每场至少说明来源敌人身份与所属地域牌组、附属物（如有）、生命／护甲、暗牌程序与卡背种类、翻开偏移、各牌延迟、触发效果、锁定规则、可打断条件、资源供给、起始材料、循环长度和段尾冲突检查。旧敌人“不持有玩家法器”的不对称表达可保留，不能自动赋予敌方完整生产系统。

当玩家没有对应打断法术时，应仍可判断承受损失、保护或调整未来生产的代价；不承诺每套构筑都能取消每张敌牌。单一来源后不再有多敌合并程序；锁定目标失效按SYS-003落空处理。同一来源多牌同刻到期的规则尚未确定，首版内容不安排，不用隐含优先级补齐。

### 必需字段

本表从 [敌人与遭遇内容](../../content/enemies-encounters.md)归位，沿 CORE-054；实际敌人条目仍由内容页维护。

| 新内容 | 必需字段与限制 |
| --- | --- |
| 来源敌人 | 每场唯一；身份、所属地域牌组、生命／护甲；其死亡即胜须沿 SYS-003 TL-13 的完整终局条件 |
| 附属物（可选） | 不发敌牌、不计入胜负；其余规则未定，首版不使用 |
| 普通伤害牌（攻击▲） | 翻开偏移、正延迟、伤害、目标、可否取消；普通掉血不打断法器 |
| 明确打断牌（打断⊘） | 上述信息＋按 SYS-003 TL-09 锁定剩余最长施法所在法器、具体中断范围、可取消条件；无施法或无批次即落空 |
| 防御■／其他✱敌牌 | 首版不使用；其他类须另定通用副记号 |
| 双威胁组合 | 两张牌各自截止、是否需要同时主动操作、普通循环能处理哪一项 |
| 遭遇程序 | 全部牌的翻开偏移、Δ、到期、循环长 L、段尾遗留倒计时与同拍检查 |
| 环境初态 | 基础材料供给、开局材料、高阶料实际获取／加工来源；未定处标 Unknown |

### 首版内容约束

以下为 CORE-054 已采纳约束，不把首版限制外推为所有未来敌人的永久规则：

- 同一遭遇内任意两张敌牌 T 不同；允许段尾遗留，但不与新段任何 T 同拍。
- 首批敌人只有生命，不使用防御类敌牌或敌方护甲。
- 基准打断敌取 Δ 不小于预期玩家套组的最长 D，使被锁定的当前批次总能完成，压力只落在之后的开工选择上。
- “截击”（Δ≤目标剩余 R，当前批次无法再避开）只用于特色敌；截击型双威胁须满足 T_伤 ≥ r_断＋D_防＋1，保留“锁定后再起手防护”的反应路线。翻开表开战即公开，是截击可预见的前提；实际配置仍须核对供料、容量和同拍入行后的排队。

### 应对窗口核对

状态：Derived，沿 [阶段二工作包的窗口关系](../../../sources/inbox/2026-10-05-stage-two-enemy-pressure.md#从已采纳规则推出的窗口关系)，不新增耗时或敌牌参数。

前提：应对法器在揭示拍 r 空闲，完整材料与容量当拍可用，前方无排队，并在 r 的观察窗口提交合法方案。r 拍末开工，r＋D 完成入行，最早生效拍 e＝r＋D＋1。

| 检查 | 必须满足 | 边界 |
| --- | --- | --- |
| 新起手防护 | e≤T，即理想条件下 Δ≥D_防＋1 | 防护必须已经取得本拍生效资格，并明确能够防住所面对的效果 |
| 新起手取消 | e＜T，即理想条件下 Δ≥D_取消＋2 | 普通队列内实际生效才算取消，不能在 T 补救 |
| 等料、等位或排队 | 按实际等待顺延 e，再检查同一截止 | 每多等待一拍，所需窗口也多一拍；不能只看 D 或 Δ＞0 |

具体输入到结果见 [截止窗口示例](examples.md#防护与取消的不同截止)。

## 敌情信息合同

本节索引已有的信息义务；完整展示与可达性权威在 [交互 TL-17／36](../../common/interaction-save/rules.md)。

| 时点／状态 | 必须可知的信息 | 仍受限制的内容 |
| --- | --- | --- |
| 出发前 | 下一批可选遭遇的敌人类型与主机制，沿 [路线 TL-32](../../common/run-route/rules.md#tl-32-单向路线与遭遇信息) | 不展示完整暗牌内容；图谱页只是表现候选 |
| 开战、揭示前 | 每张暗牌的程序位置、翻开拍、种类符号及文字 | 数值、Δ、目标与完整效果尚未揭示；形态或纹饰不得泄露 |
| 揭示 r 至到期 T | 全部效果、锁定目标（含无锁定对象）、T 与可取消条件 | 揭示不立即生效，也不改变牌内容 |
| 指定打断锁定后 | 法器剩余施法、危险开工带 [T−D, T−1]、停供结束拍须≥T、预计生效拍与同拍入行序 | 预览不能代替真实材料、容量和队列检查 |
| 取消、落空、循环与终局 | 空档保留、落空原因、跨段遗留 T、胜负原因分别可查 | 动画不提前后续牌、不重触发或改写结算结果 |

卡背种类沿 TL-36 的攻击▲、防御■、打断⊘、其他✱并配文字，只表示大类。地域变体可改花色图案、配色、材质与装饰笔触，不改符号轮廓、位置与含义；其他类副记号待具体子类另定。必要信息须有点击／键盘可达的文字与数字，不只依赖颜色、纹饰、声音或动画。具体形态与图谱页布局见 [设计](design.md#表现方向与可调整部分)。

## 跨系统接口与失败结果

| 接口 | 本系统需要保留的边界 | 权威位置 |
| --- | --- | --- |
| 打断锁定 | 揭示时取剩余 R＝a＋D−r 最大的处理法器，含 R＝0；并列沿战前法器序。锁定法器而非原批次 | [行动卡 TL-09](../action-card-system/rules.md#tl-09-敌牌揭示与锁定) |
| 无锁定、无批次或目标失效 | 照常到期并落空一次，不等待、不改选、不转为伤害 | [行动卡 TL-12](../action-card-system/rules.md#tl-12-伤害与法器中断) |
| 取消与防护 | 取消严格早于 T；T 拍已经能够生效的防护按共同拍序先行，护甲不自动抵挡单列的中断 | [行动卡 TL-10／11／12](../action-card-system/rules.md#tl-10-取消敌牌) |
| 中断与返工 | 中断当时正在处理的批次；退料、进度损失与容量回收沿法器规则，已入行行动不因此消失 | [法器 TL-07](../artifact-system/rules.md#tl-07-打断与返工) |
| 生命与终局 | 完整事件后检查；玩家存活且来源死亡才胜，同检查点双亡玩家失败。终局停止后续行动、完工与开工，未到期敌牌作废 | [行动卡 TL-13／29](../action-card-system/rules.md#tl-13-生命程序循环与终局) |
| 暂停与恢复 | 双方时间一同冻结；恢复保留程序位置、翻开表、锁定对象（含无锁定）和倒计时，不刷新暗牌 | [交互 TL-17／19](../../common/interaction-save/rules.md#tl-19-中断与恢复) |

### 标记接口（Qualified 引用）

[已有局部素材](../../../sources/materials/M-2026-10-08-action-card-framework.md)确认玩家和敌人都可作为标记宿主，正负相对宿主区分；实际持有层数与未来定时预告不同。具体叠层、上限、支付、存续和登记语义引用 [标记规则](../action-card-system/mark-system/rules.md)，不在敌人系统重复定义。

这部分仍为 Qualified，不改变上面的首版无敌方护甲／防护牌限制，也不让敌牌改走玩家生产队列。具体敌人标记卡、与敌牌同拍兑现的顺序、敌牌取消后相关定时效果的绑定处理均未完成；名称、宿主资格或四格展示不提供额外程序、延迟或事件权限。
