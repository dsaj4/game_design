## 揭示取消与跨段遗留

- 用途与依据：[敌人 TL-16](rules.md#tl-16-敌方程序约束)、[行动卡 TL-09／10](../action-card-system/rules.md#tl-09-敌牌揭示与锁定)。
- 前提：时间表有某张攻击牌，翻开拍 r，到期 T＝r＋Δ；下一张翻开拍及循环长 L 已固定。以下取消分支与遗留分支分别观察，不把已取消的牌又当作存续牌。

| 时点／分支 | 能确定的结果 | 边界 |
| --- | --- | --- |
| 开战、尚未到 r | 可见程序位置、翻开拍、攻击▲及文字 | Δ、伤害、目标和完整效果仍隐藏 |
| r 揭示 | 完整效果与目标公开并锁定，开始正延迟倒计时 | 不在 r 即刻造成该牌效果 |
| 有权限的取消行动在 e＜T 生效 | 对应敌牌被取消，原空档保留 | 下一张不提前、不补发；取消权限和实际生效都不可省略 |
| 另一分支：该牌未取消，跨过循环边界但尚未到 T | 旧倒计时继续，新循环按原表推进 | 不清空、重置或复制旧牌；内容须已避开跨段同拍到期 |
| 若内容安排两张牌同拍到期 | 不在本例推导顺序 | 首版约束不允许该输入；扩展规则 Unknown |

本例不决定程序生成算法、每场 L 或具体 Δ，也不开放未揭示暗牌的提前取消。

## 防护与取消的不同截止

- 用途与依据：[窗口关系](rules.md#应对窗口核对)、行动卡 TL-08／10／11。
- 前提：揭示拍 r，应对法器空闲且可于本拍末开工，材料和容量齐备、前方无队列阻挡，D 固定；分别比较具有明确防护权限的行动和具有明确取消权限的行动。不是同拍结算两张玩家卡。

| 步骤 | 能确定的结果 | 反例或额外条件 |
| --- | --- | --- |
| r 观察并提交，拍末开工 | 完工为 r＋D | 缺料／缺位则不能据预览当作已开工 |
| r＋D 完成入行 | 最早生效为 e＝r＋D＋1 | 入行当拍不兑现；排队可使 e 更晚 |
| 已有资格的防护在 e＝T 生效 | 按防护先行保护随后相应效果 | 普通护甲不自动保护单列中断，须核对能力 |
| 取消行动在 e＝T 生效 | 不能取消该敌牌 | 严格要求 e＜T；动画先播不改变截止 |
| 额外等料、等位或排队一拍 | 原 e 顺延一拍，再与 T 比较 | 防护和取消各自截止不变；不能仅凭 Δ＞0 判定可应对 |

因此理想条件下防护需 Δ≥D_防＋1，取消需 Δ≥D_取消＋2。本例不把理想条件设为所有实际遭遇默认，也不增加即时插队权限。

## 锁定并列与无施法

- 用途与依据：[行动卡 TL-09](../action-card-system/rules.md#tl-09-敌牌揭示与锁定)；对应 TL-V62／63。
- 前提：指定打断牌在 r 揭示；逐个分支给出当时状态。R＝a＋D−r，以下 1 与 0 取自已有验收情境，只作边界说明。

| 揭示时输入 | 确定结果 | 到期边界 |
| --- | --- | --- |
| W 剩余 1 拍，A 剩余 0 拍 | 锁定 W | 锁定的是法器；不承诺 T 时仍是原批次 |
| 两法器 R 相同 | 锁定战前法器序靠前者 | 不是临时供料优先级，也不是总 D 较大者 |
| 只有一个 R＝0、将在本拍完工的批次 | 该法器仍属于揭示时锁定候选并被选中 | 本拍稍后可完工；T 时是否有新批次另看实际状态 |
| 没有任何施法 | 无锁定对象，照常倒计时 | 即使之后某法器开工，到期也不补选，落空一次 |

本例不开放战中改牌。R 读取公开状态只用于已声明的目标选择。

## 续开停供与返工

- 用途与依据：[行动卡 TL-12](../action-card-system/rules.md#tl-12-伤害与法器中断)、[法器 TL-06／07](../artifact-system/rules.md#tl-06-路由与临时设置)；对应 TL-V64／65。
- 前提：W 已被锁定，到期 T；当前批次会在 T 前完成，后续批次固定耗时 D。每个分支独立，且 W 的其他开工条件有明示输入。

| 分支／时点 | 确定结果 | 失败或未决边界 |
| --- | --- | --- |
| 在 a∈[T−D, T−1] 续开 | T 时该批次仍受打断；即使 a＋D＝T 也先打断后完工 | 不同时取得成品与退款 |
| 停供使 W 不续开，临时方案结束拍设为 T | T 边界恢复基础供料，敌牌结算时无处理批次而落空；条件满足时可在 T 拍末开工 | 前提是原批次早已完成；停供不暂停现有加工 |
| 方案结束拍早于 T，恢复后又在危险带内开工 | 新批次仍被打断 | “原批次完成”不等于锁定已解除 |
| T 发生中断 | 退料、丢失进度；回收容量及退料最早 T＋1 可用 | 若有其他原本可用的完整料和独立空位，仍可在 T 拍末检查重开；不是整机冷却 |
| T 时没有批次，或锁定目标已不存在 | 落空、结算一次离场 | 不等待、不改选、不转成伤害或额外产出 |

已入行行动不因来源法器被打断自动消失。若揭示时当前批次满足 R≥Δ，它属于当前批次会被截击的另一情境，不能套用本例的“先完成再停供”。本例不决定标记等额外效果的退款或绑定失效。

## 击杀拍与战斗结束

- 用途与依据：[行动卡 TL-11／13／29](../action-card-system/rules.md#tl-13-生命程序循环与终局)；对应 TL-V66／67。
- 前提：同拍有敌方到期伤害和已取得资格的玩家攻击，后者足以杀死来源敌人；无额外复合触发。若有本拍已可生效的防护，先按 TL-11 结算，再比较下列分支。

| 分支 | 确定结果 | 不允许的解释 |
| --- | --- | --- |
| 到期敌伤害先使玩家死亡 | 完整事件后判负，后续玩家攻击不再结算 | 不能借“本拍本来能击杀”取消已结算的死亡 |
| 玩家承受后存活，随后攻击杀死来源敌人 | 完整事件后判胜，尚未到期的已揭示敌牌作废 | 胜利不是一次取消法术，不额外触发取消收益 |
| 终局已成立 | 停止后续动作、完工、开工及额外收益；已完成结果不回滚 | 不因画面仍在播放而继续倒计时或产出 |
| 某个合法完整事件结束时双方归零 | 玩家失败 | 不是双方同胜；本例不补造双亡复合卡及其步骤 |
| 来源已死而有不发牌附属物 | 附属物不阻止胜利 | 这不授予首版使用附属物或规定其死亡、掉落等机制 |

复合效果怎样划为完整事件仍 Unknown；本例只使用已定终局条件，不决定未来附属触发的总序。

## 地域卡面与规则信息

- 用途与依据：[信息合同](rules.md#敌情信息合同)、[交互 TL-36](../../common/interaction-save/rules.md#tl-36-决策保存与信息可达性)；对应 TL-V68。
- 前提：用两个地域的假设外观呈现同一攻击类，不指定新的地域、敌人、美术资源或具体暗牌数值。

| 步骤／条件 | 应满足的结果 | 边界 |
| --- | --- | --- |
| 更换花色、配色、材质和装饰笔触 | 攻击▲轮廓、位置、含义与种类文字保持一致 | 不能把攻击画成防御符号，或只藏在纹饰中 |
| 灰度、小尺寸或减动效 | 仍能通过符号、文字和数字辨识已公开信息 | 这是设计要求，尚无实际样张观察结果 |
| 尚未揭示 | 只读到该阶段允许的信息 | 不通过姿态、符号大小或颜色提示 Δ、伤害与目标 |
| 已揭示并使用键盘／点击查看 | 能获取完整效果、锁定与截止等必要信息 | 不只靠悬停、指向动画或声音 |

具体排版、演出及两套生命表现仍待设计；神秘感是否成立见 [体验假设](experience.md)，不由此例证明。
