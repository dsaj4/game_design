# 敌人：体验目标

2026-10-11 · Hypothesis / NotRun。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 预见压力 | 区分揭示前线索与揭示后完整信息 | 必须背出隐藏延迟才有生路 |
| 选择有代价 | 说明承受、转防或停供的放弃项 | 总是无代价执行同一操作 |
| 打断可理解 | 识别锁定法器和危险续开批次 | 以为原批次完工就解除锁定 |
| 胜负可解释 | 依据结算顺序解释致死拍 | 以动画顺序判断胜负 |
| 地域仍可读 | 灰度减动效下沿用种类识别 | 纹饰取代了通用符号 |

观察时先记录玩家预测与选择理由，再对照实际结果。分开记录规则误读、信息找不到、数值失衡；使用具体内容和界面版本。验证任务尚未执行。
