# 敌人：设计

2026-10-11 · DesignNote。CORE-054 的方向与首版约束沿现行规则。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

用可预见的程序压力改变玩家的生产和兑现选择。

| 设计重点 | 内容 |
| --- | --- |
| 压力节奏 | 通常一个关键威胁，少量双威胁；普通区间保持自动运行。 |
| 玩家选择 | 依实际能力比较承受、转防、提前取消、揭示前让位或锁定后停供；每条路线须有真实材料、容量和截止依据。 |
| 信息分层 | 揭示前看翻开表与种类，揭示后看完整效果和绝对到期拍。神秘感来自来历和意象。 |
| 首版风格 | 秘仪与炼金：失控作品、未约束存在、具身象征。每名敌人对应一种意象与工序，同一敌人不混地域。 |
| 表现候选 | 遭遇图谱页由图与格言表达主机制，正式制作前核实意象出处。工序、取消空档、落空及循环须可辨。 |
| 可重复判断 | 固定程序允许学习；用不同生命、库存和队列核对同一威胁是否仍存在有价值的不同应对。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q05／06／08／10、FB-Q01。
