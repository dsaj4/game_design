# 敌人：设计

2026-10-27 · DesignNote。表现方向沿既有资格，当前首场时间与内容约束已由CORE-065替换。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

用可预见的程序压力改变玩家的生产和兑现选择。

| 设计重点 | 内容 |
| --- | --- |
| 压力节奏 | 通常一个关键威胁，少量双威胁；生产区间保持自动运行，结算列间仍须确认。 |
| 玩家选择 | 依实际牌、列位与效果费用比较承受、调序、换牌或提前铺牌；取消须有内容授权，停供须有真实耗材，不能虚构所有配置都能回避。 |
| 信息分层 | 原生暗牌只看所在列、类别与即时／延时标识；翻开当列执行，生成的后续从此公开完整效果、对象和可用回合。神秘感来自来历和意象。 |
| 首版风格 | 秘仪与炼金：失控作品、未约束存在、具身象征。每名敌人对应一种意象与工序，同一敌人不混地域。 |
| 表现候选 | 遭遇图谱页由图与格言表达主机制，正式制作前核实意象出处。工序、取消空档、落空及循环须可辨。 |
| 可重复判断 | 固定程序允许学习；用不同生命、库存、列位和手牌核对同一威胁是否仍存在有价值的不同应对。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q05／06／08／10、FB-Q01。
