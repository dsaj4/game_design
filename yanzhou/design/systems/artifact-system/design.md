# 法器：设计

2026-10-23 · DesignNote。ART-I1—4 为已确认设计意图；规则见 rules。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

执行配方，承接玩家对未来生产的调整。

| 设计重点 | 内容 |
| --- | --- |
| 程序与决策 | 详情解释投入、工序、修饰和产出；相关调整从对应法器进入。现场保留用途、当前批次、未来设置和等待原因。 |
| 器具差异 | 以工序、兼容配方和用途区分器具，形象提示流派；以实际兼容表解释用途。 |
| 运行表现 | 加工／空闲两类形态，配短原因提示。完整信息在详情；减动效时仍能识别状态。 |
| 代价 | 材料、加工D、本轮列位、手牌上限与整理点共同决定实际生效。产得更快可能只增加烧牌；末轮等待与位置取舍都要可见。 |
| 调整 | 在观察窗口调整未来供料、既有用途及材料阶级；保留原计划也是选择。 |
| 契合与成长 | 契合效果逐法器定义；时间修饰看最终整数D及实际生效收益。付费但被取整抵消时说明原因。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q04／06／11、INS-Q04、FB-Q01。
