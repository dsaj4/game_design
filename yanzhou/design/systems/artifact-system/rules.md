## TL-03 一批生产的可见状态

| 状态 | 条件与行为 | 必须显示 |
| --- | --- | --- |
| 配置非法 | 铭刻缺核心或不兼容；该用途不执行 | 缺项／不兼容原因 |
| 等待 | 配置合法，但完整材料、容量或必要标记不足；本次跳过 | 各项缺口 |
| 加工 | 一次托管完整材料、预留全部容量、冻结本批D和必要标记 | 承诺用途、投入、预留、进度、预计完工 |
| 完成入行 | a+D拍幸存完工，结清标记费用，预留转行动卡 | 入行和实际队列位置 |
| 空闲检查 | 每拍末检查一次，齐备则续开，否则等待 | 下一批用途和条件 |

D是唯一生产耗时，正整数且至少1。a拍末开工、a+D拍完成；开工当拍不额外推进。没有交付、休歇、独立冷却或可调首次起点。第0拍先揭示／观察，再用初始库存首次开工。

### 时间修饰公式（CORE-056）

`D = max(1, ceil(max(0, D0 + ΣΔ) × ∏m))`

D0为基础正整数拍数，Δ为有符号整数修正，m为非负有限倍率；无倍率时取1。耗时减p%对应1−p，除以k对应1/k且k>0。负倍率、除零、非有限值为非法内容；“速度提高”须先明确换算为耗时修正。

同一次开工检查读取同一状态快照，每项有效贡献只计一次。同类先按内容的层数、覆盖或并存声明形成贡献；不把n层自动当n次倍率，不读取其他项的中间结果。固定增减后连乘，最后只取整一次，最低1拍、无默认额外上限。完整检查成功后冻结本批D，处理中不重算。

已启用且条件成立的付费修饰，即使取整／下限没有进一步缩短D，也足额冻结、完工扣除。预告显示最终D、费用及无进一步缩短。必需费用不足等待；内容明示可选并有基础回退时才可不增强运行。

## TL-05 开工预留与完成入行

`已入行牌数 + 有效预留容量 + 待下拍复用容量 ≤ Q`。每牌占1，开工预留本批全部张数。配方可明确为零材料（CORE-059）；未填写配方不是零材料。零材料仍检查合法配置、D、Q及必要标记。

预留只占容量，不占未来牌序。幸存完工时直接转为实牌，进入队尾，不再抢位，也没有完工待位状态。同拍完工按战前法器序；实际多牌批次须在内容中明确内部顺序。

维护／恢复之后，按有效供料优先级对各空闲法器检查一次，默认战前法器序。联合检查合法配置、完整材料、所需容量及全部必要标记；成功才一起承诺。失败不部分托管或占位，跳过后继续下一法器，不回扫、不设置自动公平轮转。前一个成功者即时占用，后一个读取剩余量。

正常行动离队容量可在当拍末使用，完工法器可续开；终局后不继续开工。开工侧所有同类标记费用合计检查，冻结量与D一起承诺，不因本批随后冻结而回算D。详见[标记冻结](../action-card-system/mark-system/rules.md#批次标记冻结core-055)。

## TL-06 路由与临时设置

观察窗口可免费调整未来批次的材料路由、供料先后、已有用途和兑现材料阶级。指定阶级不足则等待。已托管材料、处理中批次、容量预留及已入行牌保留本批承诺。

**固定用途（CORE-059）：**同一完整合法铭刻配置可以在内容中声明有限用途列表，每个用途绑定完整配方、D、张数、行动及失败分支。观察窗口择一，下一次开工锁定所选用途；基础加工与铭刻用途仍择一运行。选择用途不更换铭文，不任意改卡效，也不在行动生效时弹出模式选择。

临时供料最多一份，结束拍>当前拍；新方案替换旧方案。到期边界先恢复基础供料，再揭示并接受新操作；新操作用于当拍末。不会恢复被替换的旧临时方案。恢复保留已付成本、承诺、返工、延误及合法产出。

供料只能通过未承诺材料影响未来开工；正在加工者不暂停、不改速、不撤回，已入行牌不重排。零材料用途没有可停供材料，仅改变供料先后不等于停机。攻击／防御／运转是功能说明，不是三个固定端口。

结算中收到的操作留下一观察窗口。具体付费干涉入口见[问题TL-Q09](../../../governance/questions.md)。

## TL-07 打断与返工

明确打断作用指定法器当时的加工批次。普通掉血不打断生产。被打断批次不产行动，丢失进度，退回普通材料；解除预留，回收容量及退料最早下一拍可用。

冻结标记只释放仍有效部分，最早下一拍可用；已自然失效或合法移除的部分不复活。其他阶段已经支付的费用不按此退回。若法器另有原本可用的完整材料、标记和独立空位，可在当拍末重开；不得使用刚回收部分。

已入行牌不随来源法器被打断消失。该规则不提供玩家主动撤销批次。

## TL-38 统一法器与行动输出

法器执行合法铭刻用途或明示的无铭文基础加工用途，统一生产行动卡。铭刻核心必须完整；基础加工按自身输入合法性检查，不能单独满足开战至少一台合法铭刻法器的条件。

所有用途都经历处理与普通队列。资源型行动生效后生成资源，最早下拍可用。各用途接受哪些修饰须明确声明。

## TL-45 法器与核心铭文的契合增幅

法器对指定核心铭文提供特别增幅，逐内容列明关系、形式、量值及叠加。契合与资源产物增幅分别记账。EX-001暂不启用两护符的候选契合加成。
