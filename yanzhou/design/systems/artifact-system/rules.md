## TL-03 一批生产的可见状态

| 状态 | 行为与显示 |
| --- | --- |
| 配置非法 | 缺核心／不兼容，该用途不执行，说明原因 |
| 等待 | 完整材料、容量或必要标记不足，显示缺口，本次跳过 |
| 加工 | 显示承诺用途、托管投入、预留、冻结D、进度与完工拍 |
| 完成入行 | a+D拍幸存完工，结清费用、预留转实牌，显示实际队位 |
| 空闲检查 | 每拍末一次，按TL-05续开或等待，显示未来用途／条件 |

D为唯一耗时、正整数；a拍末开工，a+D完成，开工当拍不推进。没有交付期、休歇、冷却或可调首次起点。第0拍先揭示观察，再用初始库存开工。

### 时间修饰公式（CORE-056）

`D = max(1, ceil(max(0, D0 + ΣΔ) × ∏m))`

D0为基础正整数，Δ为整数修正，m为非负有限倍率，无倍率取1。耗时减p%用1−p，除k用1/k（k>0）；负倍率、除零、非有限值非法，“速度提高”须先换算耗时。

同次检查读同一状态，每项贡献计一次；同类层数／覆盖／并存按内容声明，不把n层自行当n次倍率，不互读中间结果。先固定增减，再连乘，最后一次取整；最低1拍、无默认上限。开工成功冻结D，不因本批冻结费用或加工中状态变化重算。

启用且条件成立的付费效果，即使取整／下限抹平收益仍足额冻结、完工扣费，预告须显示无进一步缩短及费用。必需不足等待；明示可选并有基础回退才不增强运行。

## TL-05 开工预留与完成入行

`实牌 + 有效预留 + 待下拍复用容量 ≤ Q`，每牌占1，开工预留本批全部张数。明确零材料可通过材料检查，空白配方不可；配置、D、Q、必要标记仍检查。

维护／恢复后，按有效供料序（默认战前序）逐台检查空闲法器：配置、完整材料、容量及合计必要标记都满足，才同时托管、预留、冻结本批D及费用。失败不部分承诺，继续下一台，不回扫、不自动公平轮转；前台成功占用后，后台读取剩余量。

预留只占容量、不占牌序；幸存完工直接转实牌入队尾，不抢位、不完工等位。同拍完工按战前序，多牌批次内部顺序须内容声明。正常离队空位可当拍末使用，完工者可续开，终局不再开工。标记结清见[冻结合同](../action-card-system/mark-system/rules.md#批次标记冻结core-055)。

## TL-06 路由与临时设置

观察窗口可免费调整未来材料路由、供料序、已有用途和兑现阶级；指定料不足等待。当前批次的用途、材料、D、产出、预留及已入行牌不变。

同一合法铭刻可声明有限固定用途，每项绑定完整配方、D、张数、行动和失败；下一成功开工锁定选择。基础加工与铭刻择一，不换铭文、不任改卡效、不在行动生效时选模式。

临时供料仅一份，结束拍>当前拍，新替旧；到期边界先回基础，再揭示和受理新方案，用于当拍末。不恢复旧方案，不回滚成本、承诺、返工、延误或合法产出。

供料只影响未承诺料，不能暂停／改速／撤回加工或重排旧牌。零材料没有可停供材料，优先级不等于停机；攻防运转是功能说明，不是固定端口。结算中操作待下一窗口，付费干涉见TL-Q09。

## TL-07 打断与返工

明确打断作用指定法器当时批次；普通掉血不打断。该批不产牌、丢进度，普通材料退回、预留解除，两者最早下拍可用。

冻结标记仅释放仍有效量且下拍可用，失效量不复活；其他阶段已付费用不退。若另有原本可用的完整材料、标记及独立空位，当拍末可重开，不能使用刚回收量。旧入行牌保留；不提供玩家主动撤批。

## TL-38 统一法器与行动输出

合法铭刻与明示无铭文基础加工都经D生产普通行动；前者须完整核心，后者按自身配方资格，不能独自满足开战铭刻门槛。资源行动实际生效才产资源、下拍可用。各用途接受的修饰须声明。

## TL-45 法器与核心铭文的契合增幅

逐内容声明指定核心的契合关系、形式、量值及叠加，与资源产物增幅分账。EX-001不启用两护符候选加成。
