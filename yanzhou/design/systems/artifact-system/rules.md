## TL-03 一批生产的可见状态

| 状态 | 行为与显示 |
| --- | --- |
| 配置非法 | 缺核心／不兼容，该用途不执行，说明原因 |
| 等待 | 完整材料或必要标记不足，显示缺口，本次跳过 |
| 加工 | 显示承诺用途、托管投入、冻结D、进度与完工生产拍 |
| 完成入行 | a+D生产拍幸存完工，结清制造费用，按桌面→手牌→溢出落位 |
| 空闲检查 | 每生产拍拍末一次，按TL-05续开或等待；结算列不检查，显示未来用途／条件 |

D为唯一耗时、正整数；a拍末开工，a+D完成，开工当拍不推进。没有交付期、休歇、冷却或可调首次起点。第0拍敌方首行已布好，先就绪观察，再用初始库存开工。跨回合批次继续，结算列不推进D。

### 时间修饰公式（CORE-056）

`D = max(1, ceil(max(0, D0 + ΣΔ) × ∏m))`

D0为基础正整数，Δ为整数修正，m为非负有限倍率，无倍率取1。耗时减p%用1−p，除k用1/k（k>0）；负倍率、除零、非有限值非法，“速度提高”须先换算耗时。

同次检查读同一状态，每项贡献计一次；同类层数／覆盖／并存按内容声明，不把n层自行当n次倍率，不互读中间结果。先固定增减，再连乘，最后一次取整；最低1拍、无默认上限。开工成功冻结D，不因本批冻结费用或加工中状态变化重算。

启用且条件成立的付费效果，即使取整／下限抹平收益仍足额冻结、完工扣费，预告须显示无进一步缩短及费用。必需不足等待；明示可选并有基础回退才不增强运行。

## TL-05 开工与成品去向

CORE-065取消成品Q、有效预留与待复用容量。桌面X位和手牌H位只限制成品留存，不作为开工条件；不能因两区满而自动停产，也没有完工等位。X5／H3见[参数](../../parameters.md)。

每生产拍拍末按有效供料序（默认战前序）逐台检查空闲法器。配置、完整材料、D和合计必要开工标记全部满足才同时托管材料、冻结D及必要费用；缺项不部分承诺，继续下一台，不回扫、不公平轮转。前台占用后，后台读取剩余可用量。明确零材料可合法，空白配方不可。

完工发生在该生产拍开工检查之前；先消费制造材料和结清开工标记，再按实际完工序放成品，同拍按战前序，多牌批次内部序须内容声明。每张先放桌面最左空位；满行则追加手牌右端，超过H立即移除最右牌。溢出不触发行动、不退款、不补发；制造付款与成品是否保住分开。

本拍完工者可在拍末续开，新批当拍不推进。末拍产物可参加本轮；末拍续开也先于最终整理，不可撤回。维护／恢复仅在对应新回合合同闭合后启用；当前首场不使用，不能照抄旧时序。标记费用沿[冻结合同](../action-card-system/mark-system/rules.md#批次标记冻结core-055)。

## TL-06 路由与临时设置

生产观察窗口及最终整理可免费调整未来材料路由、供料序、已有用途和兑现阶级；指定料不足等待。当前批次的用途、材料、D与产出不变，已产牌内容也不变。

同一合法铭刻可声明有限固定用途，每项绑定完整配方、D、张数、行动和失败；下一成功开工锁定选择。基础加工与铭刻择一，不换铭文、不任改卡效、不在行动生效时选模式。

临时供料仅一份，结束拍>当前拍，新替旧；到期生产拍边界先回基础，再观察受理新方案，用于当拍拍末。不恢复旧方案，不回滚成本、承诺、返工、延误或合法产出。

供料只影响未承诺料，不能暂停／改速／撤回加工；它不免费重排成品，成品整理另沿[TL-18](../../common/interaction-save/rules.md#tl-18-付费整理与干涉接口)。零材料没有可停供材料，优先级不等于停机。结算中所有玩法调整关闭，不自动缓存为下轮付费操作。

## TL-07 打断与返工

后续打断牌在其结算列作用原锁定法器当时的批次。普通掉血不打断。当前批次丢进度、不产牌；普通材料退回、仍有效冻结标记释放，最早下一生产拍可用，失效量不复活；其他已付费用不退。

本轮全部生产拍在结算前已完成，所以已经完工进入桌面／手牌的牌不受追溯打断。没有容量预留及回收；结算列之间不能重新开工，无论是否另有材料。下一生产拍先释放待用量，拍末按完整条件检查；新批本拍不推进，不补失去的产出。

不提供玩家主动撤批。当前回合不使用旧“打断先于同拍完工／独立空位当拍重开”路径；旧EX仅按其固定旧版解释。

## TL-38 统一法器与行动输出

合法铭刻与明示无铭文基础加工都经D生产普通行动；前者须完整核心，后者按自身配方资格，不能独自满足开战铭刻门槛。资源行动实际生效才产资源、下一生产拍可用，不在后续列直接加工。各用途接受的修饰须声明。

## TL-45 法器与核心铭文的契合增幅

逐内容声明指定核心的契合关系、形式、量值及叠加，与资源产物增幅分账。EX-001不启用两护符候选加成。
