## TL-03 一批生产的可见状态

| 状态 | 行为与显示 |
| --- | --- |
| 配置非法 | 缺核心／不兼容，该用途不执行，说明原因 |
| 待料 | 本器链接待料至多一批，可不齐；显示材料形状、缺件与最早吸收拍，不占在制名额 |
| 等待 | 待料未齐、尚未到吸收拍或必要标记不足，显示缺口，本次跳过 |
| 加工 | 显示承诺用途、托管投入、冻结D、进度与完工生产拍 |
| 完成入手 | a+D生产拍幸存完工，结清制造费用，声明卡牌产物进入对应手牌组 |
| 空闲检查 | 每生产拍拍末一次，按TL-05续开或等待；结算列不检查，显示战前固定用途／条件 |

D为唯一耗时、正整数；a拍末开工，a+D完成，开工当拍不推进。没有交付期、休歇、冷却或可调首次起点。第0拍敌方首行已布好，先就绪观察；明确零材料用途继续时可首次开工，有耗材用途初始预放最早第1生产拍吸收。跨回合批次继续，结算列不推进D。

### 时间修饰公式（CORE-056）

`D = max(1, ceil(max(0, D0 + ΣΔ) × ∏m))`

D0为基础正整数，Δ为整数修正，m为非负有限倍率，无倍率取1。耗时减p%用1−p，除k用1/k（k>0）；负倍率、除零、非有限值非法，“速度提高”须先换算耗时。

同次检查读同一状态，每项贡献计一次；多件合法辅助的同效贡献可叠加，固定量相加、倍率相乘；标记同类层数／覆盖／并存按内容声明，不把n层自行当n次倍率，不互读中间结果。先固定增减，再连乘，最后一次取整；最低1拍、无默认上限。开工成功冻结D，不因本批冻结费用或加工中状态变化重算。

启用且条件成立的付费效果，即使取整／下限抹平收益仍足额冻结、完工扣费，预告须显示无进一步缩短及费用。必需不足等待；明示可选并有基础回退才不增强运行。

## TL-05 开工与成品去向

法器按当前批次承诺完工，产物继承本批静态辅助贡献且不重复计算，结清制造费用，将声明的卡牌产物直接放入对应手牌组。任何产物都不自动填入战斗行；完工不等于卡效已经执行。产物按实际完工先后、同拍战前法器序及同批声明内部序进入持牌顺序。

手牌当前不设硬上限，不因超过3张丢新牌；浏览方式不造成库存损失。桌面仍为本场固定X位，当前X=5；手牌与桌面均不限制开工，不恢复Q、预留或完工等位。没有卡被玩家放上行时，己方该列为空。

新产卡可在本生产拍收尾后的合法出牌窗口使用；新卡须下一生产拍取得供料资格，再进入本器供料区，排入后最早下一生产拍吸收，不从手牌直接开工。当前批次、已有卡及已成支付不随待料调整改变。

每生产拍拍末按固定战前法器序逐台检查空闲法器一次。配置、本器唯一归属的完整待料、真实占形／范围接触与最早吸收拍、D及合计必要开工标记全部满足才同时吸收托管、腾空该批材料实际占格并冻结本批D、静态辅助贡献和费用；缺项不部分承诺，继续下一台，不回扫、不公平轮转。每器至多一批在制＋一批待料。明确零材料合法，不要求摆一份虚拟材料；空白配方不可。

完工在本拍开工检查前；早已预放且到时的下一批可在本拍完工后拍末续开，新批当拍不推进。末拍续开先于最终整理，不能撤回。所有开工检查结束后，再按同一战前序自动补齐待料（TL-06），新补入不得在本拍再开工。维护／恢复须另有迁移后合法内容，首场不启用；费用沿[标记冻结](../action-card-system/mark-system/rules.md#批次标记冻结core-055)。采纳依据：[CORE-068](../../../sources/draft-changes/D-2026-10-31-backpack-production.md)。

## TL-06 战前布局与下一批供料

**CORE-074：供料范围与待料归属分开。** 战前固定法器本体位置／朝向、接收范围、核心／辅助、用途与法器序。范围随本体定位和旋转，本战不改变；当前八器范围见内容库。原专属空区预留与材料完整容纳要求退出。

### 空间与一格接触

接收范围是覆盖层，不独占背包格，可以与其他范围交叠或覆盖实体所在格；包外范围不提供合法落点。材料完整占形必须在共用背包内，不与法器、辅助、散装核心、留包物或任何其他待料实体交叠；至少一个实际占用格属于指定法器的范围即可。仅贴边、碰角、图像透明边接触无效；允许材料合法旋转，不由总面积替代格集合检查。

范围内有其他实体不使法器非法，但实体占据的格不能放材料。辅助可处于范围覆盖内，只按自身真实占格与正交指向规则判断。一个材料横跨多个范围仍只属于一个法器，其他器不得吸收；材料仍须匹配固定配方、数量、阶级、锁定与可用时点。空间不足显示阻塞，不赠包外待料位。

### 指定对象、预览与提交

空手点击法器选中并显示本器范围与关联，不开工、不切用途、不改链接；精确详情沿原查看入口。带材料时可“选材料→点法器→点落点”；拖动首次进入可见法器本体或连接点时选定目标，显示虚线及范围。目标保持，路过其他器不自动换连；改目标须明确改选（点击路径可直接重选；拖动可取消后重选）。不以模糊最近距离暗选接收器。

合法落下才同时提交材料位置与唯一归属，虚线转实线。非法落点／目标、取消或不允许的阶段整项拒绝，保持操作前实际归属；移动中的影像不提前腾空原格，也不生成副本。改送或替换仅在全部目标条件成立时提交，旧器只失去实际改送材料。

实线表示已排入本器待料，不表示整批齐备、已托管或已消费。缺件显示缺口；吸收时释放真实格、清除该批待料线、转加工状态。选器突出本器范围与线，其余弱化；归属不能只靠颜色表达。

### 待料、自动补料与时间

每器至多一批在制＋一批待料，手动可逐件准备或撤回／替换／改送未吸收材料。只在TL-17生产观察窗口编辑，不暂停、改速或撤回在制；范围重叠不增加排队批数。零材料用途不要求虚拟材料。

自动默认开，可逐器关闭；关闭保留已有待料，已齐者仍按条件开工。自动只补缺项，不替换或移动手动／先前材料；从本场手牌排除锁定、未到时点、留包或其他归属，沿最低合格阶级、同阶手牌先后选择完整材料组合。复杂多槽匹配仍须内容有确定合同，不因本次几何修订开放。

对确定的材料组合，按配方槽序及同槽副本序检查整批摆法：每份朝向0／90／180／270，等效朝向只保留首次；各朝向按旋转后包围盒左上锚点从上到下、从左到右枚举。某份落点导致后续无解时可回查本次尚未提交的候选，取首个整批可行摆法。既有实体不移动；找不到整批摆法则全部不搬入，显示缺空间并继续下一器。已有待料实体不能因同器而被覆盖。

自动在t0继续时首次检查之后、每拍所有开工检查之后按固定战前法器序各执行一次；直接提交相同的唯一归属与连线，不要求模拟拖拽。后器只看到剩余手牌和空间，不争用同一实例；不在列间、最终整理或切开关时额外执行。

t拍观察窗或自动排入者最早t+1吸收，预览／链接不即时开工。改送、替换按本次提交重设最早吸收拍；初始t0可预放、最早t1吸收。资源卡组在t拍边界解封者本拍可供料，自动可在t拍末排入；制造新产与打断退料仍须下一拍取得资格。编辑窗口不随解封扩张，最终整理与列间不手动放料。

旧临时路由、结束拍、动态优先级及独占供料空区不恢复。保存目标器实例、材料实例、位置／朝向、待料最早拍和已提交事实；中断只影响在制，其他待料保持。见TL-15／17／19及TL-46。

## TL-07 打断与返工

后续打断牌在其结算列作用原锁定法器当时的批次。普通掉血不打断。当前批次丢进度、不产牌；普通材料退回对应手牌组、仍有效冻结标记释放，最早下一生产拍可用，失效量不复活；其他已付费用不退。

已排队的下一批材料保留在原供料区，不被退料覆盖、合并或重复计数；退料不自动回填原格。

本轮全部生产拍在结算前已完成，所以已经完工进入手牌或被主动上行的牌不受追溯打断。没有容量预留及回收；结算列之间不能重新开工，无论是否另有材料。下一生产拍先释放待用量；已有合格待料可在拍末按完整条件检查，只有退回手牌而未重新排队的材料不能直接重开；新批本拍不推进，不补失去的产出。

不提供玩家主动撤批。当前回合不使用旧“打断先于同拍完工／独立空位当拍重开”路径；旧EX仅按其固定旧版解释。

<a id="tl-38-统一法器与行动输出"></a>
## TL-38 统一法器与卡牌输出

合法铭刻与明示无铭文基础加工均经D直接产生声明卡牌，进入对应手牌组，不强制经一张中介行动再交付材料。核心完整与基础用途资格仍各自检查，基础加工不能独自满足开战铭刻门槛。真实战斗卡效可按内容生成卡，须该步骤实际成功；配方取用与可用时点见[TL-15](../resource-system/rules.md#tl-15-配方托管产物与维护)。各用途接受的修饰须声明。

## TL-45 法器与核心铭文的契合增幅

逐内容声明指定核心的契合关系、形式、量值及叠加，与资源产物增幅分账。EX-001不启用两护符候选加成。
