## TL-03 一批生产的可见状态

| 状态 | 行为与显示 |
| --- | --- |
| 配置非法 | 缺核心／不兼容／无炉心，该用途不执行，说明原因 |
| 已排 | 材料或明示零材料开工指令已排进本器工序行某列、尚未开工；光标右侧可免费撤回、替换、调序，显示第几列开工、第几列到货 |
| 草稿未合法 | 缺料、必要标记不足、设备占用冲突或入料口尺寸P不足，显示缺口；若为待确认的当前列，整次确认拒绝，保留可编辑草稿，不推进、不部分冻结 |
| 加工 | 显示承诺用途、冻结投入、冻结D、进度与到货列；开工后冻结 |
| 到货入手 | 第c列开工后的c+D−1列末窗口，结清制造费用，声明卡牌产物进入对应手牌组，下一列起可用 |

D为唯一耗时、正整数，单位为列。在第c列开工，占用c至c+D−1列；c+D−1列末窗口入手，c+D列起可用。开工列计入D，D1也须经过本列，不可同列使用产物。没有交付期、休歇、冷却、可调首次起点、观察窗、预放、吸收拍与待料。一器同一时间一条在制，同行批次占用区间不重叠；旧批某列末完成，下一列可开新批，无额外冷却。可用真实已持材料提前排下一批，不能把尚未入手的预告当材料；D可跨回合继续。

### 时间修饰公式（CORE-056）

`D = max(圈下限, max(1, ceil(max(0, D0 + ΣΔ) × ∏m)))`

D0为基础正整数，Δ为整数修正，m为非负有限倍率，无倍率取1。耗时减p%用1−p，除k用1/k（k＞0）；负倍率、除零、非有限值非法，「速度提高」须先换算耗时。圈下限见TL-06，催炉类效果不能突破下限。

同次检查读同一状态，每项贡献计一次；多件合法辅助的同效贡献可叠加，固定量相加、倍率相乘；标记同类层数／覆盖／并存按内容声明，不把n层自行当n次倍率，不互读中间结果。先固定增减，再连乘，最后一次取整；最低1列、无默认上限。开工成功冻结D，不因本批冻结费用或加工中状态变化重算。

启用且条件成立的付费效果，即使取整／下限抹平收益仍足额冻结、完工扣费，预告须显示无进一步缩短及费用。本列已排工序必需不足则整次确认拒绝，保留草稿待玩家修正；明示可选并有基础回退才不增强运行。

<a id="tl-05-开工预留与完成入行"></a>
## TL-05 开工与成品去向

玩家把配方所需材料（张数不超过本器入料口尺寸P）从手牌排进本器工序行第c列，允许先保留不完整草稿。确认当前列前，联合检查本列所有已排工序的配置、完整材料／P、D与设备占用区间，并按宿主／种类合并必要开工标记费用。全部合法且足额才共同确认，在该列开工，冻结投入、D、静态辅助贡献与费用。任一工序非法或合计费用不足，整次确认拒绝：不推进光标、不揭敌牌、不冻结任何一批、不部分扣费，原排布与库存保持。玩家补齐、撤回或改排后再确认，不自动顺延、不按法器序或位置选部分器具开工。未排工序的空行不自动开工；仅检查本次要开始的工序，未来列的不完整草稿不会因本列确认自动开工或被光标越过。

不完整草稿不放宽单次排料的身份、归属或配方匹配要求：同一实例重复占用、拿未到手预告或不合格材料的操作仍整项拒绝。开工前材料可免费撤回、替换、调序，开工后冻结不可撤。明确零材料用途通过点击本器工序格并选择本器战前已固定的合法用途，排入开工指令；不要求虚拟材料卡，不授予战中切用途。指令沿同一光标规则撤回、调序或冻结，仍检查D、设备占用与其他必要费用；空白配方不可。

法器按本批承诺到货，产物继承本批静态辅助贡献且不重复计算，结清制造费用，将声明的卡牌产物在c+D−1列末窗口直接放入对应手牌组，c+D列起可用；若本列战斗已终局则不补完工或产物，沿TL-25处理实际归属。任何产物都不自动填入战斗行；到货不等于卡效已经执行。多张产物须声明批内顺序，按实际结束先后、同列同批内部序入手，没有法器序设置项。

手牌当前不设硬上限，不因超过3张丢新牌；桌面仍为本场固定X位，当前X=5；手牌与战斗行均不限制开工，不预留成品容量或完工等位。没有卡被玩家放上行时，己方该列为空。

新产卡入手后，下一列起既可上战斗行，也可作为本器或他器的下一配方输入排进工序行；没有供料资格拍。回收原卡不新增待用期。费用沿[标记冻结](../action-card-system/mark-system/rules.md#批次标记冻结core-055)，首场不启用维护／恢复。采纳依据：[CORE-075](../../../sources/draft-changes/D-2026-11-04-table-axis-spatial-artifacts.md)，取代[CORE-068](../../../sources/draft-changes/D-2026-10-31-backpack-production.md)的开工与待料部分。

<a id="tl-06-路由与临时设置"></a>
## TL-06 战前布局：炉心、圈下限、组合与覆盖圈

**CORE-075：空间只在装载确认时求值一次，战中桌面只读结果，没有实时几何。**战前固定法器本体位置／朝向、炉心、核心／辅助、用途与组合；八法器本体占形继续沿[内容库](../../../content-library/artifact-geometry.md)，其接收范围字段废止。

### 炉心与圈下限

- **炉心必选。**小炉1×1、长炉1×2，占格，不嵌铭文，不产卡；没有炉心不可开战。多炉心时每格取最近炉心。
- **圈号。**某格圈号＝max(0, 到最近炉心格的曼哈顿距离−1)，与炉心共边的格为第0圈。
- **整件入圈。**一件法器取其最远格所在圈为圈号（组合体按并集最远格），圈下限＝1＋圈号（示意值，待标定）。
- **实际D＝max(圈下限, 现行D公式结果)，最终至少1。**催炉类效果不能突破圈下限。
- 战前界面须标出拖慢该法器的格与所在圈，并画出每台法器的到货线；不标则视为未满足信息合同。

### 法器组合

接触本身没有任何效果，不设被动联动与串扰。内容给出组合表；两件指定法器战前接触，由玩家主动点「组合」合并为更大的法器，一件法器同时只属于一个组合，可战前拆开重配，拆开不省地。组合体占形取并集；有自己的配方、入料口与产出，部件在组合状态下不能单独开工，所以没有中间产物。组合产物价值须高于分开跑，由内容预算保证。首批只做硫链（封相炼炉＋显咒灯）。

### 入料口尺寸P

每台法器（含组合体）由内容直接设定入料口尺寸P：一批最多投几张材料，与占形脱钩。配方材料数S必须不大于P，否则该用途非法。

### 辅助覆盖圈

辅助独立占格，自带覆盖圈（首版距辅助格曼哈顿距离不超过2，不设覆盖数上限）；被覆盖的每台兼容法器全额生效，同效叠加沿用现行规则。辅助无朝向、接口与单器连接。

旧临时路由、结束拍、动态优先级、独占供料空区、接收范围、一格接触、唯一链接、自动补料与法器序设置项均不恢复。保存炉心／法器／辅助位置、组合关系与工序行已排牌；见TL-15／17／19及TL-46。

<a id="tl-07-打断与返工"></a>
## TL-07 打断与返工（退役）

CORE-075不做打断介入生产：没有法器锁定、在制批次被打断、退料与返工；生产不被敌牌触及，已入手与在制批次都不被追溯打掉。原条款随之退役，旧版本按[固定历史](https://github.com/dsaj4/game_design/blob/d92851e951a3a8ad67e26962c4a9924ac5cd532b/yanzhou/design/systems/artifact-system/rules.md)取证，不复用本ID。后续若有敌方针对己方牌的效果，以另行采纳的封印牌表达，被封印的牌按TL-21空放，不触及生产。

<a id="tl-38-统一法器与行动输出"></a>
## TL-38 统一法器与卡牌输出

合法铭刻与明示无铭文基础加工均经D直接产生声明卡牌，进入对应手牌组，不强制经一张中介行动再交付材料。核心完整与基础用途资格仍各自检查，基础加工不能独自满足开战铭刻门槛。真实战斗卡效可按内容生成卡，须该步骤实际成功；配方取用与可用时点见[TL-15](../resource-system/rules.md#tl-15-配方托管产物与维护)。各用途接受的修饰须声明。

## TL-45 法器与核心铭文的契合增幅

逐内容声明指定核心的契合关系、形式、量值及叠加，与资源产物增幅分账。EX-001不启用两护符候选加成。
