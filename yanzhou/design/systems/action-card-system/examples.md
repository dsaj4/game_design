# 行动卡：示例

2026-10-23 · Derived / CORE-065 · NotRun。数值输入和范围见[EX-003](../../examples/round-hand.md)，不继承旧EX连续拍的生效时间。

## 产牌与生效分开

D1在第4生产拍开工，第5拍完工先入桌或手，再最终整理；若在桌面，就可参加本轮相应列。桌手都满则烧掉新牌，既不执行效果也不退制造料。已产资源类行动仍须生效才生成资源，生成资源下一生产拍可用，不是下一列可用。来源：[TL-05](../artifact-system/rules.md#tl-05-开工与成品去向)、[TL-11](rules.md#tl-11-共同拍序与效果边界)。

## 读取条件与足额支付

初始4层施法次数，普通攻击先做后可使兑现读到5层；相反排序时兑现先不足，后来补层不重试。实有9锁5也只有4层可消费，合法解锁只能在结算开始前完成。完整局部数值见[EX-003 §3](../../examples/round-hand.md#3-排序与兑现)。

## 卡内步骤与终局

同列先防御组再其他组，组内敌后我；独立护盾与攻击可分组，依赖攻击成功才得的护盾不能倒跳防御组。每完整事件结清后判终局，致死后不补记次、下一击或后列。无目标则该步不付费，按依赖跳过后续或空放，不返制造料。来源：[TL-11／30](rules.md)、[TL-13／21](../../GDD.md)。
