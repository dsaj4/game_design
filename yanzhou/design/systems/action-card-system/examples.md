# 卡牌与战斗使用：示例

2026-10-27 · Derived / CORE-067 · NotRun。数值输入和范围见[EX-003](../../examples/round-hand.md)，不继承旧EX连续拍的生效时间。

## 产牌与生效分开

D1在第4生产拍开工，第5拍完工直接把声明产物放入手牌。无H3或烧牌；玩家在最终整理选择上行，才可能在相应列执行。制造不记层，不自动产生战斗效果。配方产物无需中介行动，作为下道输入最早下一生产拍；真实卡效生成的新卡则须实际成功，入手后可在下一合法窗口上行。来源：[TL-05](../artifact-system/rules.md#tl-05-开工与成品去向)、[TL-11](rules.md#tl-11-共同拍序与效果边界)。

可回收牌整次使用处理完回手，无目标／费用不足也沿回收属性；同一列不能反复执行，原位结果只读。列间可放后续空位，每次重检费用。若把它作为普通配方输入消费，则不凭回收属性返料。

## 读取条件与足额支付

初始4层施法次数，普通攻击先做后可使兑现读到5层；相反排序时兑现先不足，后来补层不重试。实有9锁5也只有4层可消费，合法解锁只能在结算开始前完成。完整局部数值见[EX-003 §3](../../examples/round-hand.md#3-排序与兑现)。

## 卡内步骤与终局

同列先防御组再其他组，组内敌后我；独立护盾与攻击可分组，依赖攻击成功才得的护盾不能倒跳防御组。每完整事件结清后判终局，致死后不补记次、下一击或后列。无目标则该步不付费，按依赖跳过后续或空放，不返制造料。来源：[TL-11／30](rules.md)、[TL-13／21](../../GDD.md)。
