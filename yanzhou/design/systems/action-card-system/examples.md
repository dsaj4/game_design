## 生产入行与截止窗口

依据：[TL-08／10／11](rules.md)，Inherited / Accepted。沿原规则页迁出，示例本身不新增规则。

示例仅校对时间关系：假设本批已合法取得材料和容量预留，D＝1，在第4拍开工、第5拍完成即入行。按已采纳的最早下拍翻开规则，在队列允许时最早第6拍生效；第6拍已有资格的防护可能保护第6拍威胁，第6拍取消行动不能取消同拍敌牌，需敌牌至少第7拍到期。若前面仍有行动等待，实际生效更晚。示例D与具体时刻不是发行参数；第4拍开工发生于本拍末统一检查，完成时刻沿a+D。

第 0 拍起步的同一关系：D=1时0开工、1入行、最早2生效。仍以合法开工、队列允许为前提；D=1 是示例值。

## 原卡离队后仍有未来效果

依据：[ACT-Q1](rules.md#行动标记与后续兑现)及 [标记定时规则](mark-system/rules.md#定时登记与兑现)，Qualified／用户已确认。

情境：一张声明“在未来指定拍产生标记”的行动已按普通队列合法结算，未来时点尚未到达。

确定结果：原卡依普通规则离队，后续效果以独立登记继续等待；界面可显示虚幻砝码预告，宿主当前实有层数尚未因此增加。预告不占队列 Q，不额外翻牌；原卡释放容量仍按普通离队规则处理。

CORE-057现已定到期按TL-11分组、默认建立时绑定宿主；宿主死亡清理，其他敌牌取消不撤销独立登记。本例具体效果量仍须内容声明。

## 读取条件与足额支付

依据：[ACT-Q2 与 TL-30](rules.md)、[标记读取与支付](mark-system/rules.md#读取与支付)，Qualified／用户已确认并引用 Accepted 支付边界。

| 情境（非发行卡） | 确定结果 | 未由本例确定 |
| --- | --- | --- |
| 合法效果只读取“宿主拥有标记甲”，没有消费声明 | 读取本身不扣甲 | 条件成立后的具体卡效 |
| 合法支付步骤要求 n 层甲，宿主实有 k 层且 k<n | 不扣掉现有 k 层，不给出足额支付才有的效果 | 基础效果是否仍执行，取决于卡效声明 |
| 虚幻预告将产生甲，但当前实有层数不足 n | 预告不能充当已经拥有的层数支付 | 未来到时沿TL-11固定先后，不能提前支付 |

n、k、甲只用于解释合同，不是参数、标记名称或正式内容 ID。

## 同拍分组、逐击结清与竞争（CORE-057）

依据[TL-11](rules.md#tl-11-共同拍序与效果边界)，均为Derived／Illustrative／NotRun。以下独立条件例不发行实际卡牌、标记或反应能力。

| 输入与时点 | 按规则得到的结果 |
| --- | --- |
| 玩家本拍队首防护需1层甲，当前0层；既有定时登记本拍增加1层甲 | 防护组支付不足，不扣费；其余组才加甲，防护不重试，甲可供后续合法开工；失败仍占一次行动机会 |
| 队首牌声明防护和攻击两个独立步骤，敌攻击同拍到期 | 先结清防护，之后敌攻击，再玩家攻击；敌攻击致死则不执行玩家余下攻击 |
| 同卡在其余组先加甲，再付甲造成伤害，层数及目标合法 | 前一步已新增的层数能付后一步；若声明先付再加且余额不足，先付步骤失败，后加不倒补 |
| 两次攻击，第一击引发已经合法声明的一次反伤，双方在本事件后均归零 | 结清主伤害及已取得资格反应，同点双亡玩家败；第二击、后续完工及开工均停止 |
| 一个多目标主步骤及多个已获准反应 | 全部合法主结果先完成，再按反应来源建立序处理一层反应；不在目标间提早判胜，新状态不加入当前反应 |
| 一张牌试图先攻击命中，再据结果支付／获得前组防护 | 与阶段存在逆向依赖，不是合法完整卡效；须重写或另行提出例外 |
| 同一来源两张敌牌同拍到期，揭示拍不同 | 同组先较早揭示者；首版仍禁止这样排内容，排序只作通用兜底 |
| 防护步骤已完成后暂停／恢复，攻击步骤尚未轮到 | 保留原选定牌、目标与余下步骤，不再支付防护，不补翻另一张队首 |
