| 设计重点 | 内容 |
| --- | --- |
| 归属 | 玩家和敌人分别在宿主两侧显示正负状态，同类聚合层数；名称服务实际效果差异。 |
| 余额 | 实有、锁定、冻结、待释放与可消费量分别表达；未来预告使用虚幻砝码。 |
| 表现 | 实体状态与预告用形态及文字共同区分。生命／护甲按[当前视觉文字基准](../../../../visual/baseline-2026-10-26/README.md)以计数筹码呈现；筹码详情／历史仍延期，其余新展示缺口归PRE2D-Q01，不重开已闭合的TL-Q08。 |
| 内容密度 | 先用少量状态提供不同的有代价用途，再增加种类；实有层数与周期登记分别约束增长。 |
