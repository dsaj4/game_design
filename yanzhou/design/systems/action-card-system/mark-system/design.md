## 已确认方向与作用

标记表现行动留下的施法效果、法力残留或持续状态，延续牌桌、炼金与铭刻语境。它把一次行动的后果保留为可见状态，并给行动与法器提供共享的简单条件与支付来源。

正负分别放在宿主两侧，玩家和敌人各自拥有两侧；同类以层数表达积累。设计目标是让玩家看见状态属于谁、当前有多少、未来何时增加、消费换得什么。能否降低理解成本，仍需体验证据。

跨法器构筑依靠共享标记形成，辅槽不直接给另一法器加成。标记种类应靠清楚的效果差异成立，不为每张卡制造一个只能记名字的新状态；这是内容组织建议，不是已定数量上限。

## 表现方案

砝码堆叠与正负分侧已确认；几何外形、颜色、材质、堆叠压缩、数量文字和动效节奏待表现设计。建议让实有与预告在实体感和标签上都有区别，避免只依靠颜色或透明度。

Q-MARK-2 要求探索生命的两套表现：A 为生命也以砝码表达；B 为生命独立显示，标记保留砝码。两者都沿既有生命和护甲规则，不由视觉方案决定是否能支付生命、是否设置统一上限。尚未比较效果或选定方案。

ACT-Q1 已将虚幻砝码定为独立定时效果预告；原文“翻牌后落下”不再解释为原行动第二次翻牌。预告可沿时间轴排列，但不画成占普通队列容量的新卡；具体排布留后续方案。

## 未决接口

| 项目 | 已有边界 | 还需明确 |
| --- | --- | --- |
| 定时与同拍排序 | 独立登记，不占队列，战终停止周期 | 到时相对伤害、防护、普通行动、维护与开工的位置，多项到期顺序和完整事件粒度 |
| 目标与来源 | 宿主只限玩家／敌人，存活资格沿旧规则 | 何时绑定；来源消失、目标失效或关联敌牌被取消后如何处理 |
| 上限与溢出 | 每类设上限 | 各类具体上限，满层时新增／支付如何计算，超限部分如何处理 |
| 同类重叠 | 层数可叠加 | 期限是否刷新，各层是否共用期限，多个周期登记合并还是并存 |
| 层数效应 | 异类分别计算 | 各类每层的作用、是否消费、读取及量值快照时点，跨类修饰合成 |
| 支付竞争与失败 | 完整检查，失败不部分扣层 | CORE-055已定开工冻结与不足分支、打断释放；其余同拍优先级、非制造阶段已付退款、同卡生成消费次序仍Unknown |
| 移除与跨战 | 不转移；周期战终或到期停止；依赖宿主的状态随宿主清理 | 普通及被冻结标记的自然消退、驱散、跨战／战终完整合同；主动锁定不阻止自然失效，无声明时不默认保留 |
| 新事件触发 | 只有简单标记条件与定时方向，不默认递归链 | 事件型触发是否另开权限及有限性；原候选名称不代表接口已获准 |

详细阶段文件中的推荐上限、优先级、消费／生成顺序和卡池仍是来源候选。本轮不将“护盾”“护甲”“血量标记”仅凭名称合并，也不把护甲伤害规则默默替换为新标记规则。
