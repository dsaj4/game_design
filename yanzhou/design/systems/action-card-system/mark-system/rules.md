# 标记系统：规则

2026-10-31 · QualifiedFramework；CORE-055／057已采纳接口、CORE-068供料竞争与锁定衔接沿[基准](../../../baseline.md)。[设计](design.md) · [体验](experience.md) · [示例](examples.md)

当前首场施法次数读对象、叠层与支付；开工费用才读冻结。CORE-065允许即时层供后续步骤／列使用；有限期、周期、独立定时的新回合接口未闭合，不能按下方旧扩展直接启用。资格与适用范围分开。

## 对象与宿主

只附玩家／敌人，不转移宿主；种类、极性与层数描述状态，正负相对宿主各分两侧。标记定义、宿主实有状态和未来登记分别处理。

## 叠层、上限与存续

同宿主同类叠层，其他独立；叠层不自动线性增强或合并定时登记。具体上限、超限、效力、期限／刷新、移除和战终见[内容合同](../../../content/cards.md#内容必填字段)，缺项不启用。生命／护甲沿TL-29，不套普通标记上限或支付权限；未决见[TL-Q02／08](../../../../governance/questions.md)。

## 读取与支付

**首场施法次数：可消费＝实有−玩家锁定。** 标记沿[锁定操作](../../../common/interaction-save/rules.md#玩家消费锁定与预警core-055)，CORE-068材料锁定仅保护手牌自动补料，标记锁解时点及本段冻结／支付保留；解锁后恢复后续消费资格；兑现仍到生效才付费，首场无开工冻结或定时释放。具体5层与基础回退沿[EX-001](../../../examples/simple-spell.md#5-施法次数)，不是所有标记的通用价格。

简单条件只查宿主／种类／层数，读取不扣费。当前读取只认合法实有层，不认未来预告或其他批次冻结量；玩家锁定不禁止非消费读取。即时支付排除托管、冻结、锁定及待下一生产拍量。

逐步支付与失败只在[TL-30](../rules.md#tl-30-制造材料与效果支付分阶段)维护；同列及后续列消费者按TL-11逐个读余额，不重复花层。即时新增可供后步／后列，不倒补失败；结算期间不开工，下一生产拍拍末开工可读当时余额。释放最早下一生产拍可用，不在列间可用。

## 批次标记冻结（CORE-055）

仅开工侧明示费用：联合检查成功，足额冻结并记宿主／种类／数量／批次，幸存完工扣除。冻结仍属宿主，但其他效果不可读取／支付。

自然到期或合法移除仍作用冻结量：清实有失效量、记失效承诺，不补扣新增、不重算D。完工只扣仍有效部分并结清承诺；打断只释放有效部分，下一生产拍可用。开工依固定战前法器序占用剩余量；玩家锁定只作用未承诺量，不能撤批。

## 定时登记与兑现

以下两节保留CORE-057旧连续拍扩展；CORE-065首场未迁移，不能把敌后续手牌等同于独立定时登记。

有明确内容才登记，原卡离队，独立登记不占Q、不再翻牌。声明来源、宿主／目标、基础量、首次／周期、结束／次数及停止条件；虚幻砝码仅预告。

## 定时登记与有效期合同（CORE-057）

| 项目 | 规则 |
| --- | --- |
| 时间 | s建立，整数首次f≥s+1；正整数周期p，周期内容必须有限次数或结束拍e；只在兑现拍<e且次数剩余时尝试，落空也耗一次，不补兑 |
| 名单与顺序 | e边界先失效；新登记不进本拍候选，同登记每拍最多一次；保持独立身份／建立序，同源按步骤序，初始序由遭遇给定 |
| 绑定与清理 | 默认建立时绑定合法宿主实例，无宿主不建立、不付该步费；独立于原卡、法器及其他敌牌，宿主死亡／终局清理，不补发 |
| 取值 | 保存基础量、来源和支付归属，每次兑现从步骤开始状态读条件／层数／修饰；只有明示快照按其声明 |
| 有限期状态 | 同样不含e；锁定不挡到期／移除，失效量从锁定减去、不转锁新层；冻结按上段结清 |

并存／覆盖／刷新和登记预算由内容声明，实有上限与登记预算分别检查。不开放任意触发或递归登记，额外事件沿TL-37。

## 信息与反馈

结算开始后不得通过列间暂停锁解；最终整理前锁定沿共用合同。新首场只展示实际采用的余额，未来登记不作为现行功能。宿主旁用砝码堆叠、正负分侧，未来用虚幻预告；实际／上限／来源／期限及各余额资格可查。点击、键盘和空状态合并沿[交互合同](../../../common/interaction-save/rules.md#tl-17-暂停与信息)，不能混淆余额。
