# 行动卡：体验目标

2026-10-23 · Hypothesis / NotRun。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 交锋清楚 | 说明哪次效果造成了什么变化 | 只有数字／特效，不知作用 |
| 投入可追溯 | 解释投入换得什么及落空原因 | 把产卡当兑现，或未命中就期望退款 |
| 单卡强而清楚 | 辨认实际影响和必要条件 | 关键条件藏在多层详情 |
| 整理值得付费 | 能解释一次调序／换牌收益与放弃的点数 | 每轮只能照固定答案整理，或整理永远无效 |
| 积累有取舍 | 解释现在消费与保留的用途 | 只有固定自动消费路线 |
| 失败能预测 | 分清截止、目标与支付失败 | 通过动画先后猜胜负 |

观察时先记录玩家预测与选择理由，再对照实际结果。分开记录规则误读、信息找不到、数值失衡；使用具体内容和界面版本。验证任务尚未执行。
