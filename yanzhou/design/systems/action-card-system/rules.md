## TL-01 统一卡牌与战斗权限

卡牌以战斗使用权限分为三种：可上战斗行且使用后回手、可上战斗行且使用后不回手、不能上战斗行。材料是卡在配方中承担的用途，不另设与战斗牌互斥的“资源卡”种类；行动是卡在战斗列中的一次使用，不是另一种永久身份。

手牌分可战斗与不可战斗两组持牌查看；可战斗组标明是否回收。两组属于同一本场持有集合，切换视图不移动、复制、消费或自动使用卡，也不改变时间。战斗权限不等于配方匹配或跨战携带资格。

铭文与法器仍属配置实体，标记仍附玩家／敌人，金币独立；本次归并不授予它们普通卡牌的使用／消耗权限。敌牌沿其原程序，不进入玩家手牌或配方。

采纳依据：[CORE-067](../../../sources/draft-changes/D-2026-10-27-unified-card-model.md)。

## TL-44 行动类别与独立卡效

攻击▲、防御■、打断⊘、其他✱始终配文字。暗句确定种类，卡效独立声明；类别不决定结算组，槽数不决定张数。完整字段只在[内容合同](../../content/cards.md#内容必填字段)维护。

## 行动、标记与后续兑现

ACT-Q1的独立未来效果仍为扩展方向，新回合时序未闭合，不在本首场启用；ACT-Q2允许简单宿主／种类／层数条件及明示支付，不扩展为队列、行动或资源状态条件句。制造完成不产生卡效标记，合法行动步骤才产生；即时层数与未来预告分开。具体余额和生命周期见[标记规则](mark-system/rules.md)。

## TL-09 敌牌揭示与锁定

原生暗牌在回合开始布置，只公开位置、种类、即时／延时标识。到该列开始才公开完整效果、量值和目标；即时普通伤害当列执行，延时牌生成下一回合的公开后续行动。已知后续牌落桌不再次隐藏。[TL-16](../enemy-system/rules.md)管固定基础表、覆盖位置和循环。

指定打断在生成后续牌时，从正在加工者选剩余生产拍R=a+D−t最大者，并列取战前法器序。这里t为当前累计生产拍；生产末拍的完工和续开已经完成，不使用旧揭示时R0截击。无加工者记录无对象，不到下轮补选。锁法器，后续牌执行时只检查它当时批次；无批次则落空。

## TL-11 共同拍序与效果边界

### 回合与生产拍

回合n走(n−1)X+1至nX生产拍，当前X=5；第0拍先布首行、就绪观察，零材料用途再首次开工，有耗材初始预放最早第1拍吸收。以后回合准备只清旧行、布敌牌，不额外检查开工。开场手牌／玩家行沿真实初态，EX-004为空；无整理行动点。每次准备只执行一次，恢复不能重做准备或换牌。

| 每生产拍顺序 | 处理 |
| --- | --- |
| 1 边界 | 上拍待用资源／仍有效释放量可用；旧临时供料到期恢复机制退役。未迁移的有限期／定时内容不参与 |
| 2 复查 | 复查前一合法生产观察停点的已提交设置及待料资格，不在运行中接收新编辑；不揭示原生敌牌、不执行桌面卡效 |
| 3 完工 | 达到a+D的批次按战前序结清制造费用，将声明卡牌产物按TL-05放入对应手牌组 |
| 4 维护／恢复位置 | 为未来合法持续内容保留位置；当前首场无该内容，旧生命周期不能自动套入 |
| 5 开工 | 空闲法器按战前序各检查本器完整待料／明示零材料及必要条件一次，不回扫；吸收腾位，新批当拍不推进D |
| 6 自动补料 | 所有开工检查后按战前序为开启自动的法器补足一批待料；不部分自动搬入，新补料最早下一拍吸收 |

第X生产拍及动画结束后自动停在最终整理，接受免费布牌及标记锁解，不编辑生产待料／用途／自动开关；确认才进入第1列。末拍产物可由玩家放入本轮，末拍已开工批次不可撤。窗口见[TL-18](../../common/interaction-save/rules.md#tl-18-手动上行撤回与整理)。

### 逐列结算

结算列1至X不推进生产拍或任何按生产拍计的时间，也不开工、完工、维护或处理生产拍边界的退料／冻结量释放。合法卡效仍可按声明产生新卡或即时标记，其用途与可用时点见下文。每列开始公开该列原生敌牌，并固定该列双方尚有效的行动；已取消位置跳过、不补位、不从手牌补翻。

先防护组，再其余组；每组敌→玩家，牌内按声明步骤序与依赖。防护仅直接护甲或明示抵挡伤害／打断；治疗、加层、资源、削弱、取消、伤害和生成后续牌均为其余步骤。跨组仍为同一张牌的一次使用，后列不抢先，已执行步骤不重复。

候选固定后逐项复查来源、目标、条件与费用。即时标记可被后续步骤／列读取支付，不能倒补失败；防护不能依赖还未执行的攻击／加层。新卡入手后可在下一合法窗口上行，但作为配方输入最早下一生产拍可用；退料及有效标记释放仍下一生产拍才可用。回收原卡不附加待用期，列间不推进边界或开工。

每个非末列结清及动画结束且未终局，停在列间布牌窗口，确认才开始并公开下一列。所有列完成且未终局，才处理本回合到期疲劳；之后结束本轮、准备下一轮。疲劳独立于第X列，是最后一个回合末事件；暂停和单步沿交互合同，不能为停点抢跑疲劳或重复换轮。敌人定时由后续牌占位表达，不等于旧独立定时登记。

### 复合牌、目标与支付

目标绑定和名单唯一规则见[铭文TL-27](../inscription-system/rules.md#tl-27-卡效的实例条件绑定与本次名单)。每个目标组首次使用前形成名单，后续步骤复查、不补位。敌普通伤害按该列公开的内容选目标；后续打断沿生成时保存的锁定。

费用与量值按[TL-30](#tl-30-制造材料与效果支付分阶段)逐步检查。独立步骤可继续，依赖失败步骤则跳过；已完成结果不回滚。

### 卡牌使用与回收（CORE-067）

每列最多处理一张己方牌；防护组／其余组及敌→玩家的顺序、逐步支付、依赖和完整事件判终局保留。一张跨组卡的同一次使用必须等全部可执行步骤处理完、失败依赖已跳过，才算本次结束；不能在防护步骤后提前回手再执行一遍。

本次处理结束且战斗未终局时，可回收牌的原实例立即返回可战斗手牌组，内容与来源不重生，不增加回收冷却；不可回收牌移除。空放或费用不足同样处理完本次使用，再按回收属性决定去向，不退款、不倒补。以后再次上行是新一次使用，按当时目标、条件和足额费用重检，成功步骤可再次产生其声明的效果。

原行位保留只读结果到换轮，不再持有一份可操作卡；已执行列不重用。回手可用于下一个合法列间出牌窗口，不能插回当前列。末列回手立即取得手牌资格，但本轮已无可用列；不凭回收增加第六列或推进生产。

每个完整事件后仍立即判终局。若中途终局，余步骤、列、出牌窗口及未来生产停止；不为了回手补执行尚未发生效果。按已开始使用／尚未使用及实例归属完成一次确定性清理：已使用的不可回收牌不因尚有余步骤而保留；可回收及未使用卡转入战终归属核对，仍须满足独立携带资格，不能补收益或重复生成实例。

### 完整事件、反应与终局检查

一个完整事件＝一个基础步骤的检查／支付、主结果、已获准的一层附属反应及必要死亡清理；一击一个事件，整卡、整列或整回合都不是一个事件。生命归零立即失去存活目标资格，事件结清后按[核心TL-13／24](../../GDD.md#tl-13-生命程序循环与终局)检查；双亡玩家败，余步骤不执行。未终局时下一步重新核对来源、目标和条件。共同疲劳的双方损耗是同一主步骤。

**仅当内容明确使用多目标／反应：**一个同时作用多目标的步骤先固定名单及各主结果读取状态，执行全部合法主结果，再处理反应，不在目标间判终局。反应来源取主步骤开始时已有名单，主结果满足明示条件才获准；新状态不参加。按来源建立序、同源声明序处理，仍复查必要目标且不补位。已获准反应不因来源在该主结果中死亡撤销；反应不再触发反应，死亡清理不生成新收益。本段不自行开放反伤、复活或任意监听。

附属反应在所属事件内结清，不重排到全局防护组、不回改伤害；同列开始后不能取消该列敌牌。生产拍／结算列分别收尾暂停，疲劳是独立回合末事件，详见[CORE-064／067](../../common/interaction-save/rules.md#拍末暂停core-064)。异常保存仍保留最近完整事件；列内不接收玩法调整，列间仅沿TL-18编辑未开始的己方牌，不暗存其他下轮操作。

## TL-29 对象身份、护甲与失效

身份、数量、状态与能力分开。计量归零失去该状态资格，但合法效果量为0不等于对象消失；布尔或保留零值例外须明示。

护甲按宿主累计，无自然到期、周期扣减或统一上限；耗尽消失、可重新获得，不转移，战终清理。普通直接／持续伤害先扣护甲。

死亡清理宿主依赖状态；独立产物按声明存续。事件与终局沿TL-11，不额外生成资源或补结算。

## TL-30 制造材料与效果支付分阶段

| 阶段 | 唯一处理位置 |
| --- | --- |
| 开工承诺 | [TL-05](../artifact-system/rules.md#tl-05-开工预留与完成入行)：联合检查配置、本器完整待料及吸收时点、D与必要标记，不检查成品容量。最终效果目标不作为制造条件 |
| 普通耗材结清／退还 | [资源TL-15](../resource-system/rules.md#tl-15-托管输出与自动维护)：完工消费；未完工退料不补产物；制造后空放不退款 |
| 开工侧标记 | [冻结合同](mark-system/rules.md#批次标记冻结core-055)：开工占用、幸存完工扣除；不混作即时支付 |
| 行动侧支付 | 以下逐步合同；无声明不额外收费 |

每步开始时以同一状态确定目标资格、条件、完整费用及量值；全部满足才足额支付并执行，不因本步扣费后余额变化回算本步，后续步骤重新读取。无目标不扣该步未付费用；不足不部分扣费、不重试。已成步骤不因后续失败退款；可选增强仅在明示基础回退时保留基础结果。费用须声明付款者、资源和所属步骤，不能跨阶段重复收费；可用量遵守[标记资格](mark-system/rules.md#读取与支付)和玩家锁定。
