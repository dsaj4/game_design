# 卡牌与战斗使用：规则

2026-11-05 · TL条款为CurrentSpec / round-plan.1，继承CORE-067；供料／待料与打断介入生产已由CORE-075替换；ACT框架资格沿[基准](../../baseline.md)。[设计](../../../system-design/action-card-system/design.md) · [体验](../../../system-design/action-card-system/experience.md) · [示例](examples.md)

先读TL-11的生产拍／整轮锁行／逐列结算和TL-30。当前首场不启用独立定时、有限期或维护内容；扩展需先补新时序。多目标／反应段只限定既有通用事件语义，不发行新能力。

<a id="tl-01-三类卡牌"></a>
## TL-01 统一卡牌与战斗权限

卡牌以战斗使用权限分为三种：可上战斗行且使用后回手、可上战斗行且使用后不回手、不能上战斗行。材料是卡在配方中承担的用途，不另设与战斗牌互斥的“资源卡”种类；行动是卡在战斗列中的一次使用，不是另一种永久身份。

手牌分可战斗与不可战斗两组持牌查看；可战斗组标明是否回收。两组属于同一本场持有集合，切换视图不移动、复制、消费或自动使用卡，也不改变时间。战斗权限不等于配方匹配或跨战携带资格。

铭文、法器与辅助道具属配置实体，标记仍附玩家／敌人，金币独立；本次归并不授予它们普通卡牌的使用／消耗权限。敌牌沿其原程序，不进入玩家手牌或配方。

采纳依据：[CORE-067](../../../sources/draft-changes/D-2026-10-27-unified-card-model.md)。

## TL-44 行动类别与独立卡效

攻击▲、防御■、打断⊘、其他✱始终配文字。暗句确定种类，卡效执行步骤明确声明；CORE-079已映射内容的效果来源按[TL-49](../aspect-system/rules.md)区分主字相、物相和可选特殊词条。类别和词条来源不决定结算组，槽数不决定张数；拥有词条也不授予战斗权限。完整字段只在[内容合同](../../content/cards.md#内容必填字段)维护。

## 行动、标记与后续兑现

ACT-Q1的独立未来效果仍为扩展方向，新回合时序未闭合，不在本首场启用；ACT-Q2允许简单宿主／种类／层数条件及明示支付，不扩展为队列、行动或资源状态条件句。制造完成不产生卡效标记，合法行动步骤才产生；即时层数与未来预告分开。具体余额和生命周期见[标记规则](mark-system/rules.md)。

## TL-09 敌牌揭示与锁定

原生暗牌在回合开始布置，只公开位置、种类、即时／延时标识。到该列开始才公开完整效果、量值和目标；即时普通伤害当列执行，延时牌生成下一回合的公开后续行动。已知后续牌落桌不再次隐藏。[TL-16](../enemy-system/rules.md)管固定基础表、覆盖位置和循环。

CORE-078积压者第3列按已声明步骤先伤害、未终局再生成后续；牌背同时标明即时／延时两种时间行为，仍不提前公开量值。逐完整事件终局与其余组敌→玩家顺序保持，具体限定只由TL-16维护。

CORE-075不做打断介入生产：敌牌不锁定法器、不命中在制批次，原打断锁定条款退役。后续若有针对己方牌的敌方效果，以另行采纳的封印牌表达，提前一回合公开，被封印的牌按TL-21空放，不触及生产。

## TL-11 共同拍序与效果边界

### 生产拍、整轮确认与战斗列

每轮先5生产拍，再不限时布置、一次确认锁定五位，逐列自动结算，最后处理独立轮尾。首轮生产吸收旧序幕，不额外加拍。第r轮累计生产p=5(r−1)+1至5r；战斗列j=1—5独立，战斗及布置不推进D。

每拍开始先检查全部本拍草稿的完整材料／配置／P／D／占用及合计必要费用。非法则整拍拒绝暂停，已有在制亦不推进，原草稿及归属保持。全合法才共同冻结新批次，推进在制；到期批次按开工拍、战前冻结实例登记序、批内声明序结清，再按登记序发到期补给。无玩家法器优先级设置。每批消费普通输入、结清制造费用及交付声明产物为一个完整提交；同拍补给一组一次整批交付。每完整事件查终局，已结清结果不重复。生产期不执行敌行动。

p开工占用p至p+D−1，拍末到货，下一工序最早p+D；到货后的合法布置可上本轮任意战斗列。不能用本拍到货／补给倒供本拍开工，不将预告当库存。同器前拍完工后可下拍续批。未来草稿不阻挡本拍，未排工序不会自动开工。

最终确认只共同检查整行实例归属、战斗权限及位置，合法才一次锁定五位；失败保持可编辑、不揭示敌牌。未来生产草稿不阻挡该确认；卡效的目标、条件与支付仍到生效步骤核对。重复确认不重复锁行／排事件。确认后不追加开工、编辑行或锁解标记。

### 逐列结算

各列开始才公开本列原生敌牌并固定本列双方有效行动。先防护组再其余组，各组敌→玩家，牌内声明步骤和依赖顺序；空位跳过、不补位。防护只含直接护甲或明示抵挡，治疗、加层、资源、取消、攻击及生成后续属其余组。

即时标记可供后续步骤／列读取支付，不能倒补失败；战斗新增标记不倒补已结束的生产阶段。新卡及回收卡入手都不改变已锁行，本轮不能重新排入，下轮才可战斗／排料。敌后续依TL-16进入下一回合。

非末列自动开始下一列，不开放列间编辑；有暂停请求则收尾当前列停住，继续仍沿锁行执行。第五列后疲劳独立于该列，未终局才处理到期疲劳、结束和下一轮准备。回合准备清旧结果、布敌行各一次，不推进加工。生产及战斗的暂停／单步／恢复沿TL-17／19。

采纳依据：[本轮D](../../../sources/draft-changes/D-2026-11-05-round-plan-alignment.md)。

### 复合牌、目标与支付

CORE-079的词条叠加是作用来源的组合，仍须按本节及TL-30声明目标、步骤和依赖；不自动同时触发、复制同相效果或忽略费用。净化、药毒等探索示例未成为现行可执行卡效，不用示例措辞补目标、数量或顺序。

目标绑定和名单唯一规则见[铭文TL-27](../inscription-system/rules.md#tl-27-卡效的实例条件绑定与本次名单)。每个目标组首次使用前形成名单，后续步骤复查、不补位。敌普通伤害按该列公开的内容选目标；后续公开牌沿生成时保存的锁定目标。

费用与量值按[TL-30](#tl-30-制造材料与效果支付分阶段)逐步检查。独立步骤可继续，依赖失败步骤则跳过；已完成结果不回滚。

### 卡牌使用与回收（round-plan.1；保留原锚点）

<a id="卡牌使用与回收core-067"></a>

每列最多处理一张己方牌；防护组／其余组及敌→玩家的顺序、逐步支付、依赖和完整事件判终局保留。一张跨组卡的同一次使用必须等全部可执行步骤处理完、失败依赖已跳过，才算本次结束；不能在防护步骤后提前回手再执行一遍。

本次处理结束且战斗未终局时，可回收牌的原实例立即返回可战斗手牌组，内容与来源不重生，保留本批静态辅助合计贡献且不重新施加，不增加回收冷却；不可回收牌移除。空放或费用不足同样处理完本次使用，再按回收属性决定去向，不退款、不倒补。以后再次上行是新一次使用，按当时目标、条件和足额费用重检，成功步骤可再次产生其声明的效果。

原行位保留只读结果到换轮，不再持有一份可操作卡；已执行列不重用。回手立即取得手牌归属，但整轮锁行保持，本轮不再排战斗或制造；下一轮才可安排。同名不同实例可分别使用。不凭回收增加第六列或推进生产。

每个完整事件后仍立即判终局。若中途终局，余步骤、列、出牌窗口及未来生产停止；不为了回手补执行尚未发生效果。按已开始使用／尚未使用及实例归属完成一次确定性清理：已使用的不可回收牌不因尚有余步骤而保留；可回收及未使用卡转入战终归属核对，仍须满足独立携带资格，不能补收益或重复生成实例。

### 完整事件、反应与终局检查

一个完整事件＝一个基础步骤的检查／支付、主结果、已获准的一层附属反应及必要死亡清理；一击一个事件，整卡、整列或整回合都不是一个事件。生命归零立即失去存活目标资格，事件结清后按[核心TL-13／24](../../GDD.md#tl-13-生命程序循环与终局)检查；双亡玩家败，余步骤不执行。未终局时下一步重新核对来源、目标和条件。共同疲劳的双方损耗是同一主步骤。

**仅当内容明确使用多目标／反应：**一个同时作用多目标的步骤先固定名单及各主结果读取状态，执行全部合法主结果，再处理反应，不在目标间判终局。反应来源取主步骤开始时已有名单，主结果满足明示条件才获准；新状态不参加。按来源建立序、同源声明序处理，仍复查必要目标且不补位。已获准反应不因来源在该主结果中死亡撤销；反应不再触发反应，死亡清理不生成新收益。本段不自行开放反伤、复活或任意监听。

附属反应在所属事件内结清，不重排到全局防护组、不回改伤害；同列开始后不能取消该列敌牌。最终布置无时限、战斗各列自动继续且接受列末暂停，疲劳是独立回合末事件，详见[CORE-064／067](../../common/interaction-save/rules.md#拍末暂停core-064)。异常保存仍保留最近完整事件；列内不接收玩法调整，列间不接收玩法编辑，不暗存其他下轮操作。

## TL-29 对象身份、护甲与失效

身份、数量、状态与能力分开。计量归零失去该状态资格，但合法效果量为0不等于对象消失；布尔或保留零值例外须明示。

护甲按宿主累计，无自然到期、周期扣减或统一上限；耗尽消失、可重新获得，不转移，战终清理。普通直接／持续伤害先扣护甲。

死亡清理宿主依赖状态；独立产物按声明存续。事件与终局沿TL-11，不额外生成资源或补结算。

## TL-30 制造材料与效果支付分阶段

| 阶段 | 唯一处理位置 |
| --- | --- |
| 开工承诺 | [TL-05](../artifact-system/rules.md#tl-05-开工预留与完成入行)：生产拍开始前联合检查本拍各器配置、完整材料／零材料指令、P、D与占用区间，并合并开工费用；不足或非法整拍拒绝，不部分冻结，不检查成品容量。最终卡效目标不作为制造条件 |
| 普通耗材结清／退还 | [资源TL-15](../resource-system/rules.md#tl-15-托管输出与自动维护)：完工消费；没有战中撤批退料，战终未完工普通输入按TL-25退回、不补产物；制造后空放不退款 |
| 开工侧标记 | [冻结合同](mark-system/rules.md#批次标记冻结core-055)：开工占用、幸存完工扣除；不混作即时支付 |
| 行动侧支付 | 以下逐步合同；无声明不额外收费 |

每步开始时以同一状态确定目标资格、条件、完整费用及量值；全部满足才足额支付并执行，不因本步扣费后余额变化回算本步，后续步骤重新读取。无目标不扣该步未付费用；不足不部分扣费、不重试。已成步骤不因后续失败退款；可选增强仅在明示基础回退时保留基础结果。费用须声明付款者、资源和所属步骤，不能跨阶段重复收费；可用量遵守[标记资格](mark-system/rules.md#读取与支付)和玩家锁定。
