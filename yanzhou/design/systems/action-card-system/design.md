# 行动卡：设计

2026-10-27 · DesignNote。行动设计意图、ACT-Q1／2 为已确认方向；TL 条款为现行规则。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

表现攻防交锋，将上游安排兑现为战斗与资源结果。

| 设计重点 | 内容 |
| --- | --- |
| 单卡 | 效果清晰简单，单卡可以强力。说明对象、结果与必要代价；复杂度看理解所需信息，不仅看字数。 |
| 协同 | 用标记连接清楚的单卡；普通攻防仍可独立成立。 |
| 投入与兑现 | 连看材料、D、列位、手牌及每次效果支付；合成直接产卡，战斗卡效只有实际执行才生效。回收原卡与生成新卡分开。 |
| 表现 | 生效体现炼金／法术最后的使用效果。先看对象与实际变化，再查来源和步骤；动画服从规则时点。 |
| 选择 | 生产与最终整理可改未来用途；手动布牌免费，列间可改后续己牌但不能改用途或锁解，下一暗列未揭示。每次使用仍按目标与费用结算。 |
| 可追溯 | 区分桌牌、手牌、公开敌后续与宿主实有状态；独立定时尚未迁入当前首场；展示成功、延误、空放和终局未兑现的原因。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q02／04／06、FB-Q02。
