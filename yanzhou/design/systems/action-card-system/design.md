## 定位与玩家选择

行动卡把法器配置和生产投入变为一次可辨认的战斗结果。既有设计要求玩家看出“已经做好”与“来得及生效”的差别：面对公开倒计时，比较队列、材料和法器状态，决定应对或接受损失；普通区间由基础循环解决。

本轮已确认以标记扩展持续状态和后续兑现，使行动既可以当下解决问题，也可以为后续配置提供状态条件或支付来源。是否形成值得比较的路线是体验假设；不能只凭多加一种资源就宣称构筑更深。

四类行动用于识别用途。“其他✱”可以承载已明示且合法的状态效果，不作为任意新机制的入口。不要求每张行动都附带标记，普通伤害、防护、取消仍有独立设计空间。

## 表达与风格

已确认的标记方向是炼金／铭刻语境下的施法残留与砝码堆叠，细节归 [标记设计](mark-system/design.md)。通用行动符号和文字不地方化，地域风格仍只在既有允许的表现范围内调整。

建议先展示卡效结果、对象、时间及必要代价，再展开来源与复合细节；具体版式未定。原卡尚在队列、卡已结算而定时效果待兑现、宿主已有标记，三种状态必须有可辨差别。独立定时效果不绘制成又一张占位卡；预告如何映射到时间轴留表现设计。

## 待定接口

| 未决项 | 已确定的边界 | 后续需决定什么 |
| --- | --- | --- |
| 定时效果的同拍位置 | CORE-057／TL-11已定防护／其余分组及组内定时→敌方→玩家 | 具体卡效按组归位，不能另用动画顺序 |
| 一张复合卡的执行 | CORE-057已定步骤分组、逐事件结清、同卡后续可用即时标记；禁止逆向依赖 | 具体卡效仍须声明步骤、费用归属和依赖，不能让后组收益补前组失败 |
| 标记支付失败 | TL-11足额检查、失败不重试；独立步骤继续，依赖步骤跳过；既成结果不退费 | 每张卡声明必要／可选分支，不默认拥有基础回退 |
| 未来效果的目标 | CORE-057默认登记时绑定宿主并独立于原卡；宿主死亡或终局清理 | 特定敌牌依赖等例外须另行明示采纳，不从名称猜规则 |
| 时间与周期字段 | CORE-057已定首次最早下拍、结束拍不含末次及稳定登记序 | 持续刷新／覆盖、并存及登记预算仍待具体内容 |
| 卡类与复合表达 | 四类 UI 已定，各效果权限独立 | 复合卡的主类别、信息密度和具体模板；不沿空缺数推定多产 |

具体标记上限、溢出、层数效应和生命表现见子系统未决表；本页不填一套默认参数。先前阶段已经交付的候选保留原身份，本轮只抽取通用层，不重做全部卡池。
