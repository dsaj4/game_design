# 资源系统：规则

2026-10-23 · CurrentSpec。[基准](../../baseline.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

首批EX无材料或维护对象；新增资源用途才展开TL-14／15／43，实际使用持续产物再展开维护段。TL-37普通量值仍适用于已有行动。

## TL-14 卡牌战场与环境供给

战场为敌方行、资源区、玩家行及加工区；范围用对象集合／卡牌关系，不用旧格坐标。资源区收本场投入、环境料、中间和行动产物，不另设战中硬容量。

基础补给按内容周期／数量产生，新增料下拍可用，初始料0拍可用。消耗式加工减少或替换环境卡，托管后不能重复取用，再生须明示；材料与铭文、金币、干涉额度分账。

## TL-15 托管、输出与自动维护

| 普通耗材所处阶段 | 结果 |
| --- | --- |
| 开工 | 托管完整材料，其他用途不能取用 |
| 幸存完工 | 消费材料、产行动；以后排队、空放或终局均不退料 |
| 完工前被打断 | 退料最早下拍可用，完整后果见[TL-07](../artifact-system/rules.md#tl-07-打断与返工) |
| 未完工战终 | 退回后按携带资格选留，不补产物 |
| 资源行动生效 | 才生成资源，下拍可用，不再要求已消费输入实例存活 |

持续产物须另给维护、增幅、作用窗口、消失及战终合同；催化剂、托管维护、休眠加工未闭合内容不运行，见TL-Q03。

**TL-22：**到期维护不足则休眠，保留身份与增幅；补足自动恢复。
**TL-23：**维护→旧休眠恢复→新开工；前两者按下段，开工仅引用[TL-05](../artifact-system/rules.md#tl-05-开工预留与完成入行)，不另维护争料算法。所有自动消费排除玩家锁定，锁定不撤回托管或禁止合法非消费读取。

## TL-37 参数、来源与有限事件的共同合同

普通量值：`q=max(0, floor((基础量+固定增量合计)×倍率))`，无倍率取1，多倍率合成须内容声明。写单位、域、零值、读取时点和修改方式，合法0不等于程序非法。D用[时间公式](../artifact-system/rules.md#时间修饰公式core-056)，费用／维护周期／携带／疲劳各用自身域。

可追溯来源法器、批次和支付，不跨来源借加成。额外事件须声明次数、资格、后续触发与终止，不把条件筛选当触发，不允许未声明递归；持续对象说明来源消失后是否独立。

## TL-43 材料类别绑定制造内容

材料属于具体用途配方，不填暗句核心；完整字段见[内容合同](../../content/cards.md#内容必填字段)。明确零材料合法，漏字段不等于零；无铭文基础加工与零材料相互独立，前者仍经D、Q及普通行动队列，见TL-38。

### 资源身份、性质与阶级（CORE-058）

资源有身份／外观、少量性质和阶级。普通槽匹配性质＋最低阶级，特殊槽匹配身份；每份只能付一个槽。低不代高，高可付低但不自动增强。默认最低合格阶级，遵守锁定／维护／供料序；同阶选择和复合匹配须内容明确。指定阶级不足等待，不自动降阶。

### 法器分工与多阶兑现（CORE-058）

转化／升级与兑现是主要分工，不是互斥分类。兑现按明示性质和阶级接中间料，各阶相似产出同时有量值与效果差异，逐配方给行动、费用和D。

### 基础加工与环境信息（CORE-058）

普通用途公开性质、阶级、兼容、消耗与产物；等待说明原因，不自动换用途。基础启动不依赖隐藏彩蛋，彩蛋可错过。

## 维护与恢复次序（CORE-057）

仅用于已声明维护的持续产物，不凭本段新增首场维护系统。

1. 阶段开始固定两名单：活动且到期维护者、此前休眠且本拍可用者；新产／待下拍对象不入。
2. 先维护、后恢复，两组均按建立序；初始序由遭遇给定，同次建立沿目标／输出序。次序可查可保存，不随临时供料序改变。
3. 每对象每拍检查一次，完整费用和合法资源／标记共同满足才足额支付，排除托管、冻结、锁定、待用量。不足不部分扣费；活动者休眠，旧休眠保持；刚失败者不进本拍恢复名单。
4. 恢复只付一份正常周期费，不补欠费；成功当拍活动，下次维护t+p（p为正整数）。正常维护成功同样从t计时。恢复不重做此前战斗效果，新产首次维护时点由内容给定。
5. 两轮结束才按TL-05逐台新开工，前一占用立即影响后一者。
