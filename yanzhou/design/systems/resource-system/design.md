# 资源：设计

2026-10-27 · DesignNote。CORE-058 已采纳三项职责。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

提供运行约束、产出积累与环境表达。

| 设计重点 | 内容 |
| --- | --- |
| 核心约束 | 材料在即时攻防、继续精炼和跨战保留间分配；避免逐批搬料和重复等价收费。 |
| 产出积累 | 中间料可兑现，也可继续升级；各阶在量值和效果上都有差异。准备须改变可用能力。 |
| 环境表达 | 就地取材改变计划，消耗环境材料有机会成本；公开基础用途，特殊发现可以错过。 |
| 密度 | 全局种类可丰富，单场少量；高阶常见1—2个是设计目标。 |
| 链条预算 | CORE-067合成直接产卡，不再每道占战斗列；连算材料、D、后续供料时点及消费可回收牌失去的战斗机会。旧中介行动链的列位预算不能沿用。 |
| 长期取舍 | 背包、投入、选留应保留本战与后续的竞争；检查高阶囤积是否让现场材料多余。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q01／03、INS-Q03。
