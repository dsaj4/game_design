# 资源：体验目标

2026-10-31 · Hypothesis / NotRun。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 精炼有选择 | 因截止不同而直用或继续加工 | 每战固定先走同一条链 |
| 完成有意义 | 解释每道工序获得的后续能力 | 只等进度条，差异只有重复数字 |
| 自动供料可用 | 能预测自动补入哪张，关键时刻改待料或关闭自动，平时自动运行 | 自动选走想保留的牌，或持续锁解才能保护中间料 |
| 准备有代价 | 说明带什么、供料区能放下什么、投入什么与放弃什么 | 通用套装支配所有环境 |
| 语义能迁移 | 用性质和阶级理解新材料 | 每张都要重背完整配方 |

观察时先记录玩家预测与选择理由，再对照实际结果。分开记录规则误读、信息找不到、数值失衡；使用具体内容和界面版本。验证任务尚未执行。
