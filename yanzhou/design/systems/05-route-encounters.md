# SYS-005 路线与敌方程序

Project ID：game-002。文档角色：CurrentSpec。2026-10-05 / GDD 2.1 / TL-1 + INS-1 / processing.2 + timing.1 + enemy.1。结构已采纳；完整内容Unknown，体验Hypothesis / NotRun。

## 设计用途与保留范围

路线、战斗、休整和商店继续承担局内推进与构筑调整的用途。玩家在进入遭遇前比较可见机制和自身生产能力，在战斗中应对已揭示的行动。

旧版19节点、6普通＋首领、12遭遇、固定敌攻公式和数值建立在RC1卡池与2×5战场上。本次没有把这些完整表迁成新内容，也没有据此承诺新局时长。新路线规模与各节点的资源条件需随新卡表复审。

## TL-16 敌方程序约束

- 每场战斗只有一个发出敌牌的来源敌人，其死亡即胜（SYS-003 TL-13）；可有不发牌的附属物，规则另定。
- 开战前预置敌方暗牌程序，采用固定循环时间表：每张暗牌有循环内翻开偏移与Δ，循环长L，不因取消或玩家行为移动。开战即公开程序位置、翻开拍与卡背行动种类，内容在翻开时公开（[CORE-054](../../sources/draft-changes/D-2026-10-05-stage-two-enemy-pressure.md)）。
- 所有敌方行动牌揭示后按SYS-003启动正延迟倒计时，完整公开并锁定目标；不存在揭示即生效的敌方行动牌。
- 通常安排一个需要主动处理的关键威胁，少量双威胁组合。不能把全部普通倒计时都算作强制微操。
- 成功取消保留空档，后续程序不提前；段尾循环不清掉旧倒计时。
- 设计应对窗口时，要计算开工前的供料／容量等待、处理耗时与入行后排队；入行后最早下一拍翻开，队列可能更晚，不再加J、R、独立周期或S。取消必须严格早于T；已可生效防护按TL-11可在T拍先结算，不能给两者套同一截止。正延迟为资源改配和未来开工调整提供预警，不保证每个失误后的状态都可挽回。
- 敌方的隐藏信息不代表临时读取玩家选择后改牌；是否及怎样生成程序，具体内容须明示。指定打断按SYS-003 TL-09在翻开时读取公开施法状态锁定法器，属于目标选择，不改变牌的内容。

## TL-32 单向路线与遭遇信息

本局路线按约束生成一次后固定，所有可选分支应能向终点推进。玩家到分叉再选下一节点，不必开局承诺全局路径；已进入节点不可撤回重抽，已通过节点不重复访问或领奖。查看地图、进入详情及退出恢复不刷新路线或货架。

出发前可见下一批可选节点类型、遭遇敌人类型与主机制，并知道向前可达的下一休整／商店；后续没有该类节点时明确提示。商店具体商品抵达后才揭示。遭遇摘要不展示全部敌牌内容：战中隐藏、卡背线索与揭示权限仍沿TL-09，不能用旧“完整攻击安排预览”绕过它。

完整路线至少提供一次终点前可选商店机会，且该机会之前有可获得金币的战斗。玩家可以跳过，系统不在后面免费补一家；节点规模、间隔、奖励和实际可负担价格仍待设计。普通失败结束本局，终点首领胜利结束本局；不自动延长到额外商店或新奖励层。

路线验收要使用真实初始库存、实际已领取收益和携带容量，检查能否前进、有无消费机会及不同分支代价；不把“路上存在铭文渠道”当作已经获得某张铭文。

## 遭遇字段与失败路径

每场至少说明来源敌人身份与所属地域牌组、附属物（如有）、生命／护甲、暗牌程序与卡背种类、翻开偏移、各牌延迟、触发效果、锁定规则、可打断条件、资源供给、起始材料、循环长度和段尾冲突检查。旧敌人“不持有玩家法器”的不对称表达可保留，不能自动赋予敌方完整生产系统。

当玩家没有对应打断法术时，应仍可判断承受损失、保护或调整未来生产的代价；不承诺每套构筑都能取消每张敌牌。单一来源后不再有多敌合并程序；锁定目标失效按SYS-003落空处理。同一来源多牌同刻到期的规则尚未确定，首版内容不安排，不用隐含优先级补齐。

## 验收与下一步
