# SYS-002 法器生产与编排

Project ID：game-002。文档角色：CurrentSpec。基准：GDD 2.1 / TL-1 + INS-1。2026-10-04。本文已采纳条款与Unknown分开；体验Hypothesis / NotRun。

## 目的与玩家选择

玩家选择法器与合法铭刻配置，安排周期和首次运行起点，让行动在需要时入行。平时自动运行，面对敌方威胁才值得改变计划。收益是所选行动及其及时攻防；代价是材料占用、生产时间、队列等待与错过的时机。

## TL-03 一批生产的可见状态

| 状态 | 进入条件／输入 | 输出与反馈 |
| --- | --- | --- |
| 未到首次起点／休歇 | 按战前编排等待 | 显示下一次可开工时刻 |
| 缺料等待 | 已可开工但条件不满足 | 显示缺少的材料，条件满足后自动续跑 |
| 加工 | 所需材料提交给本批 | 显示托管材料、进度和预计完工；同一材料不得被其他法器重复使用 |
| 完工待交付 | 加工已完成、尚未完成输出 | 成品留在本法器；交付耗时，玩家行满时阻塞 |
| 交付完成 | 行动卡进入玩家战斗行 | 才可继续后续生产；效果产生的资源仍按其声明结算 |

加工时间、交付时间、休歇时间分别登记。它们不是旧冷却C／释放L的改名；不继承“释放三刻每刻生效”等旧过程。

## TL-04 实际节拍顺延

缺料、满行和返工带来的延误随实际完成传入后续循环；不按原定钟点补发，也不跳过本轮以追赶固定节拍。程序内容保持，实际相位会改变。预览必须标出等待原因和受影响的后续产出。

## TL-05 输出与行满

法器统一生产行动卡，需要完成入行耗时后进入有限队列。队列满时成品保留在原法器，交付后才继续生产，不丢牌、不靠无限隐藏缓存继续积压。

同刻先支付已存在产物的到期维护，再按当前有效的供料优先顺序分配剩余材料。默认使用战前法器序；玩家可依TL-06临时调整未来批次的供料优先级。同刻争入行位置仍按战前法器序，不随临时供料调整改变；未获得位置者保留成品等待。旧“后杖覆盖前杖”不适用；维护对象之间的优先顺序仍需补齐。

## TL-06 路由与临时设置

战中可免费调整合法的材料输入路由及已声明的未来输出设置，但只作用于尚未承诺的未来批次。已托管材料、当前成品、已入行牌和其目标预设均保持本批承诺。免费改线不转移已经支付的成本，也不改变铭刻配置、行动卡种类或效果预设。行动卡仍进入普通战斗行；原直接交付资源的路由不再默认开放。

路由允许临时改变未来批次的供料去向和优先级。攻击端、防御端、运转端分别描述造成攻势、获得防护、积累资源的功能，不规定恰好三个物理端口或互斥卡类。面对已揭示攻击，玩家可暂缓下一轮运转端开工，把尚未承诺且配方兼容的材料优先分给防御端，换取护甲并承担资源积累延后；也可维持原计划或优先攻击。具体运转行动与高阶材料来源仍须按INS-1另定，不恢复法器直接交付资源卡。

面对指定法器打断，先仅通过供料调整未来批次的开工时间，以避开危险加工时段；仍受首次起点、休歇、完整配方及实际顺延约束，不保证任意指定时刻开工。正在加工的批次不能借此暂停、改速或撤回材料；成品和已入行牌不重排。

临时应对结束后自动恢复基础设置；结束触发、重叠覆盖与恢复时点仍待TL-Q11补齐。已付资源、返工和延误继续有效，恢复不把相位强行拉回旧预览。保护、短时暂停法器、提速／减速及额外调时能力由独立干涉系统后续设计。[本次澄清CORE-050](../../sources/draft-changes/D-2026-10-04-routing-response-clarification.md)。

## TL-07 打断与返工

只有明确打断效果作用于公开指定的法器时才中断其加工。普通生命伤害不自动取消其他法器。被中断的加工退回本批材料，损失加工进度与时机；退料最早下一拍可用，未来循环按实际进展顺延。

已经交付的行动不因原法器后来被打断自动消失。完工待交付、正在交付的批次是否属于特定打断能力的合法对象，须由该能力明示；“中断加工”不自动获得销毁成品权限。

## 正反例与验收

- 两个法器同时完成：不能沿旧规则直接抹掉先完工法器的产物；按战前法器优先顺序交付，后者保留成品等待。
- 行满且有成品：该法器停在待交付，不能一边留成品一边制造第二份。
- 敌方在本拍打断正在完工的加工：先裁定打断，再判幸存加工完工；被打断者退料，不产成品。
- 临时防御优先：只改变尚未承诺批次的供料，已托管的运转批次照常加工；两个成品争入行仍按战前法器序。
- 后续若设计临时提速能力，其结束后应恢复基础速度，保留合法增产，不强制等量补休；此处不开放一个现成提速操作。

未来验证记录每批托管、完工、交付、翻牌时刻和每次延误原因；体验上检查玩家能否预测一处瓶颈、正常区间是否无需反复操作。未运行。

## TL-38 统一法器与行动输出

法杖统一称为法器，涵盖各式可用于施法的器具；不以杖形限定内容。每个法器绑定SYS-001所述的一组合法铭刻配置，沿既有取料、加工、交付与实际顺延流程反复产出行动卡。法器不再默认直接交付资源卡；行动卡若有生成资源的卡效，须另行声明，并经过普通战斗行生效。

此变化不调整队列容量、每拍兑现上限、材料托管或打断退料。具体批次卡数、制造要求与契合效果待内容设计。[采纳范围](../../sources/draft-changes/D-2026-10-04-artifact-inscription-core.md)。
