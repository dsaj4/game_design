# SYS-004 资源卡、环境与法术产物

Project ID：game-002。文档角色：CurrentSpec。基准：GDD 2.1 / TL-1 + INS-1。2026-10-04。本文已采纳条款与Unknown分开；体验Hypothesis / NotRun。

## 目的与核心取舍

把时间变成资源准备、维护、增幅和高阶法术的机会成本。玩家依所选行动的制造要求分配材料，在即时攻防与较晚的行动之间取舍。系统自动吸取合格材料和输出产物，普通运行不需要持续手动搬卡。

## TL-14 卡牌战场与环境供给

敌方战斗行、资源卡区、玩家战斗行和法器处理区承担规则展示。旧2×5格子、锚点、正交邻近、占格出生和满位回退不继续作为默认规则；需要的“范围”重新用明确对象集合或卡牌关系设计，不能直接把旧坐标换成屏幕像素。

基础环境资源按周期补给；统一行动输出后，高阶材料的获取／加工途径Unknown，不沿用法器直接交付资源卡的默认路径。资源区收纳环境材料、中间产物和行动明示产生的资源。法器仅吸取当前制造内容声明允许的资源，同一资源不能同时交给多个法器。

资源卡不是玩家干涉费用，也不是战外铭文库存。基础资源持续补给不意味着固定干涉费用会回充。

## TL-15 托管、输出与自动维护

加工开始后的输入属于本批承诺，免费改线不能挪走；中断退回材料按SYS-002处理。新资源及退料最早下一拍使用，不能在同拍被多级机器无限传递。

保留维护产物、持续增幅和高阶材料的接口目标；常规维护与恢复自动执行。这些规则只适用于具体内容明确提供的相应资源，不因保留维护规则而默认建立生产来源。每个实际产物仍须分别声明：
- 存续条件、维护资源与周期，以及不足时发生什么；
- 可接受的增幅、上限或限制，增幅随哪个身份保留；
- 是否作为一次性材料、持续存在对象或条件被使用；
- 加工、维护与消费之间的争用，退出与战终怎样处理。

**TL-22 维护不足**：对需要维护的高阶产物（候选名“辉核”），维护不足时进入休眠，保留身份与已有增幅；材料补足后自动恢复。维护周期、消耗量、增幅公式和其他资源寿命仍须逐项定义。休眠不是销毁，也不是免费清除维护成本；休眠期间可执行哪些加工尚待声明。

**TL-23 资源争用**：先支付已存在产物的到期维护，再按当前有效的供料优先级给新加工分料。默认战前法器序，战中可临时调整未承诺批次的资源去向和优先级，不能挪用托管材料或绕过维护。同刻入行争用仍沿战前法器序，不跟随临时供料顺序改变，失败者等待。维护对象彼此争料、休眠恢复与到期维护的先后仍Unknown。

本版尚未采纳具体维护周期、费用、增幅公式或资源寿命。旧火焰／冰霜本体、燃烧／冰冻、元素克制与阈值转化不自动等价于新资源配方，须在新卡表中重新决定。

## TL-37 参数、来源与有限事件的共同合同

每个数值声明单位、取值域、零值含义、读取阶段和修改方式。普通效果数量沿用合并固定增量、应用已声明倍率、最终向下取整并截为非负的原则：`q=max(0, floor((基础量+固定增量合计)×倍率))`。无倍率修饰时为1；多个倍率怎样合成须由相关内容明确，不暗设独立乘区。基础量与实际结果分开保存，结果为0不自动等于程序非法。

这个数量合同不自动适用于加工／交付耗时、费用、维护周期、携带容量或疲劳曲线。它们按各自参数域和已确认规则决定，旧τ及冷却公式不沿用。制造材料按内容绑定，不是核心语义空缺或执行者；行动的来源法器、批次和实际支付来源须可追溯，不跨来源借用未声明的加成。

持续产物须声明身份、所有者／来源、作用窗口、消失条件，以及来源消失后是否独立存续。若一个效果产生额外事件，须写清触发次数、可否继续触发和终止条件；条件筛选不自动变事件触发。不得凭未写明的递归生成无限事件。旧RC1的额外事件层数或总排序不直接替代TL-1总时序；本拍新产与退料仍最早下一拍可用。

这份共同合同帮助审卡和追踪因果，不自动开放召唤、元素反应或新增触发词。具体卡种须逐项满足合同后另行采纳。

## 异常与可见反馈

缺料时自动等待，并显示具体缺口及预期供给；行满时显示成品滞留位置。资源托管、可用、待下拍可用分别可查；操作结果不能让同一张牌既在资源区又在两个法器内。

资源区容量、满位返还、维护对象内部争用、堆叠与寿命待定。对这些边界不擅自丢料或免费复制。

## 正反例与验收

- 若后续内容声明基础料转化为高阶料，必须明确来源途径并留下真实消耗和耗时；本轮尚未建立该途径。
- 本拍刚退回的材料不能当拍转给另一个法器完成响应。
- 免费改合法路由只影响未承诺批次，不能变换已成品的卡种，也不能恢复直接资源交付权限。
- 无人操作的普通区间，既有循环能自动等待和续跑；若每周期都必须点维护，违反体验目标。

未来验证材料守恒、维护成本、增幅收益及自动运行的操作密度；配方和生命周期未定前不冻结测试输入。负责人为设计负责人，决策时点为资源卡表采纳／GDD-1之前。

## TL-43 材料类别绑定制造内容

材料类别与造物／对应制造内容绑定，不作为法器暗句的核心空缺供玩家独立选择。每个产出内容需声明完整制造配方、材料量、加工条件与时间；不因核心合法就免除制造成本。法器按实际供料取料、托管与消费，仍遵TL-30和资源争用规则。

绑定不是免费供料，也不预先决定具体材料映射；行动卡的卡效、材料获取链与辅槽打造成本分别设计。当前只确认材料类别的绑定关系，数量、耗时、高阶材料来源及配方变化边界Unknown。[来源](../../sources/draft-changes/D-2026-10-04-artifact-inscription-core.md)。
