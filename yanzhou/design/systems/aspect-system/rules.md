# 字相、物相与配方：规则

2026-11-14 · Accepted framework / CORE-079 / aspect-framework.1。来源及授权见[采纳D](../../../sources/draft-changes/D-2026-11-14-aspect-framework-integration.md)。本页拥有TL-49；知识／仪式归[TL-47](../../common/ritual-system/rules.md)，永久记录归[TL-48](../meta-progression-system/rules.md)。具体物品与配方仍唯一写在内容库。

## TL-49 字相资格、主相效果与物相

### 对象与适用范围

所有材料与产物用字相描述性质，用物相描述物品形态；物相不是背包格子占形。物品的**字相资格**用于满足配方或仪式条件；**主字相效果**是物品当前实际持有、能够生效或被继承的字相词条。两者分别记录，具有某相资格不等于当前具有该相效果。

该框架已采纳，具体字相／物相集合及全库映射未完成。CONTENT-LIBRARY-11的first-distillation.4及ritual-minimum-run.2仍沿其冻结的身份配方、卡效、学习与仪式合同作为未迁移内容域使用；不宣称它们已满足本页，不按名字自动补相、改效果或增知识门槛。新设计及迁移内容须按本页与[内容合同](../../content/cards.md)明示映射，缺决定时不能假定适配。旧证据不能外推新框架。

### 配方、工序与法器

1. 配方以必要字相、物相和工序约束输入及结果；满足全部声明条件的材料可替换。不从自然语言相近推定兼容，也不因身份不同排除已经满足条件的替代。
2. 法器先只限制**输出物相**，不以器型额外限制输入物相；配方自己的输入物相、数量、阶级与其他条件仍须满足。设备P、核心空缺、真实库存与固定用途沿TL-05／06／26／39／40。
3. 工序与字相有限多对多兼容，每道具体工序明确一个输出主字相；工序先对应核心铭文的动词职能。既有核心空缺及战前固定用途保留，名词槽职责待逐类设计，不据此简化为每器一枚或开放战中切工序。
4. 配方明确产物取得哪些字相资格，不自动并入全部原料字相。每份材料只支付一个配方槽，数量与重复实例检查沿TL-15／43。
5. 所选主字相的效果必须有当前投入实际持有的对应来源。只有资格、没有效果的材料可满足资格槽，却不能单独承担效果来源；缺来源须补入。知识门槛沿TL-47，猜对材料不绕过。
6. 开工共同检查、冻结、完工消费与交付、失败及战终退料沿TL-05／11／15；新内容的资格或知识不满足时按既有非法草稿处理，不部分消费。无铭文基础加工和零材料用途在新框架中的效果来源尚未映射，不凭空产生主相效果；既有明示用途只沿其冻结内容域。

### 效果的三类来源

| 类别 | 已采纳规则 |
| --- | --- |
| 字相词条 | 一个物品只保留一个主字相效果，工序决定保留哪一相，并继承当前投入实际持有的对应效果。同字相共用核心机制，同批只继承一次，多份同相原料不重复生效。 |
| 物相词条 | 合成后物品具有物相效果；同一具体物相共用基础作用，强度由明确的成品等级／配方档位规定。不同基础作用采用不同物相。 |
| 特殊词条 | 可选的隐藏额外强大效果，高级物品更可能具有；具体产生、揭示、启用及继承未定，不因高等级自动添加。 |

初级材料只有字相效果词条，仍有物相描述，不因形态存在就附送物相效果。词条结构不授予战斗、回收或跨战携带权限；是否可战斗沿TL-01及具体内容。

字相不单独配置可成长强度数值，定义的是该相的核心机制。涉及数量时从物相参数或明确当前状态读取，并写出单位、取值依据与读取时点；初级材料没有物相词条，必须明确其状态取值依据。未定义的量不是0、免费或无上限。物相负责需要设计的强度数值，具体等级／配方档位尚未给出。

词条叠加指组成同一物品的效果，不代表同时执行、全部效果无条件成功或重复触发。卡效仍按TL-44／11／30声明类别、目标、步骤、依赖与支付，普通量值沿TL-37；本页不为尚未设计的净化、药毒或特殊效果补默认目标和数值。

### 再加工与增幅

再加工只读取**当前实际投入**的对应字相效果，不从制作历史恢复已筛掉的原料效果。保留次相资格不能使该相效果重新激活；若选择该相工序而缺效果来源，须补入实际持有来源的材料。

新产物按新的输出物相重建物相词条，不累积旧物相效果。特殊词条的继承另行设计，无默认保留或删除结论。原批次辅助增幅与字相机制分别追溯，沿TL-37不自动随原料再加工传递；回收也不重加。内容必须区分继承的机制与量值修饰，不能借“继承效果”复制旧增幅。

### 信息与待定内容

已知信息应能区分：可用于哪些资格、当前主相提供何种效果、输出物相提供何种作用，以及本工序是否缺少知识或实际效果来源。隐藏名字的揭示沿TL-47，特殊词条揭示方式尚未定；不因查询详情绕过知识门槛。
