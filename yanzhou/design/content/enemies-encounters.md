Project ID：game-002。文档角色：ContentScope。2026-10-05 / TL-1 + INS-1 / enemy.1。规则见SYS-003／005／007；本页维护内容字段、首版约束、表现方向与候选。首批敌人均为**候选**，不是发行池；数值Illustrative，体验Hypothesis / NotRun。来源：[CORE-054](../../sources/draft-changes/D-2026-10-05-stage-two-enemy-pressure.md)。

旧EN01–07、B01和12场布场不作为新数值默认值，保留[原RC1内容](https://github.com/dsaj4/game_design/blob/d6e54af395518401fb4d8466b2302a1271da557a/yanzhou/design/content/enemies-encounters.md)。旧v0.1的三种敌牌候选已随探索退役，不作为当前待审遭遇表。

## 必需字段

| 新内容 | 必需字段与限制 |
| --- | --- |
| 来源敌人 | 每场唯一；身份、所属地域牌组、生命／护甲；其死亡即胜（SYS-003 TL-13） |
| 附属物（可选） | 不发敌牌、不计入胜负；其余规则未定，首版不使用 |
| 普通伤害牌（攻击▲） | 翻开偏移、正延迟、伤害、目标、可否取消；普通掉血不打断法器 |
| 明确打断牌（打断⊘） | 上述信息＋按SYS-003 TL-09锁定剩余最长施法所在法器、具体中断范围、可取消条件；无施法或无批次即落空 |
| 防御■／其他✱敌牌 | 首版不使用；其他类须另定通用副记号 |
| 双威胁组合 | 两张牌各自截止、是否需要同时主动操作、普通循环能处理哪一项 |
| 遭遇程序 | 固定循环时间表：全部牌的翻开偏移、Δ、到期、循环长L、段尾遗留倒计时与同拍检查 |
| 环境初态 | 基础材料供给、开局材料、高阶料实际获取／加工来源（未定处标Unknown） |

所有敌方行动牌均须声明正延迟Δ＞0，揭示与生效分离；具体时间逐牌设计，不把示例“5回合”写成全局参数（[CORE-050](../../sources/draft-changes/D-2026-10-04-routing-response-clarification.md)）。通常只有一个需要主动处理的关键威胁，少量双威胁。空档是取消后保留的真实时间机会；不通过提前下一牌抵消成功应对的收益。

## 首版内容约束

- 同一遭遇内任意两张敌牌T不同；允许段尾遗留，但不与新段任何T同拍。
- 首批敌人只有生命，不使用防御类敌牌或敌方护甲。
- 基准打断敌取Δ不小于预期玩家套组的最长D，使被锁定的当前批次总能完成，压力只落在之后的开工选择上。
- “截击”（Δ≤目标剩余R，当前批次无法再避开）只用于特色敌；截击型双威胁须满足T_伤 ≥ r_断+D_防+1，保留“锁定后再起手防护”的反应路线。翻开表开战即公开，是截击可预见的前提。
- 应对窗口按阶段二工作包的Derived关系检查：防护Δ ≥ D_防+1、取消Δ ≥ D_取消+2，每1拍缺料、缺位或排队各加1；Δ＞0本身不保证可应对。

## 卡面种类与地域牌组

卡背只显示通用种类符号：攻击▲、防御■、打断⊘、其他✱，并配种类文字（SYS-007）。通用组件与UI不地方化；不同地域的敌人以各自牌组的花色图案、配色、材质与符号装饰笔触体现特色，但不得改符号轮廓、位置与含义。同一敌人不混用多个地域的意象。

## 首版表现方向：秘仪与炼金

首版敌人属于“秘仪与炼金”牌组：敌人是炼金“大功”途中逸出之物——失控的作品、召来却未被约束的存在、被具身化的象征。每名敌人锚定一个有出处的炼金／魔法意象与一道工序；“工序可见、原理半遮”，规则信息完整公开，只把来历与象征留作线索。首版取材以西方赫尔墨斯炼金与仪式魔法为主，其他地域作为各自牌组后续增加。

遭遇信息以“图谱页”（寓意图＋格言，格言即出发前可见主机制）呈现，为表现候选，排版归后续UI设计；不展示暗牌内容（SYS-005 TL-32）。

意象出处来自整理者既有知识，**未核实**。正式文案或美术前须逐条核对出处，需用户授权联网或提供资料；核对前文案只写“传说／图像传统”，不写具体年代断言。
