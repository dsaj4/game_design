# 敌牌与遭遇内容合同

Project ID：game-002。文档角色：ContentScope。2026-10-04 / TL-1 + INS-1。

旧EN01–07、B01和12场布场不作为新数值默认值，保留[原RC1内容](https://github.com/dsaj4/game_design/blob/d6e54af395518401fb4d8466b2302a1271da557a/yanzhou/design/content/enemies-encounters.md)。

| 新内容 | 必需字段与限制 |
| --- | --- |
| 普通伤害牌 | 类型线索、揭示时刻、正延迟、伤害、目标；普通掉血不打断法器 |
| 明确打断牌 | 上述信息＋公开锁定的法器、具体中断范围、可取消条件 |
| 双威胁组合 | 两张牌各自截止、是否需要同时主动操作、普通循环能处理哪一项 |
| 遭遇程序 | 全部牌的揭示表、到期表、循环长度、段尾遗留倒计时和同拍冲突 |
| 环境初态 | 基础材料供给、开局材料、高阶料实际获取／加工来源（未定处标Unknown） |

通常只有一个需要主动处理的关键威胁，少量双威胁。空档是取消后保留的真实时间机会；不通过提前下一牌抵消成功应对的收益。

旧v0.1的三种敌牌候选已随探索退役，不作为当前待审遭遇表。新遭遇须重新定义揭示表、队列初态、供给与参数；这些内容未齐备前不能声称难度已验证。
