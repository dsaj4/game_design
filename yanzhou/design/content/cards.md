# 卡牌内容登记

2026-10-11 · ContentScope。首批为[EX-001简易法术流](../examples/simple-spell.md)，具体字段与数值在案例维护一次。发行池尚未冻结。

## 当前内容

| 类型 | EX-001内容 | 当前处理 |
| --- | --- | --- |
| 核心铭文 | 庇护、打击，各1实体 | 两者统一为动词，兼容逐法器声明 |
| 副铭文 | 迅速，1实体 | 两护符均兼容，一枚只装一处 |
| 行动 | 简易护盾、简易攻击、强化打击 | 普通／兑现用途及完整步骤见案例 |
| 标记 | 施法次数 | 上限、溢出、支付与战终完整声明 |
| 材料 | 无具体物件 | 配方明示零材料，不补造资源卡 |
| 暂缓 | 积蓄及未命名休整候选 | 归FB-Q03；不计已完成行动 |

## 内容必填字段

| 类型 | 字段 |
| --- | --- |
| 铭文 | 实体身份、词性、基础词义、法器兼容／核心组合、辅槽挂接、获取及持有资格 |
| 行动 | 来源用途、完整配方（或明示零材料）、D、每批张数、类别、目标及优先级、步骤与依赖、量值与读取时点、费用、失败、产出 |
| 标记 | 宿主／极性、每层作用、上限及超限、生成／读取／支付、期限与刷新、移除、战终；定时效果另写登记次数／期限及并存预算 |
| 资源 | 身份、性质、阶级、来源、量、普通耗材／特殊对象、携带标签与占用、生命周期；维护／增幅适用时补齐 |
| 敌牌 | 种类、程序位置、翻开偏移、正延迟、效果、目标／锁定及可取消条件 |

效果主体按规则资格与声明执行：核心合法性不推导额外能力，专属修饰替代通用；制造与生效支付分账；卡面类别不改TL-11结算组。普通用途公开材料性质、消耗与产物，多阶兑现同时有量值和效果差异。

旧卡池与退役候选只在[固定整理前版本](https://github.com/dsaj4/game_design/blob/a9a7be3a48356379d9fb3eed86c17cfe3ada7325/yanzhou/design/content/cards.md)保留来源，不混入本表。[缺口集中登记](../../governance/questions.md)。
