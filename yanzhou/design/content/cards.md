# 卡牌内容登记

具体对象定义与逐项资格统一查[内容库](../../content-library/README.md)，现仅保留alchemy。CORE-071已删除原首战、敌人储备、信息小样与独立造型的内容库身份；本页保留通用内容合同。

2026-11-01 · ContentScope / CORE-072。35配方制作参数、43卡权限／11成品合同与咒定义已限定采纳；完整首战套组与敌表待设计；通用机制按现行规则，旧案例只保留原固定范围。

## 当前内容

[alchemy物件](../../content-library/alchemy.md)维护32材料、11成品、8法器、10核心及1个炼金咒标记。35配方的D／承载／份数／产率／额外费用、43卡权限与11成品合同按[CORE-072](../../sources/draft-changes/D-2026-11-01-alchemy-executable-content.md)采纳；具体参数只在内容库维护，3构筑仍为草稿。核心组合、几何、携带、取得、具体补给与初态仍待闭合。原首战的铭文、辅助、三张玩家卡、敌牌和标记均已淘汰，不再是当前初始库存、实现任务或验收输入。

## 内容必填字段

只填实际使用的能力：普通首场卡不补周期／反应／维护的空结构；新增内容触发这些能力时才展开其合同。字段完整不等于资格或采纳自动通过。

| 类型 | 字段 |
| --- | --- |
| 铭文 | 实体身份、词性、基础词义、法器兼容／核心组合、实际装配归属、散装每枚1格／兼容嵌入额外0格、获取及持有资格 |
| 辅助道具 | 唯一身份、实际占形／朝向、单一相邻接口、兼容法器／用途、具体参数／步骤、贡献与叠加运算、批次／成品继承、实际取得及价格；未知尺寸不得猜配 |
| 统一卡牌 | 唯一身份、来源、三种战斗权限、材料性质／阶级（使用时）、携带资格与实际格子占形／旋转，投入后离包入手、未投入仍占格；战斗回收不等于跨战携带 |
| 战斗使用 | 类别、目标及优先级、步骤及依赖、量值与读取时点、每次使用费用、失败及回收；不可战斗卡不编造空卡效 |
| 配方／生产用途 | 完整输入（或明示零材料）、D、张数、实际产物及内部顺序；本器供料区的完整待料才可吸收，完工直接产卡 |
| 标记 | 宿主／极性、每层作用、上限及超限、生成／读取／支付、期限与刷新、移除、战终；定时效果另写登记次数／期限及并存预算 |
| 材料用途 | 匹配身份／性质／最低阶级、数量、实际格子占形与旋转后合法放置、普通耗材／特殊对象、取用及待用资格；多件配方声明槽顺序和确定匹配，不能以同面积代替形状；维护／增幅须有合法新时序 |
| 敌牌 | 种类、回合与固定列、即时／延时、牌背字段、完整效果；延时另列后续牌、生成顺序、下轮位置替换、锁定和公开／可取消边界 |

效果主体按规则资格与声明执行：核心合法性不推导额外能力，同一辅助的专属适配替代其对应通用贡献，多件同效可叠加；制造与生效支付分账；卡面类别不改TL-11结算组。普通用途公开材料性质、消耗与产物，多阶兑现同时有量值和效果差异。

旧卡池与退役候选只在[固定整理前版本](https://github.com/dsaj4/game_design/blob/a9a7be3a48356379d9fb3eed86c17cfe3ada7325/yanzhou/design/content/cards.md)保留来源，不混入本表。[缺口集中登记](../../governance/questions.md)。

## 组合核对

资格、评估与采纳沿[统一流程](../../../docs/design-workflow.md)，本页只补内容检查；一次检查少量真实组合，无须填满全池，不适用字段省略。

- 配置与取得：合法／非法组合、核心可逆嵌入、辅助占格连接及兼容、实体占用、初始库存、真实渠道与负担；有词性不代表兼容，有库存不代表可以部署。
- 贡献与选择：分清核心、各件辅助及合计修饰与契合的效果，比较同预算替代及非契合用途；词义和类型标签本身不授予能力。
- 制造与生效：设备与专属供料区的占形／接口、自动补料与手动替换、下一拍吸收、完整配方、D、张数、直接入手、手动上行、回收／消费及结算列截止，制造／效果支付分开；按现行规则计算，不沿用旧交付／休歇阶段。
- 失败与恢复：按实际采用的能力对照缺组件／缺料、满行拒绝、目标失效、来源死亡、终局与存取；已有情境引用[验收](../validation.md)，未决归questions。
- 效果与证据：新效果核对[FX身份与覆盖](../../system-design/effects/case-coverage.md)，不能用登记替代资格；试玩或模拟须有对应任务授权，Accepted与验证通过分开。
