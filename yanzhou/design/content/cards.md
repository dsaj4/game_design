# 卡牌内容登记

2026-10-23 · ContentScope。当前[EX-003](../examples/round-hand.md)只用既有法器／卡效值说明新回合局部行为；[EX-001](../examples/simple-spell.md)保留旧连续拍完整输入。新首场实际套组、敌表与整场输入尚未冻结，发行池也未冻结。

## 当前内容

| 类型 | 已有内容输入（EX-001原值） | 当前处理 |
| --- | --- | --- |
| 核心铭文 | 庇护、打击，各1实体 | 两者统一为动词，兼容逐法器声明 |
| 副铭文 | 迅速，1实体 | 两护符均兼容，一枚只装一处 |
| 行动 | 简易护盾、简易攻击、强化打击 | 普通／兑现用途及完整步骤见案例 |
| 标记 | 施法次数 | 上限、溢出、支付与战终完整声明 |
| 材料 | 无具体物件 | 配方明示零材料，不补造资源卡 |
| 暂缓 | 积蓄及未命名休整候选 | 归FB-Q03；不计已完成行动 |

## 内容必填字段

只填实际使用的能力：普通首场卡不补周期／反应／维护的空结构；新增内容触发这些能力时才展开其合同。字段完整不等于资格或采纳自动通过。

| 类型 | 字段 |
| --- | --- |
| 铭文 | 实体身份、词性、基础词义、法器兼容／核心组合、辅槽挂接、获取及持有资格 |
| 行动 | 来源用途、完整配方（或明示零材料）、D、每批张数、类别、目标及优先级、步骤与依赖、量值与读取时点、费用、失败、产出 |
| 标记 | 宿主／极性、每层作用、上限及超限、生成／读取／支付、期限与刷新、移除、战终；定时效果另写登记次数／期限及并存预算 |
| 资源 | 身份、性质、阶级、来源、量、普通耗材／特殊对象、携带标签与占用、生命周期；维护／增幅适用时补齐 |
| 敌牌 | 种类、回合与固定列、即时／延时、牌背字段、完整效果；延时另列后续牌、生成顺序、下轮位置替换、锁定和公开／可取消边界 |

效果主体按规则资格与声明执行：核心合法性不推导额外能力，专属修饰替代通用；制造与生效支付分账；卡面类别不改TL-11结算组。普通用途公开材料性质、消耗与产物，多阶兑现同时有量值和效果差异。

旧卡池与退役候选只在[固定整理前版本](https://github.com/dsaj4/game_design/blob/a9a7be3a48356379d9fb3eed86c17cfe3ada7325/yanzhou/design/content/cards.md)保留来源，不混入本表。[缺口集中登记](../../governance/questions.md)。

## 组合核对

资格、评估与采纳沿[统一流程](../../../docs/design-workflow.md)，本页只补内容检查；一次检查少量真实组合，无须填满全池，不适用字段省略。

- 配置与取得：合法／非法组合、核心与辅槽挂接、实体占用、初始库存、真实渠道与负担；有词性不代表兼容，有库存不代表可以部署。
- 贡献与选择：分清核心、修饰与契合的效果，比较同预算替代及非契合用途；词义和类型标签本身不授予能力。
- 制造与生效：完整配方、D、张数、桌面／手牌去向、满手损失及结算列截止，制造／效果支付分开；按现行规则计算，不沿用旧交付／休歇阶段。
- 失败与恢复：按实际采用的能力对照缺组件／缺料、满行、目标失效、来源死亡、终局与存取；已有情境引用[验收](../validation.md)，未决归questions。
- 效果与证据：新效果核对[FX身份与覆盖](../../effects/case-coverage.md)，不能用登记替代资格；试玩或模拟须有对应任务授权，Accepted与验证通过分开。
