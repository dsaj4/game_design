# 法器内容设计合同

Project ID：game-002。文档角色：ContentScope / Navigation。2026-10-05 / GDD 2.1 / TL-1 + INS-1 / processing.2。结构Accepted；具体新款式与数值Unknown。保留原文件名以维持链接定位。

法杖统一为法器，涵盖各式施法器具。每个法器声明：预设名词／动词词义、核心空缺及兼容组合、初始／可打造辅槽和预设修饰位置、行动卡种类、制造内容、唯一处理耗时D（正整数拍）与每批需预留的入行位置数，以及核心铭文契合关系。全部核心必填且不可打造，辅槽可空、可新增／解锁，数量原则上不超过核心槽。

暗句意义确定行动卡种类，具体卡效独立设计；法器统一交付行动卡。兼容须同时满足基础语义和法器定位，不开放对象类别／材料类别槽，不按空缺数直接多产牌。契合增幅的效果与表现形式尚未决定。

用户“剑与盾之符＋攻击／防御”是方向种子，不构成新发行身份、固定槽数或具体伤害／护盾参数。旧原木／节律／余火及W01–03保留[RC1身份](https://github.com/dsaj4/game_design/blob/d6e54af395518401fb4d8466b2302a1271da557a/yanzhou/design/content/wands.md)，不直接迁为新器具。

新法器数量、获取与初始组合，辅槽打造路径／价格、批次卡数、材料与时间映射和契合清单仍待定。须与真实铭文库存、资源来源和有限队列一起核对；按CORE-051开工预留、无位不开工、完成即入行，不另设J／R／S／独立周期。CORE-052按有效供料优先级联合检查材料与容量、不足者本次跳过；设计大批次时须检查长期等位风险，不能靠固定预留牌序获得先出牌权限。[生产规则](../systems/02-wands.md) · [铭刻规则](../systems/01-grammar.md) · [采纳来源](../../sources/draft-changes/D-2026-10-04-artifact-inscription-core.md)。
