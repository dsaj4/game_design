# TL-1 验收计划与未决输入

Project ID：game-002。文档角色：ValidationSpec。2026-10-01。全部NotRun；本轮仅静态文档核对，不启动玩法实验。

## 已确认规则的预期

| ID | Given／When | Then |
| --- | --- | --- |
| TL-V01 | 同一词卡尝试用于两处程序 | 拒绝重复占用，循环加工不消耗程序词卡 |
| TL-V02 | 队列满，某杖完成行动产物 | 成品留原杖，交付后才继续生产 |
| TL-V03 | 缺料或中断延误后续批次 | 按实际完成顺延，不补发原时点产物 |
| TL-V04 | 改未来材料路由，已有批次托管 | 已托管、已产和已入行内容不变 |
| TL-V05 | 普通攻击造成玩家生命损失 | 扣甲／生命，不自动中断全部法杖 |
| TL-V06 | 明确打断命中指定加工杖 | 仅对应加工退料、丢进度；本拍不完工 |
| TL-V07 | 本拍产资源或退料 | 最早下一拍使用，不同拍连锁无限生产 |
| TL-V08 | 敌牌翻开 | 只揭示及启动倒计时，完整公开并锁定，不提前交付该牌伤害 |
| TL-V09 | 打断在T−1、T分别生效 | 合法者前者可取消，后者不能取消T敌牌 |
| TL-V10 | 敌牌被取消 | 保留空档，后续程序不提前或补发 |
| TL-V11 | 敌程序跨段，旧倒计时仍在 | 原倒计时继续，不重复建立 |
| TL-V12 | 全局暂停 | 敌我与资源计时共同停止 |
| TL-V13 | 临时应对结束 | 恢复基础设置，费用、已产收益、返工与延误保留 |
| TL-V14 | 揭示、付费、排队之后退出恢复 | 同一结清时点及已提交操作，信息／费用／进度不重置 |
| TL-V15 | 生效时目标与制作时不同 | 按已承诺规则在生效时选取，不免费改写目标条件 |
| TL-V16 | 同一完整事件双方归零 | 沿既有终局原则玩家失败；终局后不继续产出 |

| TL-V17 | 行动到生效时没有合法目标 | 空放离队，不退制造材料、不补发 |
| TL-V18 | 高阶产物维护不足后再补料 | 休眠保留身份与增幅，自动恢复；参数另冻结 |
| TL-V19 | 同刻维护和多杖开工争料 | 到期维护先付，余料按战前杖序；无料者等待 |
| TL-V20 | 多杖争一个入行位置 | 按同一战前杖序交付，其他成品留杖等待 |

| TL-V21 | 战后挑选资源带走 | 仅可携带标签、共用容量；基础环境料清空，默认沿用偏好 |
| TL-V22 | 选中高阶资源进入下场 | 只保留种类与数量，增幅与运行状态回到该资源初始状态 |

这里只固定已定规则的预期，不暗设配方、维护内部排序或未定义能力。

## 尚不能冻结的边界输入

维护对象内部争用与托管期间维护；交付阻塞时计时；资源容量与退料；同类伤害及复合行动总顺序；状态与持续产物的作用时点；敌方到期碰撞及锁定目标失效；疲劳、有限终局与真实初始资源。

上述设计预期不唯一时停止该项执行准备，不用程序默认顺序替设计裁决。

## 体验假设与观察

| 任务 | 记录 | 成功信号 | 失败／停止信号 |
| --- | --- | --- | --- |
| 普通区间让程序运行 | 每次输入的原因和时点 | 无需每批反复点击维护 | 玩家必须持续搬料或重启 |
| 面对关键倒计时 | 选项、预计时刻、实际结果、玩家解释 | 能指出至少一种代价及是否赶得上 | 只靠试点按钮或误把入行当生效 |
| 比较低阶与高阶计划 | 实际取得材料、投入、等待与损失 | 不同取舍有适用情境 | 同预算下仅一条路线合理 |
| 解释阻塞与返工 | 原始操作及复盘语言 | 区分缺料、行满、打断和无目标 | 只知道“牌没用” |
| 退出与继续 | 退出前后已知信息及承诺 | 无重抽、返费或免费重新选择 | 恢复改变决策成本 |

真实玩家样本与量化门槛在原型输入冻结时事前登记；本轮没有样本。先记行为再记解释，保留失败与未到达，不从结果反选有利标准。
