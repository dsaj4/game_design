## 1. 玩家做什么

单人离线、Windows、简体中文、键鼠。玩家用实体铭文装配法器，法器自动生产行动卡；玩家观察敌方五个位置和己方产物，在有限行动点内整理本回合将执行的牌，或留下手牌准备以后。回合末依桌面顺序自动结算。目标是理解配方和工序，看见投入怎样兑现，并承担已开工承诺及付费整理的后果。

体验假设：有限行位、已知后续威胁和付费整理可以支持有理由的攻防与兑现选择。若总是等最后执行同一排序、只凭牌背猜测，或手牌让账目更多而非更清楚，就须重评。固定五列只能保证当前显示跨度有限，不能证明可读性、策略或平衡成立。

## 2. 整局与单战循环

整局仍是看下一节点→战前装配与投入→战斗→战果及材料选留→休整／购买→下一场。路线到分叉再选，进入节点后不撤回重抽；普通失败结束本局，终点首领胜利结束本局。完整路线和内容尚未齐备。

当前战斗：每回合X个**生产拍**，每方桌面X个位置，初始X=5。生产拍推进加工；**结算列**只是回合末的执行顺序，不另推进生产拍。第0拍为就绪和首次开工；回合n的生产拍为(n−1)X+1至nX，n从1开始。X在本场固定，不提供战中修改。

~~~mermaid
flowchart LR
  A["回合开始：敌方布牌，行动点重置"] --> B["5个生产拍：自动产牌入桌／入手"]
  B --> C["最终整理：可调整，确认后结算"]
  C --> D["第1列→第5列；逐完整事件检查胜负"]
  D --> E["未终局：到期疲劳、回合结束"]
  E --> A
~~~

首次布敌牌和发放行动点在第0拍就绪前完成；从第0拍继续才首次开工。以后换轮只布牌、重置行动点和清旧行，不额外加工或开工；下一生产拍再推进。手牌与未完批次跨回合保留。五位不保证五张：缺牌位置跳过，不补免费牌。

## 3. 对象怎样连接

| 对象 | 职责 |
| --- | --- |
| 铭文与核心槽 | 填齐预设名词／动词空缺且语义与器具兼容才合法；实体一枚一处，循环不消耗 |
| 辅槽 | 可选修饰，挂接法器原词；不新增核心、不选材或改目标，具体权限按内容声明 |
| 法器与用途 | 运行一种合法铭刻用途，或明示无铭文基础加工；下一批开工才锁定所选用途 |
| 资源卡 | 制造、维护或明示效果的材料／产物，与实体、金币、行动点分账；新首场不凭通用合同增添资源内容 |
| 行动卡、桌面行、手牌 | 成品先入桌面，满行入手；桌面本轮执行，手牌须付费换入／补入才使用；未执行的成品不是已获得效果 |
| 标记 | 附玩家或敌人的分类状态；首场施法次数区分实有、锁定和可消费，到卡效步骤才支付 |
| 敌人程序与后续牌 | 一名来源敌人，开战固定按回合的基础五位表；延时牌生成下一回合的公开后续牌，不根据玩家布局临时改牌 |

战前用真实库存装配、设置法器序、未来用途和本场投入；至少一台完整合法铭刻法器才可开始。空辅槽、暂缺材料或无直接伤害不单独禁止开战；初态仍须有至少一条公开可运行基础路线。兼容与绑定见[铭文](systems/inscription-system/rules.md)，实际字段见[内容合同](content/cards.md)。

## 4. 一批生产承诺了什么

配置、完整配方、D与必要开工标记共同满足才开工；失败不部分扣料，继续检查下一台。普通材料开工托管、幸存完工消费；如有合法声明的开工标记费用，则冻结、完工扣除。首场两护符仍为零材料、无开工标记费用，空白配方不等于零材料。

D为正整数，至少1拍；a拍末开工，a+D生产拍完工，开工当拍不额外推进。D和批次用途、材料、产出冻结，当前加工不因未来设置改变。没有独立冷却、完工等位或主动撤批。

**桌面与手牌容量不再限制开工，不预留成品牌位。** 完工按实际先后处理，同拍按战前法器序，多牌批次按内容规定内部序。先入桌面最左空位；桌面满则右侧追加手牌；手牌上限H=3，超限立刻移除最右牌，即新来的牌。成品被丢不触发卡效、不记层、不退制造成本，满两区仍可能继续生产。

未来用途、路由或阶级不改当前批次与成品内容；临时供料只保留一份，到期回基础，不恢复被替换方案。零材料没有可停供的材料，改变优先级不等于停机。详见[法器TL-03／05／06](systems/artifact-system/rules.md)。

## TL-04 实际节拍顺延

缺料、必要标记不足或返工推迟实际开工及产出，不追赶名义周期、不补发。当前不再因成品缺位等开工；须分清加工等待、错过本轮以及产物溢出，不能都叫排队。D跨回合继续，结算阶段不推进D。

## TL-08 玩家战斗行

开场桌面和手牌为空。桌面每位最多一牌，共X位；自动按完工先后填最左空位，付费整理可改变已有顺序。第X生产拍完工的牌仍可参加本轮，不再沿旧t入行、最早t+1生效的限制。

回合末从左到右按列结算，每列至多一张己方牌。空位不补牌、不挪动后列；已结算／取消位置保留只读结果，整轮结束清行。手牌不会在下轮开始免费上桌；只在合法整理中付费换入或补入，战终清空且不跨战。

**TL-21 无合法目标：**该步不付未付费用，牌按完整步骤与依赖处理后空放；不补牌、不退制造材料、不把后列拉前或等待目标。己方目标仍按原承诺在生效时自动选择；调序不改目标规则。

## 5. 生产与结算怎样推进

| 阶段 | 顺序与边界 |
| --- | --- |
| 回合开始 | 清旧桌面只读结果；敌后续牌优先占左位，余位补基础暗牌；行动点重置3。不推进D、不自动补己方手牌、不增加开工检查 |
| 每个生产拍 | 边界释放上拍待用量、到期临时设置回基础→观察受理→幸存完工并放成品→维护／恢复位置→空闲法器按有效供料序各检查一次。当前首场无维护内容，不能自行启用 |
| 最终整理 | 第X拍及动画全部完成后自动暂停，无时间限制。接受付费整理及免费设置；确认才开始结算，不回改已开工批次 |
| 每个结算列 | 先公开该列敌牌，固定该列行动；先防护组，再其余组，各组敌→玩家，牌内按声明步骤。每个完整事件后判终局，完成一列才下一列 |
| 回合末 | 五列完成且未终局时，处理本回合到期疲劳，再结束本轮。已终局不补疲劳或下一轮 |

“防护”只指直接护甲或明确挡伤害／打断；治疗、加层、取消、攻击属其余组。一张复合卡可跨两组，但仍只有本列一次使用；后一列的护盾不能提前。完整事件是一项基础步骤及其检查／支付、结果、一层已获准反应与清理，不是整卡或整回合。精确总序见[TL-11](systems/action-card-system/rules.md#tl-11-共同拍序与效果边界)。

即时新增标记可供后续步骤／列使用，不倒补失败支付；新资源、补给、退料和仍有效的释放量最早下一生产拍可用。结算列之间不生产、不维护、不新开工。独立定时、有限期与维护扩展的新回合接口尚未闭合，不按旧拍序自动启用。

## 6. 敌情、支付与失败

敌方原生暗牌只公开位置、种类、即时／延时标识，轮到该列才公开完整效果和目标。即时牌当列执行；延时牌当列生成一张下一回合才可用的公开后续行动。已知后续牌下轮落桌保持公开，不重新隐藏。

后续牌按生成顺序占下轮左侧位置，剩余位取该轮基础表对应位置；被覆盖的基础牌跳过，不在后面补发。首版每张延时牌最多一张后续牌，后续牌不递归生成，最多X张；不允许同列叠牌或回合途中加牌。首版即时牌仅普通伤害，打断走延时路线，不新增敌护甲、防御／其他类牌或附属物。详见[敌人规则](systems/enemy-system/rules.md)。

## TL-10 取消敌牌

仅具有明示权限的行动，可在目标列开始前取消更右侧已公开、已铺桌面的敌方后续牌。不能盲选原生暗牌、取消敌手牌或在同列翻开后取消。取消保留空位，不提前后列、不补发；首场尚无实际取消行动，合同不等于已发行该卡。

## TL-12 伤害与法器中断

普通伤害先扣护甲、超出扣生命，掉血不打断法器；支付生命与疲劳另算。延时打断在生成后续牌时，从加工者中锁定剩余生产拍最长的法器，并列取战前序；锁法器，不锁批次。后续牌所在列作用其当时批次，无对象／无批次只落空一次，不改选、不等候、不转伤害。

结算开始前该回合的完工已经发生；不能追溯打掉本回合已产成品。命中的在制批次丢进度、不产物；已在桌面或手中的牌保留。退料和仍有效冻结量最早下一生产拍可用，结算期间不重开，下一生产拍拍末重新检查；没有预留／待复用容量账目。完整后果见[TL-07](systems/artifact-system/rules.md#tl-07-打断与返工)。

每一步同状态核对目标、条件、完整费用和量值，通过才支付并执行；不足不部分支付、不重试、不退此前已成步骤。只有内容明示才有基础回退，见[TL-30](systems/action-card-system/rules.md#tl-30-制造材料与效果支付分阶段)。制造与整理行动点、卡效费用分别结算。

资源与标记可免费锁定自有未承诺量，锁住不自动消费，解锁恢复后续合法消费资格；不撤回托管或冻结，不阻止非消费读取。最终整理能更改锁定，结算开始后禁止中途锁解。首场可消费＝实有−锁定，兑现生效才付费，见[锁定合同](common/interaction-save/rules.md#玩家消费锁定与预警core-055)。

## TL-13 生命、程序循环与终局

每个完整事件后：玩家生命归零判负；否则唯一来源敌人死亡判胜。同点双亡玩家败。终局立即停余步骤、列、未来登记、生产和换轮，只呈现已发生结果。战终清理桌面、双方手牌、加工、护甲及按内容清理的标记；行动点失效，不补执行、不返已消费制造料。

未终局时，基础敌表按其已声明回合循环推进，不因取消或替换重排。后续牌保留身份与目标直至下轮，取代旧敌牌倒计时；当前完整表见[EX-004](examples/round-first-battle.md#4-敌牌基础表与覆盖)，不能把旧L16直接换算。

**TL-24 递增疲劳：**当前首场第10回合末首次，之后每回合末一次；第n次双方各损失5×n生命，先结完本轮各列再处理。即第10／11／12回合为5／10／15；X5时对应累计生产拍50／55／60之后，结算本身不加拍。共同损耗是一个事件，再检查胜败，双亡玩家败；不耗护甲、不打断加工。暂停、恢复、换轮不重置次数，明确新战才重置；其他构筑平衡不由此确认。

## 7. 整理、暂停、恢复与信息

每回合3行动点，不结转；以下成功操作各1点：交换桌面任意两张实牌，桌面与一张手牌原位互换，从手牌补入最左空位。不能指定补入其他位置、催产或复制。失败／同牌交换不扣，改回也是新付费；手牌满时原位互换不额外溢出。自动入区、暂停和既有免费设置不花行动点，详见[TL-18](common/interaction-save/rules.md#tl-18-付费整理与干涉接口)。

生产期暂停完成当前生产拍及动画后停，下一拍不开始；收尾过程中不能插入付费编辑。最终整理是新增受理窗口，免费用途／锁定可用于随后合法阶段，不能回改本拍开工。结算启动后全部玩法调整关闭，只可查看和设置；暂停／失焦收完当前列及动画后停，不回滚已见结果。末列后的疲劳仍须处理，停点及单步细节见[交互](common/interaction-save/rules.md#拍末暂停core-064)。

正常退出先收尾当前单位；异常恢复最近结清事件与已提交操作，静态停住，不重付、不重生牌、不重新布敌牌、不补离线时间。存档必须区分生产拍、回合、列和剩余步骤；新旧时间机制的进行中战斗不能擅自换算续打，旧证据沿原版本。

桌面固定完整X位，已处理位置暂留只读结果，下一回合清行；历史不当可用牌。界面分清本轮行、手牌、敌方已知后续牌、当前批次、未来用途和操作费，必要信息有点击／键盘路径，不只靠颜色、声音或悬停。CORE-063仍限定旧3D演示；新2D具体操作宿主与展示合同尚未采纳。

## 8. 局内成长与长期边界

新局满预设生命、0金币，普通胜利不回血。法器、实体铭文与金币属本局库存；战果收益包只领取或放弃一次，材料选留另提交，未执行的资源行动不当已得材料。

未投入材料留背包且本战不可取用；战后按标签、种类和容量统一选留，保留身份数量阶级，重置临时增幅与运行状态。普通耗材未完工退回参选，已完工不退；成品手牌不跨战携带。经济与路线见[TL-25／33—35](common/run-economy/rules.md)、[TL-32](common/run-route/rules.md)。打造实际流程、完整获取链和容量参数仍未完成。

休整拿铭文与恢复互斥，无法组成合格三候选时仅恢复／跳过；商店固定货架，一项一件、足额支付才交付，不刷新退款或保底配齐。局外成长尚未设计，不默认永久属性／实体解锁；发现和长期知识仍需另行闭合。

## 10. 用一个场景理解

有4层可消费施法次数、前两张为强化打击／普通攻击且目标存活。保持顺序时，强化先因不足5回退6并记1，普通再打6记1：共12伤、余6层。花1行动点交换后，普通先打6记1至5，强化付5打18再记1：共24伤、余1层。前提是中途未终局；这里多伤害同时花了行动点和更多储备。

局部正常／反例在[EX-003](examples/round-hand.md)维护，真实完整首场在[EX-004](examples/round-first-battle.md)维护；实现从[任务包](../development/task-pack.md)选择。体验是否成立须另有授权验证，[验收](validation.md)仅列设计预期。
