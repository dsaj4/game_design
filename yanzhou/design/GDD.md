## 1. 玩家做什么

单人离线、Windows、简体中文、键鼠。玩家战前用实体铭文装配占格法器，配置相邻专属供料位并固定用途；战中由默认自动补料或手动把材料放入待料区，法器吸收加工后产卡入手；玩家从手牌选择可战斗牌放上己方五列，与敌牌逐列交锋。可回收牌完成本次使用后立即回手，可在后续列再次打出；同一张牌也可能符合配方，作为原料消费后就不再回来。

目标是理解配方和工序，选择即时使用、反复使用或继续转化，看见投入的实际去向。空间布局是否产生取舍、自动补料与改送是否易懂、列间操作是否值得、可回收牌是否挤掉生产价值，都仍是假设；取消整理点和手牌上限不证明负担已经降低。

## 2. 整局与单战循环

整局仍为下一节点→战前装配与投入→战斗→战果及选留→休整／购买→下一场。分叉到达再选，进入节点不撤回重抽；普通失败结束本局，终点首领胜利结束本局。完整路线与内容尚未齐备。

每回合X个**生产拍**，双方战斗行各X位，当前X=5且本场固定。第0拍先布首行、就绪观察，继续才让零材料用途首次开工及自动预放；有耗材初始预放最早第1拍吸收；回合n的生产拍为(n−1)X+1至nX，n从1开始。**结算列**仅为回合末执行顺序，不推进生产时间。

~~~mermaid
flowchart LR
  A[回合开始：清旧结果、布敌牌] --> B[5生产拍：产卡入手]
  B --> C[最终整理：手动布牌并确认]
  C --> D[执行当前列，逐事件判终局]
  D --> E{还有列且未终局}
  E -->|是| F[列间停住：布置未开始列，确认]
  F --> D
  E -->|无列且未终局| G[到期疲劳及换轮]
  G --> A
~~~

换轮不额外加工或检查开工，下一生产拍再推进。未完批次、待料与手牌跨轮保留，没有整理点重置；空列跳过，不免费补牌。确认一个窗口只进入下一列，不预先公开更右敌牌。

## 3. 对象怎样连接

| 对象 | 职责 |
| --- | --- |
| 铭文与核心槽 | 填齐预设名词／动词空缺且语义及器具兼容；一实体一处，循环不消耗 |
| 辅槽 | 可选修饰，挂接法器原词；不新增核心、不选材或改目标，权限按内容声明 |
| 法器与用途 | 战前固定合法用途、占形与位置，战中不切用途；当前批次冻结投入及D |
| 专属供料位 | 相邻可见接口连接一台法器，形状限制材料大小、允许旋转；每器至多一批待料，吸收后腾位 |
| 统一卡牌 | 可战斗可回收、可战斗不可回收、不可战斗；材料是配方用途，行动是一次战斗使用，不再互斥划分资源卡／行动卡 |
| 两组手牌／战斗行 | 可战斗与不可战斗分组持牌，保存未排队材料及成品；新产卡都入手，由玩家手动上行；只读结果不是第二份库存 |
| 标记 | 附玩家或敌人的状态；施法次数区分实有、锁定与可消费，卡效步骤才支付 |
| 敌程序与后续牌 | 一名来源敌人，开战固定按回合的基础五位表；延时生成下一回合公开后续，不临时针对玩家改牌 |

铭文、法器、金币和敌牌不自动成为玩家普通配方卡。法器与供料区共享有限生产格，不能越界或重叠；这份空间不等于跨战携带容量。战前用真实库存装配、设置法器序、固定用途、生产布局、自动补料开关和本场投入；至少一台完整合法铭刻法器才能开始。空辅槽、暂缺材料或无直接伤害不单独禁止，初态仍须有公开可运行基础路线。见[铭文](systems/inscription-system/rules.md)及[内容合同](content/cards.md)。

## 4. 一批生产承诺了什么

每器至多一批在制＋一批待料。材料从手牌实际移到本器专属供料位，按占形放入、允许旋转，1×4不能容纳2×2；几何放得下也须配方匹配。手动可逐件准备，但配置、完整配方、最早吸收拍、D及必要标记共同满足才吸收开工；缺项不部分托管，继续检查下一器。吸收腾出供料位，普通输入幸存完工消费，可回收属性不免制造料。

每器默认自动补料，可在生产观察窗关闭或开启；关闭保留已排队材料，不停止在制或已有待料开工。自动只补本器当前待料空缺，不替换已放材料、不部分自动搬入；从真实合格手牌按最低阶级、同阶当前手牌先后选择，排除锁定／未到时点量，不能从战斗行、别器供料区或未投入背包取料。法器不再直接从手牌开工。零材料用途无需虚拟材料，空白配方不等于零材料。

D为正整数且至少1；a拍末开工，a+D完工，开工当拍不推进。用途、投入、D与产出冻结，待料调整不改当前批次或成品；无独立冷却、主动撤批或完工等位。

**完工直接把声明产物放入对应手牌组，不自动上桌，也不强制经中介行动才拿到材料。** 按实际完工先后，同拍战前法器序，同批按内容内部序。手牌当前不设硬上限，无H3或满手烧牌，不以成品容量限制开工。新卡可在下一合法窗口上行，作为下一配方输入须下一生产拍取得供料资格，再排入待料并等待下一拍吸收；真实卡效产卡仍须实际生效，不把预告当库存。

法器位置、用途及供料位结构本战固定；只在生产观察窗放料、撤回、替换、改送未吸收材料或改自动开关。放妥最早下一生产拍吸收，所有开工检查后才统一自动补下一批；新补入不当拍开工。旧临时供料／动态优先级退役；零材料不能靠关闭自动补料获得停机能力。详见[法器TL-03／05／06](systems/artifact-system/rules.md)及[资源TL-15／43](systems/resource-system/rules.md)。

## TL-04 实际节拍顺延

缺料、必要标记不足或返工推迟实际开工及产出，不追赶名义周期、不补发。没有成品缺位等开工；须分清加工等待、错过本轮列位和主动留牌，不能都叫排队。D跨回合继续，结算阶段不推进D。

## TL-08 玩家战斗行

每位最多一张实牌，共X位；当前开场玩家行与手牌为空，实际初态由内容给定。生产卡进入手中，玩家在合法窗口将可战斗牌放入任意尚未开始空位；上牌、撤回未使用牌、换牌与调序免费。手牌可跨轮，不自动上桌；同一实例只能在手、行、待料、托管等一个位置。

每列至多一次己方使用；空位跳过，不把更右牌拉前。已开始／已处理列不可编辑，结算结果保留原位只读至换轮。可回收牌全部步骤处理完后立即回手，不附加冷却；列间可打到后续未开始列，不能在同列重复或回到旧列。末列回手不增加第六列。不可回收牌本次用过后移除；两组手牌仅是查看分组，切换不改变库存或时间。

**TL-21 无合法目标：**该步不付未付费用，依完整步骤及依赖处理空放，不补牌、不退制造料、不前移后列或等待目标。本次处理结束按卡的回收权限回手／移除，不要求成功命中才回收；下次使用重新检查条件及费用，不补发旧失败。目标仍沿本批预设自动选择，手动调序不改目标规则。

## 5. 生产与结算怎样推进

| 阶段 | 顺序与边界 |
| --- | --- |
| 回合开始 | 清旧结果；敌后续先占左位，余位补基础暗牌；无点数、不自动上己牌、不推进D或开工 |
| 每生产拍 | 边界释放待用量→复查已提交观察窗输入→幸存完工入手→维护／恢复保留位置→按战前序检查开工→自动补下一批；当前无维护内容 |
| 最终整理 | 第X拍及动画完成后无时限停住，受理布牌与标记锁解，不改待料／材料锁定／用途／自动开关；确认才开始第1列，不撤回本拍拍末承诺 |
| 每结算列 | 开始才公开该列敌牌并固定本列行动；先防护、再其余，各组敌→玩家，按声明步骤；每完整事件查终局 |
| 非末列结清 | 动画结束后停在列间窗口；只改未开始己方牌，不改用途／供料／锁解；确认才公开并执行下一列 |
| 回合末 | 全部列完成且未终局，处理到期疲劳，再结束及准备下一轮；终局不补后续 |

防护仅直接护甲或明示挡伤害／打断；治疗、加层、资源生成、取消、攻击属其余组。跨组卡仍是一次使用，须全部可执行步骤处理完才回手，不能防护后提前重复使用。完整事件为一项步骤的检查／支付、主结果、一层已获准反应及清理，不是整卡、整列或整轮。精确总序见[TL-11](systems/action-card-system/rules.md#tl-11-共同拍序与效果边界)。

即时新增标记可供后续步骤／列使用，不倒补失败。新卡入手后按合法窗口战斗使用；新卡和普通退料最早下一生产拍取得供料资格，再经排料与下一拍吸收；有效释放标记最早下一生产拍可用。战斗回收原卡不另设待用拍；列间仍不生产、维护或开工。独立定时、期限、维护的新回合接口未闭合，不自动启用。

## 6. 敌情、支付与失败

敌原生暗牌只公开位置、类别及即时／延时标识，到该列才公开完整效果和目标。即时牌当列执行；延时生成下一回合才用的公开后续，下轮不重新隐藏。后续按生成序占下轮左位，余位取该轮基础表相同位置；被覆盖基础牌跳过，不在后面补发。

首版每张延时牌最多生成一张后续，后续不递归，最多X张；不叠同列、不在途中加敌牌。即时仅普通伤害，打断走延时；不新增敌护甲、防御／其他类或附属物。列间编辑不能提前查看下一暗牌。见[敌人规则](systems/enemy-system/rules.md)。

## TL-10 取消敌牌

仅有明示权限的卡效，能在目标列开始前取消更右已公开、已铺桌的敌后续牌。不能盲选原生暗牌、取消敌手牌或同列翻开后取消。保留空位，不提前后列、不补发；首场仍无取消卡，列间布牌不是免费取消敌牌按钮。

## TL-12 伤害与法器中断

普通伤害先扣护甲、超出扣生命，掉血不打断；支付生命与疲劳另算。延时打断生成时，从加工者锁剩余生产拍最长的法器，并列取战前序；锁法器，不锁批次。后续所在列作用其当时批次，无对象／无批次只落空一次，不改选、不等待、不转伤害。

该轮生产在结算前已完成，不能追溯打掉已产牌。命中在制批次则丢进度、不产物；已有手牌／行牌及下一批待料保留。普通输入退回手牌，不覆盖待料；普通退料和仍有效冻结量最早下一生产拍可用，列间不重开，下一生产拍拍末按本器实际待料重新检查，退回手牌不等于重新排队；没有容量预留或回收账目。详见[TL-07](systems/artifact-system/rules.md#tl-07-打断与返工)。

每步同状态核对目标、条件、完整费用及量值，足额才执行；不足不部分支付、不重试、不退已成步骤。明示基础回退才允许回退。每次回手后再用是独立的新使用，重新付费；免费布牌不免卡效或制造费，见[TL-30](systems/action-card-system/rules.md#tl-30-制造材料与效果支付分阶段)。

材料锁定保留，用于保护手中未排队原卡不被自动补料选走；生产观察窗可锁解，手动放料前须解锁，锁定卡仍可主动上牌。待料不再加锁，通过撤回／替换／改送调整；托管不可撤回。标记锁解仍可在生产观察及最终整理受理，冻结与卡效支付沿原合同。结算包括列间均不锁解、不补料，见[锁定合同](common/interaction-save/rules.md#玩家消费锁定与预警core-055)。

## TL-13 生命、程序循环与终局

每个完整事件后：玩家生命归零判负；否则唯一来源敌人死亡判胜；同点双亡玩家败。终局立即停余步骤、列、出牌窗、未来登记、生产与换轮，只呈现已发生结果。按唯一实例完成一次清理，桌面结果不重复计卡；已使用不可回收牌移除，可回收及未使用卡仍须独立携带资格，不补尚未发生效果，不返已消费输入。

战斗运行中的桌面、敌后续、加工进度、护甲及按内容清理的标记终止。未吸收待料与尚未完工普通输入按TL-25核对归属并参选。EX-004三种卡均不可跨战，独立单战终局手牌清空。未终局时敌基础表照固定回合循环，不因取消或覆盖重排；完整表见[EX-004](examples/round-first-battle.md#4-敌牌基础表与覆盖)，旧L16不直接换算。

**TL-24 递增疲劳：**当前首场第10回合末首次，以后每回合末一次，第n次双方各损失5×n生命；即10／11／12轮为5／10／15，在所有列后处理。X5对应累计生产拍50／55／60之后，结算不加拍。共同损耗是一个事件再判胜败，双亡败；不耗护甲、不打断加工。暂停、回手、恢复或换轮不重置次数，明确新战才重置；其他构筑平衡未确认。

## 7. 布牌、暂停、恢复与信息

上牌到任意未开始空位、撤回未用牌、交换／调序免费，无每轮3点。对象或位置失格整项拒绝，不吞牌、不复制、不触发卡效。只有当前生产拍／列收尾停稳才能编辑，列内及已处理列始终只读。列间只开布牌，不开放其他玩法设置；下一敌列在确认后才揭示。详见[TL-18](common/interaction-save/rules.md#tl-18-手动上行撤回与整理)。

生产暂停完成本拍及动画再停；最终整理无时限。非末列结清后必停，确认才下一列；末列后的疲劳仍独立待办，单步不抢跑。正常退出先收尾已进入单位；异常恢复最近结清事件及已提交操作，静态停住，不补离线时间、不重播结果，不把列内恢复变成新选择窗。

保存回合／生产拍／列／步骤及确认状态、每卡唯一身份和手／行／待料／托管归属、使用／支付／回手事实；读档不复制牌、不重回收或支付、不重布敌牌。旧进行中存档不静默换算，规则版本与历史证据分开。

桌面显示完整X位；手牌为两组可切换持牌，显示准确数量及战斗／回收权限，不再使用默认手牌堆或另一份资源堆库存。必要信息有点击及键盘路径，不只靠颜色、声音、悬停；固定用途、当前加工、下一批待料及自动开关分别显示，材料占形／锁定／最早吸收拍与战斗回收即时分清。C1—C3卡面约定继续；旧3D只属CORE-063，新的持牌具体排布尚待展示规格。

## 8. 局内成长与长期边界

新局满预设生命、0金币，普通胜利不回血。法器、铭文和金币属本局库存；收益包只领取／放弃一次，卡牌选留另提交。未实际生成的卡不当已得收益。

未投入卡留背包、本场不可取用。战后按携带标签、种类及容量统一选留，保留身份数量阶级，重置临时增幅和运行状态；本场回收不自动授予跨战资格，未战斗卡也不自动清空。已消耗输入不退，未完工普通输入退回后按资格参选；同一实例反复回手只算一份。见[经济TL-25／33—35](common/run-economy/rules.md)及[路线TL-32](common/run-route/rules.md)。

休整拿铭文与恢复互斥，候选不足只恢复／跳过；商店固定货架、一项一件、足额支付才交付，不刷新退款或保底配齐。打造流程、完整获取链和背包参数未完成；局外成长未设计，不默认永久属性或实体解锁。

## 10. 用一个场景理解

有4层可消费施法次数、普通攻击及强化打击且目标存活。把普通放前、强化放后，普通打6记1至5，强化付5打18再记1，共24伤、余1层；顺序相反则强化不足回退6记1，普通再打6记1，共12伤、余6层。布牌本身免费，多伤害消耗了更多储备，且中途终局会停止后续。

可回收牌则能在一列使用完成后回手，再用于后续未开始列；如果把同一牌作为普通配方原料消费，战斗回收属性不能使它返还。局部正反例见[EX-003](examples/round-hand.md)，限定完整首场见[EX-004](examples/round-first-battle.md)；[验收](validation.md)只有设计预期，实际验证须另有授权。
