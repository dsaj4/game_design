# EX-003：回合整理局部案例

## 1. 输入与边界

生产片段仅复用旧例既有两护符：守护D2、施法D3，零材料、无开工标记费、每批1牌，战前守护→施法。三行动内容来自[旧EX-001 §3—5](simple-spell.md#3-法器与铭文)，不继承其Q、敌表、逐拍结果或胜败。当前X5、H3、每轮3行动点和疲劳取[现行参数](../parameters.md)。

下列彼此独立，除明确连接外不拼成一场。生产片段不模拟敌方卡效；支付片段明确假定合法目标、无插入致死、没有其他层数变化。缺失的新敌人、生命和完整初态仍Unknown，不用说明性空敌行替代合法五牌遭遇。

## 2. 第一次生产与跨轮

第0拍首次开工后，2拍护盾、3拍普通攻击、4拍护盾依次完成；第5拍拍末桌面3张，手牌空，没有卡效生效，施法次数未因生产增加。守护4→6、施法3→6的批次保留；最终整理不能撤销它们。第5拍没产满5张不补牌。下一回合第6生产拍才推进这两批，不因中间五个结算列完成而提前完工。

## 3. 排序与兑现

| 独立局面／操作 | 结果，假定未终局 |

| 可消费4层，强化→普通，不交换 | 强化回退6、记1；普通6、记1；总12伤、余6层，未花整理点 |
| 同局面花1点交换为普通→强化 | 普通6、记1至5；强化付5打18、记1；总24伤、余1层 |

| 前一完整事件已致死 | 停止余下卡效与后列，不补记次或疲劳 |

## 4. 行位与手牌反例

敌第2列攻击、己护盾第3列不能提前防；护盾放第2列时按防护组先执行。同列双方都是致死攻击，敌先，玩家死亡便无后续攻击。空位不使后列前移。

桌面满5、手牌A/B/C，再产D：右侧追加后丢D，不退制造料、不生效。桌面一张与手牌B交换，桌面牌留在原B位置，仍3手牌，不经过临时第4张。补手牌只到最左桌面空位，之后手牌闭合；无牌／行满拒绝不收费。手牌跨轮不自动补桌，战终清空。

## 5. 延时、打断与恢复

假定本轮按序生成两张公开后续牌，下轮占第1／2列，基础表原第1／2项跳过，原第3—5项照放；不重发、补发或累计到以后。生成阶段无加工法器的打断保持无对象，下轮不能补选。锁定法器原批已完工后若又加工新批，命中的是新批；已经产到桌面／手中的牌保留。

打断发生在回合末列，不能在后列之间开工。退料／有效冻结量在下一生产拍边界可用，拍末按条件检查新开工，不存在回收容量或独立空位门槛。若当列已终局，不启动下一拍。

付费交换后异常恢复保留已交换布局和剩余点数；生成后续牌后恢复不再生成或重锁。第5列后暂停不抢跑尚未结算的疲劳；回合末完成及布下轮各一次，不靠载入再重置3点。

## 6. 疲劳边界

只核规则位置，不假定某场必然活到这些回合。第9回合末无疲劳；第10／11／12回合各在五列后共同损失5／10／15生命。双方主结果结清再判，双亡玩家败；若此前卡效已终局，不补疲劳。X5时上述位置在生产拍50／55／60之后，结算列不额外推进时间。
