# EX-003：回合与统一卡牌局部条件例

2026-11-01 · unified-card-example.3 · CORE-067／068／071派生 / NotRun。原首战的具体生产与支付片段已撤下；以下只核对已声明合法对象时的通用机制，不建立任何具体物件、卡效、配方或完整遭遇。X=5、免费布牌、两组持牌和疲劳沿现行规则。

## 1. 行位、两组与回收反例

敌第2列攻击，防护牌第3列不能提前挡；放第2列按防护组先行。同列敌先致死则玩家攻击不执行。没有己牌的空列也会经过，不可在其结果出现后回填；可以把牌预放第3列而留第1／2空位，不自动前移。

两组仅按能否上行分开，切换不复制或改变持有量。已有3张又生产新牌，全保留，不再烧新牌。未开始列的己方实牌可与合格可战斗手牌互换，不能拿不可战斗牌换上行；普通上牌到已占位拒绝，但明确互换不因两端已有牌而拒绝。桌手互换保留原手牌位置；单独撤回未使用牌则回到对应组末尾。无效落点拒绝，不吞牌；同一牌不能同时放两列或被配方取走。

假设甲已声明可回收、防护及后续加层两个步骤：防护处理后不能提前回手；全部可执行步骤及依赖处理完成才回手。第1列结清后，可在列间将原甲放第2空列，下一次重新支付、检查目标；不能回填第1列。若空放，仍按回收属性回手，不补旧失败；第5列回手也不增加第6列。原结果只读，不算另一张甲。

## 2. 材料、打断与恢复

假设甲有合法材料性质、乙是不可战斗材料：先由自动补料或玩家从两组手牌排入法器专属供料区，须满足固定用途、形状与材料资格；不能取已上行、锁定、其他待料区、托管或未到供料时点的卡。每台最多一批待料；自动只补可凑齐配方的空缺，不替换手放料。材料排入后最早下一生产拍、配方完整且法器空闲才吸收。甲若成为普通输入，完工即被消费，可回收属性不返还原料。合成产物直接入手：有战斗权限的产物可在下一合法出牌窗口上行，下一生产拍才取得供料资格，之后仍须排入待料区并等下一拍才能吸收；不先打一张中介行动，也不在同拍无限合成。

若该批未完工被打断，退回的是原输入，回到手牌待用，不覆盖已排下一批；最早下一生产拍边界后才能上牌或重新排料，不适用“战斗使用后立即回手”。已有手／行成品不受追溯打断。结算列间不开工，即使回手牌已可用，也要等实际生产阶段检查；未完工战终沿携带资格，不补产物。

两张敌后续下轮先占第1／2位，原基础对应项跳过；无加工者时的锁定仍为无对象，下轮不补选。锁法器不锁原批。回手后恢复只有一份原卡，再上行后恢复不再额外返一份；每次使用的费用及已执行步骤独立保留。列内异常恢复不能趁机打开列间布牌。

## 3. 疲劳与终局边界

第9轮末无疲劳，第10／11／12轮全部列后双方各损5／10／15生命，双亡玩家败；暂停、切组、回手或恢复不重置次数。第5列后停住时疲劳仍待办，单步只处理轮尾及下一轮准备，不推进下一生产拍。中途终局停止新窗口和余步骤，已使用不可回收牌不参选，其他实际存活卡仍须独立携带资格，未取得产物不算收益。
