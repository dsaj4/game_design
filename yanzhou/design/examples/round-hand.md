# EX-003：回合与统一卡牌局部案例

2026-10-27 · unified-card-example.1 · CORE-067派生 / NotRun。依据[采纳记录](../../sources/draft-changes/D-2026-10-27-unified-card-model.md)；原CORE-065局部例可按其共同输入提交取证。这里的局面彼此独立，不拼成完整遭遇，不发行新卡。

## 1. 输入与边界

生产片段沿守护D2、施法D3，零材料、无开工标记费用、每批1牌、战前守护→施法。三种真实卡效沿[EX-004 §3](round-first-battle.md#3-法器行动与支付)，均不可回收、无材料／携带资格。X5、无手牌硬上限、免费布牌与列间窗口沿CORE-067；不继承旧Q、H3、整理点或连续拍预期。

支付片段假定目标合法、无插入终局、没有其他层数变化。回收与合成片段只假设已合法声明相应卡／配方，不将假设对象加入首场内容。完整首场只用EX-004。

## 2. 第一次生产与跨轮

第0拍开工，2拍护盾、3拍攻击、4拍护盾进入手牌，直到第5拍后仍是三张在手、战斗行空；制造不生效或记次。玩家可把三张放到任意未开始空位，其余列留空。守护4→6与施法3→6批次保留，最终整理不撤回；中间结算列及列间确认不推进D，第6生产拍才继续。

## 3. 排序与兑现

| 独立局面／操作 | 预期，假定未终局 |
| --- | --- |
| 可消费4层，先强化后普通 | 强化回退6记1，普通6记1；总12伤、余6层 |
| 同局面免费排成普通→强化 | 普通6记至5，强化付5打18再记1；总24伤、余1层；代价是消费储备，不是整理点 |
| 初始3层，普通→强化 | 普通后4层，强化仍回退，排序不能凭空补费用 |
| 实有9锁5，轮到强化 | 可消费4，回退6再记1；总层10、锁5，列间不能解锁救付款 |
| 最终整理锁5改4 | 之后可付5打18再记1，最终5层、锁4；免费解锁不立即使用卡 |
| 前一事件已致死 | 后续卡效、记次、出牌窗口与疲劳不补 |

## 4. 行位、两组与回收反例

敌第2列攻击，护盾第3列不能提前挡；放第2列按防护组先行。同列敌先致死则玩家攻击不执行。没有己牌的空列也会经过，不可在其结果出现后回填；可以把牌预放第3列而留第1／2空位，不自动前移。

两组仅按能否上行分开，切换不复制或改变持有量。已有3张又生产新牌，全保留，不再烧新牌。未开始列的己方实牌可与合格可战斗手牌互换，不能拿不可战斗牌换上行；普通上牌到已占位拒绝，但明确互换不因两端已有牌而拒绝。桌手互换保留原手牌位置；单独撤回未使用牌则回到对应组末尾。无效落点拒绝，不吞牌；同一牌不能同时放两列或被配方取走。

假设甲已声明可回收、防护及后续加层两个步骤：防护处理后不能提前回手；全部可执行步骤及依赖处理完成才回手。第1列结清后，可在列间将原甲放第2空列，下一次重新支付、检查目标；不能回填第1列。若空放，仍按回收属性回手，不补旧失败；第5列回手也不增加第6列。原结果只读，不算另一张甲。

## 5. 材料、打断与恢复

假设甲有合法材料性质、乙是不可战斗材料：合格配方可从两组取甲／乙，但不能取已上行、锁定、托管或未到供料时点的卡。甲若成为普通输入，完工即被消费，可回收属性不返还原料。合成产物直接入手：有战斗权限的产物可在下一合法出牌窗口上行，最早下一生产拍才能给下一配方；不先打一张中介行动，也不在同拍无限合成。

若该批未完工被打断，退回的是原输入，最早下一生产拍边界后才能上牌或供料，不适用“战斗使用后立即回手”。已有手／行成品不受追溯打断。结算列间不开工，即使回手牌已可用，也要等实际生产阶段检查；未完工战终沿携带资格，不补产物。

两张敌后续下轮先占第1／2位，原基础对应项跳过；无加工者时的锁定仍为无对象，下轮不补选。锁法器不锁原批。回手后恢复只有一份原卡，再上行后恢复不再额外返一份；每次使用的费用及已执行步骤独立保留。列内异常恢复不能趁机打开列间布牌。

## 6. 疲劳与终局边界

第9轮末无疲劳，第10／11／12轮全部列后双方各损5／10／15生命，双亡玩家败；暂停、切组、回手或恢复不重置次数。第5列后停住时疲劳仍待办，单步只处理轮尾及下一轮准备，不推进下一生产拍。中途终局停止新窗口和余步骤，已使用不可回收牌不参选，其他实际存活卡仍须独立携带资格，未取得产物不算收益。

完整首场见[EX-004](round-first-battle.md)，其三张牌没有回收或材料能力；本页条件性回收故事不冒充该例运行覆盖。
