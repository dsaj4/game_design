# 参数与常量

2026-10-11 · ParameterScope。这里维护共同约束；原案例值见[EX-001](examples/simple-spell.md)，完整单战增量见[EX-002](examples/complete-battle.md)，现实播放／显示值见[交互合同](common/interaction-save/rules.md#首场战斗操作合同core-060)。全局缺失量集中在[问题登记](../governance/questions.md)。

| 参数 | 单位与确定约束 | 权威 |
| --- | --- | --- |
| 逻辑时间t | 离散整数拍，第0拍开始；首场播放秒数与倍速沿CORE-060，不改整数拍序 | TL-11／17 |
| 处理D | 正整数，至少1；a开工、a+D完工；开工冻结 | TL-03 |
| 时间公式 | max(1,ceil(max(0,D0+ΣΔ)×∏m))；无倍率为1 | TL-03 |
| 配方材料量 | 内容明确完整费用；允许明示零材料，缺字段不能按0 | TL-43／CORE-059 |
| 每批张数 | 内容声明正整数，并预留同数容量 | TL-05 |
| 队列Q | 有限；实牌＋有效预留＋待复用≤Q，每牌占1 | TL-05／08 |
| 玩家行动 | 每拍至多1张；t入行，最早t+1生效 | TL-08 |
| 开工检查 | 每拍末对各空闲法器至多1次 | TL-05／11 |
| 资源可用 | 初始库存0拍可用；新增／基础补给／退料最早下拍 | TL-14／15 |
| 容量回收 | 正常离队当拍末可用；中断回收下拍可用 | TL-07 |
| 标记承诺 | 开工冻结完整费用、完工扣除；中断仍有效量下拍可用 | CORE-055／057 |
| 临时供料 | 同时1份，结束拍>当前拍；新替旧、到期回基础 | TL-06 |
| 敌延迟Δ | 正整数，T=r+Δ；每牌声明 | TL-09 |
| 取消截止 | 实际生效<T；防护取得行动资格时可在T先结算 | TL-10／11 |
| 敌循环L | 每遭遇声明正整数及翻开偏移，程序固定 | TL-16 |
| 打断锁定R | a+D−r，取最大非负剩余值，含0；并列取战前法器序 | TL-09 |
| 来源敌人 | 每场1名；同检查点双亡玩家败 | TL-13 |
| 定时登记 | 首次f≥建立拍+1；周期p>0；次数有限或结束拍e，e不兑现 | 标记CORE-057 |
| 普通量值 | max(0,floor((基础＋固定增量)×声明倍率))；多倍率合成须内容声明 | TL-37 |
| 新局金币 | 0 | TL-33 |
| 新局生命 | 预设上限的满值，普通胜利不回血 | TL-33 |
| 开战合法配置 | 至少1台完整合法铭刻法器 | TL-31 |
| 核心／辅槽 | 核心必填且不可打造；辅槽可空，实际槽数逐法器声明 | TL-39—42 |
| 休整候选 | 3个不同名，至少1名词、1动词；选1或全放弃；池不足只恢复／跳过 | TL-34 |
| 商店单项 | 1件，买后不补；库存与价格抵达后固定 | TL-35 |
| 本局存档 | 同时1份，设置独立 | TL-36 |
| 背包 | 有限种类＋共享容量，每份占容量，不同阶级算不同种 | TL-25 |
| 战中资源区 | 当前不设额外硬容量 | TL-14 |

实际Q、生命、伤害、标记上限、D0、经济及补给等随内容给定；EX-002明确固定复用EX-001配置，新增疲劳只作用本场。跨构筑全局疲劳、背包数值、付费干涉、打造与稀有度预算按问题表决策。

参数字段须包含单位、合法域、零值、读取时点及来源。旧交付J、休歇R、冷却和首次起点S已经退役；当前R只表示打断揭示时的剩余加工拍，L只表示敌程序循环长。
