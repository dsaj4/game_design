旧C／L／τ属于RC1，不迁入本版。CORE-051取消交付J、休歇R、独立生产周期／冷却和首次起点S；它们退出参数表，不作为“值为0”的可调项。D沿本次唯一处理耗时定义。开工条件等待与入行后排队属于条件后果，不是新增生产耗时参数；资源补给与维护周期仍独立存在。

退役卡表v0.1的数字只按原提案固定版本取证，不作为当前候选或默认参数。冻结原型前逐项填单位、取值域、零值许可和来源；缺项不能从示意图补数。

## 兼容复用明确的常量与非默认项

| 参数／结构 | 当前值或限制 | 来源与范围 |
| --- | --- | --- |
| 新局初始金币 | 0 | TL-33；只指新局金币，不指每战干涉费用 |
| 新局生命 | 该局预设生命上限的满值 | 上限数值待定；普通胜利不自动满血 |
| 可开战配置 | 至少1个完整合法法器 | TL-31；法器总额度仍Unknown |
| 休整铭文候选 | 3个不同名，至少1名词、1动词；选1或全部放弃 | TL-34；池不足只恢复或跳过，不代表持有额度3 |
| 商店单项库存 | 1件，购买后不补货 | TL-35；货架槽数、内容池和价格待定 |
| 同时进行中的本局存档 | 1份，设置独立 | TL-36；不限制内部保存可靠性方案 |
| 普通效果数量 | 合并固定增量后应用声明倍率，最终向下取整且不小于0 | TL-37；不默认应用于时间、支付、维护或疲劳 |
