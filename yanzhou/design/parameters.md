# TL-1 参数登记

Project ID：game-002。文档角色：ParameterScope。2026-10-01。结构约束Accepted；未定数值Unknown。旧PG数值见[固定RC1表](https://github.com/dsaj4/game_design/blob/d6e54af395518401fb4d8466b2302a1271da557a/yanzhou/design/parameters.md)。

| 参数 | 单位／约束 | 当前值／状态 |
| --- | --- | --- |
| 逻辑拍 | 离散战斗时间 | 实际秒数Unknown；不默认旧0.5秒 |
| 首次起点S | 拍 | 战前可编排；范围Unknown，不默认0–10 |
| 加工耗时D | 拍／批 | 单独声明，值Unknown |
| 交付耗时J | 拍／批 | 放牌耗时；不复用旧释放L，值Unknown |
| 休歇R | 拍／批 | 与加工、交付分开，值Unknown |
| 循环周期 | 拍 | 随实际完成及阻塞顺延；公式需结合各阶段确认 |
| 玩家队列Q | 行动卡张数 | 有限；值Unknown |
| 玩家兑现速度 | 行动卡／拍 | 至多1张 |
| 资源容量／补给 | 张、拍 | 基础周期供给；容量、数量、周期Unknown |
| 敌牌延迟Δ | 拍 | 从揭示r到T；关键应对牌Δ大于0 |
| 取消截止 | 拍 | 实际生效严格小于T |
| 玩家干涉费用 | 另定费用单位／战 | 每场固定、暂不成长；额度、回充、共享、价格延期 |
| 法杖与词卡额度 | 根／张 | 随新卡表确定；旧数量不自动迁入 |
| 生命周期／维护／增幅 | 拍、材料量、级数等 | 候选已提出，尚未采纳具体量 |
| 敌人生命／攻击 | 点 | 随新遭遇确定 |
| 终局压力与节奏 | 拍、生命损耗 | 递增疲劳方向已定；开始时刻、频率与曲线重定，不沿旧80／120上界 |
| 跨战携带容量 | 容量单位／份 | 共用容量；数值及各资源占用量Unknown，只有可携带标签参与 |
| 战外经济 | 金币、物品、节点 | 随新可用卡池与路线复审 |

旧C为冷却、L为释放段、τ为词卡时间贡献；它们属于RC1，不能将旧L＝3搬成“入行3拍”或“连续出3张牌”。本轮用D／J／R避免符号换义。

新卡表v0.1的数字是提案初值，均留在[候选素材](../exploration/DIR-028-timeline-depth/M-2026-10-01-resource-card-pool.md)，不形成第二套当前默认参数。冻结原型前逐项填单位、取值域、零值许可和来源；缺项不能从示意图补数。
