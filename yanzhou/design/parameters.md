# 参数与常量

2026-10-24 · ParameterScope / CORE-065＋066。这里维护共同约束；现行限定完整首场的具体值见[EX-004](examples/round-first-battle.md)；旧连续拍案例值见[EX-001](examples/simple-spell.md)，旧完整单战增量见[EX-002](examples/complete-battle.md)，当前停点与受理见[交互合同](common/interaction-save/rules.md)，旧播放秒数不作为新2D默认。全局缺失量集中在[问题登记](../governance/questions.md)。

| 参数 | 单位与确定约束 | 权威 |
| --- | --- | --- |
| 逻辑时间t | 离散整数生产拍；第0拍就绪开工，结算列不递增t | TL-11 |
| 回合n／长度X | n从1计；X为本场固定正整数，当前5；第n轮生产拍(n−1)X+1…nX | CORE-065／TL-11 |
| 桌面位数 | 敌我各X位；允许玩家空位，敌开始按真实表布满；列不等于拍 | TL-08／16 |
| 玩家手牌H | 当前3张，右端追加，超限移除最右；跨轮保留、战终清空 | TL-05／08 |
| 整理行动点 | 每轮重置3点，不累存；每次成功整理1点，失败不扣、改回再付 | TL-18 |
| 首场疲劳 | 首次第10回合末，随后每轮一次，第n次双方损失5×n生命，在各列之后 | TL-24／CORE-065 |
| 处理D | 正整数，至少1；a开工、a+D完工；开工冻结 | TL-03 |
| 时间公式 | max(1,ceil(max(0,D0+ΣΔ)×∏m))；无倍率为1 | TL-03 |
| 配方材料量 | 内容明确完整费用；允许明示零材料，缺字段不能按0 | TL-43／CORE-059 |
| 每批张数 | 内容声明正整数，按内部序逐张放成品；不预留容量 | TL-05 |
| 队列Q | 旧连续拍限定，当前不使用；不是桌面＋手牌的开工闸门 | CORE-065 |
| 玩家行动 | 每结算列至多一张己牌；末拍成品可用于本轮，空位不补牌 | TL-08／11 |
| 开工检查 | 每生产拍拍末对空闲法器至多1次；换轮／列间不额外检查 | TL-05／11 |
| 资源可用 | 初始库存0拍可用；新增／基础补给／退料最早下一生产拍 | TL-14／15 |
| 容量回收 | 新首场无预留／待复用容量；材料及有效冻结量下一生产拍可用 | TL-07 |
| 标记承诺 | 开工冻结完整费用、完工扣除；中断仍有效量下一生产拍可用 | CORE-055／057 |
| 临时供料 | 同时1份，结束拍>当前拍；新替旧、到期回基础 | TL-06 |
| 敌延迟Δ | 旧连续拍限定；新首场延时牌生成下一回合才可用的后续牌 | TL-09／16 |
| 取消截止 | 在已公开更右侧后续牌的目标列开始前完成；同列来不及 | TL-10 |
| 敌循环L | 旧拍单位不迁移；新遭遇声明按回合的循环及每轮X位基础表 | TL-16 |
| 打断锁定R | 后续生成时a+D−t，按当前在制批次剩余生产拍最大，并列战前序 | TL-09 |
| 来源敌人 | 每场1名；同检查点双亡玩家败 | TL-13 |
| 定时登记 | 原f／p／e合同保留旧扩展范围；CORE-065未迁移，不启用 | 标记CORE-057／065 |
| 普通量值 | max(0,floor((基础＋固定增量)×声明倍率))；多倍率合成须内容声明 | TL-37 |
| 新局金币 | 0 | TL-33 |
| 新局生命 | 预设上限的满值，普通胜利不回血 | TL-33 |
| 开战合法配置 | 至少1台完整合法铭刻法器 | TL-31 |
| 核心／辅槽 | 核心必填且不可打造；辅槽可空，实际槽数逐法器声明 | TL-39—42 |
| 休整候选 | 3个不同名，至少1名词、1动词；选1或全放弃；池不足只恢复／跳过 | TL-34 |
| 商店单项 | 1件，买后不补；库存与价格抵达后固定 | TL-35 |
| 本局存档 | 同时1份，设置独立 | TL-36 |
| 背包 | 有限种类＋共享容量，每份占容量，不同阶级算不同种 | TL-25 |
| 战中资源区 | 当前不设额外硬容量 | TL-14 |

生命、伤害、标记上限、D0、经济及补给等随内容给定；旧EX-002固定输入和疲劳只作用旧连续拍案例。当前新首场完整初态与敌表已由CORE-066在EX-004冻结，仅适用于该案例，不成为全局默认。跨构筑全局疲劳、背包数值、其他付费干涉、打造与稀有度预算按问题表决策。

参数字段须包含单位、合法域、零值、读取时点及来源。旧交付J、休歇R、冷却和首次起点S已经退役；当前R表示打断后续生成时的剩余生产拍；旧L拍数不换算成新表循环，新表循环单位为回合。
