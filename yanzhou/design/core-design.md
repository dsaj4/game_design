# 《言咒》核心设计

Project ID：game-002。文档角色：CoreDesignSummary。修订：CORE-SUM-1 / 2026-09-24。概括基准：GDD 1.0 RC1 / doc.1；Core Concept v0.6。

本页是可单独阅读的GDD浓缩，服务于理解游戏、讨论方向与限定背景探索。已有规则的设计状态为Accepted，平衡、完整体验与玩家理解仍为Hypothesis／NotRun。详细规则以GDD及对应系统正文为准；概括不补齐例外，也不因遗漏某条规则就取消该规则。

## 1. 这是什么游戏

《言咒》是一款单人离线的战前法术编排与自动战斗游戏。玩家用实际持有的词卡写出完整法术，把它们装到法杖上，安排范围、出场顺序和第一次冷却起点，再观看各根法杖自动循环施法。沿分叉路线获取新词、购买组件或恢复生命，最终挑战首领。

目标玩家喜欢读规则、组合卡牌和调整计划，不需要编程知识。首版为Windows、简体中文、键鼠操作；完整有效局目标15–25分钟，初次含引导20–35分钟，均是设计目标而非已测结果。

核心体验承诺是：**“我知道这次法术为什么成功或落空，也知道下一场该改哪张词、哪个范围或哪一刻。”**

## 2. 玩家一局做什么

统一资源开局 → 看路线与公开敌情 → 用库存构句并编排法杖 → 锁定配置、观看自动战斗 → 普通胜利后整体领取或放弃金币 → 选择路线、休整或商店 → 调整下一场配置 → 首领胜利或玩家失败结束本局。

- 开局为100生命、0金币、4根原木杖和12张词卡。默认编排只是这些实际资源的一种用法，玩家可以拆改。
- 一条通关路径包含6场普通战斗和1场单阶段首领。全图有19个节点、12种遭遇配置；不是每局访问全部节点。
- 战前可完整重配已有资源，战中只能观察、暂停、倍速和查原因；不能临时改句、换杖或靠即时操作救场。
- 普通胜利后剩余生命、已获得库存和金币跨战保留；护甲及场内状态清理。新局不继承旧局数值资源，长期成长来自理解和策略积累。
- 玩家生命归零判负；敌人全灭且玩家仍存活判胜。同一检查点双方耗尽时玩家失败优先；首领胜利直接结束本局。

## 3. 构句：词既是表达，也是稀缺资源

每张词卡是一件实际物品，一个词位置占用一个实体，一张实体不能同时用于另一条法术。完整句子共同形成一条循环法术，而不是每个词分别放一次技能。完整法术绑定一根杖，最多4根合法法杖同时出战。

句子可以省略显式主语，例如“伤害 敌人”“获得 护甲”“释放 火焰”；也可以由合法元素执行动作，例如“火焰 伤害 敌人”。两句都要用“火焰”，就要有两张火焰实体。“我想得到同样的词义”不等于可以免费复制词。

名词、动词和修饰词各按明确词义组合；修饰词直接挂在本句原词上，增加实体占用与时间成本。类型可以多标签，流派也可混搭，标签本身不提供免费加成。条件搜索与精确实例绑定分开：同一格后来出现的新对象不是原对象，失效时不能自动换绑。本次实际对象名单固定，仍逐对象检查资格和费用。

首版普通词同名最多3张；没有额外“编入总张数”上限，实际受库存、副本分配、合法词义和4杖约束。越复杂的句子不一定越好，它会占用其他句可用的词和时间。

## 4. 编排：四根杖共同争取时间与空间

每根杖选择一个固定范围锚点、一个完整法术、出战顺序和0–10刻内的首次冷却起点。句子的词卡时间贡献及动词规定共同决定冷却C与释放段L；之后按规则循环。首次起点不是全队公共循环长度。

**所有法杖每刻竞争同一个“释放开始槽”。** 同刻有多个开始机会时后杖优先；这不表示整个释放段独占槽，已开始的持续过程可按规则并存。覆盖、打断与续排各有边界，不能理解成排队补发。

三种法杖用范围和固定芯形成差异：原木覆盖较宽；节律杖为十字范围，影响符合条件的冷却节奏；余火杖为同排范围，影响合法燃烧新增量。每杖另有2个可换镶嵌槽。买新杖是替换出战选择，不增加4杖上限。

玩家要权衡：保住哪条句子的开始机会、让哪根杖先准备元素或状态、怎样把有限范围覆盖到需要的对象。不同法杖不是四个互不相关的自动伤害来源。

## 5. 战场与执行：结果必须能解释

第一人称战场为前后两排、每排五格，玩家位于棋盘外。每格的地面与占位对象独立，每格最多一个占位对象；法杖锚点只定位范围，不占格，也不是移动指令。

逻辑刻按玩家法术、敌人行动、环境、状态四阶段推进；完整事件后检查胜负，结束就停止后续处理。普通伤害先耗护甲，实际生命伤害才打断当前冷却；费用支付和疲劳不因此变成普通伤害。根动作后的响应只允许有限一层，不能无界递归。

火焰、冰霜元素本体与宿主身上的燃烧、冰冻状态不同；固有属性与历史痕迹也不同。元素可以生成、补层、被消耗或抵消，并通过合法邻近及操控参与攻防。对象同时最多一种元素状态；新入量按既定修正后抵消。树、草地等环境按资格、阈值和身份变化产生本场痕迹或转化，不推演成万能物理模拟。

由此产生的取舍包括：立即用词打出效果，还是先建立可复用的元素；先消耗层数获得收益，还是保留给下一轮；扩大覆盖，还是选择较窄范围附带的能力。具体阈值、量值和卡牌例外只在详细正文定义。

## 6. 路线与成长：为下一场重新准备

路线提供公开压力与有限成长机会。普通战斗只奖励规定金币，不掉词卡；词卡来自起点、休整拿词或商店。休整在恢复生命与取得词之间做选择，商店用金币购买有限货架内容，没有免费刷新或随意重抽。

词卡和镶嵌按局内阶段开放，但开放不等于赠送；同名上限、物品唯一额、预算与货架共同限制取得。首版有34种词卡、19种可换镶嵌，共53种实体；55个流派设计ID中有共享实体，不是55种独立卡。

生命损耗会影响以后几场，采购也会放弃别的机会。疲劳给战斗设置有限终局，不能靠永久等待积累无限收益。成长应让新资源改变下一场的编排理由，而不只是沿用旧配置提升数字；这一体验仍需验证。

## 7. 七个系统各负责什么

| 系统 | 核心职责 | 提供给玩家的决定 |
| --- | --- | --- |
| SYS-001 实体构句与类型 | 实体分配、句义、条件与合法性 | 哪些词组成哪句话，舍弃哪种组合 |
| SYS-002 法杖与编排 | 范围、镶嵌、顺序与首次起点 | 把句子放在哪根杖，以怎样的节奏覆盖哪里 |
| SYS-003 自动战斗 | 时间、开始仲裁、事件、支付和状态 | 从执行原因判断计划哪里需要改 |
| SYS-004 元素与环境 | 元素身份、层数、邻近、抵消和转化 | 如何准备、保留或消耗场上资源 |
| SYS-005 路线与遭遇 | 公开关卡压力、分支与有限终局 | 面对哪种压力，走向哪个成长节点 |
| SYS-006 收益与成长 | 金币、有限获取、商店和休整 | 拿什么、买什么、何时恢复生命 |
| SYS-007 交互与保存 | 阅读、操作、反馈、锁定与恢复 | 看懂结果，并在允许的时点完成选择 |

界面应显示实体占用、范围、时间与失败原因，不能只靠音效或颜色传达关键规则。退出战斗后从同场开头按锁定配置重播，不能回战前重配或刷新已确认结果；界面便利不新增玩法权限。

## 8. 首版边界与未解决的问题

首版没有战中出牌或重配、永久卡牌升级与局外数值成长、联网、移动端、完整召唤与指挥、任意位移或空间塑形、复杂传播或材料加工、法术产卡产金、战中治疗／吸血／涨上限／复活。语法和分类中的旧示例不开放首版外卡牌；没有可获得副词卡、草法术或雷电新内容。

已有26组设计选择的Closed仅表示规则选择完成。完整RC1平衡、至少多类构筑可行、玩家能独立理解原因仍待验证；不能把规则确定或原型局部通过当作游戏已经好玩。

**AUD-010仍Open：同刻“新开始动作”与“既有持续过程子事件”的总顺序尚需消歧。** 例如补元素与消耗元素谁先发生，不能只凭后杖优先推导。涉及此处的探索保留条件分支，不能自行选一个顺序当成现行规则。
