# 《言咒》核心设计

Project ID：game-002。文档角色：CoreDesignSummary。2026-10-04 / CORE-SUM-3 / Core Concept v0.8。浓缩[GDD 2.1 / TL-1 + INS-1](GDD.md)，采纳范围见[CORE-049](../sources/draft-changes/D-2026-10-04-artifact-inscription-core.md)与[routing.1／CORE-050](../sources/draft-changes/D-2026-10-04-routing-response-clarification.md)。结构Accepted，当前GDD-0；体验Hypothesis / NotRun。

## 核心体验

玩家装配能自行运行的法器配置，安排材料、生产周期与行动时机。法器反复加工行动卡，有限玩家战斗行逐张兑现；敌人依预置暗牌程序揭示倒计时威胁。玩家平时观察计划运行，关键威胁出现时暂停思考，调整未来供料去向与优先级或承受损失；付费干涉的具体能力继续待定。

攻击、防御、运转是功能划分。面临将要到来的攻击，玩家可暂缓下一轮资源积累，将兼容的未承诺材料优先给防御端叠甲；遇到明确打断，则先仅通过供料调整未来开工。代价体现为积累延后、攻势减少或危险加工时段的等待，具体配方与窗口仍待内容设计。

体验假设是：安排好时间与资源，处理阻碍后，让准备的行动兑现明显收益。普通区间不要求持续搬料或逐张点击出牌；受限铭刻能否保留足够选择，尚未验证。

## 法器铭刻与三类卡

法杖统一为各式可用于施法的法器。每个法器预设暗句，仅留“名词＋动词”组合中的若干核心空缺；补全后的语义必须成立并符合器具内涵，不开放完整自由构句、对象类别或材料类别槽。全部核心必填，核心槽不可打造。

辅槽放修饰词，可留空，挂接位置／词义由法器预设；辅槽可打造新增／解锁，数量原则上不超过核心槽。费用、时机和持久范围尚未确定。

铭文是原程序词卡的装配职责：一实体一位置、循环生产不消耗，同名多处须真实副本。法器读取一组合法核心与辅槽配置反复执行；暗句意义确定行动卡种类，具体卡效另行设计。法器对若干核心铭文特别增幅，数值、效果改写、附效及“契合附魔”表现均未定。

法器统一产出行动卡，经普通战斗行生效。资源卡仍承担制造耗材与明确产物等职责；材料类别与造物／对应制造内容绑定，不独立填入核心槽。基础材料周期供给，高阶材料来源与加工途径Unknown，不继续默认法器直接交付资源卡。具体法器、铭文、卡效、配方与新发行池尚待设计。

## 时间与有限产能

每批经历取料、加工和耗时交付。行内每格一牌，同拍至多兑现一张玩家行动卡；队列满时成品留在原法器，交付后才继续生产。缺料、阻塞与返工使后续实际节拍顺延，不补发错过的轮次。

铭刻是否合法与当前是否有料分开：完整合法配置缺料自动等待。免费改合法路由只影响未承诺的未来批次，不重铭、不改已托管材料、成品或已入行牌；预览区分预计与实际结果。

## 敌情、目标与操作

所有敌方行动牌均在揭示后经过正延迟才生效。揭示前只给类型线索，揭示后完整公开效果、目标／范围、到期与打断条件并锁定目标。取消敌牌的行动也经普通队列，必须严格早于到期实际生效；成功后留空档，后续不提前。

核心不开放目标类别槽，具体行动卡仍独立声明效果目标。己方按本批承诺在生效时选择；实例消失不换同名对象，本次名单不补位，已完成合法结果不回滚。无合法目标空放离队，不退制造材料、不补发；制造与明示效果支付分开。

普通伤害扣护甲／生命，不自动中断全部法器。明确打断只作用公开指定法器，被中断加工退料、损失进度和时机。临时应对结束自动恢复基础设置，已付费、返工、延误和合法收益保留。暂停不自动授权重铭或打造。

同拍已定大类顺序为防护→伤害与打断→幸存加工完工；新产资源与退料最早下一拍使用。复合行动、维护及其他并发总顺序仍须补齐。

## 战场、恢复与跨战取舍

卡牌战场表达敌行、资源区、玩家行与法器处理区；旧2×5、邻近和范围锚点不作为默认规则。完整事件后检查胜负，玩家存活且敌全灭才胜，同检查点双亡玩家失败。未终局时敌程序循环、旧倒计时继续。

全局暂停冻结双方和资源计时；退出恢复最近结清的一刻及已提交操作，保留敌情、支付、材料、队列与进度。资源内容明确存在时才适用自动维护／休眠与增幅规则；到期维护优先，剩余材料按当前有效供料优先级分配，默认战前法器序；成品争入行始终沿战前法器序。递增疲劳方向保留，参数和终局上界重定。

只有卡表标注可携带的资源参与战后共用容量选择，记住偏好；基础料清空，只保留种类数量，增幅及运行状态重置。法器契合与辅槽打造的持久范围单独待定，不从资源重置推导。

## 正式范围与下一步

铭刻入口采用TL-38–45；TL-20材料—动作—目标入口由INS-1替代，实体占用与耗材分账继续保留。自由挂接改为辅槽预设挂接；具体内容、效果和增幅形式没有随之采纳。

每战干涉费用固定、暂不成长；辅槽打造另属构筑成长，成本未知。单向路线不回访刷取，商店固定货架一项一件，休整恢复与3选1拿铭文互斥。普通胜利不免费回血，新局满预设生命、0金币；真实开局、供给与经济需随铭刻卡表复审。旧53实体、三杖款式、12遭遇及参数不自动迁入。
