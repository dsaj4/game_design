# 《言咒》核心设计

Project ID：game-002。文档角色：CoreDesignSummary。2026-10-01 / CORE-SUM-2 / Core Concept v0.7。浓缩[GDD 2.0 / TL-1](GDD.md)与本轮[采纳记录](../sources/draft-changes/D-2026-10-01-timeline-production-core.md)。已采纳结构不等于体验验证；当前GDD-0，Hypothesis / NotRun。

## 核心体验

玩家编排一个可以自行运作的法术生产网络：法杖按各自周期收取材料、加工资源或行动卡，行动卡经过有限的玩家战斗行逐张生效。敌人依预置程序翻开暗牌，揭示将要发生的倒计时行动。玩家平时看计划运行，关键威胁出现时暂停思考，决定改后续路由、付费干涉或承受损失。

爽感假设是“安排好时间和资源，处理阻碍后，让准备已久的法术兑现明显收益”。规则不要求持续手动搬运和逐张点击出牌。

## 法术、法杖和三类卡

词卡用于战前编写完整法术，一张实体不能同时支撑两个位置；它不是每次加工消耗的材料。每根法杖绑定一个法术反复执行，多个法杖的周期、首次起点和资源依赖形成整体顺序。

资源卡是加工材料、中间产物及明示可维护的法术产物；行动卡是已生产、等待在战斗行生效的一次行动。基础环境材料周期补给，高阶材料靠加工。卡牌具体名称、配方和新词义由重新设计的卡表决定，不能按旧卡名推导权限。

句法采用“材料—动作—目标”：材料位置说明本批耗材，程序词卡持续占用，不因加工被扣除。

## 时间与有限产能

一批法术需要取料、加工、交付；放入玩家战斗行也耗时。每个行动格只放一张卡，同刻至多兑现一张玩家行动卡。待翻牌队列有限，满时成品留在原杖，交付后才继续生产。

缺料、行满和返工按实际完成使后续节拍顺延，不补发错过的轮次。预览显示预计时刻及依赖，不把名义计划画成必然结果。

己方在效果生效时按本批预设规则自动选择合法目标；没有合法目标则空放离队，不退制造材料、不补发。免费改输入／输出路由只影响尚未承诺的批次；不能改已托管材料、已产成品或已入行牌。

## 敌情与操作

敌牌翻开之前只有卡背等类型线索；翻开后公开完整效果、目标／范围、触发时刻和打断条件，并锁定目标。部分牌可被专门的打断法术取消，打断仍由法杖生产并通过普通战斗行排队。

取消必须在敌牌到期之前实际生效；同拍来不及。成功取消保留空档，不提前后续敌牌。关键威胁通常一个，少量双威胁，普通行动可以由基础循环处理。

普通伤害消耗护甲／生命，不再因为玩家掉血打断全部法杖。只有明确打断效果中断公开指定的法杖；被中断批次退回材料、损失加工进度和时机。临时应对结束自动恢复基础设置，但不退还已付费用、不抹除返工和延误。

同拍已确认的大类顺序为防护→伤害与打断→幸存加工完工；新产和退回资源最早下一拍使用。复合行动、状态周期与其他同类并发的总顺序仍须补齐。

## 战场、胜负与恢复

战场以敌方战斗行、资源卡区、玩家战斗行和法杖处理区表达。旧2×5格子、邻近和范围锚点不继续作为默认规则；具体布局仍待UI确认。

生命决定胜负，战斗未结束时敌方程序循环，旧倒计时继续。沿用完整事件后检查胜负、玩家存活且敌人全灭才胜利，以及同一检查点双方归零时玩家失败的既有终局原则；这是明确的兼容继承，不引入平局。具体同拍总顺序待补。

全局暂停冻结双方及资源计时；战中退出恢复最近结清的一刻及已提交操作，保留揭示信息、材料、队列、进度和已付费用。

## 维护、疲劳与跨战取舍

高阶产物维护不足时休眠，保留身份与增幅，补料自动恢复。到期维护先于新加工分料，余料按战前杖序分配；入行争用沿同一杖序，其他成品等待。战斗拖长后的递增疲劳方向保留，所有参数与终局上界重定。

只有标注可携带的资源参与战后选择，共用携带容量并记住偏好；基础环境料清空。跨战只保留数量，增幅与运行状态全部重置。因此资源积累可影响下一场，增幅收益需要在本场兑现；具体容量与卡种仍待定。

## 正式范围与下一步

当前正式的是上述结构及与之兼容的实体构句、明确对象资格、伤害先甲后生命、不可撤销已完成结果等基础约束。新卡表另行重设计；旧53实体、三杖款式、12遭遇及其参数不自动迁入。

费用每场固定，暂不设计成长；干涉能力另设系统后续设计。路线、商店、休整保留局外于战斗的组织用途，具体货架、初始库存、节奏与经济须随新卡池复审。维护、增幅和高阶材料的规则接口已明确，具体内容与边界仍Unknown。
