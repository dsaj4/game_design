# 交互与保存：体验目标

2026-10-23 · Hypothesis / NotRun。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 能少操作 | 生产拍无需逐拍确认，每轮最终整理确认有明确作用，关键调整有理由 | 逐拍跨多个面板维持基础循环 |
| 预测可信 | 辨认确定承诺与条件预告 | 把预测当已经发生 |
| 恢复连续 | 返回后认出原计划和已支付结果 | 需要重新猜测或重做选择 |
| 实体因果清楚 | 能沿法器、卡片与目标解释已发生顺序 | 只看动效却读不出真实余额，或误认点击牌会出牌 |
| 输入可达 | 不用拖拽或悬停也能完成必要操作 | 重要入口仅能通过一种感官发现 |

观察时先记录玩家预测与选择理由，再对照实际结果。分开记录规则误读、信息找不到、数值失衡；使用具体内容和界面版本。验证任务尚未执行。
