# 交互与保存：规则

2026-10-23 · CurrentSpec；首场合同按各自范围Accepted。[状态与来源](../../baseline.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

通用行为读TL；制作EX-002操作再读CORE-060—062；维护旧3D表现才读CORE-063。新2D仍待PRE2D-Q01，不能自行套用或废除3D宿主限制。实现证据统一见[开发入口](../../../development/README.md)，本页不重复登记各轮运行状态。

## TL-31 战前配置与可表达性

用真实库存装配核心／可选辅槽，设战前法器序、基础路由、已有用途和本场投入；未投入材料留背包，本战不可取用。

至少一台完整合法铭刻法器才能开始；缺核心、不兼容、重复占用或悬空引用先修复。空辅槽、暂缺料、条件暂不成立或无直接伤害不单独禁止开始；基础加工不能代替铭刻门槛。

初态须凭真实库存和公开供给支持至少一条可执行路线，零材料可无启动料；不赠虚构实体、不靠彩蛋、不每战补满。主动断粮承担后果。跨战可保留配置偏好，但重新核对实体、资源和目标，不把失效实例改绑同名对象。

## TL-17 暂停与信息

全局暂停冻结双方倒计时、加工、队列及资源寿命。观察窗口沿[TL-11](../../systems/action-card-system/rules.md#tl-11-共同拍序与效果边界)：边界处理和揭示后受理，合法提交影响未来批次／本拍末；结算中输入待下一窗口。暂停落在完整事件后，不拆支付与结果；继续先完成原拍余步，新操作不能插入。无需逐拍确认。

| 对象 | 必须可查 |
| --- | --- |
| 敌牌 | 公开阶段允许的信息；揭示后效果、锁定／无对象、T、取消条件 |
| 法器 | 合法性／缺口、辅槽挂接、当前承诺与未来用途、完整配方／D／行动、进度、完工拍和预留 |
| 队列 | 真牌序、来源、入行拍、最早资格与预计生效；实牌／预留／待复用分开 |
| 资源／标记 | 来源、实有与可消费、托管／冻结／锁定／待用及可用拍、维护；基础／有效供料序 |
| 打断 | 锁定法器、R、危险开工带[T−D,T−1]；有耗材停供方案结束拍须≥T |
| 费用与结果 | 已定义能力的额度、已付／待付和拒绝原因；区分伤害、打断、落空、退料、空放、等位、延误和终局 |

### 玩家消费锁定与预警（CORE-055）

观察窗口可锁／解锁自有未承诺的指定量，所有自动消费者（含维护）排除锁定量，直到主动解锁或该量失效。不锁敌方或未来新增量，不撤销托管／预留／冻结，不阻止伤害、自然失效或合法非消费读取。

开工预告显示预计消耗、可用／锁定及等待或维护不足风险，标出未兑现依赖；随已知状态更新，但不占用、不逐批确认。实际开工仍联合检查，必需不足等待，明示可选才回退。

## TL-18 独立干涉系统接口

每战固定费用、暂不成长；提速方向使用玩家费用，可保留净增产，不要求补休。具体能力／额度／价格／时长／回充／共享仍在[TL-Q09](../../../governance/questions.md)，当前无操作入口。

免费未来路由／用途／阶级与付费干涉分开；取消敌牌仍经队列。暂停不授予单器停机、当前改速、战中重铭或打造。

## TL-19 中断与恢复

退出或异常后恢复最近结清事件及已提交操作，进入暂停。所有已用机制保持以下状态；未使用机制无需生成空账目。

| 保存对象 | 保持什么 |
| --- | --- |
| 拍序与行动 | 当前拍／阶段／组／观察位置，已结清与剩余步骤；选定队首、行动机会、绑定名单、队序、入行资格及承诺效果 |
| 敌情 | 原程序／循环、公开表、揭示、锁定（含无对象）和倒计时 |
| 批次与材料 | 用途、实际选料／阶级、D、进度、有效预留；托管、消费／退料、待复用量及拍号 |
| 宿主与余额 | 生命／护甲；资源和标记的可用、锁定、冻结、失效承诺、待释放及归属／数量／可用拍 |
| 设置与输入 | 基础供料、战前序、唯一临时方案及结束拍、未来用途／阶级、已提交待受理输入 |
| 结算与局内提交 | 已提交支付、本场余费、胜负、奖励、背包投入与选留提交 |
| 使用定时／维护时追加 | 登记身份／来源／宿主／基础量／下次拍／周期／结束／余次／稳定序；活动或休眠、增幅、下次维护及本拍已检查名单 |

恢复不重付、重兑、重选、重做完工／维护／退料／领取，不提前释放待用量，不复活旧临时方案。事件内部不是重新选择点，终局不补步骤或收益。战中恢复不触发战后重置；真正战终才按[经济合同](../run-economy/rules.md)清理选留。

## TL-36 决策保存与信息可达性

保留一份进行中本局存档，设置独立。节点选择、交易、休整及抽取／放弃、确认配置、开战、战果、奖励／携带提交都保存；恢复不重抽、不退款。保存失败保留同一结果重试，并停止后续不可逆提交；读档失败不覆盖或新开局。新局替换／主动放弃须说明后果并确认，普通可撤编辑不逐步确认。

设置／说明打开暂停、关闭仍停至明确继续。必要操作／详情均可点击和键盘完成，不只靠拖拽、悬停、颜色或声音；关闭弹层焦点回来源，字号和滚动不挡操作。静音、灰度、减动效仍可读，动画不决定规则时间，预测与结果分开。

敌我类别均用▲攻击、■防御、⊘打断、✱其他配文字；地域只改花色、材质、配色与装饰，保留通用符号轮廓／位置／含义。其他副记号随内容声明。

## 资源用途、背包与预告（CORE-058／059）

未来用途／指定阶级的行为唯一见[TL-06](../../systems/artifact-system/rules.md#tl-06-路由与临时设置)，材料信息见[TL-43](../../systems/resource-system/rules.md#tl-43-材料类别绑定制造内容)。界面分清当前承诺、未来设置和未到账产物；背包显示未投入／本场投入、种类、容量和选留。保存沿TL-19；铭刻预设空缺可编辑，材料与目标说明为只读规则信息。发现合同缺口见INS-Q07。

## 首场战斗操作合同（CORE-060）

限EX-002，battle-demo.1；[采纳依据](../../../sources/draft-changes/D-2026-10-11-development-design-round-01.md)。不改EX-001固定输入。下表只补通用TL未给出的首场操作值。

### 播放、停点与受理

| 情况 | 首场行为 |
| --- | --- |
| 新战 | 短说明后停在0拍观察：r0已揭示、尚未开工；明确继续自动推进，也可单步 |
| 速度 | 默认1×每拍2秒；0.5×／1×／2×为4／2／1秒。前半观察、后半推进反馈；暂停不耗预算，换速下个观察窗生效 |
| 提交 | 窗口关闭前合法输入用于本拍末，关闭后待下窗。按实际逻辑阶段唯一归属，显示受理拍；待受理意图下窗复查，失效／超量全拒绝，不暗改数量 |
| 手动暂停／继续 | 观察即停预算；结算按TL-17完整事件停，继续先结原拍余步 |
| 单步 | 仅暂停可用，从当前位置完成到下一拍观察并做完边界／揭示；中段恢复先结原拍，不多跨一窗，途中终局停结果 |
| 超时 | 顺延现实时间并记录偏差，不跳拍追赶、不因换速重做、不补离线时间 |

默认开“打断揭示暂停”（EX-002 r8、r24……），无锁定也停；默认关“攻击揭示暂停”。触发在揭示／锁定后的观察起点，同拍合并一次并显示条目。继续／恢复不重复触发，触发状态与位置保存；开关独立保存，只影响之后揭示。自动停不改变回看位置，给公开通知与归位入口。没有每拍、完工、普通伤害、疲劳或未用类别的空开关；终局直接结果。

### 窗口、详情与信息

1080p为7列，768p为5列，等宽每列一拍、当前居中，开场左端0；历史按实际拍，实牌按队序显示预计拍，未来空格不保证无事件。预留／待复用另列摘要；历史不占Q，列数不是容量。

左右回看每次1拍，先按合法边界暂停，保留浏览位置并标真实战斗拍。Home／归位只恢复居中跟随；回看时明确继续仍保位并提示真实拍。浏览不推进。

详情打开请求暂停，可先显示最近结清状态及相位；关闭仍停、焦点回来源，自动暂停不关闭详情。用途／数量草稿须明确提交，关闭舍弃未提交部分；成功保存并显示受理拍，拒绝原因可查。已提交操作不因关页撤销。

| 对象 | 首场限定 |
| --- | --- |
| 法器／布景 | 蓝晶杖＝施法、环杖＝守护；书／晶球无命中、焦点、编号或未解锁提示，不增加库存 |
| 读数 | 生命／护甲贴宿主；施法次数常驻实有／可用／锁定精确数，筹码辅助。1080p主要值20px、768p18px，详情正文≥16px |
| 卡效与资源 | 三行动沿■／▲／▲，步骤及依赖可查；资源为空，不以抽屉格数推容量；无冻结／待释放时可合并空分项 |
| 数量锁定 | 新增／解除分别输入非负整数、步长1、可键入；0禁提交。只锁自有未承诺量，解锁≤锁定量，超量全拒绝：可用4时锁5不改成4 |

暗牌所有详情、历史预览、警报和摆位均沿TL-09公开权限；揭示后按T显示锁定、取消条件和危险带。主桌操作宿主另沿CORE-063，功能描述不授予独立二维操作条。实际显示读真实状态，不写死[指定输入的十种状态](../../../sources/inbox/2026-10-11-development-design-round-01.md#15-至少6种状态与可核对预期)。

最上弹层、正在编辑的字段优先，不穿透到底层播放／回看。

| 键位／等价点击 | 行为 |

## 首场表现与声音合同（CORE-061）

限EX-002，battle-presentation.1；[采纳](../../../sources/draft-changes/D-2026-10-12-development-design-round-03.md)及[第04轮限定解释](../../../sources/inbox/2026-10-12-development-design-round-04.md)。所有暂停入口共用本表，CORE-062／063不再复述。

### 暂停归位与真实状态

| 时点 | 画面与声音 |
| --- | --- |
| 自动播放 | 按已提交事件顺序呈现；数字／操作对象始终对应最近结清状态，滞后标“已发生”，动画不推进结算 |
| 合法暂停停点 | 取消未完轨迹／翻牌／受击及装饰运动，静态显示真实末态；截停战斗单次声、暂停环境循环 |
| 新观察窗口 | 清上一拍滞后表现；仍自动播放时，只允许本次新公开事实的一次非阻塞提示／揭示声，不遮信息或延迟受理 |
| 自动停、单步停、新终局 | 立即静态归位，不启动新战斗运动／声音；终局以结果／原因／记录反馈，胜败声不能改名UI声绕过 |
| 明确继续 | 恢复环境循环；不补播／续播已取消旧动作或音效 |
| 场景切换／重试／返回／退出 | 清旧场全部瞬态和声音，新场只反馈新事件 |

归位只清表现，不取消批次、队列或结果，不退款；加工进度、等待、护甲、已公开敌情保持。暂停中新UI点击／确认／开合声允许，受主／效果音量控制，静音不漏声。

### 单步摘要与减动效

单步立即到下一观察或中途终局，不播过渡；按真实日志顺序显示带原拍号、编号及“已发生”的静态摘要，不预演、不新增输入点／逐事件单步。摘要到下次推进，旧记录可回看；连按替换摘要，不积压瞬态或声音。

减动效取消轨迹、震屏和大幅位移，改用文字／形状／序号。静音与减动效仍可查目标、数量、支付回退、失败、胜败和同拍次序；共同疲劳两方一起显示。

### 载入、声音与退出

载入静态重建并暂停，旧声音／动作不重播、不补离线队列；最后记录可查并提示恢复，终局保持同一结果。环境静默至明确继续，不要求保存采样相位。插值、时长、声音并发与混音归制作参数，不改上述行为。

## 首场主窗口失焦与返回合同（CORE-062）

限EX-002，battle-focus.1；[采纳依据](../../../sources/draft-changes/D-2026-10-12-development-design-round-05.md)。

Alt-Tab、点击其他应用或最小化导致OS失焦时请求TL-17合法暂停；短暂切回不撤销停点，游戏内Tab不算失焦。观察立即停剩余预算，结算只结当前完整事件，不提前完成余步。

返回／还原仍停，只有合法入口明确继续；激活窗口不算播放，不解除故障／弹层或恢复终局。保留原暂停原因约束、已耗观察预算、批次、队列、已提交输入、回看和选择，不补后台时间、不自动归位。

失焦不关闭弹层，也不提交／丢弃同进程草稿；有效控件可继续编辑，失效者按回焦点规则处理。真正关闭才丢未提交草稿，退出／载入只恢复已提交状态。音画共用CORE-061；失焦／返回通知本身不冒充新UI点击声。


失焦事件本身形成终局时结清同一结果后静态停住；开始／结果页不因返回开启战斗。显示设置试用不因失焦确认，原超时恢复独立于战斗预算，不随战斗暂停冻结或延长。

## 首场桌面3D主交互合同（CORE-063）

**仅旧EX-002三维表现。** physical-table.2，Accepted；[原采纳](../../../sources/draft-changes/D-2026-10-12-development-design-round-07.md)与[2026-10-14修订](../../../sources/draft-changes/D-2026-10-14-demoncards-presentation.md)。新2D适用关系待PRE2D-Q01；以下不增加战斗能力。

### 操作入口与图形页面

主桌所有可操作入口由真实3D物件承担，含法器、卡片、标记、抽屉、播放／单步／速度／回看／归位／系统；点击和键盘激活同一对象。独立桌沿物件不增加库存，布景沿CORE-060。

不设独立二维操作条、大日志／纯文字摘要或分离透明操作层。精确名称／读数／状态可用绑定物件的只读文本；悬停／焦点可给静态轮廓和公开短提示，离开关闭，不暂停、不提交、不揭密。

近观与系统页可独立，但须用对象／状态图形及反馈表达内容，不能只给文本框加边框。开始、设置、错误、确认、结果均可用图形页，主桌入口仍为3D物件。点击／Enter近观沿合法边界暂停，静态进入／返回、关闭仍停；查看不出牌、推进、付款或改队序。数量编辑沿CORE-060，直接切未来用途由法器实体控制。

### 真实卡片与已提交事实

实牌有空间位置、厚度、正背和空间拾取，屏幕卡图／按钮不能替代。完工后按真实队序与公开预计拍显牌；预留／待复用／历史用可辨静态图形，不伪装成实牌。Q和显示列数沿核心／CORE-060。

己方已知牌保持公开正面；敌牌r前仅位置、r和类别可见，r揭示后正面并按T显示，T使用不二次揭密。位置、纹饰、近观或指线不得泄露暗牌内容。

按physical-table.2：完工先来源局部亮、实牌在目标刻位原位显现；使用为原位卡亮与真实目标效果同起，不飞向目标。仅仍自动播放的新公开牌可作r→T短转位；真实预计拍变化可作同身份公开重排。视觉不改队序、位置事实、目标、余额，不再支付／扣血／释放容量，复合牌不重复出牌。具体形制、尺寸、镜头、材质和时长留制作包。

### 停点、历史与可达性

暂停、单步、回看、载入、失焦、新观察、终局统一沿CORE-060—062，不等动画完成、不新增胜败音画例外。保持自动推进，无需逐张点击。

历史／单步图形记录保留原因、真实拍和顺序，从刻位或记录物件近观；不恢复主桌大日志，历史不成为队列牌。抽屉按合法停点静态开合，空材料不造库存，三格不是容量3。字段、字号、输入优先级与保存错误处理均沿通用TL和CORE-060。
