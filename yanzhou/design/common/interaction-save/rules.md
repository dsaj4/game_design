## TL-31 战前配置与可表达性

按[TL-46](../../systems/backpack-system/rules.md)先核对所有真实携带物同包装载，再选择本场投入卡入手；在同一背包中装配核心，摆放炉心、配置占格法器与组合、部署带覆盖圈的辅助，设合法用途和本场投入，装载确认时一次求值每台法器的圈下限，没有法器序与自动补料开关；未投入卡牌留背包，本战不可取用。至少一枚炉心与一台完整合法铭刻法器才能开始，缺炉心、缺核心、不兼容、重复占用或悬空引用先修复；无辅助或辅助覆盖不到任何法器、暂缺料或无直接伤害不单独禁止开战，基础加工不能代替铭刻门槛。

法器、炉心、辅助、材料及其他实体不能越界或重叠。具体格数、法器形状、入料口尺寸P及组合表须内容声明。生产布局与跨战携带共用同一实际网格，装载确认时一次求值圈下限；未投入卡和备用配置仍在包内，战中不可取用或顶替设备。本场手牌不保留虚拟占格。运输按真实实体计空间；其他备用配置与取得仍按内容声明。炉心位置、核心装配、辅助位置与覆盖圈、法器位置、组合关系及用途在战前提交后本战固定；未来工序草稿在生产拍之间与最终布置调整。核心可在战前可逆拆装，散装每枚1格、兼容嵌入额外0格；拆回无合法落点则保持原装配，不产生临时包外仓。换核心须预告并确认撤回已排工序行材料、复核配方与辅助。非法装配整项拒绝不吞实体；详见[TL-26](../../systems/inscription-system/rules.md#tl-26-实体铭文与词义)。辅助本体合法但覆盖不到法器／不兼容只显示无效，不阻止合法核心生产。

初态须凭真实库存和公开供给支持可执行路线，零材料可无启动料；不赠虚构实体、不靠彩蛋、不每战补满。跨战保留配置偏好仍须重核实体、资源和目标，不自动改绑同名实例。当前完整首战套组、敌表与初态见[CORE-073／074规格](../../../content-library/first-battle.md)，卡组解封事实须保存且不因恢复重发，独立案例的固定配发不成为整局每战免费补齐规则。

## TL-17 暂停与信息

生产拍之间和最终布置是编辑窗口：可免费调整五个战斗位及未来工序、锁解自有未承诺标记。事件处理中不插入玩法输入；手势／详情暂缓下一拍，已进入单位按下表收尾。用途、核心、炉心、设备位置、组合与辅助本战固定，已开工批次不可撤。

每生产拍开始先联合检查本拍全部工序及合计费用；任一非法整拍拒绝暂停，所有原排布、余额、归属及进度不变，不揭敌牌、不部分开工。提示补齐、撤回或改排，不自动顺延。未来草稿不阻挡当前拍，也不阻挡最终战斗确认。

最终布置无时限，不推进D、不追加本轮生产。确认本轮五列共同核对整行身份、归属和战斗权限，成功原子锁行；失败保持原布局可编辑且不揭牌。卡效目标、费用、条件到实际步骤再检查。确认不是承诺每张一定成功。双击或恢复不重复提交。

### 拍末暂停（保留CORE-064锚点）

<a id="拍末暂停core-064"></a>

| 状态 | 暂停／详情／设置／失焦／正常退出 | 单步／继续 |
| --- | --- | --- |
| 未进入下一生产拍 | 停住，已提交草稿保持 | 合法才走一拍，含开工、加工、到货与补给，再停 |
| 生产拍处理中 | 收尾当前拍与动画，不开始下一拍 | 异常恢复后只完成当前拍余下事件，不重新开工 |
| 最终布置 | 无时限停住、仍可编辑 | 只有明确确认才锁行；单步不能隐式确认 |
| 战斗列处理中 | 收尾当前列与动画后停，整行仍锁 | 继续自动执行剩余列；单步只完成当前／下一列，不开编辑窗口 |
| 第5列已完成、轮尾未处理 | 停住，不抢跑疲劳 | 单步仅轮尾、换轮准备，停在新轮生产前 |
| 轮尾处理中 | 收尾当前事件与必要准备后停，不启动下一轮生产 | 不重复疲劳、清行或布敌牌 |

任何完整事件终局立即截断余步，不为收尾补收益。重复暂停／单步不累积额外推进。首次生产由玩家启动，后续可自动开始；下轮暂停请求、详情或失焦跨轮均阻止自动开始，返回不自动取消暂停。动画不改变逻辑拍、D或胜负。

显示生产累计p／本轮进度和战斗r／j两个读数，冻结批次D与到货拍、未来草稿及缺口、圈下限与拖慢格、P、补给组清单／解封拍／已发事实、真实手牌数量权限、原生合法牌背与公开后续。结果投影只读。详情不能揭露未公开原生牌；C1—C3、点击和键盘路径、静音／灰度／减动效可读性继续有效。

### 玩家消费锁定与预警（CORE-055）

只保留标记锁定，不恢复材料锁定。编辑窗口可锁解自有未承诺量；冻结量不可再消费，战斗锁行后不能改锁定。锁定不禁止非消费读取或合法失效，不提前花未来层。真实卡效逐步支付沿TL-30。首战不启用未迁移的释放／维护／期限扩展。

## TL-18 手动上行、撤回与整理

生产拍之间及最终布置，可把真实合格战斗手牌放入任意空位，撤回、交换两行牌或明确桌手互换均免费。单次操作原子完成移出与进入，一实例一位置；普通上牌不能覆盖已有牌。桌手互换保留手牌位置，单独撤回按实际返回序入对应组。同名不同实例独立。

不可战斗卡、在制输入、敌牌与锁行不能参与；工序材料先合法撤回手牌才可上战斗行。不合格操作整项拒绝，不吞牌、不触发卡效。确认后所有列（含尚未执行列）均不可编辑，暂停和异常恢复不解锁，被拒输入不暗存到下轮。点击查看或切组不移动库存。

未来工序可排真实匹配材料或明示零材料指令，后者只使用战前固定用途。开工前可改，开工后冻结。晚到货可以排本轮早列；本拍产物最早下一生产拍供新工序。无自动补料、单器启停或战中重铭。拖动取消／失焦丢弃未提交预览，已提交归属保持；点击及键盘可完成同等必要动作。

## TL-19 中断与恢复

正常退出沿TL-17收尾已进入单位，不开始下一单位；异常恢复最近完整事件及已提交操作，静态暂停，继续才执行未结清部分，不补离线时间，不重播音画、不产生新编辑窗口。

| 保存对象 | 保持的事实 |
| --- | --- |
| 时序 | 规则版本、回合、累计生产拍／拍内事件、战斗列／组／步骤、阶段、整行确认锁定、轮尾／疲劳／准备已做事实 |
| 卡与排程 | 每卡唯一身份、两组顺序、战斗位、未来草稿／在制／留包归属、锁定布局、使用步骤与本轮已使用记录、回收或消费事实；历史结果不另计实例 |
| 批次与供给 | 固定用途、冻结投入／D／贡献／费用、进度、开工拍、战前实例登记序、批内序、到货和补给已交付事实；拒绝草稿不是已开工 |
| 配置与背包 | 装载／投入／重装阶段、真实格子朝向、炉心、核心副本、设备组合、辅助覆盖／贡献、部署与留包 |
| 战斗 | 生命护甲、标记真实／锁定／冻结、逐步支付、敌基础表和后续覆盖、公开范围、后续生成序及锁定目标 |
| 请求与终局 | 暂停／下轮暂停、合法已提交操作、终局与一次性归属清理、收益和选留提交；拒绝操作不延后执行 |

开拍共同冻结是一次提交，恢复不会出现只冻结部分器；后续每批完成及每组补给保存已提交位置，恢复不重消费／产出／发放。整行确认同样一次提交；已锁行恢复不可改。战斗每完整事件恢复不重付、伤害、回收或疲劳。异常事件位置只供继续，单步不把它变成布置窗口。

终局不补未来事件，未完成的确定性清理继续一次；按TL-25归属，不重复退料或把只读结果变实牌。旧档没有明确迁移时保留原档并提示不兼容，不静默用新双时钟解释CORE-076单轴档或CORE-067档。

## TL-36 决策保存与信息可达性

保留一份进行中本局存档，设置独立。已提交开战、排牌、开工、整轮确认、卡效、补给与战果不重抽／退款。保存失败保留当前结果并阻断后续不可逆提交，重试只保存不重演；读档失败不覆盖或暗开新局。主动放弃／新局替换另确认，普通草稿不逐项审批。

只读详情／历史先按TL-17停点打开，关闭仍停、焦点回来源；失焦保留同进程有效草稿，返回不自动跑。完整五位始终可见，真实卡与只读结果明确区分，手牌两组计数准确。颜色／声音不能成为唯一信息渠道；原生暗牌不能通过详情、历史或预测泄密。

采纳依据：[本轮D](../../../sources/draft-changes/D-2026-11-05-round-plan-alignment.md)。
