## TL-31 战前配置与可表达性

按[TL-46](../../systems/backpack-system/rules.md)先核对所有真实携带物同包装载，再选择本场投入卡入手；在同一背包中装配核心，摆放炉心、配置占格法器与组合、部署带覆盖圈的辅助，设合法用途和本场投入，装载确认时一次求值每台法器的圈下限，没有法器序与自动补料开关；未投入卡牌留背包，本战不可取用。至少一枚炉心与一台完整合法铭刻法器才能开始，缺炉心、缺核心、不兼容、重复占用或悬空引用先修复；无辅助或辅助覆盖不到任何法器、暂缺料或无直接伤害不单独禁止开战，基础加工不能代替铭刻门槛。

法器、炉心、辅助、材料及其他实体不能越界或重叠。具体格数、法器形状、入料口尺寸P及组合表须内容声明。生产布局与跨战携带共用同一实际网格，装载确认时一次求值圈下限；未投入卡和备用配置仍在包内，战中不可取用或顶替设备。本场手牌不保留虚拟占格。运输按真实实体计空间；其他备用配置与取得仍按内容声明。炉心位置、核心装配、辅助位置与覆盖圈、法器位置、组合关系及用途在战前提交后本战固定；工序行排牌在布置窗口光标右侧调整。核心可在战前可逆拆装，散装每枚1格、兼容嵌入额外0格；拆回无合法落点则保持原装配，不产生临时包外仓。换核心须预告并确认撤回已排工序行材料、复核配方与辅助。非法装配整项拒绝不吞实体；详见[TL-26](../../systems/inscription-system/rules.md#tl-26-实体铭文与词义)。辅助本体合法但覆盖不到法器／不兼容只显示无效，不阻止合法核心生产。

初态须凭真实库存和公开供给支持可执行路线，零材料可无启动料；不赠虚构实体、不靠彩蛋、不每战补满。跨战保留配置偏好仍须重核实体、资源和目标，不自动改绑同名实例。当前完整首战套组、敌表与初态见[CORE-073／074规格](../../../content-library/first-battle.md)，卡组解封事实须保存且不因恢复重发，独立案例的固定配发不成为整局每战免费补齐规则。

## TL-17 暂停与信息

CORE-075点击法器显示所在圈、拖慢格、到货线与已排材料；排牌预览沿布置窗口。拖动取消、失焦或退出放弃未提交预览，实际归属保持；已提交的排牌、光标位置与开工事实必须恢复。资源区显示各组清单、解封列序号和已解封状态；查看不触发领取，不因保存／恢复重发。旧版存档未提供迁移时保留原档并提示版本不兼容，不猜新排布。

CORE-075：布置窗口是唯一的编辑点，出现在每回合准备完成后和每列结清后；光标右侧的战斗行与工序行可免费排牌、撤回、替换、调序及标记锁解，光标左侧冻结只读，已开工批次不可撤，不能战中改用途、炉心、组合或设备结构。提交先后复查真实归属，失格整项拒绝，不偷改数量，不重复占用；动画或列处理过程中不插入玩法输入。

布置窗口无时限，确认后光标越过下一列。运行中请求编辑须先收尾暂停至下一布置窗口；列内与列处理过程的请求拒绝并说明下一布置窗口才可提交，不暗存变成下轮操作。回合准备自身不推进加工。「复制上一回合布局」是纯界面捷径，只填仍有合格牌的格子。

布牌窗口即布置窗口：回合准备完成后与每列结清后；标记锁解在布置窗口受理。排料操作只确定所排列的开工，不当场开工，不自动补齐。

结算列内关闭玩法编辑；列间只允许手牌与尚未开始己方列的上牌、撤回、换牌和调序，确认后才揭下一敌列。用途、炉心与组合、光标左侧排牌等在列处理中保持关闭；点击法器只读显示圈与到货线不受此限制，不暗存为下轮操作。设置及只读详情可用。完整操作见TL-18。

### 拍末暂停（CORE-064）

CORE-067沿用“收尾已经进入的单位及动画再停”，区分如下：

| 当前状态 | 请求暂停／详情／设置／失焦／正常退出 | 单步 |
| --- | --- | --- |
| 序幕／回合准备完成 | 已停于布置窗口，不自行开工 | 确认后完成下一列（含到货、开工）及动画后停 |
| 列处理中 | 收尾本列的结算、到货、开工及音画后停，下一列不开始 | 完成下一列后停于布置窗口 |
| 布置窗口 | 无时限，保持停住，可排牌及标记锁解 | 须明确确认；单步只完成下一列再停 |
| 结算列推进／列间窗口 | 完成当前列及动画后停；非末列进入布牌窗口，下一敌列尚未公开 | 确认后完成下一列再停；列间仅布牌，不加工、不锁解或改用途 |
| 第X列已完成、回合末待处理 | 保持停住，尚未处理的疲劳不能抢跑 | 仅处理回合末疲劳（若到期）、结束及下一轮准备后停，不走下一列 |
| 回合末事件处理中 | 完成该事件和必要清理后停，不开始下一回合的列 | 完成尚未结清的回合末阶段后停 |

每列停点在回合末疲劳之前；疲劳不是第X列的卡效。第1—4列结清必须经列间确认，不自动越过布牌窗口；第X列后继续可接回合末阶段，未终局才清旧行、布下轮敌牌各一次，无点数重置，再进入下一回合的布置窗口；若有暂停／单步则停在对应边界。布置窗口每回合仍须明确确认，不以“继续播放”越过尚未确认的新布置窗口。

任何终局立即停余步骤，仅播放已发生结果，不为凑拍／列／回合补收益。重复暂停或单步不积累额外推进。收尾动画只延长现实等待，不增加逻辑时间；环境／加工循环在停点冻结，静音与减动效仍生效。异常恢复不是正常暂停点，见TL-19。

### 玩家消费锁定与预警（CORE-055）

CORE-075取消材料锁定与自动补料，仅保留标记锁定：玩家自行排料，手牌里未排入的卡就是保留。工序行未开工材料可在光标右侧撤回、替换、调序；已开工不能撤批。

标记可在布置窗口锁住自有未承诺量，解锁恢复后续消费资格；不提前执行效果或补做失败。锁定不阻止非消费读取、伤害或合法失效，不作用敌方及未来新增量；冻结量不可供其他批次、条件或卡效使用。列处理中不锁解，不撤回既有在制／冻结。

预告区分手牌保留、已排入工序行与在制；显示候选消耗、缺件原因及到货列。未兑现依赖不是已到账资源；未迁移维护不借此启用。

## TL-18 手动上行、撤回与整理

玩家从已到战斗可用时点的可战斗手牌选择一张，放到己方任意尚未开始的空列；也可撤回尚未开始列中的己方实牌、交换两张这样的行牌，或将其中一张与合格可战斗手牌互换。一次操作同时完成原位置移出和新位置进入，同一实例不能同时占两列或手牌与行位。桌手互换保留原手牌位置；单独撤回按实际返回顺序加入对应组，同组其他卡的相对顺序不变。

上牌、撤回、换牌和调序免费，取消整理行动点及其发放、扣费、重置；卡效费用与制造费用继续按原合同独立支付。普通上牌要求目的列为空，不能直接覆盖已有牌；明确提交的桌手互换或两张行牌互换允许两端已有实牌，但双方都须符合上句资格。不可战斗牌、已排入工序行或已在制的牌、敌牌、当前列或已处理列不能参与，失格则整项拒绝，不吞牌、不产生卡效。点击查看、切换手牌组不构成出牌；保留点击选择／确认及键盘路径，不强制拖拽。

须在布置窗口光标右侧编辑；运行中先收尾暂停。确认后进入下一列；每列及动画结清、且未终局时，自动停在布置窗口。该窗口开放手牌、战斗行与工序行尚未开始列的布置及标记锁解，不开放用途、炉心、组合或战中重铭。确认后才公开下一列敌牌并开始该列，当前列处理中及已处理列不可编辑。空列也按列序通过，不能回头填已跳过位置。

已排入工序行的牌须先在光标右侧撤回手牌才可上战斗行；新产卡下一列起可上牌或排料。战斗与排料资格按[TL-15](../../systems/resource-system/rules.md#卡牌的战斗与排料可用时点)判断。

生产完成和回收原卡按[TL-05](../../systems/artifact-system/rules.md#tl-05-开工与成品去向)及[使用生命周期](../../systems/action-card-system/rules.md#卡牌使用与回收core-067)处理。没有单器启停、战中重铭或重排辅助权限；辅槽打造已淘汰。

## TL-19 中断与恢复

正常退出先完成当前已进入的结算列／回合末事件及表现，已有停点直接保存退出；不主动确认布置窗口或进入下一单位。异常中断只保留最近结清事件和已提交操作，静态载入且暂停；明确继续才完成余步，不自动补跑到停点、不重播旧音画。

| 保存对象 | 必须保持 |
| --- | --- |
| 背包阶段与装载 | 当前阶段、同一网格的真实物件／格子／朝向、部署或备用、核心装配与卡的投入事实，装载／收益／选留的独立提交；未给出售合同前不生成交易事实 |
| 时间与阶段 | 规则版本、回合、列序号、光标位置、布置窗口是否确认、下一敌列未公开事实、列／组／步骤、疲劳与换轮准备是否已做 |
| 卡与牌位 | 每卡唯一身份、权限、留包位置或手牌组／顺序及跨组统一手牌序、战斗行位、工序行列位或在制归属、战斗可用时点与排料可用时点；本次使用步骤及已回收／消费事实，只读结果不重复计库存。敌后续、来源、名单、生成序与资格回合保留 |
| 核心与辅助 | 铭文唯一身份及装配归属；辅助唯一身份、占形、位置、朝向、受益法器及贡献来源；批次和成品牌已记录的合计贡献，不恢复已取消的辅槽／择一状态 |
| 费用与余额 | 无整理点；保存制造在制／消费、每次卡效支付、标记真实／锁定／冻结／待用、生命护甲及疲劳次数 |
| 批次与设置 | 炉心与法器位置／占形、组合关系、圈下限求值结果、辅助覆盖圈、固定用途、工序行已排牌、当前D／进度与在制；无旧临时方案／结束拍、待料或成品预留 |
| 敌表与公开 | 本轮基础表位置、被跳过项、后续覆盖、原生揭示范围、锁定法器／无对象；不读档重抽、补发或重锁 |
| 输入与结果 | 合法已提交但待受理的免费输入，已完成布牌事实，暂停请求、终局与奖励／选留提交；结算时被拒操作不能在下轮自动执行 |

恢复不重复施加辅助贡献、不重回收或复制卡、不重复制造／伤害／释放／支付／疲劳、不重新布敌牌，不提前让待用量可用。单步恢复只完成所在单位余下合法步骤；异常事件内部不是新的列间选择点；同一实例不能在留包、手、战斗行、工序行或在制中重复存在。旧分账背包存档没有明确迁移规则时保留原档、提示不兼容，不静默猜网格；阶段编辑不成为额外仓库，不读档重领或重卖。终局恢复保持同一清理完成的结果，未完成的确定性清理不形成新选择窗口。

旧连续拍、CORE-065手牌／点数、CORE-067无供料格、CORE-068旧辅槽及CORE-069分账背包存档与当前CORE-070不是同一种进度，不默默换算旧Q、倒计时、牌序或背包续打；版本不匹配必须保留原存档并说明，迁移方案未定不冒充可恢复。真正战终才沿[经济](../run-economy/rules.md)清理／选留，不因暂停触发战后重置。

## TL-36 决策保存与信息可达性

保留一份进行中本局存档，设置独立；节点选择、交易、休整、开战、布牌、最终及列间确认及战果等已提交事实保持，不重抽退款。保存失败保留同一结果重试并停止后续不可逆提交；读档失败不覆盖或新开局。新局替换／主动放弃说明后果并确认，普通草稿不逐步审批。

详情／设置／历史运行中先请求本页停点，关闭仍停、焦点回来源；失焦收尾后返回不自动继续，同进程草稿保留，关闭才丢未提交草稿。点击和键盘可完成必要操作，不只靠拖拽、悬停、颜色或声音；静音／灰度／减动效仍能判断费用、威胁与结果。动画不决定规则时间和胜负。

桌面固定显示完整X位，不随中心线滚动。结算或取消后保留原位只读结果，下一回合清行；实际回手卡已离开行位，历史结果不能算第二份库存。手牌为可战斗／不可战斗两组持牌，无默认收拢卡堆；切组不动库存或时间，显示各组准确数量。暗牌详情、历史与预测不得泄密；已公开后续牌不能再隐藏。类别仍为▲攻击、■防御、⊘打断、✱其他并配文字，时间行为标识另列。

## 首场主窗口失焦与返回合同（CORE-062）

沿用失焦请求收尾、返回不撤销暂停、保留同进程有效草稿与选择、不补离线时间；当前收尾单位见TL-17。显示设置超时独立于游戏逻辑暂停，不因失焦自动确认。旧EX证据不证明新列／回合停点已实现。

## 首场桌面3D主交互合同（CORE-063）

physical-table.2仍只约束旧EX-002三维表现，全部原件及约束见[固定旧版](https://github.com/dsaj4/game_design/blob/084e529e2c852d2e1a508f74a8766e55763f9933/yanzhou/design/common/interaction-save/rules.md#首场桌面3d主交互合同core-063)。CORE-065明确新机制固定整行和手牌关系，不替用户选新2D操作宿主、页面、引擎或资产。旧预留图形、r→T投影和移动时间轴不能作为新机制默认表现，其他旧三维约束不因本次规则变更自动成为新2D合同。
