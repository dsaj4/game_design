## TL-31 战前配置与可表达性

用实际持有法器和铭文补齐核心、检查语义／兼容，可选辅槽；设置战前法器序、基础路由、已有用途，选择本场投入材料。投入者开战进资源区；未投入者留背包且本战不可取用。

至少1台完整合法铭刻法器才可开始。缺核心、不兼容、重复占用和悬空实例引用须修复；空辅槽、暂时缺料、条件不成立或无直接伤害不单独禁止开始。仅有基础加工不能替代合法铭刻门槛。

默认配置不赠实体或材料。内容初态须用真实库存及公开供给支持至少一条可执行路线；零材料路线的启动料可为0。基础启动不依赖隐藏彩蛋，不每战补满，玩家主动断粮承担后果。跨战保留配置偏好，但按新场实体、资源、目标重新检查，失效实例不自动改绑同名对象。

## TL-17 暂停与信息

全局暂停冻结敌我倒计时、加工、队列推进及资源寿命。每拍按TL-11完成边界失效／释放和到期方案恢复，再揭示敌牌，提供观察／提交窗口；不强制逐拍确认。

窗口内合法提交用于未来批次和本拍末检查；结算中输入留下一窗口，不改本拍已结清结果。暂停落在完整事件后，不能拆开支付与结果，也不能让下一窗口操作插入当前拍余下步骤。首场自动暂停和播放参数见本页[CORE-060合同](#首场战斗操作合同core-060)，其他内容扩展沿TL-Q08。

| 区域 | 必须能查到 |
| --- | --- |
| 敌方行 | 程序位置、翻开拍、种类；揭示后完整效果、锁定／无锁定、T、可取消条件 |
| 资源 | 可用、托管、锁定、待下拍可用及其拍号、来源、维护、基础／有效供料序 |
| 玩家队列 | 实际牌序、来源、入行拍、最早资格及预计生效；实牌／预留／待复用分别显示 |
| 法器 | 合法性与原因、辅槽挂接、当前承诺和未来用途、完整配方／D／行动、进度、预留、缺料／缺位 |
| 打断威胁 | 锁定法器、剩余R、危险开工带[T−D,T−1]；适用的停供方案结束拍须≥T |
| 玩家费用 | 已定义能力的本场额度、已付、费用及不可用原因；未定义能力不造操作入口 |
| 结果 | 伤害、打断、落空、退款、空放、等位、延误与终局原因分别记录 |

### 玩家消费锁定与预警（CORE-055）

玩家可锁定自有未承诺的指定数量资源／标记，直到主动解锁。所有自动消费者含维护都排除锁定量；不锁敌方数量、不撤销托管／预留／冻结、不阻止伤害或自然失效。只禁止消费，不禁止合法的非消费读取；未来新增量不自动锁定。

锁定／解锁在观察窗口受理。下一批开工前展示预计消耗、当前可用／锁定及可能的等待或维护不足；随已知状态更新，指出依赖尚未兑现的条件。预告不占用，不逐批确认；实际开工重新联合检查，必需不足等待、明示可选才回退。

## TL-18 独立干涉系统接口

每战费用固定，暂不成长；具体能力、额度、单位、价格、时长、回充和共享见TL-Q09，当前不提供未定义操作。提速方向使用玩家费用，可保留合法净增产，不要求等量补休。

免费未来路由／用途／阶级选择与玩家直接付费干涉分开。战斗行的取消敌牌行动仍经队列，不是即时按钮。暂停不开放单法器停机、当前改速、战中重铭或打造。

## TL-19 中断与恢复

战中退出或异常关闭后，恢复最近已结清事件及已提交操作，进入暂停。保存下列玩法状态：

| 状态组 | 必须保持 |
| --- | --- |
| 时间与阶段 | 当前拍、阶段／组、观察窗口位置、已结清步骤及余下步骤 |
| 敌情 | 原程序及循环位置、公开翻开表、已揭示内容、锁定（含无对象）、到期倒计时 |
| 玩家行动 | 原选定队首、已用行动机会、绑定名单、实际队列顺序、入行资格、承诺效果 |
| 法器 | 当前批次用途／材料／D／进度、有效预留；待复用容量与可用拍 |
| 资源与标记 | 生命／护甲、可用／托管／锁定／冻结／失效承诺／待释放，归属、数量和可用拍 |
| 定时与维护 | 登记身份／来源／宿主／基础量／下次拍／周期／结束／余次及稳定序；活动／休眠、增幅、下次维护和本拍已检查名单 |
| 设置与输入 | 基础供料、战前法器序、唯一临时方案及结束拍、未来用途／阶级、已提交待受理操作 |
| 支付与结果 | 本场剩余费用、已提交支付、胜负、奖励／携带等提交状态 |

恢复不重付、不重兑、不重新选队首／目标、不重做完工／维护，不提前使待用量可用，也不复活已替换临时方案。事件内部不能成为重新选择点；终局后不补步骤或收益。

战中恢复保留实际增幅、维护、休眠、托管与进度，不触发战后重置。真正战终才按经济合同清理与选留。

## TL-36 决策保存与信息可达性

保留1份进行中的本局存档，设置独立。节点选择、交易、休整方向及抽取结果、铭文选择／放弃、已确认配置、开战、战果、奖励／携带提交均保存。已承诺结果不刷新，不借退出退款或重新抽取。

保存失败明确报错，保留同一结果重试并停止后续不可逆提交；读档失败不自动覆盖或新开局。新局替换存档、主动放弃须清楚确认后果；普通可撤编辑不逐步确认。

打开设置／说明暂停，关闭后仍暂停至玩家明确继续。动画服从规则时间，预测与已发生结果区分。所有必要操作和详情都有点击／键盘路径，不只靠拖拽、悬停、颜色或声音；退出弹层焦点回来源。字号、滚动不挡关键操作，静音、灰度、减动效时仍可读。

卡面敌我共用攻击▲、防御■、打断⊘、其他✱并配文字。通用组件不地方化；地域可变花色、配色、材质和装饰笔触，保留符号轮廓、位置及含义。其他类副记号随具体内容定义。

## 资源用途、背包与预告（CORE-058／059）

观察窗口可选已声明基础用途或当前合法铭刻的有限固定用途、指定兑现阶级；只改未来批次。指定料不足等待，不自动降阶或换计划。普通用途显示性质、阶级、兼容、消耗、产物及行动；背包显示未投入／本场投入、种类与容量占用及战后选留。

当前批次承诺、未来设置与尚未到账产物分别展示。保存材料身份／阶级、投入、实际选料及产出承诺、普通耗材消费／退料和选留提交，不重消费、不重退料或重产资源。

[UI与发现合同的剩余工作](../../../governance/questions.md)统一在TL-Q08、INS-Q07。铭刻编辑使用预设空缺，材料和目标说明是只读规则信息。

## 首场战斗操作合同（CORE-060）

2026-10-11 · battle-demo.1 · Accepted。适用于[EX-002完整单战](../../examples/complete-battle.md)，依据[用户R1／R2答复及采纳](../../../sources/draft-changes/D-2026-10-11-development-design-round-01.md)。下列具体值已选定，运行／可读性仍NotRun；旧EX-001回归入口不借本条改变原输入。

### 播放、停点与受理

| 条目 | 本场合同 |
| --- | --- |
| 新战初态 | 短说明后进入第0拍观察窗口，已揭示r0敌牌但尚未开工，初始暂停；提示明确继续后自动推进，亦可单步，不强制之后逐拍确认 |
| 现实节拍 | 默认1×每拍2秒；0.5×／1×／2×为4／2／1秒。前半为观察提交预算，后半为规则推进与反馈预算；暂停不耗预算，新速度到下一观察窗口生效 |
| 观察与反馈 | 完成边界／揭示锁定才观察；窗口关闭固定本拍候选，之后显示结算／反馈相位，不能称为观察。规则时间不由动画回调驱动 |
| 提交边界 | 当前逻辑阶段决定受理拍；关闭前合法提交用于本拍末检查，关闭后留下一窗口。明确反馈“已提交至第t拍／待第t+1拍受理”，边界输入归属唯一 |
| 待受理输入 | 结算中可提交未来用途／锁定意图，下一窗口按真实对象及数量复查；失效拒绝并说明，不暗改数量或当前承诺。已提交待受理操作必须保存 |
| 手动暂停 | 观察窗口即停预算；结算中在当前完整事件后停。继续先结清原拍余下步骤，新操作不能插入该拍余下结算 |
| 单步 | 仅暂停时可用：完成当前位置至下一拍观察窗口的必要步骤，做其边界／揭示后停；中途终局停结果。0拍观察到1拍观察，中段恢复先完成原拍，不额外越过另一个观察窗口 |
| 预算不足 | 工程超过现实预算时顺延真实时间并记录偏差，不跳拍／跳事件追赶；换速不多推进／重做，重启不补离线时间 |

默认开启“打断揭示暂停”：每次新揭示打断牌，在锁定／无对象结果形成后的观察窗口开始处停一次，EX-002为r8、r24……，无对象也停。默认关闭“攻击揭示暂停”，开启则每次新揭示攻击同位停。首批其他类别不造空开关；没有每拍、完工、普通伤害或疲劳自动暂停，终局直接结果。

同拍多触发合并一个停点并显示已揭示条目；继续不重复停。触发已处理状态及观察位置随恢复保留，恢复暂停后继续不能重触发。两个开关独立保存，只影响之后揭示；设置关闭仍暂停。自动停不强移回看位置，以公开信息通知并提供归位。

### 窗口、详情与信息

EX-002的操作宿主与图形边界按[CORE-063](#首场桌面3d主交互合同core-063)。下文“按钮、摘要、详情”等描述功能与信息义务，不授予主页面二维按钮条、悬停文字框或纯文字面板例外。

1080p显示7列、768p显示5列，等宽一列一拍，当前居中，开场左端从0开始。历史按实际拍，实牌按队序显示预计拍；未来空格不保证无事件。预留／待复用只入独立摘要，历史不占Q，七列不等于容量。

回看左右每次移1拍，先请求全局暂停并遵守完整事件边界，保留浏览位置，标“正在回看，当前战斗第t拍”。归位／Home恢复居中跟随，不推进、不播放；玩家在回看位置明确继续时仍保留位置并提示真实拍。浏览位置不是规则时间。

点击／键盘打开详情先请求暂停，结算时到完整事件后停；可立即显示最近结清状态并标相位。关闭仍暂停，焦点回原对象；自动暂停不关闭详情。设置／说明同样开停、关后仍停。数量／用途草稿不自动提交；关闭舍弃未提交草稿，不撤销已提交操作；提交成功显示受理拍并保存，拒绝原因可查。

暗牌仅公开程序位置、翻开拍、种类；详情、历史预览、警报或摆位不得泄露Δ、T、效果量或目标。揭示后按T显示并可查锁定／无对象、取消条件及危险开工带。

| 对象 | 信息与操作 |
| --- | --- |
| 两护符与布景 | 蓝晶杖＝施法护符，环杖＝守护护符。书／晶球仅布景，无命中、焦点或未解锁提示，不增加法器库存 |
| 读数 | 生命／护甲贴宿主；玩家施法次数常驻实有／可用／锁定精确数字，筹码辅助。1080p主要数值20px，768p18px，详情正文≥16px；类别／状态配中文及符号 |
| 法器 | 当前用途／冻结D／完工拍／预留、未来用途、无需材料和缺口；切换明确仅未来批次。三行动沿既有■／▲／▲分类，不借延期省略步骤／依赖信息 |
| 队列／资源 | 队序、来源、入行、最早资格／预计拍、费用／依赖可查；实牌／预留／待复用及可用拍分列。资源为空状态，不把抽屉格数当容量 |
| 数量锁定 | 分“新增锁定n层”“解除锁定n层”，非负整数、步长1、可键入，0禁提交。仅自有未承诺量可锁，解锁≤锁定量，超量拒绝不部分执行。下一窗口实际可用4则锁5拒绝，不改为4 |

锁定不含未来新增量、不抵消伤害／自然失效，自动消费排除锁定／冻结／待释放。当前没有的冻结／待释放分项无需堆空账目，但出现时必须真实可查。

### 点击与键盘

所有必要功能均可点击／键盘完成。字段编辑优先本字段，不能穿透触发底层播放／回看；最上弹层优先处理输入。

| 键位／对应点击入口 | 行为 |
| --- | --- |
| Tab／Shift+Tab、Enter | 遍历／激活必要按钮和对象，不依赖拖拽／悬停 |
| P／播放 | 无弹层时暂停或明确继续；弹层不能穿透继续 |
| Space／单步 | 无弹层且暂停时到下一拍观察；播放时禁用且不累计补步 |
| 1／2 | 守护／施法详情并按上述暂停；不给布景编号 |
| B／用途切换 | 选中施法时提交普通／兑现切换；其他选择提示适用对象，不暗切其他法器 |
| C／队首 | 真实队首详情，无牌显示空状态 |
| D／资源抽屉 | 空资源详情开合；打开暂停，不造库存规则 |
| L／施法次数 | 标记详情，焦点至新增锁定数量；上下±1或键入，Tab至锁／解锁按钮、Enter提交 |
| 左／右、Home／窗口控制 | 无弹层／字段编辑时回看±1拍／归位，不重排或推进 |
| Esc | 关最上弹层并回焦点，仍暂停；无弹层则打开暂停菜单／设置 |

十种文字状态的形成与原始数值核对见[来源第1.5节](../../../sources/inbox/2026-10-11-development-design-round-01.md#15-至少6种状态与可核对预期)；实际UI读取真实状态，不能把指定输入下的逐拍预期写死为任意操作结果。

## 首场表现与声音合同（CORE-061）

2026-10-12 · battle-presentation.1 · Accepted，限EX-002；[R4—R6采纳依据](../../../sources/draft-changes/D-2026-10-12-development-design-round-03.md)。CORE-060的速度、完整事件停点、单步终点及输入窗口保持；本条音画运行与体验NotRun。

### 暂停归位与真实状态

所有暂停入口（手动、揭示自动暂停、详情／设置、回看和故障）在既定合法停点立即取消尚未完成的轨迹、半翻牌、受击尾段及其他瞬态，直接显示最近已结清的真实末态和静态记录；暂停期间战斗装饰运动也停止。关闭详情／设置仍暂停。只取消表现，不取消真实批次／队列、退还支付或撤销结果；保留真实加工进度、等待原因、护甲和已揭示敌情。

自动播放可按已提交事件的真实顺序演出，表现滞后时标明已发生记录；数字与操作对象始终对应最近已结清状态，不能把中间视觉位置当成真实队序或当前余额。到暂停停点、新观察窗口、终局或场景切换，清除滞后瞬态并归位，必要信息仍静态可查。不得由动画回调推进结算或补做结果。

第04轮[限定解释](../../../sources/inbox/2026-10-12-development-design-round-04.md)：新观察先清上一拍滞后表现；若本次新揭示后仍在自动播放，可仅对本次已公开事实给一次非阻塞提示及揭示声，不遮挡信息、不延迟受理。若触发自动暂停、单步停住或形成新终局，则立即静态归位，不启动新的战斗运动／声音；新终局以结果、原因及记录完成反馈，不能将胜败声改名为UI声绕过暂停。载入仍不重播，之后继续也不补已取消的提示。音频资源制作清单不授予停点例外，资源存在不等于本场可听触发已启用。

### 单步摘要与减动效

一次单步立即完成至下一观察窗口或中途终局，不播放过渡动画。按实际日志顺序一次显示本次跨过步骤的编号静态摘要，标明原拍号与“已发生”；例如第13拍防护→打断→记次可查，而当前已是第14拍观察。只列已结清步骤，不预演尚未发生的结果，不新增中间输入窗口或逐事件单步。

摘要保留至下一次推进，旧记录仍可回看；快速连按单步替换当前摘要，不积累瞬态或声音。减动效使用文字、形状和序号，取消轨迹、震屏与大幅位移。静音或减动效仍完整提供目标、数量、支付不足回退、等待／失败原因、胜败和同拍顺序。共同疲劳的双方结果一起可读，不把双亡表现为先后抢判。

### 载入、声音与退出

载入清掉旧场瞬态和声音，按已提交状态静态重建并暂停；不重播旧攻击、揭示或胜败动作／声音，不补离线表现队列，最后记录仍静态可查并提示已恢复。终局载入保持同一结果。

暂停截停战斗单次音效，继续时不补播或续播旧音效；环境循环也暂停，只有明确继续才恢复环境循环。载入后保持环境静默至继续，不要求保存精确采样相位。暂停中的新UI点击、确认或开合声仍允许，服从效果／主音量；静音不得漏声。

返回、重试、载入或退出清除旧场全部声音及瞬态，新场只反馈新的事件。具体插值、时长、声音并发上限和混音属于工程参数，不能改变上述玩家可见政策或掩盖必要静态信息。

## 首场主窗口失焦与返回合同（CORE-062）

2026-10-12 · battle-focus.1 · Accepted，限EX-002；[R7采纳依据](../../../sources/draft-changes/D-2026-10-12-development-design-round-05.md)。实际OS适配与体验NotRun，不改CORE-060／061及原案例数值。

主游戏窗口因Alt-Tab、点击其他应用或最小化失去OS焦点时请求全局暂停。观察窗口立即停止剩余预算；结算中只完成当前完整事件及其必要结果／反应／死亡清理和终局检查后停，不拆支付与结果，不提前结清原拍余步。短暂切出立即切回也不撤销停点；游戏内Tab切换控件不属于OS失焦。

返回前台或还原窗口仍暂停，玩家须经合法入口明确继续；窗口激活、控件回焦点不等于播放指令。已手动／揭示／弹层／故障暂停时保留原暂停原因及约束，返回不得解除故障、关闭弹层或恢复终局播放。实际继续先完成原拍余步，不补后台战斗时间，也不重置已经消耗的合法观察预算。

保留当前批次、真实队列、已提交待受理输入、回看位置和选中对象。失焦本身不关闭或重建弹层，不提交、改写或丢弃同进程未提交字段；返回后可继续编辑。真正关闭才沿原合同舍弃草稿，真实退出／载入仍按TL-19最近提交恢复，不新增草稿跨进程保存。有效控件恢复可操作，失效控件沿已有合理回焦点规则处理；不自动归位或跳当前拍。

暂停音画完全沿CORE-061：合法停点立即归位、截停战斗声且不续播、暂停环境；返回不重播旧动作／声音，失焦／返回通知本身不冒充新UI点击发声。失焦时当前事件形成终局，完成同一结果与清理后保持静态。开始／结果页不因返回开启战斗；显示试用不因失焦确认设置，原有超时恢复独立于战斗预算，不因战斗暂停而冻结或延长。

## 首场桌面3D主交互合同（CORE-063）

2026-10-12 · physical-table.1 · Accepted，限EX-002；[第07轮R8／R9采纳依据](../../../sources/draft-changes/D-2026-10-12-development-design-round-07.md)。新3D交互实现与体验NotRun；CORE-060—062的推进、受理、暂停、回看及恢复政策不变。

### 操作入口与图形页面

主页面所有可操作入口均由真实3D物件承担，包括法器、真实卡片、棋子／标记、资源抽屉以及播放、单步、倍速、回看、归位和系统入口。点击和键盘等价激活同一对象；独立桌沿物件可以承载现有控制，不增加玩法能力或库存。蓝晶杖＝施法护符、环杖＝守护护符，书和晶球保持无命中、焦点与功能的布景。

主页面删除独立二维操作条、悬停文字框、常驻大日志／纯文字摘要以及与物件分离的透明操作层。悬停或键盘焦点仅给物件静态轮廓／形状反馈，不暂停、不提交、不揭示。必要精确数字、卡效文字、类别和状态仍完整保留于卡面、实体读数或相应图形页面；不以筹码近似数替代准确余额。

只有点击暂停近观说明和系统界面采用独立页面，且必须有对应图形UI：对象图形、状态图形与操作反馈须实际表达正在查看／处理的对象。给原文本框加装饰边框不足以满足本条。开始、设置、错误、必要确认和结果可使用图形页面；主页面通往这些页面的入口仍是3D物件。

点击／Enter近观先按完整事件边界暂停，以最近结清状态立即静态切换；关闭静态返回且仍暂停、焦点回来源。查看不出牌、不推进、不付款、不改真实位置／队序；暂停中不播放抬起、翻牌或镜头过渡。数量编辑可在相应图形近观页键入／±1并明确提交，保持0禁提交、超量全拒绝、草稿与受理拍等现行条件。直接切未来用途由法器对应实体控制承担。

### 真实卡片与已提交事实

实际队列牌具有真实空间位置、厚度、正背面及对应空间拾取；屏幕卡图或按钮不能替代。法器实际完工后，卡片从对应来源入列，按真实队序与公开预计拍显示。预留、待复用及历史记录采用可辨的静态图形，不伪装成可出牌实牌；有效预留与待下拍复用容量仍计入Q，历史不占Q。7／5列只是显示窗口。

玩家已知牌保持公开正面与完整已知信息；合法行动时的抬起／翻转是使用动作，不重新揭密。敌牌r前背面只公开程序位置、r与类别，不从位置、纹饰、提示、近观或指线泄露Δ、T、量值、目标；r揭示／锁定后公开正面并按T显示，T时执行出牌动作，不再盖回暗面二次揭示。

保留自动推进、手动暂停和单步，不能改成逐张点击翻牌才能结算。动作依序呈现已结清的入列、揭示、出牌、目标结果及离场；规则是唯一权威，翻面／命中／离场不再支付、扣血、释放容量或推进。复合牌的一次使用不因多步骤重复出牌或付款，目标结果依实际事件，不为演出重新选目标。

### 停点、历史与可达性

全部暂停入口立即取消未完战斗运动，静态显示最近结清末态；不得要求先播完翻牌。单步立即显示有原拍号及编号顺序的静态图形结果，载入静态重建，失焦返回仍停，继续不补旧音画。终局不等卡落地，不增加胜败声或暂停运动例外；声音沿CORE-061。

历史与单步记录保留完整原因、真实拍号及顺序，从真实刻位／记录物件进入图形近观查阅；主页面不恢复大文字日志。回看先暂停并保位，归位不推进，继续时保留浏览位置并准确提示当前拍。历史痕迹不成为队列牌。资源抽屉按合法停点静态开合，空材料不造库存，三格不代表容量3。

主页面物件与独立页面均保留现行必要字段、字号及键盘／焦点优先级。静音、灰度、减动效时仍可辨目标、费用、等待／失败原因与顺序；保存错误仍明确可重试并阻止后续不可逆提交。具体物件形制、排版、镜头和动作参数由后续制作方案决定，不能改变本合同。
