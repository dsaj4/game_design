# 交互与保存：设计

2026-10-23 · DesignNote。信息义务与保存行为沿 TL-17／19／31／36；器具入口沿 ART 意图。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

让玩家分清承诺、预测和结果，并能在关键时刻调整未来计划。

旧3D EX-002主页面以真实3D物件承载全部操作，卡面与绑定物件的精简只读容器保持精确信息，悬停／键盘焦点可查公开短提示；点击暂停近观与系统页采用对应图形UI，沿[CORE-063](rules.md#首场桌面3d主交互合同core-063)。原有“现场摘要／详情”不授权独立HUD或纯文字页面；形制与排版见[旧3D制作包](https://github.com/dsaj4/game_design/blob/56a0ef07f13a647a4383a751977f2dce871bd731/yanzhou/visual/demoncards-reference-2026-10-14/design-v01.md)，不改变受理、公开资格或暂停规则。新2D展示适用关系另待PRE2D-Q01，不从此页推定新方向仍必须3D或已解除原合同。

| 设计重点 | 内容 |
| --- | --- |
| 玩家旅程 | 战前装配与投入；战中看运行和敌情，在观察窗口调整；战后领取、选留并准备下一场。 |
| 信息层次 | 现场显示决策摘要，详情解释完整来源；当前批次、未来设置、实际结果分别呈现。 |
| 操作位置 | 法器相关调整从法器进入，敌情、资源、队列与标记保留各自信息入口。 |
| 连续性 | 生产暂停收尾本拍、结算暂停收尾本列及动画；第5列之后的轮尾独立待办，最终整理明确确认后才结算；异常恢复保留最近结清位置、已提交操作及真实账目，普通可撤编辑保持轻量。 |
| 可达性 | 点击和键盘等价，文字配符号；静音、灰度、减动效条件下仍能判断成本、威胁和结果。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q08／09／11、INS-Q07。
