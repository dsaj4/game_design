# 局内经济：设计

2026-10-27 · DesignNote / CORE-067。奖励、休整、商店和携带沿 TL-25／33—35。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

让战斗收益投入后续构筑，并保留生命、金币和实体的机会成本。

| 设计重点 | 内容 |
| --- | --- |
| 分账 | 卡牌材料、标记、金币与配置实体分别记账；现行布牌免费，无独立干涉额度。胜利收益包和卡牌携带选择分别提交。 |
| 成型路径 | 用真实获得渠道检查买到或发现的组件能否部署，前段正常收入应有购买基础合格商品的机会。 |
| 选择 | 休整恢复与拿铭文互斥；固定商店使消费有放弃项。打造单独依其已定义流程。 |
| 持续积累 | 未投入卡牌也占背包；跨战高阶留存需与现场取材、拖战收益一起评估。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q01／06／07、INS-Q05。
