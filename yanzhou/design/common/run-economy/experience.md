# 局内经济：体验目标

2026-10-11 · Hypothesis / NotRun。

| 目标 | 支持信号 | 失败信号 |
| --- | --- | --- |
| 成长可部署 | 说明新组件怎样改善当前配方 | 长时间只能得到无法使用的部件 |
| 经济有取舍 | 比较恢复、拿词、购买与留钱 | 所有钱只流向唯一收益 |
| 携带可解释 | 说明为何保留或舍弃材料 | 永远无取舍，或被逐件清理拖累 |
