# 局内经济：规则

2026-10-31 · CurrentSpec / CORE-069。[状态与来源](../../baseline.md)。

[设计](design.md) · [体验](experience.md) · [示例](examples.md)

## TL-25 资源背包与部分跨战保留

本节背包指跨战携带库存，与战前生产格布局／本场供料区不同。携带背包限制具体种类数与共享容量，每份占容量；同种多份增加占用，不同阶级算不同种，共享性质不合并。卡须有明确可携带标签，基础环境料默认清空；手牌取消H3不取消跨战背包限制。

战斗回收与跨战携带不同：一张可回收牌可以没有携带资格，不可战斗卡也可能可携带。战前仍从真实库存选择本场投入，未投入者本战不能取用；胜利后将实际剩余且可携带的卡、未投入库存和已取得收益按种类与容量统一选留。已消费输入、已经使用的不可回收牌、未兑现的预告不参选；同一实例即使曾多次回手也只能计一次。保留身份、数量、阶级，重置战斗运行状态，提交和恢复不重领。普通失败结束本局，不新增失败后继续携带的路线。

未吸收待料仍是玩家真实持有卡，战终从供料区移出按资格参选；普通耗材未完工战终退回后按资格参选，不补产物；已完工输入不退。特殊对象合同见TL-Q03。选留一次提交，恢复不重领。

## TL-33 本局库存、生命与收益容器

法器、铭文、辅助道具和金币属于本局库存；已装配铭文仍属库存，但不能重复占用。辅助为独立持久配置实体，胜利后保留、下战可重新部署；未部署不提供本战效果，不被生产消耗或自动补料，不套用材料携带标签／容量。可携带成品重置本战临时辅助增幅，实体持有与成品效果分账。普通胜利不回血，剩余生命进入下一场。新局满预设生命、0金币，旧局库存及战斗状态重置，不继承局外数值成长。

每场普通胜利至多一次收益包，整包领取／放弃，不重抽或返场再领。放弃不删除已有库存，资源选留是另一提交。只有内容明示的金币与物品进入包。

新局提供真实可执行基础路线所需配置：有耗材路线给明确启动料，零材料路线可以0启动料。后续依环境、转化及携带，不每战免费补满。卡牌材料、标记、金币和配置实体分别记账。CORE-067的上牌、撤回、互换与调序免费，当前没有独立干涉额度；若以后采纳其他付费干涉，其费用来源与恢复方式须随该能力另行明确，不能由材料补给推定。

## TL-34 休整的互斥选择

每节点用一次：恢复生命、拿一铭文或跳过，恢复与拿词互斥。恢复不超过上限，满血无额外补偿；不额外发金币／商品。

先检查池与持有资格能否提供3个不同名候选，至少1名词、1动词；不足只提供恢复／跳过。选择拿词后，依次从合格名词、动词、剩余合格词名等概率抽1个，不重名，不强塞适配组件。选1或全放弃；见词后不改回恢复、不重抽。此处3是候选数，不是同名持有额度。

## TL-35 固定商店与原子交易

抵达独立商店节点时生成固定货架和价格，显示完整效果、价格及资格。详情／恢复不刷新。铭文每次从剩余合格词名等概率抽取，同店不重名，一项一件不补货；不同店可再次有同名，仍受持有资格限制。

每次购买同时检查资格与足额金币，成功才共同扣款并交付；可连续买不同商品，不部分支付、不超买。候选不足少摆，空店可离开，无补偿；不按余额／构筑暗改商品，不保底配齐核心。法器商品用自身资格，资源成为商品须内容明示。

离开留余款并沿路线前进，不回访。当前不提供卖出、退款、刷新、随机包或永久删卡。商店不附送恢复、铭文或战果。具体池、持有资格、价格与恢复量见[集中问题](../../../governance/questions.md)；EX-001值只用于案例。

## 辅助道具取得接口

CORE-069取消辅槽打造及INS-Q05原容量待办。辅助的实际渠道、价格和持有资格由内容声明；不是拿铭文时自动附赠，也不因可持有就默认加入商店池。若作为商品发行，按TL-35足额交易，不新增出售／退款或保底。首批无辅助运行耗材、独立计时或维护费；成本不足、实体占用与无效连接分别提示。
