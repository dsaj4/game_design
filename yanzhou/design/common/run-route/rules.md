## TL-32 单向路线与遭遇信息

本局路线按约束生成一次后固定，各可选分支应能向本段目标推进。到分叉再选下一节点，已进入不可撤回重抽，已通过不重复访问或领奖；查看、返回详情或恢复不刷新来源。引路打开的合法灰井仍占本段一次地域机会，不再追加一段。

当前主线为文字界起始燃契→初试→返回燃契→再试→返回燃契→终试→带回并完成终式。每段最多进入一个地域，无第四段或返回刷取。前两段可第4早回，但须完成现场任务并足额燃契后才推进；漏做且无补做路径则未完成结束。终试第4返回只能未完成结束。普通战败结束本局，终试第6胜利不直接结束整局；终局归TL-47。

| 位置 | 作用与提交边界 |
| --- | --- |
| 第1 | 本段有限入口补给，先显示再实际选留 |
| 第2 | 普通／封门／兼容入口驻影战斗；实际亲战与替换记录分开 |

| 第6 | 挑战→固定收获及驻影报酬合法选留→最多一种调查→终试核心处置；提交选留后不倒回补领 |

出发前免费显示下一候选地域、敌人类型与主要压力，并在5A／5B前保持已固定深层类型。当前已知纹样、兼容性和公开报酬不收费重看；未公开附带信息沿问兆权限。暗牌不因设计表完整而提前显示数值，战中揭示仍沿TL-09／16。休整／商店仅在内容明确提供时出现并预告向前是否可达；仪式最小局不强制插入商店或金币来源。其他采用商店的完整路线仍须在终点前提供可选购买机会及此前金币来源。

## 生成与可达性约束

起始、三段最低任务和返回燃契所需来源必须按内容包固定可达，不能靠未知随机掉落补齐。三段对应类型敌表复用，不暗增生命／伤害。普通局不保证三个普通结局全部开放；选定飞升时须提供初试普通5B匹配基础终试封门的石、初试第7空壳、再试兼容入口驻影路线，并保留终试合法来源。

来源的组与纹样在声明时点生成并固定；定筹在初试第6生成揭示前选既有组，之后不暗换。改路重新核验实际入口、解缚与兼容条件，不用入口A的记录替代B。支出只用当时实有材料：终试5B的收入不能用于出发前解缚；香料较少时在预览中提示后段合法补足选择。

校验以真实初始库存、实际选留收益、生命与TL-46逐格装载为准，仓库／待选／未来来源分账。节点来源、领取、任务和选择状态保存，不因开关详情、改准备或恢复重发。其他构筑、生成权重与长期内容规模仍见[TL-Q06](../../../governance/questions.md)。
