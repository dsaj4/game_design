# 局内路线：设计

2026-10-11 · DesignNote。路线规则沿 TL-32。 [版本与来源](../../baseline.md)。

[规则](rules.md) · [设计](design.md) · [体验](experience.md) · [示例](examples.md)

把战斗风险、构筑状态和下一次取得机会连起来。

| 设计重点 | 内容 |
| --- | --- |
| 分支依据 | 以公开主机制、当前生命和真实可运行配方选择路线；商店具体商品抵达后揭示。 |
| 内容检查 | 各分支能前进，金币先于至少一次终点前商店机会出现；逐路检查实际可负担性与放弃项。 |
| 价值 | 战斗、休整与商店交替承接构筑调整；路径差异应影响判断。 |

待决与风险统一见[问题登记](../../../governance/questions.md)：TL-Q06／10。
