## TL-47 文字界、仪式与终局

2026-11-14新增CORE-079框架，采纳来源见[本轮D](../../../sources/draft-changes/D-2026-11-14-aspect-framework-integration.md)。以下新增名字知识及召唤三要素；原ritual-minimum-run.2具体仪式仍为未完成字相映射的固定内容域。新增框架不按名称自动重写旧方法、费用或目标，迁移缺口见[ZX-G04](../../../governance/questions.md#aspect-framework-open)。

物质界承担采集、生产与战斗；文字界承担主线燃契、释读、联系、拔擢及下一段准备。文字界没有通用制造／饮药权限。现场完成、持有实物、学会方法、永久资格各自核验，不相互替代。

仪式先核对方法、实际目标、当前窗口及全部实付条件；合法且足额才一并扣除并提交效果。无目标、目标不兼容、无新信息或重复建立已有联系，不能收费后才报无效。已支付并生效的操作不因后来改路而退款；查看资料、反复开关详情或恢复不重发。

### 主线燃契与唯一结局核

起始燃契给出基本归还方法并开始初试。初试验印、再试确认两痕同源的现场事实分别是该段汇报前置，必须实际完成；有普通烬核不等于有现场记录。现场已完成但原核失去，可用实际带回的其他普通核支付。初试／再试燃契各自足额完成后才推进下一段，不能预支下一段收入。

初试第3须打开已有关系印记、对照承载处回应并主动确认验印取核；再试须分别查看两处痕迹，对照本局初试汇报关系并主动确认同源。匹配结果明确可见，不做随机真假或猜错扣料。再试两处观察只完成主线，不提供覆痕／逆流证据。生成的核先进入待选区，重复查看或核验不重发。

终试第3须关系匹配、实际选入指定核，再主动绑定唯一实例X3，不能把关掉说明当成确认。第6完成处置、带回、终式消耗均追踪同一实例；普通核、开局余烬或另一份显示同名的核不替代它。丢失X3不自动补发或另绑替身。第6挑战胜利只结束本场战斗，尚未完成整局。

离开第3前未完成动作时列出具体缺项与不可回访后果，可以在当前窗口补做，也可明确跳过并继续本段探索。返回后没有补做路径则只能未完成结束；取得的合法知识仍保留，不能靠多交材料代替现场任务。记录绑定本局、阶段及实际进入路线，不因预览或改选未进入入口提前获得。

### 释读与学习链

<a id="aspect-knowledge"></a>
#### 字相知识与名字（CORE-079）

知识主要来自书本和仪式，按不同字相具有知识等级；等级提升可解锁更多核心铭文的理解／获取资格和故事碎片。阅读书本可能授予知识等级、仪式类型及具体物品名字，不要求每本同时授予全部收益。具体等级表、阈值、解锁范围及故事内容待定，不把旧方法链自动换算成等级。

物品名字可用明确语义指向字相，不要求字面逐字相同；草、木均可指向木相，疗伤不属于字相。非直露名字可以通过隐藏名、别名或真名揭示既有字相；高级物品更倾向具有多个名字，既不保证必有，也不保证每个名字对应一个新相。命名对应须由内容声明，不以任意自然语言联想赋予资格。

知识揭示既有性质，不改变真实物品、不追溯补发旧效果。未学会必要知识不能进行受其限制的加工，即使玩家猜对材料；识别到次相也不会恢复已经丢弃的该相效果，生产沿TL-49。知识解锁与取得实体、装配核心分别核验，不能直接授予永久铭文。永久记录沿TL-48，学习动作仍沿本节主动释读及明示仪式结果。

#### 既有释读内容域

释读是文字界实际持有书籍时主动执行的免费动作，书保留。仅取得、查看或存仓不算学会；学习结果永久保留，已学方法使用时不再要求携书。历史观察可满足学习前提，不能替代当前局／当前段目标证据。

| 载体／前提 | 主动释读所得 |
| --- | --- |
| 仪式手记 | 问兆、引路、招客 |
| 手记＋曾实际观察覆痕 | 断契 |
| 手记＋曾实际观察逆流 | 夺火 |
| 解缚页 | 解缚及启阶方法 |
| 手记＋已启阶且曾实际解缚 | 定址及驻影方法 |
| 手记＋已定址且曾实际完成驻影接触（可跨局，接触可早于定址） | 升界方法 |

启阶须已经完成首次履约、学会页中方法并支付对应费用；定址须已启阶、实际解缚、持手记学会方法并支付对应费用。两次拔擢各只取得相应永久权限，已取得不重复付费，不补给使用新能力所需材料。知识、拔擢和传承持久化归[TL-48](../../systems/meta-progression-system/rules.md)。

### 问兆、纹样与引路

<a id="aspect-ritual"></a>
#### 召唤对象、仪式类型与字相主题（CORE-079）

所有仪式以召唤为核心，必须能明确指向对象。对象限制可回应领域，仪式类型决定请求行为，字相限定请求主题；类型通过知识解锁，并声明对象和主题之外的其他要求。特定供物通常指向神灵或其他召唤物，另一份祭品通常提供主题字相；多相祭品在举行前选择一个已知相，不能用尚未解读的隐藏相替代已知相。

问路已确认的结果语义是开放一个可前往的合格地点。具体对象、供物、地点生成与路线接入待定，不把问路直接视为现行问兆或引路的改名，也不增加地域进入次数。现有燃契、拔擢、终式等具体对象映射同样待设计，不能凭三要素齐全免除当前窗口、现场证据、真实支付或唯一目标要求。

新仪式或迁移内容须明确对象、类型、主题、额外条件和实际结果；无目标或无有效结果时沿本页总则不收费。特殊失败、复合请求和新增地点规则未确认，不另造随机失败或隐藏扣料。

#### 既有问兆与引路内容域

问兆仅揭示下一段尚未进入的合法候选之未知隐藏信息，包括5B清单及第6可选组附带内容。已经公开或已知、没有后续合法目标时不收费。免费查看已知资料不揭示未知内容，也不代替释读或实际调查。

折纹／环纹按目标要求相同纹样适配，来源不增加隐形排他条件。起始燃契公开后续可规划入口的纹样；来源石的纹样生成后固定，不因玩家选取、改路或恢复重抽。已公开报酬的石纹样在施仪前可查，不能隐瞒后再卖问兆。

引路只打开下一段一条已声明兼容的灰井入口，仍占该段唯一地域进入机会。支付后改选无退款，不能增加地域次数或复制节点来源。解缚须已启阶、已学方法，对明确的下一段封门实例实付匹配石与费用，替换其第2封门遭遇为普通巡守；不删除战斗、不视为亲自驱离，不改主线和其他节点。

### 招客、履约与解缚页补领

招客须已学方法，有实际对象及用途才建立有效联系。已有有效联系不重复收费；同一对象至多一项进行中的请求。首次履约同时需要有效联系、曾亲自击败封门的真实经历（可跨局）和实付一枚任意纹样石；解缚／驻影不提供该亲战经历。履约授予实体解缚页，不自动学会内容。

已履约但尚未学会且失去页者，下一局建立有效联系后可补领，免重复石费和亲战要求；需要重新招客时仍支付招客费。每局最多发一次，正在持有不再发，同局丢弃不补，学会后停止发放。页无出售、加工或供物用途；不把补领变成可循环产物。

### 常规委托

学会解缚页后，有效联系可提供验痕／收手。仅绑定下一段初试或再试；出发前可改选或取消，出发时锁定目标实例。同对象只一项进行中，每模板每局最多完成领奖一次，不能回访重刷。具体费用、收益见内容包。

验痕接取前须已知下一段覆痕且有后续灰井适配用途；实际调查、完成该段燃契、再交普通核才交付与已预览后续入口同纹的石。没有后续用途不提供此任务。收手须完成基本任务后在第4返回，未进入5—7，再完成燃契才领奖；不能借报酬支付尚未完成的燃契。

### 驻影与调查

驻影须已学方法，在出发前对下一段兼容位置支付费用并锁定落点；一段至多一次。定址前只能第2入口，定址后可在兼容的第2入口／第6深层选一处。实际替换对应遭遇，不增加战斗次数或复制补给。入口及深层报酬分别按内容包，真实成功接触且实际选留才取得。入口驻影不能覆盖尚未解缚的封门；可先分别支付解缚，再驻影。深层驻影不改变入口封门，也不取得亲自驱离资格。普通旧径无冲突版本提供入口／深层均兼容的样例，具体频率待定。深层仍保留原固定收获、调查前提及终试核心处置；不能承接这些功能时施仪前判不兼容，不先扣费再删功能。

驻影付款后绑定具体地域和位置，不免费搬移或退款；改选其他已开路线即放弃该显现，不能同段重新召一份。第4早回关闭深层显现，不发报酬。实际接触完成与材料实际选留分账，前者可作为历史学习经历，未取得的报酬不直接入仓。

第6顺序固定为挑战胜利→固定收获和驻影报酬的合法选留→至多一种可选调查→终试核心处置→第7。选留提交后不能在后续消费腾格时倒回补拿；本节点刚实际取得的适配物可用于后续调查／处置。

覆痕需当时实际持有同纹石，调查不消费石，记录本局关系及纹样。逆流需该段亲自击败封门后实际调查，记录本局力量缺口；历史亲战、解缚和驻影胜利不能替代。两者观察可用于以后学习；普通结局准备须采用本局初试／再试记录，终试才调查来不及满足本局前段准备。

### 普通结局与最后文字界窗口

普通目标共用终试挑战，处置X3前核对方法、本局证据及真实投入；提交后不可改选。信仰用归还准备，返回终式时还须主动接受追随；查看／暂缓或拒绝不自动结算，也不能倒改第6为其他目标；追忆须已学断契及本局前两段关系记录，消耗适配石；忤逆须已学夺火及本局前两段力量缺口，消耗空壳。普通死亡不产生忤逆结局，不增加特殊死亡战斗或额外首领。

返回后保留实际库存，清理前仍可合法释读、履约、拔擢。没有下一段目标的问兆／引路／解缚／驻影拒绝且不收费。可能侵占终式材料的操作要明确当前缺口、随身／仓库余量和剩余合法来源；不以隐藏硬锁替代玩家选择，不自动改用X3或补造材料。

足额支付对应终式并提交结局，才记完成和永久解锁，再清理本局实体。材料不足且已无当前合法来源时，可以停留查看或未完成结束；不免费终式、不倒回节点。提前返回、战败、只完成第6动作均不授予结局奖励。

### 飞升的独立目标

新局选择飞升前须已定址、学会升界并完成过至少一种普通结局。本局还须初试／再试实际完成驻影接触形成锚定；终试出发前对实际要进入的指定封门完成解缚，再完成终试第6挑战与升界动作、带回X3并支付独立飞升终式。

解缚入口A不满足后来改选的B；改路须重新核验实际目标。解缚后同入口合法驻影不抹掉解缚事实，也不额外生成一份记录；终试驻影不补初试／再试锚定。缺任一项不能升界，不临时退回普通结局。基础来源和兼容候选按TL-32生成约束，在出发前核验。

## 信息与恢复接口

显示“已学方法／永久经历／本局记录／实际物品”分别是什么；说明第二瓶药最早可用轮、节点待选不算库存、选留提交后不补领。具体视觉方案仍待制作。

恢复须保留节点生成、来源领取／放弃、分支与组锁定、任务绑定、纹样、目标实例、学习／履约／补领、本局调查／锚定／解缚、X3身份及处理阶段。扣费、效果、记录、发放和清理按各次已提交结果恢复，不多扣、多发或换目标；保存失败沿[TL-36](../interaction-save/rules.md)阻断后续不可逆提交。
