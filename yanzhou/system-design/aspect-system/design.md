# 字相框架的设计目标与取舍

2026-11-14 · CORE-079 / aspect-framework.1。已采纳的框架由[TL-49](../../design/systems/aspect-system/rules.md)、[TL-47](../../design/common/ritual-system/rules.md)及[TL-48](../../design/systems/meta-progression-system/rules.md)裁决；本页只解释目标与方法。来源见[采纳D](../../sources/draft-changes/D-2026-11-14-aspect-framework-integration.md)。

## 目标与玩家判断

让玩家从物品性质、形态、工序和已学名字解释为什么能加工、为什么得到这种作用，以及继续加工会失去什么。知识应能迁移到新材料，避免每个配方都是孤立密码；这仍是体验假设。

## 设计方法

设计一条生产路线时，先给必要字相／物相及工序，再明确主相效果来自哪份当前材料、产物保留哪些资格和物相带来什么作用。最后核对真实铭文、设备、份数、D、知识门槛及实际用途。具体名字、配方与数值只在内容库维护，不在本页建立第二份条目表。

同字相应保持核心机制一致，同物相保持基础作用一致；物品差异主要由物相与特殊词条解释。名字解读揭示性质，不能临时改变旧物品效果来替故事补逻辑。仪式按对象、类型、主题说明请求，具体对象和供物缺失时保留Unknown。

## 关键取舍与失败信号

- 字相资格保留使物品仍能用于其他路线，但只有一个主相效果可传递；玩家必须能看懂两者区别。若每次都需查长表，降低记忆负担的目标未达成。
- 重建物相让继续加工同时获得新作用并放弃旧作用；高阶不靠无条件累积所有前料效果。若所有路线都只追更高级且无停点价值，需要重评内容。
- 知识门槛赋予阅读和仪式实际意义，也限制盲试。若正确理解仍被大量独立知识锁阻断，需审查解锁粒度与反馈。
- 若为了不同效果不断细分物相，框架可能退回逐物件背诵。先用少量明确物相检验可迁移性，再扩充内容。

## 当前范围与下一步

框架已经Accepted，内容库仍待映射。下一步优先闭合一条真实生产链的物相、等级、数量来源、名词槽和知识取得，再处理特殊词条及仪式逐类迁移。未知统一在[问题登记](../../governance/questions.md#aspect-framework-open)，不在这里另建问题表。现有首战／仪式包只能证明原固定内容域；本框架尚无模拟、引擎或真人验证。
