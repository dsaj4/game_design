## 5A加工与恢复

共享5生产拍，每节点至多实际消费1瓶生命灵药恢复12；额外生产拍费用0。只启动剩余拍内能完成的批次。仅5A可战外消费实际生命药；其他窗口不开放，满血确认也消费，实际药不重复使用。

## 范围、时序与选留

| 接口 | 本包合同 |
| --- | --- |
| stages | 初试／再试／终试各最多进入一次，前两段第4可带最低材料返回；终试第4返回未完成结局。 |
| mainTasks | 初试第3验印取核；再试查看两痕并确认同源；终试实际取核后绑定唯一X3。 |
| node6 | 挑战→固定收获及驻影报酬合法选留→可选调查→终试核心处置→第7；提交选留后不能倒回补领。 |
| selection | 互斥组选一，组内按份选留，首份实际取得后锁组。第5共有战备一次；首次生产／饮药锁A，首次5B专属领取锁B。 |
| storage | 战斗牌实际投入才离包；仪式实体战中留包固定。实际带回进入本局仓库，物质界不能调用；整局实体清理。 |
| jobs | 同一对象一项进行中，仅下一段初试／再试；出发后不改选，每模板每局最多领奖一次。 |
| inheritance | 首次完成对应终式后解锁，下一局开始至多选一项，中途不切换；重复只记完成，不叠加强度。 |
| terminal | 挑战胜利不直接结算整局；带回后仍可合法释读／履约／拔擢；成功终式后记录再清理，缺料不补造。 |
| generation | 基本主线最低来源固定可达；普通局不保证三结局全开放。飞升初试5B石匹配基础终试封门、初试7有壳、再试入口可驻影；改路重新核验，定筹不被暗换。 |
