## 范围与来源

用户本轮明确进入主页面HTML设计，并将筹码详情和历史延期；这两项不阻塞本版结构稿。规则输入继承[文字稿](../../sources/inbox/2026-10-24-top-down-2d-battle-style.md)固定的CORE-065／066版本，不升级玩法基线。已确认文字快照为本仓库 `e4ce92762a862b6acebbea3b9198d9bb76a9d0d9` 中的该文字稿与[筹码专项记录](../../sources/inbox/2026-10-24-stacked-counter-chips.md)，加上本轮范围授权。完整状态输入沿[EX-004 §2—8](../../design/examples/round-first-battle.md)，不从旧Demo反推规则。

- 上半区两排五位逐列对齐；中区左资源、右敌上我下的筹码；下部两台实有法器及两处预留，右侧三张展开手牌；底部操作区。
- 生命与护甲只在中区。筹码有有限视觉堆叠及准确总数；施法次数同时呈现实有、锁定和可消费。筹码详情／锁解控件不在本版范围。
- 卡片和法器点击或键盘进入上层详情窗口；关闭按钮／Esc关闭、回来源焦点并保持暂停。暗牌窗口不揭示未公开名称、量值或目标；强化卡主桌仅条件图形，详情同时给两个分支。
- 整理通过独立选择入口与费用确认演示，点击牌面仍查看详情。提供桌牌交换、桌手互换、手牌提前进入最左空位；成功才扣1点。
- 法器详情可演示未来用途切换，与当前批次分开；结算状态关闭玩法编辑。没有真实游戏运行、存档或生产调度引擎。

## 如何审阅

默认是EX-004 §6第2轮最终整理、已提前铺入旧手牌但尚未执行两次交换的固定状态。可直接查看卡片／法器，也可用“整理”选择桌第2位和手第2位，确认后再交换桌第2位与第5位，观察点数与卡位。

右上“示意状态”切换就绪、第6拍生产暂停、最终整理、第二轮结算完成和第10轮疲劳待处理。切换／重置会恢复所选固定输入，不保留上一状态的局部编辑。

“确认结算”或“单步”进入明确的示意确认。结算只播放EX-004代表路线的五个列末快照；若当前排列不一致，先说明并载入固定排列，不对任意编辑计算胜败。生产与就绪的下一步也明确使用固定状态切换。疲劳按钮仅显示该轮已知扣除结果，不自动演示下一轮准备。
