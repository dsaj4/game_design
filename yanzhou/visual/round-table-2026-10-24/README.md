## 本轮装配

保留 HTML-02 的组件分区、五位两行、三张展开手牌及操作路径；将已审阅的暗酒红＋古金＋黑褐木对象图接入主页面。桌布与木桌作为底面，卡背与卡框统一纹饰，守护／施法法器和三类筹码使用效果图；铜灯、蜡封瓶与札记置于桌缘。温暖侧光与生产进度由 CSS 表现。

卡名、数值、类别和状态仍由 HTML 显示。本轮通过内置 image_gen 从已审阅的护盾卡派生空白卡框，避免原图文字与实时内容重复，见[装配补充资产](../burgundy-objects-2026-10-24/integration-v01.md)。护盾插画来自原护盾卡，试剂类使用蜡封瓶；普通攻击、强化、打断仍沿原 SVG 插画并调整配色，尚未完成全套独立插画。

右上“⋯”可开关**桌面陈设**，并进入[结构版对照](dist/structure.html)与[对象审阅](../burgundy-objects-2026-10-24/dist/index.html)。结构版是 HTML-02 原文件的完整副本，默认入口现在是装配版。

## 保持的设计边界

- 顶部仅回合、阶段、生产拍／结算列和疲劳；敌方与玩家各一行五位；中区左资源、右敌上我下的筹码。
- 生命与护甲只在中区。筹码最多显示5层并保留准确总数，0值保留空底位；层数不代表面额或数值上限。筹码详情、锁解控件与历史继续延期。
- 下部两台法器、两处预留位置，右侧三张完整手牌、容量和整理点；下缘按阶段提供整理、单步、继续／暂停及结算确认。
- 点击卡牌／法器打开上层窗口，Esc或关闭按钮返回来源焦点。暗牌只展示已公开类型与时序，强化卡详情保留两个分支。
- 整理使用独立“＋”选择入口，成功才扣点；法器未来用途与已承诺当前批次分离。

本页继续使用 EX-004 固定状态与五列结算快照，不计算任意排列的胜败，不构成真实游戏运行、玩法实验或运行验收。图像装配未改变规则、状态输入或结算流程。
