## 位置与操作

| 区域 | 本版安排 |
| --- | --- |
| 上方 | 酒红前台承载敌我两行五位；对手手部从远侧伸入 |
| 下方 | 宽工作台、两台高低不同的法器、左右两处扩展预留 |
| 左侧 | 资源浅架；当前示意零资源，保持空架 |
| 右中 | 敌上我下的筹码托盘，生命／护甲只在此处显示 |
| 右下 | 三张完整手牌、容量与整理点 |
| 上下边缘 | 窄状态带与阶段操作 |

点击牌或法器打开上层详情，Escape 关闭。拖动玩家桌牌／手牌可按既有规则交换；手牌补入只接受最左空位。有效整理消耗 1 点，保留原“整理”按钮及键盘路径。法器下的“下一批”拨片切换未来用途，当前批次保持不变。右上“⋯”可切换固定示意状态、重置、开关区域标注。

这些是原 HTML 固定状态的交互呈现，不是实时规则引擎。生产、结算沿原示意脚本；未增加鼠标研磨、资源供料、成牌领取或新的生产规则。筹码详情与历史不在本版范围。
