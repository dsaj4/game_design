## 位置与操作

| 区域 | 本版安排 |
| --- | --- |
| 上方 | 酒红前台承载敌我两行五位；对手手部从远侧伸入 |
| 下方 | 宽工作台、两台高低不同的法器、左右两处扩展预留 |
| 左侧 | 三个纵向资源卡堆；Ⅰ／Ⅱ／Ⅲ仅为造型位置编号，未定义资源种类或数量 |
| 右中 | 敌上我下的筹码托盘，生命／护甲只在此处显示 |
| 右下 | 一个手牌卡堆、容量与整理点；点击卡堆临时展开三张手牌 |
| 上下边缘 | 窄状态带与阶段操作 |

手牌默认收拢，卡堆层数对应示意中的实际手牌张数；零张显示空堆轮廓。点击卡堆或进入“整理”会展开原手牌；点击牌仍打开上层详情，Escape 先关闭详情，再按 Escape 收起手牌，焦点回到卡堆。关闭按钮也可收起。展开后的拖动整理、费用和最左空位补入规则沿前版。法器下“下一批”拨片、窄状态带和阶段操作保持原行为。

三个资源堆只展示摆位与堆叠造型，未接入资源库存或供料。原 EX-004 的零材料状态未改；卡堆外观不代表为示意添加了资源。

这些是原 HTML 固定状态的交互呈现，不是实时规则引擎。生产、结算沿原示意脚本；未增加鼠标研磨、资源供料、成牌领取或新的生产规则。筹码详情与历史不在本版范围。
