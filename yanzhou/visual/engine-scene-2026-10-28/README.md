## 本轮做成什么

十件独立imagegen基础组件已全部导入原生Godot场景：木桌、灰绿桌垫、工作台、顶部纸带、确认底板、两组手牌题签和三类筹码。各件保持独立图层，准确文字另排；原PNG和冻结包不改。工作台留两法器宿主与两预留，五列敌我牌面配对，手牌在最下方展开。

场景固定在EX-004首轮生产结束、尚未布牌：敌方四张即时攻击暗牌和一张延时攻击暗牌、己方五空位、手中五护盾一普攻，两组数量6／0；敌生命144／144、玩家60／60、护甲0、施法0／10。读数为美术快照，不是引擎结算产生的结果。暗牌仅显示类别／即时或延时，不暴露隐藏量值与目标。

法器和11张牌为清楚标注的程序占位，未生成或挪用正式法器／卡面；铭文词片、对手手部、书本和炼金陈设仍待后续美术。本轮完成的是完整战斗场景的结构与现有组件接入，生产、布牌、切组、确认结算、存取和终局尚未实现；显示的确认与题签不执行操作。

## 实际核对与剩余

1920×1080、1366×768实际Godot画面已目视核对五列、手牌完整文本、工作台与筹码的层级。1440×900窗口记录的内容视口为1440×810，维持16:9构图；截图来自引擎视口，不包含OS边框或留边画面。所有可见文字在画布内、字宽无溢出、两份打包字体覆盖实际字形且关闭系统回退。

Windows包复制到独立目录后，两档实际运行截图与源码对应PNG字节一致；从干净Git克隆按固定清单恢复10张图和两字体、重新导入后，1920画面也一致。原图／字体哈希、许可、日志与上述证据共52项限定检查通过，不等同52项玩法测试。原v01／v02美术manifest、v06及DM-G002-020固定manifest保持原字节。

首版曾有资源ID格式错误、两端手牌裁切、施法筹码被工作台遮挡和小尺寸纹理锯齿，均已修正；初版日志／截图仍保留于同轮evidence，未删除失败证据。技术细节和恢复命令只在实现仓库维护。
