## 共同画法

| 项目 | 当前基准 |
| --- | --- |
| 轮廓与器形 | 深褐、略不规则的圆墨线，外轮廓强于内部线；主体大形先于材质细节。器物古朴、手制、适度夸张；按实际显示尺寸控制线粗 |
| 色块与明暗 | 少量平涂大色块、概括的两级明暗；高光也用色块表达。玻璃、水线、炭火等必要辨识保留，避免拟真反射和琐碎体积 |
| 配色 | 暖铜、赭土、米白、灰蓝、青绿为共同色域；火焰、红芽等身份色局部突出。颜色服务物件识别，不强行把所有材料涂成同色 |
| 材质纹理 | 少量成组、顺着曲面或生长方向的短线；优先放侧缘、口沿和结构转折。法器中央保持安静，卡面背景纹样低于主体对比 |
| 细节上限 | 主体最强轮廓，纹理不能盖过剪影；不随批次添加铆钉、雕刻、饰环、复杂岩地或额外人物。当前12张图是可直接比较的密度样本 |

原始风格来源为用户指定的[Ways of Alchemy本地图集](<E:/Game/Ways of Alchemy-analysis/2026-10-31/index.html>)。实际使用的样本、角色与SHA分别沿下方两包，第三方原图留原研究目录；本页约束画法，不采纳其配方或游戏规则。

## 保留的制作经验与验收

- 先让题材直接可辨。旧护盾曾误成手抓圆球，水流与风线也容易混淆；具体材料的识别修正留在物品制作页。
- 细小刻纹、复杂铜边、碎纸纹和人物互动会争夺主体；短线成组，法器大面留白，卡面环境降对比。
- 分件会额外要求切口、遮挡面和对齐，宽白光晕会洗掉材质。选定当前画风不延续旧拼接／骨骼方案；后续动画按独立任务实现，基础图不烘焙生产亮光。
- 旧题签、装饰环和固定效果栏不再作为绘画模板。插画无字不等于隐藏必要信息；真实文字使用字体排字，显示职责沿现行合同。
- 保留原画布与PNG字节；宿主等比contain，复用纹理，按接入需求配置无损与mipmap。不把图片比例、留白或alpha当作点击几何。
- 每批用深浅背景和实际小尺寸核对：法器224／64px，独立物品152／64px，卡面155px宽及更小96px宽；主体、器形与物品—卡面身份必须一致。新基准板只做这些视觉与装载检查，不冒称重跑Godot或玩家测试。

当前保留12张源图，全部原字节未改；卡面既有运行副本与交付ZIP也未改。材料仍按每批5件审阅，现有5/32、余27种未制作；法器仅为平炼／白化题材外形，具体内容、占格和接口未定。风格已选与具体资产完成分别记录。
