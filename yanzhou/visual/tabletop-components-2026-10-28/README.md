## 来源与拆分边界

共同设计提交 `9a957634377ef16a4aa713efc808d3bcefc1be7a`。本轮为CUSTOM局部资产制作，仅使用当前视觉入口、文字合同、v06及其DIR-042说明／manifest、首轮HTML的范围说明、资产接入规范§5、DA-1、资产目录与必要操作规则；不加载其他方向、历史或旧3D资产正文，不修改玩法。源为AS-G002-032@HERBAL-ENGRAVING-06的scene-v06.png，SHA-256 `a823bd8c0fd364090d72e776407c79e6c0385702ff550052b1babe6fced2cbe2`，1672×941 RGB PNG。

制作分为两种来源，不能混称像素级分离：

- **直裁派生。** 控件和筹码先从v06可见区域按坐标切取，33个导出分片逐像素核对原RGB不变，筹码只加alpha遮罩；由控件片进一步拼成4个无字底板。没有擦除原字后猜填；底板使用本来可见的空纸面与边框，预览文字由真实字体另排。
- **参考补齐。** 直接拼接工作台透视边角有明显阶差，完整木桌／桌垫也被遮挡，无法仅靠切片恢复。为交付完整底板，使用内置image_gen沿v06分别移除物件并补齐木桌、桌垫、工作台；3个完整层是参考引导的重绘补齐，不声称原图隐藏分层或逐像素同形。准确提示词：[木桌](wood-background-prompt.txt)、[桌垫](felt-mat-prompt.txt)、[工作台](workbench-base-prompt.txt)。

生成原件完整保存在登记的外部制作目录及工具原位置。正式输出只裁透明留白（alpha≥16边界加2像素），保留区域RGBA逐像素不变，未放大、锐化或强制重置原alpha。合成预览的缩放只是接入示例，不把缩放图冒充原生导出。
