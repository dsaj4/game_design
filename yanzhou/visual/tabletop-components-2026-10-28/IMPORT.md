# 基础组件接入说明

AS-G002-034 / TABLETOP-COMPONENTS-01 · 2026-10-28。引擎无关PNG源件包，正式导入只取manifest列明的exports/。源码／原图／试切原件的位置仅作追溯，不是运行依赖。

## 文件与层级

1. `exports/layers/wood-background.png`作为不透明底层。
2. `exports/layers/felt-mat.png`作为透明桌垫层，中间不含卡位或卡牌；牌位／卡面按后续布局独立绘制。
3. `exports/layers/workbench-base.png`整体缩放放在近侧，中央法器后置；两端椭圆是预留刻位，不代表已获得额外法器。
4. `exports/ui/`是4个无字底板；`exports/chips/`是3类固定筹码图。名称、生命、护甲、施法次数和组数量均用真实字体独立排版。筹码画有有限层数，不把画面层数当作实有总数或容量。

3个完整底板为内置image_gen沿v06参考补齐；控件／筹码由可见原像素派生，来源和PNG原生尺寸见manifest。没有把整场静态截图用作运行背景。

## 伸缩与透明

| 底板 | 左／右／上／下固定边距（像素） |
| --- | --- |
| confirm | 32／30／20／22 |
| tab-active | 25／25／16／17 |
| tab-idle | 25／25／14／14 |
| header | 左22、右23、高50；只有中段横向伸缩 |

可直接取`exports/ui/*.png`；需要更细控制时用`exports/confirm/`、`tab-active/`、`tab-idle/`中的九片及`header/`三片。填充纸面与边缘采样需钳制到片内，避免过滤采到片外透明而出现浅缝。没有正式悬停／按下／禁用原画，不能将程序变色描述为已交付的原画状态。

桌垫、工作台按整体比例使用；工作台原图边角带透视，不使用外部试验目录的九片硬拼。透明PNG保留源alpha和贴近物体的轻影；生成层大面积alpha约253，未人为改成255。检查实际合成底色，勿再按黑／白底抠色，勿对原件重新锐化或以放大版冒充更高原生分辨率。

裁片坐标为源图左上角(0,0)起的像素，矩形格式[x,y,width,height]，右／下界不包含。生成层的trimRect按生成原画布记录，不是v06坐标；sceneRectExample仅是合成检查示例，不能作为冻结的命中区或布局参数。

## 验收范围

checks.json记录PNG／alpha／哈希／原像素对应和三种底色及完整层合成检查。preview-components.png与preview-layout.png仅作资产合成取证，其中的文字／数值由预览代码另排，不在正式底板里。

正式引擎导入、触区、纹理压缩／mipmap、所有目标分辨率、完整状态集和用户美术接受尚未验收；法器、铭文词片、卡面／卡背／卡框仍后置。此包不带运行代码、字体文件、玩法引擎或公开发布授权。
