## 本轮目标与边界

将底部持牌→五列布牌→最终确认→逐列结算→列间再布牌做成可操作本机HTML。沿v06构图表达，使用首场真实六张一次性牌，不增加回收牌、材料或第二份库存。原型源文件保存在 `E:/Project/yanzhou-ui-prototypes/first-battle-handflow-2026-10-28/`，不是正式2D游戏工程；本轮授权范围为该UI原型及其浏览器检查，不启动独立玩法实验。

## 本轮应检查的路径

| 操作／情境 | UI原型的预期 |
| --- | --- |
| 原始快照，仅查看／切组 | 六张真实牌仍在手，五列空；生产拍、生命和标记不变；暗牌详情不泄露未揭示信息 |
| 普通上牌到占位／取消互换 | 不覆盖、不吞牌，不触发卡效；显式确认互换才原子移动两端 |
| 桌手互换／单独撤回 | 前者保留手牌原序位，后者追加到组末；其余卡相对顺序不变 |
| 按EX-004首轮顺序布G1、G2、G3、A3、G4并逐次确认 | 留G5在手；五列后玩家60生命／8护甲、敌138生命、5层施法；次轮爆裂后续仅在第5列生成后公开 |
| 列间选牌、撤回后续、交换后续 | 仅未开始列受理，不推进生产、提前翻敌牌或修改已处理列；下一确认仍只结算一列 |
| 结算动画中重复确认或拖牌 | 不发生重复伤害、消耗、生成或跨列；动画收尾后才重新开放未来列 |
| 五列全空，仅逐列确认 | 前四列共8伤，最终玩家52生命／0甲、敌144、0层施法；六张牌仍在手 |
| 键盘／窄桌面尺寸 | Tab和Enter可达必要操作；数字1—5只对合法选择落列，Escape不推进；五列保持清楚，不靠悬停或颜色传递唯一信息 |

以上是原型检查预期，制作完成后才记录实际通过与未测；不回写正式玩法验收的NotRun。
