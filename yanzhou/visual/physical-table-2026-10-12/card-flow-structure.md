## 2. 物件—操作—信息对应

主页面的文字与精确数字分别融入真实卡面、物件读数和刻轴；类别始终保留中文与▲／■／⊘／✱。图形不能替代精确账目，近观不能成为遮蔽现场必要信息的借口。所有点击对象由同一真实身份支撑；装饰、预留和历史痕迹不冒充待生效实牌。

| 对象编号 | 主页面可观察对象与信息 | 操作入口／结果 | 制作建议及限制 |
| --- | --- | --- | --- |
| O1 活动法器 | 蓝晶杖、环杖；当前加工／等待／中断、进度、完工拍；当前承诺与未来用途可区分 | 点击／Enter、1守护／2施法打开CF-12法器近观；未来用途操作仅沿既定合同 | 进度作为法器附近贴附实体的刻度／状态形状；不能另挂屏幕文字面板。两器保持既有原姿态，书／晶球无命中与焦点 |
| O2 玩家实牌 | 有厚度窄卡，公开正面；名称、类别、已知效果、来源、队序与预计拍；最早资格可查 | 点击／Enter或C打开真实队首近观；只是查看，不使用、拖动、改序或选目标 | 卡面与小型来源标识对应法器；不为翻牌演出把已知牌盖成秘密 |
| O3 敌实牌 | r前牌背只含程序位置、r、类别；r后公开正面、T、效果、锁定／无对象 | 点击／Enter进入CF-13暗牌或CF-12公开牌近观 | r前按公开揭示刻位组织，不能按隐藏T提前放置；同类牌背的差异不能编码未知数值／目标 |
| O4 刻轴与容量 | 当前拍、观察／结算相位；实牌、空刻、历史痕迹、预留、待复用明显有别 | 刻轴实体回看／归位入口；历史痕迹点击查CF-12记录近观 | 历史用刻痕／印记加原拍与编号；容量用不同形状的非卡片标记，预留不生成可翻实牌。空刻不生成假牌 |

| O6 桌沿控制物件 | 明确继续／暂停、单步、速度；回看与当前真实拍可辨；系统入口也有实体 | P、Space、左右／Home及同义实体入口；Esc进入系统页 | 推荐独立桌沿机械件和刻轴端件，形制待HTML验证；不是把屏幕按钮透明叠在桌上。不得赋予书／晶球控制功能 |

## 3. 四种时间含义不能混淆

| 时间／事实 | 画面必须说明什么 | 不允许据此推导什么 |
| --- | --- | --- |
| 法器完成并入行 | 完成的是生产，一张真实玩家牌已经进入队列；同拍按真实入行序 | 不代表效果已发生，也不保证下一拍一定使用；t入行最早t+1且仍须队首有资格 |
| 敌牌r揭示 | 从背面变公开正面，形成真实锁定／无对象；之后按公开T组织 | 不扣血、不打断，不把揭示姿态当成T时效果 |
| T到期／玩家合法行动 | 规则按TL-11已经结清的实际步骤被展示；复合牌可能跨组 | 不因卡片视觉先落地就先结算；不能点击逐张推进或重新选择目标 |
| 历史／近观 | 已发生记录与最近结清的当前状态分别可读，查看不推进 | 不复活实牌、不重付、不补翻、不重新演出；浏览刻位不是当前逻辑拍 |

规则先结清，动作只消费事实。主页面精确读数与可操作对象始终对应最近已结清状态；若演出滞后，动作及来源记录带“已发生”语义，不能让旧视觉余额看起来仍可用。暂停、新观察、终局和离场都可以直接取消尚未完成的动作，不等待卡片到位。取消表现不撤销任何已成规则结果。

## 4. 状态编号与完整出入条件

CF编号是本文局部制作编号，不是新规则ID。CF-01—11是物件／事件状态，可与一个全局浏览状态组合；CF-12—20是查看、暂停、恢复或系统状态。后续稿件必须标明组合，例如“CF-03 + CF-14”，不能把二十项误做成必须顺序点击的流程。

| 状态 | 进入条件 | 明确可观察画面 | 退出条件及去向 |

| CF-08 已知牌出牌呈现 | 实际玩家攻击／防护等步骤或到期敌步骤已结清，且正常播放 | 使用同一牌身份做抬起、倾转／翻转出牌；已知牌的动作不是重新揭密。公开卡效入口始终可达，短暂背向镜头不改变公开性；来源指向实际目标 | 与该牌已结清步骤对应的CF-09／10；中途停点直接最新静态CF-14或CF-20。不能为复合牌每步生成、翻动一张新牌 |

| CF-10 落空／回退／中断／等待反馈 | 对应实际失败、回退、中断或等待已发生 | 回退攻击使用实际普通攻击结果并附“不足，已回退”的图形说明；打断指向真实锁定法器；无对象／无批次显示一次落空；无合法目标空放不画命中；缺位仍是法器等待。原因与结果分开，不能全部画成成功强击 | 以真实状态决定留在CF-02、继续该牌独立步骤或CF-11；不重试、不补目标、不退款、不把中断容量显示为当拍可用 |
| CF-11 离场与历史 | 实际该牌最后一步／空放结束并离队，或实际敌牌结清／取消，或终局清理 | 播放中可有一次离场动作；最近状态已不占真实牌位。结束或停点后只留明确“已发生”的刻痕／图形记录，原拍、序号和来源可查；历史不画成可再翻实牌、不占Q | 点历史到CF-12记录近观；下一推进保留可回看的历史，当前摘要可替换。无自动返回队列、无重播 |

CF-08—09不要求整张牌连续独占演出：例如同拍“防护→敌打断→该牌记次”须沿实际日志顺序展示，并保留同一玩家牌身份。只在真实最后一步或空放后离队，容量只释放一次。历史展示也不能把三个完整事件合为一次新的付款。

## 5. 点击近观的首版页面结构

以下为可逆排版建议，固定的是信息义务和入口闭环。

1. **对象区**：静态放大原卡／法器／棋子图形，名称与类别贴其本体；既有卡ID对应同一对象。玩家牌保持正面，暗牌按CF-13单独使用牌背。近观无抓取、翻暗面、出牌或手动目标按钮。
2. **关系区**：用对象小图表示来源与目标，线和中文动词表达加工、自动选择规则、已锁定目标或已发生作用。玩家牌未到生效时，只展示承诺的目标选择规则及预测性质，不能提前伪造“已锁定目标”。敌牌r后才显示真实锁定／无对象。
3. **步骤区**：按真实声明／已发生步骤用图形卡片、类别符号、费用筹码及精确数值表达。明确区分“将执行的已知卡效”和“已结清记录”；复合牌的防护、其余步骤、依赖与失败分支完整可读。必要文字是图形说明，不是整页文字日志。
4. **时间与账目区**：缩略刻轴保留原浏览位置、当前真实拍／相位及对象的合法时间字段。玩家卡列入行、最早资格、预计拍；公开敌卡列r／T；记录列原拍、顺序号与“已发生”。当前余额与历史支付结果分别标识，绝不把旧余额作为可操作数量。
5. **返回区**：明确图形关闭入口和Esc提示，关闭仍停；焦点返回来源。超过可见长度时仅图形页内部滚动，关闭与当前暂停状态保持可达，不能把主要信息缩成不可读小字。

近观页面里的来源／目标图形用于解释；首版不新增跳转任意对象、选目标、抓牌或逐步执行功能。详情中的数量／未来用途操作若出现，沿下一节边界单独设计，不与“点卡查看”混用。

## 6. 键盘、窗口与后续组件边界

| 已有输入 | 本链等价路径与限制 |
| --- | --- |
| Tab／Shift+Tab、Enter | 遍历可见有效3D物件／最上图形页控件，静态轮廓表达焦点；焦点不自动暂停、翻牌或提交。点击与Enter激活同一对象 |

| 1／2、C | 1守护、2施法近观；C真实队首近观，无牌显示图形空态，不创建牌或偷偷选下一张 |
| 左／右、Home | 无字段编辑／弹层时操作刻轴回看和归位，按CF-17；字段编辑优先字段 |

| B、L、D | B仅选中施法时提交已定义未来用途切换；L打开施法次数图形页并聚焦新增锁定数量；D对应真实抽屉把手，静态开合、打开先暂停。书／晶球没有替代快捷入口 |

悬停只给物件静态轮廓／形状反馈，离开取消，不弹悬停文字框、不暂停、不揭示。必须完全不用悬停也能读取和操作。

1080p七列、768p五列仍是显示窗口，EX-002容量Q5独立。主数值分别20px／18px、详情正文至少16px沿既定合同；空间不足应调整构图与可达入口，不隐藏精确读数。两档具体排布、多牌同拍的错位／扇列形制和窗口外对象入口的尺寸将在HTML阶段验证；每个真实对象必须有独立可达身份，不能用无法点中的重叠概图通过。

数量编辑与未来用途的完整操作页可列为后续重点交互链，本轮不细定其构图，但以下约束已经确定：

- 当前批次承诺、已入行牌不随未来用途改变；主页面若可直接切换，入口必须是实体拨片等3D物件，不能复活二维输入层。
- 数量只在相应图形近观页编辑，可键入、±1；新增锁定／解除锁定分开，0禁提交、超量全拒绝。仅锁自有未承诺量，不含未来新增量；不从暗牌或预测制造可消费量。
- 草稿不自动提交；关闭舍弃未提交草稿，已提交待受理操作保留。显示真实“已提交至第t拍／待第t+1拍受理”；失效在下一窗口明确拒绝，不暗改数量或当前承诺。

这些后续排布未完成不阻断首条“点卡—近观—关闭仍停”的HTML示意；它们仍须走文字、HTML、美术、实现四阶段，不能借首条链通过宣布DQ-15—24全部完成。

新战／载入／替换清除旧瞬态；载入的旧记录只作为静态历史，单步只保留有序静态摘要；暂停、新观察、终局先保全已发生记录再清动作。正常继续只演之后新发生的事实，不补取消过的旧动作或声音。

**实现前的工程依赖，尚无运行证据：**每张实牌必须与其生产来源、实际队序、公开目标、r／T状态、历史记录及点击对象持续一一对应；窗口移动和物件动作不能换成另一张同名牌。现有外部说明不足以证明这条3D对应关系已完成。HTML可明确标注静态公开样例，不能用样例冒充工程缺口已修复。缺失表现映射属于开发验收不通过，应在实现仓库诊断；它不是新的玩家错误页、玩法失败或自动暂停政策，不进入CF-19。

模型静态说明支持复用法器／棋子／抽屉，但动作后的姿态、穿插、点击一致性、翻牌和复位仍需真实实现证据。暂停归位必须恢复正确物件姿态，不能让器具变形或错位；静态源结构不是运行通过证据。
