# 轮盘排期与环形进度：输入摘要

2026-11-04 · Promoted / Qualified Presentation。用户已确认手势职责与首次施料落列；[资格记录](../../sources/materials/M-2026-11-04-apparatus-wheel-ui.md)限定呈现范围，不替换现行玩法。具体阈值与轮盘视觉仍为制作候选。

用户意图：尽量沿用既有UI，增加右键可拖动排期的轮盘来展示排程；确认后以圆圈倒计时表达剩余时长。先处理此方向的UI设计，不继续扩展常驻紧凑排程条。

对象／情境：布置窗口内为法器选择开工列、调整未开工批次；开工后在法器附近看剩余进度。预期价值是保留器物主体与桌面空间，减少常驻排程信息。具体操作与可读性尚未验证。

现行约束继承本包README固定输入：同一五列时钟，草稿可改、在制冻结；当前列整体校验后才开工，拒绝保留草稿；D以列计，不能由现实秒数驱动；c至c+D−1占用、c+D可用。模型建议将圆环按已提交列离散更新，未到开工列的已排草稿仍显示等待起列，不能提前倒计时。

## 已确认的输入职责

| 输入 | 用户明确的职责 |
| --- | --- |
| 正常单击右键 | 触发详情，不被轮盘功能取代 |
| 长按右键并向上拖至轮盘格 | 完成排期；移动的是指针选择目标格，不是旋转整盘 |
| 长按左键选中材料并拖至法器 | 完成施料，落点是法器本体 |
| 排期确认 | 保存排期，不推进列、不直接开工 |

用户已纠正上一轮“右键点击开盘、详情移入盘心”的建议，后者不采用。常驻紧凑排程条不再是本次制作方向，既有原型保留为比较稿。

## 手势状态与制作建议

右键按下先进入判定；在长按阈值前正常释放才打开详情。达到阈值后出现上方轮盘，向上进入格子时预览起列、占用终点及最早可用列；推荐在合法格松开即保存排期，并吞掉本次右键释放产生的详情事件，不再增加第二个确认按钮。释放确认方式由“拖至格子完成排期”的输入推导，尚不冒称用户明确指定了具体阈值。

轮盘建议使用上半圆五格，左右顺序与战斗五列一致；中心为原法器落点，避开底部材料手牌。早于光标或被在制占用的起列不能确认；离开合法格松开、Escape、失焦均取消预览，原排期不变。合法排期保存后轮盘收起；草稿缺料和未来起列保留简短常驻标记。

材料长按拿起后跟随指针，只在合法法器落下才改变真实归属；非法落点、Escape或右键取消回原手牌。正在拖材料时右键优先取消，不能同时开轮盘或详情。只保存排期不会提前消费材料或播放生产；实际开工后才锁定批次并用圆环按已提交列更新剩余加工列数。

右键阈值、左键阈值、拖动距离阈值、圆环粗细和弹出位置均是可逆制作参数，待HTML检查；长按前移动的处理不得同时触发点击与拖动。键盘等价路径仍需保留，可通过法器聚焦后的排期入口完成同一操作，具体键位未指定。

## 首次施料落列：已确认

用户明确接受推荐：空闲法器先将材料排入当前待执行列草稿，右键轮盘再改期；当前列被在制占用时不自动找后续列，提示先用轮盘指定合法起列。不采用始终强制先排期的路径。

同器有多个未来草稿时应有明确的当前编辑批次；轮盘焦点及详情提供批次选择，不按最近或最早偷偷改另一批。具体视觉待完整路径闭合后制作。

待核对风险：展开轮盘不遮持牌／确认；右键开盘与拖动取消不冲突；隐藏排程仍能常驻识别未齐草稿与拒绝；跨轮在制不被圆环误读为本轮结束；完成入手与下一列可用不混为同一时点。后续先形成文字与HTML样例，浏览器证据不替代真人理解。
