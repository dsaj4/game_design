# 沿用桌面的长按轮盘UI

2026-11-04 · WHEEL-TABLE-01 · Derived from [合格呈现素材](../../sources/materials/M-2026-11-04-apparatus-wheel-ui.md)。手势职责与默认落列已确认，轮盘外观、阈值及圆环效果PendingReview。

## 主桌与输入

上方保留敌我两行五列、右侧准确计数、下方四台法器和底部两组手牌。原紧凑条收起，不长期挤占器身空间。法器常驻短名、固定产物、草稿缺口或未来起列；实际开工后在器身周围显示剩余列数圆环。完整配方、冻结输入与精确时点通过右键单击查看。

| 输入 | 预览 | 提交与取消 |
| --- | --- | --- |
| 法器右键短按 | 无排期预览 | 正常单击打开详情；不保存排期 |
| 法器右键长按 | 上方展开五格轮盘，指针向上选起列，同步高亮战斗对应列 | 合法格松开保存排期；格外／非法格松开取消，原安排不变 |
| 材料左键长按 | 整牌拿起，法器相容性反馈 | 拖至法器施料；非法落点保留手牌；Escape／失焦／拖动中右键取消 |
| 全局确认 | 本列联合合法性检查 | 全部合法才推进一列并冻结开工；拒绝时所有草稿保持 |

原型暂用右键340ms、左键190ms长按阈值和10px长按前移动容差。它们是待评审参数；长按成立前移动过远会取消，不在释放时补触发详情。一次手势只产生一种动作，长按排期后释放不能再打开详情。浏览器组合按键另检查mousedown／contextmenu，不能只依赖单一pointerdown。

轮盘是上半圆五格，左至右对应当前回合第1—5列，同时显示全局c。指针进入格时显示“c开工→c+D−1列末入手→c+D可用”，同器占用重叠、已冻结列不可保存。轮盘是临时上层，避开底部手牌；它展开期间暂停新的确认输入，避免尚在拖选时推进光标。

## 先施料与先排期

空闲法器未选择排期时，首次施料默认当前待执行列；当前列有在制占用则拒绝本次投料，保留原手牌并提示先排期，不擅自找下一个空列。

玩家也可先用轮盘选未来起列，再拖料到本器。只有选起列、尚未施料时，显示“已选cN，尚未施料”：这是界面目标，不是已排配方、真实材料托管或零材料开工指令。空目标不会自动生产，也不阻塞当前列确认；过了所选列仍未施料则不追赶或自动续期。

材料实际进入草稿后，选中的本批保持明确身份。右键轮盘改排该批，材料随批次改变起列，库存不增减。若同器已有多个未来草稿，编辑带明确选择“新排期”或“cN草稿”；不按最早、最近或器身位置偷偷选择另一批。编辑带仍提供逐张退料、整批撤回与键盘等价入口，既有草稿不会因切焦点丢失。

## 圆环表达什么

圆环仅对实际在制批次显示。填充比例为剩余加工列数／本批冻结D，文字显示“余N列”；每列结清后更新，在无时限布置窗口内保持静止。跨轮不归零或重新填满；在制期间保存另一未来草稿，也不能重置当前批次圆环。

例：E1于c1开工，c1结清后余3列，c4列末完工入手，c5可用。完工时圆环退出，产物进入真实持牌；不是从圆环取出另一份卡。未来已保存草稿只显示待开工c，不提前运行倒计时。缺料草稿保留缺口标记，不用“暂停的生产环”误示已经开工。

## 四个关键状态

1. **默认施料**：长按汞拖到空闲E1，手牌减一，形成当前列1/2草稿；缺疗伤草时全局确认拒绝。
2. **右键改期**：长按E1右键，向上进入第3格，松开只把所选草稿改至c3；没有揭牌、推进、扣费或开工。
3. **在制续排**：E1在制环照常显示，当前列不能追加新批；先选无重叠的未来列，再施料，两个批次身份分开。
4. **取消与详情**：短右键详情；长右键格外松开取消；拖料中右键只取消材料拖动。三者不串触发。
