## 一眼能看见什么

上方继续是敌我两行五列，右侧准确计数；中下方四台法器并排，底部两组持牌与确认。法器是生产区的视觉主体，每台下面都有一条五格排程条。主桌不常驻六行大表，也不把排程藏进右键详情。

| 宿主 | 常驻信息 | 焦点时补充 |
| --- | --- | --- |
| 顶部 | 序幕／战斗回合、下一列、全局c | 不另设生产时钟 |
| 战斗区 | 原有敌我两行、五列标尺、当前边界、合法信息 | 选战斗牌时突出未开始列 |
| 每台法器 | 器身、短名／固定产物、在制或草稿状态 | 选中后突出整器及本器排程，不打开详情窗 |
| 每器五格条 | 当前回合1—5、同一个下一列标记；草稿起点、占用与跨轮续接 | 选材料即显示相容器；起列预览给完整c范围和可用列 |
| 生产区下缘的共用编辑带 | 所选法器名称、固定用途、D与圈下限摘要 | 选中批次时显示真实材料／缺口、开工—入手—可用时点，提供撤回；只展开一器，不遮别器条 |
| 底部 | 两组真实数量、持牌、分页、当前选择 | 选牌抬起，卡名和基本效果保持露出 |
| 确认区 | 下一列、确认按钮、最近拒绝原因 | 拒绝时指向问题器和草稿；多个问题均列出，不只报首个 |

四器工序仍有各自逻辑行，只是压缩到各自器身下方；四条均使用同一回合刻度和全局c，不可各自滚动到不同时间。点击某器的第3格，战斗区第3列同步高亮，建立时间对应。批次跨到下一轮时标“续至cN”，换轮接续真实在制；不把页边当完工。

## 操作顺序

1. 选择手牌。可投料的法器与其可起列位置出现预览，战斗牌同时按权限给战斗落点；不先自动从手里扣料。
2. 点击法器排程条的目标起列，或拖到该格，提交一张材料。只落到器身不猜起列，提示在下面选择列位。材料从手牌移入草稿，不当场开工。
3. 共用编辑带显示“已排／所需”和实际材料。继续添加、撤回某张、撤回整批或改排起列；都仅限未开工草稿。改排预览冲突，失格保留原位置。
4. 按全局确认。联合校验当前列所有新工序及合并费用；合法才一起冻结并推进战斗。某器缺料则所有新批次均保持草稿，时间与暗牌不变。
5. 工序结束后产物进入对应持牌组；完工标记留在条上作为记录，不能拖出第二份。下一列玩家再手动安排产物。

选器是聚焦和排程操作；右键／详情键查看完整说明。拖动中右键、Escape或失焦取消，松手不落位。键盘沿Tab进入具体格，Enter落位；Backspace撤回草稿，具体键位仍是候选。批次在制时编辑带只读，不因为占用位置在光标右侧就可撤。

## 紧凑条的视觉语言

| 状态 | 五格条 | 编辑带 |
| --- | --- | --- |
| 未排 | 淡刻度与空格 | 当前固定配方与D |
| 草稿未齐 | 起格虚线菱形＋1/2；预估占用用虚线相连 | 列出已排材料及缺项，提示确认将被拒绝 |
| 草稿完整 | 起格2/2，仍保留虚线／草稿身份 | 可撤回、改排；不显示已开工 |
| 在制 | 锁记号＋实线占用段；已走段压暗 | 冻结材料、开工c、入手列末、可用c |
| 完工 | 末端入手标记，条段压暗 | 已入手事实，说明旧条仅为记录 |
| 拒绝 | 问题器与当前起格同时描边，加缺口符号 | 明确原因和补齐／撤回／改排路径；不能只闪一下 |

色彩之外还用虚实、锁、计数与位置区分。条不靠现实时间持续填满。具体实例：E1在c6开工，四格占用c6—9，c9列末入手，c10可用；这三个时点始终在聚焦带明确呈现。

## 背包与炉心放在哪里

战前保留独立的同桌配置查看状态，展开8×5真实网格、炉心圈、最远格及实际拖慢格；提交后回到两行战斗＋四器生产区。战中“配置”入口只读回看冻结布局，不占用常驻生产区空间。法器生产区不是运输网格，器身展示尺寸不定义占格或炉心距离；两只曲颈瓶保持独立实例和固定产物。此项为本方案的呈现候选，不变更装载／空间规则。

## 尺寸与需要审阅的风险

1920基准保留较大的战斗卡面与四器形体；1366目标每器约240px以上宽度，五格落点约40px以上。法器下方编辑带固定高度，展开不顶起持牌、不盖确认。材料名、到货时点和拒绝原因用真实文字，不塞进40px小格。

优先检查：四器都有草稿时能否找到当前列问题；一器在制、一器缺料时不误认全部冻结；跨轮条是否被误认为已完工；切换焦点是否丢草稿；曲颈瓶同图不同产物是否清楚；法器与上方战斗列的时间对应是否直观。后续HTML测量只证明布局与输入，玩家理解须另有授权验证。
