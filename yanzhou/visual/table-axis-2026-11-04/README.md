## 当前交互

- **单击右键**查看法器详情；**长按右键约340ms**后向上拖至轮盘格，松开保存排期。长按成立前不打开详情，格外松开／Escape／失焦取消。
- **长按左键约190ms**拿起材料，拖到法器施料。空闲且未选排期时默认当前待执行列；被占用则保留材料，提示先排期，不自动顺延。拖料中右键只取消。
- 保存排期不推进列、不揭牌、不实际开工；全局确认仍检查本列所有新批次。实际开工后，器身圆环显示剩余加工列数，布置窗口静止，跨轮接续。
- 多草稿通过编辑带显式选择“新排期”或“cN草稿”；可逐张退料、整批撤回。键盘可选材料后用“投入所选材料”，排期轮盘可通过Tab／Enter保存。

阈值、轮盘形状、圆环外观均为可逆制作候选。法器仍为原创SVG占位；卡图是已有AS-G002-042原字节内嵌，仅作比例与空间参照。上方审阅选择器加载独立快照，不证明完整首战路线已运行。
