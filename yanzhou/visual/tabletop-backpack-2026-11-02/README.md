| 重点 | 可操作结构与反馈 |
| --- | --- |

| 放料与归属 | 材料左键选择后点击专属供料格，或整件拖入；非法放置拒绝，手→待料→在制→产物入手各有独立状态 |
| 法器命中 | 按实际本体格受理查看；L形透明空角不拦截其中的待料，主体图不代替占形 |

| 逐列 | 每次确认一列，收尾停在列间。引燃原实例回手，可再放后续列；旧位置只读，下一暗牌不提前揭示 |
| 回看与恢复 | 结构审阅中保存／恢复本稿状态；记录快照可只读回看，返回后继续原状态，不重复补料或产牌 |
| 战果重装 | 独立加载EX-005安全路线的战果规格快照；取消供料预留，四台设备＋原引燃共14格；不是本稿已经完成完整战斗的证明 |

普通左键负责选择／规则允许的操作；右键或`I`查看，Escape返回。拖动中右键或Escape取消，随后松手不意外落位。`R`为本稿材料旋转，Backspace在合法窗口收回所选行牌／待料；完整操作见HTML帮助及[外部技术说明](E:/Project/yanzhou-ui-prototypes/tabletop-backpack-2026-11-02/README.md)。`I`、详情窗口与关系显隐均是可逆制作候选，不冒称用户已选定具体键位或样式。
