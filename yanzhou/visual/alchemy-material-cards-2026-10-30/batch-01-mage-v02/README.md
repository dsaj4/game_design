## 角色与互动

法师造型直接参考[护盾AS-G002-038](../../shield-card-production-2026-10-30/README.md)：灰赭粗布袍、灰褐宽兜帽、暗砖红披巾，脸藏阴影，衣装朴素且磨损。五张不增加尖帽、法杖、华服或明确面部设定；以动作建立互动，不把人物独立贴在材料旁边。材料仍承担主要识别。

| 材料 | 本轮构图目标 |
| --- | --- |
| 水 | 法师跪在水流后侧，手掌引导流水在指前转弯，水带与滴溅保持主形 |
| 火 | 法师俯身以双手引火星落入焦木，燃烧的火焰是主形 |
| 土 | 法师按住土缘并拢回滑落土粒，表现松散土层的塑形与承载 |
| 风 | 法师手势、披巾与羽叶同向回应气流，用经过角色的风痕取代厚水带感 |
| 草 | 法师扶稳草茎、靠近新芽，茎叶与手掌形成照料关系，绿色叶片仍完整可见 |

动作仅用于本轮视觉演绎，不写入材料卡效、配方、法师技能或人物背景。01版素材及固定ZIP不覆盖；全量32身份与后续27种队列保持。
