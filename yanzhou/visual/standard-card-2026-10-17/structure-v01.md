## 2 正面的五个区域

以下为相对层级与承载关系，具体像素留到HTML结合真实投影确定。

| 区域 | 内容 | 主次与规则 |
| --- | --- | --- |
| 顶部识别区 | 短名；类别符号＋中文类别 | 名称回答“哪张”，类别回答“哪类行动”。攻击▲、防御■、打断⊘、其他✱沿现行定义，不因图形化删去中文类别 |
| 中央主体区 | 一幅主体图 | 使同类牌和不同作用可辨；图中细节不承担精确数量、费用或结算时间 |
| 下部主效果区 | 固定效果的图形＋准确量值，或条件图形 | 固定伤害显示伤害量；获得护甲显示护甲增量；无数量的打断用作用图形与短动作，不伪造“0伤害” |
| 底部后续区 | 已声明的后续效果、依赖提示 | 例如“成功后”＋施法次数图形`+1`；它属于卡效，不是剩余时间或已经到账的余额 |
| 外沿状态区 | 条件、公开／锁定、失效或已发生状态的必要提示 | 形状与短语组合；只在适用时出现，不遮名称和主效果，不把卡变成操作按钮 |

```text
┌────────────────────────┐
│ 类别符号＋中文类别       │
│          主桌短名        │
│                        │
│          主体图         │
│                        │
│ 固定图形＋量／条件图形   │
│ 后续收益与依赖（如有）   │
└────────────────────────┘
  状态签绑定卡边，不覆盖正文
```

当显示名与类别相同，例如敌牌短名“攻击”或“打断”，可合并为一处“▲ 攻击／⊘ 打断”，避免同词重复；完整身份在近观保留。玩家“护盾”与类别“防御”含义不同，保留分工。

## 3 字段在不同阅读层的分配

| 字段 | 主桌卡面 | 聚焦／悬停 | 近观必需内容 |
| --- | --- | --- | --- |
| 名称 | 短名 | 完整名称可查 | 全称、所属方与真实来源 |
| 类别 | 符号＋中文类别 | 保持同一含义 | 类别说明；不以类别推断所有步骤的结算组 |
| 主体图 | 稳定识别图 | 静态轮廓辅助选中 | 同一主体图，不换成另一套卡身份 |
| 固定主效果 | 图形＋准确量 | 可显示一句明确作用 | 对象、单位、普通伤害／护甲等作用性质 |
| 条件与分支 | 条件图形；不展示分支结果或实时猜测值 | 名称＋“含条件”，沿原短提示限制 | 完整检查时点、付款者、资源、门槛、支付、所有结果与回退 |
| 后续效果 | 依赖提示＋图形及量，已有才显示 | 可解释依赖关系 | 完整前置、先后顺序及终局停止条件 |
| 目标 | 不把玩家尚未选定的目标画成已锁定 | 仅显示规则允许的公开状态 | 玩家目标规则；敌方已锁对象／无锁定及失效处理 |
| 制造与来源 | 不放通用“出牌费用”角标 | 来源名称可查 | 玩家法器行动卡的配方／是否零材料、本批D、批次张数、承诺用途等对应已知信息；与生效支付分开。敌方程序牌不生成虚假的制造参数 |
| 时间与队序 | 时间由合法刻位承担；不印D／T／r／预计几拍 | 可高亮相关刻位与来源 | 入列、最早资格、预计生效或敌方公开时间的图形关系与准确数字；暗牌仅公开允许区段 |
| 运行状态 | 必要边签与形状 | 当前公开状态及简短原因 | 完整失败、取消、空放或已发生记录 |

本轮只定义“近观应承接哪些卡面信息”，不设计近观整屏、分页、关闭和编辑区域；这些留到详情页模块。主桌信息移出卡面后仍必须准确可查，不能借简化删去字段。

### 显示名映射

| 近观全称 | 主桌显示名 | 备注 |
| --- | --- | --- |
| 简易护盾 | 护盾 | 主效果是获得护甲，不是生命恢复 |
| 简易攻击 | 普攻 | 与强化保持不同名称 |
| 强化打击 | 强化 | 仍是条件牌，不代表当前一定获得强化结果 |

## 4 条件图形与费用的语义

条件牌在主效果区使用专属的分叉／门槛图形，和固定数值牌保持不同轮廓。推荐在图形中结合施法标记的小印记及门槛数字`5`，表示这张牌需要在生效时检查条件；具体图形形状为制作建议。

- 条件图形表示“这里存在需要查看的规则”，不表示费用已支付、已有预留或结果未知尚未揭示；不使用敌暗牌的眼形／牌背纹样，也不以问号代替已知规则。
- 门槛`5`属于施法次数条件，不是制造材料或手动出牌费用。主桌不把`−5`单独挂在牌角，避免看成已经扣款。
- 不显示`18／6`、只显示`18`或只显示当前可支付分支的伤害。当前余额改变时，卡面仍保持条件标识，完整分支在近观查。
- 主桌固定后续`+1`仍可显示依赖提示；它不补足这一次支付。攻击致死后不再记次等完整边界在近观明确。
- 只有实际事件已结清，目标反馈或历史才可显示本次真实支付及结果；该记录与仍在队列中的卡面分开。

没有生效费用的卡不堆“0费”角标；制造时已付的材料不重复写成行动额外支付。未来内容如果有不同费用，必须挂到对应步骤，不套用本例门槛或回退。

## 5 首轮实际卡牌的文字内容

以下数值只沿EX-001／EX-002固定案例，不扩为发行池默认值。方括号表示未来图形位置，不是需要在画面上印出的字符。

### 简易护盾

| 层次 | 文字结构 |
| --- | --- |
| 主桌 | `■ 防御`；短名`护盾`；盾主体；`[护甲] +4`；后续`成功后 [施法次数] +1` |
| 近观全称 | 简易护盾 |
| 近观作用 | 对存活玩家自身：防护步骤获得4护甲。该步骤成功且战斗未终局，后续增加1施法次数。 |
| 失败／支付 | 无合法目标时空放离队，不执行依赖记次；本例无额外生效费用。制造与入列不触发记次。 |

“护盾”是已有卡名，状态与量值的正式单位仍用“护甲”；主效果不写“盾4”而让玩家猜是获得量还是当前总量。

### 简易攻击

| 层次 | 文字结构 |
| --- | --- |
| 主桌 | `▲ 攻击`；短名`普攻`；攻击主体；`[伤害] 6`；后续`成功后 [施法次数] +1` |
| 近观全称 | 简易攻击 |
| 近观作用 | 对存活的来源敌人造成6普通伤害。该攻击步骤成功且战斗未终局，后续增加1施法次数。 |
| 失败／支付 | 无合法目标时空放离队，不执行依赖记次；本例无额外生效费用。 |

牌面6是普通伤害量，不是承诺扣6生命；普通伤害仍先护甲后生命。实际扣血、护甲变化和支付用各自结果反馈表达。

### 强化打击

| 层次 | 文字结构 |
| --- | --- |
| 主桌 | `▲ 攻击`；短名`强化`；强化识别主体；`[施法条件图形]`；后续`成功后 [施法次数] +1`。没有大伤害数字，没有18／6。 |
| 近观全称 | 强化打击 |
| 近观前置 | 生效时先检查合法目标，再读取当时可消费的施法次数；玩家锁定等不可消费部分不算可用。 |
| 分支一 | 可消费施法次数至少5：消耗5，造成18普通伤害。 |
| 分支二 | 不足5：不消耗，造成6普通伤害。 |
| 后续 | 攻击步骤成功且战斗未终局，增加1施法次数。先支付／攻击，后记次；后续新增量不能补本次门槛。 |
| 失败 | 无合法目标：不支付、不攻击、不记次，空放离队；不把无目标误写成“不足5则仍打6”。 |

近观必须同时列出两个分支，使用完整资源名称与准确量；不能只展示当前余额满足的分支。切换法器未来用途不预付5层，不改变已有普通牌。

### 敌方三张攻击牌

主桌统一为`▲ 攻击`、攻击主体、准确伤害量和必要公开状态。当前案例的三张公开牌分别为10、6、8普通伤害，近观全称分别为蓄力攻击、快速攻击、持续攻击。**“持续攻击”在本例仅结算一次，不表现成多次伤害、周期标记或持续伤害层数。**

目标在揭示时锁定；卡面只表达已经公开的锁定／无锁定状态，聚焦可关联实际对象。完整目标及取消条件在近观查，不能因锁图形出现就增加直接取消按钮。

### 定向打断

主桌可合并显示为`⊘ 打断`，主体体现工序受阻；主效果区使用断环／中断图形，不显示伤害数字。已公开且锁定时关联对应法器；无锁定对象时保留“无锁定”短状态，不能把后续新出现的目标自动补进去。

近观写明：作用于已锁法器到期时正在加工的一个批次，中断该批次；到期无对应对象或无批次则落空，不改选、不等待、不转伤害。普通护甲不抵挡这一单列打断，是否有特别保护按合法内容。锁定法器不等于锁定永不变化的批次，不能把旧批次图当成唯一作用对象。

## 6 未揭示背面

采用统一背面结构，只放允许公开的字段：**程序位置、中文类别＋符号、揭示时机的图形定位**。

- 背纹保持抽象、统一。类别相同的背面不能借图案、磨损、大小、颜色或边饰区分将来效果量、延迟、目标或具体攻击名称。
- 程序位置使用“序2”等短标识，不把独立数字摆成费用；它不是全局卡牌编号或剩余时间。
- 揭示时机由背面牌的公共刻位表达；聚焦／近观只呈现合法的揭示端点，不显示未公开生效刻位、Δ、量值或锁定目标。
- 背面不放正面名称、主图剪影、假伤害占位或分支框，避免从“空着的版式”推知隐藏内容。
- 暗牌近观保持背面，查看不推进、不揭示。玩家已经知道的行动牌维持正面，不借使用翻面再次制造未知信息。

例如程序2的攻击暗牌：背面保留`序2`与`▲ 攻击`，对齐公开揭示刻位4；其10／6／8等具体量和生效刻位在此状态均不显示。

## 7 状态与原效果分开

| 状态 | 表现与信息边界 |
| --- | --- |
| 普通排队 | 正面字段稳定；主桌位置是当前预计生效，不在卡面重复预计时间 |
| 当前聚焦 | 静态轮廓与名称；不提交、不暂停、不出牌、不泄露暗面 |
| 公开敌牌锁定 | 小型锁定状态与实际公开对象关联；不能把同一图形套给玩家尚未选定目标 |
| 无锁定／目标失效 | 中文短状态＋可辨形状，完整原因近观；不改写牌的原卡效 |
| 正在合法使用 | 原位强调；数字仍来自规则，不由翻面或动效再次支付、伤害或记次 |
| 实际空放／支付失败 | 静态记录说明具体原因；依赖效果不执行与独立合法步骤分别按规则，不将一种失败推广到全部牌 |
| 已取消 | 仅在真实合法取消已发生时显示“已取消”；保留原空档，不补发；不新增玩家点击取消入口 |
| 已执行／历史 | 使用无实牌厚度的痕迹与记录；历史不是占容量的实牌，不能再出牌或消费 |
| 合法量值为0 | 如果该字段的规则量值确实为0则保留0；与“无数值作用”“没有对象”分开。不能用本次实际扣血0覆盖原普通伤害6 |

本轮不定义一套新的按牌手动操作。点击／Enter查看仍先在完整事件边界暂停，关闭仍暂停并回到原对象。暂停、单步、失焦、载入、回看和终局均静态显示真实末态；条件标识、数值和失败原因在静音／减动效下保留。

## 8 可读性与图形约束

- 主体图先复用已登记纸底、现有主题图和实际字体；新图形需要制作时再按DA-1登记。本稿不新增纸牌模型或资源编号。
- 插画、类别、名称、主效果和后续效果分层，边饰不进入文字安全区。主效果数值保持现有1080p至少20px、768p至少18px的必要读数要求；近观正文至少16px，具体名字行宽在HTML测量。
- 各类别继续使用规定符号与中文。额外伤害／护甲／施法／条件图形有固定含义，首次可由焦点、图例或近观查到，不能只靠红绿颜色。
- 主效果和后续区位置稳定；没有后续效果时不制造空的“+0”或无意义收益栏。条件牌在主效果区用不同轮廓表达，不让空缺大数字看成内容加载失败。
- 单张复合牌仍是一张牌；多个步骤按真实组别／顺序解释，不拆成两张卡，不从印刷行序推翻防护先行规则。
- 主桌与近观共用同一卡牌身份、短名映射、类别和作用字段。放大后可增加说明密度，不能出现不同量值或另一套规则。

## 9 HTML阶段的核对清单

本节是下一阶段制作要求，不是已执行的测试结果。

1. 按真实主桌牌宽与近观尺寸展示同一张牌；两档视口分别核对，不将放大稿缩小就宣称可读。
2. 覆盖护盾／普攻／强化条件图形／敌方三攻击量／打断／同类别暗牌。特殊零量、无锁定、已取消等仅作适用状态示例，不新增真实卡或操作权限。
3. 强化主桌没有18／6或单个推算伤害；点击／键盘进入近观后能找到两个完整分支及失败说明。
4. 普攻的6、护甲的+4、后续施法次数+1有明确单位与依赖，时间／阶段字不再挤入该区。
5. 暗面／暗牌近观／焦点提示与窗外表示都不泄露未公开信息；相同类别背面不能反推具体效果。
6. 玩家／敌方、主效果／后续效果、条件／已支付、当前牌／历史痕迹，在灰度和静态下仍可分。
7. 点击和Enter只查看，不消费或改变牌序；暂停／关闭／回焦点沿既有行为。此轮不设计详情页整屏。
8. 与UI-REVIEW-02的CARD-01及TXT-02／03真实状态并列核对；新候选单独版本化，不覆盖B13固定截图。
