## 布局与功能

推荐先沿用这版“上方敌情、中间交锋、下方生产与队列”。视觉假设是让玩家在同一屏内比较威胁截止、当前承诺与下一张行动；尚未通过玩家验证。

| 位置 | 功能与常驻摘要 | 点击后查看或调整 |
| --- | --- | --- |
| 顶栏 | 当前拍、阶段、运行／暂停；右上全局控制 | 暂停／继续、速度、设置／说明、战斗菜单；速度数值暂未选定 |
| A 左上敌人 | 简笔主体、名称、生命；有真实标记时在宿主两侧显示 | 敌人及其状态来源；无标记时不铺空账本 |
| B 上方敌方程序 | 按程序位置排列；已结算项收窄，未结算项突出。未揭示仅位置、翻开拍、种类；揭示后完整效果摘要、T、剩余拍和锁定对象 | 完整效果、取消条件、锁定法器、危险开工带。打断卡与被锁定法器用相同编号关联 |
| C 中左玩家 | 生命／护甲独立数字；正负标记在宿主左右，同类砝码聚合显示数量 | 实有、上限、来源、消费锁定与可消费余额；只有存在时展开冻结、待释放和未来登记 |
| D 中部交锋 | 当前生效行动、目标与变化；平时只留最近结果 | 结果追溯；选择对象时改作详情区，暂停后阅读 |
| E 左下法器 | 器具、加工／等待、当前批次、起止拍／D、预留、未来用途和等待原因 | 配方、铭文／辅槽只读详情；合法未来用途调整，不给单法器暂停、主动取消批次或战中重铭 |
| F 右下行动 | 只画真实已入行牌，左边先行动；来源、效果、入行、最早资格及预计生效拍 | 目标、完整步骤、费用与失败分支；容量在独立横条记账，不画成未来牌序 |
| G 底边 | 本场资源摘要；EX-001 收纳为“0材料／无需材料” | 通用资源信息的入口位置；有材料的完整资源管理不在这版展开 |
| 右下记录 | 不占主战场的结算记录入口 | 按事件解释防护、伤害、支付、打断、落空及来源 |

图中控件只是结构符号，没有点击行为。护符形状、人物和砝码线稿都是占位；砝码图标表示同类聚合，精确层数以旁边数字为准。箭头表达生产转入队列／行动结果方向，不表示允许拖拽排序或手动施法。

## 展开与小尺寸处理

- 主视口候选为1920×1080（16:9）；图纸1920×1200，上下额外区域是评审标题与图注。主框等比放入图纸，不是将1200高设为游戏窗口。
- 详情默认关闭，一次只开一个。D区可左右分栏显示“当前承诺／未来选择”，不遮挡B区截止、E区器具入口和F区队首。局部稿列的是完整字段与反馈；次要配方解释可在D区内展开／滚动，标题、关闭、应用操作固定可见。实体布局与滚动尚待交互原型验证。
- 1366×768候选适配：保留区域锚点，收窄已结算敌牌，法器保留当前产出／完工／未来用途三行，队列首牌完整、后续牌压缩；说明性文案移到详情。只显示当前真实牌数，不为Q5固定铺满五张空卡。
- 不把整张1920图缩放当作小屏适配。小尺寸实际布局与键盘操作未执行验证；Windows键鼠优先，不扩展到手机布局。
