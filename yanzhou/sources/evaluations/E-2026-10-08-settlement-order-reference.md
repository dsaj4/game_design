## 主要风险与替代比较

- 整卡原子结算会使“攻击牌附带防护”绕开或违背已定大类序；全按卡面种类又会让同一防护因标签不同改变时点。因此按效果步骤分组，并禁止依赖逆越阶段。
- 定时效果一律提前会让定时伤害越过防护；一律延后又让它无法为当拍后续消费供层。因此按同一防护／其余分组，每组内定时优先。后组加层不能补救前组防护支付，这是有意取舍，须预告。
- 一击及一层反应结清后检查终局，可解释双亡而不让余下连击、收益或完工继续。普通动作不等待整张牌完结；反应不再引发反应，抑制无限回击。
- 维护放在完工后、开工前，已托管承诺不被抢；先维护仍工作的旧对象，再恢复休眠对象。不提供公平轮转，饥饿风险留内容预算。
- 承诺标记仍受合法失效，但不追缴替代层数、不重算D，避免隐形二次费用；过期的承诺不可通过打断复活。此项不授权驱散能力或改变上限。
- 恢复必须记录步骤及登记顺序，不能仅记当前拍；文档合同不能证明存档实现正确。

## 条件情境核对

以下为文档推导，不是运行结果；具体反应与数字仅为已声明内容的条件前提，不发行实体。

| 输入 | 唯一预期 |
| --- | --- |
| 防护需甲，甲到本拍其余定时步骤才增加 | 防护先检查不足并失败，稍后加层不重试；后续合法开工可以读取 |
| 既存定时防护、敌方攻击与玩家攻击同拍 | 定时防护先兑现，再敌方、再玩家；任一事件终局立即停止 |
| 同卡先产甲再付甲，两步都在其余组 | 按声明次序，后步可支付；不能把后组产甲倒流给防护组 |
| 第一击及合法反应后施法者死亡 | 当前事件结清；后续击不执行；同点双亡玩家败 |
| 维护失败进入休眠，本拍还有恢复阶段 | 不在同拍恢复再试一次，下拍才重新进入恢复候选 |
