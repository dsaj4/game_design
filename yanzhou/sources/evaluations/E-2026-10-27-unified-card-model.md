# 评估：统一卡牌、手动上行与回收

2026-10-27 · Evaluation / GDD-0。对象：[P](../proposals/P-2026-10-27-unified-card-model.md)，合格来源：[M](../materials/M-2026-10-27-unified-card-model.md)。评估人：agent；新取舍由用户决定。共同版本沿输入摘要，静态设计评议，不是玩法验证。

## 快速结论

**推荐推进至Draft Change审阅。** 用户已给出可见行为，统一身份与直接合成有清楚的设计联系；但即时回收、全手动上牌会改变整场决策结构，必须同时处理窗口、费用、容量和材料归属，不能作为纯术语修订回写。

## 评估维度

| 维度 | 判断与代价 |
| --- | --- |
| 核心动作清晰度 | 生产到手→选择上行→执行后回手／移除，比先区分资源与行动更直接；两组手牌仍须清楚显示三种权限 |
| 实现可能性 | 可用有限状态描述，但本轮不读代码、不作工程量估算；恢复必须记录同一实例的所在区及本次使用事实 |
| 可玩性潜力／决策深度 | 同一张牌可反复战斗或被合成消耗，有潜在机会成本；若一个可回收效果重复五次总是最佳，生产与新卡选择会退化 |
| 反馈强度 | 原牌回手、消耗及新产物可追溯；必须区分回收原卡与生成另一张卡，卡效成功与库存变化也不能混为一件事 |
| 范围控制 | 三权限及两视图可先闭合，不需要全卡池；不额外加入抽牌堆、弃牌洗牌、战中重铭或维护扩展 |
| 扩展潜力 | 同一身份可同时具有战斗效果和材料性质；须保留配方匹配与明确费用，不能变成所有卡任意合成 |
| 风险可验证性 | 去向预测、五列重复使用、留牌／合成对照可用很小的情境检查；操作负担与平衡仍需另授权验证 |
| 市场参照／差异化 | 未开展外部产品研究，不打虚构分数、不作市场成功推断 |

## 主要风险及建议

1. **立即回收与关闭编辑冲突。** 建议每列收尾后提供明确出牌窗口，当前列及已处理列不可改，下一暗列仍未公开。代价是增加最多四次列间停顿；不能再声称一键自动结完五列的体验完全保留。
2. **旧费用与容量变成隐性强制操作。** 首场首轮产六张，若保留H3且都先入手，等待生产完将先烧三张；若上牌仍每次1点且仅3点，无法铺满五列。建议取消这两项限制，以列数和实际产物限制使用；新手牌膨胀与免费调序仍需评估。
3. **可回收牌挤掉生产价值。** 一张牌回手后填后续空列，可能在一轮用五次；效果支付每次重检，生产次数与施法次数不相等。建议保留这个风险可见，首场现有三种牌按原一次性行为映射，不擅自给护盾无限复用。
4. **配方消费与回收相互矛盾。** 建议回收只描述战斗使用后的去向，作为普通配方耗材仍会在完工消费；合成不能同时保住输入。尚在战斗行的牌不得被自动配方取走。
5. **取消中介行动改变链条预算。** 建议合成直接产其物件卡，保留D、消耗与新输入最早下一生产拍可用；每道合成不再强制占一列，旧资源链平衡论证因此不能继承。
6. **旧案例造成假覆盖。** EX-004仅能沿用真实初态、卡效及敌表来源；新操作路线、手牌库存、无操作败路须重新形成设计预期，原第9轮胜／第14轮双亡不自动保留。无材料首场不能覆盖三权限或合成。

## 最终建议

进入[D](../draft-changes/D-2026-10-27-unified-card-model.md)的具体文本审阅。C1—C5沿用用户明确决定，六项新增取舍成组判断；不要求重新同意已确认的回手和持牌展示。新合同依赖这些答案，完整权威迁移在闭合后一次同步，避免混合旧3点／H3与新手动回收规则。

本轮没有制作或运行最小原型，也未进行数值模拟、真人观察或工程验证。未来验证范围沿P，全部Hypothesis / NotRun。
