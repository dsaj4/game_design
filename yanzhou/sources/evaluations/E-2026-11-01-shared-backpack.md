## 快速结论

**推荐推进限定规则采纳。** 用户已明确要求正式纳入现行设计；共同网格及阶段关系可以落为权威规则，实际网格、全套装载和售卖操作仍须补齐后才能交付完整跨战玩法。规则采纳、实现与体验验证分开。

## 玩家动作、反馈与核心取舍

玩家先把实际携带物装进同一张网格，再选投入卡入手并展开本战生产配置，胜利后重新比较留存。带前料、备用设备或散装核心会挤掉其他携带选择；嵌入核心节省其额外1格，但仍须真实副本和兼容法器。

预期体验是能解释“为什么带这件、放弃什么、先前准备缩短了哪段工序”。这仍是Hypothesis；投入卡进入无硬上限手牌后不保留虚拟占格，所以本次规则不保证前料整场持续挤占生产空间，也不凭空增加投入上限或强制消费。

## 评估维度与系统接口

| 接口／维度 | 判断与处理 |
| --- | --- |
| 动作与范围 | 装载→投入／展开→战斗→战后重装明确；同一网格替换原生产／携带分账，不替换EX-004初态 |
| 卡牌与配置 | 共用空间，不合并身份／取得资格。卡牌仍须独立携带资格；法器、核心、辅助不变成普通材料，金币不新增格子占用 |
| 核心与备用 | 散装核心1格、兼容嵌入额外0格；所有携带备用配置占包内空间。非法拆装不能吞物件或产生包外临时仓 |
| 生产与手牌 | 投入卡真实离开背包；手牌无硬上限，待料仍用实际供料格。战中未投入物只读，自动补料不能从包内偷取 |
| 经济与领取 | 旧配置可出售替换原绝对“无出售”；不由此推定地点、价格、任意时点、免费遗弃、回购或重复交易。满包／领取衔接未闭合 |
| 保存与一致性 | 记录阶段、物件归属、格子、装配、投入和各提交事实；恢复不复制、不重领、不重卖。旧分账存档没有明确迁移规则，不静默换算 |
| 实现与可玩性 | 可据已定边界拆解设计任务，但全套几何、内容与交易缺口仍阻止完整跨战实现；无实测证据，不给伪精确评分 |

## 主要风险与建议

- 运输装得走不等于部署能展开。运输态供料预留和备用设备展开细节归BP-Q03，不能直接采用Raw方案来补洞。
- 原种类上限未在本次取消；参数及后续是否保留归TL-Q01。形状有解和资格合格必须分别检查。
- 满包时可能没有合法的出售／选留路径。BP-Q03／04应一起闭合，不发免费仓库、不默认丢物或已卖出。
- 高阶前料可能压倒现场加工；阶段搬运也可能增加负担。几何选择存在不证明玩家理解或平衡成立。

## 最小验证与同类参照

先以已选生命灵药四台路线核对同一批真实物件的运输、展开和战后装载，比较带前料与带备用设备。成功信号是每个阶段归属唯一、两类布局均合法且玩家能解释机会成本；失败信号是只能靠免费仓库、假定出售或重复物件继续。原40格／t8仅是Raw静态样本，不作为发行参数或通过证据。
