# 行动卡效果机制与标记系统设计（创意阶段）

日期：2026-10-08。项目：game-002 / 言咒。状态：**Creative / Raw Idea**。本文档为阶段三行动卡设计的创意探索，聚焦**标记系统**作为核心拓展方向。

---

## 设计目标

在传统卡牌肉鸽游戏框架内，设计行动卡的效果机制，同时探索与时间轴和法器互动的独有机制——**标记系统**。

---

## 核心确认：标记系统作为独有机制

### 用户确认的设计方向

1. **标记的视觉形式**：砝码堆叠
   - 标记以砝码形式堆叠在对手棋子旁边
   - 正面标记一侧，负面标记另一侧
   - 与牌桌施法的视觉设计吻合
   - **血量也可体现为砝码**，后续称为"血量标记"

2. **标记的世界观意义**
   - 标记象征施法效果、法力残留或持续状态
   - 符合炼金/铭刻的世界观

3. **标记的附着规则**
   - **仅玩家和敌人可附着标记**
   - 行动卡产出、增加标记
   - 法器消耗标记

4. **条件设计简化**
   - 不引用行动卡、队列状态
   - 不读取资源状态
   - 不设置复杂条件句
   - **围绕标记设置简单条件**

5. **标记与时间轴的联动**
   - 与时间条件相关联
   - 每拍增加标记、特定拍数触发
   - 示例：每一拍加一个标记、当T拍来临时获得标记

6. **时间轴联动的视觉设计**
   - 获得标记效果结算后，行动行上对应位置卡牌出现**虚幻标记砝码**（象征将生成的标记）
   - 中心线（"现在"的线）扫过，卡牌翻开后标记砝码落到对应砝码堆

## 标记系统核心规则

### 标记的定义

| 属性 | 定义 |
|------|------|
| **载体** | 仅玩家和敌人（不附着于行动卡、资源卡或法器） |
| **来源** | 行动卡效果 |
| **视觉** | 砝码形式，堆叠于宿主旁边 |
| **极性** | 正面标记 / 负面标记（分两侧放置） |
| **消耗** | 法器可消耗标记作为配方条件或辅槽效果 |

### 标记的类型

| 类型 | 定义 | 极性 | 示例 |
|------|------|------|------|
| **即时标记** | 结算后立即落入砝码堆 | 正/负 | "获得1层护甲标记" |
| **延迟标记** | 通过虚幻砝码预示，翻开时落入砝码堆 | 正/负 | "在T拍获得2层蚀标记" |
| **周期标记** | 每N拍触发一次 | 正/负 | "每拍获得1层祝福" |
| **条件标记** | 满足条件时触发 | 正/负 | "当敌牌翻开时获得1层先兆" |

### 标记的生命周期

```
1. 行动卡结算 → 产生标记效果
2. 即时标记 → 直接落入砝码堆
3. 延迟标记 → 在行动行对应位置显示虚幻砝码
4. 中心线扫过 → 虚幻砝码具现化并落入砝码堆
5. 标记存续 → 持续存在直到消耗或移除
```

### 标记的消耗

| 消耗方式 | 触发者 | 效果 |
|----------|--------|------|
| **法器辅槽消耗** | 法器开工时 | 如"消耗1层蚀标记，本批材料减少M×1" |
| **行动卡消耗** | 行动卡结算时 | 如"消耗3层祝福，伤害×2" |
| **自动消耗** | 特定条件触发 | 如"战斗结束时清除所有正面标记" |

## 标记与时间轴的深度联动

### 联动模式一：延迟标记生成

```
【行动卡示例：预言·灼烧】
种类：其他✱
效果：在敌人下次触发T拍时，目标获得3层灼烧标记。
视觉：行动行中，敌牌T拍对应位置出现虚幻橙色砝码×3。
```

**视觉流程：**
1. 预言·灼烧结算 → 行动行中敌牌T拍位置出现虚幻砝码
2. 中心线扫过T拍 → 虚幻砝码具现化
3. 敌牌触发 → 灼烧标记落入敌人负面砝码堆
4. 后续每拍 → 灼烧标记触发持续伤害

### 联动模式二：周期标记累积

```
【行动卡示例：祝福之歌】
种类：其他✱
效果：玩家每拍开始时获得1层祝福标记，持续3拍。
视觉：玩家正面砝码堆每拍增加1枚金色砝码。
```

**视觉流程：**
1. 祝福之歌结算 → 标记周期效果登记
2. 每拍开始 → 金色砝码自动落入玩家正面堆
3. 3拍后 → 周期效果结束

### 联动模式三：条件标记触发

```
【行动卡示例：先兆之盾】
种类：防御■
效果：当敌牌揭示时，玩家立即获得2层先兆标记。
视觉：敌牌揭示瞬间，青色砝码×2落入玩家正面堆。
```

**视觉流程：**
1. 先兆之盾结算 → 条件标记效果登记
2. 敌牌揭示（r拍） → 触发条件
3. 青色砝码落入玩家正面堆
4. 后续敌牌揭示 → 继续触发

## 标记与法器的互动

### 互动模式一：法器消耗标记

```
【法器辅槽效果：承句·蚀噬】
效果：如果目标敌人有蚀标记，消耗全部蚀标记，本批材料消耗减少M×[蚀层数]。
```

**机制说明：**
- 法器开工时检查目标敌人是否有蚀标记
- 若有，消耗标记并减少材料消耗
- 不影响法器D值，仅影响配方

### 互动模式二：法器生成标记配方

```
【法器候选：黑曜坩埚】
暗句：「曜·铸」
配方：M×1 + E×1
效果：产出"曜铸"行动卡，附加3层蚀标记。
```

**机制说明：**
- 法器通过配方关联产生标记的行动卡
- 行动卡结算时标记落入目标
- 形成"法器→行动卡→标记"链条

### 互动模式三：标记作为虚拟材料

```
【法器辅槽效果：专注·标记转化】
效果：消耗3层祝福标记，视为提供M×1。
```

**机制说明：**
- 标记可作为虚拟材料参与配方
- 法器开工时检查标记数量
- 消耗标记后满足配方条件

## 标记系统与现有规则的兼容性

### 与时间轴的兼容

| 现有规则 | 标记系统 | 兼容性 |
|----------|----------|--------|
| 每拍至多结算一张行动卡 | 标记在结算时产生，不占用额外结算 | ✓ 兼容 |
| 防护先于伤害 | 护盾标记在受到伤害时触发，符合防护优先 | ✓ 兼容 |
| 最早下拍翻开 | 延迟标记通过虚幻砝码预示，翻开时落入砝码堆 | ✓ 兼容 |
| 敌牌Δ与T拍 | 标记可绑定T拍触发，深度联动时间轴 | ✓ 兼容 |

### 与法器的兼容

| 现有规则 | 标记系统 | 兼容性 |
|----------|----------|--------|
| 法器开工检查材料 | 标记可作为虚拟材料或消耗条件 | ✓ 兼容 |
| 辅槽修饰效果 | 辅槽可消耗标记或改变标记生成 | ✓ 兼容 |
| D与配方 | 标记不影响D，仅影响配方条件 | ✓ 兼容 |

### 与资源的兼容

| 现有规则 | 标记系统 | 兼容性 |
|----------|----------|--------|
| 资源仅在法器和资源区 | 标记仅附着于玩家/敌人，不进入资源区 | ✓ 兼容 |
| 资源下拍可用 | 标记即时或延迟生成，不占用资源逻辑 | ✓ 兼容 |

## 标记系统的设计价值

### 1. 与时间轴深度整合

- 延迟标记通过虚幻砝码可视化"未来效果"
- 周期标记创造"持续博弈"的策略空间
- 条件标记与敌牌Δ形成主动应对

### 2. 为"其他✱"类提供设计空间

- 传统卡牌游戏中"其他"类常被边缘化
- 标记系统赋予"其他"类独特价值：布局、转化、协同

### 3. 砝码视觉的叙事价值

- 砝码堆叠象征"施法效果的累积"
- 正负面分离体现"炼金的平衡"
- 血量砝码统一生命与标记的视觉语言

### 4. 可拓展性

- 未来可增加更多标记类型
- 标记消耗机制支持复杂套组
- 标记与召唤物/阵法预留接口

## 边界问题确认（2026-10-08）

| 问题编号 | 边界问题 | 用户确认 | 设计影响 |
|----------|----------|----------|----------|
| Q-MARK-1 | 标记是否有堆叠上限？ | **设置上限，仅用于防止数值过于膨胀** | 需为每种标记声明上限（如蚀上限10层） |
| Q-MARK-2 | 血量是否完全砝码化？ | **探索时做两套设计看最终效果** | 方案A：血量完全砝码化；方案B：血量独立显示 |
| Q-MARK-3 | 标记能否转移？ | **先保留不支持** | 初版标记仅附着于原宿主，不可转移 |
| Q-MARK-4 | 周期标记如何停止？ | 战斗结束或声明的持续拍数到期 | 已确认 |
| Q-MARK-5 | 标记能否叠加生效？ | 同类标记按层数叠加，不同类标记独立计算 | 已确认 |
| Q-MARK-6 | 负面标记能否附着于玩家？ | **标记以砝码形式堆叠，玩家负面一侧，敌人负面一侧** | 玩家和敌人各有正面/负面两侧，共四格放置位置 |
| Q-MARK-7 | 正面标记能否附着于敌人？ | **标记以砝码形式堆叠，玩家正面一侧，敌人正面一侧** | 玩家和敌人各有正面/负面两侧，共四格放置位置 |

### 标记放置位置布局

```
战场布局：

[玩家区域]
  ├── 正面标记堆（玩家受益）：祝福、护盾、专注、先兆、蓄势等
  └── 负面标记堆（玩家受损）：虚弱、迟缓、诅咒等（由敌人施加）

[敌人区域]
  ├── 正面标记堆（敌人受益）：强化、护甲、狂暴等（由敌人自己施加）
  └── 负面标记堆（敌人受损）：蚀、破甲、灼烧、虚弱等（由玩家施加）
```

**设计意义：**
- 四格放置位置清晰区分正负面效果的归属
- 敌人也可对玩家施加负面标记，增加威胁多样性
- 敌人可对自己施加正面标记（如BOSS强化阶段），增加策略深度
- 视觉上"砝码堆叠"隐喻"效果累积"，符合炼金世界观
