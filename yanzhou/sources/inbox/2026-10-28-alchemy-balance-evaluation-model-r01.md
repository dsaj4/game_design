## 2. “平衡”在这里具体指什么

本作是单人游戏。平衡不要求玩家与敌人各赢一半，也不要求每张牌、每个流派在每场战斗一样强。候选标准是：

1. **规则诚实。** 用同一套时序、权限和足额支付得出的强度；依赖非法操作才能成立的组合直接失效。
2. **路线可达。** 宣称能用的路线有真实取得、实体和物料渠道，且在适用压力的截止之前获得有意义的行动。
3. **情境优势。** 每条作为正式选项的路线，在一片合理、非刻意拼出的条件中值得选；其他条件下存在可说明的代价和替代路线。
4. **选择有效。** 看懂威胁、改变加工停点／支付／列序，能改变结果。不能只做数值更高的同义动作，也不能以增加操作次数冒充决策深度。
5. **成长有取舍。** 加组件能拓宽可处理问题或改善某些效率；高阶不必全面替换低阶。牺牲现成工具的红化应存在采用和保留两种合理区域。
6. **风险可理解。** 缺料、延误、费用不足、打断和错误布牌的后果有来源；普通压力下保留恢复空间，高风险转向承担更高代价需明示。
7. **资源回路可控。** 同时检查单位时间产率、全战总量、真实来源和带出用途。正收益不自动是漏洞，有界也不自动合适。
8. **玩家能使用。** 数学存在的选项需要在实际信息与操作负担下被理解和采用；这部分须另有真人证据。

用户已选定目标顺序：先合法生存并达成战斗目标，再比较实际剩余生命、耗材／持牌、用时和操作负担。后面这些维度保留多种偏好，不在缺经济输入时任定“1生命＝1咒＝1普通料”。普通核心样本保留预先指定的单步失误恢复空间，再生产需真实战略代价，具体确认边界见§16；这些是评价目标，不是各方案已经达标的证据。

## 3. 平衡标准与判定门槛

“硬失败”用于规则与前提被直接否定；“需调整”用于符合规则却损害本轮设计目标；“条件通过”只覆盖实际评估的输入域；缺数据或搜索不充分时记“证据不足”。这些结论不能用其他指标的高分抵消。

| 检查项 | 可操作标准 | 失败／调整触发条件 | 通过需要的证据 |
| --- | --- | --- | --- |
| 规则与实例 | 所有轨迹满足唯一归属、权限、时点、完整费用和终局清理；容忍违规数为0 | 重复取同实例、同拍新料续用、列间加工、旧列重用、透视暗牌等任一违规 | 覆盖相关正反例；当前文档检查不替代实现验证 |
| 启动 | 对每个宣称的起点给出取得清单、最早有效行动、第一处生存截止 | 只有材料没有渠道、只有器具没有实体核心、首个有意义行动之前已必败 | 一条符合真实信息的合法见证；真实初态生命／敌情明确 |
| 构筑用途 | 每条宣称的路线有非退化优势区域；邻近条件能解释为何仍可用或何时应转向 | 只在专门为它制造的孤立点占优，或在所有适用条件均有更低成本替代 | 同预算对照、相邻扰动及实际取得前提；不能只展示最有利算例 |
| 支配与必选 | 除已声明共同底盘外，选项不能无额外代价普遍提高所有相关结果 | 可选牌／配装在整个正常域不劣且至少一处更优；移除后绝大多数其他路线失去成立条件 | 完整域可证明时给证明，否则只报已发现反例／覆盖，不能宣称全局无支配 |
| 成长／加工深度 | 继续加工和当前兑现都能在合理条件下成为有效选择 | 所有状态都应继续加工，或所有状态都应停止；升级只有更晚、更贵而无有用区域 | 成长前后、同资源新建与已有工具转化分别比较 |
| 生存与顺序 | 按每个敌伤事件检查生命，不只看回合总治疗／总甲 | 总回复足够但回复发生前已死亡；后列咒被借给前列防护 | 逐事件生存余量、费用轨迹与截止位置 |
| 断链与容错 | 记录缺1份关键料、延1生产拍、错1个可恢复列的后果及恢复路径 | 普通核心样本只有唯一精确脚本且任何轻微可恢复误差都必败；或错误几乎无代价 | 完美、可解释失误和合理恢复三种轨迹；高压与红化可另定风险目标 |
| 回收／再生 | 正确计算制造投入、每次支付、列机会、产物来源总量与兑现时间 | 非法复制；或合法拖延在正常域普遍改善可带出收益却没有相应压力／取舍 | 速率界、总量界、最坏情形及有限收益的机会成本 |
| 取得与跨战 | 实际可取得且可部署；收益按真实选留规则进入下一战 | 用全套无取得负担证明强度，或把回收当无限携带 | C／总控接口；未闭合只给条件结论 |
| 玩家选择质量 | 能预测关键支付／时点，依据可见信息作调整，说明牺牲了什么 | 必须照抄排程、靠隐藏信息或大量无意义锁解；数学有效但无法使用 | 独立于设计者演示的真人行为；本轮NotRun |

以上没有套用任意“胜率50%”“强度差不超过10%”。零违规来自规则，差1份／1拍／1列来自系统最小决策单位。若以后需要商业难度或胜率目标，应由人群、遭遇角色和路线分布校准，另记目标来源；不能从本稿自动推出。

共同引燃起点已被用户选作候选，不能仅凭其高使用率判失衡。需分别报告“设计声明的共同底盘依赖”与“原本可选组件成为事实必选”。共同底盘仍应计成本，并检查它是否吞掉后续成长价值。

## 4. 模型的输入、状态与决策

### 4.1 一次测评必须固定的输入

用`θ`表示完整条件，至少包含：规则／内容版本、初始卡实例、初始玩家生命与上限／护甲／咒、实体器具和铭文、合法用途、供料序、未来补给时间及身份、固定敌程序与敌生命、公开信息、战终／携带接口、分析观察长度和评价目标。

以下四者独立：**拥有的实体、可部署的实体、知道的配方、已经生成的卡**。法器数量相同不自动等价取得价；配方已存在不自动说明玩家已知道；手里有材料不说明已到供料时点。

初始候选对照用效果稿§3的20张普通料＋第6／11拍各10张，原质仅经平炼；3器2核心启动、扩白／黑／红分别增加真实实体。初始生命和真实敌程序缺失，因此当前可判生产可达和资源边界，不能判真实遭遇胜负。

### 4.2 状态必须保留什么

用`S`表示某事件前的完整游戏状态；以下是数学描述所需的玩家可见／规则对象，不是程序类或另一套库存：

| 状态部分 | 必须保留的量／关系 | 漏掉会怎样 |
| --- | --- | --- |
| 时间与阶段 | 回合、累计生产拍、当前列、牌内步骤、允许编辑窗口 | 把结算当生产时间，或允许列内改牌 |
| 生命与护甲 | 玩家当前／上限、玩家护甲、敌当前生命、存活资格 | 把晚到治疗当防死，把终局后产咒算进去 |
| 咒 | 同一施法次数的实有、锁定、冻结、可消费、上限与已失效量 | 重复支付、溢出转余额、另建炼金魔力池 |
| 卡实例与归属 | 身份、来源、权限、手／行／托管／已消费／战终归属、最早供料拍、锁定 | 既留护符上行又拿去红化，一张晶核付两处 |
| 器具和在制批次 | 核心实体占用、兼容用途、冻结投入／D／产物、开工及完工拍、未来用途 | 战中重铭、修改当前批次、打断后保留进度 |
| 战斗行和敌程序 | 已处理列、己牌、敌暗牌位置与类别、公开后续、锁定法器及来源、下一轮覆盖 | 免费取消暗牌、打断改选、取消后补牌 |
| 外部与终局 | 剩余补给事件、适用的疲劳状态、真实选留资格与容量、胜败及清理是否已完成 | 延长时间却忘记疲劳，战后无上限带走所有产物 |
| 信息历史 | 玩家已经看见的牌、公开结果及允许保留的知识 | 用实际隐藏值替玩家提前最优布牌 |

转换写为`S下一事件 = F(S当前, 合法选择, θ)`。模型应逐事件记录输入与结果，使任何人能从同一状态复核下一步。当前敌程序固定时，同条件同选择应得到同结果；不为了给胜率制造随机波动。

### 4.3 决策只能使用当时可知信息

定义`O(S)`为玩家当前可观察信息，策略为“观察历史→合法选择”。暗牌精确值不在`O(S)`中，直到其列开始公开；同一可见历史下，策略不能因暗牌真实值不同作不同预判。程序虽开战固定，也不代表新玩家已知道整张表。

分开三种知识条件：初见时仅用实际公开信息；已学会固定规律时用明确给定的合法知识；全信息只作为理论上界诊断。全信息策略胜利而初见策略失败，不能直接说内容平衡；只说明信息或学习门槛可能重要。

若不同隐藏程序起初不可区分，应让同一策略在揭示前作相同选择，再观察揭示后能否调整。未来如需期望收益，隐藏程序的分布必须来自明确假设／真实投放，不能给每张暗牌私自加独立随机数。

还需禁止一种事后透视：按每张实际暗表分别挑一套恰好最合适的初始脚本，再平均成“合法策略表现”。即使每套脚本内部只读可见信息，事后选脚本这一步仍使用了隐藏答案。初见测评应先固定策略，在一组初始不可区分的程序上共同评价；只有合法知识或已揭示历史不同，策略才可分支。

## 5. 必须精确的事件推进

| 阶段／事件 | 模型必须执行的顺序与边界 |
| --- | --- |
| 第0拍 | 布敌首行、就绪观察，之后首次开工；不是预先发成品 |
| 生产拍 | 边界释放待用量／到期设置→观察受理→幸存完工消费投入并产卡入手→当前适用维护位置→空闲器具依序各检查一次 |
| 批次时间 | a拍拍末开工，a＋D完工；开工当拍不推进。完成新卡最早a＋D＋1拍可供料，不因同拍较晚器具而提前 |
| 开工检查 | 配置、完整配方、D与必要标记共同满足才托管／冻结；失败不部分扣，继续下一台，不回扫 |
| 最终整理 | 第5拍收尾后可免费布牌和改未来设置；已经开工的批次不能撤回 |
| 一列 | 开始才公开当前暗牌并固定双方行动；先防护、再其余，各组敌→玩家；依步骤核目标／费用／结果，每完整事件查终局 |
| 回收与列间 | 整卡完成才回手，后续未开始列可再用；空放仍按回收属性清理。列间不改用途／锁解、不产卡、不加工、不提前揭下列 |
| 打断 | 生成后续时按规则锁法器，结算作用其当时批次；丢进度不产物，退原输入，最早下一生产拍可用；不能追溯毁掉已产卡 |
| 末列与回合末 | 不因回手产生第6列；适用的疲劳独立结清，未终局才换轮，不额外开工 |
| 终局 | 立即停止余步骤／列／未来生产；已发生支付和消费保留，未完工原输入按合同退回参选；每实例只清理一次 |

生产拍与列是两套坐标。表中“观察长度到第R轮”仅是分析截止，不是给游戏新增回合限制：到截止仍未终局记录“观察未完”，不能擅自判负。冻结版本GDD的首场疲劳只在该场景适用时使用；B01是否沿相同战长／疲劳由总控映射，不能静默取消或普遍套用。

免费撤回／调序等不推进时间；同一窗口内反复做完再还原的无结果操作不能算增加战斗机会。以后进行策略搜索时可合并等价最终布置，但须保留影响唯一实例、托管和合法时点的差异。

## 6. 成本与结果怎样比较

### 6.1 成本先保留为向量

共同预算`B`包含：八类普通料的身份／数量与到达时刻，现成卡及其状态，器具／铭文的具体实体与占用，部署约束，法器生产占用，已有咒及锁定，生命／护甲，剩余合法列与时间，取得／替换成本和跨战容量。只知道前三器不代表已给额外白化器的价格。

三种对照不要混用：

1. **同一起点。** 完全相同卡实例、器具、供给和信息，选择不同生产／布牌策略；未消费的料保留为真实剩料。
2. **同取得预算的不同套组。** 实际取得／部署成本已知才比较；不知道时给条件边界，不能把4器3铭文都当同价。
3. **已有工具的转向。** 输入工具已在手，比较保留与合炼；原制造成本是历史投入，不再扣一次，但失去未来使用和携带的价值仍需比较。

从普通料冷启动与“工具已齐”的结果分开报告，避免用后者掩盖前期不可达。将某卡移出套组作对照时，必须同时处理被释放的原料、器具、核心与列机会，让替代策略重新规划；不能只删掉一张牌后证明它不可缺。

### 6.2 结果保留多个维度

一次结果至少报告：胜／负／观察未完，终局事件及轮列，最小生存余量，剩余生命，真实消费的普通料向量、持有／可选留卡向量，咒与护甲的生成／消费／溢出，生产等待及返工，使用／空放／无效列，必要操作次数。

有效伤害取真正扣掉的生命／护甲，不把18打在剩1生命上记成18有效伤害。治疗取实际增加生命；未吸收的护甲不记成已经防住的伤害。玩家整局剩余护甲按战终清理，不能当永久资产。中间料只能按其现实去向估值，不按根料成本假装可逆拆回。

总护甲吸收可从事件确定；某一张盾对吸收的贡献，在多个来源叠甲时不任定FIFO归功，优先用成对反事实归因。取消张数同样不等于收益，要比较被取消牌的实际后果和替代策略。

### 6.3 支配、机会成本与回本

在同条件、同目标下，A满足目标且所有相关结果不差于B，至少一项严格更好，才构成该条件内的支配。一个条件内支配不等于全条件支配。存在生命、剩料、速度等互相交换时，保留不被支配的选择集合，不强行平均出唯一最佳。

更严格地，记`Y_b(θ)`为套组b在条件θ下、所有合法信息策略能取得的结果集合，`Front_b(θ)`为其中不被支配的结果。判断“构筑A支配B”，应当对B前沿上每个结果，都能在A的结果中找到不差的对应项，并在声明的条件域内至少有严格改善；不能只拿A的最佳脚本打败B的一条随意脚本。预算对等、目标偏好和信息条件始终是该判断的前提。策略空间只覆盖一部分时，给出覆盖内判断，不称全局证明。

若θ中含玩家起初不可见的程序差异，正式策略比较应对整个不可区分条件组I使用同一策略：`Y_b(I) = {同一合法策略π在I各条件上的结果向量}`，再按声明的稳健目标或给定分布比较。单个θ的最优结果仅作条件可达性／上界诊断，不能将不同θ各自的最优脚本拼成一位初见玩家。

某资源的边际价值用同一任务下“多／少一份该资源，重新规划后结果如何变”测量。需要标量时，只能针对明确子目标，例如同样通关条件下最少消费的某种稀缺料，或相同剩料约束下最早结束；权重与目标必须公开。

局部写成`资源ρ的边际价值 = V(B＋一份ρ)−V(B)`，这里V必须说明是哪项任务，不是万能战力。费用从1变2、D从1变2都可能跨过足额或列截止，应用整数有限差分，不假设线性。

“石回本”定义为：相同起点下，启用石的可行结果第一次在选定目标／约束上达到或超过保留普通路线。若从未达到，只记在观察窗口内未回本；不能把“生成了12份根料成本的液”直接当抵消本体成本，尤其当液来不及加工或带走时。

### 6.4 统一记录的关键指标

| 指标 | 明确定义 | 用途／避免的误判 |
| --- | --- | --- |
| 首个有效行动 | 第一张实际可在合法列兑现、并对当前目标有影响的卡到达时间 | 可上行但目标无效／余额不足不等于完成启动 |
| 前缀生存余量 | 每个敌伤事件后存活时的生命，取全轨迹最小值；死亡明确记事件 | 区分平均防御够与来不及挡第一击 |
| 可达兑现次数 | 在观察窗口、足额和目标有效下真正成功次数 | 不把可回收写成无限次／每轮五次有效 |
| 有效列率 | 实际对所定目标有贡献的己方列／可用列；空列、空放另列 | 不把为了凑满牌而使用无收益卡当高效率 |
| 分因等待 | 缺完整料、保留锁定、用途选择、缺实体／不兼容、待用延迟分开 | 等待不一律是平衡弱，主动保留可能是正确策略 |
| 器具利用 | 在观察生产拍范围内实际加工占用／可计生产拍，排除列间停住 | 不把玩家思考时间当生产效率损失 |
| 资源缺口 | 完整配方欠缺的具体身份与实例数、到达时间 | 找到光、铁、第二晶核等瓶颈，不用总份数掩盖 |
| 可恢复失误代价 | 与完美合法轨迹配对，额外失血、返工、延误和剩料变化 | 识别脆弱与低风险，而非将所有失误统一罚分 |
| 拖延边际收益 | 从同一仍可获胜状态，推迟结束后的带出／生命／消费变化 | 分辨有代价产料与安全拖延成为普遍最优 |
| 选择依赖 | 去掉或限制组件并释放其预算后，其他有效路线损失 | 区分共同底盘、互补件与事实必选 |
| 操作负担 | 布牌／锁解／改用途次数与必要决策次数分别记录 | 相同结果的重复机械操作不当作策略深度；真人耗时另测 |

## 7. 场景空间：需要考虑哪些条件

### 7.1 条件轴及边界点

每个场景声明哪些值来自已定规则、已选候选、诊断假设或Unknown。只有合法组合进入玩法对照；非法兼容、缺核心等先作规则反例，不混入正常强度平均。

| 条件轴 | 正常对照／关键边界 | 主要检查什么 |
| --- | --- | --- |
| 普通料总预算 | 候选20＋10＋10包；仅初始包；关键料少1份；同总量改变身份分布 | 供给偏向是否制造假强弱；材料总份数不能代替向量 |
| 到达时刻 | 原计划、某包延1拍、在某次开工前／后到达 | 是否跨过本轮可用截止；不能只比较整战总量 |
| 环境是否持续 | 明确有限包；以后若有持续补给，另给真实周期与总量 | 外部新料是不是再生回路的真正驱动 |
| 配置与实体 | 3器2核心、白／黑扩展4器3核心、石4器3核心、全链万灵药6器5核心 | 理论内容与真实部署；不能只给红化器名字 |
| 生产并行 | 单研合；追加研合台＋精炼真实副本；关键器具拥堵 | 加器具的回报与实体／取得负担；不暗改一器并行 |
| 配方知识 | 给定有限用途、初见与已熟悉链；知识范围在对照内相同 | 路线难找和路线本身弱的区别 |
| 初始咒 | 0、费用减1、恰好足额、上限减获咒量、上限 | 1与2咒断点、醒神／万灵药溢出；锁定量另列 |
| 生命／护甲 | 满生命；缺1／12／30；对下一击满足生命＋甲＝伤害−1、伤害、伤害＋1的合法状态 | 治疗溢出、晚到治疗、护甲阈值与脆弱恢复 |
| 敌生命 | 围绕1、12／13、18／19等当前伤害断点，以及大生命长战 | 过量伤害、杀敌后不产咒、引燃可收获次数 |
| 整场压力 | 低压、稳定承伤、前置／后置爆发、公开打断后续、持续消耗 | 生存前缀、取消时限、长短战与工具价值 |
| 打断时点／对象 | 锁定时有／无在制批次；生效时同一法器有／无批次；红化在制与已完工 | 返工真实损失和短批恢复；不能指哪打哪 |
| 可取消窗口 | 无公开目标、目标在2列／4列／5列、多个目标、咒不足 | 是否有用、能否赶上、必须取最左而非最危险 |
| 当前加工深度 | 原料、灵液／晶核／火种、三级料、现成工具、红化在制 | 判断继续、停工、先战斗及沉没投入 |
| 原实例位置 | 在手、行上、托管、锁定、新产待用、用后回手 | 法律资格及真实机会成本 |
| 终局位置 | 伤害后立即胜、治疗前已败、复合牌两步之间终止 | 避免终局后收益、回收或补产 |
| 玩家策略与信息 | 简单规则、有限规划、熟练调整；初见／已学会／上界透视分开 | 理论最优与实际可用差距，暗牌信息泄漏 |
| 操作失误 | 错一次用途设置、保留锁定延1拍、先消费错误的一张可替代卡、错一个可恢复列 | 容错和恢复；不把故意自杀列为应当可恢复 |
| 战终／跨战 | 资格按候选；容量／种类限额待总控，诊断中可列不带出／紧／宽三条件 | 石产料能否带走、工具保留与越战积累 |
| 分析长度 | 在关键成品到达前、刚到达、到达后一个／多个完整轮 | 短战无回本与长战偏强；截止未结束不假判负 |
| 参数邻域 | 费用±1、量值±1、D±1的合法值、补给±1份／拍 | 断点、稳定性与调整方向；诊断变体不改已选基线 |

“缺关键料”与“补给推迟”可能相互放大；“石已到手”与“初始普通料冷启动”不能同时免费成立；“全部组件拥有”与“部署上限很小”也不能同时假设全部生效。先做输入一致性检查，再求结果。

### 7.2 最小压力组如何构造

以下只是**参数化测评情境**，不是发行敌人或读取真实敌表。均保持一名有限生命来源敌人，固定五列程序、原生即时普通伤害／延时打断及既有公开后续覆盖规则。不加入敌护甲、回血、反伤、随机换牌或针对玩家临时变招。

| 情境 | 固定输入的构造办法 | 应分辨的选择 |
| --- | --- | --- |
| 无压力校验 | 五列普通伤害量取0，敌生命有限；只核生产／费用／终局 | 排程是否合法、资源来源是否闭合；此情境不用于证明正常战斗平衡 |
| 稳定压力 | 各列同一声明伤害d，敌生命h；d／h在开战前固定 | 反复防护与杀敌速度，持续回复需求 |
| 前置爆发 | 固定某较左列为较大伤害，其余为较小伤害 | 先护甲与后治疗的差异、0咒启动；隐藏数值仍到该列才揭示 |
| 后置爆发 | 将同样总伤害的较大一击放较右，其他不变 | 同总伤害下储备时限和晚列调整价值 |
| 单个公开打断后续 | 前一轮固定延时生成，实际锁定依当时最大剩余生产拍裁决，下一轮公开铺左 | 离解的2咒截止、预先留咒、生产完工与接受返工 |
| 多个公开后续 | 在固定程序允许位置生成多份后续，按生成序覆盖下轮 | 离解最左优先、取消次数、储备和列位竞争 |
| 混合压力 | 开战前固定普通伤害与延时打断的列位置，数值不随玩家路线变 | 产线安全、护符／离解／日轮分配 |
| 长战消耗 | 增大固定敌生命，保留有限补给和明确疲劳适用状态 | 再生总量、低伤拖战、红化回报与带出价值 |

数值d、h、玩家生命和真实难度范围待总控；模型可先输出关于它们的条件边界。对这些参数的扫描不是给敌人新增适应能力。玩家策略只在合法公开程度下行动；“前置爆发”是评估者知道的结构，不自动授予玩家预知具体列伤害。

### 7.3 不做无法解释的全排列平均

按四层扩展：

1. 先固定一个输入自洽的基准：物料包、实体套组、完整压力程序、目标与信息。每条路线先找到自己的合法生产见证。
2. 单独改变一个轴，特别查足额、到达、死亡、终局等整数断点，找到优势／失败边界。
3. 定向组合高风险交互：**供给延误×精炼串行×第一轮生存；初始咒×目标列号×公开程度；红化托管×打断×现成工具缺失；石费用×有限敌生命×光／跨战容量**。
4. 用没有参与调参的邻近组合复核，再由真人验证理解与操作。不要看见结论不满意就替换这一组输入。

没有真实投放分布时，不把各条件等权的胜利比例叫“玩家胜率”。均匀覆盖只能说明诊断覆盖；正式加权需要C／总控的分布和权重。平均结果还须附最差条件、失败原因及覆盖空白，避免少数灾难被大量无压力样本冲淡。

## 8. 策略对照与测评求解

### 8.1 至少包含哪些策略

| 策略 | 允许知道／改变什么 | 比较价值 |
| --- | --- | --- |
| 无行动／仅启动引燃 | 按合法信息，不自动获得后续组件 | 压力和共同底盘校验，不能当所有路线的唯一对手 |
| 简单可解释规则 | 例如缺生命时优先现成回复、有足额咒才上消费者、按固定核心路线加工 | 检查不用照抄完整排程时是否可用；不得偷看未来暗牌精确值 |
| 当前窗口规划 | 规划当前可见后续和已有手牌的列序、支付，生产只改未来合法用途 | 检查储备压缩、取消截止及回收使用 |
| 跨生产段规划 | 依据已知配方、补给和公开威胁比较几种加工深度／红化时点 | 估计策略熟练带来的收益，仍受信息约束 |
| 合法信息下的最优策略界 | 在给定可见历史／知识范围内比较所有已覆盖的合法策略 | 给可达性和支配判断提供上／下界；搜索范围不完整必须标明 |
| 全信息诊断上界 | 评估者知道未来实际表，但仍不违反动作／支付规则 | 若连此上界都不可能达标可排除该输入；它的成功不能证明玩家实际可达 |
| 追求产料／带出策略 | 合法延迟胜利、优先石产液、按真实携带选留 | 主动找“拖战比结束普遍更好”的反例，不能只测想尽快赢的策略 |

这些是数学／行为策略类别，不是本轮启动模拟玩家、子agent或测试程序。真人熟练度也不能用一个“随机失误率”直接代替；需要记录实际看懂与选择的过程。

### 8.2 怎样得到可复核结论

对每个输入θ与套组b，定义`可行域(b)`为：存在符合信息约束的合法策略，能达成本场目标的条件集合。再保留其中不被同预算替代策略全面压过的结果。图上一个点的颜色必须同时标记“规则合法、搜索覆盖、模型结果、玩家证据”，不能只用绿灯表示一切。

某点找到成功脚本后，还要明确它是单条件见证，还是同一策略在整个不可区分条件组中的有效结果。正常初见表现采用后一种，不能先知道实际隐藏θ再选π；已掌握程序表的条件则另列合法知识前提。

结果证据分三种：

- **找到合法成功见证：**证明该策略在这些已固定条件可行；不证明同路线所有策略或所有场景都行。
- **严格不可行证明／完整搜索边界：**证明给定约束中不存在达标路线；应列出约束和证明范围。
- **暂未找到：**启发式失败、有限规划失败或观察长度不足；保持未确定，不能写成路线必败。

胜败是离散目标；若为了某子目标先固定“必须获胜”，才能进一步优化少花料、少失血、早结束等。反过来不得用输了但产液很多的结果补偿通关目标。若研究的是保留收益的偏好变化，则另列目标版本，不改原评价口径。

### 8.3 反事实必须公平

四类干预分别记录：**去掉卡及释放预算、保留卡但不使用、只改一个参数、只改一次时机**。每次都让对照重新规划同样合法选择，不强迫对照沿原脚本失败。敌程序与初始隐藏状态保持一致，比较者的信息范围保持一致。

例如比较万灵药与保留工具：从同一四个输入实例已齐的状态出发，保留组可喝生命灵药、回收护符／引燃、留料或另选合法用途；红化组可选择什么时候托管。不能让保留组站着不出牌，再称红化强。比较石与普通生产时，冷启动取得比较和“红化石已在手”的使用比较分别报告。

## 9. 关键数学边界：从卡面到全局机会成本

### 9.1 生存必须按事件前缀计算

对某次普通伤害，记事件前玩家生命为hp、护甲为a、伤害为d：`事件后生命 = max(0,hp−max(0,d−a))`，护甲相应先扣；生命归零就终局。当前列治疗随后才发生，不能填平已经归零的前缀。

直接护甲q在同列防护组先于普通伤害，可把条件从`hp＋a>d`改善到`hp＋a＋q>d`。护符还需防护步骤时已足额的1咒。治疗12与护甲12的卡面数值相同，不说明它们在当前列等价。

### 9.2 引燃／消费者的总预算

先假定石、引燃等已经真实到手，考察其后R个完整五列窗口。E为伤害成功且未终局、确实执行获咒步骤的引燃次数；即使满层溢出仍计次数，损耗另记。T为石成功产液次数，W／V分别为醒神／万灵药实际执行获咒步骤的次数，A为其他占列次数；石单次费为c（基准2，对照3）。另记窗口开始仍有效的既有咒总量为m0、其他用途消费总量为C、溢出／失效等损耗为O。m0在总量上界中包括既有锁定／冻结层；实际支付必须等其按规则可消费，释放不重复记新来源。

必要约束为：

`E＋T＋W＋V＋A ≤ 5R`

`cT＋C ≤ m0＋E＋5W＋8V−O`

每次支付前还要按当时可消费量足额，上限10还会限制中间存量。这两个总量约束只是上界，不替代逐列可行性。若引燃杀敌或未成功削减目标，不计入E；相应攻击即使占列，也应另记到非产咒列。

没有药物和其他行动时，消去E得到`T ≤ floor((m0＋5R)/(c＋1))`。有药物时相应必要界为`T ≤ floor((m0＋5R＋4W＋7V−A−C−O)/(c＋1))`，且W／V自身受物料、制造和实例消费限制，不能取任意大。

### 9.3 上稿漏算的总量约束：敌人生命

当前B01引燃为1普通伤害成功且未终局才获1咒；允许范围内敌人只有有限生命、没有本批启用的敌护甲／回血。若窗口开始敌剩余生命为h，终局致死事件之前其他来源实际削减的生命为Dother（排除最后的致死事件），则：

`E ≤ max(0,h−1−Dother)`

此式按本轮整数生命刻度推导。若总控给出合法非整数生命，E的界改用`max(0,ceil(h−Dother)−1)`，后文产液来源界同步替换；模型不能为了套公式截掉实际生命的小数部分。

必要时进一步按终局前实际事件核对。最后一击杀敌不产咒；故即使时间无限等待，固定有限敌人也不能让引燃无限提供咒。上稿§8.4只给出了列位界，其“无限安全战长总量增长”表述缺少这一固定来源条件，应收紧为**高生命／长战下有限产料可能偏强**。

只靠引燃／石、没有额外药物时，还必须满足：

`T ≤ floor((m0＋h−1−Dother)/c)`

所以取列位界、敌生命来源界、真实制造／供给界、终局时点等约束中最紧者。举例：m0＝0、h＝6、R＝3，只用引燃和石；2咒石的列位界为5液，但生命来源界仅2液；3咒石生命来源界仅1液。它们都是忽略玩家承伤的上界，不是三轮实测产出。

可手工核对该上界的一个无承伤见证：石与引燃已在手，第一轮五列“引、引、石、引、引”，得到1液、余2咒、敌余2生命；第二轮第一列石再得1液、余0咒。若继续两次引燃，后一击致死不获咒，不能再凑一次2咒支付。这仅说明此来源上界在无压力条件可达，不计工具取得、不证明实战可行。

另外两种获咒来源也须完整核算：醒神每次需消耗一张一次性成品，其链需要光；万灵药每次消费一枚护符，其链需要铁。当前B01没有产光／铁的卡效或反向配方，在有限外部投入和有限初始持牌下，这两类来源也有界。因此按R01候选合同、固定有限敌生命和有限投入，单战真正无限产咒／产液可以排除；**有限但过强、低风险拖战、跨战积累**仍需测评。未来若改变获咒条件或外部供给，再重新证明，不能沿用本结论。

这也说明伤害提高、敌生命降低或日轮多打几次，会减少可收获的引燃咒。对通关是收益，对产料可能缩短窗口，须由明确目标比较。真正无界回路只有在完整状态和外部源允许可重复、不耗尽敌生命／资源／生存余量的增益时才能成立；不能把“回收＋产卡”两个词直接当证据。

### 9.4 第二个来源约束：光预算

候选40份物料包总光为4，石本体全链恰需光4。石的卡效只生成灵液，不生成光。因此从该包冷启动做石后，**没有额外光继续制造醒神**；若先做一张醒神，也会使石缺光。即使改用石产出的灵液来做醒神，辉光仍要额外光1＋火1，不能绕过该缺口。

“一灵液→醒神5咒→两次石返两灵液”的局部正收益仍可描述，但完整成立需白化实体、光／火／水和时间。它应放在“追加至少1光或已有外部醒神／石等改变起点”的独立情境，不是同一个40份包已闭合的收益。新增外部输入必须计入共同预算。

### 9.5 两种投射与资源边际价值

飞弹与爆弹当前均为一次性18伤、7总D，同样黑化通道；根料分别为土2水3风1与土2火3水1。严格的差向量为水＋2、风＋1、火−3、土相同。若在某具体任务中明确采用局部固定的加性估值λ，且制造时点／库存差异另计，则该近似下：

`飞弹材料成本−爆弹材料成本 = 2λ水＋λ风−3λ火`

该式的正负解释这一局部加性近似下的原料取舍，不等于一般动态价值函数对整组材料变化的精确差值；正式判断仍重新规划同一预算。当水／风富余而火稀缺时飞弹可能划算，反之可能爆弹划算；互补材料断点、已有中间料、基础器争用与截止也会改变结论。没有这些条件，不应凭同为18伤判冗余，或凭名字给爆弹加范围、给飞弹加穿甲。

### 9.6 万灵药的有效输出与托管窗口

缺失生命为x、当前总实有咒为m、上限暂取10时，万灵药的即时有效输出为`(min(30,x), min(8,10−m))`；锁定量也占上限。相对直接喝原有生命灵药的额外有效治疗为`min(30,x)−min(12,x)`，在x≤12时为0，在x≥30时为18，中间逐点增加。

这不是最终净收益。保留组还拥有护符和引燃；合炼组失去工具与再生液，并承担开工托管。D为生产拍，结算在5n拍后，某次a开工到a＋D完工之间受托管影响的结算轮数为：

`N托管 = 满足 a≤5n<a＋D 的回合n的个数`

14拍开工、D2时包含15拍后的第三轮；16拍开工、18拍完成则不跨任何结算点。这个整数断点比“D2只比D1慢一倍”的平均描述重要。是否因此损失实际防护／输出，仍要与保留组的合理行动比较，而非将每个托管轮一律估成固定伤害。

## 11. 失衡怎样定位，参数怎样调整

### 11.1 先定位最早断点

依次问：输入是否真实且规则一致 → 渠道是否可达 → 生存是否赶得上 → 有限列／咒／加工如何竞争 → 替代策略是否被压过 → 取得／跨战是否改变结论 → 玩家是否能理解。前层失败时，后层漂亮数字不能补救。

| 表现 | 可能来源 | 最小区分对照 | 首要修改位置 |
| --- | --- | --- | --- |
| 所有路线第一轮无有效选择就败 | 初态、敌压力、基础起点 | 同配置只改第一处压力截止／初始现成牌等明确输入 | 总控起点／遭遇接口，不能先给所有成品加伤害 |
| 只有开透视的最优策略赢 | 信息或过窄容错窗口 | 同动作能力、不同合法知识条件 | 可见信息、学习前提或风险窗口；数学上界不能作为玩家标准 |
| 引燃后不再需要生产 | 普通产线太慢／消费者价值不足，或压力太低 | 释放共同预算后比较不同加工与列分配 | 制造与储备关系、压力域；再审回收／获咒权限 |
| 每条路线都得带某可选组件 | 过宽功能或过低机会成本，也可能是它承担未声明公共职责 | 去掉并释放预算，检查替代是否真实存在 | 明确公共职责或缩功能／加成本，不只下调一点数值 |
| 高阶总是没用 | 取得／配方／部署不达、时间不够、带出无处兑现 | 已有工具使用与从原料取得分别测 | 最早阻塞的层；调整末端数值只对确属输出不足有效 |
| 高阶总应取代低阶 | 没有牺牲、低阶无及时用途、供给无成本 | 同有限包比较早兑现、保留与继续加工 | 加工停点、费用、托管／实体／列机会；不强行等强 |
| 产液很多但没有选择变化 | 无接收配方、下游缺料／器具、无法选留 | 同产液量下只改下游渠道／容量 | 来源—接收关系，而非继续增产 |
| 收益极依赖一份光或一拍 | 合理高风险门槛，或无恢复的卡死 | 关键输入±1及相邻压力，记录风险回报 | 明示风险、替代渠道或取得；不必抹平所有断点 |
| 真人只照抄一套操作 | 实际支配、可见信息不足或操作负担过大 | 同一场景先比较多种合法有效解，再观察读者 | 分辨策略无效与策略不可见，避免纯数值误修 |

### 11.2 敏感性检查要保留整数断点

对每个候选参数先试一个最小合法单位的变化，记录结果由何处发生跳变：日轮2咒到1／3、石2到3、红化D2到1／3、关键料或到达拍±1、量值±1。D不能低于1，数量不能负，成本与效果域沿各自合同。变体仅用于诊断，不替代用户已选初值。

稳健性分别报告“最小几拍迟供会跨过兑现／生存截止”“最少缺哪种几份料会失去有效路线”“哪些初始生命／咒断点会反转选择”。这些是各轴的失效距离，不相加成统一容错分，也不要求所有高风险构筑一样稳。

例如日轮价格只改1咒，可能让0储备五列的可用次数大变；红化D2到1，可能恰好从跨结算变为同轮到达；18伤到19，仅在对应敌生命阈值附近改变击杀列。应报告这些分段边界，不用“提高10%强度”概括。

对某问题同时调产率、D、费用、伤害，会失去归因。优先只改最早断层的一组参数，保持同一验证场景和未用于调参的复核场景；再看是否产生新的支配或把弱点转嫁给其他路线。

“恢复”也需预先定义：在普通核心样本指定的单步失误后，用当时真实库存、未来供给及合法窗口，在下一个必须处理的威胁之前重新进入任一有效路线；不要求返回原最佳脚本。先指定例如多锁一拍、误选一次未来用途等失误集合，再判断是否仍有合法生存／通关见证，不能事后只挑本来就不影响结果的小错。记录实际额外代价；高风险红化和刻意超预算的情境不自动享有普通容错目标。

### 11.3 普通产率、稀缺性和传奇价值的边界

本轮保留每项1份、每批1张、普通D1／红D2。不因高级而提高全部量值，也不因传奇而允许亏损没有用途。稀有取得可能合理补偿较强能力，但没有C的取得频率／替换经济，不能用“它很稀有”给失衡开白条，也不能把材料级别当稀有度。

用户以后改变配方份数／产率时，测评必须重新展开所有受影响分支和共用前料，不能只检查被修改的一张卡。改具体身份、产出或增删B01条目须沿原内容差异流程，不由本模型自动生成新规则。

## 12. 数据与证据：模型结果怎样成为可信结论

### 12.1 每个测评结果的最小记录

在实际执行获授权并存在真实结果后，沿同一测评记录填写以下内容，不另建平行进度系统：

| 字段 | 必填内容 |
| --- | --- |
| 声明 | 要判断的平衡主张、目标标准及允许反例 |
| 输入 | 固定版本、全部初态／补给／实体／程序、信息、目标、分析长度，Unknown明确列出 |
| 对照 | 完全共同的预算，唯一变化或变化组，被释放资源如何处理 |
| 策略 | 合法知识、决策能力、规划范围，是否理论上界，未覆盖策略空间 |
| 轨迹 | 关键开工／完工／供料／支付／列序／终局，唯一实例去向；可引用固定证据，不抄全部日志 |
| 结果 | 胜负／未完、各结果维度、违反标准的最小反例、恢复与相邻扰动 |
| 归因 | 哪条约束先失效，改什么最可能改变结论，剩余替代解释 |
| 范围 | Derived或真实Observed等证据类型，条件通过／需调整／证据不足；不外推未测条件 |

某次结果只能证明其输入和策略范围。程序结果需先验证事件与规则对应；否则大量运行次数只是在重复模型误差。

### 12.2 确定性结果、场景覆盖和玩家样本分开

固定敌程序、固定状态与固定策略的重复结果，没有新增独立难度样本，不据此给出统计胜率置信。若以后策略或投放含随机，明确随机来自哪里，采用同样的隐藏状态／随机条件作成对对照，并保留不同条件的分层结果。

没有真实分布，只报告“已覆盖多少种条件，其中哪些有成功见证／不可行证明／尚未找到”。有明确目标分布后，才能给其加权成功率及不确定性；同时保留最坏情况和结构性失衡，不能让平均分掩盖它们。

真人测评按规则熟悉度分层，分别比较相同信息／预算下的选择。组内先观察行为，再询问理由，避免提前给最佳排程；次序效应、提示、学习和重复遭遇须记录或安排对照。只对获胜者比较剩余生命会产生选择偏差，失败样本及死亡事件也要并列。数学上能恢复、测试员读答案能恢复、玩家自己恢复是三种不同证据。

### 12.3 防止模型为自己证明自己

- 留出没有参与调参的邻近压力／物料组合，先固定目标与判定再看结果。
- 专门找合法的拖战、先屯甲、保留咒、放弃高阶、只用共同底盘等替代策略，不只跑设计者预期套路。
- 如果结论只在某一权重、特定初态、透视或理想补给下成立，必须把该条件写进结论。
- 将“未知取得”“未闭合携带”“搜索不足”“规则错误”“数值不合适”“玩家不理解”分别归因，不全部叫平衡差。
- 真实结果推翻假设时保留原假设及反例，修改方案后再测；不偷偷改正常场景定义来保住通过标签。

## 14. 推荐执行顺序与最小必需输入

本节是计划；本轮只完成规格及上述静态推导。

1. **先做模型正确性。** 用唯一实例、供料延迟、费用不足、回收再用、取消截止、打断退料、终局截断这些最小情境核对事件模型；规则错误必须先修。
2. **再做生产与生存界。** 固定初态、有限补给与最少合法敌压力，列冷启动见证及最早失败事件，不先扩完整整局。
3. **再做同预算策略与敏感性。** 从三构筑和石／药转向中选择最小子集，用§10测评包、反事实与关键交互找支配、断链及回本区域。
4. **再接取得／携带。** 接收C和总控的真实接口，复核成长可达性及战后拖战价值。接口未到时只完成条件边界，不伪装完整整局结论。
5. **最后补真人决策证据。** 在模型规则可靠、最明显结构问题已处理后，观察初见与熟悉玩家如何预测、选择和恢复；根据行为区分数值、信息与操作问题。

从设计模型进入“实际测评”最少还需要：一个明确玩家当前／上限生命；一份合法固定敌程序及敌生命；B01适用的疲劳／终局条件；此次是否包含跨战及其选留合同；明确执行范围和目标实现仓库（若需要程序）。当前没有这些输入，也没有本轮运行授权。

若采用真实项目材料，READ-1增补仍由用户明确选择版本与范围：共同量值可选`design/parameters.md`，携带可选`design/common/run-economy/rules.md`，敌情选用户指定的敌人／遭遇章节；本轮均未读取。也可由总控直接给最小参数包，无需扩大整份GDD阅读。

## 15. 一次测评最终应输出什么

建议输出一页结论，附必要固定证据，包含：**适用条件、合法性、可达性、有效策略／反例、主要瓶颈、优劣反转边界、失误恢复、改动建议及证据等级**。具体卡牌不逐张打一个总分。

结论使用以下顺序：

- 规则或输入自相矛盾：**阻断，先修模型／前提**。
- 找到违反已选平衡标准的合法反例：**需调整，附最小反例与归因**。
- 核心条件域、合理对照与相邻复核都满足标准：**该域条件通过**，同时列未覆盖范围；若只有数学结果，不写真人体验通过。
- 前提缺失、策略搜索不够、观察截止未结束或真人证据缺失：**相应维度证据不足**，不能将空白当通过或必败。

如果不同偏好下有不同不被支配选择，正常结论可以是“这两种选择都合理，适用条件不同”。如果一个选项在所有正常域都更优，即使平均伤害差很小也需要审；反过来，一个精心构筑在自己的合理优势域明显强，不自动判不平衡。

拖战有特殊的体验判定：若它只多花重复操作／用时，不付出生存、有限物料或携带机会成本，而且重视带出收益的玩家在正常域几乎总应拖延，按用户选定的BM-Q3列为需调整。这里不要求拖战在“更快结束”这一维也胜过及时通关；否则把用时列入结果后，模型会永远以存在时间交换为由漏报这种问题。增加机械重复时间在本稿口径下不足以单独证明战略代价合理。
