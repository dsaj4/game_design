## 2. 计数物同形，但各自保留含义

依据[领域语言](../../CONTEXT.md)的护甲／标记／整理行动点，以及[核心规则](../../design/GDD.md)TL-12／13／24和EX-004 §2—3：

| 计数物 | 现行意义与本场范围 | 呈现必须保留的区别 |
| --- | --- | --- |
| 生命 | 双方都有生命；归零按完整事件判终局 | 所属方与当前生命必须明确，生命上限仍可查；不能仅凭筹码高低判断是否存活 |
| 护甲 | 当前玩家累计防护；普通伤害先扣护甲，疲劳不扣护甲；本场敌人无护甲 | 与生命分列；用户所称“护盾”在此对应护甲数值，护盾卡仍是产生护甲的行动卡 |
| 施法次数 | 玩家现有标记；有上限，生效时可消费，锁定影响可消费量 | 实有、锁定、可消费要能同时辨认，不将同一数量抄成三份独立库存；生成行动牌尚未记层 |
| 其他标记／计数物 | 只有内容实际定义后才出现 | 统一呈现不赋予生命、护甲相同的标记支付权限，不额外给敌人新增状态 |

资源卡仍在中区左侧；成品行动卡仍在桌面或手牌。筹码呈现不把资源卡变为标记，也不把未来产出、预计收益或未结算护盾当成现有数值。整理点仍位于手牌区，是否也采用同一筹码外观留在第5节，不因“统一计数物”擅自迁到中区。

## 3. 首版细化建议（尚未确认）

- 每种计数物有稳定的位置、类型符号＋中文名称、筹码堆和准确总数。颜色辅助识别，不能独自承担类别或所属方。
- 生命总数建议用当前／上限形式；护甲显示当前总量；施法次数以实有为主读数，旁列锁定与可消费。具体排版仍需结合真实尺寸核对。
- 视觉堆叠达到上限后继续更新总数；**视觉高度上限不等于规则数量上限**。真实有上限的施法次数与无自然上限的护甲，分别沿原规则。
- 真正的0值建议保留名称和“0”，筹码堆为空；没有该计数物的对象不铺出一排假零状态。两种情形须可区分。
- 加减反馈先对应已结清事件及准确数值，再用筹码入堆／出堆或局部强调辅助说明。具体动画待效果阶段设计；静音、减动效与恢复静态画面仍能读到结果。
- 查看筹码可进入既有详情；筹码本身不默认可拖走、投注、合并、换算、手动加减或支付。消费锁定入口及受理阶段沿[TL-17／36](../../design/common/interaction-save/rules.md)，具体控件另定。

## 4. 玩家情境与待核对结果

此处是显示预期与检查计划，未执行；完整数值及战斗输入只在EX-004维护。

| 情境 | 需要读出的事实 |
| --- | --- |
| EX-004第0拍初态 | 上部敌生命、下部玩家生命／护甲／施法次数归属明确；资源区为空；顶部只有阶段和进度等信息 |
| 护盾完成生产，尚未结算 | 成品卡已入桌或入手，护甲与施法次数筹码不提前增加 |
| 护盾结算与后续记次 | 护甲增加和成功后记次分属各自已结清步骤；发生终局则不补后续记次 |
| 强化打击付款 | 实际付款只改变真实标记余额；卡上条件图形不等于预付，造牌或切换未来用途不扣施法次数 |
| 玩家锁定部分施法次数 | 实有不变，可消费按实有减锁定变化；结算开始后不能通过筹码或详情修改锁定 |
| 护甲累积超出可见堆叠层数 | 准确总数继续增长，不丢失、不截断，不误示已达到规则上限 |
| EX-004第10轮起疲劳 | 双方生命扣减，护甲不抵扣；共同事件后判终局，不能因动画先后展示另一个判定结果 |
| 保存恢复／胜败清理 | 恢复准确总数与既有锁定关系，不重播造成重复扣除；事件发生时读数与清理后的结果分别表达 |

希望达到的设计价值是：玩家在同一区域辨认敌我存量、观看增减，并准确判断可消费量。统一筹码外观能否降低阅读负担，以及大数时是否仍清楚，均为Hypothesis / NotRun。

## 5. 未知与下一步

按grill-with-docs核对已定术语和规则，必要选择按项目批量澄清处理；位置、是否顶部重复、有限堆叠＋准确总数已经闭合。余项为：

| 未知项 | 推荐方向及影响 | 下一步 |
| --- | --- | --- |
| 视觉层数上限与映射 | 控制图形高度、总数始终准确；不承诺每枚面额 | 在文字／HTML展示小数、大数、归零与增长，核对不会把显示上限看成数值上限 |
| 类型造型与0值 | 符号＋名称＋不同轮廓，0保留底位；敌我用区域和标识双重区分 | 比较可逆图形与排版，静态及灰度核对 |
| 锁定与可消费的控件 | 同一类筹码旁给实有／锁定／可消费关系；不增加可支付库存 | 补具体点击／键盘路径，沿现有免费锁解与阶段限制 |
| 整理点等扩展计数物 | 推荐可采用同一筹码语言，仍保留手牌旁的操作费位置；回合、列号与容量是进度／索引读数，不能机械套用库存筹码 | 随相关控件确认对象范围；本次明确范围至少包含生命、护甲、施法次数 |
