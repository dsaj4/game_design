# 统一卡牌与战斗回收：意图及审阅入口

2026-10-27 · game-002 · **Promoted / Accepted for scope：CORE-067**。本轮按开发启动包、CUSTOM读取；不进入探索、不读取代码，不进行游戏实现、程序模拟或玩法测试。仅记录意图、判断及必要来源，不保存逐字对话。唯一审阅入口：[Draft Change](../draft-changes/D-2026-10-27-unified-card-model.md)。

## 意图与资格边界

用户希望取消现行资源卡／行动卡的种类划分，统一卡牌，只区分「能投入战斗并回收」「能投入战斗但不能回收」「不能投入战斗」，目的是降低分类和理解负担，并便于设计配方合成。用户要求先查既有决定，以正常故事与改变选择的反例审阅，再补资格、提案／评估和Draft Change；新的取舍由用户集中判断，明确采纳后才同步权威、验收及任务包。

设计对象为卡牌身份、用途资格、生产与使用生命周期、战前投入和战后留存；目标落点是核心§3／4／8、TL-01／05／11／14／15／25／30／38／43及内容合同。预期价值仍为Hypothesis，理解负担与配方选择价值均NotRun。

用户已确认：投入战斗指上战斗行执行；可回收牌在卡效执行后回到手牌、立即可用；所有新产卡先入手牌，玩家手动上战斗行；手牌采用持牌展示，分可战斗与不可战斗两组切换查看，取消手牌堆。上述取舍不重问。用户随后确认Q01—Q06均按推荐，已采纳为CORE-067；具体结果只在D记录，不抄问答。

## 改前基线的正常故事与反例

以下仅保留共同输入版本中的改前合同，用假设材料甲及其合法配方说明当时的中介行动路径；CORE-067已替换该路径，不能再按本段实现现行规则。不发行具体卡或数值，不作游戏模拟。

**正常故事：**玩家战前把可携带材料甲投入本场。一台法器开工托管甲，另一台不能再用同一份。完工时甲被消费，得到一张产生材料乙的行动；此时乙还未取得。行动在回合末成功生效后才有乙，最早下一生产拍可供下一道配方。胜利后只把实际取得且有携带资格的余料与未投入库存一起检查容量，选择带走。依据：CORE-058、TL-05／11／15／25／43。

**会改变选择的反例：**预计本轮前列即可胜利，而加工产出的资源行动排在更右列。若已经完工，甲已消费；提前终局会停止后列，乙不会生成，甲也不退款。若玩家想把甲留给下一战，应在开工承诺前保留／锁住甲，不能在已开工后撤销。未完工战终则按普通材料退回及携带资格处理。由此可见「可回收」若意味着未消耗材料带回，与「使用后原卡仍回来」是两种会改变选择的设计。依据：TL-07／13／15／25／30、消费锁定合同；特殊催化剂不在此例内。

改后正常故事与改变选择的反例现集中在[D的场景对照](../draft-changes/D-2026-10-27-unified-card-model.md#正常故事与反例)，依据已确认的U1B／U2B及Q01—Q06采纳结果解释。三种权限不自行授予任意配方、复制实体或跨战保存。
