## 从已采纳规则推出的窗口关系

以下关系只从SYS-002／003／007与CORE-051–053推导（Derived），用于给敌牌定Δ，不是新规则。设应对法器X在揭示拍r空闲、可用完整材料与容量、前方无排队，玩家在r拍观察窗口提交临时方案：X于r拍末开工，r+D拍完成入行，最早r+D+1拍生效。

| 关系 | 条件 | 设计含义 |
| --- | --- | --- |
| 防护赶得上 | Δ ≥ D_防 + 1 | 在T已有资格的防护按TL-11先于伤害 |
| 取消赶得上 | Δ ≥ D_取消 + 2 | 取消须e＜T；同速度下取消比防护多要1拍 |
| 余量 | 每1拍缺料、缺位或前方排队，以上下限各加1 | Δ>0本身不保证可应对 |
| 打断危险开工带 | 在a∈[T−D_X, T−1]开工的批次会在T被打断 | a+D=T的批次也先受打断（TL-11） |
| 揭示前批次安全 | Δ ≥ D_X时，揭示前已开工的批次不可能落入危险带 | 打断只约束揭示后的选择，不形成不可避免的税 |
| 抢跑 | Δ ≥ D_X + 1且X在r空闲有料，可在r拍末开工并在T前完成 | 抢在危险带前做完一批 |
| 停供结束拍 | 规避打断的临时方案结束拍须≥T | 结束拍为T时，T拍边界恢复基础，T拍末开工已在打断之后 |
| 双威胁反应路线 | 打断防护法器的T_断与伤害T_伤满足T_伤 − T_断 ≥ D_防 + 1，且防护入行时前方没有同拍或更早的牌 | 等打断过后再防仍来得及；否则只剩预判或取消 |

按Δ相对应对者D，首批使用三档窗口词汇：**紧窗**（只够已在手或立即开工的防护）、**可消窗**（Δ≥D_取消+2，允许取消）、**宽窗**（能容忍至少1拍排队或缺料）。它们是内容设计用语，不是新规则。

## 敌人表现总纲：「字身」

核心意象：**玩家在写，敌人在念。**玩家的法器是留空的暗句，需要铭文补齐；敌人则是“已经写定的句子”，其暗牌程序就是它要念出的台词。敌人的身体由它的句子构成，每个规则状态都对应一种可见的书写动作。

| 规则状态 | 「字身」表现 | 必须同时给出的文字／符号 | 不允许 |
| --- | --- | --- | --- |
| 暗牌（揭示前） | 卡背只露一个部首：刂（刀部）＝普通伤害，斤（斤部）＝指定打断；其余部首保留给未来类别 | 类别文字；若阶二Q04采纳，另标程序位置与翻开拍 | 部首粗细、颜色或姿态暗示数值、目标或Δ |
| 揭示r | 整字显形（如「剐」「斫」），字的末笔拉出墨线连到锁定目标 | 完整效果、目标、T、可否取消 | 只靠墨线方向表达目标 |
| 倒计时 | 字按Δ等分为若干笔段，每拍补写一段；最后一笔落下即到期；减动效时改为静态分段 | 剩余拍数与T数字 | 只靠写字速度或抖动表达截止 |
| 到期T | 字离开敌身，扑向目标 | 结算记录：伤害／护甲吸收／打断结果 | 动画先后影响结算 |
| 成功取消 | 字被涂抹，原位置留下方框「□」，直到原T拍过去 | “已取消，空档保留至T” | 后续字提前补位 |
| 打断落空 | 笔锋扫过空着的法器，出现“飞白” | “目标法器无处理批次，无效果” | 产生资源或任何额外效果 |
| 段尾循环 | 敌人“重念”其句，新一轮字从卷首浮现；上一轮未写完的字仍在继续补笔 | 遗留牌的T照常显示 | 段尾清空旧倒计时 |
| 敌人死亡 | 句断墨散 | 已揭示牌去向按阶二Q10 | 用对象清理默认取消已揭示牌 |

这套语法同时服务可读性：部首是常用汉字知识，玩家看卡背即知类别；笔段是倒计时的直观化；方框让“成功取消换来的空档”可见。形态只外显已公开的规则状态，不泄露暗牌内容，也不暗示与规则不同的结果；每项视觉必须有点击／键盘可达的文字与数字对应（SYS-007 TL-17／36）。

## 首批候选

三名候选对应两类压力入口和一个少量双威胁。共同假设：敌人在所示区间不会死亡；不跨战、不含疲劳、维护或终局；每批一张、单一效果、稳定合法目标，沿阶段一案例限制。玩家组件沿阶段一分析代号A（攻）、B（防）、C（取消）、W（长耗时重击）的职能，具体D、数值按各套组单列，**不证明这些组件已有合法铭刻或配方**。

逐拍时间线已手工推演，并用一次性本地算术草稿逐拍复核（未入库；不是规则实现、模拟器或玩法测试）。

### 敌甲：吞刃蟾（延时普通伤害基准）

**形态速写。**一只砚台腹的老蟾，蹲在敌行里慢慢嚼墨。它吞下的是刀：揭示时，喉囊里显出一个带刀部的字，倒计时每过一拍，喉囊就鼓起一节，字多写一笔；字写完，它张口把这柄“字刃”吐向编排者。小招「刮」只是舌头一弹；大招「剐」会让整个喉囊胀成半透明，字里的刀光清晰可见。被取消时，它“噎住”——喉囊瘪下去，嘴边贴着一个方框，直到原到期拍过去才重新开口。不出招时它只嚼墨，提示普通区间无需操作。

**压力意图：**改变“材料给攻势还是给防护”的选择；大招是唯一的关键威胁，小招让玩家学会不必对每个倒计时出手。

| 字段 | 内容（Illustrative） |
| --- | --- |
| 身份／生命 | 单敌；生命Unknown，假设本区间不死；无护甲 |
| 程序与循环 | 循环L=6拍，固定时间表：偏移1揭示「刮」，偏移3揭示「剐」 |
| 甲1「刮」 | 卡背刂；Δ=2；普通伤害2；目标锁定玩家；**不可取消** |
| 甲2「剐」 | 卡背刂；Δ=3；普通伤害8；目标锁定玩家；可被明示取消刀部敌牌的行动取消 |
| 同拍与跨段 | 各T为6k+3与6k+6，无两牌同拍到期；「剐」到期正落在下一段首拍，为合法段尾遗留，不与新段揭示冲突 |
| 环境（套组甲） | 初始M×1第0拍可用；每拍补给M×1，下拍可用；Q=2 |
| 玩家套组甲 | A：攻3，D=1，M×1；B：防6护甲，D=1，M×1；基础法器序A→B |

以首段「剐」r=3、T=6为关键窗口（Δ=3：对B有1拍余量，对C是零余量的可消窗）：

| 路线 | 3–6拍关键事件 | 截至T=6 | 代价 |
| --- | --- | --- | --- |
| 维持 | A每拍兑现，B始终无料 | 生命−8 | 无攻势损失 |
| 临时B优先，结束拍4 | 3拍末B开工，4拍入行，5拍得6甲；4拍末A恢复 | 「剐」被吸6，生命−2 | 少1次攻击（−3） |
| 临时B优先，结束拍5 | B在3、4拍末各开工；5、6拍各得6甲，6拍防护先于伤害 | 生命−0，余甲4跨拍保留 | 少2次攻击（−6） |
| 套组甲′（A＋C，C：D=1，取消一张可取消的已揭示敌牌） | 3拍末C开工，4拍入行，5拍生效＜6 | 生命−0，6拍留空档 | 少1次攻击；C平时无对象，基础方案不宜供料 |

三条防护路线与维持之间是真实的生命换攻势取舍；取消在本窗口最省，但它要求战前用法器位换掉B，面对不可取消的「刮」毫无作用。若「剐」Δ改为2，取消立即失效而防护仍可赶上，这是调“可消窗／紧窗”的直接旋钮。提前一拍对「刮」叠甲也可行：护甲不自然到期，6甲能同时覆盖「刮」2点与「剐」4点。

**失效定位：**没有防护或取消组件→配置缺口，只能承伤；反应晚一拍→时序缺口（Δ=3只给零余量取消）；B有料但队列被已有攻击占满→阶段一案例丙式容量缺口。

### 敌乙：拆字鸦（指定法器打断基准）

**形态速写。**一只墨羽乌鸦立在编排者法器上方的笔架上。揭示「斫」时它歪头，喙尖拉出墨线钉在一件法器上；笔架的每根笔杆代表一拍，它每拍向目标跳一根杆。被盯上的法器下方投出羽影，覆盖“危险开工带”。到期时，如果那件法器正在加工，乌鸦一口啄进半成品，把写到一半的行动卡拆成笔画，笔画飞回资源区并标“下拍可用”——正对应退料规则；如果法器空着，它啄空、踉跄，一片羽毛飘落，没有任何资源。闲时它理羽、打量全场。

**压力意图：**改变“何时给长耗时法器供料”的选择，教会玩家看危险开工带、用一份临时停供方案让法器空等，或承担返工。

| 字段 | 内容（Illustrative） |
| --- | --- |
| 身份／生命 | 单敌；生命Unknown，假设本区间不死；无护甲 |
| 程序与循环 | L=8，固定时间表：偏移2揭示「斫」，偏移5揭示「刺」 |
| 乙1「斫」 | 卡背斤；Δ=4；打断目标法器当前处理批次，不造成伤害、不摧毁法器、不影响已入行牌；揭示时按“战前法器序中D最长者，并列取序前”锁定（阶二Q06）；可取消 |
| 乙2「刺」 | 卡背刂；Δ=2；普通伤害2，锁定玩家；不可取消；普通伤害不中断法器 |
| 同拍与跨段 | 各T为8k+6与8k+7，无同拍到期，无跨段遗留 |
| 环境（套组乙） | 初始M×1；每拍补给M×1，下拍可用；Q=2 |
| 玩家套组乙 | W：重击9，D=3，M×1；A：攻3，D=1，M×1；基础序W→A |

首段「斫」r=2、T=6锁定W，危险开工带为3–5拍（Δ=4≥D_W=3，0拍开工的批次3拍完工，安全）：

| 路线 | 关键事件 | 截至11拍造成伤害 |
| --- | --- | --- |
| 维持 | W 3拍完工后自动于3拍末续开（落入危险带）；6拍被斫，退料与释放容量7拍可用；W另有可用料与独立空位，6拍末重开，9拍完工 | 27 |
| 2拍提交停供W，结束拍6 | 3–5拍W空闲，空出的容量让A连续兑现；6拍「斫」落空；6拍末W开工，9拍完工 | 33 |
| 停供W，结束拍5（过早） | 5拍回基础，W于5拍末开工仍在危险带，6拍被斫 | 30 |

本套组下，两条“W 6拍末开工”路线的重击都在10拍兑现；维持路线真正损失的是被砍批次在3–6拍白占的材料与队列容量，挤掉了A。结束拍少设一拍就会落入危险带，这正是界面需要直接标出“结束拍须≥T”的原因（阶二Q15）。

**现实检查发现：**单张打断在替代用途充足时，“停供规避”几乎总是优于承受，选择可能退化为唯一答案（GDD支柱偏离信号“每次只有唯一应对”）。拆字鸦因此定位为**教学基准**：检验“读懂危险开工带并调整供料”；真正的取舍交给敌丙，或在阶段三让W的停工有真实机会成本（如W专用的绑定材料、W是唯一重击来源）。若玩家全用D=1的快法器，危险带只剩T−1一拍，损失也只有一拍——这是长耗时构筑的天然弱点，属于有意的构筑差异，需在阶段五核对不是固定优解。

**失效定位：**未设或过早结束停供→时序缺口；W为唯一输出且无替代用途→配置缺口（停工代价过大）；想暂停正在加工的批次→能力缺口，现行规则不提供（SYS-002 TL-06）。

### 敌丙：双卷门神（少量双威胁特色）

**形态速写。**一对悬在门框上的春联卷轴，横批是它的脸。横批写着它的主机制「断而后劈」——这正是出发前可见的遭遇主机制（SYS-005 TL-32），以字身的方式挂在敌人头顶。右卷上联先展开，显出斤部的「断」，墨线钉住你的防护法器，像把门闩插上；左卷下联随后展开，显出刀部的「劈」，墨线指向编排者，卷轴随笔段增长慢慢抡起。若上联被取消，门神“失对”：右卷只剩一个方框，下联孤零零地照旧劈下。

**压力意图：**两张牌互相咬合——打断恰好压在防护的自然反应时段上。直觉反应（见劈即防）会被打断；玩家需要读横批与卡背预判、等打断过去再精确供料，或在战前用法器序改变默认攻守。

| R3b 等断过后只供B，结束拍7 | 5拍 | 5、6拍末A停供；7拍只有B入行，8拍防护先于「劈」 | −2 | 21 |
| R4 预判 | 2拍 | 上联揭示即抢跑：B于2拍末开工（危险带之前）→4拍入行→6拍得8甲；5拍「断」落空 | −2 | 21 |
| R5 战前序B→A | 战前 | B默认优先，2拍入行、3拍得8甲；3拍续开被断，不影响已有护甲 | −2 | 9 |
| R6 取消上联（A＋B＋C） | 2–3拍 | C于2拍末开工→4拍取消「断」（＜5）；B 3拍开工→7拍得甲 | −2 | 18 |

这里有两类陷阱和三条成立的路线。R2是最自然的直觉，却同时丢掉防护与攻势；R3a显示同拍入行按战前法器序的后果——防护“做好了”但排在攻击后面。R3b与R4代价相同（生命−2、少6伤害），区别在于是“等信息完整再精确操作”，还是“读横批与卡背先下注”；R5把同一判断前移到战前，换来持续偏守的攻势损失；R6需要同时持有三种组件，是否值得由阶段三的真实获取与法器位决定。

R4依赖玩家在2拍就知道下联是刀部卡、3拍翻开（阶二Q04）。若不公开翻开拍，R4变成盲赌，门神会接近“背板”体验；这是本候选最大的理解风险，归TL-Q10后续验证。

**失效定位：**B的D=1时危险带只有一拍，门神失去咬合→配置使其退化；T_伤−T_断＜D_B+1时反应路线消失→内容时序过紧；玩家看不出同拍入行顺序→表达缺口，需阶段四展示预计生效拍（SYS-007已要求）。

## 阶段三配套需求

以下只描述敌人压力成立所需的玩家能力，交阶段三与真实法器、铭文、行动和配方一起设计；不能把这些能力当作已拥有组件。

| 敌候选 | 需要阶段三提供 | 成立条件（相对式） | 缺少时 |
| --- | --- | --- | --- |
| 吞刃蟾 | 至少一种防护行动；攻防争用同一种基础材料；可选一种明示“可取消刀部已揭示敌牌”的取消行动 | 「剐」Δ ≥ D_防+1；若要允许取消，Δ ≥ D_取消+2；补给速度接近攻势消耗，转料才有代价 | 只能承伤；HP预算需由阶段六串联 |
| 拆字鸦 | 至少一个D≥2、停工有真实机会成本的法器（专用绑定材料或主要输出来源） | 「斫」Δ ≥ D_目标；临时方案能对单个法器停供，结束拍可设为T | 全快法器时压力很弱；需接受这是构筑差异 |
| 双卷门神 | 防护法器D≥2；战前法器序可让防护前置；临时方案能停供攻击法器 | T_伤−T_断 ≥ D_防+1；双方T不同拍 | 防护过快则失去咬合；无防护则退化为蟾式承伤 |

推荐阶段三从用户种子“剑与盾之符＋攻击／防御”出发（[SYS-001 TL-45](../../design/systems/01-grammar.md)），先形成一对真实的攻／防法器，再补一个长耗时法器与一个取消法器候选；随后把本页Δ按真实D重标。种子本身仍不是已发行身份。

## 现实检查（Quick Reality Check）

**结论：Plausible but unproven。**规则层面三名候选都能产生不止一种可解释的应对（Derived）；最弱一环是拆字鸦的单张打断可能只有一个明显答案，其次是门神预判路线依赖玩家读懂翻开拍与同拍入行顺序。
