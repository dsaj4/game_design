## 2. 已经清楚、应保留的部分

| 阶段 | 可以保留的结构 | 仍不能据此断言的事 |
| --- | --- | --- |
| 效果语言 | 获得／消耗＋数量＋对象；法器生产用炼成；替换、额外、成功依赖各有职责 | 动词一致不意味着资源、标记同一时点可用，也不意味着所有减少都属于支付 |
| 物件信息 | 固定定义、装配结果、运行状态分开；制造、整理、卡效费用分开；当前批次与未来用途分开 | 信息清单齐全不代表玩家第一眼能读懂；实际呈现与理解仍待检验 |
| 世界与分类 | 遗孤探索失落知识；文明消失而世界仍在；物质界遭遇触及文字界；赌桌是主角认知；分类＝法术体系 | 连接成立不等于铭文实体的稀缺、战斗进入条件和不同体系的实际差别都已解释 |
| 炼金与稀有度 | 三原质限炼金内部；稀有度表达原理层次与力量；两者不排成同一高低阶梯 | 原理深不自动等于词条复杂、任意改规则或每场战斗都更适用 |

可追溯的当前链条是：合法铭文配置 → 承诺的加工与用途 → 成品 → 整理后的执行机会 → 按步骤产生结果与「咒」余额 → 后续步骤／列的支付选择。批次、成品和即时余额分别传递不同状态；结算列不推进生产。跨战探索与收集怎样返回下一次构筑尚未在本轮材料中闭合，不能以单战链条证明整局成长成立。

## 3. 需要优先处理的问题

下列“歧义风险”指玩家可能误读，尚无真人误读记录；“设计未定”不冒充规则矛盾。“先处理”指继续扩内容前的决策价值，不要求本轮采纳建议。

### 3.1 复合行动的短文掩盖了步骤间隔

**类型：表达风险；规则本身有答案。** 语言§3.2、§6.1和信息§6.1都知道简易护盾的护甲在防护组、「咒」在其余组，但短文“加护甲；成功后获得1「咒」”容易被理解为连续结算。实际按TL-11，同列敌方其余步骤会介于玩家加护甲和获得「咒」之间；若其间终局，后一步不发生。

推荐把会影响本次选择的顺序解释放在读者判断该牌的情境中：例如“先加4护甲；本列其余效果轮到我方时，若加护甲成功且战斗仍在，获得1「咒」”。这是表达候选，准确组序仍引用规则；不要求每张卡都堆技术字段，也不替A决定布局。强化打击的足额支付应能看出是自动分支，避免误读成结算时再手选。

同样，“获得2资源”与“获得2标记”的最早可用时点不能仅靠统一动词区分。前者当前规则最早下一生产拍可用，后者在具体对象支持时可被后续步骤／列读取；中间工序直接炼成共享资源的可用时点仍未决，不能套用前者作为已确认答案。

### 3.2 三原质已有语感，尚无稳定归属标准

**类型：设计未定，高优先。** 世界§4给出固持、流转、激发及可能用途，但“保存能量再释放的护盾”同时沾到盐和硫；“传递伤害”也可能沾到汞和硫。只按最终效果分，会退回盐＝防御、汞＝辅助、硫＝攻击；只按宽泛动词分，又可能任何物件都能解释成三者。

推荐以其在某个明确用途中的主要作用判断：固持保存或稳定什么，流转传递或转化什么，激发释放或集中什么。每次归属至少有一个近似反例。单一性质还是多性质、材料性质是否固定及能否转化，仍须明确；不靠文案自动决定。

另外必须区分“盐这一实际材料”“盐性这一性质”和“盐性材料的份数”。若写“需要2份硫性材料”，就要能回答可否混用两种材料、每份怎样计量。首版建议先用性质资格＋材料份数，不先增加硫含量、纯度等第二套数值；需要它们改变具体选择时再讨论。多性质物件也不能不经声明就在多笔消费里重复计数。

### 3.3 分类的含义已定，分类落在哪里还没定

**类型：设计未定，高优先。** 世界§6已经明确分类＝法术体系；信息§4分别列法器、铭文、行动等信息。但法器有多个用途、铭文可用于不同合法组合：器具自身所属体系、当前用途使用的原理、最终行动的体系，是否相同尚未规定。

反例：假设某器具支持两个体系的不同用途，它炼成的牌应写器具的体系、该用途的体系，还是两者并列？切换未来用途是否会改已有牌标签？若分类以后被配方或卡效读取，这会成为实际结算差异。

推荐先让分类说明“该对象实际采用的法术体系”，具体内容明确声明；器具支持范围与产物身份分别记录。旧批次和成品不因未来设置自动换类，沿已有承诺边界。不要把生产来源等同于自动继承所有属性、稀有度或体系标签；多体系器具和通用铭文的完整规则保留待设计。这不是要求每件对象都有一个额外新字段。

### 3.4 学会铭文与拥有铭文之间，还缺一条世界内解释

**类型：世界观与系统的衔接缺口，高优先。** 用户背景强调学习／收集以及天生会刻印；TL-26要求一实体一位置，同名多位置需要真实副本。世界§2已经提出“识读、理解、持有实体”不同，但尚是候选解释。若玩家理解为“记住写法就能随时重写”，实体争夺、重复收集和装配占用的理由会变弱。

推荐补足一句可反复使用的世界规则：**字形可以临摹，能生效的意义必须由铭文实体承载；刻印安置／转刻已有的效力，不凭临摹增加一枚。** 这是待审世界解释，延续既有实体规则，不增加新货币、耐久或永久知识点。重复收集提供第二个可用实体，理解同一种原理则可以承载叙事发现；具体学习资格、转刻方式和跨战保留仍未知。

### 3.5 稀有度需要可比较的力量依据

**类型：设计未定，中高优先。** 世界§7的“复现现象／掌握规律／触及原理”是解释锚点，尚不是档位。如果深层原理只体现为更多条件或更长说明，玩家可能无法知道高稀有度强在哪里；如果稀有度又保证在所有配置中都更优，低稀有度件可能很快失去比较价值。两种风险均未被实际内容证实。

推荐每个高稀有度样本选一个相同职责、相近使用条件的参照，说明优势来自量值、成本、适配范围还是新增能力，以及需要何种条件才能兑现。保留用户已定的“层次与力量”，不把稀有度改成纯复杂度或仅取得频率。高稀有度物件可以更有力，而具体配置仍可能更需要便宜、稳定的组件；是否出现全面替代由具体内容判断。

法器、铭文及产物的稀有度是否相互影响还未决定，不能自动取最高、相加或继承。资源阶级也不先与稀有度合并。先有少量可比较样本，再定档数与名称；频率和经济仍由C对接。

### 3.6 信息维度已分开，学习入口还可能过密

**类型：理解假设。** 信息§3—4和世界§6已经区分对象种类、法术体系、体系内性质、行动类别与稀有度。若这些都在初次取得时同等强调，玩家可能先记五套术语，再去找“我能用它做什么”。“分类／类别”在玩家语言里尤其相近。

推荐在具体比较情境优先回答用途、关键代价和兼容，体系／性质只在解释来源、材料资格或联动时强调。玩家称呼可明确用“法术体系：炼金”“性质：硫／激发”，现行攻击等类别保留其职责；对象种类不另包装成世界观等级。通用标记也不因来源体系不同被复制成多个余额。该建议属于信息优先级，具体交互仍交A。

### 3.7 赌桌解释与炼成用语仍有两处可补的连接

**类型：待补世界解释，不是现行规则冲突。** 赌桌属于主角认知已确定；文字界交锋有真实后果已确定。尚可补充的是：何种冲突会触及文字界、身处物质界的对手与环境为何不能绕过这次交锋。此项影响遭遇叙事，不必现在解答文明消失真因或骰子谜团。推荐为一次已知遭遇写清“如何发生、双方承受什么、结束后物质界留下什么”，暂不新增第二套物理战斗或自由逃跑规则。

另一个词义张力来自“炼金”是具体体系，而“炼成”已确定为所有法器的生产词。推荐将炼成解释为法器把已准备的意义固化成可用产物的共同过程；炼金则是其中研究材料与转化的一种体系。这样保留统一动词，也给其他体系留出空间。此为解释候选，不重新打开用户已确认的命名选择。

赌桌体验可以先依靠已有的投入、保留、兑现与未公开威胁之间的取舍来表达，是否足以产生赌局感仍待验证。骰子记忆不必立即承担随机机制；筹码意象也不能让金币、整理点与「咒」失去可辨的身份。先让已定玩法支撑意象，再判断是否真的需要新增规则。

### 3.8 候选词条需要保留失败和反制空间

**类型：已有风险的复核，不扩大词条资格。** 语言§5的专注在整个批次内免打断，且不改变原锁定选择；若某内容能持续吸引并承受打断，它可能同时保护自己和其他法器。这个收益需要作为组合收益检查，不只给“本器少丢一次进度”定价。是否稳定成立取决于敌方锁定、D及取得／机会成本，当前不能判为已存在的支配策略。

封缄的更右、公开、可取消和最左目标限制已写清；EX-004没有满足其成功展示所需的后续位置，是样本覆盖不足，不是词条无效。首版词条应先配一个合法目标和一个相似但非法目标的静态说明，之后再讨论参数。消耗表示支付，也不宜扩张为到期消失、遭敌削减等所有减少；若未来出现这些行为，按其实际原因写清，不为统一动词改变含义。

## 4. 创意优化：让已有概念承担更多理解价值

以下均为原创候选。优先考虑不增加机制层数的方案；不是新职业、正式物件或已采纳权限。

| 方向与改动方式 | 具体做法与玩家判断 | 价值假设与取舍 |
| --- | --- | --- |
| **先见作用，再理解原理**：重排信息学习顺序 | 在首次实际接触中用“效果／用途 → 为什么可用 → 体系与性质名称”连接解释。规则全文随时可查，叙事发现可以逐步补足 | 玩家先形成可操作判断，再把神秘名与经验连接；不能把费用、失败或兼容藏作剧情解谜。无需新增熟练度／知识点 |
| **同一性质，两种用途**：替换最终效果，保留原理 | 例如候选硫性攻击与硫性防护都明确支付储备以集中释放，但前者追求伤害，后者为承受威胁作准备。是否归硫以释放机制为据，非看攻防标签 | 用一个对照就能说明硫不等于攻击。每项仍独立声明目标、步骤、费用、结果与回退，不直接改现有牌，也不把盐／汞／硫做三个职业 |
| **用物件揭示文明的共同知识**：连接构筑理解与叙事线索 | 不同器具出现同一铭文原句或可辨认的语义结构；已会的原理帮助理解新器具的一项合法用途，文献再解释两者为何相通 | 同一知识既帮助构筑，又成为认识古代文明的线索；共同原句不自动给予兼容、隐藏整句奖励或永久解锁。文案与物件关系需要人工编排 |
| **少量明确的跨体系接口**：把连接放进具体配方／用途 | 待第二体系有真实内容后，让某一用途明确接受炼金材料，列出转换结果与代价；一份材料只按实际配方消费，不凭近义标签自动通用 | 避免体系完全隔绝，也避免所有材料通吃。可能催生混合构筑，但增加配方负担；当前先暂缓，不急着加“翻译术”或新资源条 |

初审曾推荐前两项；用户后续选择第一项和第三项，并将第二项所举的攻防对照调整为配方与生产对照，见本文开头的续审决定。第四项仍以前提成立为限：第二体系须已有不同的实际决策，不能只为展示混搭而新建一套体系。

设计侧可以为未来每个体系写一张短说明：**它怎样解释力量 → 玩家反复权衡什么 → 通过哪个对象改变何种状态 → 明确的限制是什么**。炼金可围绕材料选择与转化展开；其他体系需拿出不同选择，不能仅换资源名或伤害颜色。共用获得／消耗／炼成并不要求各体系具有相同玩法。

| 短文是否足以说明顺序与支付 | 简易护盾的两组步骤；强化打击实有5但锁定1；致死后不再获得「咒」；获得资源与标记的不同可用时点 | 请读者先预测顺序、付款和可用量，再解释理由；若知道共用规则仍误读，改写入口说明；仅不知规则则先调整教学。不给帮助后的答对当作独立理解 |
| 三原质能否帮助判断材料资格 | 一个明确允许性质替代的候选配方、两份合法但不同名的材料、一份名字或稀有度显得相似却不合性质的材料；另对照精确身份配方 | 能根据明示要求判断，而非只猜名字／高低档，才支持这组样本的表达。若设计者自己无法给唯一答案，先补规则，不能把问题归给玩家 |
| 高稀有度是否表达实际力量 | 同职责、相近约束下的两个待审物件，列真实优势、代价及一种不适配情境 | 读者能说出强在哪里、何时当前配置仍用另一件；若只因颜色选择，不能据此证明原理解释有效。平衡还需后续完整情境 |
| 世界解释能否支持收集行为 | “看过字形”“拥有一枚”“拥有两枚”的叙事情境，沿一实体一位置判断能同时装几处 | 能区分知道写法与持有可用实体，支持该解释的局部清晰性；不能据此证明收集动机或剧情吸引力 |

不预设任意通过百分比。修订依据是反复出现的误读及其原因；若仅靠现场补充才能答对，先处理遗漏。材料配方与稀有度样本尚需设计，因此此处是验证方向，不宣称整套计划已具备执行条件。
