# 最小描述驱动的 Agent 游戏原型探索调研

日期：2026-11-12。状态：Raw Idea / Unqualified。类型：开发探索方法的输入摘要与研究记录；不是正式 Evaluation、GDD 或实施任务。

现有研究支持将简短设计意图、按需读取、稳定工程骨架、自主验证和多候选比较结合起来，用于探索可玩原型。尚未发现直接证明“复杂原创游戏只保留核心构思与画面要求，多次独立生成后择优吸收”这一完整流程在言咒规模上优于持续迭代的对照研究。最值得验证的收益是降低人的规格编写与指导成本，并提高可借鉴方案的产出。

## 附件能支持什么

TeamMingo 的 HTML 标注整理于2026-11-09，作者自述经验来自六个游戏项目、四个月和4272次提交。本文未独立核验其项目仓库或提交数。两份附件主要构成同一套经验和对应执行提示，不是两份独立证据。

最相关的经验是：短入口文档、按需加载模块资料、固定共享骨架、逻辑与表现分离、内容数据化、统一检查入口，以及可读取状态并执行动作的调试接口。它们降低了 Agent 找资料和确认结果的成本。

作者也明确限定为 FNA／C# 的2D游戏经验，架构和验收由人设定，美术、音乐仍有人工精修。材料没有提供一次生成成功率、失败样本总量或同预算对照，因此不能证明短描述本身足以获得完整游戏。

## 对言咒的判断

渐进披露与设计授权需要分别处理。前者保留既定规则，只在需要时读取；后者允许 Agent 补全或改变未限定的细节。只给核心构思和画面要求，更接近后一种探索方式。将省略的规则继续当作隐含验收标准，会让候选既无法自由探索，也无法可靠复现主系统。

按已读核心，言咒不仅有炼金或卡牌题材，还包含材料转化、生产时间、战斗排布，以及同一卡牌立即使用、循环使用或消耗加工之间的选择。若输入只剩“炼金卡牌游戏、神秘桌面”，这些关系可能被常见类型套路替代。这是根据核心规则作出的风险推论，尚未通过生成实验验证。

建议将未来实验输入拆成四类，但不在本轮指定它们的正式内容：

1. **核心意图与可观察行为。** 玩家反复做什么选择、选择怎样改变结果、希望看见什么反馈。保留因果关系，比罗列系统名更有用。
2. **画面与交互要求。** 除风格外，描述玩家要看懂哪些状态、哪些对象可以操作、操作后怎样反馈；未来可加入明确授权的参考图。本轮没有读取言咒视觉材料。
3. **自主空间与硬边界。** 标明哪些规则必须保留，哪些数值、内容量、局部机制可由 Agent 自定；自定内容只属于该候选。
4. **工程交付合同。** 可启动、可操作、能完成选定循环、能观察状态、能复现关键动作；给定每次尝试的预算与停止条件。细分工具规范按任务需要读取。

“一次实现”宜定义为人只交办一次，Agent在预算内自主计划、编写、运行、看结果和修复。若禁止内部修复，将失去上述最相关实践中的关键反馈环节。

附件中值得先借鉴的是统一入口、固定骨架、数据与逻辑边界、可复现交互和隔离测试存档。多平台、自建完整共享引擎、双语、全面存档迁移等是否进入首批探索，应按任务必要性裁剪；不能直接照搬作者已有成熟项目的全部基础设施。

## 多次尝试与吸收方式的候选建议

先用相同最小描述、相同骨架版本、相同工具权限和预算，做少量彼此不读取结果的独立尝试。它们可以顺序执行。这样才能先观察随机性带来的差异。若每次同时更换提示、模型和引擎，就难以判断收益来自哪里。

另设一轮有意识的变化，例如改变信息组织或反馈节奏；将“重复采样”和“不同设计假设”分别记录。二者都可能有价值，但不是同一个实验。

筛选时分别看：

- 技术可用：真实输入生效，核心流程可完成，状态与画面一致。
- 意图符合：核心选择确实存在，没有被简化为另一种常见玩法。
- 体验价值：人试玩后是否愿意继续、能否理解选择及后果。
- 吸收成本：某个优点能否说明其成立条件，迁入主系统会影响哪些规则。

Agent可以筛查明确的功能条件，最终的趣味和取舍仍需人的试玩判断；作者自写的检查不能单独证明其设计判断正确。记录未通过的候选、总耗时和人工介入，避免只保留最好截图。

吸收单位优先是一个可解释的交互、反馈、布局或机制关系。可记录“在哪个情境看到了什么效果、为何值得借鉴、依赖什么规则”，再决定是否重做实现或迁移代码。原型的独立选择不自动成为主系统规则；回写沿现有资格与采纳流程。

## Unknown 与下一步

- 新空间的目标是忠实实现现行言咒的一个切片，还是保留体验意图后允许规则变体？目前未确认。
- 首批必须保留的玩家选择、允许省略的系统与内容量、画面参考均未确认。
- 引擎、资产条件、每次预算、尝试次数、交付规模和试玩者未确认。

后续若授权实验，可先比较相同切片、相同总预算下的两种输入：必要的详细规则包，与最小意图加明确自主空间。两组均允许内部验证和修复，记录多次结果、人工指导时间、意图偏离、试玩价值与吸收成本。样本少时只作可行性观察，不宣称统计优势。
