# 行动卡池完整设计（基于标记系统）

日期：2026-10-08。项目：game-002 / 言咒。状态：**Content Design / Illustrative**。本文档基于标记系统设计完整行动卡池，覆盖攻击▲、防御■、打断⊘、其他✱四类。

---

## 设计原则

### 1. 卡牌职责划分

| 种类 | 核心职责 | 标记关系 |
|------|----------|----------|
| **攻击▲** | 造成伤害，施加负面标记 | 产出敌人负面标记，消耗玩家正面标记 |
| **防御■** | 获得防护，施加正面标记 | 产出玩家正面标记 |
| **打断⊘** | 取消敌牌，施加控制标记 | 产出敌人负面标记（控制类） |
| **其他✱** | 资源转化，标记生成与转化 | 产出/转化/消耗标记，不直接伤害 |

### 2. 标记设计层次

```
基础层：直接效果 + 即时标记
  示例：造成N点伤害 + 附加1层蚀

进阶层：条件效果 + 标记消耗
  示例：如果目标有蚀标记，伤害×2

高级层：延迟标记 + 周期效果
  示例：在T拍时附加3层灼烧，每拍造成伤害

协同层：标记转化 + 复合效果
  示例：消耗3层祝福，转化为2层专注
```

### 3. 数值平衡框架（Illustrative）

| 参数 | 基础值 | 说明 |
|------|--------|------|
| 基础伤害N | 3-4 | 快速攻击（D=1） |
| 重击伤害P | 10-12 | 慢速攻击（D=3） |
| 基础护甲K | 5-6 | 防御效果（D=2） |
| 标记层数 | 1-3 | 单次产出标记层数 |
| 标记效果 | 1-2/层 | 每层标记的效果量 |

## 套组配套示例

### 套组A：蚀累积流

**核心思路：** 累积蚀标记，形成持续伤害，最后炼化转精萃

```
法器配置：
  - 白汞法杖（剑击·蚀）
  - 候选法器（累积打击、炼化）

关键卡牌：
  - AC-002 剑击·蚀：稳定产出蚀标记
  - AC-009 累积打击：蚀标记伤害递增
  - AC-031 炼化：蚀标记转化为精萃

运转逻辑：
  1. 持续使用剑击·蚀累积蚀标记
  2. 累积打击让蚀伤害递增
  3. 敌人即将死亡时，炼化转精萃
  4. 精萃用于下一场战斗的重击
```

### 套组B：祝福爆发流

## 数值平衡考量

### 伤害效率对比

| 卡牌类型 | D值 | 配方 | 即时伤害 | 长期伤害 | 总价值 |
|----------|-----|------|----------|----------|--------|
| 剑击 | 1 | M×1 | 3点 | 0 | 3点 |
| 剑击·蚀 | 1 | M×1 | 3点 | 5点（5拍） | 8点 |
| 重击 | 3 | M×1+E×1 | 11点 | 0 | 11点 |
| 累积打击 | 1 | M×1 | 1点 | 15点（5拍） | 16点 |
| 引爆（5层灼烧） | 1 | M×2 | 21点 | 0 | 21点 |

**结论：** 
- 基础卡性价比稳定
- 标记卡前期弱，后期强
- Combo卡爆发极高，但需要铺垫

### 标记经济平衡

```
祝福产出：4张卡，平均每张+2层 = 8层祝福
祝福消耗：3张卡，平均每张消耗3-5层 = 9-15层

蚀产出：3张卡，平均每张+1.5层 = 4.5层
蚀消耗：2张卡，平均每张消耗全部

结论：祝福产出略低于消耗（鼓励选择性使用）
       蚀产出高于消耗（鼓励累积后爆发）
```
