## 简易法术流核心设计

### 流派定位

**一句话概括**：通过多个快速周期护符错开施法，持续产出简单防御和攻击行动，积累使用次数标记后兑现强化效果或高伤害输出。

### 核心循环

**启动阶段**：
- 玩家装配2-3个护符类法器，每个D=2-3拍，无需材料或消耗少量基础材料
- 错开启动时间，让时间轴尽量填满
- 开始积累"施法次数"标记

**运转阶段**：
- 护符持续产出低成本行动卡（护盾、小伤害攻击）
- 每次行动卡生效时在玩家身上叠加"施法次数"标记
- 判断是继续积累还是兑现：
  - **继续积累**：保持高频产出，标记层数增长，后续行动卡逐渐增强
  - **提前兑现**：使用特殊兑现行动消耗标记，获得一次高数值效果

**压力应对**：
- 面对攻击：切换到防御护符优先，快速叠护甲
- 面对打断：错开法器时间避免重叠施法窗口
- 缺Q：多个法器同时处理会占满队列，需要权衡

**机会成本**：
- 早期兑现获得即时收益，但失去后续累积增幅
- 继续积累等待更强效果，但可能被打断或来不及防御
- 多护符占用铭文实体和法器槽位，难以兼顾其他流派

### 擅长与不擅长

**擅长**：
- 持续稳定输出，不依赖高阶材料
- 时间轴利用率高，空窗期少
- 标记积累提供可预期的成长曲线
- 面对长战有优势

**不擅长**：
- 单次爆发不足，初期伤害低
- 依赖不被打断，打断损失进度和标记
- 队列容量紧张时多法器互相竞争
- 无法快速应对突发高威胁现在我开始设计最小物件集合。基于刚才明确的核心循环，我需要设计法器、铭文、行动卡、标记、资源、敌人等系统物件。

### 6. 标记（1种）

#### 标记：施法次数
- **宿主**：玩家
- **极性**：正面（对玩家有利）
- **生成方式**：每张简易护盾或简易攻击生效时+1层
- **读取条件**：强化打击检查≥5层
- **消费方式**：强化打击成功时消耗5层
- **上限**：10层（本轮候选，依据：防止无限积累）
- **溢出处理**：达到上限后不再增加（候选）
- **期限**：战斗结束前持续，无自然到期
- **刷新**：不刷新，持续叠加
- **清理**：战斗结束清零
- **战终处理**：不保留

**设计理由**：
- 提供可见的积累进度
- 支持"继续积累vs提前兑现"的取舍
- 简单的层数机制，易于理解
- 上限10层防止数值膨胀，同时允许连续2次强化（5+5）

**案例1总结**：

- 玩家看到：法器开工 → 等待D拍 → 行动卡完工入行 → 下拍生效产生效果和标记

### 案例2：直用与继续准备的比较

**场景设定（第10拍）**
- 玩家生命：20，护甲：2，施法次数：6层
- 敌人生命：36
- 下一张待生效行动：简易攻击（第11拍生效）
- 施法护符刚完工，准备再次开工
- 敌牌：牌3（打断，T=13）即将到来

**方案A：继续使用简易攻击（基础模式）**
- **操作**：保持当前配置，继续生产简易攻击
- **第11拍**：简易攻击生效 → 敌人-6（剩余30），施法次数+1（7层）
- **第13拍**：新简易攻击生效 → 敌人-6（剩余24），施法次数+1（8层）
- **第16拍**：再一次简易攻击生效 → 敌人-6（剩余18），施法次数+1（9层）
- **累计输出**：3次攻击共18点伤害
- **最终标记**：9层（接近上限）
- **优势**：持续积累标记，为未来更强的兑现做准备
- **劣势**：伤害分散，敌人仍有较高生命

**方案B：切换到强化打击（兑现模式）**
- **操作**：在观察窗口选择施法护符的"强化模式"（候选机制）
- **第11拍**：简易攻击生效 → 敌人-6（剩余30），施法次数+1（7层）
- **第13拍**：强化打击生效 → 检查标记≥5成功，敌人-18（剩余12），消耗5层标记（剩余2层）
- **第16拍**：简易攻击生效（标记不足5层，无法再次强化）→ 敌人-6（剩余6），施法次数+1（3层）
- **累计输出**：6+18+6=30点伤害
- **最终标记**：3层（重新积累）
- **优势**：快速压低敌人生命，可能提前结束战斗
- **劣势**：消耗标记后需要重新积累

**实际失去和得到**：
- 方案A失去：快速击杀的机会，可能需要更多回合
- 方案A得到：9层标记储备，未来可连续2次强化（5+4或直接等10层）
- 方案B失去：标记储备清空，后续攻击回到基础强度
- 方案B得到：敌人接近死亡（剩余6点），只需再1次简易攻击

**更合适的条件**：
- **方案A更合适**：敌人当前威胁不高，战斗可以持续，想要达到10层上限后连续释放
- **方案B更合适**：敌人即将进入危险阶段（如第二轮更强打断），需要尽快击杀；或护甲不足，担心被击败

### 案例3：压力与失败

**场景：缺Q导致循环阻塞**

**第8拍初始状态**
- 玩家生命：18，护甲：4，施法次数：4层
- Q=5，当前队列：[简易护盾][简易攻击][简易护盾][简易攻击][空]
- 已入行4张，可用余量1位
- 守护护符：刚完工，需要入行
- 施法护符：处理中，还需1拍完工（第9拍）
- 敌牌揭示：牌3（打断，T=13，锁定施法护符）

**第8拍：队列满载，第一张牌生效**
- 队首简易护盾生效 → 护甲+4（现在8），施法次数+1（5层），释放1位
- 守护护符完工的简易护盾立即入行，占用刚释放的位置
- 开工检查：
  - 守护护符：需要Q=1，当前可用0（5个预留/已入行位置都被占用）→ **等待容量**
  - 施法护符：仍在处理中
- **失败发生**：守护护符无法续开工，防御循环中断

**第9拍：打断即将到来，第二张牌生效**
- 队首简易攻击生效 → 敌人-6，施法次数+1（6层），释放1位
- 施法护符完工 → 简易攻击入行
- 开工检查：
  - 守护护符：Q可用1 → **开工成功**，预留1位，预计第11拍完工
  - 施法护符：Q可用0 → **等待容量**
- **失败持续**：施法护符被阻塞，而第13拍将被打断

**第10拍：意识到打断无法避免**
- 队首简易护盾生效 → 护甲+4，施法次数+1（7层）
- 玩家观察：施法护符当前批次（第9拍开工的，预计第12拍完工）剩余时间R=12-10=2拍，是最长的，将在第13拍被打断
- **损失**：即将失去第12拍的攻击输出，进度损失2拍，材料无损失（本流派无材料）

**第13拍：打断生效**
- 敌牌3（打断）生效 → 施法护符当前批次被打断，释放预留容量，下拍可用
- **实际损失**：
  - 2拍加工进度浪费
  - 原计划第12拍完工的攻击推迟至少3拍（需要重新开工+处理）
  - 攻击循环节奏被打乱

**第14拍：恢复路径**
- 开工检查：施法护符材料齐备，Q有空位 → 重新开工，预计第17拍完工
- **恢复代价**：比原计划晚了5拍（17 vs 12）

**合法恢复路径**：
1. 继续依靠守护护符维持防御
2. 施法护符重新开工，恢复攻击循环
3. 标记保留（7层），未来可以使用强化打击弥补输出损失

**案例3总结**：
- 失败类型：缺Q导致循环阻塞，无法及时错开施法时间避开打断
- 损失：进度和时机，输出推迟5拍
- 教训：多法器运行时需要关注Q容量，保持队列流动；看到打断提前释放队列空间
- 无损挽救？不能。打断已经发生，进度无法恢复。但标记未损失，可以继续运转。

### 案例4：构筑成长与战后去向

**战斗结束状态**

  - 劣势：Q压力增大（更频繁占用队列），可能加剧阻塞

**下一次战斗准备**
- 生命：22（若选恢复）或12（若选铭文/放弃）
- 配置选择：根据获得的铭文和辅槽，在编辑窗口装配
- 明确区分：编辑窗口（战前）可以调整铭文和辅槽，战中只能选择已有用途和供料

**案例4总结**：
- 使用真实取得的替代铭文（「积蓄」），可以改变一个法器的用途
- 辅槽「迅速」提供有侧重的成长（提速，不改变主逻辑）
- 金币是稀缺资源，购买选择影响后续发展
- 编辑窗口与战中操作严格区分

### 三、主要风险与审查报告对照

按交接文档要求，优先回答审查报告中的四件事：

#### 风险1：链条是否值得等待？
- **现状**：D=2和D=3的链条，每次等待2-3拍获得一张行动卡
- **价值**：简易护盾提供4点护甲，简易攻击造成6点伤害+1层标记
- **对比**：若D=1即时产出，失去"等待-积累-兑现"的节奏；若D=5+，等待过长，压力应对不及时
- **结论**：候选D值可在纸面上形成等待价值，但实际体验需验证。标记积累提供长期价值，部分补偿等待。
- **风险**：若Q阻塞频繁，等待变成"被迫延误"而非"主动准备"，价值感下降。

#### 风险2：能否在真实Q与敌情下兑现？
- **Q压力**：候选Q=5，2个法器预留2位+已入行2-3张，余量1-2位，存在阻塞可能（案例3已验证）
- **敌情压力**：敌人Δ=4-6拍，D=2-3的法器有机会在威胁到期前产出响应行动
- **打断威胁**：第13拍打断，若两法器时间重叠，会损失进度
- **结论**：纸面可兑现，但存在阻塞和打断风险。需要玩家主动管理队列流动和错开时间。
- **风险**：若Q实际为3，阻塞将非常频繁，严重影响兑现；若敌人Δ缩短至2-3拍，法器反应不及。

#### 风险3：标记是否增加选择而非重复收费？
- **现状**：施法次数标记由简易护盾和简易攻击免费生成（无额外支付）
- **选择**：积累5层后可选择"继续积累至10层"或"兑现强化打击"
- **对比案例2**：继续积累获得更多标记储备，兑现获得即时高输出，各有适用场景
- **是否重复收费**：标记生成免费，强化打击消耗标记换取额外效果（18点 vs 6点），属于"额外选项"而非"必须支付才能使用行动卡"
- **结论**：标记提供了选择分支，不是重复收费。但若未来所有行动都必须消耗标记才能生效，则变成重复收费。
- **风险**：若标记上限过低（如5层），选择简化为"存满立即兑现"，失去积累策略深度。

#### 风险4：玩家是否必须频繁锁解才能维持正常运行？
- **现状**：本流派无材料，法器自动循环，标记自动生成
- **需要锁定的情况**：若玩家想保留标记不被某个"自动消耗标记"的效果使用（当前设计中不存在）
- **操作频率**：战前装配铭文，战中仅需在关键压力点调整供料（如案例3应对打断时）
- **结论**：当前设计不需要频繁锁解维持运行。观察窗口调整为应对压力，非常态操作。
- **风险**：若未来加入"自动消耗标记的维护机制"或"多个法器竞争同一标记"，锁定需求会增加。

### 四、其他系统性风险

| 风险 | 描述 | 影响 | 缓解措施 |
|---|---|---|---|
| **标记上限导致浪费** | 达到10层后，继续行动不再增加标记 | 玩家可能感觉"溢出浪费"，被迫兑现 | 明确告知上限存在意义（防止膨胀），或设计"溢出转化"机制（需额外设计） |
| **单一标记类型单调** | 只有施法次数1种标记 | 协同深度有限，后期可能重复 | 未来扩展第二种标记（如"蓄能"），支持不同兑现路径 |
| **无材料流派缺少资源管理** | 法器无需材料，降低资源系统参与度 | 削弱资源作为核心约束的设计目标 | 明确这是"入门流派"特色，后续流派需要材料链；或加入"可选材料强化"（消耗1份基础料换取+2伤害） |
| **法器种类单一（都是护符）** | 2个法器都是护符，缺少形象差异 | 难以体现"工序/配方差异"的设计意图 | 后续扩展其他器具类型（如法杖、仪式刀），形成明显工序区别 |
| **敌人程序过于简单** | 固定4牌循环，无变化 | 重复战斗缺少新鲜感 | 作为首个敌人，简单合理；后续设计需要条件分支、多阶段等变化 |
| **强化模式权限不明确** | Q1中的"选择模式"机制未确认 | 影响强化打击的实现方式 | 优先选择候选B（条件自动判断），减少新权限；若需要候选A，补充"用途内产出选择"规则 |
| **标记清理时机** | 战斗结束清零，跨战不保留 | 每场战斗重新积累，无长期成长 | 明确这是设计意图（避免跨战滚雪球）；若需要成长感，通过辅槽/契合提供，而非标记保留 |
