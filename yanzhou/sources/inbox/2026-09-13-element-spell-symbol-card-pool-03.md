## 本期筛选标准

1. 一张卡表达一次转换、一个触发或一条规则替换；对称的火冰分支可以共用一条规则。
2. 符号只缩短已可理解的概念，不把复杂账目压缩成难懂缩写。
3. 不把单纯加伤害、加层数、减冷却或阈值增减列为本期创新卡。
4. 去掉额外资源存储、未来跳过事件、分期输出和跨对象继承机制；其历史设计保留。
5. 规则变更仍优先考虑，但限定在卡面明示对象／本杖来源，不自动覆盖全局。
6. 己、敌、树木等仍是公共词库对象，伤害等仍是公共动作；本期不重复把它们计为元素创新卡。

## 符号与卡面读法

| 符号／词 | 含义 |
| --- | --- |
| 🔥 | 火焰元素本体 |
| ❄ | 冰霜元素本体 |
| 【燃】 | 燃烧状态；与🔥区分 |
| 【冻】 | 冰冻状态；与❄区分 |
| 🛡 | 护甲 |
| 己／敌／目标 | 玩家自己／敌人／本句选定的合法目标，不自动替代所需实体词卡 |
| A→B | 消耗A，得到或产生B；不表示固定等量换算 |
| 条件：结果 | 当条件发生时产生结果；一次合法事件不是按每层分别触发 |
| 改为 | 替换原效果，只执行替换后的结果 |

“邻近施加”统一表示元素向自身邻近合法单位施加对应状态：🔥施加【燃】，❄施加【冻】。具体范围和阵营仍按基础规则及所用卡牌。本杖指装有该镶嵌的法杖；镶嵌限定该来源，不无条件影响全部法杖。

符号是本期卡面展示约定，不新增词卡语法或程序语言。完整法术仍由合法实体词卡组成，仍参与共享释放槽。符号箭头只用于消耗转换；规则替换用“改为”，不混用箭头语义。

## 卡面外的统一边界

- 除“爆裂”写明耗尽全部外，消耗量与收益量后续设计；箭头不推定一比一。实际消耗是收益依据，无合法对象或实际消耗为零不凭空生成收益。
- 只有释放类动作承担相关释放资格。汲取、倾注、拆甲等不能无条件补生新元素；已有抵消／克制顺序与正余量初始层数规则继续适用，止界针另作明示例外。
- 净化合并熄灭／解除的卡面入口，仍按被指名的状态执行；不追溯撤销过去伤害或已产生护甲。
- 指令芯、借位镜、满溢阀、溢流芯、逆霜镜、止界针、自噬的分别改触发、直接范围起点、满位分支、同种分支、冰冻结果、异种余量结果和自然衰减时点。只在其声明范围内替代原规则，不同时领取被替代效果。
- 逆霜镜下状态仍为冰冻、按冰元素关系克制／抵消，不自动转成燃烧，也不额外再给原护甲；这是该杖例外，不撤销“冰冻基础增甲”的用户决定。
- 护生／避亲仅改变本体邻近施加的阵营，不自动改变满位回退或独立伤害的对象。
- “法术补层”仅指完整法术直接给已有元素增加层数，不含新生初始层数或镶嵌派生补层；应激的因此不被蚀甲炉的被动补层反复触发。空心的关闭自动邻近，独立卡牌触发与替代效果仍需按选用组合声明。
- 这些未决不能通过再造一个玩家看不懂的缩写隐藏；若选中组合必须附带过长说明，应继续合并或删减设计。
- 不执行数值／玩法测试，不扩展草状态／法术，不恢复旧Parked参数。
