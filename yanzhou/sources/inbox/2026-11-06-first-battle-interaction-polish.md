## 当前玩家动线

新战／继续 → 战前查看与配置 → 选择材料、投料及排期 → 推进本轮5拍 → 收货与最终布置 → 确认整轮、锁行交锋 → 未终局进入下一轮；胜利进入选留，失败进入回看与重试。

生产期间也可以调整战斗行；五拍结束后不限时最终布置。查看、暂停、取消和保存恢复贯穿全程，不解除已冻结工序或战斗锁行。当前选留后没有下一场。

| 阶段 | 当前玩家操作 | 优化重点 |
| --- | --- | --- |
| 进入与恢复 | 新战、继续，辨认阶段与桌面 | 明确当前阶段、在制批次和下一步 |
| 战前配置 | 查看四器与小炉，用坐标及旋转表单调整 | 直接操作与空间效果预览 |
| 投料与排期 | 切组、翻页、查配方、点选或长按拖料、选拍 | 兼容目标、缺料、草稿与在制清楚分开 |
| 生产与收货 | 推进、处理拒绝、查看进度、找到产物 | 展示承诺、加工和真实交付的连续关系 |
| 五列布置 | 放置、撤回、调序、明确互换 | 合法落点、对象连续性与确认后果 |
| 交锋与换轮 | 观看结算、暂停、查看结果、再次安排回收牌 | 解释生效顺序和下一轮使用资格 |
| 战果与选留 | 查看胜败、勾选携带、填写位置 | 区分结果记录与真实库存，预览选留 |

## 统一优化策略

1. 主桌回答当前状态；选中对象提示可用目标、缺项与时间；完整详情解释条件、费用和权限。
2. 每阶段突出一个主操作，暂停、查看、设置保持稳定位置。具体按钮整合与文案仍为候选。
3. 悬停和拿起是预览，投料形成可改草稿，开工才冻结；反馈对应实际提交边界。
4. 动画按真实、允许公开的事件组织。减动效、静音、加速仍保留状态与因果信息。
5. 先做完铁肤与引燃的代表性闭环，再扩展其余器具和完整美术包。

## 任务清单

以下全部为待开展的候选任务。每项“验收”是拟检查标准，不是已有通过结果。承接任务时须先核对相关建议资格和制作授权，明确的现行规则不重复询问。

### 01 阶段主操作与进入恢复提示

- [ ] 整理战前、生产、最终布置、交锋、终局和恢复状态下的主操作与禁用原因。
- [ ] 提供阶段摘要、主按钮文案和焦点返回方案；恢复摘要说明轮次、生产拍、在制状态和可做动作。
- **产物：** 状态与操作对照表、主桌关键状态稿、恢复提示稿。
- **验收：** 各阶段下一步明确；恢复保持暂停；详情关闭后回到来源对象；战斗暂停仍明确锁行。
- **依赖：** 现行交互合同；作为后续任务的共同输入。

### 02 选牌、查看、拖动与取消

- [ ] 统一悬停、选中、拿起、拖动、合法目标、无效释放和取消的视觉状态。
- [ ] 保留点击与键盘等价路径；短按详情、长按轮盘及拖动中取消互不串触发。
- [ ] 为拿起、落位和归位制作连续动作；阴影、倾角、层级与命中范围配套。
- **产物：** 输入状态图、卡牌操作动效样件、取消与焦点检查情境。
- **验收：** 快速移入移出、取消、失焦和连续选牌不丢失对象、不误提交；减动效仍能辨认选中与落点。
- **依赖：** 01；视觉状态沿10统一。

### 03 投料目标、配方缺项与草稿

- [ ] 选中材料时提示兼容器具，并区分兼容与当前目标拍可提交。
- [ ] 在目标附近显示已投材料、缺项及当前排期；避免依靠反复打开详情记忆配方。
- [ ] 制作“手牌移入草稿”和“撤回手牌”的反馈；草稿材料具有明确宿主。
- **产物：** 投料前后状态稿、草稿交互原型、移入与撤回动作。
- **验收：** 未齐草稿能被辨认和修正；材料始终唯一归属；投料不冒充开工，空行不自动生产。
- **依赖：** 01、02；首件使用铁肤配方的真实材料。

### 04 排期轮盘与拒绝定位

- [ ] 轮盘联动展示目标开工拍、占用区间、到货拍与下一批最早开工拍。
- [ ] 多草稿明确选择编辑对象；改排、取消及保存排期的结果清楚。
- [ ] 开拍失败定位具体缺料或占用冲突，提示可修正动作，并保留草稿。
- **产物：** 轮盘状态稿、拒绝提示稿、跨轮排期原型。
- **验收：** 排期不推进时钟；不自动顺延；当前拍共同检查失败时全部不变；未来草稿不阻挡整轮确认。
- **依赖：** 03。

### 05 开工、加工、收货与补给动画

- [ ] 区分空闲、草稿未齐、草稿齐备、开工冻结、在制与完成状态。
- [ ] 用器身、液体、火焰或蒸汽体现加工；精确进度按已提交生产拍更新。
- [ ] 产物从所属器具进入真实手牌组；非当前组用新增提示交代去向。补给有可区分的来源表现。
- **产物：** 铁肤瓶首件动画、产物交付样件、四器动画状态表及所需分层资产清单。
- **验收：** 冻结与可撤回状态可区分；同拍完成和补给保持规定顺序；动画不额外授予库存或推进生产；恢复不重复产出表现。
- **依赖：** 03、10首件素材；完整排期情境依赖04。

### 06 五列放置、撤回与整轮确认

- [ ] 选战斗牌时突出合法列，放置、撤回、调序和互换保持对象连续。
- [ ] 明确区分“能放入该列”与“后续卡效必然成功”；不预告暗牌结果。
- [ ] 确认后统一表现整行锁定；已用结果采用只读记录样式。
- **产物：** 五列布置稿、互换反馈、锁行与结果记录状态。
- **验收：** 晚到产物可在最终布置放入第1列；互换取消不改归属；确认后暂停、详情和恢复均不开放编辑。
- **依赖：** 01、02；收货衔接依赖05。

### 07 逐列交锋、回收与消耗

- [ ] 按真实事件依次表现揭牌、防护、敌方行动、玩家效果、回收或消耗，突出当前列。
- [ ] 分开呈现护甲抵挡与生命受损，治疗、获得咒等反馈关联实际来源与目标。
- [ ] 回收牌入手后显示“下轮可用”；消耗牌离场，列中结果不显示为可操作库存。
- **产物：** 铁肤挡伤与消耗、引燃攻击与回收两条可播放样件；换轮和终局截断规则说明。
- **验收：** 无需打开日志也能追踪关键效果顺序；暗牌不提前泄露；终局停止后续效果；回收原实例本轮不可重排，下一轮恢复资格。
- **依赖：** 06、10战斗状态素材、11声音样件。

### 08 战前配置与空间反馈

- [ ] 提供选物、移动、旋转的直接操作和点击／键盘替代路径。
- [ ] 预览真实占格、越界、冲突、炉心圈、决定圈下限的格与实际D变化。
- [ ] 区分“决定圈下限”与“确实提高实际D”，战中配置保持只读。
- **产物：** 四器与小炉配置原型、几何状态图、落位与拒绝反馈。
- **验收：** L形空角可合法利用；图像与逻辑格同向旋转；无效提交保留原配置；玩家可直接比较移动前后的工期变化。
- **依赖：** 01、02、10空间组件；不包含通用拆核心或换配方编辑器。

### 09 战果、真实剩余与选留

- [ ] 战果先说明实际胜败与关键已发生结果，再展示剩余和选留入口。
- [ ] 使用直观摆放与实时预览替代依赖坐标理解；明确保留、放弃及冲突。
- [ ] 结果记录、已消耗对象、退回输入与可携带库存使用不同表达。
- **产物：** 胜败稿、选留原型、确认前后及重复进入状态。
- **验收：** 失败不进入选留；未完成普通输入按规则退回后参与资格判断；已消耗不退、未来产物不兑现；选留提交一次，不额外回血或发奖励。
- **依赖：** 07、08。

### 10 统一美术与动画资产包

- [ ] 整理四器桌面背景，降低文字和落点区域的纹理对比；装饰、插槽与光影可独立调整。
- [ ] 补齐卡牌、按钮、详情、轮盘、合法落点、冻结、回收待用及结果记录的状态组件。
- [ ] 按05和07需求制作器具分层与火焰、护甲、受击、治疗、咒等特效；两只曲颈瓶用途可辨。
- [ ] 核对字体层级、透明边缘、缩图辨识、图文净空和独立文字层。
- **产物：** 首件视觉样板、状态组件规范、分层源件及运行派生、实际宿主合成图。
- **验收：** 沿Ways画风与卡面02；图像等比适配；不烘焙名称、数字和进度；特效不遮挡关键牌面与数值；颜色之外保留形状或文字区分。
- **依赖：** 先依据01、02确定状态语言，再按各任务样件扩量。源件及使用关系按既有资产规范登记，不覆盖原件。

### 11 操作声音与表现节奏

- [ ] 配套拿牌、落位、投料、开工、产出、挡伤、受击、治疗与回收声音。
- [ ] 建立操作即时反馈、加工循环、结算重点和阶段过渡的节奏层级。
- [ ] 每段动作说明触发、结束、循环、暂停／取消、遮挡顺序、锚点及减动效替代。
- **产物：** 声音事件清单、与代表性动画同步的样件、加速／静音／减动效对照。
- **验收：** 连续反馈不过度叠加；必要信息不依赖声音；速度变化不改变结果和顺序；暂停及恢复不重复播放已发生事件。
- **依赖：** 02、05、07的动作定义；先做代表链所需声音。

### 12 完整动线复核与玩家理解验证准备

- [ ] 核对铁肤与引燃完整动线，覆盖缺一料、无效释放、取消、查看、失焦、暂停与恢复。
- [ ] 在1920×1080、1366×768以及静音、减动效条件下检查关键状态。
- [ ] 准备玩家观察任务：指出材料所在位置、预测到货、解释一次挡伤、分清回收牌与结果记录。
- **产物：** 完整流程审阅包、工程检查证据与缺陷清单、独立的玩家验证计划。
- **验收：** 工程正确、视觉可读和真人理解分别记录；观察误投、反复查详情、找不到产物及错误重用等行为，再决定修订或扩量。
- **依赖：** 代表链需01、02、03、05、06、07、10、11；完整首战再纳入04、08、09。真人验证须另有实验授权，本记录不启动测试。
