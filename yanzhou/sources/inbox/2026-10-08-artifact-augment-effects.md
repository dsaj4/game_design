# 法器辅槽效果设计（基于标记系统）

日期：2026-10-08。项目：game-002 / 言咒。状态：**Content Design / Raw**。本文档设计法器辅槽效果，重点是与标记系统的深度互动。

---

## 设计目标

基于标记系统，设计法器辅槽效果，使法器与行动卡、标记形成完整闭环：

```
法器（辅槽效果） → 行动卡（产出标记） → 标记累积 → 法器（消耗标记）
```

---

## 辅槽效果设计框架

### 1. 辅槽的基础定义（已有）

| 属性 | 规则 |
|------|------|
| **数量** | 原则上 ≤ 核心槽数，可打造/解锁 |
| **可选性** | 辅槽可空 |
| **挂接** | 修饰词预设挂接位置 |
| **不影响** | 辅槽不改变核心铭文组合 |

### 2. 辅槽效果的三大类型

#### 类型A：材料/产能调整（已有）

```
代表：专注（减少材料消耗）、蓄言（额外产出卡牌）
特点：直接影响配方，不涉及标记
```

#### 类型B：标记消耗（新增，核心）

```
代表：承句·蚀噬、专注·标记转化
特点：消耗标记改变配方或产出
```

#### 类型C：标记增幅（新增）

```
代表：契合·灼烧、铭刻·祝福
特点：增加标记产出数量或效果
```

### 3. 辅槽效果的触发时机

| 触发时机 | 说明 | 代表效果 |
|----------|------|----------|
| **开工检查时** | 检查配方前，先检查辅槽消耗条件 | 标记消耗类 |
| **处理过程中** | 影响D值或处理逻辑 | 加速类（不推荐，与D语义冲突） |
| **完工时** | 行动卡入行时，附加额外效果 | 标记增幅类 |

## 标记消耗类辅槽效果（核心设计）

### 设计原则

```
1. 消耗标记改变配方，不改变D值
2. 消耗条件可选（有标记则消耗，无标记则正常）
3. 消耗效果显著，鼓励玩家累积标记
4. 消耗后标记清零，形成循环
```

### 效果清单

#### 辅槽效果-001：承句·蚀噬

```yaml
效果名称：承句·蚀噬
类型：标记消耗
触发时机：法器开工检查时
效果：如果目标敌人有蚀标记，消耗全部蚀标记，本批材料消耗减少M×[蚀层数]（最多减少至M×0）。
标记消耗：蚀×全部（敌人负面格）
适用法器：攻击类法器（白汞法杖、白汞坩埚）
设计意图：将持续伤害标记转化为经济优势

数值示例：
  - 配方：M×1
  - 蚀层数：3
  - 实际消耗：M×0（免费生产）
  - 限制：最多减至M×0，不能倒给玩家材料
```

#### 辅槽效果-002：专注·标记转化

```yaml
效果名称：专注·标记转化
类型：标记消耗
触发时机：法器开工检查时
效果：消耗3层祝福标记，视为提供M×1。
标记消耗：祝福×3（玩家正面格）
适用法器：所有法器
设计意图：将攻击资源转化为生产材料

数值示例：
  - 配方：M×2
  - 祝福层数：6
  - 实际消耗：M×2 - M×2 = M×0（消耗6层祝福，获得M×2）
  - 限制：祝福不足3层时不触发
```

#### 辅槽效果-003：炼化·灼烧

```yaml
效果名称：炼化·灼烧
类型：标记消耗
触发时机：法器开工检查时
效果：消耗全部灼烧标记（敌人负面格），每2层提供E×1。
标记消耗：灼烧×全部（敌人负面格）
资源产出：E×[灼烧层数/2]（向下取整）
适用法器：资源类法器（沉星护符）
设计意图：将延迟伤害标记转化为精萃资源

数值示例：
  - 配方：M×2 → E×1
  - 灼烧层数：5
  - 额外产出：E×2（5/2=2）
  - 总产出：E×1 + E×2 = E×3
```

#### 辅槽效果-004：守护·护盾

```yaml
标记消耗：护盾×全部（玩家正面格）
适用法器：防御类法器（白汞桃木剑）
设计意图：将防御标记转化为经济优势

数值示例：
  - 配方：M×1
  - 护盾层数：2
  - 实际消耗：M×0（免费生产）
```

#### 辅槽效果-005：承句·破甲

```yaml
效果名称：承句·破甲
类型：标记消耗
触发时机：法器开工检查时
```

#### 辅槽效果-006：专注·诅咒

```yaml
效果名称：专注·诅咒
类型：标记消耗（特殊）

标记读取：诅咒×N（玩家负面格，不消耗）
产出增加：×2
适用法器：所有法器
设计意图：负面标记的转化利用，风险收益并存

数值示例：
  - 配方：M×1 → 剑击×1
  - 诅咒层数：2
  - 实际消耗：M×3（1+2）
  - 实际产出：剑击×2
  - 权衡：高材料成本换高产出
```

#### 辅槽效果-007：承句·虚弱

```yaml
效果名称：承句·虚弱
类型：标记消耗
触发时机：法器开工检查时
效果：消耗全部虚弱标记（敌人负面格），每层使本批D减少1拍（最低D=1）。
标记消耗：虚弱×全部（敌人负面格）
处理加速：D - [虚弱层数]（最低1）
适用法器：所有法器
设计意图：将控制标记转化为生产效率

数值示例：
  - 配方：M×1，D=3
  - 虚弱层数：2
  - 实际D：1（3-2=1）
  - 注意：这涉及D值改变，需审查与"D是唯一处理耗时"的兼容性
  - 推荐改为：本批材料消耗减少M×[虚弱层数]
```

#### 辅槽效果-008：炼化·迟缓

## 标记增幅类辅槽效果

### 设计原则

```
1. 增幅行动卡产出的标记数量或效果
2. 不消耗标记，只增强产出
3. 与法器契合机制结合
4. 鼓励专精特定标记流派
```

### 效果清单

## 套组配套示例（辅槽版）

### 套组A：蚀循环流（升级版）

```
法器配置：
  - 白汞法杖 + 契合·蚀（增幅蚀产出）
  - 候选法器 + 承句·蚀噬（消耗蚀降低成本）

关键卡牌：
  - AC-002 剑击·蚀
  - AC-009 累积打击

运转逻辑：
  1. 白汞法杖（契合·蚀）产出剑击·蚀（蚀×2，原×1）
  2. 累积打击让蚀伤害递增
  3. 蚀累积到5层后，第二法器开工前消耗蚀，免费生产
  4. 形成"产出蚀 → 蚀造成伤害 → 消耗蚀免费生产"循环
```

### 套组B：祝福爆发流（升级版）

```
法器配置：
  - 白汞桃木剑 + 铭刻·祝福（防御产出祝福）
  - 候选法器 + 专注·标记转化（祝福转材料）

关键卡牌：
  - AC-014 镜御·护盾
```

## 辅槽效果与标记系统的完整闭环

### 闭环验证

```
玩家行为链：
1. 装配法器 + 选择辅槽效果
2. 法器产出行动卡（辅槽增幅标记）
3. 行动卡结算产生标记
4. 标记累积（即时/延迟/周期）
5. 标记触发效果（伤害/防护/控制）
6. 法器开工前消耗标记（辅槽效果）
7. 降低成本或增加产出
8. 回到步骤2

反馈循环：
  - 正反馈：消耗标记 → 降低成本 → 更多产出 → 更多标记
  - 负反馈：标记达到上限 → 产出浪费 → 鼓励消耗
  - 平衡点：产出与消耗达到动态平衡
```

### 数值平衡检查

| 维度 | 产出侧 | 消耗侧 | 平衡状态 |
|------|--------|--------|----------|
| **蚀标记** | 3张卡产出（平均+1.5层/张） | 2个辅槽消耗 | 可持续循环 |
| **祝福标记** | 4张卡产出（平均+2层/张） | 3张卡+2个辅槽消耗 | 略紧张，鼓励选择 |
| **灼烧标记** | 3张卡产出（平均+2.5层/张） | 1张卡+2个辅槽消耗 | 偏松，累积潜力大 |
| **护盾标记** | 2张卡产出（平均+2层/张） | 1个辅槽消耗 | 平衡 |
