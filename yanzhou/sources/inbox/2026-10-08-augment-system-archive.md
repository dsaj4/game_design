# 系统设计档案框架与辅槽系统案例

日期：2026-10-08。项目：game-002 / 言咒。状态：**System Archive / Framework**。本文档建立系统设计档案的框架，以辅槽系统为第一个完整案例。

---

## 一、系统设计档案框架说明

### 档案目标

每个系统的档案应该回答：
1. **这个系统是什么？** 定位与职责
2. **玩家在这个系统中做什么？** 关键决策与注意力分配
3. **系统怎样支持核心玩法？** 与其他系统的关系
4. **怎样做好这个系统？** 设计规范与原则
5. **看起来怎样？** 完整设计示例

### 档案的思想转变

| 维度 | 创意阶段 | 优化阶段 |
|------|----------|----------|
| **目标** | 探明边界，最大化可能性 | 清晰定位，最小化认知负担 |
| **方法** | 加法：增加功能和选项 | 减法：去掉非关键要素 |
| **验证** | 这是否有趣？ | 这是否必要？玩家是否能理解？ |
| **设计** | 尽可能多的细节 | 最少的必要细节 |

### 档案结构（三部分）

```
┌─ PART 1: 系统档案 ─────────────────┐
│  定位、职责、关键决策、注意力分配  │
└────────────────────────────────────┘
            ↓
┌─ PART 2: 设计规范 ─────────────────┐
│  原则、约束、不做什么             │
└────────────────────────────────────┘
            ↓
┌─ PART 3: 设计示例 ─────────────────┐
│  简化后的完整设计，作为参考       │
└────────────────────────────────────┘
```

## 二、玩家注意力分配模型

### 核心原理

玩家的认知资源是有限的。设计时需要考虑：

```
战前（局外）
  ↓
选择法器 (A) → 选择辅槽 (B) → 选择铭文 (C)
  ↓
决策分布：A占40% | B占35% | C占25%
          （最重要） （重要）  （参考）
```

### 辅槽在战前的注意力位置

**理想状态：**
- 玩家关注度：35%（第二位，仅次于法器选择）
- 决策复杂度：中等（3-5个选项，而非20+个）
- 决策时间：15-30秒（快速扫过，不需要深思）
- 决策动机：直观看到"战斗力+20%"这样的效果

**当前问题：**
- 20个辅槽效果，玩家需要比较所有选项 → 认知负担过重
- 效果复杂（标记消耗、条件判断） → 理解成本高
- 法器+辅槽的组合爆炸 → 决策时间过长

## 三、辅槽系统设计档案

### PART 1：系统档案

#### 1.1 定位与职责

**系统定位：** 卡牌升级与数值成长的载体

**关键职责：**
1. **数值成长**：让玩家感受到"战斗力在成长"
2. **构筑消化**：法器+行动卡+标记的机制组合 → 数值体现
3. **差异化**：不同法器搭配不同辅槽 → 个性化构筑

#### 1.2 核心玩家决策

```
决策一：选择合适的辅槽主题
  问题：这个法器需要什么加强？
  选项：三选一（如攻击、防御、经济）
  时间：3秒
  
决策二：细化具体辅槽效果
  问题：用哪个具体的效果？
  选项：基础配置 vs 高级配置
  时间：5秒
```

#### 1.3 玩家注意力分配

```
战前决策流程中的注意力消耗：

1. 选择法器（必须） ████████████ 40%
   - 这个法器适合我的打法吗？
   
2. 装配辅槽（必须） ██████████ 35%
   - 这个辅槽能显著提升战斗力吗？
   
3. 微调铭文（可选） ███████ 25%
   - 要不要追求完美搭配？
```

#### 1.4 玩家的"理想体验"

| 阶段 | 理想感受 | 当前状态 |
|------|----------|----------|
| **看到辅槽列表** | "哦，我知道这个会让我更强" | ⚠️ "这20个选项是什么..." |
| **选择辅槽** | "配合法器选了最合适的" | ⚠️ "哪个才是最优的？" |
| **看到效果** | "战斗力明显提升了" | ✓ 可以达到 |
| **继续优化** | "用这个新辅槽，伤害翻倍了" | ⚠️ 优化空间不清晰 |

### PART 2：设计规范

#### 2.1 辅槽系统的设计原则

**原则1：可视化数值成长**
- 玩家应该看到具体的数值提升（"伤害+50%"而非"消耗蚀标记"）
- 数值提升应该是直观的、容易对比的

**原则2：减少决策路径**
- 每个法器配套3-4个推荐辅槽
- 不超过5个选项，否则决策时间超过30秒

**原则3：明确的优先级**
- 基础配置 < 中级配置 < 高级配置
- 玩家清楚地知道"什么时候升级"

**原则4：关联而非独立**
- 辅槽应该关联法器特性，而非通用效果
- "这个辅槽是为这个法器设计的"

**原则5：聚焦核心功能**
- 只做"数值成长"、"构筑消化"两个功能
- 砍掉"复杂的标记互动"

#### 2.2 不做什么

| 不做项 | 理由 |
|--------|------|
| 20个通用辅槽效果 | 选择过多，认知负担大 |
| 复杂的标记消耗链 | 理解成本高，不如直接加伤害 |
| 每个法器4个以上辅槽位置 | 打造成本过高 |
| 动态改变法器D值 | 破坏"D是唯一处理耗时"的设计 |
| 跨法器的组合玩法 | 让玩家同时考虑多个法器 → 认知爆炸 |

#### 2.3 设计规范细化

**规范1：辅槽的数值规范**

每个辅槽应该提升明确的数值：
- **攻击法器**：伤害+10%-50%（按配置层级）
- **防御法器**：护甲+20%-50%
- **资源法器**：产出+20%-100%
- **通用效果**：成本-20%-50%

**规范2：辅槽的复杂度规范**

| 复杂度 | 说明 | 例子 |
|--------|------|------|
| **简单** | 玩家看一眼就懂 | "伤害+30%" |
| **中等** | 需要5秒理解 | "每张蚀标记+5%伤害" |
| **复杂** | 需要深思或查阅 | "消耗3层祝福，视为提供M×1" |

**规范3：玩家的优化迭代**

```
初始配置（10分钟）
  ↓
感受战斗力 ✓ 满意 / ✗ 不足
  ↓ 不足时
解锁新辅槽
  ↓
替换为更强的辅槽
  ↓
重新感受战斗力 ✓ 更强了
```

### PART 3：设计示例（简化版）

#### 3.1 法器-辅槽配套表（简化后）

##### 白汞法杖（攻击基础）

| 辅槽效果 | 层级 | 效果 | 战斗力提升 |
|----------|------|------|----------|
| 🔰 精准 | 基础 | 伤害+10% | 10% |
| ⭐ 暴击 | 中等 | 伤害+30%，但消耗+1M | 20% |
| ⭐⭐ 连击 | 高级 | 每张卡额外产出1张 | 50% |

**选择指引：**
- 新手或困难模式 → 精准（稳定+10%）
- 标准模式 → 暴击（平衡输出和成本）
- 高手或精通模式 → 连击（极限操作）

##### 白汞桃木剑（防御基础）

| 辅槽效果 | 层级 | 效果 | 战斗力提升 |
|----------|------|------|----------|
| 🔰 守护 | 基础 | 护甲+15% | 15% |
| ⭐ 反甲 | 中等 | 护甲+30%，基础护甲数值翻倍 | 40% |
| ⭐⭐ 循环 | 高级 | 每个防御卡，下一批攻击+20% | 60% |

**选择指引：**
- 防守为主 → 守护
- 平衡防攻 → 反甲
- 防御反击流 → 循环

##### 沉星护符（资源转化）

| 辅槽效果 | 层级 | 效果 | 战斗力提升 |
|----------|------|------|----------|
| 🔰 提纯 | 基础 | 精萃产出+20% | 20% |
| ⭐ 炼化 | 中等 | 精萃产出+50%，坩埚伤害+30% | 50% |
| ⭐⭐ 转化 | 高级 | 灼烧标记→精萃，产出翻倍 | 100% |

**选择指引：**
- 常规精萃流 → 提纯
- 精萃平衡流 → 炼化
- 极限精萃流 → 转化

#### 3.2 辅槽效果重新设计（应用减法）

**原则：** 每个效果应该用一句话说明，玩家秒懂

| 旧设计 | 新设计 | 简化理由 |
|--------|--------|----------|
| "消耗全部蚀标记，本批材料消耗减少M×[蚀层数]" | "伤害+5%/层蚀标记" | 直观化为伤害数值 |
| "如果目标有蚀标记，消耗全部破甲标记，每层使本批D减少1拍" | "伤害+10%/层破甲标记，仅对敌人有效" | 删除D改变，聚焦伤害 |
| "消耗3层祝福标记，视为提供M×1" | "生产成本-15%/层祝福标记" | 转化为成本下降的形式 |

#### 3.3 玩家的优化迭代示例

```
游戏开始
  ↓ 战1-5：使用基础辅槽
  认为"战斗力+10%，可以接受"
  ↓ 战6：遇到强敌
  觉得伤害不足
  ↓ 获得新辅槽"暴击"（+30%伤害）
  ↓ 战7-15：安装新辅槽
  感受到"伤害明显变强"
  ↓ 战16：再次遇到困难
  ↓ 获得高级辅槽"连击"（额外产出）
  ↓ 战17+：安装新辅槽
  感受到"完全是另一个量级"
```

**理想感受链：**
1. 战1-5："哦，这个法器还不错"
2. 战6："需要升级一下"
3. 战7-15："感觉强了很多"
4. 战16："是时候升级了"
5. 战17+："这才是真正的强"

## 四、与其他系统的关系

### 辅槽系统的上游依赖

```
法器系统 ──→ 辅槽系统
（法器选择）  （提升法器）

铭文系统 ──→ 辅槽系统
（行动卡类型）（调整行动效果）
```

### 辅槽系统的下游影响

```
辅槽系统 ──→ 标记系统
（生成更多标记）

辅槽系统 ──→ 配方系统
（改变材料消耗）
```

### 玩家决策的顺序

```
1. 选择法器（40%注意力）
   ↓
2. 选择辅槽（35%注意力）← 本系统
   ↓
3. 装配铭文（25%注意力）
   ↓
4. 进入战斗
```

**关键点：** 辅槽应该是"法器选择后的自然下一步"，而非需要深度思考的新问题。

## 五、设计检查清单

使用本清单验证辅槽系统的设计：

- [ ] 每个法器最多3-4个推荐辅槽
- [ ] 每个辅槽的效果用一句话可说清（5秒理解）
- [ ] 辅槽提升的都是直观数值（伤害、护甲、产出、成本）
- [ ] 辅槽有明确的层级（基础→中等→高级）
- [ ] 玩家能看到具体的战斗力提升百分比
- [ ] 没有跨法器的复杂组合
- [ ] 没有动态改变D值的效果
- [ ] 辅槽与法器特性相关（不是通用的）
- [ ] 标记系统不与辅槽深度耦合
- [ ] 玩家可以看到"优化迭代路径"
