## 3. 推荐操作流程草案

以下为 R8-A／R9-A 条件下的具体可评审推荐，**尚未采纳**。保留既定桌面构图、两法器映射与两档列数；不要求用户决定相机角度、翻面轴、动画秒数或模型制作参数。

| 场景 | 玩家看见与操作 | 规则及信息边界 |
| --- | --- | --- |
| 新战 | 短说明结束后看到桌面第0拍与真实物件；以独立桌沿播放控件或P明确继续，亦可单步 | 初始暂停、已公开r0敌牌、尚未开工；不添加逐拍必点确认 |
| 法器加工 | 蓝晶杖＝施法，环杖＝守护；真实法器表现加工、等待、完工或中断，进度／未来用途可查 | 只有真实活动法器加工；当前承诺与未来设置分开，不增加器具能力 |
| 真实入牌 | 真实完工后，一张有厚度的窄卡从对应法器输出并落入桌面预计刻位；同拍按真实入行序排列 | 预留／待复用只用不同形状的容量提示，不画成可翻实牌；展示位置不改变队序或资格 |
| 玩家牌待生效 | 已知玩家牌以公开正面落在预计刻位，名称、类别、已知效果与预计拍可读；点击近观查完整信息 | 不为了制造“揭密翻牌”而把已公开玩家牌改成暗牌。背面偶然朝向镜头的在途姿态也不改变其公开资格，不能取消已有信息入口 |
| 玩家牌出牌 | 合法行动时真实卡片抬起、翻转出牌并呈现防护、攻击、支付与必要后续步骤，最后离开真实队列 | 出牌翻转是已知牌的使用动作，不是重新揭示。规则先合法结清，动作消费已提交事实；一张复合牌不按步骤重复翻牌、不重复付款或释放容量 |
| 敌牌揭示 | 未揭示牌背只带公开程序位置、r和类别；到r形成揭示／锁定后，真实卡片翻面，并按已公开T归位 | r揭示不等于T生效；不得由暗牌摆位、纹饰、近观或目标指线泄露Δ、T、量值或目标 |
| 敌牌到期 | 已揭示牌保持公开正面，在T抬起／出牌呈现目标作用，再移出待生效行 | 不重新盖回暗面再“揭示”一次，不把r揭示动作当伤害；锁定、无对象、落空与中断遵守真实事件，不为表演重选目标 |
| 棋子／筹码 | 防护、受击、层数增减和锁定从对应3D宿主／筹码呈现；精确数字贴宿主／所属筹码区 | 精确生命、护甲、实有／可用／锁定数字仍常驻；筹码近似数不替代真实余额 |
| 悬停／键盘焦点 | 物件静态轮廓与短名称／公开状态提示，离开取消 | 不暂停、不提交、不翻暗牌；悬停不是必需入口，Tab／Enter可等价完成 |
| 点击／Enter近观 | 先按合法完整事件边界暂停，立即静态切换近观姿态／镜头，说明绑定该对象，可读完整已知信息；关闭后静态返回 | 近观只是查看，不出牌、不推进、不付款，不在暂停中播放抬起／镜头过渡。暗牌保持牌背和公开字段；视觉近观不改变真实刻位、队序或身份 |
| 用途／锁定 | 从法器／标记物件进入相应操作，桌面拨片表达普通／兑现未来用途；数量在近观编辑并明确提交 | 数量可键入、±1；0禁提交、超量全拒绝；显示受理拍，草稿不自动提交；不要求拖动单个筹码 |
| 播放／单步／回看 | 独立桌沿实体控件提供继续／暂停、单步、倍速；刻轴控制回看与归位，键盘路径保留 | 不复用书／晶球作新功能；回看先暂停，归位不推进，7／5列仍是显示窗口，不是Q |
| 历史／摘要 | 历史刻位使用明确“已发生”的静态痕迹，点选查看；单步结束显示编号静态摘要，可在独立记录入口查全 | 历史不画成真实队列卡、不占Q、不重播；默认桌面不常驻大幅滚动日志框 |
| 资源抽屉 | 点击真实把手或D，按暂停边界静态显示向桌内展开的姿态及真实零材料空态，关闭静态归位 | 不借UI开合声音例外授予暂停运动；三格不是容量3，无假库存或可拖假物品 |
| 系统界面 | 开始、设置、保存／读取错误、必要确认与结果可采用简洁二维界面；战斗主操作返回真实物件 | 不以系统界面例外恢复整排战斗HUD；保存错误仍阻止后续不可逆提交并可重试，错误不能只用模型颜色表示 |

字数、符号、精确数字与长文可达性沿现有合同，不靠玩家从远处数筹码、辨颜色或听音效猜状态。近观扩大的是阅读空间，不给敌暗牌新增看牌权限。新实体播放控件只表达已有操作，不新增库存或玩法对象；形制由后续制作决定。

## 4. 已有规则唯一可解项

依据[交互规则](../../design/common/interaction-save/rules.md)、[交互设计](../../design/common/interaction-save/design.md)、[行动规则](../../design/systems/action-card-system/rules.md)、[行动设计](../../design/systems/action-card-system/design.md)及[EX-002](../../design/examples/complete-battle.md)：

| 项目 | Derived clarification，不重问 |
| --- | --- |
| 规则与动画 | 动画不决定逻辑时点，不由翻面／命中回调追加结算或付款；按最新结清状态显示数字和可操作对象 |
| 自动／单步现行基线 | 现行自动为主、2秒一拍与速度档、既定揭示停点、到下一观察窗口的单步继续有效，除非用户在R8明确要求重订 |
| 暂停与半翻牌 | 所有暂停入口在合法停点取消未完战斗运动，真实卡片立即归到最近结清状态；不冻结半翻牌，不为看完3D动作延迟暂停 |
| 查看与战斗静止 | 点击详情／抽屉先按完整事件边界暂停、关闭仍停是既定规则；新UI声音可用不等于暂停运动有例外。第3节的近观／抽屉采用静态切换是本轮具体推荐，未从声音条文推导出相机／物件过渡许可 |
| 单步 | 到下一观察窗口立即显示真实静态末态与有序摘要，不播放3D过渡或另加逐事件输入窗口 |
| 载入与失焦 | 静态重建真实牌／棋子／筹码并暂停，旧动作／声音不重播，环境静默至明确继续；失焦返回仍停，保留已提交状态、浏览、弹层与同进程草稿 |
| 终局 | 在真实终局检查后立即静态呈现结果与记录，停止余步；不是必须等最后卡片落地才判胜负，不补胜败音画例外 |
| 牌面与两时点 | 玩家已知牌静态正面展示；敌牌r前背面仅公开字段，r后保持公开正面，T出牌不二次揭密；未揭示字段保持秘密，不把“翻开”一词用成提前扣血 |
| 对象与选择 | 点选查看不等于执行；两法器自动选择目标／队列按承诺推进，不开放抓牌改序或拖到敌棋子指定目标 |
| 可达性 | 全部必要操作有点击／键盘路径，Tab聚焦真实可操作对象，最上近观／设置优先；文字与符号、静音／减动效可读性保留 |
| 布景 | 书与晶球仍无命中、焦点及功能；新桌沿控制不能以美术换皮偷偷改写这两件布景的身份 |

“暂停仍必须播翻面”“单步逐张演完”“读档补演旧牌”不是本轮默认候选，因为已有 R4—R7 直接决定。若用户主动明确改这些政策，再就具体变更处理，不提前新增题目。
