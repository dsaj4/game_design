## 拟新增内容

```md
预留只占容量，不预定未来牌序；实际入行后进入正常队列，同拍入行沿战前法器序。入行拍为t的行动最早t+1拍翻开，仍受队列及每拍至多一张限制。
```

```md
维护先付，再按当前有效供料优先级依次检查完整材料和可用容量；两者均满足且配置合法才托管、预留并开工，不满足者本次跳过。中断结清时解除该批预留，释放容量与退料最早下一拍复用。
```

```md
仅一份临时供料方案，玩家指定结束拍，到期分料前恢复基础方案；新方案替换旧方案，到期不恢复旧临时方案。托管、预留、已入行牌及既成后果不变。
```

```md
预留是否固定未来实际牌序尚未决定，不能把容量约束直接解释成队头占位或允许改序。
临时应对结束后自动恢复基础设置；结束触发、重叠覆盖与恢复时点仍待TL-Q11补齐。
```

替换为上述明确规则；删除与本批已答事项相同的当前Unknown。原来源文件保留当时未决范围，当前问题只留下尚未确认部分。

## 采纳理由

用户对已明确列出并说明代价的五项推荐整批确认。条件Q10随Q9成立；没有互斥项或需重复批准的范围。规则把生产容量与实际牌序分开，同时明确入行与生效的时间差、临时应对的恢复边界。

## 仍需保留的疑问

- 完整同拍总序、完整事件粒度、复合效果、敌我同类到期与终局；下一批开工检查在总序中的阶段。
- 行动正常离队空位在本拍哪个阶段可用于开工、多牌批次内部关系；中断释放下拍可用规则不自动推广到所有离队情形。
- 同拍临时方案到期与新操作的受理先后、供料之外的未来输出设置；这些归TL-Q02／11继续决定。
- 维护对象内部争料、退料资源区容量、战终托管归属、实际Q／D／批次卡数与卡效。
- 玩家是否理解预留、窗口及结束拍，长批次是否长期等待；均Hypothesis / NotRun。

不新增公平轮转、免费撤销、付费调牌序、重铭或当前批次暂停／改速。保留唯一D≥1、无位不开工、完工即入行、后续无冷却、严格早于T取消及既有防护→伤害／打断→幸存完工部分顺序。
