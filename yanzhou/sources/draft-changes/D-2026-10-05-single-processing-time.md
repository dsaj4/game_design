## 拟新增内容

```md
开工必须同时具备合法配置、完整制造材料及本批所需队列容量；开工时托管材料并预留所需入行位置，无位不开工。处理中预留与已入行行动卡共同占用有限容量Q。完工时预留转为行动卡入行，不增加容量占用，不设完工后等待。
```

“共同占用”可记为已入行牌数＋全部有效预留位置数≤Q；这只是容量约束，不决定预留的具体排位。免费供料调整不挪用已开工批次的材料或预留。

## 拟替换内容

原文（SYS-002 TL-03／05）：

```md
加工时间、交付时间、休歇时间分别登记。
队列满时成品保留在原法器，交付后才继续生产。
```

新文：

```md
法器只保留处理耗时D，取至少1拍的整数；不设独立生产周期、冷却／休歇R、交付耗时J或首次起点S。条件满足即按开工阶段自动处理，完成后立即入行。无位在开工前等待，已开工批次不再因行满滞留成品。后续批次不增加独立冷却，仍须满足开工条件。
```

## 采纳理由

用户明确要求简化法器生产耗时，并对容量前移、取消S、D正整数的三项推荐整批确认。容量预留是其明确选择的代价，不再要求重复批准；不把此次确认扩展到其他批次问题。

## 仍需保留的疑问

- S1-Q1：入行最早翻开；S1-Q5：临时供料结束与恢复。
- 预留是否锁定实际牌序、多个法器开工争容量的顺序、打断后的预留释放时点和可复用时点。
- 后续批次检查的同拍位置、具体批次张数／多牌关系及Q／D数值。
- 完整事件、复合效果、敌牌失效、资源维护等既有未知；本次均不关闭。

取消敌牌仍须实际早于T，入行不等于生效。资源维护／补给周期未被取消。未新增直接调牌序、手动暂停／改速当前批次等权限。没有实验、卡池或实现采纳。
