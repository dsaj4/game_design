## 拟新增内容

```md
一桌一轴：战中只有一张桌子，横向为回合内X个时间列，纵向为一条战斗行加每台已部署法器各一条工序行。唯一动词是排：牌放进战斗行第c列为即时使用；放进法器工序行第c列为投料并在该列开工；不放为留手。撤回免费，直到光标越过该格；光标左侧冻结只读，右侧可改。一器同一时间一条在制，同行不重叠，开工前可免费撤回、替换、调序，开工后冻结。产物在工序结束后的列间窗口入手，下一列起可用。最终整理与列间窗口合并为一个布置窗口。复制上一回合布局是纯界面捷径，只填仍有合格牌的格子。

炉心：战前必选，小炉1×1、长炉1×2，占格，不嵌铭文，不产卡；没有炉心不可开战；多炉心时每格取最近炉心。某格圈号＝max(0, 到最近炉心格的曼哈顿距离－1)。整件法器取其最远格所在圈，圈下限＝1＋圈号。实际D＝max(现行D公式结果, 圈下限)，至少1；催炉类效果不能突破圈下限。空间只在装载确认时求值一次，战中桌面只读结果；界面须标出拖慢该法器的格与所在圈。

组合：接触本身没有效果。内容给出组合表；两件指定法器战前接触，玩家主动组合后合并为更大的法器，一件法器同时只属于一个组合，可战前拆开重配。占形取并集，按并集最远格计圈。组合体有自己的配方、入料口与产出；部件在组合状态下不能单独开工。

入料口尺寸P：每台法器（含组合体）由内容直接设定，含义为一批最多投几张材料，与占形脱钩；配方材料数不得大于P。

辅助覆盖圈：辅助自带覆盖圈，被覆盖的每台法器全额生效，同效叠加沿用现行规则；取消朝向、接口与单器连接。首版覆盖范围为距辅助格曼哈顿距离不超过2，不设覆盖数上限，测试后再定。

联动：战前公开敌基础表的类别轮廓（位置、类别、即时或延时标识，不含效果）。封印牌作为新增敌牌类型另行采纳，首战不引入。疲劳折合列数，战前读数为本场在N列内最多产出X批，取时间上限与料量上限的较小值。
```

## 采纳理由

现行闭环里，生产钟与出牌钟之间只有手牌一条单向接口，生产换成抽牌堆时间轴照样成立，战中状态面（待料、托管、吸收拍、资格拍、锁定）远大于决策面。一桌一轴保留需要继承的体验：理解配方与工序、同一张牌的三向抉择、看见投入的去向、公开威胁与疲劳的节奏压力，同时删去大批仅为协调两套钟而存在的状态。纸面算术显示首战四台在1枚小炉下最少拖慢1列、装载35/40，空间约束可落到具体数字。
