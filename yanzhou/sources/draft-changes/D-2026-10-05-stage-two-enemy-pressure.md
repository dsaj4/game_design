## 拟新增内容

```md
敌方程序为固定循环时间表：每张暗牌有循环内翻开偏移与Δ，循环长L，不因取消或玩家行为移动。开战即公开每张暗牌的程序位置、翻开拍与行动种类；数值、Δ、目标与完整效果翻开时公开。
```

```md
指定打断翻开时，在正处理批次的法器中锁定剩余R＝a+D−r最大者（含R=0），并列取战前法器序靠前者；无任何施法则无锁定对象，照常倒计时，到期落空。到期打断所锁定法器当时的处理批次；无批次或目标已不存在则落空：无效果，结算一次离场，不等待、不改选、不转为伤害。
```

```md
每场战斗只有一个发出敌牌的来源敌人，其死亡即本场胜利，未到期的已揭示敌牌随战斗结束作废；不发牌的附属物不计入胜负，规则另定。伤害与打断大类内，本拍到期的敌方行动先于本拍玩家行动结算；到期伤害已使玩家死亡则玩家失败。
```

```md
行动卡（敌我共用）分攻击▲、防御■、打断⊘、其他✱四类，始终配种类文字，只表示大类。其他类敌牌加通用副记号。通用组件与UI不地方化；地域牌组只改花色、配色、材质与装饰笔触，不改符号轮廓、位置与含义。被锁定法器显示危险开工带[T−D, T−1]，停供方案提示结束拍须≥T，并显示预计生效拍与同拍入行顺序。
```
