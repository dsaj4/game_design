2026-10-23 · Accepted / G002-CORE-064 / beat-pause.1。用户直接要求完成本拍及动画后暂停，并明确选择所有暂停入口统一、接受揭示后本拍仍完成的后果。来源与唯一共同输入版本见[M](../materials/M-2026-10-23-beat-end-pause.md)，取舍见[E](../evaluations/E-2026-10-23-beat-end-pause.md)。

| 替换位置 | 现行行为 |
| --- | --- |
| TL-17、CORE-060暂停／单步／详情／回看 | 任何暂停请求完成当前拍及动画后停；单步完成一拍后停；下一拍不开始 |
| CORE-060揭示暂停 | 揭示时请求，本拍拍末停；此前合法输入照常，收尾后的调整待下一观察窗口 |
| CORE-061、CORE-063停点音画 | 播完本拍已发生事件的动画与一次性声音，停点冻结循环；删去取消动画与单步静态跳过 |
| CORE-062失焦 | 后台仅收尾当前拍，返回不撤销请求、不自动继续 |
| TL-19恢复／退出 | 正常退出先收尾；异常载入静态保留最近结清状态，不重做旧事件、不自动补跑 |
| 核心、术语、案例、任务包与验收 | 同步上述行为；实际预期以[权威规则](../../design/common/interaction-save/rules.md#拍末暂停core-064)为准 |
