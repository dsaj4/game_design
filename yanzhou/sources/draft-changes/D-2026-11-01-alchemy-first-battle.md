# 新炼金首战冻结

2026-11-01 · **Accepted / Content Specification · CORE-073 · first-distillation.1**。GDD 3.6／GDD-0。依据[用户明确委托](../inbox/2026-11-01-alchemy-first-battle.md)、[Qualified M](../materials/M-2026-11-01-alchemy-first-battle.md)与[评估E](../evaluations/E-2026-11-01-alchemy-first-battle.md)。用户授权确定并冻结本场，具体选值为此委托下的设计决定；不冒称用户逐值确认。

## 目标与新增

以[内容库catalog](../../content-library/catalog.json)的`alchemy.encounter-first-distillation`为唯一具体配置，[首战规格](../../content-library/first-battle.md)自动派生；新增EX-005承载静态时间、胜败推导和验收预期，不复用EX-004。

采纳四台真实设备、八枚预嵌核心、四个固定用途、对应占形与兼容、启动材料及数量、有限补给到达与下一拍资格、玩家初态、唯一新敌人及四种敌牌、完整A／B五列循环、信息公开、胜败与战终处理。CORE-072的D、配方连接、数量、卡效与费用保持。

仅为本包闭合TL-46运输／展开及TL-25选留：运输预留本体，投入卡离包后再展开供料；战终停止生产、结清真实归属后取消供料预留并重装。本包携带标签和种类上限、无奖励／无商店明确在catalog；不替其他遭遇或全库填默认值。几何冻结是本包可部署规格，不将文案、美术或通用兼容全盘晋级。

## 替换与影响

替换现行入口中的“完整首战套组／敌表／初态尚无合法输入”为CORE-073限定输入已齐、实现与体验NotRun。新增一敌及四敌牌使内容库为67项，35原配方及3构筑身份保持。同步GDD、baseline、内容合同、相关细则、问题、来源、决策、验收与开发入口。

不恢复CORE-071淘汰的38项、原敌表／首战默认、原EX-004或其实现证据；不采纳上一批尚未确认的Q9全8器具组合、Q10全材料携带标签、Q11通用补给样例。只冻结本次所需子集。

## 理由、疑问与状态

先提供能生产、能攻击、能防护并有明确胜败的单场内容，再验证产线与回收的取舍。EX-005的静态路线可检查时点与算术，不能证明最优打法、难度合适或玩家乐趣。

**已采纳并同步现行设计。** 实现、玩法模拟、平衡和真人体验均NotRun；本次只授权设计与文档／几何检查，未启动实验。整局路线、商店、其他设备和配方的完整部署继续待设计。
