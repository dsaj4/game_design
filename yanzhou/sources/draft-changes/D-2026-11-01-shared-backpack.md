## 新增与替换

| 原文边界 | 采纳后的边界 |
| --- | --- |
| 生产空间与跨战携带容量不同／分账 | 同一张真实网格按装载、开战投入／展开、战斗、战后重装使用；每阶段真实物件均须满足其已定空间合同 |
| 配置库存不受材料携带容量约束，可留包外备用 | 法器、核心、辅助与可携带卡共用空间，备用配置也占格；取得和携带资格仍分开，无免费包外设备仓 |
| 核心嵌入不另占生产格，散装占用未定 | 散装每枚1格，兼容嵌入额外0格；真实副本、战前可逆拆装和战中固定保留 |
| 未投入库存与生产布局分别处理 | 本场投入卡真实离包入手，不保留虚拟格；留包物本战不可取用，已部署设备／供料及保留物固定；手牌继续无硬上限 |
| 胜利卡牌按独立容量选留 | 合格剩余卡、未投入物和真实配置重新竞争同一网格；不补已消费输入，不把可回收视为可携带 |
| TL-35绝对无出售 | 允许旧配置物出售的系统方向；对象细分、入口、时点、价格和满包／交易恢复待定，未闭合前不执行具体售卖 |

高阶以跨战准备前料、本战完成后段为主要设计方向；生命灵药四台为后续设计样本，现有首场与内容资格不因此替换。种类上限不在本次取消范围，是否后续保留与实际值仍待TL-Q01。

## 保留与排除

保留CORE-069辅助单器连接／同效叠加／贡献继承，CORE-068专属供料／战前固定用途／默认自动补料／一在制一待料，CORE-067统一卡牌／免费布牌／回收，以及D、敌程序、逐事件终局和疲劳。

不采纳40格、具体尺寸／形状、运输仅计本体／不预留供料、备用设备不展开供料、初始配发、扩包曲线、新携带白名单、免费遗弃、售价或任何新卡效。Raw工作稿和内容库候选不整体晋级。售卖能力被采纳不代表操作合同已可实现；BP-Q01／03／04与TL-Q01／06继续列明缺口。

## 采纳理由与同步

将携带资源和配置选择纳入同一可见空间，消除备用设备的免费容量，使前战准备与本战产能形成取舍。阶段交接与唯一归属进入规则，未定具体值保持Unknown。

同步核心、细则、基准、规则／来源索引、编号与问题、系统手册／工作稿状态、开发入口及任务包；内容库只更新10个已有核心的“散装1格”规则说明并重建派生页，不改其名称、配方、几何或发行资格。图稿与原始素材不改。
