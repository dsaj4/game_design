# 主系统一致性与设计风险审查

Project ID：game-002。文档角色：DesignReview / Governance。日期：2026-10-04。输入：`e9b2a8fa7c88e9a34ab6e9a37b4cf05daecf89a4`，GDD 2.1 / TL-1 + INS-1，GDD-0。状态：文档订正已执行；新玩法建议未采纳；体验Hypothesis / NotRun。

## 结论与证据边界

**设计逻辑有成立可能，但关键应对和构筑取舍尚未得到内容与玩家证据支持。**当前最薄弱的一环是“揭示威胁后还能作有意义的选择”：行动必须经过生产和队列，既有批次不可改写，而重铭与直接干涉细则尚未定义。若免费改线不能在截止前改变结果，战中判断可能只剩观看和承受。

这不是对游戏不好玩的结论。已采纳的实体占用、材料承诺、满行保留、严格截止和保存边界能建立清楚的因果关系；不足在于还没有实际法器／铭文／配方／敌牌／预算共同证明这些约束会产生多种可行取舍。现阶段最值得补的是一小组完整内容与时序，不是继续扩充机制数量。

证据标记：**Derived**为已读规则推出的约束或条件风险；**Assumed**为尚无玩家证据的行为／体验预期；**Unknown**为设计未定。以下没有本轮Observed玩家证据。历史Accepted不变；文档检查不能关闭体验问题，也不能将GDD-0提升为GDD-1。

## 设计风险与未闭合接口

下列均Open。优先级P1表示在限定原型输入冻结前优先处理，P2表示在内容／经济扩展前处理；并非已证实的Bug。具体待决仍统一维护在[questions](questions.md)，本页记录理由、反例与建议。

### AUD-021 · P1：关键威胁可能只剩“看见但做不了”

来源：[TL-02／27](../design/systems/01-grammar.md)、[TL-06](../design/systems/02-wands.md)、[TL-08／10](../design/systems/03-combat.md)、[TL-18](../design/systems/07-interaction-save.md)。Derived：取消实际生效必须早于T，暂停只增加思考时间；路由不能改变既有批次、成品和行动种类。INS-1又固定材料类别与行动种类，具体免费路由能改变什么尚未举出完整实例。

反例：揭示时唯一取消法器尚在加工前一批，队列又塞满；所有合法方案的最早生效都不早于T。若承受损失也是唯一剩余结果，这次揭示没有战中选择。它可以是预谋不足的合理惩罚；风险是多数关键威胁都如此。**不建议为修复它自动增加即时取消或免费重铭。**先用实际库存列出揭示时至少两种不同代价的完整应对路径（设计审查目标，不是保证每套构筑都可取消），包括继续原计划、改未来供料或承受损失。专门取消法器若持续运行，还会在没有合法敌牌时按TL-21空放，消耗材料和队列；靠断料避免空放又可能赶不上下一次揭示，这个取舍须用内容证明。关联TL-Q09／10、INS-Q07；免费改线本身的用途须先说清。

<a id="aud-022"></a>

### AUD-022 · P1：公共队列可能压平产线、提速与多法器价值

来源：[TL-05](../design/systems/02-wands.md)、[TL-08](../design/systems/03-combat.md)、[TL-18](../design/systems/07-interaction-save.md)。Derived：N拍内最多兑现N张玩家行动卡；一旦持续入行需求高于1张／拍，有限缓冲最终阻塞，增加Q只能改变等待和滞留。这个上界针对卡数，不等于伤害或所有构筑收益上界。

风险：提速只把成品更早堵在法器里；高优先级低价值牌挤占取消、资源生成或高收益行动。若未来高阶材料也经行动牌产生，其准备步骤还要竞争同一出牌额度，不能只比较加工时间。反例是快攻持续入行，让一张已经完成的防护错过窗口。建议同预算比较“料不足、产能不足、队列饱和”三种状态，分别查增加法器、提速和单牌价值的边际收益；不直接改已采纳的1张／拍。关联TL-Q04／06／09，INS-Q02／03。

<a id="aud-023"></a>

### AUD-023 · P1：部分时序不足以裁定复合牌与胜负

来源：[TL-11／13／29](../design/systems/03-combat.md)、[TL-17](../design/systems/07-interaction-save.md)。Unknown：防护→伤害／打断→完工是大类顺序，“完整事件”却没有定义到一张复合牌、一个效果步骤还是同类同时发生的一组行动。

反例：玩家与敌人都剩1生命，同拍双方造成1伤害；按逐牌完整事件先后会得到相反胜负，按同时事件又可能双亡失败。另一张牌既护甲又伤害，若拆到不同大类，中间终局和目标失效能否中止后半段也未定。不能把“双方同检查点归零判负”当成已确定同拍都处理。建议先给上述场景与同拍揭示／暂停一个唯一预期，再列完整事件顺序；第一组内容若不需要复合牌，可先明确排除，保留后续规则缺口。关联TL-Q02／05。

<a id="aud-024"></a>

### AUD-024 · P1：周期、批次与临时恢复缺少可执行定义

来源：[TL-03–07](../design/systems/02-wands.md)、[参数](../design/parameters.md)、[TL-44](../design/systems/01-grammar.md)。Unknown：战前可选“周期”与D／J／R的关系、阻塞时J计时、入行最早翻开、一次多牌的部分交付，以及临时设置何时结束都没有闭合。

反例：一批产2张，玩家行只余1格；整批等、逐张进入、重新计交付各自影响占用与响应。临时改线若按“威胁解除”恢复，两个威胁重叠时谁覆盖谁、返工后的第一批用何设置也无答案。建议先选一批一张作为待确认的最小内容范围，并给一张逐拍状态表，明确阻塞前／中／后、取消后再开工和基础设置恢复触发；D/J/R零值域单列。不能从当前示意图补出公式。关联TL-Q04，新补TL-Q11。

<a id="aud-025"></a>

### AUD-025 · P1：维护优先可能造成长期断粮，而非短暂等待

来源：[TL-22／23](../design/systems/04-elements-environment.md)、[TL-30](../design/systems/03-combat.md)。Derived条件：若每次到期维护吃光可用补给，新加工永远得不到料；多个产物争用还可能使固定低优先级对象长期休眠。材料补足不代表所有对象都能恢复。

例如每次补1份、已有产物同时维护需1份，且没有其他供给，则基础行动无法重新开工。这里只是条件反例，不是正式数值。若产物又被托管且仍吃维护，短缺更难由玩家解释。建议先核对最低补给和最坏维护负担，明确休眠、托管与竞争结果；可以保留资源耗尽作为构筑失败，但要有预警与可追溯原因，不偷偷增加公平轮转或免费补料。关联TL-Q03／06、INS-Q03。

<a id="aud-026"></a>

### AUD-026 · P1：高阶资源链已被切断，不能用旧收益链证明新核心成立

来源：[TL-38](../design/systems/02-wands.md)、[TL-14／15／43](../design/systems/04-elements-environment.md)、[CORE-049](../sources/draft-changes/D-2026-10-04-artifact-inscription-core.md)。Unknown：高阶资源获取／加工目前没有正式路径，只有维护、增幅与携带接口。清理FX冲突后，这个缺口应保持可见。

后果：没有来源就无法比较即时攻防与高阶准备；若材料只能由消耗同种高阶料的行动生成，还会出现无法启动的闭环。建议先只选一条完整取得链，逐项写初始来源、消费、产出、排队和启动条件，确认不依赖免费组件；随后才评估维护和跨战。行动产资源是一种可另行设计的方向，不是本次默认答案。关联INS-Q02／03、TL-Q06。

<a id="aud-027"></a>

### AUD-027 · P2：契合与预设暗句可能把组合压成查表和固定答案

来源：[TL-39–45／26／28](../design/systems/01-grammar.md)、[GDD体验支柱](../design/GDD.md)。Assumed：受限空缺更易理解、不同情境会选不同核心和辅槽。Derived条件：若契合组合只有正收益、成本相同且替代方案没有情境优势，玩家没有放弃契合的理由；同理，若打造只增益且资源无其他价值，它只是必做升级。

“符合器具内涵”能帮助说明主题，不能独自判定合法性。自然语言像同义词却因逐法器白名单产生不透明差异，会让玩家记答案。建议每个代表法器至少列契合方案、可行非契合用途和非法反例，显示基础行动／修饰／契合的各自贡献；先决定哪些词义可迁移理解，再扩专属组合。此为审查建议，不强制任何铭文通配。关联INS-Q01／04–06、TL-Q10。

<a id="aud-028"></a>

### AUD-028 · P2：旧随机获取结构可能不适合现在的有限兼容

来源：[TL-34／35](../design/systems/06-rewards-growth.md)、[TL-31](../design/systems/07-interaction-save.md)、[TL-39／40](../design/systems/01-grammar.md)。Derived：休整保证词性分布，不保证适配现有法器；商店也不按构筑补齐。INS-1要求核心全部必填，所以有库存并不等于能用。

反例：玩家缺一个特定法器可用的动词，候选虽含动词却全部不兼容；为此放弃恢复，最后只得到未来也未必能用的部件。更隐蔽的是池中缺名词时，按既有TL-34连可用修饰词的拿取机会也整体关闭。建议用真实初始库存与小型奖励池枚举沿途可用、可留待未来、完全无用途三种结果；先收敛内容和渠道，再决定是否需要改抽取结构，不直接添加保底。关联TL-Q06、INS-Q01／05。

<a id="aud-029"></a>

### AUD-029 · P2：跨战收割、护甲储存与疲劳存在相反激励

来源：[TL-25／33](../design/systems/06-rewards-growth.md)、[TL-24／29](../design/systems/03-combat.md)。Derived条件：若留下最后一个弱敌能安全继续产可携带资源，而且新增资源的下场收益大于拖延生命成本，就会奖励故意不结束战斗。基础料清空和增幅重置不能消除“高阶数量”积累；战间维护状态重置还可能改变持有成本。

护甲无自然到期和统一上限，防护过量可能先积累缓冲，也可能只挤占队列；疲劳绕甲，但目前没有曲线证明它足以约束收割或保证所有合法恢复组合有限终局。建议同预算比较立即胜利／多等一批／更久拖延的跨两战结果，分别检查生命、资源容量和后续起跑优势；不直接恢复已被拒绝的全量清空或跨战维护。关联TL-Q01／07／10。

<a id="aud-030"></a>

### AUD-030 · P2：信息可查不等于因果可理解，自动运行也不等于有决策节奏

来源：[TL-17／19／36](../design/systems/07-interaction-save.md)、[核心循环](../design/GDD.md)、[验收](../design/validation.md)。Assumed：玩家能同时理解兼容、占用、托管、加工、交付、队列、截止、维护和付费等关系。当前“都有地方显示”仅保证信息存在，没有证明玩家能及时找出真正瓶颈。

反例：取消牌有料、法器已完工，但交付阻塞导致错过截止；玩家可能误以为是材料或按钮问题。另一方面，每张普通牌都弹暂停会变成碎片操作，威胁太少则可能长时间只观看。建议在实际内容中优先回答“哪项承诺挡住了下一步、现在能改变什么、预计何时生效”，同时观察普通区间的必要操作和无决定等待；逻辑时长与暂停思考的现实用时分开记录。参数和样本未定，不编造操作频率门槛。关联TL-Q08／10。

最低成本的下一步是**静态逐拍推演材料表**：同一真实库存下记录普通自动区间、一次揭示、至少两种代价不同的应对、行满／维护缺料／终局的结果。先发现规则不唯一处，再冻结限定原型；真正执行纸面试玩、模拟或真人测试另需任务授权，本轮未执行。玩家阶段先记录实际尝试和解释，再询问偏好；若需要提示才会使用方案，不能当作独立理解的证据。
