## 体验风险与最小验证（TL-Q10）

以下是待验证假设，不是已观察缺陷。获得具体测试任务后再执行；当前纸面核对只确认规则与算术。

| 风险 | 出现条件 | 最小检查 |
| --- | --- | --- |
| 可回收牌挤掉生产与合成 | 同一牌能连续使用后续列，合成却会消费它 | 比较同预算下重复使用、留手加工及新产物是否各有合理场景；旧每道必占行动列的限制已退出 |
| 无上限手牌持续膨胀 | 生产大于实际使用，两组来回查找 | 比较新增产物能否改善选择、必要翻页与查找；旧H3烧牌已取消，但产量不等于有效使用的失败经验保留 |
| 周期收益脱离普通出牌预算 | 独立登记持续增加但只给层数上限 | 分开数并存登记、未来总收益和实有层数 |
| 自动消费迫使玩家反复锁解 | 多消费者争同类资源／标记 | 区分有新信息的调整与重复维护同一计划的操作 |
| 配方发现变穷举 | 免费尝试，词义不能预测结果 | 先记尝试前理由，再看新反馈是否改变下一次预测 |
| 固定敌表只剩背板 | 原牌只露牌背、后续牌公开，或每轮只有唯一有效排法；廉价诱饵可能吸收所有打断 | 对照首次遇敌／熟悉程序及真实库存、生命、列位与卡效费用；只有无代价支配才考虑改内容，不默认封堵诱饵或保证失误可救 |
| 成长无实际收益 | 取整／D下限抹平修饰，或新增卡只留在手中、未改善实际使用，契合只有无代价正收益 | 比较实际生效、支付与非契合替代；加速可能只增加囤牌，不保证更多有效行动 |
| 组件取得不支持构筑 | 词性齐全仍不兼容；放弃回血却获得无用途组件 | 用真实路线和库存查可部署性及机会成本；缺名词时休整无候选的整包后果也要检查，不默认新增保底 |
| 拖战囤积支配现场取材 | 可积累、跨战携带，而疲劳未成约束 | 比较主动结束与继续拖战的净收益，连同生命和携带预算 |
| 少量对象仍有过多账目 | 回合／生产拍／结算列、两组手牌、回收和消费锁定同时出现 | 让玩家解释一次失败和下一步选择，记必要查阅及误判 |
| 资源与标记重复收费 | 两份账只为相同倍率增加重复等待 | 列各自支持的玩家选择；删掉某层若只少记账，先改该内容，不直接合并通用机制 |
| 维护吞掉全部供给／闭环无法启动 | 每次补1而维护也需1，或两个消费者互等对方产出且无初始料／回退 | 核对最坏负担、真实启动来源与休眠竞争；保留可解释失败，不偷加公平轮转或免费补料 |
| 取消牌常空放或等待过迟 | 只能取消已公开且尚未开列的后续牌，实际卡效和可达列位尚缺 | 比较提前承诺、等待和其他应对的实际代价；不能据此默认开放插队或免费补救 |
| 最终及列间窗口变成固定作业 | 每列只重复点继续或搬同一牌，没有新选择 | 对照完整手动路线与合法回收卡，记录选择理由和操作次数；无测试授权不执行 |
| 自动战斗难以理解 | 信息分散或长时间没有选择；反复暂停只为维持运行 | 让玩家解释阻塞、能改什么与何时兑现；分开逻辑时长、现实等待和需要提示才理解 |

这些风险只在对应内容实际采用时展开，不生成首场新机制。来源为[历史审查](../history/README.md#治理历史)中仍未被后续决定解决的条件风险；已闭合D公式、总序与恢复定义不重开。真实验证先冻结场景及通过／失败信号，沿具体实验授权执行，不从成功子集反推全局成立。
