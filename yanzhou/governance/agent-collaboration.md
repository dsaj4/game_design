# 言咒多智能体协作规范

版本：AGC-1 / 2026-10-02。这里定义可反复接续的工作方式；本次建立规范并未启动后台代理、定时任务、实验或新会话。

采用 **1 名协调者 + 最多 3 名工作者**。小任务由单个代理完成；只有目标可以拆成独立责任时才并行。设计决定由用户授权和既有流程形成，不能用代理投票代替。

## 角色与所有权

| 角色 | 主要责任 | 写入与工具 |
| --- | --- | --- |
| 协调者 / 集成者 | 冻结本轮材料与目标，分配路径，维护依赖，归并冲突、批量提问、最终检查和提交 | 独占共享索引、治理记录及获授权的正式文档集成；资格澄清用 grill-with-docs |
| 设计工作者 | 在允许范围扩展或细化一个机制/方向，明确与既有设计关系 | 只写任务卡指定的方向文件或合格草案；按需调用 gameplay-mechanism-designer、gdd-toolkit |
| 独立审查者 | 核查证据、反例、接口及文档前后一致；指出阻塞和不确定性 | 默认只读设计，输出独立审查意见；按需调用 game-design-reality-check、gdd-toolkit；不自行采纳 |
| 实现 / 验证工作者 | 在获授权的外部代码仓库完成限定 Demo 或测试，报告偏差与可复现证据 | 独占指定代码路径；技术细节留代码仓库，协调者更新本仓库开发索引和 DA-1 登记 |

没有实现授权时，第四席空置，或换成材料分析者：用 game-analysis-orchestra 处理指定媒体材料。不是额外增加第五个同时运行的角色。审查者可在下一阶段承担验证，但不能把自己的设计自评冒充独立审查。

## 每轮任务卡

复用所属方向 README、现有开发交接或对应治理记录，不另建总任务数据库。委派消息至少包含：

```text
项目/方向与本轮目标：
材料模式：CORE / GDD / FULL / CUSTOM / NONE
允许读取的实际路径、固定提交/日期，及显式排除项：
资格/采纳状态与已有授权：
当前代码仓库、分支、版本（没有实现任务则写不适用）：
每个角色负责的文件、只读范围及禁止触碰的共享文件：
输入依赖、交付物、可验证的完成条件：
是否授权具体实验；若授权，范围和停止条件：
本轮时间/轮次界限及需交还用户的决定：
```

探索任务先按 start 与探索 AGENTS 选择材料。新方向默认 CORE，已有方向沿登记版本；治理任务默认 NONE 加明确元数据白名单。所有子代理继承同一限制，不通过其他代理转述获取被排除背景。FULL 也不自动包括外部代码、旧项目或历史归档。

## 协作循环

1. 协调者检查 Git 状态与允许材料，确认任务卡；能独立推进的先做，缺失的关键输入保留 Unknown。
2. 需要并行时按互不重叠文件委派，并明确告知工作者“你并非独自在代码库工作，不得撤销他人修改，需适配并存改动”。同一系统的强依赖内容先串行形成接口，再并行细化。
3. 审查者读取固定输入和本轮交付，区分来源证据、模型推演与实际测试。Raw 的审查仍是原位置的构思审查，不跳级写正式 Evaluation。
4. 协调者合并问题，先从白名单材料找答案，再把需要用户选择的问题按依赖成组提出推荐和影响。既有明确采纳授权可继续；没有授权的玩法变化停在规定阶段。
5. 只有具体实现/实验任务已授权时，才交给实现角色。以开发索引选定的实际项目和版本为准，不默认采用旧 Demo 或复用其他方向结论。新建或复用资源按 DA-1 登记。
6. 协调者检查链接、状态、编号、来源与改动范围，提交推送本轮文件，留下下一轮入口。所有结论分别记录 Accepted、Hypothesis/NotRun 和实现状态；代码通过不证明玩法有趣。

同一 checkout 中所有代理共享分支和未提交改动：工作者不得切分支、重置工作区或自行提交他人文件，由协调者统一暂存提交。确需隔离并行写作时，按授权使用独立 worktree，并以明确提交交接；多个会话不自动获得彼此文件的写权限。跨仓库交付要分别记录仓库与提交。

## 接续与暂停条件

每次交付保留：输入版本、修改文件、实际检查结果、未决问题及下一项可执行动作。下一轮先核对这些信息是否过期。材料范围变化、写入冲突、资格关键项缺失、需要新的执行授权或达到本轮界限时结束该轮，汇报具体阻塞，不让代理互相循环派单。

持续协作依赖这些可恢复记录，默认不意味着无人值守常驻。只有用户明确要求时才新建会话、发送跨会话消息或设置自动化。

可直接使用的启动句：

> 按 AGC-1 启动本轮多智能体协作。目标是【具体方向/系统的问题】，材料为【模式、白名单和版本】，最多协调者加三名工作者；先划定文件所有权，审查与设计分开。本轮完成条件是【交付与检查】，实现/实验授权为【具体范围或无】。完成后提交推送并留下下一轮交接。
