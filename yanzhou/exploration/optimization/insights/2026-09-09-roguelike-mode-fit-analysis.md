# 法术体系的肉鸽模式匹配研究

## 研究问题

在保留词卡构句、离散时间、公开敌意、打断、路线、休整、商店和局内构筑的前提下，什么样的肉鸽外层能放大法术体系的独特决策，而不是把玩家注意力转移到另一套主玩法？

## 主要结论

推荐的模式组合是：**公开敌意的法术远征 + 时间承诺战斗 + 词卡流派构筑**。

一句话原则：**读敌意，组一句，押节拍，带着代价走下一站。**

它的肉鸽部分不是再加一个独立小游戏，而是让每次战斗的施法选择改变下一站的资源与路线状态：玩家在公开的敌方准备下，用词卡组成一句法术，决定立即兑现、承诺后兑现或留下回响；战后用有限的奖励、商店和休整机会调整词卡与全局道具，再选择下一条可见分叉路线。这样“随机性”主要改变可用表达和风险环境，核心决策仍然来自法术语义与时间。

## 为什么适配当前体系

| 当前已有能力 | 肉鸽层的职责 | 玩家得到的连续问题 |
| --- | --- | --- |
| 词卡构句 | 奖励/商店改变可表达的句子集合 | 下一场我想让哪些句子更容易出现？ |
| 离散时间与补牌 | 敌人节拍、承诺和打断制造短期风险 | 现在结算、等一个窗口，还是先铺条件？ |
| 公开敌意 | 路线和遭遇提供可预知但不完整的未来压力 | 当前卡组能承受哪种敌人和时间表？ |
| 生命、护甲与休整 | 把战斗损耗转成路线机会成本 | 为了拿一张词卡，是否值得少一次恢复？ |
| 商店、金币与全局道具 | 改变构筑的长期约束和补救手段 | 买即时补强，还是投资一种施法节奏？ |
| 召唤与关联卡 | 让构筑出现“场上单位—临时词卡”的分支 | 我是在强化本句，还是强化下一轮供给？ |

## 建议的外层结构

### 一局结构

`起始词组与一个基础倾向 → 可见分叉路线 → 战斗/休整/商店/事件节点 → 普通战斗奖励或道具 → 单阶段终点首领`

首轮只需要一条短远征，不需要局外成长、职业锁、复杂地图或多阶段首领。路线节点的价值在于改变“下一场施法问题”，而不只是发放更多数值。

### 词卡与构筑

- 奖励优先改变句子的**可表达性、时间预算和材料供给**，不以统一长句倍率替代流派差异。
- 每个流派用一个可复述的转换关系表达，例如“把等待换成状态储备”或“把召唤物生命换成额外施法窗口”；具体流派名称和卡表仍 `Unknown`。
- 奖励允许拒收，商店提供补洞和转向机会；构筑的价值是改变可行计划，不是单纯提高面板。

### 战斗与肉鸽的连接点

每场结束时保留少量会影响下一战的结果：生命损耗、金币、已取得词卡/道具、以及本局路线位置。不要把战斗评价压成分数排行榜；“更快结束”只有在它减少受击或增加金币时才有意义，不能独立成为第二套计分游戏。

## 五层设计链

| 层级 | 候选内容 | 需要验证 |
| --- | --- | --- |
| Primitive Rule | 路线节点改变可获得资源，法术有兑现时机 | 玩家是否能理解节点选择和时间姿态的因果 |
| Interaction | 路线风险 × 词卡供给 × 敌方节拍 × 生命/金币 | 同一奖励是否在不同卡组/生命状态下有不同价值 |
| Pattern | 先补表达性、再承受高压节点；或围绕一种兑现时机构筑 | 玩家是否能用一句话描述自己的构筑计划 |
| Strategy | 在当前生存、未来句子质量和路线收益间取舍 | 是否存在至少两条可行远征计划 |
| Meta | 不同敌人和节点迫使玩家改变施法节奏 | 环境是否能反制单一万能流派 |

## 不推荐作为首轮主模式的组合

- **法术得分闯关**：会把注意力从“解决敌意”拉到刷倍率，词义和时间可能退化成计分触发器。
- **法术背包管理**：能产生整理取舍，但当前体系尚未确认空间对象；先引入网格摆放会把验证预算花在第二个核心交互上。
- **伪实时施法竞速**：会与已确认的离散时间、无现实反应要求和可见规划方向冲突。
- **大规模事件/局外成长**：尚未有核心构思或玩家范围依据，首轮无法判断它是否在放大施法而非稀释施法。

## 可转化假设

若一局肉鸽持续要求玩家在“下一场可表达什么”和“本场能否安全兑现”之间做选择，并且路线、奖励和商店会改变这两个问题，那么词卡构句可能成为肉鸽的长期构筑轴，而不是战斗内的固定配方查表。

该假设对应核心循环、路线奖励和构筑章节，当前只能进入 `idea-inbox/`，状态为 `Raw Idea / Unqualified`。

## 最小验证

用 3 场连续战斗、2 条分叉路线、6 个占位词、3 类奖励和 2 种敌方节拍做桌面推演。每个节点只提供一个明确的构筑变化；记录玩家是否会因为下一场的施法计划改变路线，而不是只选即时数值最高的奖励。

成功信号：玩家能说明“我为什么拿这张词/走这条路，它会改变下一场哪句法术”；至少两条路线在不同生命、金币或手牌状态下各有理由。

失败信号：奖励只按面板高低选择；战斗和路线互不影响；所有构筑最后都依赖同一时间姿态；路线信息不足以支撑选择；节点数量增加但玩家无法解释因果。

## 未知、冲突与限制

- 完整词表、流派、敌人和路线分布均 `Unknown`。
- “法术远征”是否需要事件节点、诅咒或局外解锁尚未决定；首轮不假定这些系统。
- 现有“战场编译器”候选与本候选可以组合，但不能把三种时间姿态视为已确认规则。
- 本报告没有真人、模拟或外部产品完整体验证据；结论为 `Provisional / Needs Human Review`。
