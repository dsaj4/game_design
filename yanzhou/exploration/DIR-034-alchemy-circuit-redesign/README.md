## Spark：三个结构不同的候选

### 共同约束（TL-1 硬边界）

无论选哪个候选，以下约束都不能违反：

构筑卡（原词卡）持续占用程序位，不是每批耗材；资源卡是真实耗材；行动卡是生产完成后进入有限战斗行的一次行动。全批材料一次托管，不能部分扣料开工，一份材料不能同时支付两个配方。加工、交付、休歇分开计时；缺料、行满、返工按实际顺延，不补发。无合法目标时空放离队，不退制造材料。取消敌牌必须严格早于触发时刻 T。普通掉血不自动打断全部炼金工具。

### 候选 A：炼金回路（节点连接型）

**承诺**：玩家把资源源、处理节点、催化节点和行动出口连成一条可运行回路；同样的材料经不同路径产出不同类型和时机的行动卡。法阵是路径的结构，炼金工具是路径上的处理单元。

**构筑结构**：回路是一张有向图。每个节点有一个输入接口和一个输出接口；输出的类型和标签决定下游节点能否接收。玩家在战前把节点连起来；改线只影响尚未托管的批次，已托管不可更改。

典型回路样本（Raw 候选，数值未定）：

```
灵屑 → [熔炼节点] → 火种 → [压缩节点] → 浓缩火种 → [伤害出口] → 行动卡：高温矢
灵屑 → [熔炼节点] → 火种 → [分流节点] → 火种A → [伤害出口] → 行动卡：普通矢
                                      → 火种B → [催化节点＋霜晶] → [打断出口] → 行动卡：封止
```

**玩家选择**：短回路快速产出 vs 长回路追求协同突破；稀缺催化节点给攻击还是打断；一条稳定单用途回路 vs 一条可分流的多用途回路；是否让两条回路争夺同一材料源。

**反馈**：每个节点显示"等待输入 / 加工中 / 输出堵塞 / 已交付"；协同触发时相关节点同时高亮；失败时指出断点（缺料、接口不匹配、行满、时间来不及）。玩家应能回答"这张行动卡由哪些节点共同生成"和"下次该拆哪一段"。

**代价**：节点槽位有限；同一节点实体不能同时在两条回路；长回路消耗更多时间；分流降低单路径稳定产量；高阶催化剂消耗后回路可能暂时退化；拆解已运行回路会损失部分已托管材料。

**主要未知**：连接规则过多后玩家是否会专注排查接口而非做策略判断；最优回路发现后是否长期不变；协同触发如果隐藏是否会让突破显得像随机奖励；接口限制过严是否退化为固定配方。

---

### 候选 B：炼金批次（配比风险型）

**承诺**：每次玩家把资源投入同一炼金容器，决定投料顺序、配比和是否冒险追加；一炉资源的选择决定产出一张什么强度的行动卡。法阵是容器，炼金工具是处理阶段。

**构筑结构**：每个批次有有限投料位、若干处理阶段、一个主产方向和若干副产物；顺序会改变结果，规则公开不隐藏。玩家可在封炉前撤出尚未消耗的资源，但会损失批次稳定度或支付拆炉费用。

典型批次样本（Raw 候选，数值未定）：

```
稳定批次：火种＋压缩    → 确定产出：普通火矢
高风险批次：火种＋霜晶＋不稳定催化 → 可能产出：延迟高伤 / 不稳定残渣 / 低效回收版
多段批次：霜晶→护甲，护甲余辉→催化→打断（先防御再兑现打断）
```

**玩家选择**：现在稳定出行动 vs 赌一炉高阶产出；稀缺资源投入当前批次 vs 留给下一次关键威胁；何时封炉止损 vs 继续追加；选单张强行动 vs 一组彼此触发的小行动。

**反馈**：炉内显示当前配方标签；每加入一种资源预览可产出的结果类别；风险值、稳定度和预计完成时刻公开；封炉后明确标注"本批次不可再修改"。使用"部分揭示"而非纯随机：结果范围公开，具体强度在最后一步确定，未知来自风险承诺而非隐藏规则。

**代价**：投入资源在封炉后托管；长批次延迟行动卡交付；催化剂通常一次性消耗；拆炉损失部分材料；失败批次留下残渣占用库存；冒险追加可能错过敌方截止时刻。

**主要未知**：配方结果过于固定时玩家是否只是查表；风险区间过宽时失败是否被理解为运气；每一炉都需要重新操作是否违背轻操作体验；高阶收益明显高时是否被迫全都冒险。

### 候选 C：炼金工坊（模块自动机型）

**承诺**：玩家搭建一座会自行运行的炼金工坊，用有限槽位安装生产模块、转化模块和输出模块；工坊本身不断生产行动卡，玩家通过拆换模块改变整套机器的行为。法阵是工坊蓝图，炼金工具是模块槽位。

**构筑结构**：工坊由固定区域构成：资源入口→处理槽→催化槽→分配槽→行动出口。每个模块有输入类型、输出类型、周期、槽位占用、维护费用和一个公开标签。玩家可以在战间拆换模块以改变整条生产链，而不只是改变一张行动卡。

典型模块样本（Raw 候选，数值未定）：

```
压缩器：两份低阶 → 一份高阶（牺牲速度换强度）
回收器：行动卡结算后的残余 → 下一批材料（减少浪费）
共鸣器：只有满足两个不同标签同时到达时才启动（高奖励高要求）
过载器：牺牲维护稳定性换取额外行动卡（短期爆发，长期压力）
旁路器：主材料不足时走备用出口（防止断供）
```

**玩家选择**：用槽位放稳定生产模块 vs 放条件苛刻但突破上限的模块；把资源投入单条高产线 vs 分成两条等待共鸣；是否安装回收模块牺牲即时产量换长期循环；哪个模块要拆掉才能为新协同模块腾出位置。

**反馈**：工坊蓝图常驻显示每个模块的输入输出和连接；资源流以颜色和标签沿节点移动；共鸣模块在满足前显示"缺少哪条输入线"；预览显示拆掉某模块会影响哪些下游节点；战后显示本场机器的实际产量、浪费和未触发协同。

**代价**：槽位和连接数量有限；复杂工坊维护成本持续增加；模块拆换可能损失当前生产进度；高阶模块可能需要跨战保留资源；生产链过长使行动卡来得太晚。

**主要未知**：玩家是否只在战前搭一次，战中不再思考；模块依赖多时反馈是否变成工程图排错；自动化越强行动卡输出是否像被动数值增长；"协同突破"是否只由稀有模块触发而变成收集门槛。

## 对比

| 维度 | A 炼金回路 | B 炼金批次 | C 炼金工坊 |
| --- | --- | --- | --- |
| 核心构筑对象 | 节点与连接关系 | 一炉资源的顺序、配比和风险 | 长期运行的模块机器 |
| 装配感 | 连接节点、搭建路径 | 投入材料、安排处理阶段 | 安装模块、维护和扩展机器 |
| 自由构筑 | 高（组合来自路径变化） | 中高（组合来自投料和顺序） | 高（组合来自模块网络） |
| 变化来源 | 中间产物、分流、接口和时机 | 配比、顺序、风险和副产物 | 周期、维护、槽位、模块依赖 |
| 协同突破表现 | 多节点汇合，可迁移的结构发现 | 赌对配方后的高阶产出 | 共鸣条件满足时的双产出 |
| TL-1 兼容性 | 高——回路仍是法杖生产网络 | 高——批次承诺模型直接对应 | 中——自动化方向需谨慎控制 |
| 玩家最大代价 | 稀缺节点的机会成本 | 封炉后材料不可撤回 | 复杂工坊的维护成本 |
| 主要验证问题 | 接口规则是否过多让玩家排查而非策略 | 高风险是否变成被动承受运气 | 战中是否还有主动决策空间 |

## 推荐：候选 A 炼金回路

推荐 A 作为本轮重设计主方向，原因如下。

TL-1 的核心体验定义是"自行运作的法术生产网络"，玩家安排时间与资源，在关键威胁时干涉。A 把这条因果链留在常驻视野：每个节点的状态可直接读取，玩家能解释"为什么这张牌来晚了"或"为什么这根炼金工具停了"。

A 的协同突破表现为可迁移的结构原则而非隐藏配方。玩家发现的是"让两个标签在同一时刻汇合会产生双段行动"，而不是偶然触发一个整句奖励。这更符合"多种变化、自由发现"的体验目标。

A 与现有炼金工具的视觉语义（炼金工具作为处理单元、法阵作为连接结构）最自然对应，不需要引入容器或机器等新的隐喻层。

B 的批次模型与 TL-1 的托管承诺高度一致，适合作为 A 的补充（单次投料仍是一个批次），而不必作为独立方向。C 的工坊模型风险较高——完全自动化可能让玩家失去战中决策感，且维护成本的信息架构复杂度最高。

## 关键未知与下一步建议

**规则层面**（需要在进入正式卡池前确认）：

- 节点的连接依据是类型、标签还是固定接口；
- 中间产物是否允许跨回路传递；
- 拆解时返还完整资源、部分资源还是残渣；
- 一个节点能否被多个批次共享；
- 协同是否只在同一批次内生效。

**体验层面**（需要真人观察）：

- 玩家能否在不打开详情的情况下理解一条回路；
- 玩家是否会主动尝试不同结构，而不是寻找唯一最优配方；
- 协同反馈是否足够强，让玩家感觉是自己搭出来的突破。

**建议验证**：提供 4 种基础资源、6 个处理节点、3 个行动出口和有限战斗行，给同一批资源设置"快速应对"和"延迟爆发"两种威胁情境，观察玩家是否会搭出两种不同的回路而不是共用一条万能路径。
