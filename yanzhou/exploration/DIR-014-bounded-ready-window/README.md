## 具体构思

以下摘录沿用原来源的时间与候选状态；其中旧规则、推荐顺序和计划均不自动成为当前规则或执行授权。

### 保留前提与真正增量

RC1已有首次起点0–10、词卡冷却、正释放段、共享开始槽、后杖优先、命中生命取消当前冷却、完成冷却／节律／跳冷却／复诵。以下不是“把固定周期换成可变周期”这么宽泛的创新声明；已有物品本来就会改期。

本轮探索的是三种**由战前构筑明确选定的时间关系**：相邻周期预算重新分配、当前机会有限保留、上游实际动作控制下游启动。没有战中改配置、免费词义、第二开始槽、额外出战杖、复活或新疲劳豁免。

### R2：给一次法术有限的等待窗口

Candidate ID：`C-bounded-ready-window-v01`。设计对象：释放资格／冷却周转，GDD §3、§5。来源推断：E-TIME-03、04。

#### 玩家实际做什么

某杖可装一件候发配件：冷却结束时若没有合法对象，允许等至多2刻；有对象时才尝试开始，不预先抢走当刻共享槽。窗口仍无对象就失去机会。只用已分配词卡支持的条件，不免费增加生命阈值、智能选敌或新语义。

例：操控火焰的法术第6刻到点，但火焰第7刻才产生。普通模式第6刻空放后续排；候发模式允许第8刻读到元素再释放。第7刻由别杖创建火焰，同刻即使能读取它也不能获得第二开始槽；真正有空槽且条件满足的时点才可能执行。

#### 等待如何付代价

占用一个可换镶嵌槽，每杖最多保留一份机会。等待期间这根杖不开启下一次冷却，也不积累复诵或蓄势；成功释放后从实际释放段结束续排，超时则从窗口终点对应名义段结束续排。因此等2刻就让后续周转至少推迟2刻，不能既补回旧法术又照拿所有原定后续次数。

候发期间仍受玩家生命伤害取消，不能成为免打断的准备区；已取消机会不能进入候发。因同刻优先级输掉槽的机会仍按原覆盖取消，不提供免费排队救回。原型仅尝试“无合法对象时等待”，不同时扩展到支付不足、被打断、被覆盖的全面容错。

#### 策略与风险

低频、依赖元素或印记的法术可牺牲周转换一次有用释放；基础直接伤害可能更需要稳定循环和其他镶嵌。等待还可能让这一杖错过后续关键防御刻，所以选择需要看整段时间。

当前CG01条件只决定本次选谁，失败照常空放；R2新增的是**保留机会并承担等待**，不是新增条件语法。若组件几乎总是必装，应判断是否只是修复挫折的体验功能，不能直接宣称深度提升。

#### 最小验证

供给准时／晚1刻／晚3刻三种抽象输入，比较普通和候发的有效释放数、下一次机会和被打断结果。超时与取消必须可解释；正信号是稳定循环和保留机会各有用途。负信号是候发只有收益没有代价，或者所有效果最后都挤成固定优先队列。完整战斗与真人验证NotRun。
