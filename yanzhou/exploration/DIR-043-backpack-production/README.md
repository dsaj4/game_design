## 当前方向：战前配置法器，战中预放下一批材料

2026-10-31连续确认摘要：用户先选A作为战前配置手段，随后确认相邻／可见接口供料，补充供料位尺寸限制可处理材料大小，保留手牌存放未排队、未处理的材料与成品，并允许提前把下一次生产材料放入供料区；法器无在制材料时在下一拍吸收开工。本节取代前轮“战中仅展示、不调整供料”的边界，不改变现行GDD状态。

- **战前构筑：**法器与供料位占用空间；通过相邻供料位及可见接口形成生产关系。接口具体方向、是否允许共享供料区尚未定。
- **尺寸约束：**供料位不只是配置成本，其格子大小同时限制可处理材料的大小。Q9已确认按实际形状能否放入判定，允许旋转；1×4供料位不能接纳2×2材料。具体材料形状尚未设计，不擅自为所有卡赋予尺寸。
- **手牌：**保留未进入排队／处理的材料与成品。保留手牌这一决定替代模型此前“战前预设保留数量”的建议；不能自动视为用户接受保留数量规则。
- **待料与加工：**Q10已确认一台法器至多一批在制＋一批待料；配方可含多件材料，齐备才吸收。吸收时材料移入加工区并腾出供料位，可继续预放后续一批。排队与已吸收加工分别呈现，不以“预放”宣称已经消费或已经开工。
- **取料时点：**用户指定下一拍吸收开工。“法器无材料”按没有在制批次理解；完整配方齐备才吸收已获确认，其他开工条件仍沿CORE作为暂用边界。忙碌法器不因预放下一批而并行加工。放置本身不即时开工，最早下一生产拍取料；下一拍内部的精确取料顺序仍待细化。
- **战中调整：**Q11已确认仅在生产观察窗口调整尚未吸收的材料，可撤回、替换或改送；法器位置和供料位结构战前确定，战中不移动或改形，已开工批次不可撤回。结算列间不开放供料调整或生产，原战斗行布牌保留。
- **候选状态：**A继续深化为固定设备与供料位、材料可排队的方案；没有加入重力、实时落料或全库存容量拼图。B/C仍为备选。下文首轮比较与推荐保留为推理依据，涉及材料不定尺寸、自动从手牌取料、战中只展示的旧建议均以本节为准。

### 当前操作关系与设计判断

已确认的区域关系为：**手牌（尚未排队）→供料区（下一批候选）→法器加工→成品回到手牌**。上行箭头代表实际对象归属变化，不是复制库存；加工后的消费时点、打断退料继续按CORE边界审视，不由表现动画改变。

模型建议将手牌作为不直接自动供料的保留区：只有放入供料区的材料进入生产候选。这样“保留用于战斗还是送去生产”可以通过移动同一张牌直接表达。用户已明确三个区域的职责，但是否彻底取消任何自动从手牌补料的方式，尚需在正式化时闭合，不宣称所有路由细则已确认。

这轮修改让空间同时承担两个取舍：战前在法器数量与较大供料位之间分配面积；战中决定把哪张手牌提前交给下一批生产。大供料位扩大可处理材料范围，但若没有额外代价或配方差异，可能只产生“一律留最大”的答案；尺寸需要对应真实选择，不能仅增加摆放门槛。待料区与加工区分开也可能减少空转，但若每批都只能重复拖入同一种材料，操作仍可能机械化。这些均为推断，未获玩法证据。

例：法器正在加工甲，玩家把乙从手牌放入供料区等待下一批。乙尚未加工，不能与甲混为一批，也不能同时留在手中使用；甲完工后乙何时吸收，应由明确的拍序裁决。若空闲时已放妥完整材料，按用户要求下一拍开工，放置动作本身不即时触发生产。不完整或尺寸不合的配方不会因动画先行而被当作成功开工。

显示建议区分**手中保留、供料区待吸收、法器内加工、完工产物**；加工中保留进度，供料区显示下一批缺什么。开工吸收先表达托管，完工再表达实际消费，以保持与当前CORE的一致性；最终是否调整消费时点另行决定。吸收后释放供料位置供下一批使用已由Q10确认，具体动态表现尚未设计。

## 判断：先决定让空间承担哪种选择

总体判断为**逻辑可行、体验未证实**。最弱假设是“增加摆放操作会增加有效控制，而非重复劳动”。用户陈述了问题，但本轮没有玩家观察证明其发生频率及主要成因。

需要区分三种直接性：看得见谁在吃料；能亲手改变谁先拿料；能靠旋转、腾位和疏通决定生产。固定供料位优先服务前两种，流动背包把第三种变为新的主要玩法。三者不必同时加入。

用户所说的“占位材料”暂称**供料位**：一个持续存在的规则位置，如1×3空位；它自身不是一份材料，也不是无限库存。最新确认增加材料尺寸上限与下一批预放职责。几何匹配与配方匹配应分开：能放进去不等于能被该配方使用。1×3不直接等同三单位料；待料至多一批已确认，具体可容纳件数还取决于材料形状及配方。

“材料流动”也须分开：消费后手动补位、按生产拍自动沉降、实时下落，分别产生整理、预测、反应压力。用户尚未决定重力或时间限制，不能从“俄罗斯方块式”直接推定。

## 首轮三个候选（当前确认见前文）

以下选项暂统一按“仍有五生产拍和战斗列、完整配方开工”比较；实时制不是默认前提。举例中的治疗、攻击和升级配方只是解释选择，不是新增正式卡或数值。

共同情境：两台法器争用一份既可用于眼前防御、也可继续加工的稀缺材料；玩家还想保留下一批原料。比较重点是如何把有限资源给当前需要的生产，而非谁能塞最多东西。

| 候选 | 玩家反复作出的选择 | 玩家成本与失败后果 | 设计负担与成立条件 |
| --- | --- | --- | --- |
| **A 固定供料位＋占格法器**：法器与供料位组成持久布局，符合声明的真实库存按规则供料；材料消费不改变占位轮廓 | 把共享材料供给治疗还是攻击；留给战斗还是下一批；增加一台法器，还是留出供料位／未来辅助物位置 | 付出布局面积、生产机会和预留资源；供错料导致目标法器缺料、晚产或失去保留牌。静态空间本身不产生越顶失败 | 相对较低，但仍需明确供料归属与多机争料；空间若不影响连接、能力或取舍，就只是把菜单铺成格子 |
| **B 材料占格、法器在包外**：真实材料进入各法器供料区，消费腾位；先按静止可整理解释，沉降为独立可选规则 | 将大块材料给哪台法器；先消费哪块来腾出有用形状；保留高价值原料还是保障当下开工 | 付出搬动、旋转与持续判断；有总空格仍可能放不下，目标区被不合用材料占住，导致饥饿或延误。若补入丢失／溢出才有损料，当前未定 | 中高；每件材料要定义形状、数量与转化关系。优点是材料去向可见；风险是填空策略压过配方用途 |
| **C 占格法器＋材料按拍流动**：固定机器成为流路中的障碍和消费点 | 把机器放在哪里才能接到料；牺牲缓冲空间装更多机器；保留通道还是让上游先消费 | 付出机器面积、通路及操作注意力；机器越多可能越缺吞吐，错位或上游抢料导致下游断供；局部堵塞可能连锁扩大 | 最高；要解决材料跨区归属、沉降、遮挡、争料与加工冻结。只有“设计物料流路”本身是目标，增加这些规则才有理由 |

辅助遗物在A/C中仅保留为用户未设计的构筑可能，本轮不编造其词条来填补玩法缺口。

### 为什么暂推A

它最直接针对“我能控制谁消耗哪份资源”。推荐的候选反馈是：拖动或改供料归属时，显示下一次哪些真实卡会被哪台法器托管、哪些保留、何时预计完工，以及失败是缺料还是不兼容。已有批次冻结，移动只影响下一次开工；不能借移动免费撤批。

建议优先让法器和供料位承担有限空间，而暂不要求每张材料都有形状。这样仍保留“装更多法器与供料布局”的空间取舍；但若法器摆哪里效果都相同、供料位能无差别无限供给，格子就没有充分设计理由。此时简化为直接拖料到法器也可能更合目标，不能为了保留背包外形强加规则。

若用户核心愿望是“每轮亲手摆弄材料并借消耗腾位”，B应升为首选，A不足以满足。C保留为独立、更重的物流方向，不因兼具两个思路就视为折中低成本方案。

## 两个设计轴的具体后果

**法器是否占格：**占格使机器数量与缓冲／供料能力竞争，可把体积作为性能成本；不占格使注意力集中到材料分配，但须明确机器数量由什么既有或候选约束限制，不能把包外理解为无限机器。只有法器位置改变接口、范围或通路，摆放位置才比纯数量上限多出选择。

**材料是否真实占格及流动：**静态供料位代表一种持续承诺，适合学习和调配；真实材料占格使每次消费改变空间，适合持续整理，但需要形状内容、归属和回流规则。重力不必与真实尺寸捆绑；可先允许实体材料自由放置、消费留空，再判断自动沉降是否带来值得预测的后果。

B/C存在三个容易被误当深度的问题：

1. 若所有材料都能无限堆在同一位置，体积约束会被绕过；若完全不能堆叠，拖动次数可能激增。数量与面积关系Unknown。
2. 若任意时刻免费重排且没有承诺边界，路径与位置可以被随时绕过；若不让纠错，又可能把一次误放变成无法恢复的停机。需要明确操作窗口与可撤销范围。
3. “清掉材料以腾空间”可能鼓励生产当前无用的东西；若产物立即去无限手牌，则生产同时是释放场地的手段。这可以成为有意取舍，但必须识别它，而不能默认属于漏洞或默认有趣。

## 与核心GDD的概念层关系

只依共同版本的GDD正文判断；未核验系统分册，不声称规则完全兼容。

| 核心依据 | 背包方案引出的裁决 |
| --- | --- |
| §1、§3、TL-08：材料是统一卡牌的一种配方用途；同一实例只能在手、行、托管等一个位置 | 2×2物品与战斗卡面可表达同一对象，但不能形成两份库存。一份“治疗药水”是留作战斗还是投入配方仍是同一选择；其正式效果、回收权限及形状均未定义 |
| §4：法器从两组手牌取合格材料；未投入背包不可取用 | 新生产背包若只是供料配置视图，和把库存搬入其中是不同改动。后者改变供料来源；应与现行跨战背包区分，不能让未投入库存暗中参战 |
| §4、TL-04：完整配方开工托管、完工消费；没有成品缺位等开工 | 实体块在开工离开网格，还是保持“加工中”占位直至完工，会改变腾位时间。若一块代表多份材料，部分消费是否缩形／拆块也未定。不能仅凭动画解决 |
| §4、TL-08、TL-12：产物直接入手，手牌无硬上限，可回收牌立即回手；打断退料最早下一生产拍可用 | 若所有手牌都进有限网格，则必须处理产物无位、回收无位、退料无位。要求回手前先拼图或满格烧牌会改现行核心规则。A把网格用于配置可少触及这些冲突；B/C仍要定退料去处 |
| §2、§5、§7：生产与逐列战斗分开；列间只开放布牌，生产不推进 | 按生产拍整理／流动可沿现有节奏提出局部变化；战斗列间搬料、持续实时下落均是新增权限或时间规则，不能默认为表现升级 |
