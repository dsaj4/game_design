# 辅助道具替换辅槽：主系统评估

2026-10-31 · 评估对象：[Qualified M](M-2026-10-31-spatial-auxiliaries.md)；共同输入与阅读范围沿M。评估人：设计agent。**推荐推进；体验Hypothesis / NotRun。**

## 判断与取舍

| 维度 | 判断 |
| --- | --- |
| 动作与反馈 | 战前放置／旋转辅助，查看受益法器与合计参数；核心装配在同一背包交互完成，职责可区分 |
| 决策与代价 | 同效叠加允许集中强化，也允许分配多台；机会成本来自占形、连接和取得，不用固定辅槽数替代空间预算 |
| 范围 | 单目标、静态单参数；无辅助相互强化、全包光环、独立触发链或新运行费用 |
| 可行性 | 规则接口可以明确落入现有批次及真实实体模型；具体空间输入仍缺，不据此承诺实现成本或可玩性 |
| 参考与差异 | README记录的背包乱斗空间关系提供表达参照；言咒的生产批次、供料区和成品手牌仍须独立验证 |
| 风险 | 叠加集中成为唯一答案；加速触及D下限或只增加无用囤牌；核心唯一配对使装配成为重复作业 |

## 接口复审

| 接口 | 处理 |
| --- | --- |
| 辅槽／核心 | 删除固定辅助槽、打造及副铭文词性挂接；保留核心必填与兼容，一枚实体不重复占用 |
| 空间／供料 | 辅助实体与法器、专属区不得重叠；效果指示不占格，只命中法器本体；不自动吸收辅助 |
| 叠加／公式 | 多件贡献各计一次；D固定量相加、倍率相乘、最终取整且至少1；普通量值沿TL-37，未声明多倍率内容不能猜算 |
| 批次／成品 | 开工冻结辅助静态贡献；本批产物继承；旧牌不追溯，回收与存档不重加，作为原料不传递到新产物 |
| 费用／扩展 | 首批静态被动；保留旧标记付费接口的限定资格，不能以换容器启用未发行扩展 |
| 内容／旧证据 | 迅速保持单一实体与减时；EX-004数值路线条件性保留，旧辅槽实现证据不能覆盖新空间规则 |
| 跨战／存档 | 辅助属配置库存；成品临时增强战后重置，配置实体仍保留；旧存档无隐式转译 |
