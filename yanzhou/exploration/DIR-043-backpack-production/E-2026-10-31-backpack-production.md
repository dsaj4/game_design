# 背包式法器管理：主系统复审

2026-10-31 · Evaluation · 评估人：agent。对象：[Qualified素材](M-2026-10-31-backpack-production.md)，共同输入版本与用户确认沿该素材；不另建Proposal。判断为**推荐推进已确认机制合并**，Hypothesis / NotRun。

## 快速结论

手牌、待料、加工三个位置能明确生产承诺边界，形状与设备面积构成战前取舍；默认自动补料缓解逐批重复放料。主系统必须同步淘汰战中切用途和临时供料方案，不能叠加两套相互矛盾的调度。

## 评估维度与系统接口

| 维度／接口 | 判断与处理 |
| --- | --- |
| 核心动作／反馈 | 已明确战前配置、生产窗改待料、下一拍吸收；显示排队与加工，不能用动画代替真实归属 |
| 法器×资源 | 开工只取本器专属待料批；自动补料保留材料锁定及阶级规则，补入后不当拍吸收 |
| 生产×总序 | 保留先完工后开工、每器每拍一次；自动补料在所有开工检查后完成下一批准备，不能同拍自动连锁生产 |
| 手牌×战斗 | 待料不在手，不能直接出牌；未吸收可在生产窗撤回；列间不开放供料以绕过牌的归属 |
| 中断×待料 | 在制普通输入退回手牌并保留下一生产拍待用；已排队下一批保留，不被退料覆盖。原进度损失不变 |
| 经济×空间 | 生产布局、手牌容量与跨战携带分别管理；待料仍是真实持有物，战终统一核资格，不重复选留 |
| 首场×用途 | EX-004零材料机制可沿用；原战中改兑现路径失效，改为战前选兑现并静态核对，不伪装新版背包实现已验收 |
| 制作与范围 | 形状、接口和真实配方需后续内容；本轮不估工期，不补造发行素材或格数 |
| 可玩性／深度 | 空间与保留牌有机会成本，但尚无玩家证据；默认自动补料也可能让待料干预失去价值 |
| 同类参照／差异 | 首轮官方研究见方向页，支持空间参与构筑、消费腾位等结构；不证明言咒市场或体验成立，核心仍是铭文及工序 |

## 主要风险与建议

自动从手牌搬走战斗牌可能令人意外，须保留材料锁定、自动状态和待料预览；不自动替换已放材料。大格／小格的价值须由真实材料与同预算替代说明。多件配方存在多个同阶完整组合时，必须有明确顺序，不能凭算法猜填内容。

最低成本的后续验证是同一资源冲突下检查预测、保留及改送，不测喜好替代行为；空间不影响决定、必须频繁纠错或只剩机械搬料时应回审。没有验证执行授权，本轮不运行。
