#### 4. 空档蓄能：让主动留白产生收益

- Candidate ID：`C-idle-reserve-v01`。
- 推荐顺序：后置备用，不建议第一轮与有限调速同时叠加。
- 候选规则：编排中主动留出的空刻积累有上限的通用储备，释放消耗储备。如此可形成连续释放与积累后集中释放的取舍；储备名称、增长和消耗值均未定。
- 玩家改变的决定：是否让出某些安全释放时刻，保住后续关键窗口所需的储备。
- 预期价值：空格成为主动安排的一部分，玩家可以构造不同的节奏。
- 必须先解决的关系：何时算空刻、储备不足如何处理、覆盖/打断是否扣费、敌方命中产生的空刻能否回收收益、每刻恢复与消耗先后，均为 `Unknown`。不能默认打断反而免费充能；不能默认缺能导致法术排队或改变 TS4/TS5 的原周期。
- 成本与风险：会让全部法术相互争夺一份资源，新增理解负担和整套循环失效的可能；若储备约束成为唯一决策，时间背包的作用可能被削弱。
- 最小对照建议：只有在已有规则下主动留空缺乏理由、且用户选择节奏蓄放体验时，才比较无储备与一条最小储备规则；每次只改一个机制。
