## 目标与机制坐标

| 层 | 本轮表述 | 规则如何支撑 |
| --- | --- | --- |
| 玩家目标 | 在战斗中存活并击败敌人 | 行动生产兑现；防护、封止和伤害竞争材料与队列 |
| 体验目标 | 自由构筑、多种变化、可解释的协同突破 | 同义操作在多个材料/辅助/路由/行动顺序中复用 |
| 设计目标 | 从线性短句扩成可装配生产网络，同时保留TL-1承诺与瓶颈 | 端口由真实卡定义，节点各是一完整配方；法阵只搬运真实产物 |
| 主要坐标 | 资源数量/身份、关系与时间 × 转化、分配、门槛、延迟与一次消费 × 工具实体、资源容器、法阵网络和行动流程 | 变化必须传递成本与状态，不只改名称或给通用倍率 |

核心循环是：战前装配 →〔实体占位/合法接口〕→ 自动托管加工 →〔材料归属/进度/成品〕→ 资源回流或行动入行 →〔可用料/队列/目标状态〕→ 生效与威胁判断 →〔余料/延期/未来路由〕→ 后续批次。战斗结束退出；暂停全冻结。当前算例不含完整敌方程序、疲劳、终局或退出恢复的实现，不能据此宣称完整战斗已闭环。

## 三层对象与端口构句

- **构筑卡**承担主系统词卡职责：操作、材料选择、产物/目标选择、辅助规则。每实体持续占一个真实槽，循环不销毁；拆解返还同一实体。同名多位置需真实副本。
- **炼金工具**执行一个完整配方。标准六槽为操作、材料一、材料二、结果一、结果二、辅助；轻型四槽只保留操作、材料一、结果一、辅助。一个工具同时至多一批或一成品。
- **法阵**把一个资源出口接到相容的资源入口。每份产物只有一个去向；公共池或一工具。连接不创造新操作，不转换材料类型，不复制资源或构筑卡。
- **资源卡**是实际耗材、中间产物或保留型核。**行动卡**是制造后进入有限行的一次结果。资源卡不能替代构筑卡，行动卡不能兑换制造费或永久词卡。

合法配方为“操作卡 ＋ 该操作要求的材料接口 ＋ 产物或目标接口 ＋ 可选一张相容辅助”。单输入行动仍可读成“火种—伤害—首个活敌”；双输入资源改造可读成“辉核＋火种—增幅—原辉核”。新增关系没有免费获得自然语言权限。

物理空槽不授予语义：合成/增幅操作卡声明第二输入；分馏辅助卡声明第二输出。每个端口都需实际选择卡占位。材料与产出可用同名接口卡，但同一实体不能同时占两处。没有隐藏“完整句A额外＋X”的整句奖励。

## 不是八按钮的自由组合

[卡目录](card-catalog.md)声明30张卡：18构筑、4资源、6行动、2工具。[机器数据](atlas-data.json)按同一卡义提供18条可计算操作条款，作为构筑语义的枚举，不是另授予18张免费配方卡。配置必须同时满足实体、槽位和操作/辅助条款，名称吻合不绕过占位。

自由变化至少来自四个有代价的轴：

| 变化轴 | 同义卡的合法变化 | 改变的决策 |
| --- | --- | --- |
| 材料 | 同一“伤害”支持火种6、霜晶4、辉核24＋8g | 即时消耗、防护/封止料争用、高阶准备；不存在“霜标签自动冰冻” |
| 结构辅助 | 炼成单流或加分馏双流；伤害可浓缩、裂纹引爆或核择机 | 多产物要付3灵屑/3加工并占第二出口；浓缩多付灵屑/时间；择机占掉其他辅助机会 |
| 路由 | 分馏霜晶未来送护甲、霜裂或封止；火种未来送直击、合成或增幅 | 只有一份真料，改变去向会让其他工具等待 |
| 行动顺序 | 霜裂先兑现再由装B17的伤害消费；晚了/不同宿主/到期只打基础量 | 准备也占普通行动行，不免费附送标记或第二次伤害 |

同一工具辅助槽最多一张，不能同时浓缩和裂纹引爆。没有辅助的B04辉核伤害可以在g0开工；B18把最低g1写入该工具程序，是一个真实合法变体而不是消费核的总门票。阈值固定1，战中改阈值属于改程序，不冒充免费路由。

六槽工具支持双输入/双出口，轻型仅少槽且没有速度/费用优势。本轮只说明可表达差异，不宣称两工具已形成平衡取舍；正式取得方式、价格、出战额度Unknown。展示共同库存也不是正式游戏赠送的起始库存。

## 保留的时间、材料与承诺

1. 足量完整配方才一次托管；不足不部分扣料。读取状态不自动消费，消费/保留须由操作声明。
2. 开工即承诺本批材料身份/来源、输出去向、效果预设与明确参数。成功加工结清消费；被明示中断只返该批原实例、丢进度，下拍可用。
3. 候选时间口径为t开工，t＋D完工，t＋D＋J交付，资源下拍可用、行动最早下拍生效；D/J/R分别声明。缺料、行满、返工按实际交付顺延，不补发。
4. 候选Q3，同拍至多一己方行动。满行留成品在原工具，成功交付才继续；不预占行动格、不倒退交付计时是DIR-032候选复用。
5. 维护先于新加工分料；余料和入行位置按战前工具序。候选内部排序为到期维护先、休眠恢复后，各组按创建序。不是替主系统关闭Unknown。
6. 辉核g0..3，4拍维护1灵屑；托管期间暂停维护/增幅，返回下拍可用，从可用拍重新计维护；恢复付一次整费无欠费。以上具体值与细则仍候选。
7. 己方目标生效时按承诺规则选择，名单本事件不补位；无目标空放、不退制造料。实例消失不转绑同名对象。
8. 取消敌牌必须实际严格早于T。普通生命伤害不自动中断工具；本拍明示中断先于幸存完工。已入行牌不因来源工具后来中断消失。
9. 免费改线只影响未承诺未来批次，已定向资源不因改线重新归属。恢复、终局、跨战携带沿主系统合同，展示册不会实现后反向证明已采纳。

## 网络连接与协同的有限边界

| 来源 → 载体 → 接收 | 关系与可见后果 | 触发、费用、时间、次数/上限与终止 |
| --- | --- | --- |
| 灵屑 → 火种/霜晶 → 下游工具 | 转化/分化：即时料与高阶料竞争 | 炼成每批2灵屑/D2/J1/1份；分馏3灵屑/D3/J1/火霜各1；下拍可用。缺料/中断/终局停止，无逆向免费炼料 |
| 火种＋霜晶 → 新核 → 增幅/伤害 | 转化：材料身份换成高阶候选 | 合成每批各1/D3/J1/新核1g0；无一料多用，工具单批、缺料等待 |
| 同核＋火种 → g＋1的原核 → 辉击 | 蓄积：较晚高阶收益，维护争料 | 每次消费火种1/D2/J1，原核hold/返还；g上限3，满级停增幅，休眠不可消费/增幅；辉击consume核1/D2/J1/普通行 |
| 霜裂行动 → 宿主裂纹 → 装B17的伤害 | 共振：同一伤害事件固定＋8 | 来源为独立行动，消费霜晶1/D1/J1/1次兑现；宿主1标记，E..E＋6；每伤害至多消费1次/＋8。消费/到期/死亡清理，不产额外行动，重复只刷新 |
| 伤害辅助浓缩 → 明示灵屑/额外加工 → 同一行动 | 转嫁：把更高量移到制造成本 | 额外灵屑1、D＋1、固定＋4；1辅助，不能递归，不能和B17共装，缺额外料整批等待 |
| 多工具 → 已产行动 → 有限行 | 阻滞：高产不等于及时 | Q3/每拍1；满行留工具，无无限隐形缓存；终局停止，空放离队不退款 |

没有正反馈复制：增幅循环每次少1火种、增加时间且上限3；标记引爆消费一次准备，不返回标记；分馏不存在资源逆向免费循环。法阵图可以自回路，但不保证每个合法构筑都有效。

**保留失败路径：**把增幅核出口一直定向回本工具，g3核会回到该工具且增幅停工。未来改线不能把已经定向交付的g3核挪走。若要g3送辉击，必须在处理g2→g3这批尚未承诺前改该批未来输出去向；已经错过时不能凭本册获得免费搬运新能力。满级停工是合法构筑的可解释失败，不删掉这类组合来伪造“任何搭建都能成功”。
