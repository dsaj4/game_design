## 2026-10-28 底部持牌与语言细节更新

用户要求先将现有方向适配新设计，手牌采用《杀戮尖塔》式的屏幕底部持牌方式，并适量补充咒文、铭文与语言细节。底部手牌的位置和呈现方向已明确；本图的扇形角度、选中抬升、切组题签及器物比例属于本轮可逆制作建议，待审阅。没有引入该参照游戏的能量、抽弃牌或费用规则，也未使用其图像资产。

图中选择[EX-004 §5](../../design/examples/round-first-battle.md#5-从真实初态到手牌与打断)第一轮生产结束、尚未布牌的状态：五张护盾与一张普攻在可战斗组，不可战斗组为0，己方五位空。敌行四张即时攻击暗牌与一张延时攻击暗牌，仅露类别与时间；生命、护甲、施法次数沿该时点。选中普攻的抬升只表示待布置，未上行或生效。

- **手牌位置。** 六张实牌沿最下缘浅弧展开，名称和主体图露出；左下两组题签显示准确数量。撤去旧资源堆、手牌堆、容量和整理点，确认结算位于扇形右侧。
- **对象与信息。** 保留敌我各五位、双法器及两处空预留；法器本批进度与下批设置分行。为让五个布牌目标完整露出，最终稿收低晶体笼的上部；器物高低差较v03减弱，属于本轮构图取舍，未改变法器身份或规则。
- **语言细节。** 铜环加细线铭刻与连写字形，法器核心用庇护／打击、辅槽用迅速；书页增加法阵、边注和朱砂小印，卡框保留轻纸纤维与墨线。大面积牌图继续用符号板的实色底和大轮廓。其余拟文字仅是装饰，不新增铭文库存、配方、语言规则或世界观结论。

内置image_gen先以v03和符号板编辑，再纠正多画一张护盾、错误进度圆点及晶体笼遮挡。仅最终选稿复制为scene-v06.png；三步准确提示词与生成原件沿manifest保留。PNG本机保管，不随文档上传。

已目视核对六张牌的构成、两组数量、五列空位、暗牌公开范围、初态计数、双法器／两预留、数字进度及牌位遮挡；核对PNG规格和工具原件／副本哈希。生成字形、边注及小字仍需人工排字，最外侧牌脚随底缘裁切；超多卡浏览、焦点、点击／拖放／键盘、切组及列间确认没有由静态图获得验收。PRE2D-Q01仍Open，未制作新HTML或真实实现，未运行玩法实验。

## 本轮采用什么

- 纸本秘术的二维墨线、手工设色与少量排线；暖木桌面、米白纸牌、低饱和灰绿桌垫、旧铜器具。
- 前方敌我各五位牌行，近侧宽工作台作为主要物件；矮宽守护法器与高窄施法法器形成高低差，两处空预留保持清楚。
- 草木元素减至最低，以法阵、摊开的秘术书、细小炼金器具和几何铭纹建立施法环境；装饰不占牌面与读数区域。
- 卡牌继续设计时重点参考AS-G002-033的大轮廓、实色图案区与六类主体，不要求沿用v03卡图全部细节。符号板源自v05；本轮保留这一独立参考，不继续采用v05整场构图。
