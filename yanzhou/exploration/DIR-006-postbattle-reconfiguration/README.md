## 构思概览

奖励后替换实体词卡并局部重组下一场编排。

这是整理时的Research / Provisional适配判断；早期背景不自动升级为RC1。当前主系统采用范围见[吸收记录](../comparison.md#背景适配与主系统吸收)。

## 具体构思

以下摘录沿用原来源的时间与候选状态；其中旧规则、推荐顺序和计划均不自动成为当前规则或执行授权。

### 保留的底层与增量边界

| 本地已明确底层 | 本轮如何对待 |
| --- | --- |
| 战前编排、战中自动循环 | 四项候选均不要求战中手动插牌或重排 |
| 有限首次启动窗口，各法术独立循环 | 调速候选只讨论战前选定周期，不引入战中时刻漂移；具体首轮口径仍待确认 |
| 同刻单释放、后加入者覆盖、仅损失本次 | 新机制不能静默改变优先级、补发或排队 |
| 命中打断该刻普通释放，后续周期不变 | 敌方阶段和资源候选需与这条规则明确共存，不自动给予抗打断 |
| 实体词卡独占、编入总张数有限 | 战后新词和调速成本要与容量选择发生关系；不得默认另有免费容量 |
| 默认公开敌方整场攻击安排 | 敌方变化以战前可知的时间表为前提；不靠未告知的随机变招制造难度 |
| SC1 暂缓具体卡片效果 | 使用抽象法术与系统关系，不定义火焰、寒冰、强化等卡片效果和倍率 |

#### 3. 战后重组：让奖励改变下一场的计划

- Candidate ID：`C-postbattle-reconfiguration-v01`。
- 推荐顺序：第三，战斗内取舍能成立之后再接入。
- 候选规则：每场后有明确的重组机会，在词卡总容量约束下替换投入的词卡、拆装法术或重新安排下一场首次启动。重组权限、回收与费用规则尚未确认。
- 玩家改变的决定：新词可能让某个法术更有用，也可能占用组成另一法术的同一张实体词卡，或令原来的周期搭配不再适用；玩家选择是否保留旧组合、牺牲什么来换新组合。
- 预期价值：拿到奖励后产生“这次可以换一种编法”的期待，而不仅是沿用原排程提高数值。
- 与背景关系：活动包已有奖励、路线和商店概念，不能将它们自动移植为本候选现成规则。本候选新增的是时间背包中跨战重组的明确入口与取舍，不起草整套经济系统。
- 成本与风险：每场都强迫全盘重排会疲劳；不提供可保留旧编排的操作会放大重复劳动。奖励来源与词卡周期的关系不清时，不能保证新词一定改变节奏。
- 最小对照建议：连续两个抽象遭遇，中间只给一次可拒绝的词卡替换机会；观察是否出现局部重组的理由，以及不换卡是否也能成为合理选择。
