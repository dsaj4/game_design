## 构思概览

暂借一张火/冰名词换本场初始元素，该实体不能再入句，战后返还。

### B · 借词布阵：这个“火焰”用来写咒，还是先放到战场

**玩家体验。**我把一个词借给世界，就少了一张写咒的词；场上因此提前拥有一个可以利用、也可能被抵消的元素。

- 来源：[霓虹白客](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/06-neon-white.md)的一物两用，[文字游戏](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/15-word-game.md)的媒介与世界统一，[堆叠大陆](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/16-stacklands.md)的直观实体操作；[永恒牌](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/07-eternal-decks.md)提示不可逆消耗的软锁风险。
- 新增规则草案：战前最多封存一张实际持有的“火焰”或“冰霜”名词卡，换取一个已有种类的初始元素，放入公开的合法空格。本场它不再能进入任何法术；开战前可撤销，战后原卡返回库存。其他词暂不提供阵地效果。
- 场景：起始有两张火焰词卡，原本可以组成“释放 火焰”与“火焰 伤害 敌人”。借走一张后，可用剩下的一张编操控句，直接利用预置火焰；代价是同一场无法再用另一张火焰持续补生。预置元素自然衰减、被抵消或范围不合后，操控句可能失去对象。没有凭空复制副本。
- 真实代价：提前获得元素与节省生成过程，对应放弃本场一张名词的循环用途；占位也会改变后续合法出生位置。借用须显示剩余实体、失效句子及可选落点。
- 与基线的差异：新增 SYS-001/002 的战前实体用途与 SYS-004 的初态来源。首个实验建议沿用“场景预设中立元素、无所属法杖、不获本杖特性”的现有性质，不冒充某根法杖创建；玩家选择其落点是新权限。开战后仍按旧规则确定来源、身份、范围与固定名单。
- 需要明确的新参数：初始层数、允许落点及其与预置物冲突处理。第一实验用同一个固定层数比较火/冰，数值在实际原型前确定，不能把这里当完成的规则规格。
- 首要风险：初始元素无论如何都更强，借词只是必选启动礼包；或回收/同名副本的解释使玩家误认为卡已销毁。
- v0→v1：从“所有词都能永久献祭改写场景”，缩成“两个名词、最多一张、仅本场封存”；不增加拆字、材料加工或万能语义解释。

**最小验证（Planned / NotRun）。**使用真实12卡起点，比较不借、借火、借冰三种配置；对照普通可出生场景与受占位约束场景。全部使用同一套敌人、生命与初始层数，不免费补回借走的卡。先检验非法重复分配和保存恢复，再观察5位新玩家。继续信号：至少4人独立说清“提前得到什么、失去哪个合法句子”，且不同场景出现不同选择；失败信号：借词在所有输入上无损支配，或多数人持续把阵词当作额外免费副本。它最值得先验证，但当前没有优势证明。
