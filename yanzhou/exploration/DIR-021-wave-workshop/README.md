## 具体构思

以下摘录沿用原来源的时间与候选状态；其中旧规则、推荐顺序和计划均不自动成为当前规则或执行授权。

### 设计工作假设与术语

1. **战斗内**是已编排法术的自动运行；**局内战间**是同一远征中的路线、休整、商店和重构；**局外**是本局结束之后的复盘与下一局动机。
2. 保留 RC1 的实体卡、最多4杖、时间槽与空间范围作为比较基点。替代方向如修改自由重配、地图结构或终局，会明确标出。
3. 优先贴近15–25分钟有效整局目标。新增系统占用多少时间要测，不能把多步骤自动当作更深。
4. “策略更深”的候选判据：不同资源／敌情下有不同合理选择；同一选择存在可解释的机会成本；获得新词会影响句义或时序；成败能归因于自己的准备。
5. 核心比较单位是完整循环。下列A–D择一作为主方向；其子环节不是额外四套系统全部上车。

### C：守点波次工坊——成长由连续压力推动

Candidate ID：`C-wave-workshop-v01`。

#### 循环与独特取舍

编排→自动防守一波→清楚的波次结算→短暂停留选词／调整→下一波→有限终局。玩家的长期问题变成“当前组合能否覆盖下一类压力，以及应当何时从稳定防护转为爆发”。

适配《言咒》的版本应保留波间思考窗口。先比较有限的连续波次；用户举例中的“无限”属于可借鉴的成长节奏，不作为已确定终局规则。

#### 相对RC1的改变

- 用波次序列替代分叉路线和休整／商店空间选择，原地图取舍会减弱，需要另一种机会成本支持选词。
- 初始候选建议每波按新战斗处理：生命与本局库存延续，护甲、元素、计数和战场重建。继承场上元素的版本会牵涉状态所有权、临时身份和累积失控，应另立版本，不能混在此例。
- 每波沿当前战斗疲劳结算并有明确最后一波。若改成无限波次或中途撤离收益，必须重做胜负、难度曲线、奖励上限和存档；不沿用“普通最晚80刻”证明整局有限。
- 波间拿词替代多少原购买机会、是否仍用金币、恢复安排均是Unknown，不在本轮补成正式系统。
- 局外可以记录最远进度和自己完成的构筑战例；不同词表和规则版本不能混算成统一公平排名。

#### 适配与风险

好处是成长节点固定、每波都有清楚的下一目标，较容易形成压力升级。代价是当前玩家没有战中走位或反应操作：拉长战斗可能只是延长观看；同时读句与赶波次也会改变目标体验。首先应测“固定节奏补词是否比选路更有趣”，而不是先制作无限内容。

最小验证：用3个已有遭遇作有限波次，保留相同资源预算，对比路线版的选择理由与观看／编辑时间。若仅靠更频繁给资源取胜，不能归因为波次结构更好。未运行。
