# EL-01 效果语言与卡面展示候选

2026-10-02。归属 game-002-optimization / DIR-032。文档角色：DirectionNote / UI Study。新增表达方案为 **Raw / Unqualified**；Q17仅确认“战前展开词卡，战中收起并可展开”。本页不增加卡义、触发效果或法杖属性，不替代已确认的[P试点规格](P-2026-10-02-playable-loop-demo.md)。可读性与用词尚待用户评审、真人观察。

## 推荐方案

**效果用短句，常见规则用关键词，数量与时间用固定位置的UI。** 法杖回答“造什么、花什么、多久交付、现在卡在哪里”；产出的行动牌回答“对谁、做什么”；运行状态回答“还要等多久、为什么没有发生”。

战前保留真实词卡构句与占用，战中将构句收为法术名，点击展开。每个表面只承担其当前决策所需信息：完整规则随时可查，费用、目标、紧迫截止和异常原因不能只藏在悬停里。

## 1. 先分清五种对象

| 对象 | 主显示 | 展开显示 | 不混入 |
| --- | --- | --- | --- |
| 词卡 | 词名、构句角色、已占用／持有数量；战前显示真实词卡槽 | 该词参与的已声明配方 | 不能把“火种”词卡当成可消费火种资源；不虚构每个词的独立伤害 |
| 法杖／其法术模板 | 杖序、法术名、每批投入、产出预览、加工／交付／休歇、当前状态 | 原句、首次起点、输入筛选、基础路由与实例来源 | 六根试点杖相同；不添加稀有度、耐久、词槽上限、速度倍率或杖专属能力 |
| 资源实例 | 名称、数量、可用性；辉核增幅与维护时点 | 实例身份、产出杖、专供对象、托管去向、携带规则 | 普通火种不是“6攻击随从”；维护费不是制造费 |
| 行动实例／玩家战斗行 | 名称、效果、队列位置、最早可生效拍；必要的目标规则 | 来源法杖、批次及已支付投入 | 已制造行动不再显示可点击支付按钮，不重复扣料 |
| 敌方行动 | 揭示后的效果、已锁定对象或无目标、到期拍、可否封止 | 锁定规则、来源、取消／空放原因 | 暗牌只保留已获准公开的类型线索；不提前暴露完整程序 |

“法术模板”是配置的展示视图，不新增一类可免费取得的实体卡。玩家改变模板依然要占用真实词卡。

## 2. 四层信息，各有位置

1. **主句：结果。** 如“对敌人造成6伤害”“获得8护甲”。数字加粗，保留动词与对象，不能只放一个剑图标和6。
2. **属性栏：比较。** 每批投入放配方旁；加工2拍、交付1拍、休歇8拍放连续三格，不把三者统称“冷却”。起点和路由在战前或展开区调整。
3. **状态栏：此刻。** 显示“交付·还剩1拍”“待入行·战斗行已满”等；进度条仅辅助，不用颜色独自表达原因。
4. **详情：例外与追溯。** 点击词条、卡面“详情”或键盘确认，展开定义、合法目标、同拍边界和来源。Esc关闭并回到原控件。

新手提示默认展开短括注，玩家可收起；收起不隐藏期限、支付、无目标、休眠、满行或临时路由的失效条件。主句建议不超过两短句，特殊情况允许加一条边界提示；这是排版目标，不通过删规则硬凑字数。

## 3. 一套固定的效果句式

| 情形 | 表达模板 | 约束 |
| --- | --- | --- |
| 伤害 | 对〈对象〉造成〈数值〉伤害。 | 该数值是伤害量，不能声称等于扣除生命；护甲另算 |
| 防护 | 获得〈数值〉护甲。 | 默认主体为玩家，在敌方效果里必须写明对象 |
| 资源生产 | 产出〈数量〉〈资源〉。 | “产出预览”不表示现在就可用；实际交付旁明示下拍可用 |
| 资源改造 | 使投入的〈资源〉增幅＋〈层数〉。 | 此处保留原实例；不可简写成“再造一枚” |
| 取消敌牌 | 封止最早到期的1张敌方行动。 | “封止”的统一定义包含已揭示、可封止和严格未到期；无合法目标空放 |
| 中止加工 | 打断〈锁定法杖〉的当前加工。 | 不等于封止队列，不销毁成品；失效时空放，不转锁 |
| 周期规则 | 维护：每〈周期〉拍，支付〈费用〉。 | 参数全部明示；缺费进入休眠，后续依原规则自动恢复 |

现阶段不在每张行动上重复“生效时：”，因为行动实例本就于出队生效；也不引入“入场、战吼、亡语”等尚未存在的触发机制。未来确有不同触发时机，才使用“〈时机〉：〈效果〉”并重新确认语义。效果短句不是任意自然语言解释器，只对应当前声明配方。

“每批投入”与“已托管”分开：前者列完整需求，后者显示当前批次已经取走的物品。加工成功时结清消费；打断返料、增幅保留核等细则仍按P。把所有投入统一画成“已消耗”会误导，尤其是增幅用的那枚辉核。

## 4. 首批只做四个规则关键词

关键词可点击，有短释义和完整定义；普通动词“造成、获得、产出”不另外加术语名。以下是既有规则的表达归纳，不是新增能力：

| 关键词 | 卡面／短释义 | 唯一完整含义与边界 |
| --- | --- | --- |
| 封止 | 取消1张未到期敌牌。 | 仅选择已揭示、可封止、到期拍严格晚于当前拍的敌牌；最早到期优先，同期按公开顺序；生效时选择，无目标则空放。到期17拍，最晚16拍封止，17拍同拍不行。 |
| 打断 | 中止法杖当前加工，材料下拍返还。 | 只中止仍在加工的批次；托管物原身份返还，下拍可用。已完工、交付中、已入行不受影响；敌方断咒在揭示时锁杖，失效不转锁。不同于封止。 |
| 增幅 | 同一辉核提高一级，上限3。 | 投入的辉核须生效中且未满级；另耗1火种；加工成功时原核增幅＋1，身份保留，交付后下拍可用。休眠核不能消费或增幅。辉击每级额外8伤害是辉击的规则，不是所有增幅对象自动获得伤害。 |
| 维护 | 每4拍支付1灵屑；缺费休眠。 | 本试点辉核在资源区按周期付费；先正常维护再恢复休眠，同组按创建顺序。恢复付一次完整费用，无欠费累积；托管时暂停维护，返还后重新计周期。恢复规则详见P。 |

“增幅”作动作时带＋1；作属性时显示“增幅2/3”。“维护”始终带费用和周期。关键词定义中的参数不能省成“维护1”让玩家猜单位。

以下属于**分类、属性或状态**，不当成新增规则关键词：

- 分类：资源、行动、防护、伤害。不能仅凭分类名额外触发效果。
- 属性：每批投入、加工、交付、休歇、携带占用、可否封止、最低增幅筛选。
- 状态：待启动、待料、加工中、交付中、待入行、休歇中、生效中、休眠、待可用、已托管。
- “可封止”是敌牌可被封止的资格，不是它自己能施放封止；此徽标须保持可见。

## 5. 八条配方的实际文案

表中“主句”放在产出预览／效果区；投入与时间是独立UI字段，不能因为短句省略就免付资源。

| 法术名 | 真实词卡构句 | 每批投入 | 加工／交付 | 主句 |
| --- | --- | --- | --- | --- |
| 炼成火种 | 炼成／火种 | 灵屑×2 | 2／1拍 | 产出1火种。 |
| 炼成霜晶 | 炼成／霜晶 | 灵屑×2 | 2／1拍 | 产出1霜晶。 |
| 合成辉核 | 合成／辉核 | 火种×1＋霜晶×1 | 3／1拍 | 产出1辉核。新核增幅0/3；维护每4拍1灵屑显示在资源属性栏。 |
| 火矢 | 火种／伤害／敌人 | 火种×1 | 1／1拍 | 对敌人造成6伤害。 |
| 霜甲 | 霜晶／获得／护甲 | 霜晶×1 | 1／1拍 | 获得8护甲。 |
| 封止 | 霜晶／打断／待发行动 | 霜晶×1 | 2／1拍 | 封止最早到期的1张敌方行动。 |
| 辉击 | 辉核／伤害／敌人 | 生效中的辉核×1 | 2／1拍 | 对敌人造成24伤害，每级增幅额外造成8伤害。 |
| 增幅辉核 | 增幅／辉核 | 未满级且生效中的辉核×1＋火种×1 | 2／1拍 | 使投入的辉核增幅＋1。上限3；辉核保留。 |

“封止”法术的底层词卡依然是“霜晶／打断／待发行动”；展示名不改词卡含义或库存。本轮通过不同对象区分“打断待发行动→封止”与“打断加工→中止批次”，不能悄悄把已有“打断”词卡删掉或拆成两张。

辉击未取料时显示基础公式，不能根据池里最高核预告必定40伤害。确定使用增幅2的核后可显示“对敌人造成40伤害”，详情列“24＋2×8”；一旦制造完毕，不再随资源区其他辉核变化。展示稿的增幅滑条只演示这个排版，明确不是已经发生的游戏结果。

## 6. 具体UI布局

### 法杖：固定三行＋一块产出预览

- 第一行：杖序与法术名，右侧显示当前阶段。例“05 封止｜交付中”。
- 第二行：每批投入。例“霜晶×1”；战中有批次时追加“已托管”或“制造已结清”的真实状态。
- 第三行：加工2拍 → 交付1拍 → 休歇8拍；运行进度只亮当前段。三段之和仅是无阻塞名义周期，不能标作一定每11拍出牌。
- 产出预览：一张简洁行动牌或资源卡；标题、对象／效果、参数、产出后去向。行动尚未入行时明显标“产出预览”，不能与正在排队的真实牌混淆。
- 战前词卡槽展开；战中默认收起。首次起点、输入来源和战前路由进入展开区。
- 临时改线时出现两条互不替代的说明：“本批→公共池（已承诺）”“后续批次→W5（直到蓄力重击结束）”。没有临时覆盖时只显示一条当前去向。

### 行动牌：结果优先

顶部是法术名与行动类型；正文一到两句，伤害／护甲数字用最大字号；底部显示队列位置与时点。无目标不能用“0伤害”伪装成正常攻击，应写“无合法目标，将空放／已空放”并可查原因。

玩家行动行始终显示“每拍至多1张”。能确定时用“下一张”；受未来交付或中断影响时用“最早第N拍”，不写保证命中的倒数。满行保持满进度并显示“待入行”，不重播交付条。

### 资源卡：数量、身份状态、维护分开

普通资源用图形＋中文名＋数量；辉核额外显示“增幅2/3”和三级刻度。生效中显示“2拍后维护：灵屑×1”；休眠显示“休眠｜不能消费或增幅｜待付灵屑×1恢复”；托管中显示“由W4占用｜维护暂停”。返回资源区后的周期按真实规则重新计算。

“可用／待可用／已托管”表示物品位置和可取性，“生效／休眠”表示辉核状态，不用一个灰色图标同时表示全部情况。携带界面显示“占3容量，跨战增幅归零”；普通火种和霜晶占1容量，灵屑不可携带。

### 敌牌：两个时间，不能合并

例：蓄力重击“对玩家造成18伤害”；主时间是“第17拍到期”，旁边为“还剩4拍”；可封止徽标附“最晚第16拍生效”。它避免玩家误以为17拍出封止仍赶得上。断咒显示已锁定“W3”或“未锁定目标”，不在揭示后重新选择更高进度的杖。

| 已揭示敌牌 | 主句 | 独立属性／状态 |
| --- | --- | --- |
| 击打 | 对玩家造成6伤害。（第二战为9） | 不可封止；实例到期拍按实际揭示时间计算 |
| 蓄力重击 | 对玩家造成18伤害。（第二战为24） | 可封止；显示到期拍与最后可封止拍 |
| 断咒 | 打断W3的当前加工。 | 可封止；W3是实例揭示时实际锁定的杖，不是模板固定目标。未锁定时改为“未锁定目标，到期将空放” |

## 7. 异常必须一眼可见

| 情形 | 主显示 | 详情补充 |
| --- | --- | --- |
| 缺真正可取的霜晶 | 待料：缺1霜晶 | 池里若有但来源不符，写“现有霜晶不符合W2来源限制”，不笼统说库存为0 |
| 行动行已满 | 待入行：战斗行3/3 | 交付已完成；等待空位，耗时不重置 |
| 达到生产起点前／休歇中 | 第N拍可尝试开工 | 届时仍需足料，不能保证开工 |
| 封止到期同拍 | 已错过封止窗口 | 最晚T−1拍；T拍不可取消 |
| 蓄养条件不满足 | 等待增幅≥2的辉核 | 当前可用核最高等级、来源限制分别明示 |
| 休眠 | 不能消费／增幅 | 付一次完整维护费可恢复，无欠费 |
| 目标消失或无合法目标 | 空放 | 不转移锁定目标，不退已消费制造料；保留敌方程序空档 |
| 隐藏敌牌 | 攻击／干扰的卡背线索 | 不显示未来伤害、确切截止、目标或新牌顺序 |

图形一物一义：火种三角、霜晶菱形、辉核六边形、灵屑星点；均带中文和数量。颜色仅辅助区分，红色同时附“已错过”等文字；紫色不代表稀有度。伤害不用资源图形代替。数字统一阿拉伯数字和“拍”，不混用秒、回合或冷却。

## 8. 取舍与下一步

不采用“所有效果都写成全文”：准确但会在每根杖重复公共结算。也不采用“全部图标＋大量自创关键词”：占位少却增加背诵负担，无法直接解释缺料和截止。本轮选择短句与固定属性栏，少量关键词有同屏提示。

下一步先评审实际样稿，再决定是否替换DM-G002-004界面。当前只确认了Q17；四关键词、卡面布局及术语密度仍是候选，主系统未采纳。

建议真人观察任务（未执行）：分辨火种词卡与火种资源；说出一根杖投入、产出和等待原因；判断17拍敌牌的最后封止时刻；解释辉核休眠与增幅2的区别。记录误读和是否需要口头补充，不以点击测试替代这些结论。若“封止”和“打断”持续混淆，优先让“打断加工”保持完整短语，不再继续缩写。
