## 规范化表述

以TL-1自动生产和有限战斗行为基础，制作先单战、再两战相连的最小可玩试点。第一层覆盖供料、加工、攻防与提前打断，第二层加入一条维护型高阶产物链以及独立的奖励／携带结算和重新编排。普通区间自动运行，玩家在关键敌情后暂停理解依赖，调整后续批次并观察代价。付费干涉首步仅保留接口，具体能力在核心可玩后再选；完整路线、商店和长期成长不属于首版切片。

## 设计对象与GDD映射

- 对象：词卡试点、生产／战斗／资源系统接口、短局结算、玩家反馈与可执行边界。
- 目标：本方向试点提案；若以后进入主系统，对应GDD第2、4–9、11、14–16章及SYS-001–007。
- 完成度目标：试点范围达到可执行规格；不把局部原型称为主系统GDD-1或完整游戏。

## 玩家处境、行为与反馈

- 玩家面对有限词卡、法杖、材料和队列；程序自动执行，关键威胁有公开截止。
- 玩家能看到资源可用／托管／待可用、法杖缺料／加工／滞留、队列与实际事件。
- 战前编排程序与时机；战中暂停，改变未承诺批次的路由，或承受损失保持原计划。
- 行动和返工须明确给出来源、实际时刻与原因；无目标、缺料、行满和打断不能共用模糊失败提示。
- 希望玩家能解释延误，并通过编排改变结果；至少两种有代价的有效解法是待验证目标。

## 已确认的试点边界

| 来源 | 唯一裁决 |
| --- | --- |
| Q8 | 上拍新产／返料可用→到期维护及休眠恢复→已入行防护→到期伤害与打断→疲劳→幸存完工与交付→本拍补给为下拍可用→新批次开工→揭示新敌牌并留观察机会。同类伤害先敌后我；多敌按固定身份和程序位置。每完整事件后判终局。首批无跨防护／伤害的复合牌。 |
| Q9 | 交付计时不因满行倒退，不预占行动格；计时完成后无位则持成品等候，按杖序入行。入行最早下拍生效，交付成功后才休歇及续产。 |
| Q10 | 来源敌人死亡取消其未触发牌；锁定目标消失则到期空放，不换同名新目标；保留空档。 |
| Q11 | 到期维护先于休眠恢复；各组按产物创建先后。恢复支付一次完整维护费，重新计算周期，不补缴休眠期。托管产物暂停维护／增幅，返还保留身份／增幅并重新等待维护周期。 |
| Q12 | 胜利后未完工托管料退回，未交付资源以真实成品加入结算，再受携带标签／容量约束；行动、队列和进度清理，不退已消费制造成本。失败结束本局；奖励与携带分别提交保存。 |
| Q13 | Codex制定Demo候选参数，并可在已确认机制内依程序检查／可达性试跑调数留记录；新词义、能力、系统仍需确认。调试数值不升级主系统采纳或真人证据。 |
| Q14 | 使用候选中8条配方、4种玩家行动、3种敌牌及声明词义；暂缓灵屑词卡但保留灵屑资源。休眠核不能消费／增幅，增幅身份不变且有上限；攻击、封止及断咒按已确认的确定性选择器执行。 |
| Q15 | 资源输出到公共池或指定杖，输入筛选任意合法来源或指定生产杖；辉击可设最低增幅。战中覆盖绑定已揭示威胁，解决／到期恢复；无揭示威胁时可持续至战终。开工承诺路由，不改既有批次。 |
| Q16 | 资源区不设储存上限，队列与携带容量有限。第一战可用基础与辉核攻击，胜利收益包提供真实增幅词卡；第二战才能增幅。切换编排不赠送词卡或资源。 |

## 机制—行为—体验假设

| Mechanics | Dynamics | Aesthetics |
| --- | --- | --- |
| 有限队列与真实加工／交付 | 提前预留产能，比较打断与防护时机 | 看懂并掌控延误 |
| 材料在低阶与高阶链竞争 | 为较晚收益承担眼前威胁 | 准备兑现的满足 |
| 奖励、携带与重编排 | 将第一场经验及有限资源投入第二场 | 自己修正构筑的连续感 |
