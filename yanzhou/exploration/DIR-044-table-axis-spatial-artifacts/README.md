## 构思概览

**诊断。** 现行闭环里，5个生产拍与5个结算列是两套钟，之间只有手牌一条单向接口；把生产换成抽牌堆，时间轴照样成立。状态面（待料、托管、在制、战斗行、锁定、吸收拍、供料资格拍）远大于决策面。要继承的体验：理解配方与工序、同一张牌用／留／投的三向抉择、看见投入去向、敌方公开威胁与疲劳的节奏压力。

**一桌一轴（用户认可思路）。**

- 战中只有一张桌子：横向是回合内5个时间列，纵向是一条战斗行加每台已部署法器各一条工序行。战前背包只负责装配，战中没有背包几何。
- 唯一动词是「排」：牌放进战斗行第c列是即时使用；放进工序行第c列是投料并在该列开工；不放是留手。撤回免费，直到光标越过该格。一根光标：左边冻结只读，右边可改。
- D以列计，可跨回合；一器同一时间一条在制。产物在工序结束后的列间窗口入手，下一列起可用（此前「完工列当列可用」已废弃）。
- 可删除的现行机制：生产拍、累计拍、第0拍、观察窗、待料、托管、吸收拍、供料资格拍、材料锁定、唯一链接、接收范围与一格接触、自动补料及开关。最终整理与列间窗口合并为一个布置窗口。
- 保留：统一卡牌与三权限、两组手牌、回收规则、TL-21空放、敌暗牌与延时后续、疲劳与终局。

**空间法器约束（交接稿记为用户逐项确认）。** 空间只在装载确认时求值一次，战中桌面只读结果。

- 炉心必选（小炉1×1、长炉1×2，占格，不嵌铭文，不产卡）。格距＝到最近炉心格的曼哈顿距离减1，最小0，即共边为第0圈。
- 整件入圈，跨圈取最远格所在圈。圈下限（示意）＝1＋圈号。实际D＝max(配方D，圈下限)，并入现有D公式，最终至少为1；催炉类效果不能突破下限。
- 组合取代邻接：接触本身无效果；内容给组合表，战前玩家主动「组合」后合并为更大的法器，占形取并集，有自己的配方与产出，部件在组合状态下不能单独开工。
- 入料口尺寸P由内容直接设定，与占形脱钩，配方材料数S不得大于P。
- 辅助改为覆盖圈：按最远距离覆盖，被覆盖的每台法器全额生效，同效叠加沿用现行；删除朝向、接口与单器连接。
- 取消法器序设置项；暂不做延后、串扰、打断介入生产；不做位置定序。

**生产与战斗联动（A、C、D为骨架）。** A敌情当订单（战前公开敌表类别轮廓）；C敌方「封印」我方牌效果，做成提前一回合公开的延时牌，被封印的牌按TL-21空放，生产不被触及；D疲劳折合约50列，作预算尺。催炉卡效留到内容阶段；不恢复打断介入生产。

## 配方D重标定提案

**时间口径。** 新规则下，在第c列开工、D列后入手、第c+D列起可用，与现行「a拍末开工、a+D完工」的间隔相同，D的数值与单位量级可以沿用。变化在别处：现行生产先于结算列跑完5拍，新规则下生产与交锋同钟，开局没有预生产（见TA-Q09）。

**标定原则（提案）：每条配方的D不低于其法器在单枚长炉下可达的最优下限。** 这样任何单炉构筑都不会遇到「配方写D2、空间永远做不到」的虚设数字，剩余差距由炉心数量与摆位承担。

| 法器 | 配方D分布 | 单枚长炉最优下限 | 结论 |
| --- | --- | --- | --- |
| 初相坩埚 | D2×3 | 2 | 不改；余量0，小炉会变D3，长炉才达标，炉心因此有分化 |
| 刻纹研钵 | D3、D3、D2、D4 | 1 | 不改 |
| 盘管萃炼器 | D2×3、D3×3、D4、D5 | 3 | **三条D2改D3** |
| 封相炼炉 | D3～D5 | 3 | 不改；D3余量0 |
| 白瓷曲颈瓶 | D2、D2、D3 | 2 | 不改 |
| 黑铁铸模 | D3、D4、D4 | 2 | 不改 |
| 黄铜显咒灯 | D3、D4、D3 | 2 | 不改 |
| 红玻璃合一炉 | D6、D5 | 4 | 不改 |

**拟改三条：** 滚烫蒸汽（alchemy.r04）、轻盈雾团（r05）、草药汁液（r06）由D2改D3。35条的D分布由2/3/4/5/6＝9/14/8/3/1变为6/17/8/3/1。

**连带：** 草药汁液进生命灵药链，合计D工时9→10；轻盈雾团进水银飞弹链，18→19；滚烫蒸汽进炼金爆弹链，20→21；万灵药含生命灵药，53→54。首战四个用途的D（3、2、2、3）与首战所用的预制材料都不受影响。各成品的「冷启动首份下界」按旧口径推出，须随新时间线重算。

**为什么不用别的办法。** 改萃炼器占形要重新走CORE-074几何采纳；靠多放炉心也能让D2达标（表A，2枚即可），但那把压力转成炉心数量，是TA-Q01的决定，不该由D去兜底。若TA-Q01定为每场至少2枚炉心，这三条可以不改，提案随之撤回。

**成立条件。** 提案只依据表A与配方表的算术，未经玩家测试；它不改变catalog.json，走采纳后才回写。

## TA-Q10 纸面推演（2026-11-04，用户授权）

性质：用脚本逐列模拟一条固定出牌路线并计数拖放，是纸面推演，不是真人游玩，也不是原型。只能说明这条路线的拖放次数与时点，不证明可理解性、乐趣或真人操作量；玩法与体验仍NotRun。脚本为临时文件未入库，按下列假设可复算。

**模型假设：**

- 首战1枚小炉，沿已求得的一个最优摆法：萃炼器D4（草本灵液），铁肤瓶D2、生命瓶D2、显咒灯D3（引燃术）不拖慢。其他最优摆法的拖慢落点未穷举。
- 一桌一轴时间线：第c列开工、D列后入手、第c+D列起可用；入手即可作下一批投料，没有供料资格拍与吸收拍。材料齐备时玩家总是立刻开工。
- 补给疗伤草沿EX-005的解封序号5、10，改为列序号并在列间窗口入手，第6、11列起可用；序幕回合计入列序号。
