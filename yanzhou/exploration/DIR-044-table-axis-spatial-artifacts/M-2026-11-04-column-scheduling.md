## 规范化决定

| 编号 | 已确认内容 |
| --- | --- |
| R1 | c列开工，占用c至c+D−1列；最后一列结束后的窗口入手，c+D列可用。D1也必须经过本列；删除“开工当列不推进” |
| R2 | 布置与合法性检查→确认并冻结本列投入→揭示敌牌并战斗结算→未终局才结清本列工序、解封补给→下一布置窗口；终局不补产 |
| R3 | 同器上一批某列末完成，下一批最早下一列开工；可用真实持有材料提前排下一批，占用区间不得重叠，无额外冷却或自动补料 |
| R4 | 不完整排料可留为草稿；确认当前列前检查该列工序的完整性、设备占用与费用。非法则拒绝此次推进、保留可编辑状态，玩家补齐、撤回或改排后再确认；不暗中顺延 |
| R5 | 同列多器开工费用合并检查；不足按R4拒绝，由玩家选择保留工序，不以法器序或位置抢资源 |
| R6 | 明示零材料用途由点击工序格并选择本器固定用途排入开工指令；不生成虚拟材料卡，撤回与冻结沿同一光标规则 |
