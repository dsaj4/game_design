## 构思概览

成对选择下一场挑战和指定词卡奖励。

## 具体构思

### A · 双面战利品：为想要的词，选择要面对的难题

**玩家体验。**我选的成长不仅强化下一套咒式，也决定必须怎样赢下下一场。

- 来源：[孤勇英豪](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/11-unstoppable.md)是主依据；[火爆狂飙](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/08-heat.md)、[Moon Colony Bloodbath](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/13-moon-colony.md)补充延迟后果与塑造挑战；[夺心魔虫](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/12-mindbug.md)提醒我们避免只堆强度。
- 新增规则草案：在一个既定分支点展示两份不可拆开的契约，各包含**下一场完整公开布场＋胜后指定词卡**。玩家二选一，锁定后不能换奖励或退出重抽。只增加两份固定契约，沿现有自动战斗；原有金币、胜负与疲劳先保持，额外词卡是明确的新获取渠道。
- 场景：当前持有火焰2、冰霜1。候选包一是“早攻遭遇＋火焰副本”，包二是“初甲遭遇＋冰霜副本”。已有模板是否可直接组成同成本的这对契约须在原型准备时核对；这里不是宣称 RC1 已有这两包。玩家想补火焰组成第二条操控句，但需要先解决早攻；想买冰相关组件也可能更愿意准备另一场。
- 真实代价：选一份会失去另一份的词与更合适的挑战机会，生命损耗会带到后续。必须提前检查同名3张额度、实际卡池开放期别及合法资源；额度满的奖励包不能继续诱导选择。
- 与基线的差异：改变 SYS-005/006；RC1 战斗只奖金币，此方向增加契约词卡，不得写成既有掉落。既有完整重配保留，不用强锁旧句制造承诺。
- 首要风险：玩家总能选最容易又最适合自己的包，成长—挑战关系形同虚设；或稀有奖励逼玩家承担必败战斗。奖励价值应与遭遇机会成本一起研究，不能只统一加敌人生命。
- v0→v1：从“全卡池双面化、每次强化都制造敌人”，缩成“一个节点、两份固定契约”；不给每个词设计一个新敌人。

**最小验证（Planned / NotRun）。**两种合法库存 × 两份契约，用相同生命、期别和后续商店输入对照；保留无契约的 RC1 参考条件。先纸面检查实体额度和经济，再让5位目标玩家说明取舍。暂定继续信号：至少4人能说出奖励和代价，且更换库存后出现有理由的选择变化；失败信号：两种库存都无需看敌情便固定选同包，或新奖励使后续采购失去取舍。真实胜率、整局强度与额外词卡价格影响仍未知。
