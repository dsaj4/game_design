### 真正可表达的选择与仍缺失的取舍

当前能切未来用途、锁／解自有未承诺层数、暂停查看／继续／单步。不能战中重铭、手动打牌、手选目标、插队、取消批次、即时取消敌牌或单法器停机。

第14拍观察有9层时，现行规则允许锁5，使可消费仅4；此时强化打击不支付、回退6伤害后记1，实有到10、锁定仍5。与不锁的“付5打18后余5”相比，保留5层会少造成12伤害。这是可读的账目差异；**现配置没有被动保留收益或另一消费者，尚未证明少打12的路线有值得选择的理由**。不能为展示取舍凭空增加护甲、利息或后续奖励。

依据FB-Q01的候选“未来批次启停”，作一个反事实核对：若允许12拍阻止施法续开，并在13拍恢复，9→12已完工的强化牌照常保留，下一批为13→16；旧规则自动12→15、13拍被打断后也能凭独立空位13→16重开。此固定输入下，两者下一次完工相同、均无材料损失；短暂容量差异也没有在原路线造成阻塞。**仅加开关不保证产生有效调度收益**。这只是有明示前提的纸面比较，不采纳启停、不运行候选规则。

本场适合先检验“读懂承诺与兑现”；要证明“关键取舍成立”，还需FB-Q01／02及新的首场输入。未来新规则确认后保留EX-001／002原回归，另立具体输入，不改写旧结果。
