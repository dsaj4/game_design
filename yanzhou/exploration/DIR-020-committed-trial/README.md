## 具体构思

以下摘录沿用原来源的时间与候选状态；其中旧规则、推荐顺序和计划均不自动成为当前规则或执行授权。

### 设计工作假设与术语

1. **战斗内**是已编排法术的自动运行；**局内战间**是同一远征中的路线、休整、商店和重构；**局外**是本局结束之后的复盘与下一局动机。
2. 保留 RC1 的实体卡、最多4杖、时间槽与空间范围作为比较基点。替代方向如修改自由重配、地图结构或终局，会明确标出。
3. 优先贴近15–25分钟有效整局目标。新增系统占用多少时间要测，不能把多步骤自动当作更深。
4. “策略更深”的候选判据：不同资源／敌情下有不同合理选择；同一选择存在可解释的机会成本；获得新词会影响句义或时序；成败能归因于自己的准备。
5. 核心比较单位是完整循环。下列A–D择一作为主方向；其子环节不是额外四套系统全部上车。

### B：限额整备连续试炼——让两场共用一个核心计划

Candidate ID：`C-committed-trial-v01`。

#### 循环与独特取舍

看完整两战主题→为两战配置一套四杖核心→第一战自动执行→用一次局部改装机会适应第二战→第二战→整备站全面重构。

候选规则：两战段开始时可自由配置；中间仅允许完整重构一根法杖，其他杖的句子／镶嵌保留。法杖锚点、首次起点和必要的失效实例重绑定仍可免费调整，因为每场场地和对象身份本来就不同。交换某个实体出另一根杖也算影响那根杖，不能通过跨杖搬运无限改写；具体编辑计数需资格确认。

玩家要决定哪几根杖承担跨战稳定职责、哪一根作为备用应对。例如第一战用元素引擎，第二战需要把一根操控杖换成直接攻防，就要事先确保它不抽走其他三句正在独占的实体。

#### 相对RC1的改变

- 直接改变“每场战前可使用完整库存自由编排”的合同；不属于轻量调参。
- 战中仍自动，普通词卡不被消耗；新的稀缺资源是编辑机会。
- 为不可带入下一场的引用提供免费合法修复；若规则导致上一场合法配置无法进入下一场、且一次修改无法修复，说明候选协议未闭合，不能靠惩罚玩家解决。
- 局外沿咒典记录“两战都能用的核心＋替换模块”，无永久编辑点、付费绕过或强度成长。

#### 为什么目前只列次选

它可能形成稳定核心与临时模块的取舍，但A里已有生命、金币、实体占用与错过路线的承诺。必须先观察自由重配是否真的消除了长线选择，不能把编辑困难本身当作策略深度。

最小验证：同一两战输入、同一库存，比较自由重配和上述限制，记录计划是否更有前瞻性、遇到非法编辑的次数、是否反复撤销、是否只是少试了有趣句子。若玩家的主要任务变成研究“怎样改才不扣次数”，退回或放弃限制。未运行。
