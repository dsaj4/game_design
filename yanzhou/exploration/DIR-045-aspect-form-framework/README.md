## 目标与用户已表达的构思

复杂配方目前需要记忆；用户希望用一套可理解的框架限制配方、材料和成品作用，让玩家能从性质、形态与名字理解生产关系。这里的“降低记忆负担”是目标，尚无体验证据。

### 1. 物品的两条描述轴

- 所有材料与产物具有性质轴和形态轴。性质轴可称属性／性相／字相；形态轴可称形态／物相／实相。本文暂用“字相”和“物相”方便讨论，正式术语尚未确认。
- 字相对应物品性质，不同字相需要不同工序处理，工序对应法器支持的核心铭文。
- 物相对应物品形态，不同物相交由不同类型法器处理。尚未确定这是按输入形态、目标产物形态，还是两者共同限制。
- 用户示例：清泉水＋疗伤草，经坩埚中的凝练成为水木灵液；水和草的性质汇入一个产物，“水”关联凝练，“灵液／药水”关联坩埚。
- **该示例仅说明构思，与现有内容库无关。**“草”在结果名中变成“木”的依据、疗伤性质是否保留、混合字相需要哪些工序均未定义；不自动补成草属木或五行体系。

### 2. 命名与知识揭示

- 物品名字与性质高度相关；字相不要求机械匹配同一个字，只要名字的构成能明确指向对应性质即可。
- 玩家从书本或仪式了解物品别名、真名，从而认知对应字相并解锁合成配方。
- 命名承担辨识线索与知识揭示功能，同时是用户希望建立的言咒世界观联系；尚未定义真名的世界成因，不继承旧世界设定。
- 尚未明确：名字揭示既有性质还是改变可用性质；已猜出正确材料但尚未获得知识时能否生产；解锁覆盖单一配方还是一组可推导配方。

### 3. 知识体系

- 知识主要来自书本与仪式，按不同字相具有知识等级。
- 提高知识等级可解锁更多核心铭文与世界观故事碎片。
- 阅读书本可能带来知识等级、新仪式类型以及具体物品名字；未声明每本书必定同时给出全部收益。
- 尚未明确各级阈值、跨字相依赖、故事碎片内容，以及“解锁铭文”与取得／装配实体铭文的关系。

### 4. 仪式体系

- 所有仪式以召唤为核心，必须有可指向的对象；通常由特定供物指向神灵或其他召唤物。
- 另一个要素是请求的字相，通常由另一份祭品的字相表达请求内容的领域。
- 第三个要素是通过知识解锁的仪式类型，规定除对象、字相外的其他要求。
- 用户示例：先从书本解锁问路仪式，再于祭坛献上炼金符契、清泉水与辅助香料，向炼金之神请求并获得一个新的水属性地点。
- 本例只留在探索：炼金之神及供物未成为正式世界观或内容条目。“获得地点”具体是获知、开放路线还是生成新地点，仍为Unknown。

## 玩家情境与预期价值

用户构思所支持的候选行为链：阅读书本或举行仪式→获得名字／字相知识／仪式类型→理解可用材料与工序→选择法器并装配相关铭文→加工产物→使用成品或继续转化。仪式中则选择请求对象、请求领域与仪式类型，并备齐额外要求。

希望玩家能回答三个问题：这份材料为什么能用；为什么需要这道工序及这种法器；结果为什么具有这些作用。预期价值是让知识能迁移到未见配方，减少孤立记忆；能否做到仍待验证。

尚未闭合的取舍包括：同字相材料是否可替代，复合字相如何选工序，以及成品立即使用、继续加工、作为祭品三种用途如何竞争真实库存。上面这些取舍是待设计内容，不是用户已确认规则。

## 首批待确认问题

以下均为**模型建议，尚未获得用户确认**。编号只用于本方向的本批讨论；用户可逐项回答或明确整批按推荐，未回答项保持Unknown。

| 编号 | 待确认边界 | 推荐与影响 |
| --- | --- | --- |
| ZX-Q01 | 新框架只是给固定配方分类，还是允许玩家按规则推导并替换材料？ | 推荐先做有边界的通用配方：配方规定必要字相、输入／输出物相和工序，满足条件的材料可替换；具体产物与效果受明确规则限制。比每对材料单列配方更能迁移知识，但需要处理多结果冲突。 |
| ZX-Q02 | 字相包含“水／草”这类性质，也包含“疗伤”这类功能吗？草与木是什么关系？ | 推荐字相可描述材性及功能，但逐项明确类别与允许效果；不把草自动归木。示例暂按“水＋草”讨论，待确认是否建立草→木层级；避免未经定义的转换成为新记忆负担。 |
| ZX-Q03 | “水→凝练”“灵液→坩埚”是唯一对应吗？法器看输入还是输出物相？ | 推荐工序与字相采用有限多对多兼容，法器约束可接收的输入物相及可产生的输出物相。这样同一水相仍可走不同工序，但需要让玩家看见明确兼容关系。 |
| ZX-Q04 | 成品作用从哪里来：逐配方手写，还是由字相、工序与物相共同约束？ | 推荐字相规定允许的作用领域，工序规定保留／转化哪些性质，物相限制使用方式；精确效果另明确声明。按Q02是否纳入功能字相调整作用来源，不凭“水”直接推导治疗，也不默认叠加全部原料效果。 |
| ZX-Q05 | 玩家猜对了未解锁配方，是否仍能制作？别名／真名是揭示还是改变物品？ | 推荐名字揭示物品既有性质；未解锁对应知识时不能进行受其限制的加工，即明确的知识门槛。它贴近“知识解锁配方”的原意，但会限制盲试发现；若偏重实验玩法可改为允许盲试。 |
| ZX-Q06 | 知识升级解锁铭文，是否直接给予一枚永久可用实体？ | 推荐先解锁理解／获取资格，实体铭文仍需另行获得并装配；知识可永久保留。保留现行知识与局内实体的区分，具体取得渠道Unknown。 |
| ZX-Q07 | 仪式中对象、字相和类型分别决定什么？复合字相祭品怎么办？ | 推荐对象限制可回应领域，类型决定请求行为，字相限定结果主题；复合字相祭品在举行前明确选一个已知字相。问路先解释为开放一个可前往的合格地点，地点生成与路线限制另定；不把新地点直接视为无条件创造。 |

## 主要未知与后续验证

- 字相集合、单物品多相数量、别名与真名的差异、同相材料替代边界，以及作用强度来源均未定义。
- 同一组字相与物相是否足以区分两个不同产物，材料个体差异是否仍然有意义，尚无裁定；若每种例外都要单记，框架可能只增加术语而未减少负担。
- 多相材料需要同时加工、选相加工还是逐步加工；被忽略的相保留还是失去；错误组合的反馈和消耗，均为Unknown。
- 仪式供物消耗、失败、重复请求、无合格地点时的结果，以及对象之间的差异未定义；不自动补入神系与世界故事。
