## 目标与用户已表达的构思

复杂配方目前需要记忆；用户希望用一套可理解的框架限制配方、材料和成品作用，让玩家能从性质、形态与名字理解生产关系。这里的“降低记忆负担”是目标，尚无体验证据。

### 1. 物品的两条描述轴

- 所有材料与产物具有性质轴和形态轴。性质轴可称属性／性相／字相；形态轴可称形态／物相／实相。本文暂用“字相”和“物相”方便讨论，正式术语尚未确认。
- 字相对应物品性质，不同字相需要不同工序处理，工序对应法器支持的核心铭文。
- 物相对应物品形态。配方均由必要字相、物相和工序约束，允许满足条件的材料替换；具体产物及效果仍须明确规则。
- 法器先只限制输出物相，不以法器类型额外限制输入物相；配方自身的必要物相条件仍适用。工序与字相采用有限多对多兼容，同一字相可对应不同工序。
- 用户示例：清泉水＋疗伤草，经坩埚中的凝练成为水木灵液；水和草的性质汇入一个产物，“水”关联凝练，“灵液／药水”关联坩埚。
- **该示例仅说明构思，与现有内容库无关。**用户已确认“草”和“木”都明确指向同一个木字相，“疗伤”不算字相；这不扩展为完整五行体系。

### 2. 命名与知识揭示

- 物品名字与性质高度相关；字相不要求机械匹配同一个字，只要名字的构成能明确指向对应性质即可。
- 玩家从书本或仪式了解物品别名、真名，从而认知对应字相并解锁合成配方。
- 命名承担辨识线索与知识揭示功能，同时是用户希望建立的言咒世界观联系；尚未定义真名的世界成因，不继承旧世界设定。
- 名字揭示物品既有性质；未解锁相应知识时，不能进行受其限制的加工，即使玩家猜对材料也不绕过知识门槛。
- “疗伤药剂”这类不直接显露字相的名字可以存在，其字相需要通过知识解读隐藏名获知。物品等级越高，越倾向于具有多个隐藏名／别名／真名；这是一种倾向，不等于每升一级必增一名或每个名字必对应不同字相。
- 隐藏名、别名与真名的具体区别，以及一次解读解锁单配方还是一组规则，仍为Unknown。

### 3. 知识体系

- 知识主要来自书本与仪式，按不同字相具有知识等级。
- 提高知识等级可解锁更多核心铭文与世界观故事碎片。
- 阅读书本可能带来知识等级、新仪式类型以及具体物品名字；未声明每本书必定同时给出全部收益。
- 知识永久保留；知识升级解锁铭文的理解／获取资格，实体铭文仍需另行获得并装配，不直接给予永久实体。
- 各级阈值、跨字相依赖、故事碎片内容和铭文取得渠道仍为Unknown。

### 4. 仪式体系

- 所有仪式以召唤为核心，必须有可指向的对象；通常由特定供物指向神灵或其他召唤物。
- 另一个要素是请求的字相，通常由另一份祭品的字相表达请求内容的领域。
- 第三个要素是通过知识解锁的仪式类型，规定除对象、字相外的其他要求。
- 用户示例：先从书本解锁问路仪式，再于祭坛献上炼金符契、清泉水与辅助香料，向炼金之神请求并获得一个新的水属性地点。
- 对象限制可回应领域，仪式类型决定请求行为，字相限定结果主题。多字相祭品在举行前明确选择一个已知字相。
- “获得地点”已确认先按开放一个可前往的合格地点解释；地点生成和具体路线限制仍待设计。炼金之神及供物只留在探索，未成为正式世界观或内容条目。

### 5. 字相、物相与特殊效果词条

用户第二轮确定采用效果词条叠加：物品效果由字相词条、物相词条和可选的特殊词条组成，而非直接叠加所有原料的全部效果。

| 词条类别 | 已确认的构成规则 | 设计边界 |
| --- | --- | --- |
| 字相词条 | 只保留一个主字相，取生产工序对应的主字相，并继承当前投入材料实际持有的对应效果；初级材料只有字相词条。同字相共用核心机制，同批只继承一次，不因多份同相原料重复生效。 | 字相不单独配置成长数值；所需数量取物相参数或明确当前状态。初级材料无物相词条，必须明确其状态取值依据。缺少主相效果来源时须补入来源，不能只凭字相资格恢复被筛掉的效果。 |
| 物相词条 | 合成后的物品都有物相词条；同一具体物相共用基础作用，强度由明确的成品等级／配方档位规定。再加工按新产物重建物相词条，不累积旧物相效果。 | 初级材料仍有形态描述，但没有物相效果词条。其他基础作用使用不同物相；具体物相集合、等级与档位数值仍待设计。 |
| 特殊词条 | 如有，则提供隐藏的额外强大效果；物品越高级越可能有特殊词条，需另行设计。 | 不把高等级视为必有特殊词条；生成、揭示、使用条件及再加工继承均未定。 |

**用户效果示例（探索用，不是正式卡牌规格）：**

| 对象 | 用户给出的效果 |
| --- | --- |
| 清泉水 | 水相“净化”：清除场上的一种状态。 |
| 疗伤草 | 木相“药毒”：将自己的若干生命转化为中毒状态。 |
| 凝练后的水木灵液 | 主水相“净化”：解除场上的一种状态；物相“治愈”：回复10点生命。木相“药毒”不在该成品的效果列表内。 |

例中凝练选择水为主字相，因此继承净化而不继承药毒，治疗则来自物相词条。“清除／解除”先按同一示例表述，不自行定义两种效果。“一种状态”的对象与清除范围、“若干生命”的取值和中毒宿主、各词条结算顺序尚未设计；不套用未读取的行动／标记细则。

**字相资格与字相效果已确认分开：**产物保留配方明确赋予的字相资格，不自动累积全部原料字相；仅一个主相提供效果。水木灵液保留水、木资格，可在满足其他条件及相应知识门槛时作为水／木材料或祭品，但当前只有水相净化效果。灵液物相提供治愈，10点仅为示例值。

再次加工时，只继承当前投入实际持有的主相对应效果，并重建新物相效果。水木灵液单独作为木相资格来源不能重新激活药毒；木相工序若需要该效果来源，须另补实际持有药毒的材料。不追溯已消费的疗伤草，特殊词条继承仍未定。

## 玩家情境与预期价值

用户构思所支持的候选行为链：阅读书本或举行仪式→获得名字／字相知识／仪式类型→理解可用材料与工序→选择法器并装配相关铭文→加工产物→使用成品或继续转化。仪式中则选择请求对象、请求领域与仪式类型，并备齐额外要求。

希望玩家能回答三个问题：这份材料为什么能用；为什么需要这道工序及这种法器；结果为什么具有这些作用。预期价值是让知识能迁移到未见配方，减少孤立记忆；能否做到仍待验证。

同字相材料在满足配方其他条件及主相效果来源要求时可以替代；工序选择决定成品主字相效果。非主相仍可承担配方和仪式资格，但不自动提供可继承效果。同相物品差异由物相与特殊词条承担；具体内容及立即使用、继续加工和祭品之间的价值取舍仍待设计。

## 主要未知与后续验证

- 字相集合、单物品可识别多相数量、别名与真名的差异、具体等级／配方档位及数值、药毒状态取值依据仍未定义。

- 非主相资格及重复加工继承已确认；特殊词条生成／揭示／启用／继承、名词槽职责、无铭文基础加工适配，以及新知识／资格失败提示仍待设计。
