### D · 自编遗迹：选择下一场的地形，也选择自己的解题条件

**玩家体验。**我不只在现成战场上安排法杖；还要判断哪种场地结构适合现在的词，以及它带来什么限制。

- 来源：[蓝途王子](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/17-blue-prince.md)将探索与空间构筑合一；[万境奇旅](../../history/exploration-2026-09-24/insights/gic-2026-09-20/cases/18-vantage.md)提醒丰富场景不能靠无限特例堆积。
- 新增规则草案：先完整公开敌人位置与攻击表，再从两份审核过的环境模板中选一份；选择只改变指定环境格，不改敌人、不赠物品，不允许任意清空障碍。确定后才完成构句并锁定开战。
- 场景：一份模板给靠近前排敌人的元素出生空位，但后排缺少可储层的树；另一份提供后排树群与转化机会，同时封住前排的直接出生邻格。初期直接短句、持续生成、后排借位操控可能因此有不同偏好。具体十格模板必须在原型前列出，这里只定义结构差异。
- 真实代价：每份模板同时提供帮助和限制，不能存在空位更多、目标更近、转换更容易的全面优势选项；如果无法构成这样的对照，就没有理由给玩家增加一次选择。
- 与基线的差异：改变 SYS-005 的固定遭遇生成合同；元素邻近、出生选择、转化阈值不变。新选择必须进入锁定保存输入，退出不换模板。
- 首要风险：玩家等于总给自己出简单题，削弱遭遇对构筑的压力；地形选择与 A 的奖励选择互相重复；制作、验证布场的成本高于两个选项看起来的规模。
- v0→v1：从整局房间拼接、永久房间成长，收束为“一场、两个既有对象构成的地形模板”。

**最小验证（Planned / NotRun）。**两份完整十格模板 × 两种相同总资源、不同构筑倾向，先检查合法出生与所有公开目标。继续信号是构筑变化会使模板偏好反转，并能说出失去的机会；失败信号是各构筑都选同一模板，或玩家无需适应环境就能把全部压力删去。该方向内容成本最高，建议排在前三项之后。
