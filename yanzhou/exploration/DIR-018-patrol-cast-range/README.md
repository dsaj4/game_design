## 具体构思

### 方向三：巡行范围——同一句法术沿战场逐轮移动

Candidate ID：`C-patrol-cast-range-v01`。层级：新增玩法。目标章节：GDD §3、§5、§9、§11。

#### 一个具体场景

战前为一根特殊法杖选定三个锚点F2→F3→F4，按正常循环轮次推进；假设第6、10、14刻开始，分别使用对应锚点。条形时间轴的三次释放与地面三个锚点连成一条虚线路径，实际开始时只点亮本次范围。

棋盘上甲在F2、乙在B4，公开对象顺序甲先于乙；借用W01两排三列的范围形状做候选示例。两敌均存活时：第6刻范围覆盖列1–3，首个候选是甲；第10刻覆盖列2–4，仍按公开顺序选甲；第14刻覆盖列3–5，甲不在范围，首个候选变成乙。不是范围里有两个敌人就自动群攻。

#### 玩家做出的新决定

- 用一根杖周期性照顾左右不同目标，减少为另一侧另配完整法术的压力。
- 代价是不能每次都打同一个优先敌人；移到另一侧时，原目标可能继续攻击。
- 调首次冷却起点会整体改变巡行抵达各位置的时刻；调路线会改变相同节奏处理敌人的顺序。时间和空间终于共同构成一个战前选择。
- 搭配固定生成杖时，巡行操控杖可能暂时离开执行元素范围，产生真实空放；也可能在不同地点找到不同来源的元素。范围路线必须考虑现有元素选择规则。

#### 规则边界

RC1的WG01规定锚点战中固定、没有移动指令。此候选必须成为新的法杖范围规则，不能仅换动画就让现有原木杖自动移动。这里移动的是法杖的作用范围，不搬动敌人、地面或已生成元素。

第一轮限定三个预选锚点、按名义正常周期前进，取消／覆盖也推进，防止故意取消来永远停在有利位置。每次开始固定本次锚点与名单；持续L段保持该次范围，不能每刻扫出一次额外命中。下一周期选择下个锚点，第三个之后返回第一个。

首个实验只允许一根巡行杖，复诵沿原次锚点且不推进路线。场景上不能把一条从左到右的装饰光束误解为路经所有格都受伤。借位镜、余火被动范围等混合影响暂不纳入第一轮输入，正式推广前须逐条裁决，不能默默删除原效果。

#### 最小验证

比较固定范围与巡行范围：敌人同侧／分散两侧、相同库存、相同实际法术。若巡行减少分配词卡但增加处理优先目标的延误，可能成立；若固定F3已覆盖全部关键对象，巡行只是动画或纯惩罚，应直接记录无收益情境。

视觉解释见[巡行示意源](../../history/exploration-2026-09-24/insights/visuals/timeline-field-patrol.html)。该示意把两敌固定为存活，只展示范围和首个合法候选，不计算伤害、击杀、取消、环境变化或完整施法合法性，不能记作可玩原型或玩法验收。
