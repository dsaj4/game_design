## 构思概览与基准关系

已明确的探索对象是“支撑整款游戏的基础卡牌规则”，目标是简单清晰。具体玩家动作、约束、结算目标以及是否替换现有机制尚为Unknown。

核心摘要中的言咒以实际词卡构成完整法术，战前分配到法杖并安排范围、顺序与首次起点，战中自动执行；词卡实体分配、句义合法性、释放开始槽竞争、场上元素利用共同形成取舍。摘要的体验承诺是玩家知道法术为何成功或落空，并知道下一场该改什么。

用户已确认本方向“所有机制都可重做，另选基础规则”。现行构句、四杖、自动战斗及其他机制均不作为候选的硬约束；它们只提供概念层参照。是否保留词卡、法术题材或原体验承诺仍未决定，不能由“言咒探索”自动推断。该回答授权探索替代方案，未授权采纳或覆盖现行设计。若后续候选主动复用现行时间规则，仍须沿摘要保留AUD-010的未决状态。

## 探索方法建议（Agent Proposal / Raw Idea / Unqualified）

先用三句话描述一个候选：玩家反复做什么、必须遵守什么限制、怎样得到可见结果。再检查去掉特殊卡效果后，这个基础操作是否仍然能产生选择；后续卡牌可以改变已有取舍。此处是方法建议，尚未选出玩法。

“简单清晰”的暂拟讨论标准是：基础规则可以短句讲明，玩家能从牌面和局面预测一次操作的直接后果，并能说出选择A而放弃B的理由。标准尚待用户确认；不预设教学时长、胜率或卡牌数量。

### 当前待确认：词义合法性的公开规则

本轮暂将“词义关系匹配”定义为：卡牌连接的依据来自词的含义及它在表达中承担的角色，而非单纯同符号或数字关系。仅明确这个依据，不推定无限自由构句、条件牌、句长或AI裁决已获采纳。

当前唯一待确认问题：**词义匹配的合法性应该怎样让玩家判断？**

| 合法性规则候选 | 含义 | 当前状态 |
| --- | --- | --- |
| 有限公开句式 | 如“对象＋动作＋目标”；用少量公开结构帮助玩家直接判断，Agent推荐 | 未选择；例句结构尚未确认 |
| 词义接口接龙 | 每张词牌显示能接哪类词；逐步形成表达 | 未选择；连接类型与结束条件Unknown |
| 开放语义组合 | 主要按自然语言含义判断表达是否成立 | 未选择；一致判定及玩家预期如何建立Unknown |

Agent判断：合法性只是“能不能这样组”，仍需另行确定“为什么选这一句而放弃另一句”。公开、有限规则可能降低判断负担，但可理解性及策略深度尚未实测。推荐不等于用户选择；不因为选择词义匹配就继承现行言咒语法。
