## 原始表达与确认记录

用户原话：

> 将每一刻的行动设为一张卡牌，从左到右摆在桌上，对手也有同样的一行卡牌，但对手的先盖在场上。战斗开始，从左到右逐个翻牌，同时的共同翻开，代表一次战斗

2026-09-24，两次澄清：

1. 用户选择**“有部分线索，具体牌隐藏”**。确认信息结构；线索种类、数量、可靠性及侦察系统尚未确认。
2. 用户选择**“由词卡组成的一次完整法术”**。确认时间轴卡牌代表一次完整法术，延续词卡构句。它不是单张词分别执行一个动作，也未确认要新增一套独立动作卡。

因此已明确：双方各有一行行动，横向表达时间；同刻双方共同翻牌；敌方牌先盖住，战前有部分线索；每张行动牌代表由词卡组成的一次完整法术。

“一排代表一场战斗”按原话保留。牌翻完仍无人败北如何处理尚未确定，不能直接补成循环播放或再次排牌。玩家牌是否背面显示、双方行长是否永远相同、同时揭示是否同时生效仍为Unknown。

## 构思概览

**玩家先用词卡组成完整法术，再依据有限敌情把法术排成未来行动；开战后双方逐刻揭示，观察自己的准备、出手和防护是否落在合适时机。**

Agent提出的体验假设：桌面位置直接表达“何时发生”，帮助理解时间关系；暗牌要求预判并留出容错；逐刻揭示使玩家能找到计划奏效或失败的位置。用户尚未单独确认体验优先级，也未做试玩验证。

建议重点完善两类选择：

- **横向接续**：前一刻为后一刻创造条件，例如先准备元素，再用另一条完整法术消耗它。
- **同刻对抗**：这一刻的安排是否适合敌方行动，例如将防护安排在可能遭到重击的位置。

只有同刻克制而缺少前后联系，可能变成连续猜拳；只有自己的连招而敌方时点无关，可能变成固定最高收益序列。这些是风险推断，尚非测试结论。

## 待讨论的最小版本

本节均为 **Agent Proposal / Raw Idea / Unqualified**。用户只确认上节两项，以下不能自动视为采纳。

| 设计点 | 建议 | 必须保留的取舍与边界 |
| --- | --- | --- |
| 决策时机 | 战前排完整行，开战后自动揭示 | 延续战前承诺；是否有战中干预仍待明确 |
| 构句到铺卡 | 每条完整法术以一张行动牌展示，可展开查看组成词卡 | 展示不能免费复制实体词资源；重复释放与重复占用的关系待定 |
| 时间格 | 首轮讨论使用等长格，每格表达一次行动 | 新格是否等于原逻辑刻未知；不能默认把冷却或持续法术压成瞬发 |
| 行长 | 后续纸面验证可先用短序列，例如6格 | 仅为试验候选，不是正式数值；长度要兼顾规划负担和前后联系 |
| 敌情线索 | 优先考虑可靠但不完整的信息：某格属进攻类，或某段可能出现重击 | 类型提示、时间窗提示是可选方案，不自动全部加入；具体牌名与效果保密 |
| 敌方承诺 | 建议敌方序列在玩家确认前锁定，线索与序列一致 | 避免玩家排好后才针对性改牌；如何生成敌方序列尚未定 |
| 关键关系 | 先用准备、释放、防护之间的配合讨论 | 这些是法术承担的功能，不是已确认的新卡表或额外资源 |
| 同刻结算 | 候选：同时翻开，先确定本刻防护与合法条件，再共同结算双方伤害，最后检查终局 | 防护可应对同刻攻击；但与现行分阶段事件规则存在差异，尚未采纳。控制、打断和新状态生效时点需另定 |
| 复盘 | 保留已翻开的两行，解释关键格的成功或失效原因 | 让玩家能说明下一场要移动哪张牌，不只看输赢 |

不建议第一轮同时加入抢速、插队、推迟敌牌、临时换牌、侦察资源和复杂克制环。先验证基本关系，再决定是否需要额外机制。

### 四刻示意

下面只解释候选关系。动作是完整法术的功能简称，不是新词卡清单；四格不是已确定的战斗长度。

| 时间 | 第1刻 | 第2刻 | 第3刻 | 第4刻 |
| --- | --- | --- | --- | --- |
| 战前敌情示例 | 未知 | 进攻类 | 未知 | 进攻类 |
| 玩家法术安排 | 准备元素 | 防护 | 消耗元素攻击 | 防护 |
| 敌方暗牌揭示后 | 蓄力 | 重击 | 蓄力 | 重击 |
| 排位理由 | 为后续准备 | 抵挡本刻攻击 | 抓住可能的准备窗口 | 保住剩余生命 |

取舍应来自有限库存与时机：把防护提前，可以应对早期压力，却可能失去准备后续法术的机会；把消耗元素的法术提前，可能更早产生收益，却可能因元素尚未准备而落空。能否实际形成这些取舍，取决于最后确认的资源和结算规则，不能靠示意宣称深度成立。

## 相似机制研究

检索：2026-09-24；未亲自运行游戏。比较维度为预排整行、隐藏行动、按序揭示、同刻对抗。本次检索不能证明原创性，也不能证明没有更接近的产品。

| 游戏与来源 | 核实的相似机制 | 关键差异与参考价值 |
| --- | --- | --- |
| **Robo Rally（2023规则）**：[规则正文](https://www.rulespal.com/robo-rally-2023/rulebook)，Programming / Activation；[发行商入口](https://retailers.renegadegamestudios.com/robo-rally/) | 选5张卡背面排入1–5号槽；逐槽翻开所有玩家的对应牌，再执行行动 | 本次最接近“预排整行＋共同揭示”。其目标是机器人竞速，同槽行动按优先权依次执行，不是效果完全同时发生。可参考前序行动如何改变后续计划 |
| **弈仙牌**：[官方商店](https://store.steampowered.com/app/1948800/Yi_Xian_The_Cultivation_Card_Game?l=schinese)；[篝火营地实玩评测](https://www.taptap.cn/moment/350016546409549302) | 商店确认卡组构筑；评测描述战前排列招式、从左到右自动出牌，牌序支持组合 | 评测描述双方轮流行动、整行可循环，不是逐列共同揭示暗牌。适合参考“排牌后自动对战”。机制细节来自2022年历史评测，不冒充2026年全版本规则核验 |
| **Yomi**：[官方机制说明](https://www.sirlingames.com/yomi) | 双方每回合各放一张暗牌，同时揭示；不同动作有不同收益，为判断对手提供依据 | 每回合选择当前动作，不是预先排整场。可参考预测对手的依据，但不能将逐回合重选的体验直接外推到整行锁定 |
| **BattleCON: Trials of Indines**：[规则正文](https://www.rulespal.com/battlecon-trials-of-indines/rulebook)，Play Sequence / Reveal Step | 双方设置攻击组合并同时翻开，再按Priority确定主动方 | 不是预排完整时间轴，同时揭示后仍有行动先后。提醒本方向必须独立说明速度、打断和效果结算 |

来源边界：Robo Rally及BattleCON细节来自规则书文字转录，Yomi来自官方说明；Robo Rally发行商PDF抓取不稳定，因此细节使用成功读取的2023版规则转录核对。弈仙牌实玩评测与官方产品概述分别标识。未保存第三方全文快照。

研究结论：**卡牌时间序列和同时翻牌都有明确先例。** 本方向值得验证的差异候选是“词卡构句形成完整法术＋依据有限敌情安排其时机＋逐刻展示双方结果”。这些元素组合后是否产生独特体验，尚未证明。

## 资格缺口与下一步

已有可追溯表达、初步对象、可见流程与两项用户澄清；下面仍为Unknown，当前不晋级正式素材：

1. 同刻只保证共同翻牌，还是效果共同生效？防护、打断、双方生命归零如何处理？这是下一关键问题。
2. 同一法术多次铺入时间轴时，是同一套词卡的重复施放，还是要投入多套实体？与法杖冷却如何衔接？
3. 牌翻完无胜负时怎么办？空格、无效行动、跨刻持续、多敌人如何表达？
4. 采用现有执行的可视化，还是替换现有编排与循环？仅读CORE不足以宣称兼容。
5. 部分线索具体公开什么，可靠到何种程度？是否允许战中改牌？
6. 预期体验优先级与验证办法尚待确认；当前体验和测试建议均为Agent候选。

最小验证建议：**Planned / NotRun**。待行动资源与结算边界确定后，用同一套少量法术、两个不同敌情线索做纸面排牌；保持库存和强度不变，观察玩家是否因线索调整牌序，以及复盘能否指出具体调整位置。本轮未运行测试。

- 支持信号：敌情改变排位理由；前序准备实际影响后续；玩家能解释预测依据和失误原因。
- 反对信号：始终使用同一最高收益序列；输赢主要来自无从推断的暗牌；一次失误使后续全部失效；只觉得在等动画。
- 这些是验证候选，不是已确定验收标准；暂无平衡、可理解性或好玩证据。
