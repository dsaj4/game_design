### 候选 A：公开条件敌意——让敌人成为可以改写的题目

Candidate ID：`C-conditional-intent-v01`。目标对象：敌人／遭遇，GDD §5、§9。

**具体场景。** 一名“蓄击卫”公开显示：“第18刻行动；若行动检查时护甲仍大于0，重击；否则轻击。”在攻击图标旁显示条件及两个结果。18刻仅为纸面场景值，不是正式参数。

**新增规则草案。** 每个特殊敌人先只带一个条件分支，到既定敌攻时点才读取护甲状态并选行动；不隐藏随机改期。判定发生在该刻玩家法术之后、敌人自己的行动之前，因此玩家能计划临界刻破甲。轻／重击均为有限普通伤害，差值待定；敌方后续基础时刻不因为分支自动改期。

**玩家取舍。** 用直接伤害打掉甲并削血；用现有清除或元素消耗／拆甲先改条件；或者把词和释放机会留给自身防御、承受重击。清甲会占据一整根法杖及其共享槽机会，清空后再循环也可能无目标。元素拆甲有准备成本，但能把敌甲转成己方防御；绕甲攻击能更快伤生命，却保留敌方重击条件。相同敌甲由此成为“要不要拆、什么时候拆”的资源。

**与已有设计的区别。** 现有敌甲只参与耐久与合法支付；新候选让其成为敌人行动的可操作前提。不给所有敌人免费接入玩家冷却系统，不新增战中操作，不把冰冻误写成停攻。

**最小组合示例。** 清甲法术安排在重击检查前；防御法术安排在另一名快卫攻击前。玩家可能为了保住一次防御而延后清甲，或集中先杀快卫。是否真有相位空间必须按实际词时间核算，不能只凭画出两格宣称成功。

**防退化。** 条件失败只削弱招式，不成为唯一可通关路径；普通输出与防御应保留解法。首次只加一个条件，不同时开放敌方全套语法或第二资源条。若所有构筑都被迫带清甲，先修敌招收益差或条件窗口，不再添解锁卡补洞。

**未知与验证。** 重／轻差值、甲量、可读预览、跨流派应对是否均可达。先以同预算直接输出、拆甲转防、守住重击做纸面比较，再用真人看图预测。成功信号是敌情改变导致编排改变且理由可解释；失败信号是固定插一条清除后所有战斗同解。
