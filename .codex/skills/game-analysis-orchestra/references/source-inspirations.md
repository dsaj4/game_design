# Source Inspirations

This skill borrows process structure from PaperOrchestra and AutoSurvey, but does not copy their scientific-writing goal.

## PaperOrchestra

Relevant ideas:

- Pre-writing materials can be transformed into formal long-form output.
- An outline agent should plan the document before section writing.
- Section writing should follow a structured outline.
- Diagrams and plots deserve their own planning step.
- Deterministic scripts should guard schemas and coverage.

Deferred ideas:

- Literature review agent.
- Plot refinement loop.
- Peer-review-driven content refinement.
- LaTeX submission output.

## AutoSurvey

Relevant ideas:

- A long survey/report should be built from section/subsection plans.
- Reference material should be assigned before writing.
- Section count, section role, and local evidence scope should be explicit.
- Evaluation is a separate phase.

Deferred ideas:

- Large external retrieval database.
- Citation scoring.
- Survey-length tuning.
- Automated evaluation loops.

## Game Analysis Translation

```text
Paper idea/logs          -> game screenshots/transcripts/notes
Paper outline            -> eight-module game-analysis outline
Literature review        -> later competitive/reference research
Section writing          -> module-by-module dossier writing
Plotting                 -> core loop and system relation diagrams
Content refinement       -> later dossier review and rewrite
```
