# 新手说明：独立构思，共享方法

每款游戏有独立工作区。复用方法不会自动复用另一款游戏的设定。
当前从 [game-002](../workspaces/game-002/README.md)开始，其核心为战前法术编排与自动战斗，规则口径已形成稳定基线，具体参数与体验仍待验证。

## 两条项目流程

- research/：问题、资料选择、产品分析、假设、原型观察和复盘。
- game-design-workflow/：Raw Idea -> 资格确认 -> Qualified GDD Material -> GDD/Proposal -> Evaluation -> Draft Change -> Accepted/Parked/Rejected。

玩法 GDD 与代码进度分开。代码实现不能证明玩法成立。
[共享知识入口](shared-knowledge.md)只提供模板、方法、课程与规范；具体设计留在项目内。

新游戏的未知保持 Unknown。旧项目保存在[归档](../archive/2026-09-05-core-card-project/README.md)，默认不检索、不作为新游戏素材。
直接提出一个想法、参考产品或问题，agent 会在当前工作区记录，并一次确认一个关键问题。

## 玩法探索入口

[玩法探索区](../exploration/README.md)已建立最小骨架。指定“game-002 优化”会进入基于版本化背景包的优化项目；指定“独立肉鸽探索”会进入空白起点的新项目。两者各有原始想法、素材、评估和 GDD 目录，互不继承玩法；背景包和实验状态以各项目注册表及入口为准。
