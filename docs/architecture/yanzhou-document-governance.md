# ADR：言咒主系统与探索文档分离

日期：2026-09-23。状态：Accepted / Documentation。来源：用户确认执行全量整理。

## 问题与决定

现行GDD、核心摘要、阶段交接和FX历史重复陈述规则，探索背景存在旧包与显式RC1并行。采用一套current规则正文、固定来源历史、独立方向索引与专题比较。各系统拥有明确规则，参数和内容按ID引用。

## 备选与取舍

仅加顶部“以新版为准”成本低但不能消除正文冲突；直接删除旧文件破坏来源和已有链接；每轮复制整套GDD会形成多处维护。当前方案保留兼容入口与历史文本，增加一次迁移和链接维护成本，以减少后续规则漂移。

## 运行质量与失败处理

静态检查涵盖UTF-8、本地链接、锚点、内容ID、文件迁移与已有用户变更。历史文件不当作现行规范，原始包及第三方快照不修改。发现缺失旧外部路径记录为既有边界，不伪造恢复或新证据。新歧义保留Open，不能为了宣称全部Closed选定玩法。

## 边界与结果

不更改玩法、参数或运行代码，不引入线上服务、权限或账户。索引不复制密钥或外部私密配置。独立肉鸽和旧项目保持隔离。实际结果见[整理报告](../../workspaces/game-002/docs/governance/organization-report.md)。
