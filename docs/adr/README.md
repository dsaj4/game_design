# Architecture Decision Records

这里记录跨目录的知识系统、工作流和协作架构决策。ADR 只说明为什么采用某种系统方案，不替代 `AGENTS.md`、GDD 模板或项目核心构思。

## 当前记录

- [ADR-0001：采用分层游戏设计知识加工系统](0001-game-design-knowledge-system.md)

## 使用规则

- 只有涉及多个目录、长期维护或难以逆转的系统选择才新建 ADR。
- 项目玩法结论仍进入 `game-design-workflow/decision-log.md`；代码技术决策进入对应代码仓库。
- 方案改变时新增或更新 ADR，保留旧记录和 `Superseded` 关系，不删除历史上下文。
