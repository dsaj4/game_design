# 从 Snakes 源码看打击感与特效实现

## 为什么先读 Snakes？

在阅读《小丑牌》（Balatro）源码之前，作者建议先研究一款名为 Snakes 的极简肉鸽游戏。Snakes 据说是《小丑牌》的灵感来源，且《小丑牌》确实有部分代码直接来自 Snakes。它以 MIT 协议开源在 GitHub，同时上架 Steam，并获得特别好评。

Snakes 虽然体量小，但“肉鸽”游戏的核心要素一应俱全：道具设计、Steam API 的使用、伤害计算公式等，都值得作为学习样本。正因为《小丑牌》部分代码源自 Snakes，先厘清 Snakes 的代码结构，能降低后续阅读《小丑牌》源码的难度。

## 视频内容定位

游戏基础部分可以参考已有的笔记，本视频直接切入最有价值的部分——**打击感的代码实现**。打击感系统由多个视觉效果协同构成，包括：摄像机抖动、弹簧、闪烁、粒子、慢动作。

为了便于演示，作者提供了修改版源码：注释掉了 Steam 验证、增加了中文注释、补充了实验用代码，并做了汉化。打开源码后，在 `main menu` 的 `LOL` 相关代码处，可以找到打击感实验入口。按照注释取消对应代码行的注释，再按 F 键即可触发不同的打击感效果。

## 摄像机抖动效果

摄像机抖动是打击感中最直观的反馈。Snakes 的实现思路是：将 `objects` 依据物理行为和摄像机行为分组，由 group 统一绘制。在绘制前后分别调用 `camera.attach` 和 `camera.detach`：`attach` 保存当前坐标系并根据 `camera` 的 X、Y 建立新坐标系，`detach` 恢复之前保存的坐标系。

抖动函数被调用时，会在一段时间内不断改变 `camera` 的 X 和 Y。由于每次绘制前都重新建立坐标系，画面就会随着 X、Y 的变化持续偏移，从而产生摄像机抖动的视觉效果。视频中演示了 `camera.shake` 和 `camera.spring shake` 两种抖动方式，后者带有弹簧回弹的衰减特性。

## 弹簧效果

弹簧效果与摄像机抖动原理相似，核心同样是“改变坐标系”。`spring.pull` 会在一段时间内不断改变 `spring` 的 X 值，然后利用不断变化的 X 值来改变坐标系或所绘制物体的比例。

- 用法一：用 `spring.X` 不断创建新坐标系，让整个画面产生弹簧式位移；
- 用法二：用 `spring.X` 改变绘制物体的缩放比例，让物体本身产生弹性伸缩。

两种方式都能形成“命中后回弹”的打击反馈。

## 闪烁效果

闪烁效果通常用于表现命中瞬间的高亮。实现上调用闪烁器的 `flash` 方法，会让其 F 属性在一段时间内变为 `true`。然后在绘制物体颜色时检测 F 属性，若为 `true` 就绘制特殊颜色，否则绘制普通颜色。颜色切换本身即形成闪烁。

## 粒子效果

粒子效果用于增强命中时的视觉冲击。视频中略过了具体代码，但演示了效果：取消两处注释后，可以看到每两秒出现的红色粒子，分别对应 `hit pole` 和 `hit circle` 两种粒子形态。粒子效果的实现相对简单，作者建议直接阅读源码。

## 慢动作效果

慢动作适合用在低频、力量感强的行为上，例如《Snakes》中英雄死亡时就会触发慢动作。

实现位于 `sh.lua` 文件中的全局函数 `slow`。该函数控制一个全局时间缩放变量（例如 `timeScale`），然后将该缩放因子乘以 group 的更新参数 `DT`，即可让该 group 的更新速度变慢。具体来说，若缩放因子为 n，则 group 的更新速度变为原来的 n 分之一，从而产生慢动作效果。

## 总结与资源

本视频重点拆解了打击感中五种特效的代码原理：

1. 摄像机抖动 → 不断改变坐标系；
2. 弹簧 → 用动态 X 值改变坐标系或比例；
3. 闪烁 → 用 F 属性切换颜色；
4. 粒子 → 按时间生成粒子对象；
5. 慢动作 → 通过全局缩放因子影响更新速度。
