## 拟新增内容

建议目标核心新增“统一法术底层UF-v1.0”正式章节，写入如下文本；全部条款由本地正式素材提供完整细则。

```md
玩家在战前用实体词卡确定执行者、一个动作及其对象／资源短语，每条完整法术绑定一根法杖，最多四根。一张实体词卡同时只支撑一个出现位置。每根法杖最多安装一张改写卡，卡面同时声明可选条件与一种改写职责：增强、结果替换、支付约束或过载。

所有完整法术由正常循环启动。改写只在本杖获准释放时判断一个条件，成立则使用改写版本，否则使用基础版本；不得在事件发生时即时插队、复活取消机会或排队补发。普通冷却C计入全部装配词卡与改写卡的时间贡献，C与释放时长L均至少一刻，基础版与改写版共用L。首次冷却起点仍在0–10刻内安排。

同刻后置法杖先获开始槽，再确定名单、判断条件与检查费用；无目标或缺资源不把机会退回被覆盖法杖。实际生命伤害取消当时冷却机会，护甲完全抵住则不取消；取消保留名义结束点，之后继续自身循环。

相位与跨杖协奏统一为前两刻有效施法条件：只认指定另一根杖在t−2或t−1的正常主动作实际改变生命、护甲、状态量或对象存在。零结果、费用支付、被动与状态跳数不刷新；持续法术每次只在首次实际生效时记一次。两个普通法术相邻不自动获得加成，自身不能接续自身。

资源沿具体宿主的已有状态规则生产、保留及消耗。固定费用联合足额检查，明确限量消费按实付量；不得用本次自产资源支付本次动作，也不得返还同次同类消费费用。先用印记验证，再逐项迁移元素层数，不另建通用能量或热量经济。

过载首先适配即时直接伤害与护甲：本次实际产生正量结果后，下一轮冷却增加卡面D刻，每次最多计一次；无结果不产生新代价。已并入下一轮的等待不因那一轮取消退款，也不重复收取同一份代价。终局立即结束，终结一击无需额外等待；该优势留待整局平衡验证。

词的角色只在动作明确许可中复用。空执行者显示自身，空改写使用基础版，缺动作或必需对象属于非法配置。改写换目标或改费用必须明示；不开放万能类型转换、随机补齐或空槽额外奖励。

四阶段、固定名单、费用复查、首次来源、完整事件后胜负与疲劳继续按明确规则执行；一层后置响应不得启动新法术。UF范围暂缓旧复诵、跳／减冷却、多修饰与额外镶嵌改写，法杖特殊芯逐项复审。无冲突的路线、商店、休整与保存沿用，不增加永久成长或新货币。

基础／改写版本、条件、费用、实际下一次时刻及失败原因必须可查，未来依赖仅作条件投影。先教授普通短句，再逐一引入接续、资源消费与过载。两刻窗口为已确认待验证初值；具体卡牌强度、时间贡献与经济参数须成套重审，设计采纳不表示玩法已测试。
```

## 拟替换内容

### 修饰词的装配上限

目标“修饰词”章节原文：

```md
修饰词直接挂接本句的一张实体名词或动词；同一原词可挂多张，每张都直接修饰原词，不修饰其他修饰词。每张修饰词占用实体副本并贡献词卡时间，遵守普通库存与分配规则，不在每轮循环消耗。
```

新文：

```md
每根法杖的完整法术最多安装一张改写卡。卡片声明条件（若有）、适配范围、唯一改写职责、目标权限、费用及时间贡献；条件不满足仍执行合法基础版本。改写卡独占实体且贡献冷却，不在每轮施法消耗。旧修饰词和镶嵌只有通过UF迁移审查后才能进入新内容池，不依据旧多挂接规则叠加。
```

目标核心“G002-CORE-033”原文中的许可：

```md
普通实际C最低1，只有完整复诵及耗印跳冷却允许0。
```

新文：

```md
UF-v1.0所有普通冷却C至少1刻，释放时长L至少1刻；旧完整复诵、耗印跳冷却和其他跳／减冷却内容暂缓。仅过载可按明确条款延长下一轮冷却；不会制造当前刻或额外释放机会。
```

同步要求：不能只替换这两句而继续把RC01／02、RC03跳冷却、BR06多槽改写、WG01特殊芯、CG旧词卡和旧测试配置标为UF当前规则。对应段落应在后继版移入明确的历史／暂缓范围，并从当前规则入口统一路由至新版本；历史决定和RC1原参数保留来源身份。
