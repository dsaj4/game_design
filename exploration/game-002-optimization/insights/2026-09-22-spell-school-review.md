# 简易与元素流派简化：机制分析、边界与来源

- 日期：2026-09-22；Project ID：game-002-optimization。
- 研究状态：Research / Provisional；设计候选：[SF-v0.1](../idea-inbox/2026-09-22-spell-school-simplification.md)，Raw Idea / Unqualified。
- 设计前提：[UF-v1.0](../idea-materials/M-2026-09-22-unified-spell-foundation.md)已采纳；本研究不重开其16项决定。
- 证据：文档对照与手工反例推导；未运行游戏、模拟、原型或真人测试。本文不是正式Evaluation。

## 判断

推荐把现有流派整理为“直接兑现、敌人身上的印记、场上火焰储备”三个可比较方向。元素的主要复杂度来自自动作用、动态生产分支和环境转化，单纯改卡面无法消除。

因此SF-v0.1保留元素作为真实对象和资源执行者，建议关闭自动邻近与环境转化，把输出收回正常法术机会。代价是减少自动扩散的涌现；这项设计取舍必须显式确认。

冰霜另有结构问题：若简化成“储层换甲”，而护甲已能永久保留到本场结束，冰霜没有独有的储存优势。仅靠更高量值可以使它强，却不一定更有决策。推荐暂缓，优先让三种保留方向各自成立。

## 1. 现有复杂度具体在哪里

| 原结构／来源 | 玩家必须同时推理什么 | 推荐处理 |
| --- | --- | --- |
| 简易／状态／元素多类型，02类型章 | 语法分类与构筑家族不同；释放元素也可能是简易 | 保留类型定义，停止把标签当奖励；家族直接描述打法 |
| 复诵、蓄势、冷却操作，03 RC01–03 | 成功口径、额外开始、计数、兑现、未来周期 | UF已关掉一部分；再暂缓计数，利用同一个改写槽表达进阶 |
| 印记免耗，03 RC08 | 同一引爆有支付和不支付版本，关联后置消费触发不同 | 基础引爆付清；首轮不开放免耗与返还 |
| 元素释放，03 RC07及04 CORE-021 | 同种优先、敌人锚点、出生格、状态回退，每刻重新判断 | 固定格子，一次生成／补层／失败，过程不再逐刻切换工作 |
| 自动邻近＋指令＋应激，03 RC10 | 自动、主动、补层触发是否合并，哪一次能再触发 | 关闭额外邻近，所有输出来自正常主动法术 |
| 空心＋自噬，03 ST04 | 无自动作用时衰减也可能关闭，长期储层另成体系 | 不保留双修饰改变寿命；本体统一沿既有自然衰减 |
| 首次来源持久能力，03 RC04／12 | 哪根杖先创建、后补量是否改变反刺／逆霜等 | 来源身份保留；不开放同名状态的多种持久行为 |
| 元素、环境、状态与属性，04 | 哪些宿主有生命／甲、阈值、释放覆盖、补生与继承 | 当前入口不作用树草；保留基础状态和属性规则，不再叠环境资源网络 |

不把删规则数量当成好玩证据。关闭自动邻近会实质移除事件，固定落点会实质减少动态选取；把详情藏起来而继续执行所有旧规则不算本轮简化。

## 2. 为什么选择保留本体，但取消自动输出

| 候选架构 | 清晰度优势 | 主要损失／问题 | 本轮判断 |
| --- | --- | --- | --- |
| 全部改为目标身上的火冰状态 | 对象最少，准备／消费很容易解释 | 元素趋近印记，失去真实执行者与空间落点；UF合法角色复用更窄 | 保留为进一步缩减的备选，不优先 |
| 本体＋正常法术主动消费 | 可保留对象身份、场上储备、局部爆裂与多杖分工；所有输出共用开始机会 | 比自动法术慢，至少两杖；必须证明空间与储备值得成本 | 推荐SF-v0.1 |
| 简化自动邻近但保留本体＋目标状态 | 保留放置后持续影响战场的鲜明体验 | 仍有本体衰减、扩散、目标状态周期和主动消费四种节奏；易形成增殖问题 | 如用户重视自动扩散可重做，本稿先Park |

“关闭自动”不是永远否定自动元素，而是以本次明确的简洁优先级选一个可解释版本。若失去自动输出后元素无独立玩法，应承认本方案失败，不用隐藏免费产出补救。

## 3. 具体流派是否有独立选择

| 方向 | 决策来源 | 与其他方向的区别 | 可能退化的情形 |
| --- | --- | --- | --- |
| 直接攻防 | 当前威胁、短周期、改写占槽、相位与过载 | 不需要先建立支付资源，基础攻击可尽早清敌 | 只有一种最佳攻防比例，条件或过载变必装 |
| 印记 | 投入哪个敌人、等几轮、何时消费、是否留标记给条件 | 资源不衰减，但绑定目标；先死会损失投入 | 生产后立刻引爆永远最优，等待只是拖延 |
| 火焰局部爆裂 | 落点、生产与消费时序、范围名单、留量或耗尽 | 储备可跨当前目标保留，范围收益依真实位置；自身有衰减 | 地图总有唯一最优落点；或者永远单敌，退化成印记变体 |
| 火焰倾注燃烧 | 将储备转到目标，等待跳伤还是再用一杖提前兑现 | 将输出分布到后续状态阶段；与下一正常机会形成竞争 | 三步链过慢；提前引爆总优或永不值得；只增加计算 |
| 冰霜储备（Park建议） | 仅剩何时把量换护甲 | 当前没有足够明确的独有选择；护甲本身已经可储存 | 等价预算下被直接护甲支配；调大数量后只变成强制升级 |

比较不依赖新增货币或永久成长。元素多用一个格子并不自动算策略深度；必须出现“此处范围更好，但未来消费机会更差”等可观察的冲突选择。

## 4. 综合分析

| 维度 | 预期改善 | 明确代价或风险 | 如何推翻这项假设 |
| --- | --- | --- | --- |
| 可玩性 | 从少步骤攻防逐步引入准备与兑现，每次动作结果更容易理解 | 慢筹备可能在打断压力下始终无法成型 | 同资源条件下筹备只能依靠赠卡或人为降低压力存活 |
| 策略深度 | 目标宿主与场上本体的资源位置不同，配合四杖和实体机会成本形成选择 | 选择可能只是更高倍率，元素是昂贵的伤害前置 | 改目标、时间、位置后最优配置仍几乎不变 |
| 涌现性 | 构筑者自行排出护甲保护→生产→接续消费、局部多目标爆裂等可追溯配合 | 自动互养、环境转化等连锁明显减少 | 所谓组合只是卡面固定两件套，移除一个组件整条路线就消失 |
| 规则复杂度 | 生产一次、主动付费、不叠持久来源特性，因果路径更短 | 多宿主、来源、自然衰减和固有属性仍要学；不是零复杂度 | 学会UF后仍无法判断层数在哪、为何失败或何时消散 |
| 独特性 | 保留词义角色复用、元素真实执行者、法杖正常机会与局部范围 | 印记／资源爆发本身并不独特，关闭自动后元素表现可能平淡 | 玩家的策略描述只剩通用“先充能再攻击”，没有时间和位置因素 |
| 内容与维护成本 | 同一生产、支付、状态规则可复用，初版不维护环境阈值和多类被动 | 旧卡池、地图与敌人将来仍需重审，不能无成本套回RC1 | 后续每张卡都需要恢复一项新例外才能成立 |

以上均为机制推断，无虚构分数、胜率或用户理解结论。

## 5. UF兼容审查

| UF约束 | SF处理 | 边界 |
| --- | --- | --- |
| 单根动作、三位置、一改写 | 生产和消费分在不同正常法术；支付与交付是动作内固定步骤 | 一条法术不能自行产生所需支付再消费 |
| 实体独占、四杖 | 生成与操控分别占元素实体；示意配置不保证起始库存 | 不引入免费生产副本或第五杖 |
| 条件正常时判断；前两刻接续 | 生产的真实结果可供接续；层数仍须独立检查 | “曾生产过”不等于“现在够付” |
| 共享槽先仲裁 | 占位或资源失败不退槽；下一正常机会再试 | 固定落点失败不是自动寻找替代 |
| C／L及取消续排 | 每次生产只有一个结果，仍守正L及名义周期 | 本轮不宣告L＝1，不用减少事件偷偷改时间 |
| 宿主资源与实付 | 敌印记、目标燃烧、本体层数各自读量 | 无隐形跨宿主转账；状态／本体不共用全局池 |
| 过载 | 本批适配范围比UF更窄；仅保留玩家直接攻防及合格引爆 | 不复议已确认的D、取消无退款等底层 |
| 首次来源与状态／四阶段 | 身份、来源、衰减进度和状态顺序继续保留 | 内容层关闭自动／特殊来源能力，不删除底层身份规则 |
| 有限角色复用 | 元素可以被生成、补量和用作执行者；状态可生成／引用／消费 | 不让所有元素自动适配所有动作 |
| 不即时加放、不多改写 | 本体不因补层、消散或操控自动放另一个动作 | 不能以“基础能力”重建已暂缓的复诵链 |

SF对RC1自动邻近、环境转化、释放过程和主动爆裂范围的变化，是明确的内容层替代候选；不能把“保留UF”表述成“没有改变旧元素机制”。

## 6. 手工反例：检查候选边界

以下是规则推导，不是执行测试结果。

| ID | 情境 | SF预期结果 | 主要检查点 |
| --- | --- | --- | --- |
| SF-C01 | 标记生产与引爆计划同刻开始 | 后杖赢槽，败者本次取消；若引爆赢但没有量，双方都可能无收益 | 不给筹备流特殊让位 |
| SF-C02 | 有印记的敌人被别杖先杀 | 印记随宿主结束，引爆绑定不自动改目标 | 目标投资风险 |
| SF-C03 | 同一敌人同时有印记和燃烧 | 两种量并存；每次引爆只支付所选一种 | 没有打包读取 |
| SF-C04 | 释放固定格被树占据，别处有空格／同种 | 本次失败，无回退无移位；赢槽仍消耗机会 | 固定格是否真的易预测 |
| SF-C05 | 固定格已有另一杖创建的同种 | 只补量，来源和衰减进度不改；原创建者引用仍指原身份 | 没有偷换归属 |
| SF-C06 | 本体归零，下次释放在原空格新建 | 得到新身份；旧实例引用失效，合法条件引用可在以后重新选取 | 位置动作与实例绑定分开 |
| SF-C07 | A前一刻补火，另一杖已把火用尽，B接续A | 接续条件可能真，但B无合法资源而失败 | 接续不担保费用 |
| SF-C08 | 爆裂支付耗尽本体，名单有多个敌人 | 整次支付一次，对付款前固定的合法名单交付；无第二份消散伤害 | 自耗完成与多目标费用 |
| SF-C09 | 爆裂没有合法相邻敌人 | 不付层数，本次无结果；不转去攻击远处敌人 | 不为范围失败赠收益 |
| SF-C10 | 同一火焰被两条法术依次消费 | 各读取实际剩余；后者不足按自己的上限模式处理，归零则无执行者 | 没有预留或重复支付 |
| SF-C11 | 倾注后源火焰消失 | 目标上已成立的燃烧继续；其跳伤不写接续记录 | 本体与状态独立身份 |
| SF-C12 | 本刻法术阶段消费全部燃烧 | 后续状态阶段无该状态，不补发其本刻跳伤；已经结算的往昔伤害不撤销 | 提前兑现确实放弃收益 |
| SF-C13 | 元素旁有同种元素和树草 | 没有自动邻近、互补层或环境转化；只能等正常法术明确作用 | 旧自动规则不会暗中复活 |
| SF-C14 | 释放装接续增强，消费杖也有接续增强 | 前者只增加本次生产量；后者只按自己本次条件增强结果；不获得生产卡的第二份增幅 | 一杖一改写不等于全链只一张，但也不跨动作复制 |
| SF-C15 | 冰霜方案与直接护甲在同投入、同总量下比较 | 直接护甲更早保护且不衰减；冰霜的独立优势尚未成立 | 接受搁置，不能只称“更深” |
| SF-C16 | 敌人带固有冰属性而身上有燃烧 | 属性修正和当前状态分别判断；本次消费燃烧不当成自然衰减再乘属性 | 保留的状态复杂度仍须解释 |

还有平衡上无法由本表回答的问题：伤害经取整变零是否频繁、火焰是否活得到消费时刻、范围爆裂是否成为通解、短句是否始终压过筹备、过载終结收益是否过强。答案必须来自后续明确输入，不能从这些反例推出“已平衡”。

## 7. 后续最小验证建议，不在本轮执行

先用没有特殊来源、环境转化或过载的简单场景比较直接攻防与印记；再加入同预算火焰生产与局部爆裂；最后加入燃烧与提前引爆。每层只增加一类决策来源，不同时补完整卡池。

应观察：

- 玩家能否预判固定格生产、费用不足、资源已被花掉和目标死亡的结果。
- 相同库存与合法实体预算下，不同敌人数、空间位置和公开攻击时点能否改变配置选择。
- 玩家能否解释等一轮／现在消费的得失，而非只寻找最大显示伤害。
- 元素角色复用能否从已有词义推导，还是必须背“生产杖＋消费杖”的固定答案。

成功信号是能解释、能因场景而调整、至少出现可比较的有效方案；失败信号是总有同一通解、准备流只有额外赠卡才可用、元素只是多步骤普通伤害。具体样本、量值、阈值和合格标准须在后续验证范围内制定。

冰霜先进行概念复审：找到不依赖“数值更大”的独立选择后再讨论启用；否则继续Park。不能为了完成流派数量指标加回已删除的被动链。
