## 2. 问题诊断

| 上一轮现象 | 对理解的实际影响 | 新候选的处理 |
| --- | --- | --- |
| “专注的”含目标印记、条件和50%增强 | 卡名不足以推出任何具体规则 | 条件和量若需要就明确表达；本轮暂不带入 |
| “转守的”替换结果却仍需原敌人合法 | 玩家容易把一句话读成另一种目标逻辑 | 来源、去向都在转移句里出现，合法性来自句中角色 |
| “火焰／燃烧／倾注”各自携带专属权限 | 玩家先背类型白名单，再背资源换算 | 初版统一生物身上的火，只做同类数量操作 |
| “爆裂”同时决定支付、空间、名单和结果 | 一个词隐藏多项独立决定 | 群体作用由空间与集合关系显式表达；引爆暂缓 |
| 23卡、6配置都合语法 | 只能说明文档没有违反自身配置约束 | 新标准是未示范句子的预测与自主构造，不把静态合法当直觉成立 |

核心不是卡面字数。完整效果写得再清楚，若每张新卡都新增一套例外，知识仍不能迁移。

## 3. 同一词义的替换检查

一个合格原语必须能接受合法角色替换而保留自身意义。不能要求所有词在所有位置合法；但类型解释必须统一，而不是每个配方再发许可。

| 固定部分 | 改动 | 仍不变化的规则 |
| --- | --- | --- |
| 转移动作、敌人到自己 | 护甲换火 | 来源减少的实际量就是去向增加的量；没有额外转换 |
| 增加动作、3点火 | 敌人换自己 | 接收方增加火；不会因自己是玩家就自动变成火焰护盾 |
| 移除、自己、最多3点 | 火换护甲 | 指定存量减少；移除护甲不会被解释成自伤 |
| 造成伤害、3点 | 单目标换“每个”名单 | 同一伤害规则逐个应用；不因是群体而变元素爆炸 |
| 有护甲的敌人 | 伤害换移除火 | 筛选只决定对象，不提供额外倍率 |

后两行属于第二层关系词候选；不是本轮四动作核心已经实现的功能。

## 4. 20项手工反例推导

全部为对书面规则的人工演算，状态为Reasoned / NotRun。普通生物、无属性免疫、单刻合法法术，除特指外没有额外增益。

| ID | 情境 | 规则应给出的结果／暴露的问题 |
| --- | --- | --- |
| SL-C01 | 敌人2甲，受到3伤害 | 失2甲、1生命；“3伤害”不等于必失3生命 |
| SL-C02 | 给有1火的敌人增加3火 | 变4火；增加时不额外造成4伤害，等待状态阶段 |
| SL-C03 | 敌人5甲，移除最多3甲 | 变2甲；自身不加甲，敌人不失生命 |
| SL-C04 | 敌人2甲，转移最多3甲给已有1甲的自己 | 敌人0甲、自己3甲；只搬2，不凭空补足3 |
| SL-C05 | 自己4火，转移最多3火给已有1火的敌人 | 自己1火、敌人4火；搬运时无一次额外火伤 |
| SL-C06 | 敌人A2火、B1火，把A最多3火转给B | A0、B3；若都存活到状态阶段，仅B承受3点该类伤害 |
| SL-C07 | 给敌人增加3甲 | 合法且通常不利；不能为保护预设流派把结果改成扣甲 |
| SL-C08 | 移除自己最多3火，但只有1火 | 移除1；不回生命、不产生1点通用能量 |
| SL-C09 | 敌人无甲，尝试转移其甲 | 两端合法但实际量0；不算有效施法、不补发、仍占开始机会 |
| SL-C10 | 来源和去向绑定同一人 | 编排拒绝，无真实转移；不允许以一减一加刷新接续 |
| SL-C11 | 来源有火，去向已死亡或超范围 | 整次转移无结果，来源不扣；开始槽不回退 |
| SL-C12 | 来源敌人已死亡，原身上曾有火 | 死亡后的历史量不是可搬运资源；不复活、不自动转绑 |
| SL-C13 | 当前有3火，状态期按演示法则处理 | 先3伤害，再降为2；若事件已判胜负则沿统一停止规则 |
| SL-C14 | 从A搬2火到B，再由另一杖搬回 | 若中间无衰减总量不变；两次分别占机会，不能因“重新施加”各乘倍率 |
| SL-C15 | 尝试“把敌人的3点伤害转给自己” | 非法配置；伤害是事件，不是候选开放的存量 |
| SL-C16 | 尝试从自己搬3火给每个敌人 | 初版非法：去向需单一对象；不默认复制或猜测均分 |
| SL-C17 | 第二层：指定格周围有3敌人，仅2人在杖范围 | 最多选范围交集里的2个；没有“每个”时仍只取一个 |
| SL-C18 | 第二层：对有护甲的敌人造成3伤害 | 按条件选目标，伤害仍3；不继承SCF的专注倍率 |
| SL-C19 | 第二层：给每个敌人增加3火，名单有2人 | 每人3、总共6；这只是数量语义，不能证明现有成本平衡 |
| SL-C20 | 高优先级转移没有资源，与低优先级伤害同刻开始 | 转移先赢槽后得0结果，伤害被覆盖；SL没有暗改UF的调度 |

20项推导没有靠新增专用卡补齐，但不构成真人可理解性的证据。尤其“火会伤甲还是绕甲”“搬运后是否立即跳伤”“每个3是否总3”等仍是必须实际测的理解点。

## 5. 可玩性、策略深度、涌现与复杂度

| 维度 | 候选可能带来的收益 | 仍未解决的风险 |
| --- | --- | --- |
| 清晰度 | 四个动作保持意义；来源、去向、状态和量直接可读 | 受控语言仍需教学；中文省略和长句可能让玩家漏看关系 |
| 可玩性 | 自救与进攻可由同一搬运产生，局面直接影响价值 | 若常见局面没有可搬的量，玩家只会一直增加和伤害 |
| 策略深度 | 比较提前制造与临战回收、分散与集中、来源与目标 | 同C同量时夺甲可能支配移除；不做参数不能宣布成立 |
| 涌现 | 新用途由换词推出，研发不必逐个登记配方 | 组合数增长不代表有用选择增长；合法弱句可能占绝大多数 |
| 规则复杂度 | 去掉23卡中的大量独有例外，可用一张词义表教学 | 复杂度会转移到目标选择与世界规则；每加一种免疫都可能侵蚀一致性 |
| 内容成长 | 新状态或关系能复用已有动词，发现面更大 | 动作同质化、稀有词只变数字、语句越来越长 |
| 时间编排 | 搬运要赶在伤害／死亡／火衰减前，先后顺序有含义 | 仍有抢槽与受伤取消；看懂句子不等于看懂整条时间轴 |
| 流派特色 | 攻防处理眼前结果，火处理在宿主间分布的持续量 | 移除实体火与爆裂后，元素的空间存在感和爆发吸引力下降 |

这里不打综合分；没有对局或用户数据支持精确排名。建议推进的是语义假设的验证，不是直接采纳整套底层。

## 6. 不能靠隐藏例外处理的平衡问题

### 夺甲与剥甲

敌人有甲且我方需要甲时，同量同周期的夺甲既破甲又防护，通常比单纯移除更有利。额外目标词的时间占用可能形成代价，但具体时间未定，不能当作已经平衡。

后续应在相同总预算下比较：转移较长的配置／周期、双端范围要求、获取成本，是否足以让短句在紧迫窗口中有用。若不够，可以调整整个动作强度或成本；不要写“护甲转移只生效一半，但火转移又是另一公式”。

### 搬火与重新点火

搬自身火可能兼顾减压和输出；搬敌人之间的火只是调整既有分布，耗时可能不如直接增加。需要有即将死亡、位置受限或必须集中威胁的场景，且玩家能预见它们。

不能为证明搬火有用，专门把所有敌人做成只有搬火才能打败的谜题。先检验一般战斗中是否经常有合理用途。

### 聚集与分散

演示法则每宿主每刻衰减1，会让集中3火与三人各1火的未来总量不同。这是世界规则自然导出的差异：集中更保留总量，分散可同时影响多个对象。但死亡过量、击杀顺序、范围与搬运机会也会改变优劣。

若这个差异过强，应调整统一衰减法则，再重测所有句子；不能对“集火配方”另写特殊损耗。

## 7. 内容准入和验证顺序

每个新词先过四个问题：

1. 能否用一句话说清它固定改变的东西？
2. 换成另一种合法状态／对象后，玩家还可用同一条解释吗？
3. 不展示完整配方，玩家能预测它参与的陌生句子吗？
4. 它是否带来新的决定，而非只给一个旧效果换名？

新状态首先定义世界作用与承载对象，再接入增加／移除／转移。若它只对一张专属配套卡有意义，先不当作底层原语。关系词只改变选择关系；不得附带隐藏加成。

验证分开进行：

- 语义：小样本词义迁移与自主构句；门槛见候选第8节。
- 选择：同预算的小规模对局夹具，验证不同法术各有合理情境；不铺开完整卡池。
- 身份：直接攻防与火量经营是否被玩家识别为不同玩法；不靠名称或美术提示作答。

若语义不过，先改词义／句法；若语义过而选择不过，改代价和世界情境；若流派身份不过，再决定是否恢复实体层。三类失败不能混称“需要多加几张卡”。

## 8. 结论与边界

推荐把“用固定动作操作明确存量”作为下一轮主要候选。最有说明力的例子是同一个转移词自然产生夺甲、自身灭火兼点敌、敌间集火，而非再命名三种技能。
