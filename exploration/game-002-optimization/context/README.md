## 本地已确认术语：UF-v1.0

2026-09-22用户确认UF-T01–16，形成[统一法术底层正式素材](../idea-materials/M-2026-09-22-unified-spell-foundation.md)。下表是本地新规则的词汇，不改写活动背景包或冒称目标RC1已同步。

| 术语 | 含义 | 区别 |
| --- | --- | --- |
| 改写卡 | 为一条法术提供一种结果或支付改动的实体组件，可带明确条件 | 不等同额外法术或任意程序 |
| 定时应变 | 在本杖正常机会根据条件采用本次效果版本 | 不等同事件即时施法 |
| 接续 | 利用指定另一根杖近期有效施法的条件 | 不等同免费合击或全局连击值 |
| 有效施法 | 正常法术的主动作实际改变合法对象的生命、护甲、状态量或存在 | 不等同仅合法但零结果的成功事件 |
| 过载 | 用下一轮额外等待换取本次直接结果增强 | 不等同可交易债务或随机失控 |
