# 战场编译器：读战场，写一句，押一个时间点

## 原始想法

把现有施法体系的核心特色从“寻找更强的词卡配方”转为“根据当前战场，编译一句要在特定时间兑现的命令”。玩家仍用名词/动词词卡构句，但每句话必须选择 `Now`、`Commit` 或 `Echo` 之一；时间姿态决定效果何时成立，也决定风险、机会成本和后续组件空间。

## 触发来源

用户提出“如何修改现有施法体系的核心设计，使其更具策略深度，更具差异化”，并要求提炼类似“大巴扎：背包管理+组合机器”的简单核心原则。研究洞察见[I-20260909-001](../insights/2026-09-09-casting-system-distinctive-directions-analysis.md)。

## 可能带来的玩家体验

玩家不是背配方，而是在敌方意图公开的情况下判断：现在兑现是否足够、是否值得冒险等待更强的结算、是否先埋下回响让下一次选择变得更好。目标体验是“我知道这句话会怎样改变局面，也知道我为什么选择这个时间点”。具体体验仍为 `Unknown`。

## 暂定标签

- 类型：Mechanic / Core Casting Principle
- 玩法关键词：词卡组合、时间语法、公开承诺、打断风险、状态依赖
- 风险关键词：延迟支配、回响递归、UI 复杂度、固定姿态最优、隐藏触发
