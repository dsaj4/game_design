## 新方向登记规范

新想法先进入idea-inbox；存在独立的玩家选择、修改对象或可单独验证假设时分配下一个DIR编号。一份文件的多项候选分别索引，别名合并须保留来源。新版本保留原Candidate ID并递增修订，不另造近义重复方向。新增后同步比较、背景适配、问题和运行索引；未完成比较写Unassessed，不填想象的评分。

暂停、否决、吸收只改变状态，不删除原条目。未来任务默认只读所选方向；本次全量比较是用户明确授权的管理整理，不撤销其他任务的“不阅读其他方向”限制。
